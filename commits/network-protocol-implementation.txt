docs: 网络协议实施设计——v0.x WSS+二进制帧，v1.0 QUIC迁移路径

三层架构：设备(UART)→边缘(feelingsd)→服务器→客户端
v0.x: tokio-tungstenite + axum WSS + rustls TLS 1.3
v1.0: quinn QUIC 全栈，只换传输层不换帧格式
二进制帧 16B 固定头 + Stream ID 多路复用 + CRC-16
JWT 认证 + 数据最小化（原始信号不出边缘）
离线降级：本地 PbmStore + 重连批量同步

Q1-Q4 已拍板：
- 自定义帧保留，不切 protobuf
- 边缘走纯 WS client，v0.7+ 再加本地 HTTP
- 数据库 SQLite→PostgreSQL，schema 留给 ADR 015
- 同步触发走 epoll LT/ET 事件源（Core ADR 014）
