docs: Feelings 运行时状态机——从冷启动到完整闭环，九阶段链路，用户给方向教练选配方机器帧级执行

- 九阶段总览——冷启动建基线建档监听等事件合议评估选配方注入微调静默安全档案进化
- 冷启动 Session Zero——采集不刺激建基线建档安全验证——零数据先探索推荐系统同构——这轮不刺激为将来刺激得准
- 监听态——采集跑触发器站岗教练休眠——四类触发源用户声明身体异常场景变化定时任务
- 评估态——多 agent 合议实时乘档案乘意图——三职能陪伴深度安全——安全 Agent 权重最高
- 匹配态——四重约束场景状态意图档案边界——选主旋律配方——调整是旋律内切换是旋律间
- 注入态——FPGA 设备内帧级零延迟——教练介入方案不介入执行
- 微调态——反馈梯度维持微调切换静默停止——帧级微调会话级复盘
- 安全态——P0 物理直刹任何阶段可进入——漏桶临界异常停止
- 档案进化——基线漂移偏好更新耐受模式安全阈值断档历史平均
- 角色分工——用户声明最高权限教练合议选配方 FPGA 帧级执行档案长期背景
- 放 design 目录——系统运行时行为设计用户体验是表现层
