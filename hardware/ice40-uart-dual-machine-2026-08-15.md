# iCE40 UART 双状态机 FIFO 调试全记录——仿真通过，板级未通

> 作者：qc
> 日期：2026-08-15
> 性质：硬件调试日志
> 结论先行：串行架构 + 停止位采样 + FIFO（2a 版）板级验证通过；双状态机并行版（2b，单颗 iCE40 内部 RX/TX 两个独立子机，与双 FPGA 无关）仿真逻辑验证正确（0xA5 逐位回显），板级仍不回显。仿真与物理之间的这条缝，记在这里。

## 一、增量阶梯——今晚的路线

```
步进 1   working + 停止位采样        → 板级 ✅
2a       步进1 + FIFO16（串行）       → 板级 ✅
2b       双状态机并行（单颗 iCE40 内，    → 仿真 ✅ / 板级 ❌
         RX/TX 独立子机；与双 FPGA 无关）
```

每一步都是小 diff、可审、可回退。前两步确认了：停止位逻辑无罪、FIFO 机制无罪。

## 二、2b 找到并修掉的真 bug

### 1. 多驱动冲突（真凶）

`push_pend`/`pop_pend` 被两个 always 块同时写——yosys 报 "multiple conflicting drivers"，综合出垃圾逻辑。

```
修法：单驱动纪律
    事件脉冲（rx_good/tx_req）由源块独占写、每拍自清零
    pending 标志只在结算块里写
    跨块信号全是寄存器，无脉冲握手
```

### 2. 索引写时序

`rx_data[rbit] <= rx` 的 8 路写使能解复用器 + 全局 CE 分布，是拖垮 48MHz 时序的长链。

```
修法：移位寄存器装载
    rx_data <= {rx_data[6:0], rx}
    TX 同步改移位发出 tx_data[0] + {1'b0, tx_data[7:1]}
```

### 3. nwords 竞争

RX 入队和 TX 出队同拍相遇时，两个 `nwords <=` 非阻塞覆盖，计数漂移。

```
修法：统一结算点（先消费 pending 再锁存新事件）
```

## 三、板级负面结果（该进 FORGET 的）

**HFOSC 的 CLKHF_DIV "0b01"（24MHz）在这块 UP5K 板上不出时钟。**
症状：绿灯常量、tx 冻结在 0、CP2102 RXD 常亮——所有寄存器停在复位值。
FORGET P2 里"未经验证"四个字，今晚被验证了：不能用。时钟只有 "0b00"（48MHz）一条路。

## 四、仿真记录（iverilog）

- yosys sim 的 `-clock` 机制玩不转，弃用
- brew 装 iverilog 13.0
- 两个自坑：
  - 单位误会：显示格式串里自己写了 "ns"，$time 实际是 ps——时钟根本没坏，是我自己骗自己
  - 寄存器无初始化：仿真里 x+1=x、rstate==0 对 x 恒假，状态机永远不启动——真 FPGA 上电为 0 天然没问题，仿真需要显式 initial
- 最终结果：发送 0xA5，TX 波形 1,0,1,0,0,1,0,1 逐位正确——RX→FIFO→TX 全链路功能正常

## 五、仿真与物理的缝

逻辑仿真通过，板级仍失败。板级现象：绿灯常量 + RXD 常亮 + TXD 按一下闪一下（2b 固件确认在跑，行为不对）。

未解决的嫌疑：

```
① 固件生效问题    拖拽烧录是否真正替换了旧 bitstream
② 上电时序        CP2102 枚举前 TXD 电平状态
③ 板级特定行为    仿真里测不到的物理细节
```

下一步板级隔离（FORGET 调试法）：
先烧 known-good 确认硬件 → 对比心跳速率确认固件生效 → 拔 TXD 看 RXD 是否还亮（区分"FPGA 在狂发"还是"RX 在狂收"）。

