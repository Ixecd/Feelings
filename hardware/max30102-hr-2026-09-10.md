# 心率估计做进 FPGA（板上实时 HR）— 2026-09-10

> 板子: iCESugar (iCE40UP5K-SG48) + MAX30102
> 目标: 不再把原始 PPG 传给 PC，**在 FPGA 上直接算出心率**，串口只发结果
> 结果: ✅ 板上实时输出 `HR=NN`，手指按稳时稳定在 **~67 BPM**（65~70 波动）

承接 `max30102-ppg-bringup-2026-09-10.md`——那里只把原始波形搬到 PC 算；
这里把"算心率"搬回设备端。

---

## 一、为什么做进 FPGA

- **隐私红线**：`docs/architecture` 要求原始生理数据永不离开设备，PC 上算只是开发期临时
- **脱 PC**：阶段 9 要电池供电独立运行
- **省带宽**：原始 150 B/s → 结果几 B/s
- **实时**：为后续闭环铺路

---

## 二、算法（全定点/整数，无浮点）

```
原始 RED(18bit, ~100sps)
   │  ① 高通去 DC   dc += (x-dc)>>5       → 去基线（~0.5Hz）
   │  ② 低通去噪     sm += (ac-sm)>>2      → 去高频（~4Hz）
   ▼   得到 0.5~4Hz 带通信号（脉搏频段）
峰检测
   │  ③ 3 点局部极大（d1>d0 && d1>d2）
   │  ④ 迟滞阈值：>75%(thr_hi) 记为候选峰；落回 <25%(thr_lo) 才重新"武装"
   │  ⑤ 不应期 300ms（防二次波/抖动重复计数）
   ▼  每个心跳一个峰
   │  ⑥ 相邻峰间隔 IBI（1ms 计数器测，墙钟时间，与采样率无关）
   │  ⑦ IBI 离群抑制：偏离均值 >25% 丢弃（防运动伪迹假拍）
   │  ⑧ IBI IIR 平滑：avg = (avg*3 + ibi)/4
   ▼
BPM = 60000 / avg_ibi   （迭代减法除法，一次/心跳，多周期无妨）
```

- **迟滞（75%/25%）**是抗抖动的关键：没有它，一个心动周期里的二次波/毛刺会造成假拍
- **IBI 离群抑制**挡住运动导致的偶发假间隔
- 包络 `emax/emin` 用慢衰减自动跟随幅度（手指压力变化），阈值随之自适应

## 三、RTL

- `hr_estimator.v`：上述算法，输入 `sample_valid` + `sample[17:0]`，输出 `bpm`/`beat`/`ibi`/`quality`
- `max30102_hr.v`：顶层——配置 MAX30102 → **~100sps** 读 FIFO（仍是"读 WR_PTR → 对齐 RD_PTR → 读 6 字节"）
  → 把 RED 喂给 `hr_estimator` → 每检测到一次心跳，UART 发一行 ASCII：`HR=NN\r\n`
- 时钟降到 **12MHz**（24MHz 时序不收敛，关键路径是 24 位包络运算 + 17 位除法）

正弦/端口：`SCL=ball46, SDA=ball44, tx=ball6, led=ball39`（同 PPG 工程）

`sim/tb_hr.v`：合成 PPG（72 BPM 正弦 + 0.3Hz 运动伪迹 + 噪声），100Hz 喂入。

## 五、踩的坑

1. **分频计数器未复位**：`tc` 仿真初值 x → `ms_tick=x` → 时基不走。
   （和 `i2c_master` 的 `divc` 同一个坑；硬件上电为 0 不暴露，仿真必须复位）
2. **首拍死锁**：用 `ms_since_beat < 2000` 同时做"检测条件"和"IBI 有效性"，
   首拍前该值一直涨超过 2000 → 永远检测不到第一拍。改为：检测只看不应期，`<2000` 只用于 IBI 有效性。
3. **启动瞬态**：DC 从 0 开始 → ac 首个样本达 100000，把包络顶到 46000，要 4 秒才衰减下来。
   改为**首个样本直接把 dc 对齐**（ac=0）。
4. **时序不收敛**：24MHz 下最高 18.6MHz（FAIL）。降 12MHz（`CLKHF_DIV="0b10"`）后 PASS。
5. **假拍导致 HR 乱跳**（实测 103/73/58 乱跳、末尾一路涨到 127）：
   加带通 + 迟滞阈值 + IBI 离群抑制后，实测稳定 **~67 BPM**。

## 六、复现

```bash
cd hardware/ice40-max30102
make                          # 默认 TOP=max30102_hr → max30102_hr.bin

# 拖 max30102_hr.bin 到 iCESugar 盘 → 拔插 USB
# 接线 SCL→P46, SDA→P44, VIN→3V3, GND→GND, tx(ball6)→CP2102 RXD

stty -f /dev/cu.usbserial-0001 9600 raw
cat /dev/cu.usbserial-0001     # 手指按稳，应稳定打印 HR=NN
```

实测（手指按稳，~100sps）：
```
HR=067
HR=067
HR=069
HR=069
HR=067
...
```
