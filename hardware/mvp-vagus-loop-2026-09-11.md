# MVP 实验方案 —— 迷走闭环核心假设验证

> 日期：2026-09-11
> 性质：动手清单，不是架构文档
> 目标：用**现有硬件 + 最小新增**，验证 Feelings 的核心假设
> 背景：见 `hardware/DISCUSSION.md` 第十三节——OS/Core/FPGA 全部挂起，先证效应

---

## 0. 核心假设（一句话）

> **用 HRV 作为自主神经状态的代理，对耳部施加轻微刺激（先声音、后 tVNS），
> 形成"感知→调节"闭环，能产生可感知、且可测量的有益效果。**

（第一台设备选迷走：tVNS 有文献、HRV 能客观衡量、有清晰安全边界——闭环假设里最容易证伪/证实的一个。）

---

## 1. 为什么先做这个

- 后面所有东西（OS / Core / 9 Pass / 新 MCU / 小 FPGA）都建在"闭环有用"这个地基上
- 证真 → 往上加得有理；证伪 → 省下几年
- 且 **S0（建基线）本来就是 ROADMAP 阶段 0 的任务**，不白做

---

## 2. 系统构成

```
感知:  MAX30102 ──I2C──► iCESugar ──UART──► PC (Mac)
       耳后/手指 PPG      (已通, ~67BPM)     HRV 计算 + 规则 + 日志
                                             │ 触发
执行:  ① 声音: PC 直接 afplay（零新硬件）
       ② tVNS: PC ──UART──► iCESugar ──I2C──► MCP4725 ──► LM334 恒流 ──► 耳电极
                           (复用现成 I2C master)  (设电流)    (隔离+软启动+OVP)
```

**全部现有件**：iCESugar、MAX30102、CP2102、LM334、MCP4725、ISO7721、B0505S、耳夹电极。
**新增**：PC 侧一个 Python 脚本（改 `tools/ppg_capture.py`）+ iCE40 加一段"收 UART 命令 → 设 DAC"（小改）。
**不用 nRF52832**（无资料，已放弃）；规则先跑在 PC 上。

---

## 3. 分阶段实验设计（由小到大，每步有判据）

> **测量哲学（2026-09-12 修订）**：不做"实验室式静坐 A/B/C"——它把真实情境（注意/活动/情绪）全剥掉，
> 测出来的东西日常不成立。改为：**自然情境（工作/刷手机/放松）+ 连续记录 + 动态基线 + 盲法随机**。
> 探索性 pilot（先打点看情况）允许；但"确认有效"必须 **盲 + 记录**，不能靠感觉。
> （见 `docs/feelings-science/state-follows-attention.md`）

### S0 基线（第 1 周，必须做）
- 采集**日常范围**（不同时段/情境，不必固定时刻）；每段 ≥5min；先用受控静息打底，再铺日常
- 产出：**个人基线区间**（**SDNN** 的均值±σ；RMSSD 不作判据——指尖 PPG 的 RMSSD 不可信，见 FORGET.md，仅作参照记录）
- 判据：拿到稳定的个体基线（这就是 ROADMAP 0.3）；动态调整归软件层，不在硬件阶段做

### S1 开环响应（第 2 周）——自然情境 + 盲法
- 在日常里（工作/刷手机/放松）**随机盲打**：app 决定何时刺激，被试不知道
- 用**动态基线**（连续记录）比较"刺激后一段 vs 基线"、"打了 vs 没打"
- 判据：刺激后 HRV 相对基线有**可重复**的变化，且"打了"与"没打"**可区分**
- 探索性打点（先看有没有明显变化）可当 pilot；但下结论要盲 + 记录，不靠感觉
- 没反应 → 换参数（音量/时长/靶点/电流）再试；仍无 → 记录"该刺激无效"

### S2 闭环对照（第 3~4 周，核心）
- 规则：**HRV 低于"基线-1σ"且持续 1 分钟 → 触发刺激 2 分钟**
- **对照**：隔日伪随机——A 日真规则触发，B 日随机触发（同频率），当日不告诉自己是哪组
- 判据：见第五节
- 日志：每段记录 HRV 曲线 + 自评（1~10 状态）

### S3 tVNS 替换声音（第 4 周起，安全验证后才做）
- 先用 **1kΩ+100nF 假负载**验证：电流精度、波形、开路钳位
- 再贴人：**电流 ≤1.5mA，软启动 1-2s 缓升，双相对称方波防直流**
- 其余流程同 S1/S2

---

## 4. 安全红线（★ 不商量）

```
tVNS:
  · 电流 ≤1.5mA（绝对上限 2.0mA 硬熔断）
  · 软启动：0.1mA→1.5mA 线性缓升 1-2s，禁止突变
  · 开路检测：使能前微电流探针，Vout 触及钳位轨 → 判开路 → 不输出
  · 输出端 12V 稳压管 OVP 钳位（防脱落重触放电打火）
  · 隔离：ISO7721 + B0505S 就位
  · 电池供电、拔掉所有下载器/示波器/串口线，才允许贴人
声音:
  · 音量 ≤ 舒适上限（约 ≤60dB），时长单次 ≤2 分钟
通用:
  · 任何不适 → 立即停，记录
```

> 这些全部照抄 ROADMAP 已有的红线，MVP 不是降安全的理由。

---

## 5. 判据：什么算"有效"

**可测量（客观）**：
- S2 闭环阶段，触发后 5 分钟内 HRV 回升幅度，**A 日（真规则）显著大于 B 日（随机）**，
  且跨 ≥3 对 A/B 日重复出现
- 量化建议：触发后 5min 的 **SDNN** 均值 − 触发前 5min 均值；A/B 两组的差值做简单对比

**可感知（主观）**：
- 自评量表（1~10，紧张↔放松）在 A 日与 B 日有方向一致的差异
- 定性记录：每次实验后一句话感受

**诚实原则**：
- 客观指标优先于主观感受
- 对照组必做（防安慰剂）；自己当被试 + 实验者，对照是底线

## 6. 要写的软件（PC 侧，最小改造）

1. `ppg_capture.py` 升级版：
   - 持续收 `FE E1` 帧 → 每拍 IBI（**数样本时基**，见 DISCUSSION 第五节）
   - 1 分钟滑动窗算 **SDNN**（RMSSD 不参与判定，见 FORGET.md）
   - 规则：`HRV < 基线-1σ 持续 60s → 触发`
2. 触发输出（先①后②）：
   - ① `afplay` 播放 2 分钟音频
   - ② 通过串口给 iCE40 发命令 → I2C 写 MCP4725 设电流（iCE40 侧加一小段：收 UART 命令解析 → DAC 写）
3. 日志：CSV（时间戳 / IBI / HRV / 是否触发 / 自评）

## 8. 失败也值钱

- "刺激无效" → 换刺激类型/位点/参数，或换代理信号（EDA 等）
- "闭环无效但开环有反应" → 说明模型/规则要改，不是效应不存在
- "全无效" → 回到文献，重新设计假设——**省下了接下来所有的工程量**
- 每一轮结果都写进实验记录（哪怕失败），这就是 Feelings 的"个体基线"开山数据

---

*一句话：先在日常里盲打几次、用你建的基线看有没有变化，再决定要不要建操作系统。*
