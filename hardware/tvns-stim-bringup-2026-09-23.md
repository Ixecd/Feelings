## 二、第 1 步：隔离电源 ✅

```
隔离侧 5.3V；主板侧 4.88V
主板 GND ↔ 隔离 GND = 0L（开路）→ 墙成立
```

- 顺带踩了个"看错显示"的坑：`0L`（Overload=开路）被当成 `0`（短路），虚惊一场。
- 正确认识：万用表两笔相碰 = 0.5Ω（真 0）；分开 = 0L（开路）。

## 三、万用表自检（怀疑读数时的 10 秒法）✅

```
10kΩ + 100Ω 串 5V 分压，中点对 GND：
  理论 = 5 × 100/(10000+100) ≈ 49mV
  实测 48.2mV → 表 OK
⚠️ 小电压务必切 200mV 档：留在 20V 档会把 68mV 读成 0.06/0.0（像 0）
```

## 四、第 2 步：恒流源（LM334 全灭 → 改 LM358P）✅

**LM334Z（TO-92）买了 3 颗，3 颗全坏**：
- 接法（Rset 在 R–V−、负载 V−→GND）、接线、面包板——全验过（通断全响），芯片就是不导通。
- 脚位已核对：datasheet 底视图 `V+ R V−`，即**平面朝自己 = 左 V−、中 R、右 V+**（中间永远是 R）。
- 结论：**便宜 LM334Z 批次是坏件/假货**，别死磕。

**改用 LM358P（双运放）搭运放恒流源（VCCS）**：
```
Vref(分压) ──► LM358 pin3 (+)
pin2 (−) ──► Rsense(1kΩ) ──► GND
pin1 (OUT) ──► 假负载(1kΩ) ──► pin2      ← 负载接在 OUT 和 IN− 之间
I = Vref / Rsense
```
- 固定 Vref（10k+1k）→ I ≈ 0.45mA；**负载 1kΩ↔100Ω 换 10 倍，电流不变** → 恒流成立。
- Vref 换成 1kΩ 电位器（102）→ **可调 0 ~ 2.44V**（对应 0~2.44mA）。
- 结论：**第 2 步用 LM358P 方案过关**，LM334 这条线放弃。

## 五、第 3 步：ISO7721（受阻）❌

**脚位（这次彻底搞清）**：DIP-8/SOIC-8 **逆时针**编号，缺口/圆点朝上：
```
    VCC1 │1   8│ VCC2       1-4 = 主板侧
     INA │2   7│ OUTA       5-8 = 隔离侧
     INB │3   6│ OUTB
    GND1 │4   5│ GND2
```

**一路踩的坑**：
1. **脚位理解错**：以为"上排 1-4、下排 5-8"，把 VCC2（隔离 5V）当 GND1 接到主板 GND → 两侧串 → B0505S 过流 → **i5 慢慢熄灭**。
2. **焊接连锡**：焊出 `pin6↔pin7` 短（OUTB↔OUTA 两输出互打）→ 严重发热。
3. **重焊后仍异常**：`pin3↔pin4` 冷态开路、**通电发热后才短** → 失效。（两个可能：焊接热损伤 / 助焊剂残留高温漏电）
4. 发热/失效的 ISO7721 拔掉线后 i5 恢复正常 → 确认问题在 ISO7721 侧。

**决定**：
- 不用 PC817；**重买 ISO7721**，重焊。
- 若清洗助焊剂（IPA）后冷/热复测不再漏 → 芯片可能没坏；仍漏 → 焊伤，换。

## 六、今天的关键教训（已同步 `FORGET.md`）

1. **便宜 LM334/LM358/比较器先当"可能假的"**——量不出电流先换芯片，别死磕接法。
2. **万用表分压自检法**（10k+100Ω ≈49mV）+ 小电压用 200mV 档。
3. **电阻/通断档必须断电测**——带电量 = 垃圾读数（会假报短路）。
4. **SOIC 焊接**：300–320°C、每脚 ≤2 秒、助焊剂（**少用**，别用一大坨助焊膏）、
   焊完逐脚量相邻（掰也不变）、**焊后必清洗**（助焊剂/助焊膏残留高温会漏电，症状=热短路）。
5. **DIP/SOIC 脚位是逆时针**（缺口朝上，左边下 1-4、右边上 5-8）。
6. **疑似失效件不装**：无法证明它没坏 + 用在安全路径 → 换（疑罪从换）。
