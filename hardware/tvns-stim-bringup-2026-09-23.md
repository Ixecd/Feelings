## 二、第 1 步：隔离电源 ✅

```
隔离侧 5.3V；主板侧 4.88V
主板 GND ↔ 隔离 GND = 0L（开路）→ 墙成立
```

- 顺带踩了个"看错显示"的坑：`0L`（Overload=开路）被当成 `0`（短路），虚惊一场。
- 正确认识：万用表两笔相碰 = 0.5Ω（真 0）；分开 = 0L（开路）。

## 三、万用表自检（怀疑读数时的 10 秒法）✅

```
10kΩ + 100Ω 串 5V 分压，中点对 GND：
  理论 = 5 × 100/(10000+100) ≈ 49mV
  实测 48.2mV → 表 OK
⚠️ 小电压务必切 200mV 档：留在 20V 档会把 68mV 读成 0.06/0.0（像 0）
```

## 四、第 2 步：恒流源（LM334 全灭 → 改 LM358P）✅

**LM334Z（TO-92）买了 3 颗，3 颗全坏**：
- 接法（Rset 在 R–V−、负载 V−→GND）、接线、面包板——全验过（通断全响），芯片就是不导通。
- 脚位已核对：datasheet 底视图 `V+ R V−`，即**平面朝自己 = 左 V−、中 R、右 V+**（中间永远是 R）。
- 结论：**便宜 LM334Z 批次是坏件/假货**，别死磕。

**改用 LM358P（双运放）搭运放恒流源（VCCS）**：
```
Vref(分压) ──► LM358 pin3 (+)
pin2 (−) ──► Rsense(1kΩ) ──► GND
pin1 (OUT) ──► 假负载(1kΩ) ──► pin2      ← 负载接在 OUT 和 IN− 之间
I = Vref / Rsense
```
- 固定 Vref（10k+1k）→ I ≈ 0.45mA；**负载 1kΩ↔100Ω 换 10 倍，电流不变** → 恒流成立。
- Vref 换成 1kΩ 电位器（102）→ **可调 0 ~ 2.44V**（对应 0~2.44mA）。
- 结论：**第 2 步用 LM358P 方案过关**，LM334 这条线放弃。

## 五、第 3 步：ISO7721（受阻）❌

**脚位（这次彻底搞清）**：DIP-8/SOIC-8 **逆时针**编号，缺口/圆点朝上：
```
    VCC1 │1   8│ VCC2       1-4 = 主板侧
     INA │2   7│ OUTA       5-8 = 隔离侧
     INB │3   6│ OUTB
    GND1 │4   5│ GND2
```

**一路踩的坑**：
1. **脚位理解错**：以为"上排 1-4、下排 5-8"，把 VCC2（隔离 5V）当 GND1 接到主板 GND → 两侧串 → B0505S 过流 → **i5 慢慢熄灭**。
2. **焊接连锡**：焊出 `pin6↔pin7` 短（OUTB↔OUTA 两输出互打）→ 严重发热。
3. **重焊后仍异常**：`pin3↔pin4` 冷态开路、**通电发热后才短** → 失效。（两个可能：焊接热损伤 / 助焊剂残留高温漏电）
4. 发热/失效的 ISO7721 拔掉线后 i5 恢复正常 → 确认问题在 ISO7721 侧。

**决定**：
- 不用 PC817；**重买 ISO7721**，重焊。
- 若清洗助焊剂（IPA）后冷/热复测不再漏 → 芯片可能没坏；仍漏 → 焊伤，换。

## 六、第 4 步：换向开关 H 桥（L293D）✅（2026-09-24）

**bench 模式**：跳过 ISO7721（贴人前必须有隔离），ECP5 直连 L293D，全共地，只假负载。

### 静态测（先验桥，不接 i5）
```
pin1 (EN1) → 5V（常使能）
pin2 (IN1)=5V, pin7 (IN2)=GND → OUT1(pin3)≈4.2V,  OUT2(pin6)≈0.51V
对调 IN1/IN2                 → OUT1≈0.51V, OUT2≈4.2V
→ 输入对调，输出跟着对调 ✅（H 桥本身是好的）
```

### 脉冲测（接 i5）
```
pin1←E17(en), pin2←D16(in1), pin7←D17(in2)
示波器：OUT1/OUT2【交替】→ 正相 OUT1高/OUT2低、死区都低、负相倒换、静默都低
周期 40ms、脉宽 200µs、死区 ~9.8µs → 标准双相 ✅
```

### ★ 关键坑：L293D 必须整颗在【主板侧】
```
现象：L293D 跨在"主板 / 隔离"分界上时，两个输出都 ≈4.84V（不换向）。
根因：左半 pin1-8 的 GND(pin4,5) 落在【主板 GND】，
      右半 pin9-16 的 GND(pin12,13) 落在【隔离 GND】；
      而主板 GND 与隔离 GND 是分开的（B0505S 隔开）→ L293D 的"地"被劈成两半
      → 芯片参考电位乱 → 输出乱（都高/都不翻）。
处理：bench 阶段全部用【主板 5V/GND】；L293D 整颗放主板侧，
      或把 9-16 的电源/地也接到主板轨。隔离侧这轮完全不接。
```

### 另一个小坑：make flash 是 SRAM（掉电丢）
```
· make flash   → 烧 SRAM，掉电/重插 USB 就没了 → 每次重上电都要重烧
· make flash-f → 烧 flash，掉电不丢（上电自启）
· 看到 LED ~1Hz 闪 = FPGA 没配置（不是我们的 25Hz 固件）
```

### 尝试把 LM358 恒流源塞进 VCC2 —— 失败（重要结论，2026-09-24）
```
目标：让电流由恒流源设定（而不是由负载决定）。
接法：LM358 pin1 → L293D VCC2；L293D GND(4,5,12,13) → LM358 pin2 → Rsense(1kΩ) → GND；pin3 ← Vref。
现象：运放顶死（pin1≈3.6V 到上限、pin2≠pin3），输出不饱和。
根因：★ VCC2 被恒流源限压后，L293D 达林顿【高边基极驱动不够】
      → 高边压降 2.6V（正常应 ~1.2V）→ 没饱和 → 电流失控、方向不对称。
结论：**L293D 不适合"恒流源喂 VCC2"的拓扑**——达林顿靠 VCC2 提供基极电流，
      一旦 VCC2 被电流源限制，就被"饿死"。（早先担心过、这次实测证实。）
处置：bench 回到【固定 5V 当 VCC2】的 H 桥（已验证）；
      恒流整合改走【DRV8833(MOSFET 桥)】——MOSFET 不靠基极电流，可电流馈 VCC2。
```

## 七、第 4 步续：DRV8833（MOSFET 桥）+ 恒流源整合 ✅（2026-09-24/25）

### 为什么换 DRV8833
L293D 达林顿不能"电流馈 VCC2"（见 §六：VM 被限流 → 高边基极被饿死）。
换 **DRV8833（MOSFET H 桥）**——MOSFET 不靠基极电流，可电流馈 VM。

### DRV8833 模块引脚（2×8）
```
左列(上→下)： NC  AIN2  AIN1  STBY  BIN1  BIN2  NC   GND
右列(上→下)： VM  NC    GND   AO1   AO2   BO2   BO1  GND
```

### 第一步：固定 VM=5V，先验换向
```
接线：VM→5V；所有 GND→GND；STBY→5V；AIN1←D16、AIN2←D17；AO1/AO2→假负载；BIN1/BIN2→GND
结果：双相换向正确（正相 / 滑行 / 负相），幅度比 L293D 大且干净（MOSFET 压降小）
死区 = 滑行(高阻)，AO1/AO2 都 ≈0.05V（两个都关）✓
```
> DRV8833 没有单独 EN：死区靠 `AIN1=AIN2=0`（滑行）实现，正好对上我们 RTL 的死区 (0,0)。

### 第二步：恒流源整合（LM358 喂 VM）
```
接线：LM358 pin1(OUT) → DRV8833 VM
      DRV8833 所有 GND → LM358 pin2(IN−) → Rsense(1kΩ) → GND
      LM358 pin3 ← Vref(电位器)
      STBY→5V；AIN1←D16、AIN2←D17；AO1/AO2→假负载
```
**静态测（AIN1=5V、AIN2=GND，无脉冲）读数**：
```
pin3 (Vref) = 0.50V
pin2 (IN−)  = 0.50V   → 运放【闭环】✓（L293D 死活闭不上，DRV8833 闭环了）
pin1 (VM)   = 2.99V   → 够 DRV8833（下限 2.7V）
Rsense 压降 0.50V → I_回 = 0.526mA
假负载 2.2kΩ 压差 1.34V → I_载 = 0.61mA
→ 负载变 2.2 倍，电流只变 ~15%  → 基本恒流 ✓
```

### 结论
> **DRV8833 + LM358：恒流 + 换向，bench 上成立**（精度 ~15%，受 5V 余量限制）。
> 这就是换掉 L293D 的目的——L293D 做不到电流馈，DRV8833 做到了。

### 两个踩坑
```
① "0Ω 短路"是【带电量电阻】的假读数：
   DRV8833 GND↔GND轨 带电测=0Ω，断电测=966Ω(=Rsense) → 其实没短路。
   ★ 电阻/通断必须断电测。
② 万用表 DC 档在低占空比脉冲下只读到"滑行平均值"
   （脉冲只占 ~1%，两个输出都≈0.3V，量不出脉冲电流）
   → 恒流必须【静态测】（AIN1/AIN2 固定一个方向）。
```

### 已知限制
```
· 15% 电流偏差 = 5V 余量不足（VM 顶到运放上限）+ 面包板/元件容差
· 真精度 & 真负载(1-10kΩ) 需要【隔离 9-12V】供电 → 贴人前专做
```

### 第 5 步：保护（隔直 + OVP）（2026-09-24）
```
① 10µF 隔直：串在 DRV8833 AO1 → 负载 之间（无极性独石）
   → 脉冲后波形"缓缓滑落" = 电容放电（τ ≈ 10µF × 负载），正常不是故障
   → 有源双相脉冲形状不受影响；CH1(串了电容)滑、CH2(没串)直掉，印证就是它

② 双向稳压管：两只 5.1/6.2V，阴极背对背串，跨在负载(电极)两端
   → 当前 5V bench 下电极电压 ≤3.5V，够不到阈值 → 【不导通】（正常）
   → 9-10V 运行时电极可能到 ~9V → 需换成 ~12V（1N4742A）
   → 规则：阈值略高于正常工作电压、远低于损伤电压（选低误钳、选高没用）

③ 4.7K 下拉 → 留给安全层（接 DRV8833 STBY / 使能端）
```

## 八、今天的关键教训（已同步 `FORGET.md`）

1. **便宜 LM334/LM358/比较器先当"可能假的"**——量不出电流先换芯片，别死磕接法。
2. **万用表分压自检法**（10k+100Ω ≈49mV）+ 小电压用 200mV 档。
3. **电阻/通断档必须断电测**——带电量 = 垃圾读数（会假报短路）。
4. **SOIC 焊接**：300–320°C、每脚 ≤2 秒、助焊剂（**少用**，别用一大坨助焊膏）、
   焊完逐脚量相邻（掰也不变）、**焊后必清洗**（助焊剂/助焊膏残留高温会漏电，症状=热短路）。
5. **DIP/SOIC 脚位是逆时针**（缺口朝上，左边下 1-4、右边上 5-8）。
6. **疑似失效件不装**：无法证明它没坏 + 用在安全路径 → 换（疑罪从换）。
