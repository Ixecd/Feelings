> 目的：把"安全"从"靠感觉"变成**硬件保证**——异常时由硬件切断，不依赖 MCU / 算法。
> 关联：`tvns-stim-build-plan-2026-09-20.md`（Layer 0–5 安全模型）、`tvns-stim-topology-v1-2026-10-03.md` §6（分层保护链）。

## 0. 要防什么（威胁清单）

| 威胁 | 后果 | 靠哪层防 |
|---|---|---|
| **过流**（短路/阻抗骤降/参数误设）| 灼伤、深部强刺激 | ★ 硬件超流切断 |
| **直流**（电荷不平衡）| 电解、灼伤 | 隔直电容 + 电荷平衡 |
| **过压**（桥击穿/异常瞬态）| 组织损伤 | OVP 钳位 |
| **市电通路**（USB/电脑地直通人体）| 触电 | 隔离 + 电池 |

## 1. ★ 硬件超流切断（核心，本层第一优先）

目标：一旦负载电流超阈值，**几十 µs 内**由硬件把刺激关掉，**不经 MCU、不靠软件**，并且**锁死**（不会自己恢复）。

### 1.1 采样点
负载电流流过 **Rsense**，所以采 Rsense 两端电压即可（只反映负载电流）：

```
V_sense = I_load × Rsense
```

阈值的量级（**Rsense = 100Ω**，走主流参数后，见 `tvns-stim-params-mainstream-2026-10-08.md`）：

| 层 | 电流 | V_sense |
|---|---|---|
| 治疗软上限 | 4mA | 0.40V |
| **硬熔断（本层）** | **5mA** | **0.50V** |
| 绝对上限 | 5.5mA | 0.55V |

→ 比较器阈值取 **≈0.50V**（5mA），距离软上限留余量、距离绝对上限留余量。

### 1.2 基准
用 **TL431**（2.5V 基准）分压得到 ~0.70V，**不要**直接用 5V 分压（不稳）。
> 分压比 0.70/2.5 = 0.28；用 1% 电阻，**实测标定**到 0.70V。

### 1.3 比较器（LM393N，DIP-8，开漏输出）
```
LM393:  IN+ ← Vref(0.70V)
        IN− ← V_sense(Rsense 上端)
        V+  ← 5V ; GND ← GND
        OUT → 上拉 10k → 5V      （开漏，必须有上拉）
```
逻辑：

| 状态 | 条件 | OUT |
|---|---|---|
| 正常 | V_sense < 0.70V | 上拉高（open）|
| **故障** | V_sense > 0.70V | **拉低** |

（极性可按最终逻辑调整；核心是"超流 → 一个明确的硬件信号"。）

### 1.4 锁存（74HC00，NAND SR 锁存）
- 故障信号 → **置位**锁存；
- 锁存输出 = `safe`：
  - `safe = 1`（正常）：允许刺激；
  - `safe = 0`（已跳闸）：**锁死**，必须**手动复位**（按钮）或断电才解除。
- 未用 NAND 输入接 GND/VCC，不悬空。

### 1.5 动作：safe 与 EN 相"与"
```
EN1（到 H 桥的使能）= EN（来自大脑） AND safe
```
- `safe=0` → **EN1 恒为 0** → 桥全关（且 !en 关 sink），**与 MCU/FPGA 无关**；
- 用一颗 74HC08 门实现（或用现有逻辑的空闲门）。

> 这就是拓扑里那句：**贴人侧 EN1 = EN(经隔离) AND 比较器_safe**。

### 1.6 判据（要实测）
- [ ] 注入 >1.8mA（或拉高 V_sense）→ **几十 µs 内** OUT 翻转、EN1 归 0；
- [ ] 故障消失后**不自动恢复**（锁死），需手动复位；
- [ ] 复位后正常刺激可恢复；
- [ ] 全过程**不经 MCU**（拔掉 MCU 也应有效）。

## 2. OVP（独立过压钳位）

- 位置：**跨电极两端**；
- 器件：一对**同值**双向钳位（两只稳压管**反串**，或一只双向 TVS）；
- 阈值：**略高于最大工作电压、远低于损伤阈值**：
  - **30V 供电**时电极可能到 ~27V → 选 **~36V**（两只 18V 反串，或对应 TVS）；
  - ★ 阈值**别写死**，按"整对反串实测 Vclamp @1/3/5mA"再定；
- ★ 两只必须**同值**，否则不对称钳位 → 引入直流偏置。

---

## 3. 隔直（DC-blocking）

- 位置：**串在电极回路**；
- 器件：**10µF 非极性**（双相回路，绝不能用极性电解）；
- 作用：挡住任何净直流；
- ★ 只是 DC-blocking，**不是完整故障安全屏障**（桥击穿仍可能有瞬态电流）；
- ★ 须核实**实际电压下的有效容量 C_eff** 与耐压。

---

## 4. 上电 / 失效态（"没初始化 = 全关"）

- EN 默认低（上电 / 未初始化 = 桥关）；
- 各驱动级硬件下拉（sink 栅 100k、NPN 基极 100k、LS 栅 10k、HS 栅↔源 100k）；
- `safe` 默认 = 0（上电即锁死）或至少不主动放开 → **上电瞬间不刺激**。

---

## 5. 与"功能层"的关系

```
功能层：FPGA/MCU 出 en/in1/in2 → 逻辑 → H 桥 → sink → 电极
安全层：Rsense 采样 → 比较器 → 锁存 → 与 EN 相与 → 关断
        OVP / 隔直 / 强下拉 ← 独立于功能层
```

**安全层独立供电、独立路径**：即使功能层跑飞、MCU 死机、FPGA 配置失败，安全层仍能关断。
