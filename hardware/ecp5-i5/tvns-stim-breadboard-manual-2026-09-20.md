# 第 0 章 我们到底在造什么

## 0.1 一句话

我们要造一个**极小的、能来回摆、能随时关掉的水流系统**，将来把"水流"送到耳朵上的两片小金属片上，轻轻刺激神经。

## 0.2 为什么是"水流"

把**电流**想象成**水流**：

```
水太少  →  没感觉，没用
水刚好  →  轻轻刺激到神经（有效）
水太多  →  把皮肤冲坏（烧伤）—— 绝对不行
```

所以我们的全部工作，就是把水流**控制在"刚好"那一档**，并且**随时能关**。

## 0.3 这个系统有四个关键角色

| 角色 | 大白话 | 用什么零件 |
|---|---|---|
| **限流阀** | 不管后面接什么，永远只放"设定好的那么点水" | LM334（恒流源） |
| **换向开关** | 让水流一会儿往左、一会儿往右，不能只朝一个方向 | L293D（H桥） |
| **一堵墙** | 把"插着电脑的一边"和"贴在人身上的一边"彻底隔开 | B0505S + ISO7721（隔离） |
| **安全阀** | 万一管子脱落、电压飙高，先把高压泄掉 | 稳压管（5.1V/6.2V） |

## 0.4 为什么电流必须"来回摆"（双相）

如果电流**一直朝一个方向**，就像给一块电池一直充电——电荷会在皮肤里越攒越多，最后**烧**。

所以我们要让它**一会儿左→右，一会儿右→左**，平均下来是零。这叫**双相**。

换向开关（L293D）就是干这个的。

## 0.5 为什么要"隔离"（最重要的一步）

电脑、USB、示波器，它们的"地"是**连到墙上插座的地**的。如果这个地连到人身上，一旦漏电，人就危险。

所以我们在中间造一堵**墙**：

```
墙这边（危险，接着市电）        墙那边（安全，浮空，可贴人）
  电脑 / i5板 / 示波器    ||    B0505S 出来的新5V + 电极
```

- **电**不能穿墙（B0505S 提供墙那边的独立电源）。
- **信息**能穿墙，但只能以"小纸条"（数字信号）的形式，通过 **ISO7721** 这个"传话筒"。

**这是安全的地基。墙没造好，绝不通电。**

# 第 2 章 安全规则（先背下来，再动手）

```
① 面包板阶段，永远只用假皮肤（1kΩ + 100nF），绝不贴人。
② 只要电路还插着 USB / 电脑 / 示波器，绝不碰人体。
③ 先搭一小块，量对了，再联下一块。不许一次全接完再通电。
④ 每次上电前，先断电，用眼睛把接线再检查一遍。
⑤ 手不要同时碰"墙这边"和"墙那边"的地（可能被电到）。
⑥ 任何冒烟、发烫、焦味 → 立刻拔 USB。
```

# 第 3 章 面包板怎么用（30 秒学会）

```
面包板中间有一道凹槽。凹槽两边，各有竖着的一列列小孔：
  · 同一"列"的 5 个小孔是【内部连通】的（同一根线）。
  · 跨过中间凹槽的左右两列【不连通】。

面包板最上、最下通常有红蓝两条长排孔（电源轨）：
  · 红排 = 接 +5V
  · 蓝排 = 接 GND（地）

芯片（DIP）要【跨着中间凹槽】插：
  这样它左边的脚和右边的脚各在一列，不会短路。
```

# 第 4 章 动手前的准备

## 4.1 认方向

- **芯片**：一端有个**半圆缺口**或小圆点，那是"第 1 脚"的标记。数脚时**逆时针**数：1,2,3...
- **稳压管**：一端有一圈**色环**，那是**负极（阴极）**。
- **独石电容**（10µF/104）：**无正负**，随便插。
- **电阻**：无正负，随便插。阻值可以看色环，**更靠谱的是用万用表量**。

## 4.2 万用表怎么用

```
量电压：旋到 DCV（直流电压）20V 档。
        黑表笔 = 地（GND），红表笔 = 要量的点。屏幕显示电压。
量通断：旋到 蜂鸣器/通断 档。两笔碰一起会"嘀"。
        两点通 = 嘀；不通 = 没声音。
量电阻：旋到 Ω 档。两笔跨在电阻两端，读阻值。
```

## 4.3 示波器怎么用

```
探头：尖头 = 信号点；旁边夹子 = 地（夹到 GND）。
先设：电压 1V/格，时间 5ms/格（先看整体），再放大到 200µs/格看细节。
触发：用"上升沿触发"，让波形稳定不跑。
```

# 第 5 章 一步一步搭（不许跳）

> 每一步都：先接线 → 通电 → 量 → 记录 → 断电 → 才做下一步。

## 5.1 第 1 步：隔离电源（先只搭这个）

**目标**：造出"墙"，并确认墙真的隔开了。

**接线**：

```
【墙这边 / 主板侧】
  i5 板排针上标着 "5V" 的孔  ──►  B0505S 的 +Vin
  i5 板排针上标着 "GND" 的孔 ──►  B0505S 的 -Vin

【墙那边 / 隔离侧】—— 引到面包板另一块区域
  B0505S 的 +Vout  ──►  隔离 +5V（面包板另一处的红排）
  B0505S 的 -Vout  ──►  隔离 GND（面包板另一处的蓝排）
```

**通电后量（万用表，DCV 档）**：

| 量什么 | 正常值 | 说明 |
|---|---|---|
| 隔离 +Vout 对 -Vout | ≈5V | 墙那边的电有了 |
| **主板 GND 对 隔离 GND** | **开路（不响，电阻 MΩ 级）** | ★ 这才是"墙"成立的证据 |

**⚠️ 如果隔离电压 >5.5V**：说明 B0505S 空载飘高。在隔离 +5V 和隔离 GND 之间插一个 **220Ω 电阻当预载**（约 23mA），电压应回到 ~5V。

**做完**：确认墙成立 → 断电 → 下一步。

---

## 5.2 第 2 步：限流阀（LM334 恒流源），先不接别的

**目标**：造出"不管后面接什么，电流恒定"的阀门。

**原理（一句话）**：LM334 保证流过它的电流 `I = 67.7mV ÷ Rset`（25°C；datasheet 写作 `227µV/°K ÷ Rset`）。Rset 越大，电流越小。

```
想要 1.5mA → Rset ≈ 45Ω
想要 0.5mA → Rset ≈ 135Ω
想要 0.1mA → Rset ≈ 677Ω
```

**引脚**（两种封装，接法不同）：

```
【裸 TO-92，3 脚】datasheet Figure 4（底视图）：从左到右 = V+、R、V−
   ⚠️ 底视图可能左右镜像；接好先测，没电流就 V+/V− 对调（不会烧）。

【SOIC-8 贴片：LM334M / LM334MX】datasheet Figure 1：
   脚1 = R        脚4 = V+        脚5、8 = NC（悬空不接）
   脚2、3、6、7 = V−（内部全通，接任一个即可）
   ★ 贴片不能直接插面包板，必须先焊到 SOIC-8→DIP 转接板上（和 ISO7721 同款）。
     （另一款 LM334SM 用的是 Figure 2 的 alternative pinout，别混）
```

**接线**（datasheet Figure 13「Basic Current Source」，权威）：

```
隔离 +5V ──► LM334 的 V+ 脚
LM334 的 R 脚 ──► Rset ──► LM334 的 V− 脚      ← Rset 接在 R 与 V− 之间
LM334 的 V− 脚 ──► 1kΩ 假负载 ──► 隔离 GND      ← 电流从 V− 流出，经负载到地
```

**Rset 用什么**：先用**固定 100Ω 电阻**验证（应得 ≈0.68mA），确认电路对了，再换 **10KΩ 电位器 + 串 47Ω** 来调。

**通电后量**：用万用表量 1kΩ 假负载两端的电压 V，则 `电流 I = V ÷ 1000`。

| 量什么 | 正常值 |
|---|---|
| 100Ω Rset 时的电流 | ≈0.68mA（即假负载两端 ≈0.68V） |
| 调电位器 | 电流能在 ~0.1mA ~ 1.5mA 之间变化 |
| 电流是否稳 | 轻微动一下负载，电流基本不变（这就是"恒流"） |

**做完**：确认限流阀能设定电流 → 断电 → 下一步。

## 5.3 第 3 步：接"传话筒"和大脑（ISO7721 + i5）

**目标**：把大脑的三个信号（开/关、往左、往右）安全地传过墙。

**大脑的引脚（i5 板 P5 排针上）**：

| i5 引脚 | 名字 | 意思 |
|---|---|---|
| E17 | en | 开/关 |
| D16 | in1 | 往左 |
| D17 | in2 | 往右 |

**先给 i5 烧程序**（在电脑上）：

```
cd hardware/ecp5-i5/stim_pulse
make flash
```

烧完 i5 会开始不停地产生脉冲（板上 LED 会闪）。

**ISO7721 的接法**（两片，共 3 路信号）：

```
第 1 片 ISO7721：
  1 脚 VCC1 ── 主板 +5V
  4 脚 GND1 ── 主板 GND
  2 脚 INA  ── i5 的 E17 (en)
  3 脚 INB  ── i5 的 D16 (in1)
  5 脚 GND2 ── 隔离 GND
  8 脚 VCC2 ── 隔离 +5V
  7 脚 OUTA ── 去 L293D 的 EN1
  6 脚 OUTB ── 去 L293D 的 IN1

第 2 片 ISO7721：
  1 脚 VCC1 ── 主板 +5V
  4 脚 GND1 ── 主板 GND
  2 脚 INA  ── i5 的 D17 (in2)
  5 脚 GND2 ── 隔离 GND
  8 脚 VCC2 ── 隔离 +5V
  7 脚 OUTA ── 去 L293D 的 IN2
  （第 2 片只用了 1 路）
```

> ⚠️ ISO7721 是 SOIC-8 贴片，脚位以 datasheet 为准（标准是 1=VCC1, 2=INA, 3=INB, 4=GND1, 5=GND2, 6=OUTB, 7=OUTA, 8=VCC2）。**先不接 L293D**，只用示波器量 OUTA/OUTB。

**通电后量（示波器，探头地夹夹隔离 GND）**：

| 量哪里 | 正常值 |
|---|---|
| ISO 的 OUTA (en) | 一会儿高、一会儿低的方波 |
| ISO 的 OUTB (in1) | 和 en 差不多同步的方波 |
| 死区时 | en 和 in1 都变成 0 |

**做完**：确认信号能过墙 → 断电 → 下一步。

---

## 5.4 第 4 步：接"换向开关"（L293D）

**目标**：把单向的水流，变成来回摆的双相水流。

**L293D 脚位（DIP-16，缺口朝左，逆时针数）**：

| 脚 | 名字 | 接什么 |
|---|---|---|
| 16 | VCC1 | 隔离 +5V（逻辑电） |
| 8 | VCC2 | **限流阀的输出**（LM334 的 V−） |
| 1 | EN1 | ISO 的 en |
| 2 | IN1 | ISO 的 in1 |
| 7 | IN2 | ISO 的 in2 |
| 3 | OUT1 | → 假负载一端 |
| 6 | OUT2 | → 假负载另一端 |
| 4,5,12,13 | GND | 隔离 GND |

**接线**：把第 2 步的 1kΩ 假负载，从"LM334 到地"改接到 **OUT1 和 OUT2 之间**。

**通电后量（示波器，跨 1kΩ 假负载）**：

| 量什么 | 正常值 |
|---|---|
| 波形形状 | 正相 200µs → 停 10µs → 负相 200µs → 停 |
| 周期 | 40ms（即 25 次/秒） |
| 正相 | 电压为正，例如 +0.5V |
| 负相 | 电压为负，例如 −0.5V |
| 峰值电流 | 峰值电压 ÷ 1000，应 ≤1.5mA |

**⚠️ 如果 OUT 根本不翻转 / 压降特别大**：
L293D 是"达林顿"输出，它的高边开关需要从 VCC2 取一点驱动电流。而限流阀只给 1.5mA，可能"喂不饱"它。这就是之前说的 **L293D + 恒流馈电要验**。
- 能翻 → 继续用。
- 翻不动 → **换 DRV8833**（MOSFET 桥，几乎不耗驱动电流，正好配恒流馈电）。DRV8833 需补购。

**做完**：确认能双相翻转 → 断电 → 下一步。

## 5.5 第 5 步：加保护 + 假皮肤定型

**目标**：加两道保护，让以后即使出错也不容易伤人。

**① 隔直电容（10µF）**：

```
L293D OUT1 ──► 10µF 电容 ──► 假负载 A 端
L293D OUT2 ────────────────► 假负载 B 端
```

作用：万一哪里出问题变成直流，这个电容会**挡住直流**，不让它一直往皮肤里灌。

**② 安全阀（稳压管，双向）**：
一个稳压管只能挡**一个方向**的高压。我们是双相（两个方向），所以要**两只稳压管反向串起来**：

```
  假负载 A 端 ──► 稳压管1 负极 ── 稳压管1 正极 ──┐
                                                  ├── 假负载 B 端
  假负载 A 端 ──► 稳压管2 正极 ── 稳压管2 负极 ──┘
  （两只 5.1V 或 6.2V 的稳压管，头对头串）
```

作用：无论哪个方向电压超过 ~5-6V，都会被泄掉。防止电极脱落时电压飙高、重新接触时"打火"。

**③ 下拉电阻（4.7KΩ）**：
在 L293D 的 EN1 脚和隔离 GND 之间，插一个 4.7KΩ 电阻。
作用：如果大脑（i5）掉电、引脚"悬空"，这个电阻会把 EN1 自动拉低 = **自动关断**。

**通电后量**：波形应该和第 4 步一样，只是现在多了隔直和保护。确认没有异常削顶。

## 5.6 第 6 步：关断测试（贴人前的最后一道）

**目标**：确认"能随时关掉"。

| 测试 | 怎么做 | 应该看到 |
|---|---|---|
| 正常关 | 把 i5 的 en 引脚（E17）暂时接地 | 输出立刻停 |
| 大脑断电 | 拔掉 i5 的 USB | EN1 被下拉电阻拉低 → 输出停 |
| 开路 | 拔掉假负载 | 电压被稳压管钳住，不无限升高 |

# 第 7 章 常见故障对照

| 现象 | 可能原因 | 怎么办 |
|---|---|---|
| 隔离侧没电 | B0505S 接反 / 主板 5V 没接 | 检查 +Vin/-Vin、+Vout/-Vout |
| 隔离侧电压 >5.5V | 空载飘高 | 加 220Ω 预载 |
| 限流阀电流不对 | LM334 脚接错 | 查 datasheet，重新确认 V+/R/V− |
| ISO 输出没信号 | 输入侧/输出侧电源没接、方向反了 | 查 VCC1/GND1 和 VCC2/GND2 |
| L293D 不翻转 | 达林顿被恒流饿死 | 换 DRV8833 |
| 波形乱 | 地没接好 / 示波器地夹没夹 | 确认共地 |
| 发烫/焦味 | 接错短路 | 立刻拔 USB，重新查线 |
