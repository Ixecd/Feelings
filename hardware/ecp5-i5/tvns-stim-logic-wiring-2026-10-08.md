# tVNS 逻辑译码接线图（74HC04 + 74HC08）— 2026-10-08

> 用途：从零搭"大脑"——把 **en / in1 / in2** 变成 **a1 / a2 / !en**。
> DIP-14 方向：**缺口朝上**，左上 = pin1；沿左边往下 1→7，沿右边往上 8→14。
> 所以：**pin7 = 左下 = GND**，**pin14 = 右上 = VCC(5V)**。

---

## 0. 脚位速查

**74HC04（6 个反相器）**：`1→2`、`3→4`、`5→6`、`9→8`、`11→10`、`13→12`（左边是输入，右边是输出）

**74HC08（4 个与门）**：`1,2→3`、`4,5→6`、`9,10→8`、`12,13→11`

## 1. 我们要的逻辑

```
n1 = en · in1          n2 = en · in2
!in1 = NOT in1         !in2 = NOT in2         !en = NOT en
a1 = n1 · !in2         a2 = n2 · !in1
★ in1=in2=1 → a1=a2=0（硬件互锁，绝不同时开）
```

---

## 2. 74HC04（反相器）接线

| 74HC04 的脚 | 接到 |
|---|---|
| **pin14** | 5V |
| **pin7** | GND |
| pin14 和 pin7 之间 | 跨一颗 **100nF** |
| **pin1** | **in1** |
| **pin3** | **in2** |
| **pin5** | **en** |
| **pin9、pin11、pin13** | **GND**（没用的输入，必须接地）|
| **pin2** | 输出 = **!in1** |
| **pin4** | 输出 = **!in2** |
| **pin6** | 输出 = **!en** |

## 3. 74HC08（与门）接线

| 74HC08 的脚 | 接到 |
|---|---|
| **pin14** | 5V |
| **pin7** | GND |
| pin14 和 pin7 之间 | 跨一颗 **100nF** |
| **pin1** | **en** |
| **pin2** | **in1** |
| **pin4** | **en** |
| **pin5** | **in2** |
| **pin13** | **74HC04 的 pin2（!in1）** |
| **pin10** | **74HC04 的 pin4（!in2）** |
| **pin9** | **74HC08 的 pin3（n1）** |
| **pin12** | **74HC08 的 pin6（n2）** |
| **pin3** | 输出 = **n1** |
| **pin6** | 输出 = **n2** |
| **pin8** | 输出 = **a1** |
| **pin11** | 输出 = **a2** |

## 4. 三个信号要"分叉"（一根线去多处）

| 信号 | 同时接到 |
|---|---|
| **en** | 74HC04·pin5 ＋ 74HC08·pin1 ＋ 74HC08·pin4 |
| **in1** | 74HC04·pin1 ＋ 74HC08·pin2 |
| **in2** | 74HC04·pin3 ＋ 74HC08·pin5 |

## 5. 测试

### 第一步：只搭 74HC04（pin14/pin7/100nF + pin9,11,13 接 GND + 三个输入）

黑表笔接 GND：

| 输入 | 量 | 应该 |
|---|---|---|
| in1=5V → pin2 | ≈0V ｜ in1=GND → pin2 | ≈5V |
| in2=5V → pin4 | ≈0V ｜ in2=GND → pin4 | ≈5V |
| en =5V → pin6 | ≈0V ｜ en =GND → pin6 | ≈5V |

### 第二步：加 74HC08，测真值表

黑表笔接 GND，量 **a1 = pin8**、**a2 = pin11**：

| en | in1 | in2 | a1 | a2 |
|---|---|---|---|---|
| 1 | 1 | 0 | ≈5V | ≈0V |
| 1 | 0 | 1 | ≈0V | ≈5V |
| 1 | 1 | 1 | ≈0V | ≈0V（互锁）|
| 0 | 1 | 0 | ≈0V | ≈0V |
| 0 | 0 | 1 | ≈0V | ≈0V |

## 6. 常见坑

- 每颗芯片 **pin14/pin7 各接各的**（两颗都有 pin14、pin7，别只接一颗）。
- 未用输入**不能悬空**（74HC04 的 pin9/11/13 接 GND）。
- 上电前先断电量 **5V↔GND = 0L**。
