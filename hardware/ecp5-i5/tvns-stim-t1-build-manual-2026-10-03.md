## 0. 总览与信号流

```
i5 ─► CA-IS3762(default-low) ─► 逻辑(74HC08+74HC04): a1=en·in1 / a2=en·in2 / !en
                                       │
                     a1 → HS1+LS2 ; a2 → HS2+LS1 ; !en → Vref→0(关 sink)
                                       │
                              H 桥 ─► 电极 Z ─► B ─► sink(LM358+2N7000+390Ω) ─► 隔离GND
```

**电源（隔离域，共一个隔离 GND）**
```
+VS   = 隔离 9~12V（MN-305S 浮空输出；先 9V）   ← LM358 pin8 + H 桥高边 + 储能
逻辑5V = B0505S +Vout（逻辑 / 基准电位器 / 去耦）
隔离GND = B0505S −Vout = MN-305S 负极
```

**引脚（按此接，接前逐颗验；弯排针/TO-92 极易看反）**
```
2N7000 (N-MOS)  平面朝自己、脚朝下: S G D        ← 逐颗验
BS250  (P-MOS)  平面朝自己、脚朝下: D G S        ← ★ 锁厂家后验
2N3904 (NPN)    平面朝自己、脚朝下: E B C
LM358  (DIP-8)  1=OUT1 2=IN1- 3=IN1+ 4=GND | 5=IN2+ 6=IN2- 7=OUT2 8=V+
74HC08/04/00 (DIP-14) 7=GND 14=VCC
```

## 2. ★ 安全规则（本版加强）

```
① 全程假负载（Step1/2 用【纯电阻】），绝不贴人。
② 市电部分：MN-305S 及市电侧【全部封闭/绝缘】，绝不裸露在面包板上；
   面包板上只允许出现【已经隔离后的低压输出】。
③ 上电调试：不触碰任何裸露市电节点。
   需要同时测两侧 → 用【隔离/差分测量设备】。
   ★ "我不同时摸两个地"不是市电安全措施。
④ ★ 示波器地夹 ≠ 隔离验证工具：
   普通台式示波器的地夹连保护地 → 夹到隔离 GND 就等于给隔离域建了
   一条到地的导电路径。此时【不能】再用"主域 GND ↔ 隔离 GND = 0L"证明隔离完整。
   隔离验证要用：差分探头 / 隔离示波器 / 断电静态量。
⑤ deadtime 定义 = en=0；power-up = en=0 = 全关。
⑥ a1·a2 恒为 0（绝不允许 a1=a2=1）。先断后通。
⑦ 冒烟/发烫/焦味 → 立刻断电。
```

## 3. ★ 逻辑与信号定义（本版锁死）

```
n1=en·in1  n2=en·in2  !in1/!in2  （74HC08 用满 4 门 + 74HC04）
a1 = n1 · !in2       a2 = n2 · !in1      !en = NOT(en)
a1 → HS1 + LS2       a2 → HS2 + LS1      !en → 把 IN+(Vref) 拉低（关 sink）
★ in1=in2=1 → a1=a2=0：**"11=全关"是【硬件保证】**（不靠 RTL）

真值表：
  en=1, in1=1, in2=0 → a1=1, a2=0 → HS1+LS2（正相）
  en=0, *,   *       → a1=0, a2=0 → 全桥 OFF（死区/停）+ !en 关 sink
  en=1, in1=0, in2=1 → a1=0, a2=1 → HS2+LS1（负相）
  en=1, in1=1, in2=1 → a1=0, a2=0 → 全关（非法态自动安全，硬件互锁）

★ 正式 Step3/4 【必须用 a1/a2】，不能用裸 in1/in2。
   "用裸 in1/in2 + en 可选加强" = 错，会让 en=0 时桥仍可能导通。
```

**Vref 硬件上限（★ 防误操作）**
```
1k 电位器 5V─┐
             ├─ wiper ──39k──┬── Vref_limit(≈1.0V) ──10k── LM358 IN+
        GND──┘              │
                          10k
                           │
                          GND
（QD 2N3904: C→IN+, E→隔离GND, B←10k←!en）
→ nominal（Vlogic=5.00V）：Vref_limit≈1.02V → Imax≈2.62mA，不会跳到 5V/12.8mA。
★ B0505S 非稳压 → Vlogic 是 nominal 5V → 上面是 nominal；实际以【实测 Vlogic+电阻容差】为准。
```

## 4. ★ 固定接法（别漏）

```
【LM358 第 2 通道固定】
  pin5 (IN2+) → 隔离GND ; pin6 (IN2−) ↔ pin7 (OUT2)     ← 0V 跟随器

【★ 失效态下拉（power-up / 掉电 / 输出不定时都保证 OFF）】
  sink 栅 →100k→ GND             ← 本版补（LM358 未上电/高阻时保证 QS=OFF）
  LH1/LH2/QD base →100k→ E       ← 本版补（逻辑/隔离器未定态时保证 OFF）
  （CA-IS3762 default-low 只是 first line，不能代替这些硬件下拉）

【IC 本地去耦】每 IC 100nF：LM358 pin8-4 / 74HC08·04·00 pin14-7 / CA-IS3762 侧B VDDb-GNDB
【电源入口储能】隔离5V 10µF ; +VS 10µF
【未用逻辑输入】74HC08/74HC04/74HC00 全部接 GND 或 VCC，别悬空
```

## 5. Step 0：断电验【OFF 态】（先做这个，再谈上电）

```
[ ] a1=0 时：HS1 / LS2 必 OFF（栅↔源电压为 0）
[ ] a2=0 时：HS2 / LS1 必 OFF
[ ] !en=1 时：IN+ 被拉低（≈0V）
[ ] sink 栅极有明确下拉路径
[ ] HS 栅有明确上拉到 +VS（+ 栅↔源 47~100k）
[ ] LS 栅有明确下拉到 GND
[ ] 任何时刻不会出现 a1=a2=1
```

## 6. Step 1：验 sink —— 两个版本（★ 先做 6A）

### 6A. LM334 版（推荐先做：最简，无 windup）

```
【sink = LM334 + Rset】（必须是【真品】！我们买过 3 颗假货）
  B → LM334 V+ ; LM334 V− → 隔离GND
  Rset 接在 LM334 的 R 脚与 V− 脚之间（datasheet Fig.13 "Basic Current Source"）
  I ≈ 64mV / Rset（25°C）：128Ω→0.5mA、64Ω→1mA、32Ω→2mA（串电位器可调）
【负载】隔离 +VS(9V) → 纯电阻 1k/2k/5k → B
量：负载压差 ÷ 负载阻值 = I
[ ] 换负载 1k→2k→5k，电流基本不变
[ ] 实测电流（±3% 初始 + 温漂 +0.33%/°C → 别信丝印，量了算）
[ ] 单颗先验（★实测脚位：平面朝自己 = 左 V+ / 中 R / 右 V− —— 与直觉相反，先接反过）
★ 优点：没有运放/栅极/windup/补偿网络，一步到位。
★ 代价：温漂、±3% 初始、需 ~1V 端压；★ 它是电流调节器，不是安全层。
```

## 6.1 LM358 版接线（Step 1）

### 接线

```
【运放 LM358】★ 设计锁 LM358B；现有 LM358P 可用但按 0.7MHz/0.3V/µs/7mV 保守
  pin8 (V+)  → 隔离 +VS(9V)     ← 不用 5V（非轨到轨，输出上限 ≈Vcc−1.5V）
  pin4 (GND) → 隔离GND
  pin3 (IN+) → 见 §3 的 Vref_limit（经 10k）
  pin2 (IN−) → Rsense 上端（= sink 源极）
  pin1 (OUT) → 1kΩ → sink 栅极
  （第 2 通道按 §4 固定）

【sink QS = 2N7000】 D→B ; S→Rsense(390Ω)上端 ; G←1k←pin1 ; G→100k→GND ★栅下拉
【Rsense 390Ω】 sink 源极 → 隔离GND
【负载】隔离 +VS(9V) → 假负载【纯电阻 1k/2k/5k/10k】→ B
        ★ 本步【不要 100nF】（τ=100µs 会污染 200µs 脉冲的电流读数）
```

### 6.2 量什么 / 判据

```
Vref(pin3) / pin2 / 负载压差 / Rsense 压差
[ ] pin2 ≈ pin3（闭环）
[ ] 换负载 1k→2k→5k→10k，电流不变（I = Vref/390）
[ ] Vref≈1V 时 I≈2.56mA；无发烫
[ ] 0.1mA 端：可调出，但精度需实测（Vref=39mV 已近 LM358 offset）
    → 第一轮恒流验证区间建议 ≥0.5mA
```

## 7. Step 2：验 windup（用 !en 拉 IN+）

```
接线：QD 2N3904: C→IN+ ; E→隔离GND ; B←10k←!en
测试：方波开关 en；示波器看 Rsense（地夹夹隔离GND）
★ deadtime 先用【50µs】，再 30→20→10 逐级缩；每级以 Rsense 真实波形为判据
[ ] en=0 → a1=a2=0 → IN+=0 → sink 关（OUT 被拉低）
[ ] en=1 → 桥导通、电流【平滑建立】，无过冲尖峰
[ ] 若有过冲 → 查 QD 是否真拉 IN+、!en 极性
★ 时序：deadtime 开始时 sink 还在导通(IN−=Vref) → 拉低 IN+ 产生负误差
  → 运放主动拉低 OUT → 停在低位 → 释放时从"关"平滑爬升。
```

## 8. Step 3：H 桥静态（★ 用 a1/a2）

### 8.1 接线

```
【★ +VS 与桥之间串限流电阻】
  +VS ──[10kΩ]── 桥的 +VS 节点      ← 本版改 10k（1k 时直通可达 9mA，太大）
  假负载也用 10kΩ 纯电阻：正常 I≈0.45mA、直通 I≈0.9mA（真正"几百µA~1mA"）
  确认 4 条路径全对之后，再去掉这个电阻。

【高边 P-MOS HS1/HS2】
  S→限流后的+VS ; D→mid1/mid2 ; G→10k上拉+VS + 栅↔源100k + NPN 集电极
【高边电平移位 LH1/LH2 (2N3904)】
  C→P-MOS栅 ; E→隔离GND ; B←10k←a1(LH1)/a2(LH2)   ★基极必串限流
【低边 N-MOS LS1/LS2】
  D→mid1/mid2 ; S→B（本步 B 直接接隔离GND，旁路 sink）
  G←a2(LS1)/a1(LS2) + 10k下拉隔离GND
【负载】mid1 ── 假负载(纯电阻) ── mid2
```

### 8.2 手动测（用跳线给 en/in1/in2，看 a1/a2）

```
en=1,in1=1,in2=0 → a1=1,a2=0 → HS1+LS2 → 负载压差 ≈ +VS
en=0,*,*          → a1=0,a2=0 → 全断   → 两 mid ≈0
en=1,in1=0,in2=1 → a1=0,a2=1 → HS2+LS1 → 负载压差 ≈ −VS
★ 人为测试并确认：a1=1 且 a2=1 是【非法】，硬件层最好根本做不出 11
```

### 8.3 判据

```
[ ] 00=OFF / 10=正相 / 01=负相 / 11=非法
[ ] 无 shoot-through、无发烫
[ ] a1=0 时 HS1/LS2 确实 OFF（Step0 的复验）
```
