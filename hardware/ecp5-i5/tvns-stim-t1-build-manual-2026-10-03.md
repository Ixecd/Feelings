## 0. 总览与信号流

```
i5(3V3域) ──E17/D16/D17──► CA-IS3762 ──► 隔离域:
   en,in1,in2 ──► 开关驱动 ──► 离散 H 桥(HS1/HS2/LS1/LS2)
   !en ────────► windup 下拉(死区关 sink)
   负载 ──► 低边公共点 B ──► 恒流 sink(LM358+2N7000+Rsense) ──► 隔离GND
                         └─► 10µF 隔直 + 双向稳压管(OVP)
```

**4 步 bring-up**（本手册主线）：① 只搭 sink → ② 验瞬态 → ③ 桥静态 → ④ 全闭环。

## 1. 元件与选型

| 用途 | 型号 | 封装 | 备注 |
|---|---|---|---|
| 高边开关 HS1/HS2 | **BS250** | TO-92 直插 | P-MOS，Vds −45V；Rds(on) ~10Ω（mA 级够）|
| 低边开关 LS1/LS2 | **2N7000** | TO-92 直插 | N-MOS，Vds 60V；❌ 别用 BSS138(SOT-23 贴片) |
| sink 管 | **2N7000** | TO-92 | 同上 |
| 高边电平移位 | **2N3904** ×2 | TO-92 | NPN |
| windup 下拉 | **2N3904**（或 2N7000）| TO-92 | 死区关 sink |
| 运放 | LM358P | DIP-8 | 恒流 sink |
| 译码/反相 | 74HC00 | DIP-14 | 生成 !en；★ 闲置输入接 GND/VCC，别悬空 |
| Rsense | **390Ω** 金属膜 | 直插 | I=Vref/390；Vref 0.04~1V → 0.1~2.5mA |
| 栅极串阻 | 1kΩ | 直插 | sink 栅极前（防振铃）|
| 上拉/下拉/基极/Vref缓冲 | 10kΩ | 直插 | 各驱动 + Vref→IN+ 的限流分压 |
| 隔直 | 10µF 独石 | 直插 | 串在负载回路 |
| OVP | 双向稳压管 ×2 | 直插 | 一对【同值】；9-10V 运行用 ~12V(1N4742A) |
| 基准 | 1kΩ 电位器(102) | 直插 | Vref |

**电源（隔离域，共一个隔离 GND）**
```
+VS   = 隔离 9~12V（MN-305S 浮空输出；先 9V）   ← 喂 LM358 pin8 + H 桥高边
逻辑5V = B0505S +Vout（喂 逻辑 / 基准电位器）    ← 不喂 LM358
隔离GND = B0505S −Vout = MN-305S 负极
```

**引脚（先按此，接线前对照 datasheet / 用表确认；弯排针极易看反）**
```
2N7000 (N-MOS, TO-92)  平面朝自己、脚朝下: S G D
BS250  (P-MOS, TO-92)  平面朝自己、脚朝下: D G S   ← ★ 务必查 datasheet 确认
2N3904 (NPN,  TO-92)   平面朝自己、脚朝下: E B C
LM358  (DIP-8) 1=OUT1 2=IN1- 3=IN1+ 4=GND | 5=IN2+ 6=IN2- 7=OUT2 8=V+
74HC00 (DIP-14) 1,2→3 | 4,5→6 | 9,10→8 | 12,13→11 | 7=GND 14=VCC
```

## 2. 安全规则（先背）

```
① 全程假负载（1kΩ + 100nF），绝不贴人。
② 隔离域内有 MN-305S(市电) 时，手别同时碰主域 GND 和隔离域。
③ 每小步：接好 → 断电复查 → 上电 → 量 → 记录 → 断电 → 才下一步。
④ 先 9V，别一上来 12V。
⑤ 冒烟/发烫/焦味 → 立刻断电。
⑥ 先断后通：HS/LS 绝不直通（软件死区 + 硬件兜底）。
```

## 3. 第 1 步：只搭【低边恒流 sink】（不接 H 桥）

目标：在一个 1k~10kΩ 假负载上，把电流稳在 0.1~2.5mA 且不随负载变。

### 3.1 接线（全引脚）

```
【运放 LM358】
  pin8 (V+)  → ★ 隔离 +VS（9V）   ← 不用 5V！（原因见下）
  pin4 (GND) → 隔离GND
  pin3 (IN+) → 经 10kΩ → 电位器滑片（电位器：两端→隔离5V / 隔离GND）
  pin2 (IN−) → Rsense 上端（= sink 源极）
  pin1 (OUT) → 1kΩ → sink 栅极

★ 为什么 pin8 用 +VS(9V) 而不是 5V：
  LM358 非轨到轨，输出上限 ≈ Vcc − 1.5V。5V 时最多 ~3.5V；
  而 2N7000 的 Vth 最大 ~3V，大电流时源极(Rsense 上端)抬到 ~1V，
  栅极需 ~3.5V 才维持导通 → 5V 会顶天花板、大电流恒流失效。
  接 +VS(9V) → 输出可到 ~7.5V，余量充足
  （IN+/IN− 仍 0~1V，在共模输入范围内，不影响）。

【sink 管 QS = 2N7000】
  D(漏) → B 点
  S(源) → Rsense(390Ω) 上端
  G(栅) ← 1kΩ ← LM358 pin1

【Rsense 390Ω】sink 源极 → 隔离GND

【负载回路】
  隔离 +VS(9V) → 假负载(1kΩ) → B 点
```

### 3.2 上电前检查

```
[ ] pin8 = 隔离 +VS(9V)、pin4 = 隔离GND
[ ] pin3 经 10kΩ 到电位器滑片
[ ] Rsense 在 sink 源极→隔离GND 之间（不在别处）
[ ] 负载只从 +VS 到 B，不接别处
[ ] 断电量：+VS ↔ 隔离GND 不短
```

### 3.3 量什么

```
Vref (pin3)  = ?
pin2 (IN−)   = ?          ← 应 ≈ pin3（闭环）
负载两端压差 = ?  → I = 压差 / 负载阻值
Rsense 压差 = pin2 → I = pin2 / 390
```

### 3.4 判据

```
[ ] pin2 ≈ pin3（闭环）
[ ] 负载 1k→2k→5k，电流基本不变（I = Vref/390）
[ ] Vref≈1V 时 I≈2.5mA；过程无发烫
```

## 4. 第 2 步：验【瞬态消除（windup）】

目标：模拟"死区断电"，确认每相开启时**没有过冲尖峰**。

### 4.1 接线（在 step1 基础上加）

```
【windup 下拉 QD = 2N3904】
  C(集电极) → ★ LM358 pin3 (IN+)   ← 不接栅极！原因见下
  E(发射极) → 隔离GND               ← 接 GND，不接 B
  B(基极)   ← 10kΩ ← !en            ← 死区/停时 !en=1 → 把 Vref 拉到 0

★ 为什么拉 IN+ 而不是拉栅极：
  · 拉栅极 → sink 关、IN−=0，而 IN+ 仍是 Vref → 运放【正饱和】OUT 冲高 →
    !en 释放瞬间 sink 被充满 → 全开 → 仍 Zap。
  · 拉 IN+ → 死区【开始时】sink 还在导通(IN−=Vref) → 负误差 → 运放主动把 OUT
    拉低 → 停在低位、保持闭环不满 → 释放时从【关】平滑爬升，不 zap。
（电位器滑片经 10kΩ 到 IN+，QD 拉低时形成分压，保护电位器。）

【!en 从哪来】
  · 调试用：手动跳线当 !en（1=关 sink）
  · 正式：74HC00 用一个 NAND 当反相器，把 en → !en
```

### 4.2 怎么测

```
用方波(或手动)开关 en / !en：
  !en=0（en=1）：sink 工作，电流 = 设定值
  !en=1（en=0）：sink 关断（栅极被拉到 GND）
示波器：探头量 Rsense 上端（或负载两端），地夹夹隔离GND
```

### 4.3 判据

```
[ ] en=0 时：电流迅速归 0（IN+ 被拉低 → 运放把 OUT 拉低）
[ ] en 上升沿：电流【平滑爬升】到设定值，【无过冲尖峰】
[ ] 若有过冲 → 查 QD 是否真把 IN+ 拉低（!en 极性、C 是否接在 pin3）
```

> ⚠️ 反例（别这么接）：若把 QD 拉在【栅极】上，sink 关且 IN+ 仍 = Vref，
> 运放会正饱和、OUT 冲高 → 释放瞬间照样 Zap。**要拉 IN+。**

## 5. 第 3 步：【离散 H 桥静态】（B 先接地，旁路 sink）

目标：确认 4 个方向的通断正确、无桥臂直通。

### 5.1 接线（全引脚）

```
【高边 P-MOS：HS1、HS2】
  S(源) → +VS
  D(漏) → HS1:mid1 / HS2:mid2
  G(栅) → 上拉 10kΩ 到 +VS；并接电平移位 NPN 集电极

【高边电平移位 NPN：LH1、LH2（各一个 2N3904）】
  C → P-MOS 栅极
  E → 隔离GND            ← ★ 发射极接 GND，不接 B（上拉电流不经过 Rsense）
  B ← 10kΩ ← in1（LH1）/ in2（LH2）
  ★★ 基极【必串 10kΩ】：74HC00 输出直怼 B-E 结 = 短路 → 会烧 74HC00 或 NPN

【低边 N-MOS：LS1、LS2】（对角线：a1→HS1&LS2, a2→HS2&LS1）
  D(漏) → LS1:mid1 / LS2:mid2
  S(源) → B（本步先直接接隔离GND，旁路 sink）
  G(栅) ← in2（LS1）/ in1（LS2）  ← 直驱(MOS 栅电容性、无直流)
  并接下拉 10kΩ 到隔离GND          ← 防上电瞬间误导通

【负载】mid1 ── 假负载 ── mid2
【本步】B → 隔离GND（跳过 sink）
```

> 开关信号直接用隔离后的 in1/in2（RTL 死区时 in1=in2=0，天然全断）：
> `in1 → HS1_on + LS2_on`、`in2 → HS2_on + LS1_on`。
> （可选安全加强：用 74HC00 把 in1/in2 与 en 相与再驱动。）

### 5.2 手动测（不接 i5，用跳线给 in1/in2）

```
in1=1, in2=0 → HS1+LS2 开：mid1≈+VS−压降、mid2≈0 → 负载压差 ≈ +VS
in1=0, in2=1 → HS2+LS1 开：mid2≈+VS、mid1≈0  → 负载压差 ≈ −VS
in1=0, in2=0 → 全断：两个 mid 都 ≈0
```

### 5.3 判据

```
[ ] 两个方向压差对调 ✅
[ ] (0,0) 时两 mid 都低（无直通）
[ ] 任何时刻【没有】HS/LS 同一 half-bridge 同时开
[ ] 无发烫（发烫=直通）
```

## 6. 第 4 步：【全系统闭环】

### 6.1 把 B 接回 sink

```
去掉 step3 的 "B→隔离GND" 跳线；
把 H 桥低边公共点 B → sink 的 QS 漏极(D)。
（其余 step1/2/3 保持不变）
```

### 6.2 接信号

```
CA-IS3762 侧B：V01(en) / V02(in1) / V03(in2) → 驱动/译码
（i5 已烧 RTL，跑起来）
```

### 6.3 上电 + 观察

```
示波器：探头量 负载两端（跨 mid1-mid2 / 电极），地夹夹隔离GND
先 5ms/格 看整体 → 200µs/格 看细节
```

### 6.4 判据

```
[ ] 双相方波：正相 200µs → 死区 10µs → 负相 200µs → 歇；周期 40ms
[ ] 死区期间两 mid 都低（B 无电流）
[ ] 每相开启【无过冲尖峰】（windup 已修）
[ ] 电流恒定（= Vref/390），换负载不变
[ ] 关断/OVP/隔直 在位
[ ] 隔离墙：主域 GND ↔ 隔离 GND = 0L
```

### 6.5 ★ 预期现象（正常，别慌）：LS 管"源极跟随"

```
用【极小负载】(0Ω 导线 / 100Ω) 测桥两端时，可能看到：
  高边 P-MOS 压降 ≈0，但低边 N-MOS(LS1/LS2) 却吃掉好几伏。
原因：LS 栅极由 5V 逻辑驱动 → 源极(B) 永远 ≤ 5 − Vth ≈ 3V。
  小负载 + VS=9V 时 B 本应升到 ~7V，但被 LS 栅极压在 ~3V → 多出的 ~4V 由 LS 吃掉。
结论：良性、正常。
  · B 被压在 ~3V 时 sink 照常恒流（>1V 空间就够）；
  · 换上真实 1~5kΩ 负载 → 电压主要落在负载上 → B 降到 1~2V → LS 完全饱和。
→ 看到"空载时 LS 压降大"，别以为桥坏了。
```

## 8. 常见故障对照

| 现象 | 可能原因 | 怎么办 |
|---|---|---|
| 电流不随 Vref 变 | 基准没对本域 GND（见 FORGET A·4）| 电位器另一端接隔离GND |
| 换负载电流就变 | 采样点错 / Rsense 不在 sink 源极 | 查 pin2 = Rsense 上端 |
| 开启有过冲尖峰 | windup 下拉没生效 | 查 QD 的 !en 极性、C/E 接法 |
| 电流高频振荡 | 栅极容性负载振铃 | 串 1kΩ；仍振 → OUT-IN− 跨 1nF |
| 高边不导通 | 电平移位 NPN 发射极接错 / 上拉没接 | E→隔离GND、栅极上拉 10k→+VS |
| 低边不导通 | Vgs 不够（B 抬太高）| 降低 Vref 满量程 |
| 某方向不换向 | in1/in2 接反 | 对调 |
| 发烫 | 桥臂直通 | 断电查 HS/LS 是否同时开 |
| 上电就烧 | 电源短路 / 直通 | 断电逐段量 |
