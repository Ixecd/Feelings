## 0. 一句话

把 **"极性切换"** 和 **"电流控制"** 拆成两个独立的部分：

- **极性切换** = 一个**离散 H 桥**（只负责让电流换向，本身不耗直流）
- **电流控制** = 一个**低边恒流 sink**（串在回路里，只测负载电流）

两者分开后，采样点**只看到负载电流**，不再被开关器件自身耗电污染。

---

## 1. 为什么要重画（v0 / v1 的死因）

```
v0: L293D(达林顿)，恒流喂 VCC2 → 高边基极被"饿死" → 高边不饱和 → 电流失控
v1: DRV8833(MOSFET)，恒流喂 VM → 被【芯片自身耗电】饿死
    实测（2026-10-03）：
      · DRV8833 空载就吃 ~1.6mA（状态 B 导通 ~5.6mA，其中负载 ~4mA）
      · 而我们的负载电流只有 0.1~2.5mA —— 同一量级！
      · 恒流喂 VM 上限卡在 ~0.6mA < 1.6mA → 芯片连自己都养不活 → 必卡
对照实测：VM 直接接 9V → 负载正常 9V；VM 改回运放限流 → 负载塌。

根因（一句话）：
  "喂 VM"的电流 = 负载电流 + 芯片自身耗电；
  芯片自身耗电与负载同量级 → 无法分离 → 不能用"喂 VM"控制负载电流。
```

---

## 2. 设计目标

```
· 双相：每周期【正相 200µs → 死区 10µs → 负相 200µs → 歇】
· 恒流：I = Vref / Rsense，0.1 ~ 2.5mA 可调；负载 1~10kΩ 变，电流不变
· compliance：到 ~10V（电极阻抗 1~10kΩ × mA）
· 采样【只测负载电流】，不被开关器件自身耗电污染
· 可随时关断；硬件限流（安全层，不经 MCU）
· 用【裸件】搭（自己控制电路，不迁就模块）；以后可搬去电池/做小
```

---

## 3. 核心原则

```
★ 极性切换 ≠ 电流控制
   · 极性切换用【开关】      —— 理想开关稳态不耗直流，只负责"往哪流"
   · 电流控制用【串联恒流环节】—— 在【负载回路里】采样，测的就是负载电流
   → 拆开后：开关只管换向，恒流只管大小，互不污染
```

## 4. 拓扑 T1（推荐）：离散 H 桥 + 低边恒流 sink

### 4.1 框图

```
                     +VS (隔离域 9-12V)
                      │
            ┌─────────┴─────────┐
           HS1(P)              HS2(P)        ← 高边开关
            │                    │
          mid1                 mid2
            │                    │
           EL1 ────── Z ────── EL2             ← 电极 / 负载(假皮肤)
            │                    │
           LS1(N)              LS2(N)          ← 低边开关
            └─────────┬─────────┘
                      │
                      B   (低边公共点)          ← 全部回流都从这走
                      │
              ┌───────┴───────┐
              │   恒流 sink    │   N-MOS + op-amp(LM358) + Rsense
              └───────┬───────┘
                      │
                     GND (隔离地)
```

### 4.2 两相真值表

| 相 | HS1 | LS2 | HS2 | LS1 | 电流路径 |
|---|---|---|---|---|---|
| **正相** | 开 | 开 | 关 | 关 | +VS→HS1→mid1→EL1→**Z**→EL2→mid2→LS2→B→sink→GND |
| **死区** | 关 | 关 | 关 | 关 | 无（B 上无电流）|
| **负相** | 关 | 关 | 开 | 开 | +VS→HS2→mid2→EL2→**Z**→EL1→mid1→LS1→B→sink→GND |

> 开关信号可**由现有 3 路译码**（i5 RTL 只出 en/in1/in2）：
> `HS1 = LS2 = en·in1`、`HS2 = LS1 = en·in2`（用 74HC00 简单与门即可）。

### 4.3 为什么这样就干净

```
· MOSFET 栅极是【电容性】：稳态不耗直流（不像 DRV8833 有内部电荷泵/逻辑耗电）
· 高边开关只通过"负载电流"，没有旁路耗电
· 低边公共点 B 上，唯一的直流就是【负载电流】
  → sink 的采样电阻【只看到负载电流】→ 恒流可标定、可信
```

### 4.4 电流设定（沿用已验的 LM358 VCCS 原理）

```
I = Vref / Rsense
op-amp(LM358):
   IN+  ← Vref（电位器，对本域 GND）
   IN−  ← Rsense 上端（= sink MOS 的源极）
   OUT  → sink N-MOS 栅极
sink N-MOS: 漏极接 B，源极经 Rsense 接 GND
→ 运放自动把采样调成 Vref → I = Vref/Rsense
```

### 4.5 元件与接法（初稿，待细化）

```
· HS1/HS2: P-MOS（源接 +VS；栅极经电平移位下拉开通）；或 N-MOS + 自举
· LS1/LS2: 逻辑电平 N-MOS（源接 B）
· sink:   N-MOS + Rsense + LM358
· 逻辑输入: 隔离域（CA-IS3762 输出的 in1/in2），经 en 门控/译码
· 保护:   负载串 10µF 隔直；负载跨一对【同值】双向稳压管(OVP)
```

### 4.6 门极驱动注意（要解决的点）

```
· 高边 P-MOS：栅极要相对 +VS 摆动 → 简单电平移位（NPN/NMOS + 上拉电阻）
· 低边 N-MOS：栅极相对 B(~1V) → 用逻辑电平 MOS，或相对 B 驱动
· ★ 门极驱动【不能把直流注入 B】——否则又污染 sink 采样
  （栅极电流要走各自的驱动回路，不走负载/回流路径）
· ★ 死区必须"先断后通"：同一 half-bridge 的 HS/LS 不能同时导通
  （RTL 已产 (0,0) 死区 10µs，硬件再兜底）
```

## 5. 拓扑 T2（备选）：保留 DRV8833 + 电极回路采样

```
· DRV8833 仍做 H 桥（VM 固定 9-10V，给它吃够）→ 只负责换向
· 在【电极串联回路】里放 Rsense + 恒流元件 → 只测负载电流
· 难点：双相 → 采样电压会【换号】→ 需要"双向/整流"采样 + 串联元件也要双向
→ 比 T1 复杂，列为备选
（注意：若仍从 DRV8833 的 GND 测回流，它自身 1.6mA 会污染 → 不可行）
```

---

## 6. 关键设计约束（T1/T2 共通）

```
· 死区：先断后通；RTL 已产 (0,0) 死区 10µs
· 隔直：负载串 10µF（挡直流，防电荷累积）
· OVP：负载跨一对【同值】双向稳压管（阈值略高于工作电压、远低于损伤电压）
· 安全层：独立【比较器 + 锁存】(LM393N + 74HC00)，超流 → 硬关，不经 MCU
· 隔离：信号过 CA-IS3762；电源 B0505S（+ 隔离 9-12V）
· VM 上限：若仍用 DRV8833，VM ≤ 10.8V（本次 T1 离散桥无此限制）
```

