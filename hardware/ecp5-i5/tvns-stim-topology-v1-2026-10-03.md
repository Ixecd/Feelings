## 0. 一句话

把 **"极性切换"** 和 **"电流控制"** 拆开：
- **极性切换** = 离散 H 桥（只换向，不耗直流）
- **电流控制** = 低边恒流 sink（串在负载回路，只测负载电流）

## 1. 为什么要重画（v0/v1 死因）

```
v0 L293D 恒流喂 VCC2 → 达林顿高边基极被饿死
v1 DRV8833 恒流喂 VM → 被芯片自身耗电(~1.6mA)饿死（与负载同量级）
根因：桥芯片 VM 上的电流 = 负载 + 芯片自身耗电，无法分离。
```

## 2. 设计目标 + ★ compliance（二维，公式降级措辞）

```
硬指标：
· 双相：正相 200µs → 死区 → 负相 200µs → 歇；周期 40ms
· 恒流：I 可调；负载变电流不变；采样只测负载电流
· 可关断 + 硬件超流切断；电源/逻辑双轨（共隔离 GND）

★ compliance 是【二维】的：I 和 Z 不能各自取最大值
   VS ≥ I×Z + Vheadroom_required(I,Z)
   Vheadroom_required = V(Rsense) + Vds(QS) + Vds(LS) + Vds(HS) + 走线 + margin
   ★ 1V 只是【初期预算】，不是最终规格 —— 由 bench 实测确定。
   ★ 尤其 Vds(LS) 是本架构最不确定的一项（见 §4.6）。
   初期预算(~1V)下反推：
     VS= 9V → I×Z ≤ 8V ：1mA@8kΩ、2.5mA@3.2kΩ
     VS=12V → I×Z ≤ 11V：1mA@11kΩ、2.5mA@4.4kΩ
   ⚠️ "2.5mA @ 10kΩ" 需 ≥25V + headroom → 9~12V 不可能。
   → 二选一（§10 待锁）：
     工作区 A（当前电源够）：I≤1mA 且 Z≤10kΩ
     工作区 B（要 2.5mA@10kΩ）：+VS 升到 ~30V
```

## 4. T1 设计

### 4.1 电流路径
```
+VS → HS1/HS2 → 电极 Z → LS1/LS2 → B → sink → Rsense → 隔离GND
```

### 4.2 ★ 状态机（deadtime=en=0；a1·a2=0 是硬件保证）

```
逻辑（74HC08 用满 4 门）：
  n1 = en·in1 ; n2 = en·in2 ; !in1 = NOT(in1) ; !in2 = NOT(in2) ; !en = NOT(en)
  a1 = n1·!in2 ; a2 = n2·!in1
  → in1=in2=1 时 a1=a2=0：★ "11=全关"由硬件保证，不靠 RTL。

真值表：
  en=1,in1=1,in2=0 → a1=1,a2=0 → HS1+LS2（正相）
  en=0,*,*          → a1=0,a2=0 → 全关（deadtime/停），且 !en=1 关 sink
  en=1,in1=0,in2=1 → a1=0,a2=1 → HS2+LS1（负相）
  en=1,in1=1,in2=1 → a1=0,a2=0 → 全关（非法态自动安全）
★ DEADTIME 定义 = en=0（不是 in1=in2=0）
★ ★ deadtime 时：桥无电流；Rsense 电流≈0；B 允许漂浮，不把 B=0 当必要条件。
```

### 4.3 为什么干净
```
MOSFET 栅电容性（稳态不耗直流）→ B 上唯一直流 = 负载电流 → sink 采样干净
```

### 4.4 电流设定（含 Vref 上限；★ nominal 措辞）

```
I = Vref / Rsense
LM358 ★型号统一：设计锁【LM358B】（PDIP）：GBW 1.2MHz / slew 0.5V/µs / Vos 3mV
                  现有 LM358P 可用，但按保守值：0.7MHz / 0.3V/µs / Vos 7mV
      V+ → +VS(9V)   ← 非轨到轨，5V 输出上限 3.5V 会顶死大电流
      IN+ ← Vref 分压（经 10k）
      IN− ← Rsense 上端（= sink 源极）
      OUT → 1kΩ → sink 栅极
sink N-MOS: 漏极→B，源极→Rsense→隔离GND

★ Vref 硬件上限（防误操作）：
  电位器滑片(0~Vlogic) ──39k──┬── Vref_limit ──10k── IN+
                             10k
                             GND
  nominal（Vlogic=5.00V）：Vref_limit ≈ 1.02V → Imax ≈ 2.62mA
  ★ B0505S 是【非稳压】隔离 DC-DC → Vlogic 是 nominal 5V，不是精确 5.000V
    → 上面全是 nominal；实际 Imax 以【实测 Vlogic + 电阻容差】为准。
    → 不能把 2.5mA 当成"未经测量的硬上限"。
```

> ⚠️ 0.1mA → Vref=39mV；LM358P 的 Vos(max)≈7mV → 误差 ~18%
>   → 0.1mA 是"可调出"，不是"高精度维持"；第一轮验证建议 ≥0.5mA。

### 4.5 元件与接法

```
· 逻辑：74HC08（四与门，用满）+ 74HC04（六反相）
        n1=en·in1 ; n2=en·in2 ; a1=n1·!in2 ; a2=n2·!in1 ; !in1/!in2/!en
        （★ 单颗 74HC00 只有 4 NAND，做不出这些逻辑）
· HS1/HS2：P-MOS（BS250）；源→+VS；栅→10k上拉+VS + 栅↔源 100k
· LS1/LS2：N-MOS（2N7000）栅直驱 + 10k 下拉 GND
· sink：N-MOS（2N7000）+ Rsense + LM358
   ★ sink 栅→100k→GND（本版补：LM358 未上电/高阻时保证 QS 为 OFF）
· 隔直：10µF 【非极性】；锁 C_nom=10µF / C_eff(min)=? / V_rating ≥ ?
   （陶瓷"标称 10µF" ≠ 实际电压下还有 10µF → 按实际电压核实有效容量）
· OVP：一对【同值】双向稳压管跨电极（型号待实测）
· 去耦：每 IC 一颗 100nF；隔离5V 与 +VS 入口各 10µF 储能
· LM358 第 2 通道：pin5→GND，pin6↔pin7（0V 跟随器）
· 未用逻辑输入：74HC08/74HC04/74HC00 全部固定 GND 或 VCC
· 型号注意：BS250 / 2N7000 / 2N3904 都是【多来源老型号】——
  不用通用 pinout 图，只以"采购到的具体 manufacturer + ordering code"的 datasheet 为准。
```

### 4.6 门极驱动与基准地（★ LS 是 compliance 限制）

```
对角驱动：a1→HS1&LS2 ; a2→HS2&LS1 ; a1·a2=0（硬件保证）
· 高边 P-MOS：NPN 电平移位。★ NPN 发射极接隔离 GND（不接 B）。
   ★★ NPN 基极必串限流 1~10kΩ（逻辑门直怼 B-E = 短路）
   ★ base→emitter 各加 100k 下拉（逻辑/隔离器掉电时保证 OFF）
   ★ 栅↔源 100k：驱动失效时栅回源 → P-MOS 必 OFF
· 低边 N-MOS：栅直驱 + 10k 下拉 GND。源在 B（浮动）。
   ★★ 已知 compliance 限制：VGS(LS) = Vlogic − VB；B 升高 → VGS 降低 → LS 压降上升。
      "2N7000 能不能完全打开"【不作为设计假设】——
      只以【目标 I/Z 条件下实测的 VDS(LS)】为准。
· 门极驱动不能把直流注入 B（否则污染采样）。
```

### 4.7 windup 与修复（含时序）

```
现象：死区时桥关 → 负载无电流 → IN−≈0 而 IN+ 仍=Vref → 运放正饱和 → OUT 冲高
      → 下一相开启瞬间 sink 全开 → Zap。
      （注：此时 B 允许漂浮，不把 B=0 当必要条件，只要 Rsense 电流≈0）
修复：死区(!en=1)把 【IN+(Vref)】拉低 —— 不要拉 sink 栅极。
时序：deadtime 开始 → IN+↓ → 负误差（IN− 此刻仍=Vref）→ 运放主动拉低 OUT
      → sink 关、停在 OUT 低位 → deadtime 结束 → IN+ 恢复 → 恒流环重新建立。
（Vref 经 10k 到 IN+；QD 拉低时成分压，保护电位器。）
```

### 4.8 VCCS 稳定性 + ★ deadtime（降级为"待实测"）

```
· LM358 非栅极驱动专用，容性负载能力 ~100pF 量级 → 栅容需隔离。
  参数跟型号走：LM358B 1.2MHz/0.5V/µs/3mV ； LM358P 0.7MHz/0.3V/µs/7mV（更慢）
· 必做：OUT 与 sink 栅极之间串 1kΩ。
· 1nF 补偿【不预设】：看到 ringing 才加。
★★ deadtime 10µs 现为【待实验确定】，不是"已证明安全"：
   en 同时管 bridge 和 sink，二者只差逻辑传播延迟 → 不保证"先关稳再动作"。
   bench 先 50µs → 30 → 20 → 10 逐步缩短，每级以【Rsense 上真实电流波形】判据。
   （用 LM358P 更慢，更不能想当然。）
```

### 4.9 ★ sink 的两个实现（可拔插块；H 桥/隔离/保护不变）

```
同一套 H 桥 + 隔离 + 保护，只换"sink 块"：

T1-L（简化版，bench 先做）：LM334 + Rset
  B → LM334 → GND ；I ≈ 64mV / Rset（25°C）
    Rset：128Ω→0.5mA、64Ω→1mA、32Ω→2mA（串电位器可调）
  优点：无运放、无栅极、无 windup、无补偿网络；真两端浮地元件。
  代价：温漂 +0.33%/°C（实测校准）；初始 ±3%（实测，不信任丝印）；
       需 ~1V 端压（进 compliance）；★ 是"电流调节器"，不是安全层。
  ★ 前提：必须是【真品 LM334】——我们买的 3 颗 LM334Z 是假货（FORGET）。

T1-P（精密版，需要再上）：LM358(B) + 2N7000 + Rsense + Vref（即 4.4/4.7/4.8）
  优点：I=Vref/Rsense 定值、便于以后 DAC 软件控制、低漂。
  代价：运放+MOS+栅极+windup 修复+补偿网络。
```

> 选择原则：**bench 第一版走 T1-L**（快、简单、验证概念）；
> 当出现"温漂不满意 / 要软件调流 / 要精确 0.1mA"时，再换 T1-P，一点不迟。
> 安全链（隔离/OVP/隔直/硬件熔断）**两个版本都必须保留**。

```
保留 DRV8833 换向 + 在【电极串联回路】采样。难点：双相→采样换号。→ 比 T1 复杂。
（仍从其 GND 测回流 → 1.6mA 污染 → 不可行。）
```

## 6. ★ 保护：分层链

```
一级：恒流限制        —— 本 sink（Vref/Rsense）
二级：硬件超流切断    —— LM393N + 锁存 → ★直接切【高边驱动供电】或拉低所有栅极
三级：独立过压钳位    —— 双向稳压管(OVP) 跨电极（★按整对反向串联实测，见 §10）
四级：串联隔直        —— 10µF 非极性 = DC-blocking element（★波形回路的一部分）
                        ★ 不是"完整故障安全屏障"（桥击穿仍可能有瞬态电流）
                        ★ 锁 C_nom/C_eff(min)/V_rating；按实际电压核实有效容量
五级：电源/隔离安全   —— 电池 + CA-IS3762(default-low) + B0505S
   ★ default-low 只是 first line，不能代替各驱动级的硬件下拉（见 §4.5/4.6）
```

## 9. Bring-up（4 步）

```
第 1 步：只搭低边恒流 sink（不接桥）
  假负载【纯电阻】1k/2k/5k/10k；调 Vref；换负载电流不变。
第 2 步：验瞬态（windup）
  方波开关 en；示波器看 Rsense：上升沿无过冲。
  ★ deadtime 先用【50µs】，再逐级缩到 10µs（见 §4.8）。
第 3 步：离散 H 桥静态（B 接地，旁路 sink）
  ★★ +VS 与桥之间串【10kΩ】限流；假负载也用【10kΩ 纯电阻】：
     正常 I ≈ 9V/(10k+10k) ≈ 0.45mA；桥直通 I ≈ 9V/10k ≈ 0.9mA
     → 真正落在"几百 µA~1mA"，不给 MOSFET 做毫安级摔跤测试。
  手动给 a1/a2，确认 00/10/01/11 → OFF/正/负/OFF；无 shoot-through；再去掉限流。
第 4 步：全闭环
  B 接回 sink；接 RTL；看负载两端 + Rsense：
  双相干净、deadtime 内 Rsense 电流确实回 ≈0、无尖峰、恒流。
```
