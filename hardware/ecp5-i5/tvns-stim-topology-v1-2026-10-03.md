## 0. 一句话

把 **"极性切换"** 和 **"电流控制"** 拆开：

- **极性切换** = **离散 H 桥**（只负责换向，本身不耗直流）
- **电流控制** = **低边恒流 sink**（串在负载回路里，只测负载电流）

→ Rsense 里的电流 = **负载电流**，不再是"负载 + 桥芯片自身耗电"。

## 1. 为什么要重画（v0 / v1 的死因）

```
v0: L293D 恒流喂 VCC2 → 达林顿高边基极被饿死
v1: DRV8833 恒流喂 VM → 被芯片自身耗电(~1.6mA)饿死（与负载同量级）
根因：桥芯片 VM 上的电流 = 负载 + 芯片自身耗电，无法分离。
```

## 2. 设计目标 + ★ compliance envelope（二维，不许互相矛盾）

```
硬指标：
· 双相：正相 200µs → 死区 10µs → 负相 200µs → 歇；周期 40ms
· 恒流：I 可调；负载变电流不变
· 采样只测负载电流（不被开关器件自身耗电污染）
· 可关断 + 硬件超流切断
· 电源 +VS（隔离域）+ 逻辑 5V（隔离域），共隔离 GND

★ compliance 是【二维】的：I 和 Z 不能各自独立取最大值
   VS ≥ I×Z + headroom(≈1V：Rsense + 3×MOS + sink)
   反推（headroom 按 ~1V 估）：
     VS =  9V → I×Z ≤ 8V  ：1mA@8kΩ、2.5mA@3.2kΩ
     VS = 12V → I×Z ≤ 11V ：1mA@11kΩ、2.5mA@4.4kΩ
   ⚠️ "2.5mA @ 10kΩ" 需要 ≥ 25V + headroom → 9~12V 不可能。
   → 必须二选一（或在 §10 明确锁死）：
     工作区 A（当前电源可满足）：I≤1mA 且 Z≤10kΩ
     工作区 B（要 2.5mA@10kΩ）：+VS 升到 ~30V
   （真耳朵阻抗 ~1~5kΩ：2.5mA@5kΩ = 12.5V+ → 约 15V 够）
```

## 3. 核心原则

```
★ 极性切换 ≠ 电流控制
   · 极性切换用【开关】（理想开关稳态不耗直流）
   · 电流控制用【串联恒流环节】（在负载回路里采样）
```

## 4. T1 设计

### 4.1 电流路径

```
+VS → HS1/HS2 → 电极 Z → LS1/LS2 → B → sink → Rsense → 隔离GND
```

### 4.2 ★ 状态机（deadtime 绑定 en=0；a1·a2=0 硬约束）

```
正相：en=1, in1=1, in2=0   → a1=1, a2=0 → HS1+LS2 开
死区：en=0, in1=0, in2=0   → a1=0, a2=0 → 桥全关 + !en=1 → Vref→0（sink 关）
负相：en=1, in1=0, in2=1   → a1=0, a2=1 → HS2+LS1 开
歇 ：en=0, in1=0, in2=0   → 同死区

★ 定义：DEADTIME = en=0（不是"in1=in2=0"）
  否则会出现 in1=in2=0 但 en=1 → 桥关、VCCS 仍开 → windup 又回来。
★ 硬约束：a1·a2 必须恒为 0（永远不允许 a1=a2=1 同时开）。
★ power-up = OFF：上电/未初始化时 en=0 → 桥关 + sink 关。
```

### 4.3 为什么干净

```
· MOSFET 栅极电容性：稳态不耗直流
· 低边公共点 B 上唯一的直流 = 负载电流
  → sink 采样电阻只看到负载电流
```

### 4.4 电流设定

```
I = Vref / Rsense
LM358: V+ → +VS(9V)（非轨到轨，5V 输出上限 3.5V 会顶死大电流）
       IN+ ← 经 10kΩ ← 电位器滑片
       IN− ← Rsense 上端（= sink 源极）
       OUT → 1kΩ → sink 栅极
sink N-MOS: 漏极→B，源极→Rsense→隔离GND
```

> ⚠️ Rsense=390Ω 时：Imax 2.5mA（Vref 0.975V）；**Imin 0.1mA → Vref 仅 39mV**，
> 已接近 LM358 的 offset 量级 → 低电流精度有限（见 §10 待锁）。

### 4.5 元件与接法（修正后）

```
· 逻辑：74HC08（四与门）+ 74HC04（六反相）
        a1 = en AND in1 ; a2 = en AND in2 ; !en = NOT en
        （★ 单颗 74HC00 只有 4 个 NAND，做不出上面 3 个逻辑 = 5 gate）
        （替代：74HC00 + 74HC04。别为了省一颗 IC 把极性塞进驱动级。）
· HS1/HS2：P-MOS（BS250）；源接 +VS；栅 10k 上拉 +VS + 栅↔源 47~100k（失效态保险）
· LS1/LS2：N-MOS（2N7000）直驱 + 10k 下拉 GND
· sink：N-MOS（2N7000）+ Rsense + LM358
· 隔直：10µF 【非极性/无极性】（双相脉冲回路，不能用普通极性电解）
· OVP：一对【同值】双向稳压管跨电极
```

### 4.6 门极驱动与基准地

```
对角驱动：a1→HS1&LS2 ; a2→HS2&LS1 ; a1·a2=0
· 高边 P-MOS：NPN 电平移位。★ NPN 发射极接隔离 GND（不接 B）。
              ★★ NPN 基极必串限流电阻 1~10kΩ（74HC00/74HC04 直怼 B-E = 短路，烧件）。
              ★ 栅↔源 47~100k：NPN 断时保证栅回源 → P-MOS 必 OFF。
· 低边 N-MOS：栅直驱 + 10k 下拉 GND。源在 B（浮动）。
              要保证 逻辑高(5V) − B 最高 > Vth（Vref 满量程压低有帮助）。
              ⚠️ 这项要【实测】验证 VGS margin，不能只算。
· 门极驱动不能把直流注入 B（否则污染采样）。
```

### 4.7 windup 与修复（含时序）

```
现象：死区时桥关 → 负载无电流 → IN−=0 而 IN+ 仍=Vref → 运放正饱和 → OUT 冲高
      → 下一相开启瞬间 sink 全开 → Zap。
修复：死区(!en=1)把【IN+(Vref) 拉低】——不要拉 sink 栅极。

时序（正是为什么拉 IN+ 有效）：
  deadtime 开始 → IN+ ↓ → 出现负误差（因为 IN− 此刻仍=Vref）→ 运放主动把 OUT ↓
  → sink 关断、停在 OUT 低位（闭环不满）→ deadtime 结束 → IN+ 恢复 Vref
  → 恒流环重新建立（从"关"平滑爬升）
（Vref 经 10kΩ 到 IN+，下拉成分压，保护电位器。）
```

### 4.8 VCCS 稳定性 + ★ deadtime settling

```
· LM358 非栅极驱动专用：GBW ~1.2MHz、slew ~0.5V/µs，容性负载能力仅 ~100pF 量级
  → MOSFET 栅极电容需要隔离。
· 必做：OUT 与 sink 栅极之间串 1kΩ（把栅容与运放输出节点隔开）。
· 1nF 补偿电容【不预设】：先只装 1kΩ；只有示波器看到
  gate ringing / Rsense ringing / 电流过冲，才加（可能要 1nF）。
  （200µs 脉冲本来就短，无条件加大会把"稳定"换成"太慢"。）
★ 逻辑 deadtime ≠ 模拟已稳！
  sink 从关到稳可能跨数伏，10µs 对 0.5V/µs 的 LM358 并不宽裕。
  必须【在 Rsense 上实测】：确认本相电流已回 0，下一相才建立。
```

## 6. ★ 保护：分层链（不是"单点挡")

```
一级：恒流限制        —— 本 T1 sink（Vref/Rsense）
二级：硬件超流切断    —— LM393N 比较器 + 锁存 → ★ 直接切【高边驱动供电】或拉低所有栅极
三级：独立过压钳位    —— 双向稳压管(OVP) 跨电极（阈值见 §10 数值化）
四级：串联隔直        —— 10µF 非极性 = DC-blocking element
                        ★ 是【波形回路的一部分】，不是"完整故障安全屏障"：
                          桥击穿时电容会被充/放，人体侧仍可能得到【瞬态】电流。
五级：电源/隔离安全   —— 电池 + CA-IS3762(default-low) + B0505S
```

> 撤销旧措辞："无论 H 桥怎么击穿，直流都灌不进人体" → 改为上面的分层表述。

## 9. Bring-up（4 步；静态步加串联限流）

```
第 1 步：只搭低边恒流 sink（不接桥）
  假负载一端 +VS、另一端 B；调 Vref；换负载电流不变。

第 2 步：验瞬态（windup）
  方波开关 en；示波器看 Rsense：上升沿无过冲尖峰。

第 3 步：离散 H 桥静态（B 接地，旁路 sink）
  ★★ 在 +VS 与桥之间【串一个限流电阻】（先给它几百 µA~1mA）：
     万一 HS1+LS1 直通，先烧的是电阻，不是一堆 MOSFET。
  手动给逻辑，确认 4 条路径 + 无 shoot-through；确认后去掉电阻。

第 4 步：全闭环
  B 接回 sink；接 RTL；示波器看负载两端 + Rsense：
  双相干净、deadtime 内电流确实回 0、无尖峰、电流恒定。
```
