## 1. 这段路我们走了什么

从"一块空面包板"出发，把 tVNS 刺激链**从零搭出来**：

- **器件预检**（2N7000/BS250/2N3904/LM334/74HC0x 逐颗验）；
- **逻辑大脑**（74HC04 + 74HC08：`en/in1/in2 → a1/a2/!en`，含互锁）；
- **离散 H 桥**（BS250 高边 + 2N7000 低边 + 2N3904 电平移位）；
- **恒流 sink**（一路换：LM334 → LM358 → 最终锁 **OPA171**）；
- 走到"**能出双相恒流**"（正相 200µs → 死区 → 负相 200µs）。

然后**卡在"波形难看"**：毛刺、振铃、拖尾、滑尾、"冲上去又滑下来"……
反复调、换了三轮恒流方案，最后意识到：

> **不是"手艺差"，是"工具的物理极限"。**

## 2. 踩过的坑（部分清单）

| 坑 | 教训 |
|---|---|
| **LM334 买到假货**（3 颗全坏） | 便宜芯片先买 1 颗单独验 |
| **ISO7721 手工焊 0/10** | 能用预焊模块/直插，绝不手工焊贴片 |
| **L293D 跨隔离地 → 输出乱** | 桥芯片必须整颗在同一地域 |
| **L293D 恒流喂 VCC2 → 达林顿被饿死** | 桥芯片 VM 电流 = 负载 + 自身，分不开 |
| **DRV8833 自身 1.6mA → 恒流源被吃干** | 同上；且是"电机驱动"域不匹配 |
| **LM334 无使能 → 拖尾/滑尾** | 两端浮地电流源，"关不干净" |
| **LM358 非轨到轨 → 关不死** | 小电流有残余，波形底部抬起来 |
| **波形"冲上去又滑下来"** | 环路 windup / 无主动关断 |
| **接触不良、线松、读数飘** | 面包板弹片点接触，不可靠 |

## 3. 核心结论：**面包板 = 草稿纸**

面包板**能回答**的：

- ✅ 这电路**通不通**？
- ✅ **逻辑对不对**（真值表、时序状态）？
- ✅ **稳态量准不准**（恒流值、电压、电流）？

面包板**回答不了**的：

- ❌ 快沿**干不干净**？（有没有振铃/毛刺）
- ❌ 有没有**地弹**、**串扰**、**天线拾取**？
- ❌ 波形**形状**对不对？

→ 后者全由**寄生参数**决定，而面包板**恰恰是寄生最重的地方**。

**所以：在面包板上追求"完美波形"，方向就错了。**

---

## 4. 为什么"完美波形"在面包板上基本不可能

四个"**不受控**"：

```
① 接触不受控   弹片「点接触」：接触电阻会飘（几十 mΩ~几 Ω）；
                还有接触电感。碰一下引线，电阻就变。
② 引线不受控   一根十几厘米杜邦线 = 一根电感（~nH/cm）+ 一根天线；
                工频、开关电源干扰全收进来。
③ 参考地不受控  电源/地是长条铜片，没有「完整地平面」；
                GND 回路阻抗高 → 地弹 V = L·di/dt。
④ 布局不受控   器件摆哪、线走多长，全靠手摆 → 回路面积大 → L 大。
```

**关键不是"某根线的绝对长度"，是"回路面积（loop area）"**——去 + 回围成的圈越大，寄生 L 越大、越像天线。

---

## 5. 一把尺子：**"值"问题 vs "寄生"问题**

| | **值**（标称/容差/温漂） | **寄生**（接触/引线/栅容/地弹） |
|---|---|---|
| 表现 | 电平高低、电流大小、**慢漂移** | **毛刺、振荡、振铃、边沿抖动** |
| 例子 | 电阻容差、Vref 偏、Rsense 温漂 | 接触 R/L、引线 L+天线、栅极 LC、GND 回路 |
| 谁能查 | **仿真能查**（SPICE 用的就是这些值）| **仿真查不到**（除非把寄生也建模）|
| 在哪暴露 | 哪都行 | **面包板最重，PCB 最轻** |

**要点**：电阻"标称 ≠ 实测"只改**电平/电流**，**不造成**毛刺/振荡/振铃——它**最多二阶地**影响环路裕度，**不是形状问题的"主因"**。

---

## 6. 器件层面：三条恒流/驱动路线的教训

| 方案 | 本质 | 致命点 |
|---|---|---|
| **LM334** | 两端浮地、**PTAT** 电流源 | **无使能**（关不干净→拖尾）+ 温漂 `+0.33%/℃` |
| **LM358 + VCCS** | 运放搭恒流（电位器调 Vref）| **非轨到轨**（关不净）+ 需补偿电容 + GBW 0.7MHz + 漂移来自 Vos/电位器/Rsense |
| **DRV8833** | 集成**电机** H 桥 | **域不匹配**：1.6mA 母线静态 + 电荷泵**开关噪声** + MOS `Rds(on)` 温漂吃余量 + 无微电流闭环 |

补充精度：
- **LM334 的"拖尾" ≠ 温漂**：拖尾是**动态/架构**（无使能、负载电容）；温漂是**分钟级直流**。两回事。
- **DRV 的 `Rds(on)` 温漂**：只要用**串联采样电阻**，它**不进采样路径**，电流读数**不受影响**；它影响的是**余量/输出摆幅**。

→ 这正是 T1 把 **"换向"（干净开关）** 和 **"控流"（专门 sink）** 拆开的原因。

---

## 7. 我们最终采用的路线

- **全离散、不用封装模块**：BS250 / 74HC08 / 74HC04 / 2N3904 / 2N7000 / OPA171。
  - 好处：**寄生由自己掌控**（能短回路、加栅阻、铺地）；
  - 代价：**寄生也得自己解决**（模块能"藏"的噪声/耗电，全摊在你面前）。
- **分工两条腿**：
  - **仿真（SPICE）验"设计/值"**（恒流 / anti-windup / 时序）；
  - **面包板只验"逻辑/稳态"**；
  - **寄生问题 → 焊接/PCB**（短回路 + 地平面）。
- 参数锁定：**30V / ≤5.5mA / 25Hz / 200-500µs / OPA171 / anti-windup(A+C)**；
- 已产出：**原理图（netlist 校验）+ BOM**；下一步 **PCB**。

---

## 8. 给未来的规矩

1. **面包板只验逻辑/稳态；别在上面追波形。**
2. **快沿、精度、噪声问题 → 直接焊（洞洞板/PCB）。**
3. **高 di/dt 回路，先缩短它**：短飞线、就近地、就近去耦、（必要时）加**栅阻**。
4. **值错 → 仿真能查；寄生 → 只能靠实物/布局。**
5. 面包板上：**"难看 ≠ 电路错"**；**"好看 ≠ 电路对"**——两者差的是"实测 + 布局"。
6. **换方案前先问**："这是"值"问题还是"寄生"问题？" —— 别用换器件去治寄生。

---

## 9. 一句话收尾

> **面包板是草稿纸：它帮你想清楚"该连什么"，但成品的"波形长什么样"，得由焊死的板子和受控的布局来回答。**
> 我们在面包板上花的这段时间没有白费——它把**设计**验死了；只是**波形**这件事，从一开始就不该指望它。

# 附录 A：电极-皮肤界面（为什么必须闭环）

> 本篇正论是"面包板/寄生"；附录收的是**同一次讨论里浮出来的另一半**——**负载那一端（皮肤）**，它决定了"闭环"到底在闭什么。

## A.1 界面等效

```
电极─皮肤界面:  Cdl(双电层电容) ∥ Rct(电荷转移电阻)  ──串联──  组织(Rs+Rtis + 膜电容)
```

- 我们这个频段（脉冲**主体**低频、200µs 级）→ **Warburg 扩散阻抗占比极低**，可近似成**一阶 RC**；
- 主导波形畸变/剂量偏差的是 **Cdl、Rct、表皮串联电阻 Rs（角质+油脂）**；
- `τ ≈ Rct · Cdl`。

现象对应：
- **上升沿"爬"**：恒流一来，电流**先给 Cdl 充电**，电压慢慢抬到 Rct 导通阈值，才逐渐注入深层 → 时间常数 `τ`；
- **结束"拖尾"**：Cdl 通过 Rct **缓慢放电**。

> ⚠️ **两处要说准**（否则留硬伤）：
> 1. **面包板杂散 C（pF）≪ Cdl（µF）**，并联上去对 `τ` **毫无影响**。面包板给的是**电感 L（→快沿振铃）**，**不是电容**；bench 上那条**拖尾**主因是 **LM334 无使能**。
> 2. `5mA/10µF = 0.5V/ms` 是**界面自然爬升**（`I/Cdl`），**不是运放压摆**；T1 里运放驱动的是 **MOS 栅极**（小摆幅），**不是电极**。LM358 卡的是**输出摆幅（关不干净）+ 环路补偿**，不是 slew。

## A.2 界面的"记忆效应"（时变器件）

- **分钟级**：连续刺激 → 局部升温/出汗 → `Rct↓ Cdl↑ τ↑` → **同电流体感变强**（"从酥麻变刺痛"）；
- **数十分钟级**：若双相**净直流不为零** → 电荷在 Cdl 累积 → **界面极化电压** → 触发**电极反应**（水电解、离子迁移、金属溶解…）→ **泛红/灼伤**。**这才是真正的皮肤损伤根源，不是"电流本身太大"。**（"~200mV" 只作参考，**越低越安全**。）
- **位置**：电极挪 1mm，接触面积/角质/油脂全变，`Z` 可跳 **30%+**。

→ **这就是"每帧测 Z"的意义**：界面全程在变，不是开机测一次合格就完事。

## A.3 为什么"恒流"救不了全部（两个环）

- **恒流（电流环）**：`Z` 涨 → `V` 涨 → `I` 不变。它挡的是**阻抗变化**；对"**个体响应差异**"无能为力。
- **生理环**：EDA/HR/温度 → HRV/LF → **调剂量**（每人/每侧各自读基线，双侧不镜像）。

```
生理环(已有): EDA/HR/温度 → HRV/LF       → 该给多少
界面环(要补): Z + 直流偏移 + 恒流余量     → 接触门 / 剂量事实 / 电荷平衡
闭环 tVNS  = 这两环的叠加
```

# 附录 B：界面环实现（两步走）

## B.0 当前阶段 = 最小闭环

> 现在是最早阶段：**能采集、能恒流**即可。所以**最小版 = 恒流源（已做）+ 一路电极电压采样 + 现有生理采集**。EIS、精细分类都往后放。

## B.1 第一步：基础界面环（优先落地）

**硬件**：加一路**差分电压采样**跨在 **`EL1–EL2`**（电极-皮肤两端，**不含**隔直电容 C2），经**隔离**后送 ADC。**隔离是皮肤接触设备的安全底线**（AMC1300 隔离放大器，或岛侧 ADC + 数字隔离 ISO1540）。

**算法**：
- 采样时机 = **脉冲平顶中点**（避开双电层充放电瞬态）；
- `Z = V / i_actual`——**用实测电流**（"事实"），不是设定值（对上 `0x26` 的命令 vs 事实）；
- 三个观测量：
  1. **`Z`（幅值阻抗）** → **接触门**（超限禁发/提示擦耳甲艇）、**剂量事实**（与生理数据对齐，区分"阻抗变了"还是"人真反应了"）；
  2. **直流偏移/电荷平衡** → 监控**隔直电容电压**（或采样端直流分量）→ 漂了就**实时微调正负脉宽**；
  3. **恒流余量** → `Z` 接近电压摆幅上限时**提前降额/提示**，避免恒流失锁。

> 落地要点：隔离放大器要能扛**双相极性翻转（±）**和**~28V 共模**；`EL` 与 `MID` 的接法要分清楚。

## B.2 第二步：进阶界面诊断（EIS，后续迭代）

在基础版之上，叠加**低频小幅度 AC 探针**（如 100Hz、几十 µA），做**简化单频 EIS**：
- **同步解调**出电压的**实部/虚部** → 对应阻性(`Rs+Rct`)/容性(`Cdl`)；
- 粗分类：**阻性偏高 → 油脂/角质**；**容性偏高 → 出汗/导电膏过多**；**剧烈波动 → 接触不良/移位**；
- 联动：识别界面状态 → 自动微调**软启动斜率 / 电流上限**。

> 落地要点：探针频率要贴着界面 `τ`（`f≈1/(2πRct·Cdl)`）选，**100Hz 是起点猜测**；单频=单点，想分四类宜留 **2–3 频点**；探针**插在脉冲间歇**、**极小 + 自身电荷平衡**。

# 附录 C：与本篇的关系

- 本篇正论（面包板/寄生）回答"**在哪验、怎么验**"；
- 附录回答"**负载那一端怎么测**"——两者是同一次讨论的两半：
  - **面包板只验逻辑/稳态**（A 篇）；
