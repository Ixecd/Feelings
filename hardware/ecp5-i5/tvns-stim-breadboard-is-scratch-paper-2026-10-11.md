## 1. 这段路我们走了什么

从"一块空面包板"出发，把 tVNS 刺激链**从零搭出来**：

- **器件预检**（2N7000/BS250/2N3904/LM334/74HC0x 逐颗验）；
- **逻辑大脑**（74HC04 + 74HC08：`en/in1/in2 → a1/a2/!en`，含互锁）；
- **离散 H 桥**（BS250 高边 + 2N7000 低边 + 2N3904 电平移位）；
- **恒流 sink**（一路换：LM334 → LM358 → 最终锁 **OPA171**）；
- 走到"**能出双相恒流**"（正相 200µs → 死区 → 负相 200µs）。

然后**卡在"波形难看"**：毛刺、振铃、拖尾、滑尾、"冲上去又滑下来"……
反复调、换了三轮恒流方案，最后意识到：

> **不是"手艺差"，是"工具的物理极限"。**

## 2. 踩过的坑（部分清单）

| 坑 | 教训 |
|---|---|
| **LM334 买到假货**（3 颗全坏） | 便宜芯片先买 1 颗单独验 |
| **ISO7721 手工焊 0/10** | 能用预焊模块/直插，绝不手工焊贴片 |
| **L293D 跨隔离地 → 输出乱** | 桥芯片必须整颗在同一地域 |
| **L293D 恒流喂 VCC2 → 达林顿被饿死** | 桥芯片 VM 电流 = 负载 + 自身，分不开 |
| **DRV8833 自身 1.6mA → 恒流源被吃干** | 同上；且是"电机驱动"域不匹配 |
| **LM334 无使能 → 拖尾/滑尾** | 两端浮地电流源，"关不干净" |
| **LM358 非轨到轨 → 关不死** | 小电流有残余，波形底部抬起来 |
| **波形"冲上去又滑下来"** | 环路 windup / 无主动关断 |
| **接触不良、线松、读数飘** | 面包板弹片点接触，不可靠 |

## 3. 核心结论：**面包板 = 草稿纸**

面包板**能回答**的：

- ✅ 这电路**通不通**？
- ✅ **逻辑对不对**（真值表、时序状态）？
- ✅ **稳态量准不准**（恒流值、电压、电流）？

面包板**回答不了**的：

- ❌ 快沿**干不干净**？（有没有振铃/毛刺）
- ❌ 有没有**地弹**、**串扰**、**天线拾取**？
- ❌ 波形**形状**对不对？

→ 后者全由**寄生参数**决定，而面包板**恰恰是寄生最重的地方**。

**所以：在面包板上追求"完美波形"，方向就错了。**

---

## 4. 为什么"完美波形"在面包板上基本不可能

四个"**不受控**"：

```
① 接触不受控   弹片「点接触」：接触电阻会飘（几十 mΩ~几 Ω）；
                还有接触电感。碰一下引线，电阻就变。
② 引线不受控   一根十几厘米杜邦线 = 一根电感（~nH/cm）+ 一根天线；
                工频、开关电源干扰全收进来。
③ 参考地不受控  电源/地是长条铜片，没有「完整地平面」；
                GND 回路阻抗高 → 地弹 V = L·di/dt。
④ 布局不受控   器件摆哪、线走多长，全靠手摆 → 回路面积大 → L 大。
```

**关键不是"某根线的绝对长度"，是"回路面积（loop area）"**——去 + 回围成的圈越大，寄生 L 越大、越像天线。

---

## 5. 一把尺子：**"值"问题 vs "寄生"问题**

| | **值**（标称/容差/温漂） | **寄生**（接触/引线/栅容/地弹） |
|---|---|---|
| 表现 | 电平高低、电流大小、**慢漂移** | **毛刺、振荡、振铃、边沿抖动** |
| 例子 | 电阻容差、Vref 偏、Rsense 温漂 | 接触 R/L、引线 L+天线、栅极 LC、GND 回路 |
| 谁能查 | **仿真能查**（SPICE 用的就是这些值）| **仿真查不到**（除非把寄生也建模）|
| 在哪暴露 | 哪都行 | **面包板最重，PCB 最轻** |

**要点**：电阻"标称 ≠ 实测"只改**电平/电流**，**不造成**毛刺/振荡/振铃——它**最多二阶地**影响环路裕度，**不是形状问题的"主因"**。

## 6. 器件层面：三条恒流/驱动路线的教训

| 方案 | 本质 | 致命点 |
|---|---|---|
| **LM334** | 两端浮地、**PTAT** 电流源 | **无使能**（关不干净→拖尾）+ 温漂 `+0.33%/℃` |
| **LM358 + VCCS** | 运放搭恒流（电位器调 Vref）| **非轨到轨**（关不净）+ 需补偿电容 + GBW 0.7MHz + 漂移来自 Vos/电位器/Rsense |
| **DRV8833** | 集成**电机** H 桥 | **域不匹配**：1.6mA 母线静态 + 电荷泵**开关噪声** + MOS `Rds(on)` 温漂吃余量 + 无微电流闭环 |

补充精度：
- **LM334 的"拖尾" ≠ 温漂**：拖尾是**动态/架构**（无使能、负载电容）；温漂是**分钟级直流**。两回事。
- **DRV 的 `Rds(on)` 温漂**：只要用**串联采样电阻**，它**不进采样路径**，电流读数**不受影响**；它影响的是**余量/输出摆幅**。

→ 这正是 T1 把 **"换向"（干净开关）** 和 **"控流"（专门 sink）** 拆开的原因。

## 7. 我们最终采用的路线

- **全离散、不用封装模块**：BS250 / 74HC08 / 74HC04 / 2N3904 / 2N7000 / OPA171。
  - 好处：**寄生由自己掌控**（能短回路、加栅阻、铺地）；
  - 代价：**寄生也得自己解决**（模块能"藏"的噪声/耗电，全摊在你面前）。
- **分工两条腿**：
  - **仿真（SPICE）验"设计/值"**（恒流 / anti-windup / 时序）；
  - **面包板只验"逻辑/稳态"**；
  - **寄生问题 → 焊接/PCB**（短回路 + 地平面）。
- 参数锁定：**30V / ≤5.5mA / 25Hz / 200-500µs / OPA171 / anti-windup(A+C)**；
- 已产出：**原理图（netlist 校验）+ BOM**；下一步 **PCB**。

## 8. 给未来的规矩

1. **面包板只验逻辑/稳态；别在上面追波形。**
2. **快沿、精度、噪声问题 → 直接焊（洞洞板/PCB）。**
3. **高 di/dt 回路，先缩短它**：短飞线、就近地、就近去耦、（必要时）加**栅阻**。
4. **值错 → 仿真能查；寄生 → 只能靠实物/布局。**
5. 面包板上：**"难看 ≠ 电路错"**；**"好看 ≠ 电路对"**——两者差的是"实测 + 布局"。
6. **换方案前先问**："这是"值"问题还是"寄生"问题？" —— 别用换器件去治寄生。

---

## 9. 一句话收尾

> **面包板是草稿纸：它帮你想清楚"该连什么"，但成品的"波形长什么样"，得由焊死的板子和受控的布局来回答。**
> 我们在面包板上花的这段时间没有白费——它把**设计**验死了；只是**波形**这件事，从一开始就不该指望它。
