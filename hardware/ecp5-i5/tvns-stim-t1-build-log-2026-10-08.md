## 1. 从零的物理装配顺序（装配 → 手册 Step 0→4）

不要按手册 Step 编号来"焊"，按下面的域来装，装完再逐 Step 验：

- **Phase A｜器件预检（不通电）— ✅ 2026-10-08 完成**

**器件预检实测记录（2026-10-08，万用表二极管档）**

| 器件 | 实测脚位（平面朝自己、脚朝下） | 实测现象 | 结论 |
|---|---|---|---|
| 2N7000 (N-MOS) | 左 S / 中 G / 右 D | 红左黑右 = 0.606；反 = 0L；中↔左右 = 0L | ✅ 合格 |
| BS250 (P-MOS) | 左 D / 中 G / 右 S | 红左黑右 = 0.608；反 = 0L | ✅ 合格 |
| 2N3904 (NPN) | 左 E / 中 B / 右 C | 红中黑左/右 = 0.684；左→右 = 0L | ✅ 中=B、NPN 确认（E/C 顺序按 datasheet） |
| LM334Z (TI) | 左 V+ / 中 R / 右 V− | 用户功能验证通过 | ✅ 合格 |
| 74HC08 / 74HC04 | DIP-14：7=GND（左下）14=VCC（右上） | 蜂鸣档 7-14=0L；二极管档 红7黑14=0.645、反=0L | ✅ 内置保护二极管正常 |
- **Phase B｜逻辑译码（74HC04+74HC08）— ✅ 2026-10-08 完成**
  - 74HC04 三路反相器全对（!in1/!in2/!en：1进0出、0进1出）。
  - 74HC08 真值表五行全对：110→a1=1/a2=0；101→0/1；**111→0/0（硬件互锁）**；0**→0/0。
  - 供电：5V = i5 主域（**本阶段不搭隔离**）。
- **Phase C｜低边开关 LS1/LS2（2N7000）— ✅ 2026-10-08**（a1→7000-2、a2→7000-1 斜对角；栅 4.7k 下拉）
- **Phase D｜高边开关 HS1/HS2（BS250）+ 电平移位 LH1/LH2（2N3904）— ✅ 2026-10-08**（栅 20k+100k 上拉→VS'；基极 4.7k 串 + 100k 下拉→GND）
- **Step 3 整桥静态 — ✅ 2026-10-08**：a1→mid1 高/mid2 低；a2→mid2 高/mid1 低；全关时 mids 悬空（≈1.3V）无电流。VS' 限流临时 10k→**1k**（5V 下 10k 会让 P-MOS 开不透）
- **Phase E｜sink 块 + Rsense**：T1-L（LM334Z，**已单独验通**：负载 1k/2k/4.7kΩ → 0.67/0.675/0.677 mA，恒流成立）
- **Phase F｜保护**：隔直 10µF 非极性 + OVP（跨电极，一对同值）
- **【暂缓】隔离域**（B0505S / CA-IS3762 / MN-305S）：本阶段用 i5 5V 主域；**贴人前必须补回**
- **接线完成后**：从 **Step 0（断电 OFF 态）** 开始逐 Step 验。

**接线铁律**（manual §4）：每个 IC 一颗 100nF 去耦；隔离 5V 与 +VS 入口各 10µF 储能；所有下拉/上拉别漏。

## 2. Step 0 — 断电验 OFF 态（先做这个，再谈上电）

**不带电**，用万用表通断/电压检查：

- [ ] a1=0 时：HS1 / LS2 必 OFF（栅↔源电压为 0）
- [ ] a2=0 时：HS2 / LS1 必 OFF
- [ ] !en=1 时：LM358 IN+ 被拉低（≈0V）
- [ ] sink 栅极有明确下拉路径（100k→GND）
- [ ] HS 栅有明确上拉到 +VS（+ 栅↔源 47~100k）
- [ ] LS 栅有明确下拉到 GND（10k）
- [ ] 任何时刻不会出现 a1=a2=1
- [ ] **Step 0 前置**：BS250 / 2N7000 / 2N3904 各**逐颗验 pinout**（平面朝自己、脚朝下：2N7000=**S G D**、BS250=**D G S**、2N3904=**E B C**；多来源老型号，只认手上这颗的 datasheet）

## 3. Step 1 — 验 sink（★ 先做 6A）

### 6A. LM334 版（T1-L，推荐先做）

```
sink = LM334 + Rset（★ 必须是真品，先单颗验）
  B → LM334 V+ ; LM334 V− → 隔离GND
  Rset 接在 LM334 的 R 脚与 V− 脚之间（datasheet Fig.13 "Basic Current Source"）
  I ≈ 64mV / Rset（25°C）：128Ω→0.5mA、64Ω→1mA、32Ω→2mA（串电位器可调）
负载：隔离 +VS(9V) → 纯电阻 1k/2k/5k → B
量：负载压差 ÷ 负载阻值 = I
```

- [ ] **单颗验真**：★ 实测脚位（平面朝自己 = 左 V+ / 中 R / 右 V−，**与直觉相反**）；先接反过一次
- [ ] 换负载 1k→2k→5k，电流基本不变
- [ ] 实测电流（±3% 初始 + 温漂 +0.33%/°C → 别信丝印，量了算）
- 记录：`I(1k)=___  I(2k)=___  I(5k)=___  Rset=___`

### 6B. LM358 版（T1-P，需要精度/软件控制时再上）

```
pin8(V+)→隔离+VS(9V)（★ 不用 5V，非轨到轨）
pin4(GND)→隔离GND
pin3(IN+)→§3 的 Vref_limit（经 10k）
pin2(IN−)→Rsense 上端（= sink 源极）
pin1(OUT)→1kΩ→sink 栅极
第2通道固定：pin5→隔离GND ; pin6↔pin7
QS=2N7000: D→B ; S→Rsense(390Ω)上端 ; G←1k←pin1 ; G→100k→GND
Rsense 390Ω: sink 源极 → 隔离GND
负载：+VS(9V) → 纯电阻 1k/2k/5k/10k → B   （★ 本步不要 100nF，会污染 200µs 脉冲电流读数）
```

- [ ] pin2 ≈ pin3（闭环）
- [ ] 换负载 1k→2k→5k→10k，电流不变（I = Vref/390）
- [ ] Vref≈1V 时 I≈2.56mA；无发烫
- [ ] 0.1mA 端可调出，但精度需实测（39mV 已近 LM358 offset）→ **第一轮验证区间建议 ≥0.5mA**

## 4. Step 2 — 验 windup（用 !en 拉 IN+）

```
QD 2N3904: C→IN+ ; E→隔离GND ; B←10k←!en
方波开关 en；示波器看 Rsense（地夹夹隔离GND）
deadtime 先用 50µs，再 30→20→10 逐级缩；每级以 Rsense 真实波形为判据
```

- [ ] en=0 → a1=a2=0 → IN+=0 → sink 关（OUT 被拉低）
- [ ] en=1 → 桥导通、电流平滑建立，无过冲尖峰
- [ ] 有纹波/过冲 → 查 QD 是否真拉 IN+、!en 极性
- 记录 deadtime：`50µs[ ] 30µs[ ] 20µs[ ] 10µs[ ]`

## 5. Step 3 — H 桥静态（★ 用 a1/a2，不用裸 in1/in2）

```
+VS ──[10kΩ]── 桥的 +VS 节点          ← 本版改 10k（1k 时直通可达 9mA）
假负载也用 10kΩ 纯电阻：正常 I≈0.45mA、直通 I≈0.9mA
HS1/HS2: S→限流后+VS ; D→mid1/mid2 ; G→10k上拉+VS + 栅↔源100k + NPN 集电极
LH1/LH2: C→P-MOS栅 ; E→隔离GND ; B←10k←a1/a2
LS1/LS2: D→mid1/mid2 ; S→B(本步 B 直接接隔离GND，旁路 sink) ; G←a2/a1 + 10k下拉
负载：mid1 ── 纯电阻 ── mid2
```

手工给 en/in1/in2（跳线），看 a1/a2：

- [ ] 00=OFF / 10=正相 / 01=负相 / 11=非法
- [ ] 无 shoot-through、无发烫
- [ ] a1=0 时 HS1/LS2 确实 OFF（Step 0 复验）
- [ ] 4 条路径全对后 → **去掉 +VS 的 10kΩ 限流**

## 6. Step 4 — 全闭环

```
B 接回 sink；接 RTL(en/in1/in2)；示波器看 负载两端 + Rsense(地夹夹隔离GND)
```
