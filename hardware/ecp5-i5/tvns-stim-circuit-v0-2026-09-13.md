# tVNS 刺激电路 v0 —— 框图 · 连接表 · 安全

> 日期：2026-09-13
> 目标：ECP5 i5 → **双相恒流** → 耳甲艇电极（人）。
> 物料：见 `hardware/BOM.md`。控制：ECP5 出波形，PC/app 出规则。
> ★ 铁律：**先假负载（1kΩ+100nF）验证，再贴人**；贴人必须电池供电 + 拔掉所有下载器/串口。

## 一、整体框图

```
                        ┌─────────────── 隔离带 ───────────────┐
ECP5 i5 (连USB/市电)     │                                      │  (贴人侧, 浮地)
  │  波形定时:           │                                      │
  │   EN(脉冲) ──┐       │                                      │
  │   IN1/IN2 ──┤       │                                      │
  │   (极性)    │       ▼                                      │
  │             └──► ISO7721 (数字隔离) ──► L293D EN/IN1/IN2    │
  │                                          (H桥: 极性翻转)     │
  │  I2C(SDA/SCL) ───► MCP4725 (DAC) ──► Vref                   │
  │                    (设幅度)               │                  │
  │                                          ▼                  │
  │                                    [恒流源 LM334 或 LM358 VCCS]
  │                                          │  I = Vref/Rset|Rsense
  │                                          ▼                  │
  │                                    L293D VCC2 (供电)         │
  │                                          │                  │
  │                                  L293D OUT1/OUT2            │
  │                                     │        │              │
  │                          隔直10µF ──┘        │              │
  │                                     │        │              │
  │                                  电极A      电极B             │
  │                              (耳甲艇)   (耳垂/耳后回流)      │
  │                                                             │
  │  B0505S (隔离5V) ──► 给贴人侧供电 (LM334/LM358/L293D/MCP4725)│
  └─────────────────────────────────────────────────────────────┘
```

**一句话**：`ECP5 出定时 → 隔离 → H桥翻极性 + 恒流源定电流 → 隔直 → 电极`。

## 二、电流源（两选一）

### A. 手动版（最简，先用这个验证电路）—— LM334

```
隔离5V ──► LM334(V+)
              │
   Rset = 电位器(10kΩ) + 串一个小电阻   ← 接在 LM334 的 R 脚(见 datasheet)
              │
           I = 67.7mV / Rset  ──► 输出电流
```
- 转旋钮 = 调电流；**软件插不进去**。
- ⚠️ 10kΩ 电位器对 0.1–1.5mA 偏大（有效行程 ~6%）→ 串个 ~47Ω 起，或换 1kΩ 电位器。

### B. 软件版（闭环用）—— LM358 VCCS + MCP4725

```
MCP4725 VOUT (0–1.5V) ──► LM358 (+)
LM358 (−) ◄── Rsense 上端
LM358 OUT ──► Rsense 上端 (驱动)
Rsense 下端 ──► GND
→ I = VOUT / Rsense   (Rsense=1kΩ, VOUT 0–1.5V → 0–1.5mA)
```
- 软件设 VOUT = 设电流；**闭环必需**。
- LM358 单电源 5V，输出上摆 ~3.5V（不轨到轨）→ **compliance 有限**（见第八节）。

> 先搭 **A** 验证电路通不通、找阈值；确认后再上 **B**。

## 三、H 桥（双相）—— L293D

```
L293D (DIP-16):
  VCC1(pin16) = 隔离5V (逻辑)
  VCC2(pin8)  = 恒流源输出 (驱动供电)
  EN1(pin1)   = 脉冲使能 (ECP5, 经隔离)
  IN1(pin2)/IN2(pin7) = 极性 (ECP5, 经隔离)
  OUT1(pin3) / OUT2(pin6) = 到电极
  GND(4,5,12,13)
```

**双相时序**（ECP5 生成）：
```
正相: IN1=1 IN2=0, EN=1 (脉宽 0.2-0.5ms) → EN=0
负相: IN1=0 IN2=1, EN=1 (同脉宽)         → EN=0
... 每周期一次, 频率 20-25Hz
```

- 只用 **1 路 H 桥**（L293D 有 2 路）。
- "D" = 内置续流二极管（防感性反冲）。
- ⚠️ L293D 输出压降 ~1.4–2V/侧 → 吃 compliance。

## 四、隔离 + 电源

```
信号隔离: ECP5 GPIO → ISO7721 → L293D 的 EN/IN   (2 通道: EN + 极性; 或 3 线)
   ISO7721: 两侧各接自己的 VCC/GND; 数字信号跨隔离带
电源隔离: B0505S-1W: 5V(主板) → 隔离5V → 贴人侧全部供电
   ★ 贴人侧的 GND 与主板 GND【不连通】——这是安全的根本
```

> ⚠️ ISO7721DR 是 SOIC-8 → 焊在 **SOP→DIP 转接板**上（1.27mm 面）才能上面包板。

## 五、保护

```
① 隔直:   10µF 独石(无极性) 串在 OUT1→电极A 之间   → 物理防直流
② OVP:    稳压管(~5.1V/6.2V) 跨在 电极A-电极B 之间  → 防脱落重触打火
③ 限流:   恒流源本身限流(LM334/VCCS)；再加硬限流(可选)
④ 看门狗: ECP5 若挂 → EN 停 (纯硬件 or 逻辑) → 输出停
⑤ 软启动: 电流 0→目标 线性缓升 1-2s, 禁突变
```

## 六、连接表（模块级）

| 从 | 到 | 信号/电源 | 备注 |
|---|---|---|---|
| ECP5 GPIO | ISO7721 输入侧 | EN / IN1 / IN2 | 3 线（或 2 线+编码） |
| ISO7721 输出侧 | L293D EN1/IN1/IN2 | 隔离后数字 | 用隔离侧 VCC/GND |
| ECP5 I2C | MCP4725 SDA/SCL | 数字 | ⚠️ 若 MCP4725 在贴人侧，I2C 也要隔离；**建议 MCP4725 放主板侧**，输出 VOUT 经隔离/直接给 VCCS |
| MCP4725 VOUT | LM358 (+) | 模拟 Vref | 0–1.5V |
| LM358 OUT | Rsense 上端 | 电流 | I=Vref/Rsense |
| Rsense 下端 | GND(贴人侧) | — | |
| 恒流源输出 | L293D VCC2 | 电流 | 经 H 桥 |
| L293D OUT1 | 10µF → 电极A | 双相电流 | 隔直 |
| L293D OUT2 | 电极B | 双相电流 | 回流 |
| B0505S +Vout/−Vout | 贴人侧 VCC/GND | 隔离5V | |
| B0505S +Vin/−Vin | 主板 5V/GND | — | |

> ⚠️ **MCP4725 放哪侧**：若放贴人侧，I2C 需隔离（麻烦）；**建议放主板侧**（ECP5 直接 I2C），VOUT 作为"低压参考"给贴人侧的 VCCS——但 VOUT 也跨了隔离带 → 需确认参考地怎么接（见第八节待定）。

## 七、上电 / 测试顺序（★ 不许跳）

```
0. 先搭好, 不接人
1. 假负载: 1kΩ + 100nF 代替电极, 接在 OUT1/OUT2 之间
2. 上电(隔离5V), 示波器看:
   · 波形: 双相方波, 频率/脉宽对
   · 电流: 串个 1kΩ 采样电阻看 I=V/R, 对得上设定
   · 幅值: 电流 ≤1.5mA, 硬上限 2.0mA
   · 软启动: 0→目标 缓升
   · 开路: 断开负载 → Vout 到钳位轨 → 应停止输出
3. 全过 → 才允许贴人
4. 贴人: 电池供电 + 拔掉【所有】下载器/串口/示波器; 从最低电流开始
5. 任何不适 → 立即停
```

## 八、已知坑 / 待定

```
① compliance(电压余量): 5V 供电 + L293D(~2V) + LM358(上摆~3.5V)
   → 电极阻抗高时可能顶不满电流
   → 对策: 提高隔离电源(如 12V 隔离) / 换低压降 H桥(DRV8833) / 接受
② LM358 模块默认 100x 增益 → 用前调到 1x(跟随)或改成 VCCS 接法
③ 10kΩ 电位器范围偏大(手动版) → 串小电阻或换 1kΩ
④ MCP4725 放主板侧 vs 贴人侧 → Vref 跨隔离带怎么接【待定, 搭时定】
⑤ 电流监测: 想读实际电流 → 采样电阻 + 示波器(现在) / 以后加 ADC
⑥ 双相切换死区: 换向前 EN=0 留死区, 防上下桥直通
```
