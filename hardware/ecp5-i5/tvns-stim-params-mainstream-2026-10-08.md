# tVNS 刺激参数对齐（走文献主流）— 2026-10-08

> 决定：**走主流 taVNS 路线**（不再走"微电流"），+VS 可到 **30V**。
> 依据：文献主流 **25Hz / 200µs（可 200–500µs）/ 强度 1–4.5mA**；200µs 感知阈 ≈2.24mA，常用"200% 感知阈"≈4.5mA；恒流刺激器标配上限 **5mA**。

## 2. 为什么这样改

- **Rsense 390→100Ω**：5mA 时 390Ω 要吃掉 **1.95V**（白白占 compliance）；100Ω 只吃 0.5V。
- **OVP 12→36V**：30V 供电时电极可能到 ~27V，钳位要**高于工作电压、远低于损伤**，取 ~36V。
- **电容耐压**：桥上会出现 ~30V，10µF（非极性）与储能电容耐压必须 **≥50V**。
- **compliance**：30V − 约3V 余量 = 27V 可加在负载上 → 5mA 时 Z≤5.4kΩ（耳朵常见 1–5kΩ，够）。

## 3. ⚠️ 连带问题（必须在原理图前解决）

1. **运放供电**：LM358 最大 32V，**30V 贴上限**，不安全。
   - 方案 A：运放单独走 **~12–24V 稳压轨**（与 30V 桥分开）；
   - 方案 B：换**高压运放**（如耐 36V 以上）。
   → **二选一。**
2. **栅极上拉开销**：HS 栅极上拉（20k∥100k=16.7k）在 30V 下变成 **1.8mA 静态电流**（a1/a2 一开就流），而且它会**穿过 VS' 限流电阻**，把 30V 拉低。
   - 30V 下，(I_load + 1.8mA)×1k 的压降很可观 → **VS' 限流值 / 栅极上拉都要重新权衡**，或改成更省电的栅极驱动。
3. **安全层阈值**：比较器采样仍取 Rsense → 硬熔断 5mA × 100Ω = **0.50V**（要重定标）。
4. **高压器件核对**：BS250(Vds)/2N7000(Vds)/2N3904(Vceo) 在 30V 下都要核 datasheet。

| **运放供电** | **A：单独 12–15V 稳压轨** | 降额（30V 对 36V 运放占 83%，不够）、输出摆幅只需 ~3–5V、PSRR 隔离 Boost 纹波 |

## 6. ★ review 修正（画图前必改）

1. **隔直电容：不要用 X7R/X5R 陶瓷。**
   - X7R **电压系数强**（50V 额定、30V 工作时有效容量可能只剩一半）+ **压电噪声** → 精密刺激回路不适用。
   - 改：**薄膜电容**（聚酯/聚丙烯 2.2–4.7µF / 50–100V），或**两只极性电容背靠背**串成无极性。
   - ★ 必须**实测 30V 下的 C_eff**（手册本来就把这列为待锁项）。
2. **Vgs 钳位是"必需"不是"可选"。** BS250 的 Vgs 绝对最大通常 **±20V**，30V 直接**打穿栅氧**。12V GS 稳压管（或 TVS）**必须上**，并全型号核对栅氧耐压。
3. **VS' 的 bench 1k 限流：最终版必须去掉或大幅改小（~10–47Ω）。**
   - 你的 28V 计算里**没扣这颗电阻**：真实工作点 (5mA + 栅极电流)×1k ≈ **5V**，直接把 compliance 吃掉。
   - 最终版的过流兜底交给**硬熔断（eFuse/比较器锁存）**，而不是这颗限流电阻。
4. **四层电流阈值要自洽**：现在有 **软4 / 硬5 / 绝对5.5 / HW 6.0** 四个数。请明确各自角色：
   - 软 = 治疗上限（软件可设）；硬 = 协议硬截断；绝对 = 不允许超过；6.0 = **硬件比较器最终动作阈值**。
   - 或者简化成三层，别让它们互相打架。

## 8. 仿真发现与锁定（2026-10-08）

### 8.1 高边关断时序（30V，含栅极电容/米勒）
| 上拉 | 到关断区(-3V) | 基本关断 |
|---|---|---|
| 100k | 15.4µs | 29µs |
| 22k | 3.6µs | 6.6µs |
| **10k** | **1.7µs** | 3.1µs |
| 4.7k | 0.9µs | 1.6µs |

→ **锁定：上拉 10–22k；死区 20–30µs**（100k 配 10µs 死区会直通）。

### 8.2 ★ Anti-Windup（30V / Rsense=100Ω / 运放12V轨）
稳态 5.00mA ✅，但发现**相位起始电流尖峰**：无 VS' 限流时达 **14.2mA** → 会误触 6mA 硬熔断。
根因：死区时 `IN−=0`，QD 只把 `IN+` 拉到 ~20mV（>0）→ **运放照样往高饱和**（qgate~10V）→ 下一相一开就冲。

**对比（仿真）：**
| 方案 | 峰值 | 评价 |
|---|---|---|
| 仅 C（vref 软启动）| 14.2mA | ❌ 运放已饱和，无用 |
| 仅 A（死区抬 IN−）| 8.2mA | ⚠️ 残余环路过冲 |
| **A + C** | **4.997mA** | ✅ **零过冲，锁定** |

**选定方案 A + C：**
- **A**：死区时把 `IN−`（Rsense 上端）抬到 **~50mV**（> `IN+` 被 QD 拉的 ~20mV）→ 运放输出**真到低**（栅极 0.2V）；
- **C**：`vref`/`IN+` 加 **0.5–1nF** → 相内电流**平滑爬升 ~15–40µs**，消除环路过冲。
- ★ A 与 C **缺一不可**。

### 8.3 其他锁定
- 硬件熔断响应：现实值 **~1–10µs**（改掉"<500ns"）；
- 熔断动作要**物理切断 + 栅极泄放**（仅拉 Boost EN 不够）；
- 控制中间态锁 **`EN=0`（全关）**；
