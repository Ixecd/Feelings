## 一、5V 通路的关键纠正

### ① OVP 必须换管（否则等于没有保护）

```
5V 隔离轨上，1N4742A（12V）永远不导通 → 开路打火无钳位。
→ 换 BOM 里那包 1W 直插中的 5.1V 或 6.2V 稳压管。
（tvns-stim-circuit-v0:116 原本就写"选 ~5.1/6.2V 更配隔离 5V"）
```

### ② 假负载必须低阻（5V 的物理上限）

```
可用电压 ≈ 5V(隔离) − L293D(~1.8V) − 源开销(~1V) ≈ 2.2V
→ 假负载 Z ≤ ~1.5kΩ 才推得满 1.5mA（1.5mA × 1kΩ = 1.5V）
→ Z=5kΩ 时电流会掉：这是 compliance 限制，不是故障。
→ Phase B/C 一律用 1kΩ 假负载；高阻场景标注"5V 下不可测"。
```

> 贴人前要面对的正是高阻场景（皮肤 1–10kΩ+）——那时必须补 compliance（隔离 9–12V 或 DRV8833），
> 见 `FORGET.md:123-125`。

## 二、安全层模型（搭建时逐条对照）

```
Layer 5  生理闭环     反射检测(PPG HR骤降→切断) / 呼吸 / 累计剂量漏桶 / 双侧独立校准
Layer 4  操作/人体     电池供电+拔全部下载器 / 假负载先验 / 擦耳甲艇 / 阻抗门 / 左侧优先 / 急停
Layer 3  协议         0x26 命令vs事实(i_actual+z_load) / 0x3X安全帧→硬件熔断 / 三层电流上限
Layer 2  固件/实时     双相+死区(0,0) / 每相电荷上限 / 脉宽上限 / 软启动1-2s / 看门狗5ms / 非法态→Safe
Layer 1  电气硬件     隔离(B0505S+ISO7721) / 恒流源 / 隔直10µF / OVP钳位 / 比较器+锁存 / 强下拉
Layer 0  物理边界     激活阈值 < 安全窗 < 组织损伤阈值（每人每耳每帧不同）
```

**三条公理**（`tolerance-is-not-safety.md`、`signal-intensity-impedance-bilateral.md:105-125`）：

1. **耐受 ≠ 安全**：皮肤痛觉阈值 ≠ 深部迷走反射阈值。深部反射可突变。**安全绝不依赖用户痛觉反馈。**
2. **安全独立于决策模型**：硬件钳位 = 系统必需的积分常数 C，必须从外部焊进去，不经过算法。
3. **可逆 ≠ 无害**：一帧注入 = 一次化学引爆（皮质醇半衰期 60–90min）。参数精度就是安全。

**电流三层上限**（`frame-protocol.md:282-288`）：
```
协议可表 2.55mA（宽松） → 硬熔断 1.8mA（出厂，绝对 ≤2.0mA） → 治疗软上限 1.5mA
```

## 三、搭建前的焊装准备（Phase A，无人）

```
A1  ISO7721DR（SOIC-8）焊到 SOP→DIP 转接板
    · 340–360°C（不是 550）；必用助焊剂；锡少量；焊一个量一个
    · 参考 FORGET.md:227-236「焊 2.54mm 排针正确方法」
A2  万用表通断档量相邻孔 → 无连锡，才上电
A3  备小阻值：Rset≈47Ω / 677Ω；Rsense=1kΩ；确认金属膜电阻包够
A4  备 5.1V / 6.2V 稳压管（替 12V 1N4742A）
A5  ⚠️ 补购 LM393/LM339 + 基准 + SR 锁存（D2，BOM 现无）
```

## 四、Phase B —— 隔离 + 电流源（无人，假负载）

```
B1  搭 B0505S 隔离电源 → 上电
    ★ 判据：隔离侧 5V 正常；万用表量【主板 GND ↔ 贴人侧 GND】= 开路
B2  搭恒流源 A：手动 LM334
    · Rset = 电位器 + 串小电阻（或换 1kΩ 电位器）
B3  假负载 1kΩ + 100nF 接在 OUT1/OUT2 之间
B4  上电，示波器 + 串采样电阻测：
    ★ 判据1  波形：双相方波，频率 25Hz，脉宽 200µs/相，死区 10µs
    ★ 判据2  电流：I = V/R 对得上设定值
    ★ 判据3  幅值：≤1.5mA；硬上限 2.0mA
```

## 五、Phase C —— H 桥 + 安全层（无人）

```
C1  L293D 接隔离后的 IN1/IN2；ECP5 驱动
    · 烧录：stim_pulse/ 目录 `make flash`（SRAM）或 `make flash-f`（flash 自启）
C2  ✅ 已完成（2026-09-20）：EN1 从 VCC 引出为受控信号（默认低）
    · ecp5_stim_pulse.v 新增 output en；脉冲相 EN=1，死区/停 EN=0（双重关断）
    · 上电初值 en=0 → 上电即安全态
    · 引脚：en=E17、in1=D16、in2=D17（i5 P5 排针，已对官方引脚图核对）
    · 仿真 errs=0；综合 25MHz PASS（189MHz 余量）
    · 贴人侧接法：EN1 = EN(经隔离) AND 硬件安全比较器_safe
C3  搭硬件比较器 + 锁存 → 控 EN
    · LM393/LM339 + 基准 + SR 锁存；超限直接拉低恒流源/EN，不经 FPGA
    · DAC/EN 走线焊 4.7kΩ 强下拉（FPGA 三态化时无条件关断）
C4  验证三路硬切：
    ★ 判据1  开路：断负载 → Vout 到 5.1/6.2V 钳位轨 → 停止输出
    ★ 判据2  过流：超阈 → 比较器锁存 → EN 拉低
    ★ 判据3  看门狗：FPGA 停喂 → 5ms → 所有输出归零
    ★ 全部不经过 FPGA/软件
```

## 六、Phase D —— 人体（仅 A–C 全过）

```
D1  电池供电 + 拔掉【所有】下载器 / USB / 串口 / 示波器
D2  擦耳甲艇（酒精棉片）→ 测 Z（阻抗门）
    · Z > 30kΩ → 接触差/积垢 → 重擦重放
    · Z 不稳 → 没贴实 → 重放
D3  左侧优先；最低电流起；PPG 实时盯心率
D4  任何不适 → 立即停，记录
```

## 八、本计划明确不做（留到贴人前）

```
· compliance 升压（隔离 9–12V 或 DRV8833）——高阻场景必需
· 软启动 0→目标 1–2s 缓升
· 反射检测：PPG 心率骤降 → 立即切断
· 阻抗测量链 + 20µA 探针开路预判
· MCP4725 闭环电流控制
· i_actual / z_load 跨隔离（AMC1300 或 岛侧ADC+ISO1540）
```

> 这些**不影响 5V 通路验证**，但**贴人前必须补齐**。先跑通通路、再补安全、最后才谈贴人。
