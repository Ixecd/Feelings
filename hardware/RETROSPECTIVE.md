## 二、主要弯路（逐条：经过 / 代价 / 根因 / 本可如何）

### 弯路 ①（最大）：ISO7721 手工焊 —— 0/10
```
经过：买 SOIC-8 的 ISO7721，焊到转接板上。反复出现：
      · pin6↔pin7 连锡（两输出互打）→ 发热
      · 冷态开路、通电发热后才短（热损伤 / 助焊剂残留漏电）
      · pin1-4 连锡 → 输出其实是输入从短路漏过去
      · 最后一次性焊 10 片，没有一片 pin2/3/6/7 干净
代价：10 片芯片 + 大量时间 + 反复排查（脚位/隔离/VCC1电平/接触）
根因：SOIC 贴片 + 手工烙铁 + 面包板接触 = 成功率≈0
本可：一开始就买【预焊模块】（CA-IS3762 模块这种，排针已焊）
```

### 弯路 ②：LM334 整条线 —— 买了两批，全是假货
```
经过：先有 LM334MX(贴片, 需转接板)；又买 LM334Z(TO-92)×3。
      搭好恒流源：接法/接线/面包板全验过（通断全响），芯片就是不导通。
      先用"电阻分压自检"确认万用表没问题 → 断定芯片是坏件/假货。
代价：两批 LM334 + 好几轮排查（脚位、镜像、方向、电阻值）
根因：便宜芯片 = 假货/劣质 + 没"先单颗验证"
本可：买回先拿 1 颗单独测（分压自检法在手），确认再继续
结局：放弃 LM334，改用 LM358P 搭 VCCS —— 反而更可控、更灵活
```

### 弯路 ③：L293D → DRV8833 —— 验证完才发现拓扑不适配
```
经过：L293D 把双相 H 桥验证通了（静态 + 脉冲都行）。
      但把"恒流源喂 VCC2"接上后：L293D 达林顿【高边基极被饿死】
      → 高边压降 2.6V、不饱和 → 电流失控。
代价：L293D 及围绕它的接线、排查（跨地、静态全0、波形乱）
根因：没先确认"达林顿 H 桥能不能电流馈"（L293D 靠 VCC2 供基极电流）
本可：早一步想到"电流馈要用 MOSFET 桥"，先上 DRV8833
结局：换 DRV8833（MOSFET）→ 恒流源喂 VM 闭环成功
```

### 弯路 ④：囤"以后用" —— 一堆料还没上
```
MCP4725 / LM393DR / SN74HC00 / 耳塞电极 / 10KΩ电位器 /
STM32F407 / AD5933×2 / AD1256×2 / DS18B20 / LM358模块×5 …
代价：占资金、占桌面；有些还买错了（如 1N4742A 12V 在 5V 电路没用）
根因：设计没定就囤料
本可：just-in-time —— 用到哪一步，买哪一步的料
```

### 弯路 ⑤：其它小项
```
· PC817C：买了，因"反相 + 失效语义要额外处理"弃
· nRF52832：买了，发现无资料，弃（最终 MCU 选型未定）
· FT2232HL：550°C + 连锡，焊毁一个（焊接教训已记 FORGET）
```

## 三、根因（就三条）

```
1. 手工焊 SMD（最大的坑）
   —— SOIC 贴片 + 烙铁 + 面包板，成功率极低，反复烧时间+芯片

2. 便宜芯片 = 假货/劣质
   —— LM334Z 整批不导通；便宜"大牌"芯片踩雷概率高

3. 先买后想（囤料）
   —— 设计没定就买一堆"以后可能用"，多数没用上
```

## 四、纪律（以后照做，硬性）

```
【选型】
① 能用【直插(DIP) / 预焊模块(breakout)】→ 绝不用手工焊 SMD
   ★ 例：CA-IS3762 模块（排针已焊）取代 ISO7721 贴片
② 关键器件【先买 1 颗验证】，确认后再批量
③ 去【信誉好的店】买，避免假货（"大牌便宜货"尤其警惕）
④ 选器件先确认【拓扑适配】（例：电流馈要 MOSFET 桥，别用达林顿）

【采购】
⑤ 设计定型再买料（just-in-time），不囤"可能要用"
⑥ 买之前核【参数是否匹配当前电压/场景】（例：5V 电路别买 12V 稳压管）
⑦ 选型/采购前，先在 BOM 里登记"为什么买、用在哪一步"

【焊接】
⑧ SMD 焊接：300–320°C、每脚 ≤2 秒、助焊剂少用、焊完必清洗
⑨ 焊完必测：相邻脚 0L + 隔离 MΩ + "掰也不变"
⑩ 疑似失效件不装（疑罪从换）
⑪ 有条件用【热风枪 / 请人焊】，别硬钢手工烙铁

【验证】
⑫ 每一小步都量、都记录；先假负载，再联下一块
⑬ 万用表分压自检（10k+100Ω≈49mV）；小电压用 200mV 档
⑭ 电阻/通断【必须断电测】（带电测 = 假短路）
```

## 五、公道话：哪些是"学费"，哪些"本可避免"

```
【不可避免的探索成本】（不撞不知道）
 · LM334 是假货 —— 不买回来测，不知道
 · ISO7721 手工焊成功率≈0 —— 不试，不知道
 · L293D 不能电流馈 —— 不实测，不知道达林顿会被饿
 · 万用表"0L vs 0"、带电测电阻、示波器假象（177V）—— 都是"见过才懂"
→ 这类是硬件开发正常的学费，值。

【本可避免的】（下次别再犯）
 · 囤料：MCP4725/LM393/74HC00/STM32/AD5933… 还没用上
 · 先买 MX 又买 Z、先买 L293D 又买 DRV8833、反复买 ISO7721（10 片）
 · 没先查"拓扑适配"就动手
→ 这类是"纪律问题"，照第四节做就能省。
```

## 六、其实没白费：核心在推进

```
"感知 → 双相恒流刺激"的每一环，都【验证过】了：
  · 隔离电源(B0505S)      ✅ 5.2V，主GND↔隔离GND = 70-80MΩ
  · 恒流源(LM358P VCCS)   ✅ 0~2.44mA 可调、负载变电流不变
  · 双相 H 桥(DRV8833)    ✅ 40ms/200µs/死区10µs
  · 电流馈 VM             ✅ 闭环成立（pin2=pin3）
  · 保护(隔直+OVP)         ✅
  · 关断测试              ✅ 能手动关 + 控制断电关
唯一卡住的，是【隔离器的焊接】—— 一个"载体"问题，不是原理问题。
CA-IS3762 模块到货，这个坎大概率就过了。
```

> **弯路主要不在"原理"，在"焊 SMD + 买假货 + 囤料"。**
> 把这三条堵住（用模块、先验一颗、设计定型再买），后面的路会顺很多。

## 七、购物 / 选型 checklist（贴墙用）

```
买之前问自己：
  [ ] 这一步【现在】就要用吗？（不需要 → 先别买）
  [ ] 有没有【直插 / 预焊模块】版本？（有 → 优先它，别买贴片）
  [ ] 参数和当前【电压/电流/场景】匹配吗？
  [ ] 信誉好的店？能先买 1 颗验证吗？
  [ ] 它在 BOM 里对应【哪一步】？

焊之前问自己：
  [ ] 这颗能换成【预焊模块】吗？（能 → 换）
  [ ] 温度 300–320°C？每脚 ≤2 秒？有助焊剂？
  [ ] 焊完量了相邻脚 + 隔离 + 掰一掰吗？
  [ ] 烫过的可疑件，还继续用吗？（别用，换）
```
