## 当前阶段（2026-09-10）：监测与建基线

**核心认知：先监测、先建基线，再谈调节。**

调节哲学（过载者先降载、唤醒型 vs 调节型、能量=恢复资源）都需要**个体基线**做翻译层——不知道这个人自己的数字区间，就无法判断"过载/缺失/唤醒方向"。刺激与音频要排在基线之后。基线也是 Feelings 区别于"一个能打电流的闭环机器"的地方。

**目标：先把传感器数据流动起来，攒出个体基线（行 ③）。**

```
0.1  ✅ I2C 扫通：iCE40 软 I2C 读通 MAX30102 PART_ID + FIFO 原始 PPG，
        PC 端分析出 68 BPM（2026-09-10）。
        交付：可复用 i2c_master.v + max30102_ppg.v + iverilog 仿真 + PC 分析脚本。
        详见 max30102-ppg-bringup-2026-09-10.md
0.2  ⏳ 持续采集 → UART 上传 PC → 能看到波形/数字（PPG 已能持续读并出波形，
        待补：连续长时流（不丢帧）+ 其余传感器 MPU6050/DS18B20）
0.3  ⬜ 长时记录（数天起）→ 建立个体基线区间（HR/HRV/皮温/皮电/accel）
0.4  ⬜ 基线可视化：先当"镜子"（给用户看，也验证感知链路可信）
```

**交付物：PC 上能看到连续、可信的传感器数据流 + 一份个体基线。**
（这一步不做刺激、不做闭环——只把"能持续、可靠地测"做实）

## 二、双 FPGA 帧协议联调

**目标：iCE40 发传感器模拟帧 → ECP5 收帧校验 → 回传结果。**

**通信方案：当前 UART 460800 波特，远期切 SPI Master/Slave。**

100Hz 传感器帧（9 字节/帧 = 900 字节/秒）在 460800 波特率下余量充足。后续接入 I2S 音频帧或 24-bit ADC 连续波形时，带宽和异步波特率漂移会成为瓶颈——届时将 iCE40 作为 SPI Master，ECP5 作为 SPI Slave，硬件时钟同步，彻底消除波特率偏差。当前阶段 UART 足够，不提前引入复杂度。

```
2.1  加硬件握手线：ECP5 CDONE → iCE40 GPIO（ECP5_READY）
     iCE40 上电后静默，ECP5_READY 拉高后才启动帧发送
     防止 iCE40 先跑完配置而 ECP5 仍在加载→IO 高阻→UART 亚稳态误判
2.2  3 线连接：iCE40 TX → ECP5 RX，ECP5 TX → iCE40 RX，ECP5_READY → iCE40 GPIO，共地
2.3  9 字节帧格式落地：
     [0-5] 6 字节传感器数据（HRV/GSR/Temp/Accel X/Y/Z）
     [6]   帧序号 0-255 循环
     [7]   CRC-8-CCITT
     [8]   帧尾 0xA5
2.4  iCE40 写帧发送模块（定时 10ms 发包，模拟 100Hz 传感器帧率）
2.5  ECP5 写帧接收模块（打两拍同步、CRC 校验、错误计数）
2.6  ECP5 CRC 通过回 OK 帧，失败回 NAK 帧，iCE40 LED 汇报丢帧率
2.7  5ms 看门狗：ECP5 超时未收到有效帧 → 异步熔断 → LED 报警
```

**交付物：帧在双板之间稳定跑，CRC 校验通过，看门狗可触发。**


## 三、MCU I2C 扫通

**目标：桌面验证 AD5933 通信，确认阻抗测量可行。**

AD5933 输出端含 DC 偏置——直接贴在皮肤上会导致电极极化（烧灼感、阻抗漂移）。必须在 AD5933 输出端加隔直电容 + 运放 AFE，输出纯交流正弦激励（10kHz 50mVrms），杜绝 DC 注入人体。桌面验证阶段用电阻负载代替皮肤。

AD5933 默认 16.777MHz MCLK 下最低激励频率约 1kHz。10kHz 测的是角质层+深层组织高频复阻抗，和传统 DC 导纳法不在一个域。算法用阻抗模值 |Z| 变化率而非传统 DC 电导。如需低频激励（100Hz-1kHz），由 nRF52832 或 iCE40 分频出低频时钟喂 AD5933 MCLK。

```
3.1  ST-Link V2 连接 STM32F407，烧录固件，串口终端确认跑通
3.2  I2C 引脚扫描——AD5933 的 SCL/SDA 定位
3.3  写 STM32 I2C 驱动，读 AD5933 设备 ID → 确认通信正常
3.4  配置 AD5933 扫频参数，读复阻抗（实部+虚部）
3.5  1kΩ 电阻负载验证阻抗读数精度，对比万用表
3.6  隔直电容 + 运放 AFE 设计验证（桌面先搭，不进 PCB 前）
```

**交付物：桌面端可读到 AD5933 阻抗值，AFE 方案验证通过。**

## 五、传感器逐个接入 FPGA

**目标：每个传感器模块在 iCE40 上独立跑通，数据帧输出。**

ICS-43434 I2S 数字麦克风接入 iCE40 时，利用内置 8 个 DSP 块（16×16 MAC）做 I2S 接收与下采样滤波，不要用普通 LUT 拼乘法器。iCE40UP5K 的 5280 LUT 做音频 DSP 资源紧张，MAC 硬核是关键。

```
5.1  ✅ MAX30102 PPG — iCE40 软 I2C master 读 FIFO 原始值，UART 上传 PC，PC 分析 68 BPM
     ✅ 心率估计做进 FPGA — 板上实时 HR（带通+迟滞峰检测+IBI 平滑），实测稳定 ~67 BPM
        （2026-09-10，见 max30102-ppg-bringup / max30102-hr 文档）
     ⬜ 待办：示波器验证红外 LED 驱动波形/PD 输出波形；HRV；按帧协议打包

5.3  AD1256 — SPI 读 24-bit ADC 原始值
5.4  ICS-43434 I2S — iCE40 DSP MAC 做 I2S 接收 + 下采样
5.5  iCE40 串口定期 dump 传感器原始数据 → PC 终端/文件
```

**交付物：每个传感器在 FPGA 上独立跑通，数据可通过串口观察趋势。**


## 六、执行器逐个接入 ECP5

**目标：ECP5 可以驱动每个执行器输出可控信号。**

**tDCS 安全隔离——第一阶段就做，不准延期。** 只要 ECP5 连接着 ST-Link、CP2102 或示波器——任何与市电地连通的设备——禁止将 tDCS 电极贴在人体上测试。用 1kΩ + 100nF 的等效皮肤负载代替。人体测试必须满足以下全部条件：电池供电、断开所有下载器和 USB 线、tDCS 前端已加数字隔离器（ISO7721）+ 独立 DC-DC 隔离电源（B0505S）。

```
6.1  动圈入耳 — I2S 或 PWM DAC → 听频/音量可控 → 耳甲贴片测试
6.2  压电陶瓷 — PWM GPIO → 升压模块 → 触控频率/强度可控
6.3  tVNS 恒流源——自搭路线（LM334 恒流源核心 + 波形调制），双相对称方波输出防直流极化灼伤：
     6.3.1  数字隔离器 ISO7721（ECP5 GPIO → tDCS 使能端）
     6.3.2  隔离电源 DC-DC B0505S（tDCS 侧独立供电）
     6.3.3  GPIO 控制恒流源使能 + MCP4725(DAC)/电位器控制电流（0.1-1.5mA，LM334 1µA-10mA）
     6.3.4  输出端硬件 OVP：1N4742A 12V 稳压管钳位（电极脱落时 Vout→轨，重新接触瞬间放电打火）
     6.3.5  接触检查——微电流探针 + 软启动缓升：
            使能时先输出 20µA 极微弱探针电流 → 采样 Vout
            若 Vout 瞬间触及 12V 钳位轨 → 判定开路/未贴合 → 立刻熔断不输出
            若 Vout 在正常区间（20µA × ~2kΩ ≈ 40mV）→ 接触良好 → 启动 1-2 秒线性电流缓升
            0.1mA → 1.5mA，防止电流突变给皮肤骤刺感
     6.3.6  等效负载测试：万用表测电流精度，示波器看波形无过冲
     6.3.7  人体测试前置条件：电池供电 + 全部下载器断开 + 隔离已加 + OVP/接触检查就位
6.4  ECP5 写安全熔断逻辑：
     电流超限 → 硬件比较器直接拉 GPIO → 无 FPGA 参与
     帧超时 → 5ms 看门狗 → 所有输出归零
```

**交付物：每个执行器可控、可调强度、可拉闸。tDCS 人体测试前隔离方案已就位。**


## 七、ESIR 信号注入模拟

**目标：在双 FPGA 上模拟一次完整的"感知→计算→注入→反馈"回路。**

ECP5 BRAM 存储漏桶能量槽状态——电磁干扰可能导致 BRAM 被写入随机值，引发执行器误触发。状态机必须包含非法状态自恢复逻辑：任何未定义的 state 值跳转到 Safe State（所有执行器输出归零，等待下一帧有效命令）。

```
7.1  ECP5 实现漏桶模型（4 维能量槽：安全/归属/自主/胜任）
     BRAM 存储 + 非法状态 → Safe State 自恢复
7.2  iCE40 发模拟偏差帧（比如：皮电上升=紧张，HRV 下降=疲惫）
7.3  ECP5 收帧 → 更新漏桶 → 能量越过阈值 → 触发纠偏信号
7.4  ECP5 回传 iCE40：触发帧（执行器类型+强度+持续时间）
7.5  iCE40 LED 模拟执行器输出（不同颜色/闪烁模式代表不同执行器）
7.6  PBM 简化版：ECP5 BRAM 记录每次触发的时间戳+偏差值+纠偏结果
```

**交付物：闭环跑通，偏差 → 计算 → 纠偏 → 反馈 → 记录，全链路在 FPGA 上。**


## 八、真实传感器+执行器闭环

**目标：传感器数据真实地驱动执行器输出。**

```
8.1  PPG 心率 → iCE40 I2C 读 → 串口帧 → ECP5 漏桶更新
      HRV 低于基线 → 漏桶归属槽下降 → 触发动圈入耳暖音
8.2  EDA 皮电 → AD5933 读阻抗 → iCE40 帧 → ECP5

8.3  温度传感器 → 漏桶环境槽更新
     皮温过低 → 触发压电陶瓷低频振动（模拟拥抱 CT 纤维激活）
```

**交付物：一个人戴上耳夹 PPG，心率变化真的能触发动圈入耳播放声音。**


## 九、脱离 PC 独立运行

**目标：电池供电，无串口线，独立闭环。**

**电源路径管理——USB/电池不能硬并联。** 调试阶段需要同时插 USB-UART 抓日志和用电池供电。USB 5V 和锂电池正极不能直接并在一起——倒灌会损坏电池或拉烧电脑 USB 口。必须加防倒灌肖特基二极管或 P-MOS 自动切换电路，或者直接用带 Power-Path 管理的锂电充电芯片（BQ24075 / ETA6002）：插 USB 时自动切为 USB 供电并给电池充电，拔 USB 无缝切为电池供电。

```
9.1  柔性 Li-Po 电池 → 电源路径管理 IC（BQ24075/ETA6002）→ LDO 3.3V → 双 FPGA + 传感器
9.2  上电自启动：FPGA 从 SPI Flash 加载 bitstream（不需要 PC 烧录）
     iCE40 等 ECP5_READY 拉高后才发帧
9.3  独立运行 3 小时以上不掉电
9.4  数据记录到 ECP5 BRAM（环形缓冲区，存最近 N 帧）
9.5  BLE 透传：nRF52832 定期读 ECP5 状态 → 手机 App 显示
```

**交付物：设备断开所有线缆，电池供电，拿出房间独立运行。**

## 开发原则

**示波器先看波形，再写代码。**
任何传感器接入第一步不是写驱动，是示波器看电源纹波、I2C 边沿、信号幅度。波形不对，代码写再对也是错的。

**tDCS 安全红线——不准在线调试时贴人。**
只要 ECP5 连接着 ST-Link、CP2102 或 PC 示波器——任何与市电地连通的设备——禁止将 tDCS 电极贴在人体上测试。用 1kΩ + 100nF 等效负载代替。人体测试必须：电池供电 + 全部下载器断开 + 数字隔离器 + 隔离电源 + OVP 钳位 + 接触检查全部就位。

**恒流源必须防开路打火。**
电极松动脱落→恒流源拉满输出电压→重新接触→高电压瞬间放电。不是不舒服，是疼。输出端必须有 12V 稳压管硬钳位 + 接触检查逻辑（输出前 ADC 采 Vout，开路时禁止使能）。

**隔离高压。**
压电驱动 50V+ 和模拟前端必须分区域，单点接地，数字隔离器隔离 PWM 控制信号。高压信号跳一根线到低电平区烧一片。

**飞线不进面包板。**
I2C 400kHz 在面包板寄生电容和接触电阻下边沿全塌。杜邦线直连模块排针，或者自己焊排针转接板。

**安全熔断不依赖软件。**
ECP5 逻辑炸了执行器不能继续输出。硬件比较器 + 外部下拉电阻 + 看门狗三重保障。不是不信任 FPGA，是不信任任何单一故障点。BRAM 状态机必须含非法状态自恢复——任何未定义的 state 值跳 Safe State，所有执行器归零。

**每一阶段都有可触摸的交付物。**
不是"架构设计完成"，是"串口终端收到字符了"。"LED 闪了"。"心率波形在示波器上看到了"。"动圈入耳出声了"。

## PoC 调试手册——四个物理陷阱与推进顺序

Option 2B 单侧原型板打样之后，以下四个坑是第一批上电必须焊死的调试锚点。

### 陷阱一：隔离带寄生电容与汗液渗透

```
物理现实    Conformal Coating 能隔绝盐分，但柔性 PCB 在高湿/微汗下频繁弯折→涂层微观裂纹。

调试动作    打样第一块柔性 PCB 时，拿 LCR 表在 100kHz 下实测双路 VCCS 间寄生电容，
            确认严格 < 5pF。
            90% 湿度 + 盐水雾化环境 → 验证隔离电阻是否衰减到污染亚阈值刺激的程度。

不做的后果    用户出汗半小时后耳甲和耳背开始串扰——不是疼就是没效果——而你不知道原因是汗水。
```

### 陷阱二：10-15 秒密集点扫描的算法收敛

```
物理现实    瞬时 R-R 间期延长与 PPG 舒张斜率对呼吸窦性心律不齐（RSA）和轻微体动极敏感。

调试动作    单侧 PoC 上实测微电流扫描时，建立动态基线过滤算法。
            静态坐姿下阵列逐点扫描，3 个心跳周期内精准抓到 NTS 被激活的生理拐点。
            排除用户刚好呼气导致的 R-R 间期自然延长→误判为靶点。

不做的后果    密集点扫出来的"最优位置"其实是呼吸周期的随机波动——每次戴耳机校准结果都不一样。
```

### 陷阱三：咀嚼/说话的双频阻抗拆解决策边界

```
物理现实    1kHz 与 50kHz 阻抗相位差在咬肌剧烈运动与组织生理变化之间存在交叠带。

调试动作    采集用户讲话、吃硬物（苹果）、嚼口香糖、纯生理响应时的双频阻抗数据。
            绘制 2D 相位-幅值映射图，找出"物理脱空"与"组织阻抗微变"的最佳决策边界。

不做的后果    咬一口脆苹果→图上的点和副交感响应落在同一区域→误判→打折→用户觉得设备坏了。
```

### 陷阱四：ESB 私有协议的确定性时序

```
物理现实    Nordic ESB 避开了 BLE 连接间隔开销，但 2.4GHz 强干扰环境（满载 Wi-Fi 6 路由器旁）
            TDMA 时隙仍可能丢包。

调试动作    主设备 FPGA 时钟源广播主时钟，从设备 PLL 在 1% 丢包率下测时钟漂移。
            确保采集时钟同步误差始终 < 1ms。

不做的后果    隔壁房间路由器信道满了→腕部设备偶尔差 3ms→不是不能用→是偶尔感觉不对→你不知道为什么。
```

### 推进顺序

```
第一步: 硬件 PoC       Option 2B 单侧原型板打样
                      重点——柔性电极贴合 + 涂层隔离 + AD5933 双频采集

第二步: 算法验证       密集点扫描——10-15s 超短期自主神经响应闭环
                      抓取 ΔRR 与 PPG 舒张斜率，验证 Arnold 密集点定位收敛

第三步: 体验落盘       Performance Flow 赛前包软硬件联调
                      验证上场前 30min 注入后，60-90min 离线时域长尾的实际生理表现
```
