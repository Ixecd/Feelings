> 作者：qc

## 一、引子：抓娃娃机的启发

抓娃娃机创新思考——娃娃是死的，金鱼是活的。抓到的也不是你的——活的换积分，积分换稀有物种。

不是"拿到就走"。是"拿到才开始"。

Feelings 的产品设计和抓娃娃机的底层心理同构——但不是让你上瘾，是让你毕业。

## 二、三层递进模型

### Layer 1: 抓金鱼——即时感受

```
safety 信号注入 → 2min 后催产素峰值 → "现在安全了"
belonging 30-40 强度 → amygdala 恐惧抑制 → 社交信心上升

用户感知到的是: "戴上设备 → 感觉变好了"
设备看起来是: 信号源——依赖品
```

这是金鱼。你抓到了，但它不是你的——摘了设备就回到原点。

### Layer 2: 积积分——PBM 基线累积

```
每一帧生理数据 → PBM 基线缓慢位移
Session 10+: 冷启动窗口关闭 → 阻尼淡入 → 个人基线成形
三个月后: 同样的焦虑场景 → 身体自己知道怎么镇定
          HRV 基线上升 15% / 静息皮质醇降低 20%
```

这不是"这一次感到安全了"——是**这一次让下一次更容易安全**。

积分在累积，但用户意识不到。他只知道自己"最近好像没那么容易紧张了"——那是基线在悄悄滑动。

### Layer 3: 换鲨鱼——永久状态迁移

```
从"需要设备才能镇定" → "设备不在也能镇定"

路径:
  重复使用 → 基线位移 → 等控器重新锚定 → 自主神经基调永久改变
  → 不是忘掉了焦虑——是等控器不再把"陌生"默认判为威胁
  → 不是学会了镇定——是"镇定"变成了身体的本能反应
```

这不是兑换了一个更厉害的信号。是**你的身体变成了稀有鲨鱼**。

摘了设备，鲨鱼还在你身体里游。

## 三、反依赖的本质

大多数产品的商业模式是依赖闭环：

```
传统产品:
  使用 → 依赖 → 更多使用 → 更深依赖 → 无法离开
  "没有我你不行" = 最好的商业模式

Feelings:
  使用 → 基线累积 → 依赖减弱 → 使用减少 → 最终退出
  "你不再需要我" = 最好的产品设计
```

这不是营销话术——是硬编码在 `ColdStartGuard` 和 `DampingMatrix` 里的机制。冷启动守护保证新用户有足够的保护窗，但保护窗会随着 Session 计数关闭。阻尼矩阵让初始信号放大，但个人基线收敛后放大系数回退到 `×1.0`。

不是"越用越强"——是**越用越不需要用**。

---

## 四、为什么这是唯一正确的设计

信号注入是干预自主神经系统的。如果设计成"越用越依赖"：

```
永远需要设备才能镇定 → 自主神经被架空 → 等控器萎缩
→ 摘了设备比没用之前更脆弱
→ 这不是产品——是枷锁
```

"吸附式、5秒可摘"不只是形态选择——是伦理基线。摘下必须无痛，身体不能依赖于机器。

反依赖设计的底层假设：

```
人体本来就有一套完整的自主调节系统。
Feelings 不创造任何新通路——只激活已有的。
激活之后——人体自己接管。
不是"帮你镇定"——是"提醒你的身体: 你会镇定"。
```
