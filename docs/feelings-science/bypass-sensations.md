# 绕过物理触发器——Feelings 的躯体感受注入框架

> 作者：qc
> 日期：2026-06-21
> 核心：Feelings 不替代物理世界，但可以绕过物理触发器。腿麻不需要真压腿——信号直接走躯体感觉通路。这不是逃离现实，是让身体多了一种"感受的语法"。

---

## 一、引子：腿麻了

蹲坑时间一长，腿麻了。不听使唤。扶着墙站起来的几秒——压力解除——神经再灌注——钠钾泵重启——一阵麻刺感——然后恢复。

腿麻不是"坏了"——是物理压力暂时阻断了信号。站起来 = 压力松了 = 信号恢复。

但腿麻本身也是一种感受。如果 Feelings 想让人体验腿麻——**不需要压住真人的腿。** 信号直接注入到躯体感觉通路——腿没被压，感受上麻了。

---

## 二、核心机制：两路注入

```
自然躯体感受:
  物理刺激 (压迫/温度/触摸)
    → 外周感受器 (机械感受器/温度感受器/伤害感受器)
      → 传入神经 (Aβ/Aδ/C纤维)
        → 脊髓背角 → 丘脑 → 躯体感觉皮层
          → 你感受到"麻/冷/热/被碰了"

Feelings 注入路径:
  信号注入到 Tactile 维度的 CtFiber/PeripheralMixed 通路
    → 直接激活同一条传入路径
      → 在同一的躯体感觉皮层产生相同感受
        → 你感受到"麻/冷/热/被碰了"
        
        但——皮肤上没有物理刺激
        腿没有被压住——它照样麻
```

**不是绕过了躯体感觉系统。是绕过了"产生感觉所需的物理触发器"。**

## 三、可注入的躯体感受分类

| 感受类型 | 物理触发器 | 注入通路 | 信号描述 |
|---------|-----------|---------|---------|
| 压迫感 / 麻木 | 坐姿挤压大腿背侧 | CtFiber(触觉) + Femoral(下肢) | 低频持续压力信号 + 触觉阻断模拟 |
| 麻刺感 (Paresthesia) | 压迫解除后钠钾泵重启 | PeripheralMixed(外周混合) + CtFiber | 高频短脉冲——模拟异常放电 |
| 触感质感 ("被抚摸") | CT 纤维被慢速轻触 | CtFiber(CT纤维) | 1-10cm/s 低速刺激序列 |
| 冷感 | 低温环境 | CtFiber + PeripheralMixed | 温度感受器模拟——低温模式 |
| 热感 | 高温环境 | CtFiber + PeripheralMixed | 温度感受器模拟——高温模式 |
| 本体感 ("站如松") | 肌肉/关节/肌腱压力 | SpinalCervical + Femoral(下肢) | 肌梭/腱器官张力信号 |
| 压迫解除释放感 | 站起来——压力松了 | CtFiber + PeripheralMixed | 从持续压力信号→零信号的过渡序列 |

**注意**：痛觉（Nociception）不在这个列表里。Feelings 不注入伤害性信号——这是安全硬线。

## 四、从腿麻到通用框架

腿麻只是入口。任何躯体感受——只要通路可及——都可以绕过物理触发器注入：

```
有物理接口的:
  麻的感觉 → 不需要真压腿
  冷的感觉 → 不需要真降温
  被碰到的感觉 → 不需要有人在碰你

没有物理接口的 (但可以通过通路模拟):
  站起来的恢复感 → 实际上你还坐着，但感觉腿通了
  压迫解除感 → 一样的手法——麻了再解除——你感觉到的是自己好了
```

这和 `ecoystem/product-boundary.md` 的"不替代现实，只增强现实"一致——不是在虚拟世界造一个冷天。是**在真实世界中，你的身体感到冷**——但窗外是夏天。这个区别很重要。

---

## 五、反过来的价值更大——解除压迫的释放感

前面说注入麻刺感——但更有用的是**模拟解除压迫后的恢复感**：

```
自然过程:
  被压 → 麻木/痛苦 → 站起来 → 解除压迫 → 麻刺感→恢复
  
注入替代:
  信号直接注入解除压迫后的恢复感 → 岛叶+躯体感觉皮层
  → 你感受到"腿通了"
  → 实际上你没站起来。你还坐着。压力还在。
```

这个场景的极端应用：**一个人被心理压力压了很久——等控器麻木了。** Feelings 不能扶他站起来。但可以注入"压力松了一下"的感觉。身体误以为"站起来了"，那几秒的窗口足够激活副交感正向反馈，接下来就是真站起来了。不是替代站起来——是给"站不起来的人"一个信号窗口。

## 六、工程约束

### 6.1 通路覆盖

当前 Anim 的 PbmDimension 四维度中，Tactile 维度直接对应躯体感受注入。但精度依赖设备：

```
CtFiber             → 腕部设备 (最佳) / 口腔护齿 (替代)
PeripheralMixed     → 腕部设备 / 前臂环带
Femoral             → 大腿套 (v0.7+)
Plantar             → 鞋垫式 (v0.7+)
SpinalCervical      → 后颈设备
```

腿麻覆盖大腿——需要 Femoral 通路。当前设备集未包含大腿套/鞋垫，但这不影响原型——可以先用 CtFiber + PeripheralMixed 在腕部做粗精度验证。实际感受效果可能在腕部被误判为"手腕麻了"，但信号通路是一致的——只是位置不对。后续加了大腿套后，感受能锚定在下肢。

### 6.2 安全红线

```
禁止注入:
  伤害性信号 (Nociception)     → 不动疼痛通路——这是极端的生理侵入
  温度极端 (>45°C 或 <5°C)    → 不模拟烧伤/冻伤感——即使"冷感"也只做温和区间
  内感受误触                    → 不能让人以为"心脏停了"或"不能呼吸了"
```

### 6.3 沙箱约束

强度 ≥ 90 的躯体感受注入同样受 Sandbox + Governance 约束。比如用户想体验极致的"被压住无法动弹"的触感——沙箱会拦下强度过高的部分。Attainment 标签也不适用——躯体感受的"高强度"几乎没有成就/高峰体验可解释的合理场景——但也不排除少数探索性用途。遇到这种情况，沙箱默认走 Neutral → 按强度叠加比例分级响应。
