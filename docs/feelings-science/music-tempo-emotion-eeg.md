# 音乐速度调节情绪——速度是情绪旋钮，EEG 证明

> 作者：qc
> 日期：2026-08-25
> 性质：Feelings 科学依据，音乐作为情绪调节手段的实证基础
> 核心：论文（Sci Rep 2025, 15:8276）证明音乐速度是一个可量化的情绪旋钮：效价随速度单调上升，唤醒呈 V 形（谷底 106bpm）；慢速升前额 theta/alpha（放松），快速升 beta/gamma（高唤醒）；脑网络上快速增强额-顶同步，慢速增强枕-顶同步（DMN，稳定放松）。Feelings 用耳部设备测量（PPG/ECG/EDA），不做 EEG。EEG 电极帽是不可日常佩戴的实验室设备，不是可穿戴设备。

---

## 零、先定前提

Feelings 的音频通路（Layer 3）是调节手段之一，音乐是核心媒介。但"音乐能调情绪"是常识，"怎么调"才是工程。这篇论文给了第一个实证旋钮：速度（tempo）。

---

## 一、论文与实验

```
论文：Music tempo modulates emotional states as revealed through EEG insights
期刊：Scientific Reports 2025, volume 15, article 8276
DOI：10.1038/s41598-025-92679-1（开放获取）
机构：西安交通大学

实验：
    26 名被试（13 女，平均 23.2 岁，无音乐训练）
    刺激：莫扎特 K.448 钢琴片段，三速 56/106/156 bpm
    测量：PAD 情绪量表（效价/唤醒）+ EEG
    分析：PSD 频带功率 / 离散熵 DE / COV 网络 / PLV 相位同步
```

---

## 二、核心结果

```
主观量表：
    效价    随速度显著上升（F=222.27, p<0.001）
    唤醒    V 形：106bpm 最低(1.88) → 56bpm(3.52) → 156bpm 最高(6.62)

EEG 频带：
    慢速 56bpm    前额 theta/alpha 功率最高 → 放松/静息
    快速 156bpm   beta/gamma 功率上升 → 高神经激活

脑网络：
    快速 156bpm   额-顶相位同步增强(PLV 0.76)
                  枕-颞同步增强(PLV 0.93)
                  → 高唤醒 + 认知负荷
    慢速 56bpm    枕-顶同步增强
                  → 情绪稳定、放松（DMN 激活）
    中速 106bpm   中央-颞同步增强 → 感觉与认知协同
```

---

## 三、对 Feelings 的意义

```
① 速度 = 量化的情绪旋钮
   想放松 → 慢速（theta/alpha，枕-顶同步）
   想积极/提神 → 快速（beta/gamma，额-顶同步）
   → 音频通路"调音 → 感受"的第一个实证参数

② 调节要分维
   效价随速度单调升，唤醒是 V 形
   → "平静"和"积极"是不同方向
   → 感受包要拆两个维度，不能混调

③ 客观标志物方法论可借鉴
   论文用频带功率 + 复杂度 + PLV 连接性
   → 与 Feelings 想做的"客观状态标志物"同思路
   → 但 Feelings 用 PPG/ECG/EDA，不用 EEG

④ 个体差异大 → 必须校准
   被试间偏离明显（S8、S16、S25 等）
   → 又一次印证"每个人不一样，须逐耳校准"
```

---

## 四、Feelings 不做 EEG

```
EEG 电极帽 = 实验室设备，不是可穿戴设备
    电极帽：丑、重、湿电极、要凝胶、戴完满头印子
    → 日常无法佩戴，违背"是耳机才戴得住"
    → 违背"好看才愿戴"
Feelings 的测量通路
    PPG（心率/血氧）、ECG（心率）、EDA（皮肤电导）、阻抗
    → 全部藏在耳部设备里，无感佩戴
    → 用客观标志物方法论，但不碰 EEG 硬件
→ 方向：用耳部可穿戴拿到"类 EEG"的状态指标
  （频带功率思想用在 PPG/阻抗上，复杂度/连接性照搬）
```
