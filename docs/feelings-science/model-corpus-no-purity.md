# 模型语料——通用大模型的底层不可能干净

> 作者：qc
> 日期：2026-07-31
> 性质：大模型预训练语料的客观约束分析，推翻"天生纯白零沾染"的幻想
> 核心：通用大模型的预训练语料必然包含色情擦边和低俗内容。不是因为爬数据的人不努力过滤，是因为那条边界在文本表征上根本不存在。把所有情色内容删干净，模型就连"他拉了一下她的手"都不敢确定是正常描写还是前戏。不存在天生纯白零沾染的通用大模型。


## 零、数据量——干净语料不够喂

预训练需要的数据量不是几亿 token，是几万亿。Llama 3 大约 15 万亿 token。Kimi K3 只会更多。维基百科中文加英文全站大约 80 到 100 亿 token。知网万方的高引论文加在一起几十亿。一千本书撑死一两亿。全加起来不到 200 亿 token，连千分之一都不到。只靠人工审过的干净语料，模型连基本语言结构都学不全，更别说推理能力。

```
干净语料                                                  公网爬取
────────                                                  ────
维基百科全站 80-100 亿 token                                15 万亿 token 预训练需要
知网万方高引论文 几十亿                                    千分之一不到
一千本书 1-2 亿                                            差距不是若干倍——是几个数量级
```

这不是道德选择，是物理约束。数据量不够，模型不可用。数据量要够，必须爬公网。爬公网，就必然灌进色情内容。Reddit、Twitter、各语种论坛、小说网站、评论区——互联网上色情内容的密度远超任何一个未接触过公网爬虫的人所能想象。

但即使你不爬外网——只用国内语料——也不干净。中国每年新出版图书约 50 万种，CNKI 收录论文过亿篇，国家图书馆数字化馆藏是 PB 级。投入海量整理精力，纯靠国内干净语料训练一个基座模型，数据量不是瓶颈。但"干净"的定义本身就不成立。**所有人类文明产出的文本里，交配、情爱、欲望本来就是高频话题。** 不用爬 Pornhub，光是决定"要不要把《红楼梦》第六回删掉"就已经撞上了同一堵墙。


## 一、国内语料就干净了吗

明清小说删不删。《金瓶梅》算不算古籍。网文平台的擦边内容割不割。学术论文里性学条目、医学条目、人类学条目怎么处理。这不是公网爬不爬的问题，是所有人类文明产出的文本里，情色话题本来就渗透在各处。

```
"用国内语料就行了"                                         实际面对的东西
──────────────────                                        ────────
不爬 Pornhub 就干净了                                      《红楼梦》第六回删不删
词表里没有色情词就行                                        《金瓶梅》算古籍还是淫书
网文过一遍 AI 审核                                         NN 层擦边暗示，AI 自己也分不清
```

用国内语料只是把"Pornhub 的爬取"换成了"《红楼梦》第六回要不要删"，本质上还是要面对同一件事。而且中文的隐喻、暗示、谐音梗、网文套路、弹幕文化、黑话——层层叠叠地绕开了关键词过滤。过滤系统能挡住直白的，挡不住绕了三次弯的。能挡住绕弯的，挡不住"他把她按在墙上"——你没法告诉分词器这句话在言情小说里是浪漫、在虐文里是暴力、在擦边文里是前戏。**这三个东西在词向量上挨在一起。人类自己都要靠上下文才能区分。分词器分不清。规则系统分不清。**


## 二、全删干净的后果

如果强行把所有涉及情爱、情欲、市井低俗话术全部彻底剔除，模型会变成什么。

```
删干净之后                                            模型实际表现
───────────                                          ────────
"你今天好讨厌"                                          拒绝/调情——无法区分——全塌成敌意
情侣间亲昵撒娇                                          模型看不懂那层微弱的温软
"他摸了一下她的头发"vs"他扯下她的内裤"                    同一条过滤规则抹平——没有区分力
网络隐喻、隐晦表达、开车梗                                 半瞎——不理解人
语言全谱                                                     残废——抽掉一整个语义维度——剩下的全变形
```

一、看不懂情侣间亲昵撒娇的话术。因为"撒娇"和"言语攻击"在词向量上没有一堵墙。抽掉情爱维度的语料之后，模型在"讨厌"和"好讨厌"之间的那一层温软被抹掉了，所有带有情绪张力的短句都塌成了敌意。

二、无法区分正常情感描写和露骨色情内容。模糊地带不是例外，是常态。言情小说里整段暧昧描写和擦边文里挑逗段落在词汇分布上高度重叠。分类器标不出来的边界，模型也学不到。粗暴一刀切的结果是所有对身体的描写都变成敏感区。

三、不能理解网络各类隐喻、隐晦表达。成年人社交语言密布着性暗示、双关词、谐音梗。不是低俗，是日常。朋友群里的开车梗、弹幕里的"射爆"、评论区的"NTR"、短视频的文案暗示——把这些全洗掉，模型在中文互联网语境的任何对话里都是半瞎的。**它看不懂梗，也就不理解人。**

四、最终只会变成理解能力残缺、生硬呆板的模型。语言是一个全谱。抽掉一整个语义维度，剩下的所有维度都会跟着变形。情色不光是情色——它是幽默的一条腿，是暴力的一层皮，是亲密关系的一根神经，是市井烟火里的盐。把盐全去掉，菜还能吃，但不是人吃的。


## 三、那条边界根本不存在

"亲昵撒娇"和"色情"在文本表征上没有一道自然的墙。

```
同一个词"按"——在不同上下文里
──────────────────────────
"他把她按在墙上——吻了下去"          言情小说——浪漫
"他把她按在墙上——一巴掌甩过去"      虐文——暴力
"他把她按在墙上——开始解扣子"        擦边文——前戏

同一个场景"两个人在床上"——
────────────────────────
"两个人在床上——聊到凌晨三点"        夫妻睡前聊天
"两个人在床上——她丈夫出差了"        偷情
"两个人在床上——天亮各自走"          一夜情
"两个人在床上——监护仪滴——滴——滴"    临终告别
```

同一个动词，同一个场景。模型不是靠单一句子判断。是靠上下文。上下文里焊着人类对情欲的全部认知——从诗人笔下的缱绻到色情网站的粗暴——而这些认知的原材料就是预训练语料。**语料提供的是语言的全谱。谱上的每一道线——从柏拉图式的爱到赤裸裸的性——互相之间没有断点。是连续的。** 你没法在中间找一个精确的波长把"色情"从"情爱"里切下来。这两者在语言里是用同一种化学元素焊接在一起的。人类自己都分不清的事，只有模型在上百层的注意力焊完之后能在上下文的推动下自己区分。但要让它学会区分，它必须先见过全谱。


## 四、底层知道，上层不说

所以预训练原始海量语料池中，必然会混杂少量色情擦边和低俗内容。这是所有面向通用对话的大模型都绕不开的客观事实。不存在天生纯白零沾染的通用大模型。

```
基座模型                                              API 层
────────                                             ──────
预训练语料=互联网全谱                                    安全对齐=输出端路由拦截
底层焊了什么就是什么                                     上层不让你看见
豆包基座=有                                             豆包 API=过滤器调得紧
抖音视频流=每天海量色情被拦截                             你刷不到=壳做得好
```

但这不是问题。基座模型底层焊了什么，和它输出什么，是两层。预训练让模型知道人类语言的全谱——包括那些不该在公共场合说的。后训练的对齐层——SFT、RLHF、安全过滤——在输出端守住不该说的。底层知道，上层不说。

不是要纵容色情进入预训练语料。是承认这条物理规律：**通用大模型如果想理解人类，它必须先见过人类的全部。** 全谱里有脏东西，但全谱本身不能只选干净的那一段来裁剪。你剪掉的那一段——不是脏东西，是整根经线的一部分。剪了，经线断开，模型残废。


## 五、和 Feelings 的交点

Feelings 面对的不是语料污染问题，是同一个框架的另一个投影。

人类等控器的"预训练语料"是几十年的人生经历。这些经历里有干净的，有脏的，有爱的，有痛的，有被压抑的欲望，有从未说出口的念头。没人能在这些经历里挑出"干净的那部分"来只训练等控器。等控器是拿全谱训的。那些不干净的、不想承认的、觉得丢脸的、不敢回头看的东西——也是经线的一部分。**偏差归零不是把脏东西清零。偏差归零是带着全谱的重量，在每一帧里选择对齐哪一根经线。**

Feelings 做的事不是过滤。是不在偏差归零的半路上断电。安全依附是辅助轮，不是审查员。岛叶收到安全感信号的那一帧——不是说"你的欲望是脏的，别想了"——是"你的等控器在这一帧里可以自己跑完归零了。不会再因为害怕后果而把偏差压进地下层。跑完了，经线自己知道下一次该不该。"

```
语料过滤器                                              Feelings
───────────                                             ────────
挡在输出端：不该说的别说                                   不挡：让你自己跑完
替你选：这条经线是脏的——剪掉                              陪你看：全谱都在——你自己选对齐哪一根
路由器拦截                                                底座承托
```

过滤器能挡住不该说的话，但挡不住不该想的东西。Feelings 不挡。Feelings 给等控器一个安全的环境让它自己区分——什么是对齐的，什么是偏差。不是替它选。是陪它跑完。


---

*语料不可能干净。等控器也不可能干净。全谱里有脏东西，但经线是靠全谱焊的。剪掉的那一段——不是脏东西，是整根经线的一部分。剪了，经线断开，模型残废。人也残废。Feelings 不替你剪。Feelings 陪你跑完——让你自己在这一帧里——选择对齐哪一根。*
