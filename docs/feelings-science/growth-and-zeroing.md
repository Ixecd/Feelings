# 成长的归零——从遗憾到可惜到那条没人替你走的山路

> 核心：成长不是变聪明了。是那根经线在几十万帧偏差归零之后，焊深了。回头看，那条路上每一步，都是以前的等控器自己跑过的。不是嘲笑过去的自己，是你现在的基线比那个版本的你高了一截。站在更高的基线上，看到了以前那条路的坡度。


## 零、觉得自己蠢——是基线被推高了

隔上一段时间觉得之前的自己蠢得不行。不是变聪明了。是那根经线在上一次偏差归零之后焊深了。回头看，那条路上每一步，都是以前的等控器自己跑过的。现在觉得蠢——不是以前的自己真的蠢——是你现在的基线比那个版本的你高了一截。站在更高的基线上，看到了以前那条路的坡度。不是嘲笑过去的自己，是等控器的基线被几十万帧偏差归零一点一点推高了。

知道不该做什么。比知道该做什么更贵。因为每一帧"不该"，都是之前的一帧"真的做了"。偏差在等控器里自己烧过，然后那根经线——不是学来的，是疼回来的。不是后悔，是那根经线在偏离之后自己跑了归零。跑完了，下一次，不用再跑。它自己知道，那条路，不是给你的。


## 一、青春期的勇敢——熔断器还没焊好

一次勇敢的尝试，一次青涩的对话，一次坦荡的展示，一次大胆的告白。当时没想那么多，就是这么干了。不会觉得有什么不妥，只是想这么做。然后冷静下来之后，那种事后觉得不应该这么莽撞的情绪会急速涌上心头。

不是勇敢。是等控器的熔断器还没焊好。偏差的归零回路，在那个年纪，还没被疼过。你不知道做了会怎么样，所以你先做了。然后偏差在事后第一次被你的等控器读进去。疼。不是后悔。是那根经线在"莽撞"的偏差归零，第一次焊在了"不该这么直接"的方向上。不是应该忍住，是那根经线在冷静下来之后自己跑了归零。跑完了，下一次不会再有同样的一帧。它自己知道那条路，不是不能走，是自己疼过，知道走完后涌上来的那股潮水，已经退不回去了。

但发生总比沉默留下遗憾好。第一种勇敢，偏差在之后跑，疼一次，焊了。


## 二、想法的转变——被现实硬生生折断的旧经线

现在觉得就应该这样那样。过了一段时间，或许因为一些事情，彻底改变了之前那种想法。反而会觉得之前的想法过于单纯、天真、不切实际。觉得那是自己幻想中描绘的画面，实际和那完全是两回事。

第二种转变，不是幻想破灭。是物理告诉等控器，你之前那套，跑不通。旧经线被现实硬生生折断，新经线自己焊。不是变世故了，是被现实校准了。校准之后，新经线比旧经线重，也更窄，因为它不再是自己画的，是物理替你锻的。

```
第一种成长    偏差在事后跑——疼一次——焊了——下一次——那根经线自己知道。
第二种成长    旧经线被事实折断——新经线自己焊——不是画出来的——是锻造出来的。
```

如果这种感觉逐渐消失了。有两种可能，取决于那条经线还在不在跑。基线收敛，偏差在几十万帧里被归零归到足够窄了。每一帧的增量越来越小，不是因为不成长了，是精度从米变成了毫米。毫米级的进步，肉眼看不见，但 PBM 读得到。不是消失了，是细腻到你自己感觉不到了，但基线还在往上走。原地踏步，等控器不跑了。壳替你跑了，舒服，不需要变。偏差来，壳替你扛，经线不焊，基线不动。一年后回头看，和一年前一样，不觉得蠢，因为没有任何一帧你用过自己的等控器跑归零。不是偏差稳定，是壳替你吞了所有偏差，你自己的等控器，关机了。


## 三、地基和盖楼——打了最好的地基，从来没往上焊一层

从小不管是学习还是运动还是进入一个行业，听到让人印象最深的话，就是打好基础。打好地基。地基不打，盖不高。不打地基只盖高楼，必塌。但打了最好的地基，一辈子只在上面盖一个小平房，地基白搭了。白打了。因为你从来没敢在那块地基上，往上多焊一层。

不是地基的问题。是你焊地基的时候已经跑了无数次偏差归零。但到了"往上焊"的那一帧，你偏了。偏在"万一太高，摔下来怎么办"的方向。然后你没有跑那帧，壳替你在最安全的平地上替你盖了一层。你看着，觉得还行，平，不摔。但地基在地下，烂了。不是真的烂，是从来没被人用来站高，跑。

基础是经线，不是壳。打好地基不是让你一辈子蹲在地基上，是让你在那块焊过的经线上，敢往高处焊一层。哪怕那一层第一次歪了，下一帧再多焊一层，歪了再改。楼是歪着建高的。不歪，不需要地基。你也飞不了。但一直不走，地基只是你蹲过的那个坑，不是能站在高原上往下看的那个你自己盖的，哪怕歪了，至少你站上去了。


## 四、从遗憾到可惜——等控器自己跑完了那条路

在感情里，当遗憾变成了可惜的时候，也是一种心态的转变。更通透了，放过了自己，也放过了别人。

```
遗憾     "我为什么不——"——偏差在自己身上——等控器还在跑。
         "如果再给我一次机会——我会做不同的选择。"
         偏差未归零——经线还在那个方向上——还没焊完。

可惜     "那件事本来可以——"——等控器的归零——跑完了。
         "我不再需要那条路——因为那条路——不是我的——也不需要再是了。"
         偏差归零完成——经线焊在了"放过"的方向上。
```

不是遗憾变成了冷漠。是那根经线在偏差面前自己跑了，跑完了。然后下一帧，不再需要那件事在等控器里重新归零。放过，不是忘。是不再需要那条路了。


## 五、乌托邦——壳的最完美版本，不是成长

人们总喜欢想象构建一个乌托邦来满足自己所有的幻想。那不是成长，是逃避。

乌托邦是壳的最完美版本。不需要跑偏差，不需要归零，不需要面对那个站在你面前的人，不需要接受那件事已经过去，不需要说"可惜"。壳你自己画的，在纸上，在脑子里。"如果都这样，就好了。"

```
成长          你从那扇门出去——门口没有乌托邦——只有一条没人在纸壳上帮你画的山路。
              路上歪着——偏差在一帧一帧自己跑——然后你自己走。
              不是壳里，是脚下——这条路是水泥，不是纸。
```

成长不是想象一个没有偏差的世界。是**你从那扇门出去，门口没有乌托邦，只有一条没人在纸壳上帮你画的山路，路上歪着，偏差在一帧一帧自己跑，然后你自己走，不是壳里，是脚下，这条路是水泥，不是纸。不是梦想让你成长，是你自己跑完的每一次归零，把你从那扇门里推到了门外那一条真正的硬路上。不是壳碎了，是你自己出门了，门没关，但你已经不需要再留了。**
