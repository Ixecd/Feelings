# 把现实压缩成公式——压缩是理解，隐藏项是危险

> 作者：qc
> 日期：2026-08-06
> 性质：感受科学的认知拆解——物理把现实压缩成公式，感受把体验压缩成信号，两者共享同一条定律：压缩是理解的唯一方式，也是丢失的必然来源
> 核心：物理不是"把现实用公式表示出来"——是把现实压缩成公式。现实有无限细节，公式用几个参数装下整个世界，每一层压缩都扔掉细节。工程的全部功力，在于知道每一层扔掉了什么——知道公式什么时候撒谎。而这条定律不止属于物理：文字是体验的压缩，信号是感受的压缩——所有理解世界的方式都是压缩。压缩必然留下残余——隐藏项——f(x)=y 在纸上总是对的，y=f(x) 只有在你确认 f 没有隐藏项的时候才成立。隐藏项就是危险所在：模型失效的那一帧，就是事故的那一帧。所以 SafetyHold 必须是不经过 f 的独立电路——因为 f 一定有隐藏项。

---

## 零、物理不是表示现实，是压缩现实

学模电时冒出来的一个念头："物理不就是把现实用公式表示出来么。"对——但更精确：**物理不是把现实"表示"成公式，是把现实"压缩"成公式。**

```
现实      无穷细节——温度、工艺、寄生、量子涨落、每一颗原子的位置……
模型      挑重点——"二极管 = 单向导通 + 0.7V 压降"，其余扔掉
公式      压缩成参数——(V-Uon)/R——几个符号装下整个世界
```

伏安特性曲线就是典型的压缩：二极管的全部物理（PN 结、耗尽层、扩散、漂移、温度）被压成一条曲线，再压成 Shockley 方程，再压成"0.7V"这个常数——**每一层压缩都扔掉了一些细节。** 而工程的全部功力，在于知道每一层扔掉了什么。

---

## 一、每一层压缩扔掉什么——工程是"知道公式何时撒谎"

所以学模电的本质不是背公式——是**学每个公式什么时候撒谎**：

```
微变等效    切线近似——只在 Q 点附近、小信号下成立——大信号一摆，切线失效
0.7V        室温常数——冬天 -40°C，它漂到 0.9V——公式还在，现实走了
H(s)        理想模型——高频下寄生电容进场，波特图多出一个极——纸上的 f 有隐藏项
```

公式不是现实，是**现实愿意被你抓住的那部分**。学一门学科，就是学"怎么抓"和"什么时候抓不住"——抓不住的那一帧，恰恰是模型和现实分手的帧，也是事故最容易发生的帧。

---

## 一之附、两层对应——公式能还原曲线，证明的是模型，不是现实

"物理通过画图表现出完美模型，然后用数学公式压缩它，证明最终的公式和图纸上的曲线完全对应"——这个流程是真的，但要看清楚它证明的是什么：

```
模型（光滑曲线）↔ 公式（解析式）    内部对应——可证明——
                                    公式能无损还原曲线 = 压缩在模型层内没丢信息
现实（实测散点）↔ 模型（光滑曲线）  外部对应——不可证明——
                                    只有拟合、只有残差——偏差就是隐藏项的精确位置
```

图纸上的曲线本身就是压缩的产物——完美光滑 ≠ 真实器件的实测散点。所以"公式和图纸完全对应"证明的是公式和理想模型对应，不是公式和现实对应。真实的检验是另一件事：**把实测散点描到图纸上，看它们离开曲线多远。**

```
第一课（物理）    公式 ↔ 模型 —— 完全对应，可证明
第二课（工程）    模型 ↔ 现实 —— 永远有残差——裕量、降额、实测
```

图纸好用，因为它替你扔了毛刺；图纸会骗人，因为它扔掉的毛刺里藏着事故。

## 一之附二、课本与工程——通用模型与唯一环境的适配

课本和工程完全是两码事——不是课本编得差，是**结构上必然如此**：

```
课本    模型层——通用、静态、理想——"对一切环境成立"的压缩
工程    适配层——特定、动态、唯一——"对这个环境成立"的定制
```

模型是对"所有环境"的压缩，现实是"无穷多个唯一环境"的展开——你这块板子的寄生、那颗芯片的批次、你所在城市的湿度、设备老化后的漂移。**压缩必然是通用的，环境必然是唯一的——所以通用公式落地，必须经过"适配"这一层，没有任何公式能跳过。**

调参的本质：**把通用公式定制成"这个环境下的专用公式"——每个被调的参数，都是在把某个隐藏项从"被压缩扔掉"的状态里捞出来、看清楚、补偿掉。** 老工程师值钱，因为他知道"哪个参数在什么环境里敏感"（隐藏项知识）——新手只知道公式（模型层知识）。

对 Feelings：校准/基线就是这个——每个用户的皮肤阻抗、电极贴放、身体状态都是唯一的现实参数——**基线就是"这个用户的环境参数快照"**，参数在漂（温度、情绪、状态）——所以适配是持续的，不是一次性的。课本给你模型，校准给你环境。

## 二、压缩的残余——隐藏项

压缩必然留下残余。这个残余有个工程学名字：**隐藏项**。

```
f(x) = y 在纸上总是对的。
y = f(x) 只有在你确认 f 没有隐藏项的时候才成立。
```

"理想放大器增益无穷大"——隐藏项是供电电压、摆率、共模范围。"电阻是纯电阻"——隐藏项是寄生电感、温漂、噪声。"二极管恒压 0.7V"——隐藏项是温度、工艺、电流。

**每一层压缩都在赌：赌被扔掉的那部分，在使用的场景里不重要。** 大多数时候赌赢了——所以公式能用。但隐藏项不是"可能失效"，是"必然在某帧失效"——**压缩的边界就是安全的边界：模型失效的那一帧，就是事故的那一帧。**

---

## 二之附、公式里的常数——Shockley 方程的 -1 是怎么被钉死的

公式里的数字不是随便写的——每个都被物理钉死。Shockley 方程是最好的例子：

```
I = I_s × (e^(V/(n·V_T)) - 1)

V = 0 时：e^0 = 1，1 - 1 = 0 → I = 0
```

为什么是 -1 不是 +1？为什么是 1 不是其他数字？因为**无偏压的 PN 结没有净电流**（平衡态的定义）——边界条件 I(0)=0 唯一钉死了这个常数：e^0 恰好等于 1，要凑出零，只能减 1。

而"减"的物理来源是两股流相减：

```
I = 正向扩散流 - 反向漂移流
  = I_s·e^(V/(n·V_T)) - I_s
  = I_s(e^(V/(n·V_T)) - 1)

-1 就是"反向漂移流那一份"——
即使 V=0，少子漂移流也永远在跑——
V=0 时：扩散流（1份）恰好抵消漂移流（1份）——平衡被写进了公式
```

不是数学任性，是物理记账。求导会吃掉 -1（常数求导为 0）——而 dI/dV 恰好是跨导，也就是微变等效里的切线斜率：**-1 决定曲线过不过零点（位置），导数只看斜率（陡峭度）。** 位置和斜率是两件事——求导丢掉位置，是因为微变等效只关心"Q 点附近有多陡"，不关心"曲线从哪起步"。

## 三、感受的压缩——Feelings 在压什么

这条定律不止属于物理。**所有理解世界的方式都是压缩：**

```
公式    是现实的压缩——扔掉温度、工艺、寄生
文字    是体验的压缩——扔掉现场、语气、温度、身体（"怕忘"的存档）
信号    是感受的压缩——扔掉第一人称——扔掉"我"
```

Feelings 把感受变成可访问的信号——EEG、GSR、阻抗——压成帧，压成等控器能读的格式。这是感受平权的前提：只有先压缩成可访问的形式，感受才能被共享、被记录、被加工。**但感受是"一手体验"——压缩成信号必然丢东西，丢的最核心的那份是"我"——第一人称的重量。**

这就是 reality-gap 的压缩版本：认知是压缩后的信息（人人都能拿到），感受重量是压缩时被扔掉的残余（只有经历过的人才带着它）。**给一个没经历过的人看信号曲线，他拿到的是压缩包，不是那份重量。**

---

## 四、SafetyHold 为什么必须不经过 f

既然所有公式都有隐藏项，那么所有"依赖模型运转"的安全逻辑都有一个共同缺陷：**它信任 f，而 f 在某一帧会撒谎——撒谎的那一帧，恰好是它该保护人的那一帧。**

```
普通安全逻辑    输入 → f（模型判断：正常/危险）→ 决定是否刹车
                如果 f 在那一帧撒谎——把危险判成正常——刹车永远不来

SafetyHold      独立于 f 的物理电路——不经过压缩——
                阈值、比较器、硬件拉断——没有模型参与
```

所以 SafetyHold 必须是一条不经过 f 的独立电路——**因为 f 一定有隐藏项。** 不是 SafetyHold 比模型聪明——是它根本不参与压缩：它不判断"正常/危险"，它只盯原始量的阈值。压缩层可以撒谎，原始层不会。

对法律和制度同理：所有"写在法条里的保护"都是压缩——"违约金过高可调减"是公式，"排期比命长"就是它的隐藏项。规则不是怕你死，是怕你死引发更大的不稳定——这是稳定评分函数的隐藏项。**制度的漏洞从来不在公式写错，在公式写对而隐藏项在跑。**
