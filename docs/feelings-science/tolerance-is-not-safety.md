# 耐受不等于安全——tVNS 的副作用分层与安全层设计

> 作者：qc
> 日期：2026-09-14
> 性质：安全设计原则——从"耳朵不疼"到"深部反射"，一条被消费级设备忽略的红线
> 核心：**皮肤痛觉阈值 ≠ 内脏反射阈值。耳朵适应了（不疼），不代表深部迷走反射不会突然跳阈值。安全绝不能依赖用户的痛觉反馈，必须独立于用户感受地卡住。**

## 零、一句话

**"耐受"（耳朵适应了、不刺痛了）≠ "安全"（深部反射阈值也提高了）。** 这两套阈值是分开的。把"不疼"当"没事"，是消费级 tVNS 最危险的一个默认假设。

---

## 一、副作用分两层

### 浅层（预警级，"善意报警"）

```
· 耳廓皮肤痛 / 刺痛
· 轻微恶心
· 偶尔干咳（Arnold 反射）
· 一过性头晕
特征: 信号明确、来得快、低强度、一过性
     关掉刺激 → 几十秒到几分钟退掉
像: 吃到一点辣, 嗓子发紧 → 停下就没事
```

### 深层（反射级，"突变"）

```
· 咽喉-声门反射被误触 → 喉痉挛倾向
· 剧烈内脏-神经型锐痛（不是皮肉灼痛）
· 突发迷走抑制: 心率骤降、眼前发黑（晕厥倾向）
特征: 不频繁, 但一旦撞上 = 突变、爆发式
     瞬间声门收紧、呛咳、窒息感、神经痉挛
像: 一小块极辣的碎渣精准卡在会厌褶皱 ——
   不是大面积灼烧, 是【精准命中一个高敏感触发点】
```

**关键**：深层的"痛"不是皮肤痛。它是**内脏-神经型的锐痛 / 反射**，痛感等级远高于耳内刺痛。

---

## 二、机制：ABVN → 孤束核 → 中枢交叉反射（不是"直击会厌"）

**先纠正一个常见误读**：

```
迷走确实广泛支配咽喉/会厌/声门 —— 对
但那是【喉返神经 + 喉上神经内支】
耳电极刺激的是【耳廓的 ABVN】—— 另一条分支
→ 会厌的传入纤维【不在耳朵里】, 电极不可能"直接命中"它
```

**真实路径**：

```
耳部 ABVN → 孤束核(NTS) →（与喉/心反射【中枢交叉】）→ 喉/心反射
```

**这条修正决定设计方向**：

```
❌ 不能靠"把电极挪开、避开会厌"来防（会厌不在耳朵里）
✅ 要靠【限制总传入驱动】(电流/脉宽/电荷/时长) → 别把 NTS 推到反射阈值
```

> 证据级别（诚实标注）：
> **咳嗽 = Arnold 反射，有文献** ✅；
> **心率骤降/晕厥 = 有报道、机制合理** ✅；
> **喉痉挛 = 推测**（ABVN 与喉传入同汇于 NTS，交叉可能，但未见大量报道）。

---

## 三、★ 耐受 ≠ 安全（本文的核心）

```
自己调机器, 慢慢加高电流 → 耳朵表皮适应了, 不刺痛了
→ 你以为"安全了"
但: 深部迷走分支的反射阈值 和 皮肤痛觉阈值 【完全不同】
   皮肤不疼 ≠ 内脏反射不会突然跳阈值
```

**它不一定是渐进式难受，可以是突变**：

```
安安稳稳刺激半小时, 前 28 分钟都没事
→ 最后两分钟某个微小的电极移位
→ 脉冲刚好对齐一组高敏感传入纤维
→ 瞬间触发强烈反射
```

**所以**：

> **安全绝不能依赖用户的痛觉反馈。** 必须独立于用户感受地卡住。

---

## 四、工程含义：安全层清单（不止"恒流 + 最大电流"）

```
① 硬限流         独立比较器, 不经 MCU（MCU 挂了也要断）
② 每脉冲电荷上限  幅度 × 脉宽 —— 不是只卡 mA
③ 脉宽上限       别越档放大
④ 软启动/缓升    0→目标 1-2s, 禁突变（防惊跳/反射）
⑤ ★ 反射检测     PPG 心率骤降 → 立即切断
⑥ ★ 物理急停     用户永远能一下切断
⑦ 开路/短路检测
⑧ 左侧优先       减心率影响
⑨ 阻抗监测       电极移位 → 电流路径变 → 预警
⑩ 累计剂量上限   单次时长 / 总电荷
```

**玩具款 vs 靠谱设备的分水岭**：

```
玩具款: 只卡"最大毫安" → 保证耳朵不起泡
       但拦不住"一次精准命中反射的尖锐刺激"
靠谱设备: 假设【用户的痛觉反馈会失效】
       用【独立硬件】卡住 电荷/脉宽/时长 + 反射检测 + 急停
```

**顺带修正一个常见说法**：决定"招不招深部纤维"的是**每相电荷（幅度 × 脉宽）**（时值/chronaxie），**不是"边沿陡不陡"**。软启动防的是"突变"，不是"前沿斜率"。

---

## 五、对 Feelings 的意义

```
1. 安全层必须先于"效果"建好
   深部反射是【低概率 · 高后果】→ 不能等出事再补
   → 这正是"先薄后加、先验证"的另一个理由:
     先薄的是【功能】, 不是【安全】

2. 安全独立于"用户的感受"
   用户说"不疼" ≠ 安全 → 设备不能只信用户的反馈
   → 独立硬件 + 反射检测(生理信号) + 急停

3. 安全也要"个体化"
   深部反射阈值因人而异 → 与"找你的点/剂量"是同一件事
   通用硬件 + 个体安全上限

4. 这正是 Feelings 与"玩具款"的区别
   不卖"希望", 卖"可信" —— 安全层是"可信"的一部分
```

---

*"不疼"是皮肤在说话；"安全"要靠设备自己算。两者永远不能划等号。*
