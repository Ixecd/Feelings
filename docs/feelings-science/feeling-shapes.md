# 感受的形状

> 作者：qc
> 日期：2026-04-06
> 核心：成分相同，形状不同，体验完全不同

---

## 一、为什么需要「形状」这个维度

之前的感受包描述重点放在混音结构——主旋律加点缀，多个感受的配比。这是感受的**成分**。

但成分相同，形状不同，体验完全不同。

就像同样的食材，做成汤和做成固体，入口的感受是两回事。

```
混音结构    感受是什么（成分）
感受形状    感受怎么展开（时间轴上的运动方式）
```

形状描述的是：感受怎么来，怎么走，在哪里停，停了之后是什么。

两者加在一起，才是一个感受包的完整描述。

## 二、七种基本形状

### 1. 渐强渐弱型

```
强度
▲
│        ╭────╮
│      ╭╯      ╰╮
│    ╭╯          ╰╮
│╭╯                ╰╮
└──────────────────────→ 时间
```

平滑的弧线，舒适，可预期。感受从低到高，到达峰值，然后慢慢消退。大脑对这个形状最熟悉，防御最低。适合探索类感受包，新用户入门选择。

**体验质地**：像一次完整的呼吸，吸进去，呼出来，结束后有平静的余韵。

---

### 2. 突停型

```
强度
▲
│              │
│           ╭──╯
│        ╭──╯
│     ╭──╯
│  ╭──╯
│──╯
└──────────────────────→ 时间
```

垂直积累，然后断。不是渐渐消退，是戛然而止。

断裂之后的那一刻，是整个体验里密度最高的地方。大脑的预期在那一刻落空，神经系统措手不及——那个措手不及比任何平滑的高潮都更真实。

**子类详见第三节。**

---

### 3. 波浪型

```
强度
▲
│    ╭╮        ╭╮      ╭╮
│  ╭╯  ╰╮    ╭╯  ╰╮   ╭╯╰
│╭╯      ╰╮  ╯      ╰╮ ╯
│          ╰╯        ╰╯
└──────────────────────→ 时间
```

起伏交替，每次回落都是下次积累的起点。感受不是线性的，是循环深入的。每一次波峰比上一次稍高，每一次回落让神经系统在下次积累前有短暂的缓冲。

**体验质地**：像游泳时的节奏，一下一下，每一下都在加深。最适合需要反复接触才能真正落地的复杂感受。

---

### 4. 延迟爆发型

```
强度
▲
│                    │╲
│                 ╭──╯  ╲
│                 │       ╲
│─────────────────╯        ╲
└──────────────────────────→ 时间
```

长时间低强度铺垫，然后突然释放。等待本身就是体验的一部分。低强度阶段看似平静，实际是张力在悄悄积累。爆发的力量来自铺垫的时间长度，等得越久，释放越猛。

**体验质地**：像憋住的一口气，憋了很久，然后一下呼出来。

---

### 5. 平台型

```
强度
▲
│      ╭──────────────╮
│    ╭╯                ╰╮
│  ╭╯                    ╰╮
│╭╯                        ╰╮
└──────────────────────────→ 时间
```

快速到达某个强度，长时间维持，然后缓退。不追求峰值，追求持续。让用户在某个感受状态里真正「待着」，不是快速经过。

**体验质地**：像泡在一个温度恰好的水里，不是刺激，是沉浸。适合冥想类、平静类、专注类感受包。

---

### 6. 双峰型

```
强度
▲
│        ╭╮          ╭╮
│      ╭╯  ╰╮      ╭╯  ╰╮
│    ╭╯      ╰╮  ╭╯      ╰
│  ╭╯          ╰╮╯
│╭╯              ╰╯
└──────────────────────────→ 时间
```

两次高峰，中间有一次回落，第二峰往往比第一峰更深。第一峰让用户以为体验要结束了，然后回落，然后发现还有第二峰。第二峰因为有了第一峰的对比，感受密度更高。

**体验质地**：像以为看完了电影，结果还有彩蛋，而且彩蛋比正片还重。意外感是这个形状的核心。

---

### 7. 余震型

```
强度
▲
│  │
│  │╲
│  │  ╲    │
│  │    ╲  │╲
│  │      ╲│  ╲    │╲
│  │        ╰──╯╲  │  ╲  │
└──────────────────╰──╰──→ 时间
```

主体结束后，断断续续的余波。主峰之后看似结束了，但感受还在，以更小的形式反复出现。每一次余震都在提醒：刚才发生的东西还在这里，还没有被处理完。

**体验质地**：像地震后的余震，像大哭后的抽泣，像分离后在某个瞬间突然又想起来。最接近真实人类情感的形状。

---

## 三、突停型的子类

突停是七种基本形状里内部分化最复杂的一个。断裂之前的积累方式不同，断裂的性质不同，断裂后的感受完全不同。

### 荒诞解构型

```
积累    严肃的、有方向的行动张力
        「要去做一件很重要的事」的那种驱动感
断裂    幽默介入，目标被解构
        「既然来都来了，先吃顿好的」——严肃被轻轻击穿
断后    不是空，是一种轻盈的「哦，原来可以这样」
```

底层机制：能量找到了意外的出口，严肃和幽默的落差制造了释放。

代表感受：人在极度认真地要做某件大事，然后被一句话从那个严肃里拉出来，发现其实没那么严重，然后笑了。

### 情感切断型

```
积累    情感连接的持续深化
        甜蜜、亲密、安全感逐渐建立
断裂    连接被切断，关系终结
        不是幽默，是真实的失去
断后    不是轻盈，是「刚才还在，现在没了」的空洞
```

底层机制：满足感被剥夺，神经系统被迫接受从「有」到「无」的落差。

代表感受：一段关系，甜蜜到某个时刻，然后结束。那个空洞的形状，是它存在过的证明。

### 成就截断型

```
积累    全力冲刺，所有精力都在这个目标上
断裂    突然完成了，目标消失，驱动力瞬间失去着力点
断后    不知所措的虚空——「现在怎么办」的茫然
```

底层机制：目标完成后驱动系统失去对象，意义真空短暂出现。

代表感受：备考半年，考完的那一刻。冲刺完成，然后发现不知道下一步是什么。

### 悬念悬置型

```
积累    张力积累到顶，答案就在那里，大脑已经准备好接收
断裂    不给答案，停在那里，体验结束了但悬念还在
断后    持续的「还没结束」感，像一个未完成的句子
```

底层机制：大脑的闭合欲望没有被满足，持续消耗注意力资源。

代表感受：故事讲到一半，「未完待续」。那个等待本身就是体验的延续。

### 外力中断型

```
积累    体验正在进行，状态极好，完全投入，不想停
断裂    外部力量打断，不是自然结束，是被切断
断后    愤怒或遗憾——「为什么现在停」的不甘心
```

底层机制：自主感被剥夺，体验的完整性被破坏。

代表感受：最好的状态被打断。游到最顺的时候被叫回去。

## 四、形状与安全边界

不同形状的安全风险不同：

```
渐强渐弱型    最安全，可预期
突停型        风险最高，断裂如果来得太猛可能造成神经系统击穿
              需要根据个人基准严格控制断裂的时机和方式
波浪型        风险中等，回落阶段是缓冲
延迟爆发型    铺垫阶段容易让用户失去戒心，爆发时措手不及
平台型        最安全之一，持续性让用户充分适应
双峰型        第二峰的意外感需要精确控制
余震型        余波的不可预期性需要监控，防止余震强度超过主峰
```

**突停型的特别注意**

突停型在高强度区间（60分以上）需要额外的安全判断：

```
断裂的时机    必须由系统基于个人基准决定，不能由用户手动触发
断裂的速度    不是瞬间归零，是极速但有控制的下降
断裂后的着陆  系统自动提供轻度的「落地感受」
              不让神经系统悬在断裂后的空白里太久
```

## 五、形状与音乐的对应

AI生成音乐实时跟随感受曲线（见 `docs/music-system.md`），形状和音乐天然对应：

```
渐强渐弱型    音乐跟着渐强渐弱，最自然
突停型        高潮时音乐全部停止，那个沉默比任何声音都响
              音乐里叫「突停」，是最有张力的技巧之一
波浪型        音乐反复积累和消退，每次循环略有变化
延迟爆发型    长时间极简低能量，然后突然全力爆发
平台型        音乐维持在一个密度，微小变化但不离开那个区域
双峰型        两次音乐高潮，第二次更强，中间真实回落
余震型        主题结束后，碎片化音乐片段断断续续出现
```

## 六、感受包的完整描述

感受包的完整描述现在需要三个维度：

```
混音结构    这个感受是什么（主旋律 + 点缀配比）
感受形状    这个感受怎么展开（七种基本形状 + 子类）
强度标称    这个感受有多强（1-100档）
```

同样是「久别重逢的快乐，强度50」：

```
版本A    渐强渐弱型    舒适的，完整的，有始有终
版本B    双峰型        以为快结束了，然后发现还有更深的
版本C    余震型        主体结束后，还会在某些瞬间回来
```

三个版本成分相同，形状不同，是完全不同的三种体验。

---

*感受的形状是感受在时间里的生命。同样的成分，不同的形状，是不同的生命。*
