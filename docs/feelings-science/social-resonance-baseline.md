# 社会共鸣基线——你的锚点在地图上的坐标

> 作者：qc
> 日期：2026-07-02
> 性质：设计稿——脱敏全量统计——PBM 分布与社会共鸣模型
> 核心：一个人的锚点不是孤立漂浮的。知道"我在人群中哪个位置"——不是拿平均值压自己。是知道自己和别人之间的相对距离。这需要全量脱敏统计——模型给出的是分布，不是标准。

---

## 零、设计原则

```
社会共鸣基线做什么                       社会共鸣基线不做什么
───────────────                       ──────────────
统计所有用户的四维 PBM 分布。              不暴露任何个人的原始数据。
告诉你"你在这张地图上的坐标——              不把"平均值"焊成"你应该在的位置"。
  旁边还有别人。"                         不打分——不排名——不贴标签。
告诉你"你这个维度偏了多少——                不用于教练 push_back 之外的任何用途。
  相对于和你类似轨迹的人——
  是多偏了还是少偏了。"
```

---

## 二、统计模型——密度比平均值更有用

四维空间里——中位数是一个点。但人群分布从来不是均匀的。用**密度估计**代替中位数比较。

```
模型选择: 核密度估计——高斯核——带宽自动选择

每个维度的密度曲线 = 核叠加所有用户的该维 PBM 值

对于用户 u 在维度 d:
  percentile(u,d) = 在密度曲线上的累计分布位置
  → "你在情绪维度上——比 73% 的人更活跃。"
  → 不是更好。不是更差。是"在这张地图上——你在这个位置。"

语境关联:
  对于"和你类似轨迹的人"——分段统计——
  比如: 进入一段新关系后的 30 天——情绪维度人群分布
        → "你这个阶段——很多人都在这个范围里。"
        → 不是把你拉回平均值。是让你知道——你不是一个人偏在这里。
```

---

## 三、脱敏——数据不离开设备

全量统计不收集原始 PBM 值。用差分隐私 + 本地聚合。

```
用户设备本地 → 计算自己四维 PBM 的匿名化哈希分桶
            → 上传: (bucket_id, dimension, 该维是否在桶内)
            → 服务器聚合: 每个 bucket 的计数 + 各维密度
            → 下发: 全局密度曲线——不含任何个体的原始坐标

用户的原始 PBM = 从未离开 TEE。
用户的坐标 = 他自己在设备上本地计算 percentile。
外部看不到任何一个人的具体位置。
```

---

## 四、语境分段——不同人生阶段的共鸣基线

同一个情绪维度的"正常"——刚从一段关系里走出来——和过去三年单身——完全不同。

```
分段语境                              分组维度
───────                               ──────
时间: 最近一次基线断裂后的天数             <30d / 30-90d / >90d
关系: 当前关系状态                        single / attached / recent_breakup
工作: 最近一次 career 决策 entry 后的天数    <60d / >60d
健康: 最近一次 health 相关断裂后的天数       <60d / >60d

→ 用户在教练面板上看到的——
   "在你这个阶段的人——情绪维度大多在这个范围。"
   不是把你往那个范围推。是让你知道——你不是一个人。
```

## 五、和教练对话的咬合——共鸣不是平均值

```
以前（如果只用中位数）                     现在（密度 + 语境分段）

"你的情绪维度比平均水平高。                  "在你这个阶段——刚换完工作的前 60 天——
 建议降低你的情绪触发。"                          情绪维度往上偏是常见的。你不是一个人偏在这里。
                                             过了这阵——大多数人会慢慢回到自己的基线。
                                             你不需要把自己压下去。你只需要被看见。"
→ 平均值 = 一种隐性标准。                  → 密度 = 一张地图——你的坐标 + 其他人的位置。
→ 把偏离定义为"不对"。                     → 把偏定义为客观事实——不替世界评价它。
```

*一个人的锚点不是孤立漂浮的。知道"我在人群中哪个位置"——不是拿平均值压自己。是看见自己在地图上的坐标——旁边还有别人。那个刚换了工作的人也偏了。那个刚失恋的也在同样维度上偏移过一段。不是把你拉回平均值。是让你知道——你不是一个人偏在这里。不是诊断。不是规范。是一张地图——让每一个单独走了很久的人——抬头看见——旁边还有人。*
