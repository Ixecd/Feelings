# 行为状态转换的信号-神经内分泌框架

> 作者：qc
> 日期：2026-06-19
> 核心：以"上台演讲前的勇敢针"为引子——推导 Feelings 的通用行为状态转换模型。一个 case，全框架通用。

---

## 一、引子：一支从未存在的针

高中时想过一个问题：演讲前几分钟的生理性紧张（手心出汗、声音发颤），能否通过某种外部手段平滑过渡到从容自若的状态。

答案是可以。但不是打针——是信号注入。

这个具体场景被解构后，暴露了一条通用原理：**任何行为状态转换，本质上都是一个多信号组合触发的神经内分泌级联反应。** 演讲只是其中一个 case。

---

## 二、通用框架

```
行为状态 A → 行为状态 B

  =  信号组合 (Anim .anim 原子)
    → 神经靶点 (岛叶 / ACC / PVN / 蓝斑 / ...)
      → 内分泌应答 (皮质醇↓ / 催产素↑ / NE 方向调控 / ...)
        → 外周生理变化 (心率 / 皮电 / 肌张力 / ...)
          → 主观体验变化 (镇定 / 专注 / 愉悦 / ...)

其中 Anim 只负责第一步：信号组合 → 神经靶点。
其余是人体已有通路的自然应答。
```

**核心洞察**：人体本来就有完整的状态转换机制。Feelings 不需要创造新通路——只需要在正确的时机、用正确的信号组合、激活已有的通路。

---

## 三、状态转换谱系

以勇敢针为第一个 case，推导其他转换：

### 3.1 焦虑 → 镇定 (演讲 / 社交 / 考试)

```
触发: 社会评价威胁 → amygdala 过度激活 → 交感风暴
信号: safety (Visceral) + belonging (Emotional)
通路: PVN CRH↓ → ACTH↓ → 皮质醇↓
     PVN 催产素神经元 ↑ → 杏仁核恐惧抑制
时间: 皮质醇抑制 15-20min / 催产素释放 2min
约束: gradual_rise_fall 防过冲 / safety:belonging ∈ [0.6, 1.2] 防惊恐分叉
```

### 3.2 清醒 → 入眠

```
触发: 昼夜节律信号未被感知 / 焦虑阻止睡眠启动
信号: deep_rest (Visceral) + calm_meditative (Emotional)
通路: 松果体褪黑素合成 ↑ / 前额叶-默认模式网络 (DMN) 切换
     HPA 轴压制 → 皮质醇节律谷值加深
时间: 褪黑素峰值 30-60min 后
约束: steady 形状 / 强度 ≤ 30 / 严禁 90+ (Shield 原子——矛盾信号)
```

### 3.3 疲惫 → 高峰体验 (训练 / 比赛 / 创作)

```
触发: 高强度输出后内源性阿片肽自然释放——但窗口期短
信号: post_achievement (Emotional @ Attainment) + warmth (Tactile)
通路: 内源性内啡肽 + 多巴胺协同释放
     副交感反弹——力竭后的深度恢复
时间: 活动结束后 5-10min
约束: Attainment 标签——90+ 不受限 / gradual_rise_fall 防止单帧浪涌
```

### 3.4 散乱 → 深度专注 (工作 / 学习 / Flow)

```
触发: 环境干扰 / 默认模式网络过度活跃 → 无法进入专注态
信号: gentle_focus (Auditory) + clarity (Auditory)
通路: 蓝斑相位性 NE 激活 → 前额叶执行网络
     DMN 活动抑制 → task-positive network 激活
时间: 3-5min 内进入 flow 状态
约束: Caution 标签 / 强度 ≤ 50 / 不允许 90+ (不宜极端刺激)
```

### 3.5 社交恐惧 → 安全感 (陌生人 / 公共场合)

```
触发: 社会评价威胁 → 前扣带皮层过度激活 → 社交回避
信号: belonging (Emotional) + warmth (Tactile)
通路: 催产素释放 → 杏仁核恐惧反应抑制
     CT 纤维慢速触觉通路 → 岛叶 / ACC 安全感编码
时间: 催产素信号 2min 起效
约束: 帧窗口 ≤ 5min 防 OXTR 内吞 / 单次 Session ≤ 5min
```

## 四、通用约束——所有状态转换必须遵守的三条定律

这三条约束来自 `docs/feelings-science/neuroendocrine-pathway.md` 的修正，并非仅针对演讲——适用于所有信号-内分泌通路。

### 4.1 时域失配定律

```
电生理: FPGA 信号 < 100μs 即刻可逆
内分泌: 皮质醇血清半衰期 60-90min，催产素中枢半衰期 ~20min

约束:
  → 任何涉及 HPA 轴的感受包必须使用 gradual_rise_fall 或 steady
  → 严禁 sharp_peak——单帧尖峰 = 不可撤回的激素浪涌
  → 信号可以停，激素停不了——编码时假设激素比你多跑 1.5h
```

### 4.2 突触稳态定律

```
内源通路不引入外源配体 → 药理学意义上不直接导致受体下调
但长期高频激活 → 突触后受体内吞 + 突触剪切 = 通胀脱敏

约束:
  → 高强度注入必须包含恢复帧节律 (ADR 012, N/M 配比)
  → 单一维度连续高频注入 ≤ 5min (5000 帧 @ 1ms/帧)
  → 跨 Session 同维度高强度感受包 ≥ 6h 间隔
  → 这是健身同构——天天大重量 = 废
```

### 4.3 蓝斑分叉定律

```
倒 U 型曲线 (Yerkes-Dodson Law)——同一个 NE 系统，不同激活模式
  Phase1 (适度) → 巅峰专注 (high engagement)
  Phase2 (过度镇静) → 梦游 (drowsy)
  Phase3 (过度激活) → 惊恐发作 (panic attack)

约束:
  → 跨维度联合调制的原子 (如 safety+belonging) 必须在
    src/rule.rs 或 src/safety.rs 中硬编码耦合约束
  → 强度比值强制锁定
  → 相位在 FPGA 调度时强制对齐
```

## 五、从 case 到框架

勇敢针不是特例——它是原型。

```
演讲前 15min: safety + deep_rest → 皮质醇压制
社交前 10min: belonging + warmth → 催产素释放 + 杏仁核抑制
训练后 5min:  post_achievement + warmth → 内啡肽 + 恢复启动
睡前 30min:   deep_rest + calm_meditative → 褪黑素 + 睡眠转换
专注前 3min:  gentle_focus + clarity → NE 相位性激活 + flow
```

每一个目标状态都有对应的信号组合、神经通路、内分泌应答和时间约束。这套框架的美在于——它不需要发明任何新东西。人体本来就知道怎么镇定、怎么专注、怎么入睡、怎么愉悦。只是需要一个触发器。

Anim 就是这个触发器。
