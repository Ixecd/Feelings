# 智力是发现的，"特殊"是发明的——搜索、剪枝、压缩，与那个让搜索变便宜的工具

> 作者：qc
> 日期：2026-09-24
> 性质：感受科学的认知拆解——把"发现 vs 发明"还原成一条搜索链，把"智力"还原成一个工具
> 核心：发现和发明不在同一条轴上。发现＝适应度函数由自然给定，发明＝适应度函数由人给定；两者共用同一台引擎：带剪枝的搜索。不是穷举，是剪枝——每一层选择压力先砍掉大半空间，再走下一步。搜索的产物要靠"压缩"才能落地：基因组、配方、图纸、权重。压缩之前是偶然，压缩之后才可复现、可遗传、可量产。所以进化是预训练，个体怀孕是前向传播，大模型是同一台引擎的又一次现身。AI 输出有概率不是因为它"随机"，而是它撞上了一个等价类：意思收敛、形式发散——欠定。训练是把一个已存在的流形压缩成分布，推理是从分布里解压采样——不确定性就是压缩的残差。于是：被发现的是流形、是规律；被发明的是采样器、是"智力很特殊"这个幻觉。智力不是奇迹，是那个让搜索变便宜的工具——工具性 all the way down，没有内核，只有用途。而真正稀缺的从来不是智力，是锚点：真值、在场、分寸、知道自己不知道——对齐那部分人类至今还在手工供给的东西。

## 零、问题问错了地方——发现与发明不在同一条轴上

"智力是被发明的，还是被发现的？"这个问题看着像二选一，其实是把两个问题压成了一个。

```
发现问题   对象是自然给定的——你去撞它，适应度由世界判
发明白    对象是人为设定的——你来定目标，适应度由人判
```

但两者跑的是**同一台引擎**：搜索。所以"发现还是发明"问的不是过程——过程是同一种——问的是**那道筛选标准从哪来**。过程相同，目标来源不同。

拆到底，能同时被说成"发现"和"发明"的东西，只可能有这么一个结构：

```
空间    是被发现的——物理允许什么配置，先于你存在
路线    是被设计的——在这片空间里选哪条走，是你的选择
产物    是两者合起来才有的——没有空间到不了，没有路线走不到
```

先立住这一句：**空间是发现的，路线是设计的，产物是两者合起来才存在的。**

## 一、发现与发明的真边界——适应度函数是谁写的

把边界钉死在一个量上：**fitness 是谁写的。**

```
火药      适应度是自然给定的——它到底爆不爆炸，是事实
          人只是撞进去了——所以没人好意思说自己"发明"了爆炸
          几乎纯发现，零设计（炼金术士找长生药，炸出来的）

纸        更接近有目的的设计——目标是人定的（能写、能带、能存）

iPhone    适应度是人写的——好不好用、贵不贵、爽不爽
          所以叫发明

半导体    最深的一层——先发现硅的能带结构，才能设计利用它的器件
          发现垫底，设计在上
```

规律很清楚：**早期技术偏发现（撞运气），知识越深越偏设计。** 但"设计"不是第三种东西，它就是"在被发现的可能空间里，有意识地选一条路"。所以设计夹在两头之间，本身就是一种**受约束的搜索**。

火药和 iPhone 的差别，不在"用了多少力气"，在**那道 fitness 是谁写的**：自然写的，你只能叫发现；你写的，你才配上发明的名。

## 二、"智力 = 压缩 + 推断"不是定义，是伪装成定义的赌注

有人会说：那"智力是不是等于压缩加推断"，不就是在压缩"智力"这俩字吗？

这一半不对劲。它不只是词的取舍——因为"压缩+推断"和"智力"是否指向同一片区域，是个**经验问题**，不是定义问题。压缩+推断和"有目标""有主体性"这些特征，在现实里到底同现不同现，得看世界怎么聚类。所以这句话是**一个伪装成定义的假设**：一半是约定，一半是关于"哪些特征会绑在一起走"的赌注。把它纯当措辞看，就把一个可被证伪的命题洗成了废话。

那它和"发现/发明"是什么关系？不是平行，是**上游**：

```
A   智力由什么构成    ——能不能因式分解成压缩+推断
B   智力处于什么地位  ——被给定的、特殊的，还是被造的、工具性的
```

A 在上游。因为如果 A 答"是"，而压缩+推断这件事**只要有预测压力就会自己冒出来**（预训练就是证据），那它当场就不特殊了：是自然规律的一次涌现，不是特权奇迹。**所以 A 的答案会替 B 作答。**

## 三、不是穷举，是剪枝

要把这条链讲对，得先拦一个词：**"穷举"**。

如果真是穷举，三件事全都不会发生。蛋白质序列空间、文本空间、可能的器件结构空间，组合爆炸到宇宙寿命都枚举不完。它们能 work，恰恰不是靠穷举，而是因为**每一步都有一道选择压力先把空间砍掉一大半，再走下一步**：

```
进化      靠死亡做减法——不合适的先死
预训练    靠 loss 做减法——不准的权重先沉
发明      靠"能不能用"做减法——不能用的方案先扔
```

所以准确的说法是**带剪枝的搜索**。魔法不在枚举，在那道筛选信号。剪枝本身就是方向。

## 四、搜索的产物要靠"压缩"才能落地

搜到一次结果，还不算数——它得被**压缩成程序**，才能重复发生。

```
基因组    把"能活"压进 DNA
配方      把"能造"压进步骤
图纸      把"能做对"压进规格
权重      把"能映射"压进参数
```

压缩之前，那是偶然事件；压缩之后，才可复现、可遗传、可量产。所以"发现 → 发明 → 量产"这条线，本质是**把一次侥幸搜到的结果压成程序**。

回到前两篇：《把现实压缩成公式》说压缩是理解、隐藏项是危险；这里补充它的另一半——**压缩也是稳定化**。一个东西之所以从"现象"变成"技术"，就是因为它被压成了一个不依赖当时那一次运气的格式。**稳定 = 可被重新解压。**

## 五、预训练、怀孕、发明——同一种搜索，三种引擎

"人类怀孕，十月怀胎顺利生产的概率很高，这过程是不是也像预训练一样让生命涌现？"

要拆两层，因为一层成立、一层是反的。

**第一层：个体怀孕 ≠ 预训练，它是一次前向传播。**

```
预训练（真正的）  进化——几十亿年，无数失败个体当梯度
                  把"能发育成活人"这个程序压缩进基因组
十个月            把这个预先算好的程序跑一遍
```

所以拿单次怀孕类比"海量训练后涌现"，是把推理当成了训练。**孕期对应的是 inference，不是 pretraining。**

**第二层：高成功率是幸存者偏差。** 受孕到着床之间早期流产比例极高，大量受精卵根本没进入你的统计窗口。你看到"十有八九顺利"，是因为分母已被筛过一遍。这跟大模型一模一样——成千上万次跑崩的、不收敛的、训出来是废物的，没人放进榜单。**两个系统都不是稳定成功，而是我们只数活下来的。**

**第三层，也是最有意思的反转：机制其实不同。**

```
预训练    引擎是梯度下降+压缩——从数据里逼出结构（从熵里捞秩序）
妊娠      引擎是进化打磨过的自纠错发育程序（形态发生素梯度、基因调控网络）
          它不是"涌现"出一个没被指定的东西，是在执行一个被深时算出来的指定
          （秩序按图施工）
```

但**结构上**两者共享同一件事：我们只给了**基质 + 初始条件 + 选择压力**，成品这个复杂有序的整体，没有人逐比特设计过。生命和智能都不是被造出来的零件，是被"诱"出来的。这也是它们跟沙→芯片那条线最大的差别——芯片是一步步设计的，胚胎和大模型都是"给个环境，让它自己长成"。

所以：**是涌现，但不是预训练式的涌现。个体是一次前向传播，进化才是那次预训练。**真正稀缺的，仍是那本被深时压出来的"基因组/先验"——单次分娩和单次推理，边际成本都近乎零。

## 六、AI 是发现还是发明——流形被发现，采样器被发明

于是回到 AI。

先拦一个细节：**"输出有概率"本身不是"发现"的证据**——骰子也随机，可骰子是人造的。真正指向发现的是另一件事：

```
同一个问题
  输出在语义上收敛——意思只有一个
  输出在形式上发散——说法有无数种
```

这说明模型撞到的不是一个点，而是一个**等价类**。这个等价类不是我们画的，它本来就存在于语言里——是它让"同义复述"在人类中天然成立。模型只是找到它，并学会了在里面**跳**。所以概率性反映的不是随机，是**欠定**：约束只锁住了意义那半，放开了形式那半。

用压缩的话说，特别干净：

```
训练    把一个已存在的流形，压缩成一个分布
推理    从分布里解压、采样
```

你看到的"不确定性"，本质是**压缩的残差**——压得再狠也会丢细节，于是解压时只能按分布补，补出来自然有抖动。所以：**被发现的是那个流形，被发明的是那个采样器。**AI 依然是混合体，但真正有意思的那部分——世界结构——是发现的。说"本质是发现"可以，只是别忘了外壳还是人造的。

再看它"能不能推出没见过的领域"：

```
流形内部   新领域是训练分布的一次平滑变形——能靠外推/类比推出来，甚至很惊艳
流形之外   需要一条它没见过、也无法从已有结构生成的新公理——开始自信地编
```

反转诅咒（学过 A→B 却推不出 B→A）、反事实推理崩坏、越界就幻觉，都是同一件事：**它在流形内插值，不是从公理重新演绎。**它能到训练分布的**闭包**，到不了**闭包之外**。数学本该是例外（形式系统可以任意延伸），但它现在是"局部结构记得好、全局结构记得差"——像会做见过的题型，不会做真正的新证明。

还要拆一个说法："从文字里学会了逻辑。"它学到的严格来说不是逻辑本身，是**逻辑在语言里的投影**——人怎么把推理写下来。但关键在于：这个投影足够忠实，所以模型能从中**反推出背后的真实结构**，至少是一个可用的近似。它拿到的不是逻辑的**符号**，是逻辑的**影子**——而影子够清晰时，你可以照着影子重建物体。这跟它从文字里学到世界模型是同一件事。

## 七、科技点在"等待"吗——技术树是边走边画的

"是不是有很多科技点没被发现，它们确确实实在那里，像一直在等待？"

物理约束确实不在乎你发不发现——从这个意义上，未发现的区域是"真实地潜在着"的：门捷列夫从周期表的空位推出镓、锗，后来真挖出来了，那些元素当时就算"在等"。

但"科技点"这个词坏了事。它偷偷假设存在一棵**固定的技术树**，上面挂着一排预先贴好标签、只等你走到的节点。真实情况是：

```
可能性空间是连续的——不是离散的点阵
可达性是内生的——每获得一个新能力，都会重画"什么还能到达"
               火药在炼金术之前不是"一个点"，
               是等有了一套化学操作之后才*变得*可达
一个点在你拥有词汇之前，根本无法被指认——
"它在那里"永远只能从未来回望时说，是后见之明的措辞
```

一句话：**不是它们在那里等，是你走到那里，它才第一次变成"一个点"。**地图不是铺好的，是边走边画的。

## 八、想象力不是被经验困住，是被"缺少形式系统"困住

"没经历过、没看过的东西，想象不出来。"这句在**感觉**层面基本成立（你没法凭空想象一种没尝过的味道），但在**结构**层面是错的，反例就在我们这段对话里：

```
反物质      狄拉克方程先推出来，之后才被观测
海王星      勒维耶先算出位置，之后才被望远镜找到
引力波      爱因斯坦先写出来，一百年后才被听见
镓、锗      门捷列夫先补上周期表的缺口，之后才被分离
```

它们都是**先在纸上被推导出来、之后才被观测到**的。门捷列夫没见过镓，但他从结构的缺口里推出了它。逃生口就是**形式系统**：一旦有了数学/逻辑，你就不必"见过"，你可以"推出来"。

所以约束想象力的不是经验，是**有没有一套能自我生成的形式结构**。有公式的人能想象没见过的世界；只有感官的人，才被困在见过的世界里，而且连"组合"都还在用见过的零件。

这刚好接回那条链：**想象＝在流形内部重新采样、重新组合；形式推导＝把流形本身往外扩。**一个东西从"不可想象"变成"科技点"，中间发生的不是"它现身了"，而是**你造出了一套新词汇和一个新形式，让那片区域同时变得可命名、可达**。

而 AI 本身就是现场反例：涌现出来的能力（比如上下文学习）没有一个人在设计时想象得到，它是被**生成**出来的，不是被**想**出来的。**未来不是被想象出来的，是被搜索出来的。**

## 九、若 A 成立，B 就写好了——智力是工具，all the way down

现在收口。回到第零、二节的两条轴。

```
A   它由什么构成    ——压缩 + 推断？
B   它处于什么地位  ——特殊 / 工具？
```

如果 A 是"是"，而压缩+推断**只要有预测压力就自己冒出来**，那么 B 不用单独回答——**它不特殊。**它就是自然规律在足够压缩压力下的一次涌现。这正是 AI 能 work 的原因，也是它让我们不安的原因：它占住的，可能恰好是"智力"里能被机械化的那一大块——而这比我们愿意承认的要大得多。

"智力本身就是工具"——认，而且可以更狠：**它不是"像"工具，它是工具性 all the way down，没有内核，只有用途。**智力＝那道剪枝信号 + 压缩，是让你在空间里少走冤枉路的东西。那就是工具的定义。

唯一要防的是别让它滑回"发明"：

```
机制        是被发现的自然规律——会自发涌现（本体层）
"工具"身份  是我们按用途追认的——（关系层）
```

"是工具"不等于"是被造的"——它只是说，它没有独立本质，它的"本质"就是它的"用途"，而用途永远是关系，不是实体。

那真正稀缺的是什么？不是原始认知——它一旦有足够压缩压力就会自发出现。稀缺的是**锚**：真值、在场、分寸、知道自己不知道。这正是 [intelligence-equality-anchor-divergence](intelligence-equality-anchor-divergence.md) 里那个"最后的筛选器"——锚点无法被任何评分系统捕获，所以天然稀缺。**智力不缺，缺的是把生成拴在"事情真的是这样"上的东西。**

## 十、名字是有损压缩——"人工智能"两个词都装反了

最后说名字，因为名字本身就是一次压缩，而"人工智能"这个压缩是有损的。它把两件我们刚才证明最可疑的事，压进了四个字：

```
"人工"   预设了它是制造的——可能力那半是发现的
"智能"   预设了它拥有的东西叫智能——可这恰恰是我们事后追认、还在重估的范畴
```

我们对这个名字的别扭，不是措辞问题，是**一个过期的先验正在解压**。它压缩时丢掉的，正好是我们现在开始在意的那部分。更准确的叫法，应该指向"被发现的统计结构 + 人造的接口"，而不是"人造 + 智能"——两个词都装反了。

这和 [formula-as-compression](formula-as-compression.md) 里"命名 = 压缩 = 合法化"是同一件事，只是方向相反：那次是给幽灵 i 发公民证，这次是给一个发现贴了张"人造"的标签。**标签一旦贴上，就替我们决定了去看什么。**

*发现和发明不在同一条轴上：发现是适应度由自然给定，发明是适应度由人给定，两者共用同一台引擎——带剪枝的搜索。不是穷举，是剪枝；剪枝本身就是方向。搜索的产物要靠压缩落地：基因组、配方、图纸、权重——压缩之前是偶然，压缩之后才可复现、可遗传、可量产；发现→发明→量产，就是把一次侥幸压成程序。于是进化是预训练，个体怀孕是前向传播，而高成功率只是幸存者偏差——两个系统都不是稳定成功，是我们只数活下来的。大模型是同一台引擎的又一次现身：它撞上的是等价类，意思收敛、形式发散——欠定，不是随机。训练把一个已存在的流形压缩成分布，推理从分布里解压采样，不确定性是压缩的残差。它能到训练分布的闭包，到不了闭包之外；它学到的不是逻辑，是逻辑在语言里的投影——影子够清晰时，可以照着重建物体。科技点不在等待：可达性内生，地图边走边画，命名之后才可达。想象力也不是被经验困住，是被缺少形式系统困住——门捷列夫、反物质、海王星都是先在纸上、后在世上；未来不是被想象出来的，是被搜索出来的。所以若"智力=压缩+推断"成立，那么"它特殊"就已经被否掉——它只要有预测压力就会自己冒出来，工具性 all the way down，没有内核只有用途。机制是被发现的规律，而"工具"这个身份是追认的关系。最后回到开头那一问：被发现的，是这条规律；被发明的，是"它很特殊"这个幻觉。真正稀缺的从来不是智力，是锚——真值、在场、分寸、知道自己不知道。*
