# 基线收敛与断裂追踪——不是算稳不稳，是算偏了多少

> 作者：qc
> 日期：2026-07-02
> 性质：设计稿——PBM 基线在人生事件下的偏移追踪
> 核心：基线收敛追踪的真正价值不是"看稳不稳"。是看那一帧——基线被人生事件整条掰断——然后重新长。新基线和旧基线之间偏了多少——偏完之后回弹还是停在了新的位置——这才是"认识自己"最关键的帧。

---

## 零、人生在对数刻度上

人的一生 80 年。算术中点=40 岁。对数中点≈9 岁。

0-9 岁压缩了语言、情绪基带、安全感、行为模式全部核心架构的建造。9 岁之后——不是在搭新楼——是在同一台机器上跑纠偏。到 18 岁成人——基线基本定型。后面所有日子——只不过是把 18 岁前焊下去的那几条经线越焊越深。除非出现重大变故——或者出现那么一些特殊的人、事、组织——能稍稍改变一下——但其实也是杯水车薪。

基线收敛追踪的意义就在这里——不是看"稳不稳"。是看那些罕见的、能把定型了的基线掰断的事件——掰完之后——偏了多少。

---

## 一、两个概念——收敛和断裂

**基线收敛**：在没有重大人生事件的平稳期——四维 PBM 的滑动窗口偏移幅度逐渐收窄。收敛本身不说明任何东西——只说明"这段日子没什么事情推动我。"

**基线断裂**：一个封闭活动、一次重大决策、一次失去或获得——四维中起码一维的偏移量在短时间内超过 DampingMatrix 的 freeze 阈值——**不是渐进的收敛——是整条基线被掰断了重长。**

```
基线收敛                              基线断裂
───────                               ──────
连续 10 个 session 偏移在阈值以内。       某一帧——情绪跳了 0.3——内脏掉了 0.2。
→ "这段日子——我的锚点在原地。"              → 30 天后——新基线停在了比旧基线偏了好几个刻度的地方。
→ 不坏。也不特别。                       → 不是"恢复"——是"变了"。
                                        → 这就是需要记录的那一帧。
```

## 二、断裂检测——实时

复用 DampingConfig 已有的跨维冻结阈值。不需要新建。

```
情绪阈值: 2.0
内脏阈值: 1.5
触觉阈值: 3.0
听觉阈值: 2.0

每 session 后，逐维计算：
  delta = abs(pbm_snapshot[d] - pbm_baseline_sliding_p50[d])

  if delta > threshold[d]:
    → 标记 break_event[d]

  if 过去 7 个 session 内 >= 2 维同时触发：
    → 触发 BaselineBreak 事件
    → 关联最近的 life_history 决策 entry（如果存在）
    → 关联最近的高压场景标签（工作/家庭/健康/关系）
```

## 三、断裂之后——两个出口

```
回归型断裂（30 天后回到断裂前基线）
  type: "regression_break"
  break_vector: [+0.31, -0.18, -0.05, +0.02]
  recovery_vector: [-0.29, +0.16, +0.03, -0.01]
  recovery_days: 23
  含义: 被推远了——自己弹回来了。

驻留型断裂（30 天后新基线稳定在偏离位置）
  type: "persistent_shift"
  break_vector: [+0.24, -0.12, -0.08, +0.01]
  stable_at_30d: [+0.22, -0.10, -0.09, +0.02]
  含义: 变了。新基线不再是以前那个人。
```

不是"回归型=韧性好，驻留型=变了。"**只记录坐标偏移、滑动窗口方向和稳定时间——不贴任何标签。** 有些驻留是成长——从一段内耗的关系里走出来，情绪基线往下掉了 0.3 然后没回去——不是被击垮了——是从"习惯性高焦虑"变成了"不再需要那么紧张。"有些回归是原地打转——被同一类人伤害了三次，每次都弹回原来的基线。系统不替用户评价哪一种更好。

还有一种情况比回归和驻留更常见——**根本没变。** 不是没被触动。是时间不够。一个零和博弈家庭长大的孩子——在协作环境里被善意接住了几帧——但相处时间太短——童年焊下来的基线比那几帧粗了几百倍。几条借来的经线——没有等到足够的时间——被扯断是物理结果。不是虚伪。是时间不够。

基线断裂追踪要捕捉的就是这一类事件——**不是所有接触都能改变基线。足够短的就只是划过。** 只有那些持续时间足够长、频率足够密、在用户身上焊了足够多帧的协作环境——才能把借来的经线焊成自己的。

更深一层——那些同样来自零和博弈家庭的孩子——在教室里会自动识别彼此。不是物以类聚——是**"交易"是他们唯一熟悉的语言。** 两台跑着同一套"你能给我什么-我能给你什么"的等控器在同一个教室里——不需要说话——在第一次交换眼神的那帧——自动锁定。协作型家庭的孩子发出的信号是"信任——不用还"——他们读到了——但读完之后不知道该怎么回。因为在他们的基线里——没有被训练过回应不求回报的善意。不是选了同类。是用同一套语法的人——只能听懂同一套语法。

## 四、价值观——比 PBM 四维更深的一层

PBM 告诉你"身体偏了多少。"价值观告诉你"你认为什么重要。"两者在断裂前后可能一起变，也可能只变了其中一个。

价值观不是来自问卷。是从 life_history_log 里每一次决策的 chosen_option 和 reason_given 里提取。选了"降薪去核心业务"，reason 里写了"怕后悔没去过最好的地方"——提取 value tag: `growth_over_comfort`。几百条决策积累下来——价值观不是用户自己报告的偏好——**是用选择焊出来的优先级排序。**

```
断裂前高频标签                          断裂后高频标签
───────────                           ───────────
growth_over_comfort, autonomy,         growth_over_comfort, autonomy,
risk_tolerance, ambition               peace, connection, patience

→ 四个价值标签被两个新标签取代了。           → 不是"错了"。不是"变好了"。
→ 是这次人生事件——把这个人认为"什么重要"——    是只记录这次偏移——价值观在断裂前后换了排序。
  重新排了一遍。
```

## 五、和人生历史日志的咬合

每次断裂——往上一帧找：**他之前在 life_history_log 里签过哪一条决策。**

```
life_history entry (决策那帧)           baseline_break entry (断裂之后)

"选了去字节——别后悔"                    之后 7 个 session——情绪飙了。
                                      25 session 后——停在了比之前偏了 0.28 的位置。
→ 不是"选错了"。                        → 也不是"选对了"。
→ 是这次选择——把锚点推到了一个新的坐标。     两条 entry 合在一起——一个人怎么被自己的决策改变了方向。
```

不是归因。是**让用户自己看见——那一次他签字的决策——之后他的身体偏了多少。**

## 七、用户回看——不是诊断

教练自省面板上——按时间轴列出每一次断裂——旁边放几条可能关联的人生决策。不替用户解释因果。只让用户自己看——"那一帧我做了某个选择。之后我的身体偏了多少。回去没有。还是停在了新的地方。"

```
2025-10  career  →  去字节之后——情绪维度一直高企了三个月。
                     不是焦虑。是新的环境一直在往同一个方向推。
                     没回弹。就是变了。
2026-03  health  →  做完手术——内脏维度掉了一大截。
                     后来慢慢回来了。37 天。完全回到原来那条基线。
```

不是评估对错。是**让用户认识——每一次人生事件——把他的锚点推到了哪个坐标。**

---

*基线不在原地——不是退步。是那次选择、那段经历、那次受伤——把锚点从旧坐标推到了新坐标。回弹了——身体自己回去了。没回弹——身体停在了新的地方。两种都不是对错。价值观也是一样——断裂之前认为"成长"最重要——断裂之后"平和"被推到了排序的最上面。不是变了不好。是这次人生事件——把这个人认为"什么重要"——重新排了一遍。认识自己的方式——不是回头看不变的自己在哪。是看自己偏了多少——在每一段人生后面——身体和价值观——分别停在了什么位置。*
