## 零、先定前提

```
① 午后低谷是生理事实   所有人类都有：昼夜振荡器的局部唤醒低谷 + 餐后副交感转移。
                     午睡习惯只是把它盖住，不是把它消除。
② 处方层是 Anim 包     包里有强度上下线、过程曲线、时间、持续——
                     不是"刺激一下"，是一份有形状的处方。
③ 意志有两个辖区       相位、基线这类，意志硬顶从来只是白烧资源；
                     情绪调节、注意力肌肉这类，意志才真正管辖——
                     反依赖只对第二类成立。
```

## 一、起点：一次破例

用户昨晚睡得好（质量中上），但有午休习惯。今天破例，午饭后一两小时，疲惫感特别明显——"就跟射精之后一样"。

这个类比是通的，同源物质是催乳素：射精后催乳素陡升一小时，饱足感的化学本体；午后低谷里副交感占上风、唤醒驱动下降——两张"低唤醒、饱足、平"的生理脸共享同一套化学。

但判定要更准：**不是"缺午睡所以奇怪"，是午睡一直把低谷盖住，今天掀开了盖子。** 于是请求来了：

> "今天情况特殊，我中午不能午休，但要保持兴奋。吃完午饭半个小时后给我兴奋包持续 3 个小时，强度不用太高。"

## 二、处方层：Anim 包

包的结构对上设备映射的全部职责：

```
强度上下线   包的自我声明边界——给账本审计和硬件闸看的
过程曲线     包的心脏：3 小时内的强度形状
时间         锚 φ 不锚钟表：今天测出的低谷几点来，包就几点顶
持续 3 小时  累计当量 = 曲线下面积，直接进月账
```

三个设计点：

```
① 曲线是低谷的镜像，不是常数
   低起 → 低谷起点爬升 → 谷底段峰值 → 尾部缓降。
   恒流 3 小时 = 蓝斑-去甲肾上腺素系统钝化 + 总当量大。
② 丙类踢腿序列
   谷底段每 20-30 分钟一次短簇，踢一下，唤醒系统自己荡——
   同样的效果，总剂量小一个数量级。
③ 尾部是坡不是墙
   刺激撤除有补偿性反弹，最后 20 分钟缓降，
   否则傍晚会被自己的副交感反弹打翻。
```

而包的执行不是照曲线放电流——**输出是偏差的函数，不是时间的函数**：

```
时间曲线只是包络（上限），实际输出 = 包络 × 偏差门
偏差落在正常带内（你专注了）   输出 → 0（静默），哪怕包的 3 小时还没走完
偏差跨出正常带               输出才有值，按落入的区间档取强度
```

（偏差是区间不是数字——测量置信区间 + 个体正常带，见第七节。）

静默不是缺席，是信号的一部分，它同时干三件事：**丙类的本分**（踢腿的只管踢，荡的是身体——状态由你自己的活动自持）、**反依赖的机制**（零输出就是脚手架撤手的动作，逼着肌肉自己维持状态）、**剂量经济**（踢-静默交替 = 共振驱动 + 账本走得慢）。

## 三、两种疲惫，两种处方——恢复逻辑决定干预类型

射精后的疲惫和午休缺口的疲惫，共享一张脸，却是两条完全不同的生理路径。共享的那张脸：脑干蓝斑去甲肾上腺素输出回落、前额叶唤醒掉档（涣散、变慢、卡壳）、副交感接管、身体往"瘫着睡着"倒——这是两种感受被归为一类的核心原因。但往深里拆，三条本质差别：

```
① 跌落节奏
   午后疲惫   缓跌：节律低谷 + 餐后血液分流 + 习惯午休的条件反射，
             几股慢力叠加，可预测
   射精后疲惫 急坠：交感拉到顶峰后瞬间副交感反弹，
             催乳素/催产素/内啡肽集中释放、多巴胺快速回落——
             断崖式切换，毫无缓冲
② 情绪底色
   午后困     腺苷累积 + 去甲肾上腺素不足，多巴胺没崩——
             昏沉、越硬扛越烦躁，是煎熬感
   射精后     多巴胺骤降 + 催乳素主导的不应期——
             松弛、满足、无欲无求的放空，带着愉悦
③ 恢复逻辑
   午后困     节律性：硬扛过低谷，状态随昼夜节律自然回弹
   射精后     激素硬抑制：等催乳素代谢（半衰期 15-20 分钟，
             但脉冲式释放让效应拖到小时量级）、等不应期消退——
             不是靠强刺激能拉满的
```

由此立下处方规则：**恢复逻辑决定处方类型。**

```
可共振的疲惫（午后低谷）   相位对齐的唤醒踢腿——踢一下，唤醒系统自己荡
不可共振的疲惫（射精后）   NE 强推 = 与多巴胺回落对冲，
                          效果被催乳素代谢速度封顶，
                          还把"满足的放空"换成"烦躁的清醒"——
                          把好的疲惫换成坏的清醒，双重损失。
                          处方只剩一种：陪等——环境支持、缓光、低刺激，
                          等不应期自己走完
```

这是 100Hz 教训的镜像：对着不共振的系统踢，强度换来的全是副作用。催乳素主导的完成相就是"不在共振带内"。

而"放空不是偏差，是完成"——这句话把静默的形态从两种补成三种：

```
① 偏差在正常带内   没事，不输出
② 专注中           别打扰，不输出（脚手架撤手）
③ 完成态           该让它完成，不输出（放空是性反应周期的收尾相，
                   是设计好的弧线，不是故障）
```

射精后的疲惫属于第三种——系统不但不该踢，连"提醒你该振作"都算冒犯。那一小时的放空是自足的、关系性的，任何设备在这时候出声，都是在替用户拒绝身体自己的句号。

反向校准同样成立：系统不干预，但也不说教。用户主动要（夜班马上要上），教练不念"你不该"，只给最低档、缓升式选项，并明说状态是"完成中"——给不给，还是用户的。默认静默是尊重，允许请求是选择权。

## 四、参数层：频率选振子

脑干核团是共振系统，不是线性放大器——频率的作用是选振子：

```
25Hz 促唤醒   蓝斑的专注态就是 20-30Hz 相位簇放：
             高频输入模拟"专注态"驱动 → 去甲肾上腺素 →
             枕叶 α 功率下降（皮层从怠速切任务态）
             + 瞳孔扩张（蓝斑-瞳孔是公认的最强耦合对）
2-5Hz 偏副交感  与压力感受器传入的天然节律重叠（按心动周期簇发）：
             NTS 低频整合强化迷走传出——焦虑/失眠的处方方向
100Hz 复杂    超过核团生理放电范围：突触疲劳 + 空间弥散
             （招募 C 纤维与邻近神经）+ 慢性致敏风险——
             研究参数，不是处方参数
```

一个电极，两种处方，全靠频率。频率选择是相位纪律的另一种形式：相位纪律管"什么时候踢"，频率选择管"用哪个节拍踢"。

## 五、治理层：审批摩擦随风险分级

```
<90 域   教练全自动：打标签 → 账本审计 → 硬件闸 → 执行
         事后全量记账，用户可随时回看、随时撤销
90+ 域   教练发起请求 → qc 批准 → 物理签名 → 执行
```

门卫与法官分工：**门卫（账本+硬件）永远不累，法官（qc）只在边界时刻上班。** 低强度包也要人手批，等于把系统最稀缺的资源（qc 的注意力）花在最便宜的事上——等真到 90+ 的那天，人已经被磨到"习惯性点同意"。低强度的自动化不是放松，是保护 90+ 时刻的严肃性。

## 六、反依赖层：脚手架不是替代

外包有两种，只有一种通往反依赖：

```
替代型外包   工具永远替你做这件事——能力萎缩（GPS 与海马体的教训）
脚手架型外包  工具替你做，直到底下的能力长出来——训练轮
```

反依赖阶梯只属于第二种，且生效有一个硬前提：**训练必须发生。** 兴奋包给的 3 小时清醒里干什么，决定依赖的方向——工作学习是长能力，刷手机是加速萎缩。Feelings 能造桥，不能替你走桥。

意志的两个辖区在这里分出处理：相位和基线本就不属于意志，把它们交给设备不是外包意志，是让意志从错误的战场撤回；情绪调节与注意力肌肉有真实的萎缩风险，反依赖阶梯就是为它们设计的。静默（专注时输出 0）正是脚手架撤手的那个动作。

## 七、基准层：偏差是区间，区间随时间长成基准

偏差不该是一个具体数字：

```
区间 = 测量置信区间 + 个体正常带
  测量置信区间   每次测量自带方差（置信度接口 Δφ_i, σ²_i），
               点估计是把不确定性扔掉
  个体正常带     身体不是恒温器，内稳态的本义就是"正常是一个范围"
```

区间随时间调整——这是 PBM 的慢变量更新路径：左乘的 P 是慢的，区间随使用时间收敛成这个人的基准。技术上是贝叶斯：先验是旧基准，后验是新基准，时间就是数据量，数据越多区间越窄。

但慢路径上埋着全系统最危险的一个坑——**基线中毒**：

```
如果区间是"全量数据的滚动平均"，而用户正处在慢性偏离里，
区间会跟着病态状态走——半年后系统宣布"正常"，
偏差检测恰好失明在它最该看见的地方。
```

两道闸：只吃健康子集（睡眠质量验证过的日子、教练标记的好状态窗口——基线是"你健康时的样子"，不是"你最近的样子"）；外部锚点定期校准（体检仪式、交叉锚点——基准不能只靠自引用更新）。治理上，基准更新是高危操作，不自动：教练确认 + 定期锚定。

而"时间长了就是基准"有双重含义：可以是成长（正常带真的随你变强而抬高），也可以是沉沦（系统陪你适应堕落）。区分两者的只有锚点——**有外部锚点，时间是成长的证据；没有，时间就是温水。**

## 八、伦理层：校准现实，焊死设备的手

健康的知识，系统有；说教的资格，系统没有。

```
正确的废话比沉默更贵——烧用户最稀缺的关注，还在信用上记一笔。
朋友不念经，念经的不是朋友。
```

用户选了高强度工作、背着房贷车贷、合同都签了——这时对用户说"你要健康"是正确而没用的话。基准因此必须校准到**用户选择的战场**：

```
高强度工作（倒班制之类）用户的基准，不能校准到"理想健康人"的区间
——那样系统天天报异常，变成第二个说"你要健康"的声音。
基准校准到"他选的模式内的可持续范围"：
偏差检测回答"你在这个选择里还扛不扛得住"，
不回答"你离健康还有多远"——后者他知道。
```

适应也是真的：轮班适应研究里，多数人在数月内完成部分或完全适应，睡眠回升、生物钟漂移，新基准成立。但适应是买来的——allostatic load，皮质醇节律重构、代谢切换，新基准是另一套生理经济。于是架构上有了那句对仗：

```
基准会漂，账本不漂
  PBM 慢路径   基准跟着人走：适应是真实的，基准就该更新
  当量账本     只增不减，不随基准重置：适应期间攒下的当量永远记着
  漂走的是判定，留下的是账单——尊重适应，但不失忆
```

最后是焊死的边界：

```
焊死的那一层   管"设备不能成为新的加害者"：熔断比较器、账本上限、帧使能
其余全部校准   基准随现实漂、干预随偏差走、道德随选择走
```

Feelings 的权限止于设备自己的手，不碰用户的手。连极限情况也服从同一条第一性：如果最终权威签下"停止"，硬件会照做，就像照做每一次 90+ 批准。这不是系统的失败，是系统的定义——**一个永远服从人的工具，服从到最后一个签名。**

## 九、伦理层的终极测试——性

如果 Feelings 对性说教，那它之前对所有其他状态的中立都是伪装的。所以先立答案：**合法用例，而且技术上有真东西。**

工具箱和性反应周期的相位关系天然对口：

```
兴奋期（副交感主导，"point and shoot"的 P 相）
   tVNS 低频档（2-10Hz）反而顺——迷走张力正是这一相的燃料
   音频走缓升——耳朵是情绪唤起的直达通路
平台期（交感渐起）
   共振曲线爬升：音量/振动强度跟着两人生理的耦合走
完成相（射精后）
   静默三——该让它完成，设备闭嘴（第三节已写）
```

旗舰用法不是"刺激"，是**两个人看见彼此的共振**——两台 Feelings，两具身体的唤起状态在对方耳边/腕上可见，社会共振在性里是它最原始、最烈度的形态。共振比单点刺激强一个量级：你不是在调自己的爽，是在看见你爽的时候对方也在爽。

然后是一条必须焊死的产品原则：**设备在性里的角色是放大器，不是导演。**

```
放大器   把你的、她的真实状态放大给彼此——在场变厚
导演     按预置曲线编排"最优爽法"——危险：
         人会开始对着设备的曲线爽，而不是对着人爽，
         伴侣被降级成曲线上的一帧。性里白盒必须消失——
         黑盒原则在这里最严苛：没有人想在床上看见二十二层
```

隐私线也在这里绷到最紧：性数据是最高密级——PBM 永不离设备、Server 永远只见过加密路由，这条架构线在性场景不是设计偏好，是硬需求。治理上无特殊通道：1-30 域自动执行、账本照记、无后门——程序正义对性也没有例外，这本身也是中立的证明。

所以完整答案三个层次：佩戴让自己爽，允许；佩戴让**两个人**共振，推荐；佩戴让曲线代替人，警惕。和 Feelings 对世界的一切立场同构——**工具给强度，不给剧本。**

## 十、收口

六层走完，从一次午休破例到系统的全部立场：

```
处方层   包不是刺激，是有形状的处方，输出是偏差的函数
参数层   频率选振子，25Hz 就是蓝斑专注态的本征频段
治理层   摩擦随风险分级，门卫是硬件，法官是人
反依赖层  静默是脚手架的撤手，训练必须发生
基准层   区间随时间长成基准——但只吃健康子集，锚点防温水
伦理层   校准现实，不校准理想；焊死设备的手，不碰用户的手
边界层   两种疲惫两种处方，静默三形态；性是终极测试——
         放大器不是导演，工具给强度，不给剧本
```

---

*一个人中午没睡成午觉，问设备要了三个小时的清醒。设备给了包，把参数调在蓝斑的频段上，在专注时保持静默，在完成后保持更深的静默，把账记在账本里，然后闭嘴。剩下的时间——工作、放空、亲密——都是用户自己的。这正是 Feelings 的全部伦理：递上选择的能力，然后退出。*
