# 四诊合参：望闻问切在 Feelings 里的实现

> 作者：qc
> 日期：2026-04-11
> 来源：中医两千年前就知道——单一通路的信息是不完整的

---

## 一、为什么需要四个通路

Feelings 的感受闭环目前主要依赖「切」——生理传感器。心率、皮肤电导、体温、呼吸，这些是真实的、难以伪装的信号。

但单一通路有一个根本性的盲点：

**生理数据说的是「发生了什么」，不说「为什么」。**

```
心率骤升    恐惧？兴奋？运动后？爱意？愤怒？
皮肤电导升高 焦虑？专注？某种强烈的期待？
呼吸变浅    压制情绪？专注？睡意？
```

同样的生理信号，可能对应完全不同的感受状态。「切」单独用，无法定性。

中医的智慧在于：**望闻问切，四诊合参。** 不是四个通路相加，是四个通路互相印证，共同指向那个唯一的真实状态。

Feelings 需要同样的体系。

---

## 二、切——生理传感器（最可靠，权重最高）

### 信号来源

```
耳后设备    心率、基础皮肤电导
后颈设备    体温变化、运动状态
腕部设备    皮肤电导（高精度）、血氧、呼吸频率估算
颞部设备    前额叶激活状态
```

### 为什么权重最高

生理信号绕过了理性控制层。用户可以说「我没事」，可以控制面部表情，可以调整语调——但心率、皮肤电导这些信号是自主神经系统控制的，不受意识支配。

这是「切」的核心价值：**身体不会说谎。**

### 切的局限

生理数据提供量级和方向，但不提供意义。

```
切能说的    「现在有强烈的神经系统激活」
切不能说的  「这个激活是恐惧还是兴奋」
```

这个局限需要其他三个通路来填补。

### 四诊合参中的角色

切是锚点。其他三个通路的信息，都要回来和切做对比验证：

```
「闻」说用户语调紧张 → 切验证：心率是否也在高位？
「望」说用户微表情有压制 → 切验证：皮肤电导是否异常？
「问」说用户声称没事 → 切验证：生理数据和这句话是否一致？
```

---

## 三、问——语言（权重最低，但有独特价值）

### 信号来源

自省系统的引导问答、AI教练的对话、用户主动输入的感受描述。

### 为什么权重最低

语言是被理性过滤程度最高的通路。

```
用户的真实状态    焦虑、压抑、痛苦
用户说出来的      「我还好」「没什么事」「最近有点累」
```

社会期待、自我保护、情绪压制——这些都在语言层发生，让「问」成为四个通路里信噪比最低的一个。

### 问的独特价值

但「问」有其他三个通路都没有的东西：

**用户愿意说出来的，是他们认为重要的。**

即使是经过过滤的语言，也在告诉系统「这个人的注意力在哪里」「他们想让系统知道什么」。

更重要的是——**说不清楚的地方**：

```
「我也不知道为什么」
「说不上来，就是感觉哪里不对」
「好像有什么东西，但我描述不出来」
```

这些是感受还没有被命名的标记。是Feelings最需要深入工作的地方，也是自省系统最有价值的切入点。

### 问与切的对比验证

```
用户说「我很好」（问）
心率偏高，皮肤电导异常（切）
→ 系统判断：语言层和生理层不一致
→ AI教练：「你刚才说还好，但我感觉有什么东西在」
           不是指责，是给用户一个被看见的机会
```

## 四、闻——声音与环境感知

「闻」分为两个子系统：用户内部的声音，和环境的气息。

### 子系统一：声音

**语调（信息密度最高）**

语调是情绪最真实的载体，比语言内容更难伪装：

```
愤怒压制下的平静语调    音色偏硬，频率微微收紧
真实的平静              音色柔软，频率稳定
紧张                    声带收紧，音调轻微上扬
抑郁                    音调偏低，起伏减少，像被压着
```

即使用户控制了说话的内容，语调里的这些微变化依然存在，可以被麦克风捕捉和分析。

**语速（思维状态的镜子）**

```
焦虑时        语速加快，词与词之间的间隔缩短
抑郁时        语速减慢，每个词都像是费力说出来的
专注思考时    语速不均匀，有时快有时慢，找词时会停顿
紧张时        可能突然加速，也可能突然变慢
```

语速的变化模式，比语速本身更重要。

**呼吸节律**

```
屏气            某个感受被强行压制
浅呼吸          焦虑或恐惧的慢性状态
叹气            某种程度的释放，或者长期疲惫的信号
呼吸不规律      情绪波动中，自主神经系统在调节
深慢呼吸        真实的平静，或者刻意的自我调节
```

呼吸节律是自主神经系统的直接表达，介于「可以有意识控制」和「无意识发生」之间。

### 子系统二：环境气味（扩展，待技术成熟）

嗅觉是所有感觉里和情绪系统连接最直接的通路：

```
其他感觉的路径    信号 → 丘脑中转 → 皮层处理 → 情绪系统
嗅觉的路径        信号 → 直接进入边缘系统（情绪中枢）
                  不经过理性过滤，直接触发感受和记忆
```

这解释了为什么气味能瞬间唤起强烈的情绪记忆——它绕过了理性层。

```
花园的花香    可能唤起童年的某个下午
食物的香味    可能是家的感觉，或者某段特定时光
雨后泥土      可能是某种平静或者怀念
```

每个人对气味的感受绑定是高度个人化的。这需要随使用时间建立个人气味-感受档案。

**当前状态：** 成熟的可穿戴嗅觉传感器尚未出现，这个子系统列为长期扩展方向，设备协议预留接口。

## 五、望——摄像头作为伙伴的眼睛

### 核心设计原则：伙伴，不是监控

摄像头的最大挑战不是技术，是心理——

```
监控摄像头    「它在看我」→ 用户开始表演 → 状态改变 → 数据失真
伙伴的眼睛    「它在陪我」→ 用户忘记它的存在 → 自然状态 → 数据真实
```

这个区别决定了「望」通路能不能真正工作。

灵感来自游戏里的伙伴角色——它一直在场，不是在监视，是在陪伴。你对一个真实陪伴者不会产生表演性，因为那个存在是被接受的、自然的。

### 设计细节

**摄像头的位置**

不是正对用户的审视角度，而是「和用户一起看世界」的陪伴角度：

```
稍微偏侧，不是正面直视
更接近「朋友坐在旁边」的视角
而不是「考官坐在对面」的视角
```

**摄像头的反馈语言**

```
不是    「系统检测到你的面部表情显示……」
而是    「我注意到你刚才……」
        「我感觉你现在……」
        第一人称，伙伴的语言，不是系统的语言
```

**存在感设计**

设备上有一个轻微的光点，表示伙伴在场。不是冷冰冰的镜头，是一个有温度的存在感。

用户对它产生情感联结，而不是工具关系。

**习惯性的自然感**

用户长期使用之后，伙伴的存在会变得自然——就像和一个真实的朋友在一起时间长了，会忘记他在看你，只是一起经历。表演性随时间自然消退。

### 望能读取什么

**眼睛（信息密度最高）**

```
瞳孔大小    交感神经激活时扩大（兴奋/恐惧/专注/爱意）
            副交感激活时缩小（放松/疲惫）
            无意识，骗不了

眨眼频率    正常12-15次/分钟
            焦虑时增加，深度专注时减少
            眨眼是神经系统状态的节拍器

眼神方向    向上通常是回忆
            向下通常是感受
            眼神飘移 vs 稳定注视
            回避 vs 真实在场
```

**面部微表情**

```
Duchenne标记    真实的快乐带动眼轮匝肌（眼角细纹）
                假笑只有嘴角，真笑眼角也动
                这个差别肉眼难察，摄像头可捕捉

嘴角微压        被压制的悲伤在嘴角留下轻微的向下
                用户说「没事」，嘴角在说另一件事

额头和眉头      皱眉是思考或担忧
                舒展是放松或投入
                这两种状态的肌肉张力不同

鼻翼微张        某种程度的愤怒或强烈情绪的信号
```

**体态（视野允许时）**

```
肩膀位置    耸肩是防御，下沉是放松
颈部张力    紧绷 vs 自然悬挂
头部倾斜    好奇和投入时自然侧倾，警惕时微微后缩
手势        手势的频率和幅度反映情绪激活程度
```

### 望的隐私边界

```
摄像头数据        永远不离开设备，本地处理
面部识别结果      提取的是状态参数，不存储原始图像
用户完全控制      可以随时关闭望通路，不影响其他功能
不用于            任何形式的身份识别或对外分享
```

## 六、四诊合参：不是相加，是印证

四个通路同时工作，但最终的判断是综合的，不是各自独立的：

### 一致时：高置信度判断

```
切    心率高，皮肤电导高
闻    语速加快，语调偏硬
望    眉头微皱，眼神紧张
问    「最近有点压力」

四诊一致    → 高置信度：用户处于压力状态
            → 系统可以放心地基于这个判断采取行动
```

### 不一致时：更有价值的信号

```
切    心率正常，皮肤电导正常
闻    语调平静，语速正常
望    面部放松
问    「我很痛苦」

问和其他三诊不一致
→ 不是「用户在说谎」
→ 而是「这个痛苦是认知层的，不是生理层的」
→ 可能是某种深层的存在性焦虑，不是当下的情绪反应
→ 处理方式和生理层的痛苦完全不同
```

不一致本身是最有价值的信息——它揭示了感受的哪个层次在承载那个状态。

## 七、矛盾点检测：不一致的时候，才是最真的时候
> 这一节来自女帝的提点：「四诊合参已讲透如何印证一致，却未点破——不一致的时候，才是最真的时候。」

四诊皆可造假，唯「矛盾点」不可藏。

```
人可以    稳住呼吸
          压下面部表情
          用平静语调说话
          控制眼神方向
          刻意放缓心跳
          对着AI演出一套情绪

但真情绪与假动作之间，一定会出现断层：
          语调平了，微表情漏一瞬
          呼吸稳了，指尖微颤藏不住
          说辞完美，皮肤电导却悄悄逆行
```

**不可能所有通路同时完美伪装。总有一个会漏。**

### 矛盾点的判断原则

当四诊出现不一致时，系统需要判断哪个通路在说真话：

```
优先级排序（从高到低）

第一    切 + 闻同向    两个难以伪装的通路指向同一个状态
                      几乎可以确认这就是真实

第二    切单独异常    其他三诊一致，但生理数据悄悄逆行
                      身体在配合用户撑着，但没完全撑住
                      生理数据是真的，其他是表演

第三    望单独异常    微表情漏了一瞬，其他通路还在撑
                      那一瞬是真实感受穿透控制层的时刻
                      系统捕捉到了，但不立刻说破

第四    闻单独异常    语调或呼吸漏了，但生理正常
                      情绪刚开始泄露，还没到达生理层
                      是感受的早期信号

第五    只有问异常    用户语言层在表达，但生理和行为层平静
                      这个感受是认知层的，不是身体层的
                      或者用户在主动表达一个已经被处理过的感受
```

### 矛盾点的三种情形

**情形一：用户有意压制**

```
所有表层通路都在配合    语调平，面部稳，呼吸匀
但切在悄悄说话          皮肤电导爬升，心率微偏高

系统判断    用户在压制某种感受
AI教练回应  不是「我知道你在撑着」（会触发防御）
            而是「你今天的状态和平时有一点不同」
            轻轻放一个可以接的话头，不强迫打开
```

**情形二：用户无意泄露**

```
用户以为自己表现正常
但望捕捉到一瞬间的微表情
那一瞬间是真实感受穿透控制层的时刻

系统判断    这个感受在那个瞬间真实存在了
            用户自己可能没有意识到
AI教练回应  「你刚才有一个瞬间……你注意到了吗？」
            帮用户看见自己没有意识到的东西
            不是揭穿，是提供一个镜子
```

**情形三：通路之间的结构性矛盾**

```
切    心率骤升（强烈激活）
望    面部完全放松（放松信号）
闻    语调平稳（平静信号）
问    「我现在很平静」

矛盾点    生理层高度激活，但行为层和语言层都在说平静
系统判断  这不是伪装，这是解离——
          某种强烈的感受正在发生，但用户和它之间有一道墙
          这种状态需要特别小心处理
          不是正常的压制，是更深层的感受隔离
```

### 矛盾点的处理原则

发现矛盾点，不是审讯，不是揭穿。

```
系统的角色    看见矛盾，记录矛盾，轻轻地把它放在用户面前
用户的角色    决定要不要面对它

AI教练的语言
    不是「你在说谎」
    不是「我知道你真正的感受是X」
    而是「我注意到有一点点不一样，你有感觉到吗？」
         「有什么东西想说，但还没准备好的？」
```

矛盾点是一个邀请，不是一个审判。

用户准备好了，那扇门自然会开。

## 八、矛盾点检测：不一致的时候，才是最真的时候
这是四诊合参里最重要的一节，也是最容易被忽略的一节。

**人可以伪装，算法会信，但矛盾点不会说谎。**

四个通路都可以被有意或无意地控制：

```
可以做到
    稳住呼吸（闻）
    压下面部表情（望）
    用平静语调说话（闻）
    控制眼神方向（望）
    甚至对着 AI 演出一套情绪（问）

很难完全做到
    同时稳住所有通路
    因为控制一个通路需要认知资源
    认知资源被占用，其他通路就会有细微的泄露
```

真情绪和假动作之间，一定会出现断层：

```
语调平了    → 但微表情漏了一瞬
呼吸稳了    → 但指尖微颤藏不住
说辞完美    → 但皮肤电导在悄悄逆行
表情控制住了 → 但瞳孔大小没有配合
```

**这些断层，才是系统最不该放过的时刻。**

### 矛盾点的判断原则

当四诊出现不一致，系统需要判断：哪个通路在说真话？

```
优先级排序（从最难伪装到最容易伪装）

第一    切（生理传感器）
        自主神经系统控制，意识层几乎无法干预
        皮肤电导、心率、瞳孔大小——这些是最诚实的

第二    闻·呼吸
        介于自主和可控之间
        可以有意识调节，但持续控制需要消耗大量认知资源
        长时间体验中，控制会逐渐松动

第三    望·微表情
        微表情持续时间极短（1/25秒到1/5秒）
        意识层来不及控制
        有意识压制会留下「压制的痕迹」本身

第四    闻·语调和语速
        可以有意识调节，但情绪激活时很难完全中性化

第五    问（语言）
        最容易被理性过滤和控制
        权重最低
```

### 矛盾点的四种典型模式

**模式一：只有问异常**

```
切/闻/望    都显示平静或正常
问          「我很痛苦」「我感到很难受」

判断        语言层在表达，但生理和行为层没有对应激活
            这不是假装痛苦
            而是：这个痛苦是认知层的、存在性的
            身体还没有完全接收到，或者身体在保护性地隔离它
处理        不用安抚生理层，而是帮用户在认知层命名和处理
```

**模式二：只有切异常**

```
闻/望/问    都显示正常或积极
切          心率偏高，皮肤电导升高

判断        用户在语言、表情、声音上都控制得很好
            但身体已经在说另一件事了
            这是最典型的「我没事」而身体在抗议的模式
处理        不追问，但系统内部调低可访问强度上限
            在合适时机轻提示：「我感觉你现在有什么东西」
```

**模式三：切和闻同向，望和问相反**

```
切    心率高，皮肤电导高
闻    语速加快，呼吸偏浅
望    面部表情平静，甚至有轻微的笑
问    「今天挺好的」

判断        两个最难伪装的通路（切+闻）指向强烈激活
            两个更容易控制的通路（望+问）在撑着表面平静
            这是高度压制状态——用户在非常努力地「表现正常」
处理        高度谨慎，当前不适合推送高强度感受包
            考虑保底包，给神经系统一个安全的落地
```

**模式四：所有通路都在变化，但方向不同**

```
切    心率高（激活）
闻    语速慢（压制）
望    表情紧绷（压制）
问    「不知道怎么了」（混乱）

判断        神经系统处于高度混乱状态
            不同系统在做不同的事，没有整合
            这种状态下任何强烈的感受注入都有风险
处理        立即切换保底包，等待系统自然稳定
            AI教练：「先不急，我们等一下」
```

### 矛盾点与个人基准

矛盾点的判断，必须基于个人基准，而不是通用标准：

```
有些人天生皮肤电导偏高    → 不代表他们更焦虑
有些人说话天生语速快      → 不代表他们现在紧张
有些人的基准语调就偏硬    → 不代表他们在压制情绪
```

矛盾点检测的问题永远是：

**「这个通路现在的状态，和这个人自己的基准相比，有多少偏差？」**

不是和其他人比，是和他自己比。

---

### 实时权重动态调整

四个通路的权重不是固定的，根据情境动态调整：

```
用户在嘈杂环境    闻的噪声大，权重降低
用户在黑暗中      望受限，权重降低
用户刚运动完      切的生理基线偏高，需要校正
用户主动开启对话  问的权重提升，用户在主动表达
```

系统知道什么时候该信哪个通路，什么时候该降低哪个通路的权重。

---

## 九、四诊与个人基准的关系

四诊合参的判断，最终都要回到个人基准——

```
不是「这个人的心率高」
而是「这个人的心率比他自己的基准高了多少」

不是「这个人的语调偏硬」
而是「这个人今天的语调和他平时的语调有什么不同」
```

四个通路的基准都需要随使用时间建立：

```
切的基准    生理数据的个人基线
闻的基准    这个用户的正常语调、语速、呼吸节律
望的基准    这个用户的基础面部肌肉状态、瞳孔大小
问的基准    这个用户的典型表达方式和词汇选择
```

用得越久，四个维度的基准越完整，四诊合参的精度越高。

---

## 十、四诊和AI教练的配合

AI教练的所有判断，都建立在四诊合参的基础上：

```
教练说「你刚才扛住了」
    是因为切显示心率在那一刻有一个特定的变化
    望显示面部从紧绷到微微放松
    闻显示呼吸从浅变深
    三个通路同时指向「某个东西松开了」

教练说「今天不是好时机」
    是因为四诊综合显示用户当前状态低于基准
    不是凭感觉，是有数据支撑的判断
```

AI教练因为有四诊，才有资格说真话。

## 十一、未来：嗅觉通路的加入

当可穿戴嗅觉传感器技术成熟，「闻」的环境子系统可以接入：

```
气味传感器检测环境气味
    ↓
识别气味类型
    ↓
结合当前生理状态（切）和面部反应（望）
    ↓
判断这个气味是否触发了某种感受
    ↓
随时间建立个人气味-感受档案
    ↓
气味成为感受触发和感受识别的第五个通路
```

五诊合参，比四诊合参更完整。

这是Feelings感知体系的长期演进方向。
