# 定价模型：从免费出发，按需扩展

> 作者：qc
> 日期：2026-04-11
> 核心：感受民主化从硬件入门门槛开始

---

## 一、核心原则

```
感受的访问权不以价格区隔（GOVERNANCE红线）
但设备本身是有成本的，需要可持续的商业模式

解法：
    核心设备免费    降低入门门槛，让所有人都能进来
    扩展设备收费    按需付费，感受地图想走多远走多远
```

---

## 二、免费层：耳后设备

耳后设备是唯一必选设备，永久免费。

```
包含功能
    迷走神经刺激（情绪基调调节）
    心率采集
    基础皮肤电导
    音乐信号通路（AI生成音乐完整支持）
    基础安全监测

能体验的感受
    情绪基调类感受（平静/愉悦/低落方向性调节）
    音乐驱动的感受体验（完整）
    基础感受闭环（有限精度）
```

免费不是「残缺版」，是真实可用的起点。耳后设备单独使用，已经是一个完整的Feelings体验，只是感受地图的覆盖范围有限。

---

## 三、收费层：扩展设备

每个扩展设备独立定价，固定价格，不是指数递增。

**为什么固定价格，不是指数**

```
指数定价    每增加一个设备价格翻倍
            在某个节点让用户觉得「不值」而停止
            违背「渐进式接入」的产品哲学

固定定价    每个设备有自己的价格，代表它的真实价值
            用户按需添加，不被指数吓退
            更公平，更透明，和链上治理一致
```

**扩展设备价格（待定，需硬件成本确认）**

```
后颈设备    本体感受 / 姿态感知 / 体温运动采集
腕部设备    精确皮肤电导 / 细粒度情绪信号
颞部设备    认知状态 / EEG初步采集
飞行陪伴体  望+闻感知 / 陪伴存在感
触觉设备    长期扩展，价格待定
```

## 四、独立法人设备投资

感受民主化不是"把价格降下来"——是"把投资周期拉长"。

```
长久池用途 B    独立法人设备投资。
                设备不是消费品——是生产资料。
                和你买锅、买车、买电脑——同一逻辑。

不是补贴        不是"富人在捐，穷人在被补贴"。
                是"已经签了法人合约的人——
                给还没签的人——一笔设备贷款"。
                接住设备的人开始创作。分成。增值。
                存入者的钱增值了——不是慈善回报——是经济回报。

反馈闭环        被投资的人创造的创作分成回流长久池。
                接住设备的人——从此以独立法人身份站在 Feelings 的另一侧。
                多一个法人——整个生态的锚就粗一寸。    
```

## 五、首年探索：可能的变体

一个值得讨论的定价变体：

```
首年    耳后设备免费
        所有扩展设备首年免费试用（有时长限制）
        让用户先建立习惯，感受到价值

次年    按固定价格购买想保留的扩展设备
        不强制，用哪个买哪个
```

这个模式的逻辑：Feelings 的价值需要时间来感受。首年让用户真正知道扩展设备的价值，然后让他们做真实的购买决定，而不是在不了解的情况下掏钱。

---

## 六、与链上治理的关系

```
硬件收益    上链存证，进入分成体系
            扩展设备的部分收益流向感受包创作者
            部分进入存储池，用于低收入用户补贴

透明定价    定价规则上链，平台不能私自涨价
            价格变更需要治理宪章更新流程
```

---

*免费入门，是因为感受这件事对所有人都公平。收费扩展，是因为更广的感受地图需要更多的技术支撑。每一分钱，都花得理直气壮。*
