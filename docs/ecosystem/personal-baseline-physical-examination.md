# 个人基线建档体检——佩戴前的体检

> 作者：qc
> 日期：2026-08-12
> 性质：生态设计——入职有入职体检，佩戴 Feelings 前也有体检——个人基线建档
> 核心：冷启动从"零数据探索"升级为"有先验校准"——DXA/血液/病史单作为原始数据接入——安全阈值第一天个体化——医院合作三方共赢（医院获客/Feelings 获黄金数据/用户获筛查）——静态金标准初始化，动态 PBM 追踪趋势——互补不替代。

## 一、入职体检的类比——佩戴前体检

入职有入职体检。佩戴 Feelings 前，也有体检——个人基线建档体检。

```
入职体检：雇主在录用前——建立员工的身体档案——
          评估风险——决定岗位适配——
          入职后——日常绩效追踪

佩戴前体检：Feelings 在激活前——建立用户的身体档案——
           评估风险——决定安全阈值——
           佩戴后——PBM 日常趋势追踪

同一个结构：先建档——后使用——
    建档 = 先验数据（你是谁——出厂状态）——
    使用 = 动态数据（你现在怎么样——趋势）——
    先验初始化——动态追踪——
    没有先验——冷启动是零数据探索——
    有先验——冷启动是校准
```

## 二、冷启动的升级——从探索到校准

```
之前（零数据探索）：
    Session Zero——广谱采集——推荐系统同构——
    基线靠"猜"——安全阈值用通用默认——
    探索期长——个体化来得慢

现在（有先验校准）：
    佩戴前体检——原始数据直接接入——
    DXA（体成分金标准——测量成本可控）——
    血液检测（激素/代谢/炎症状态）——
    病史单（重大疾病/神经病史/家族遗传/过敏）——
    冷启动第一天就有：
        体成分基线（DXA 金标准）
        生化状态（血液）
        已知风险（病史——漏桶参数/安全阈值的个体化起点）
    ——基线建立从"探索"变"校准"——
    ——安全阈值从第一天就个体化——
    ——冷启动期缩短——模型从先验开始——
    ——不假装估算不是估算——但估算有真值锚
```

## 三、体检内容——黄金数据的构成

```
DXA 双能 X 射线（体成分金标准）：
    脂肪/瘦组织/骨骼——三成分——
    误差 2-4%——比 BIA 高一个量级——
    校准阻抗模型（AD5933 的阻抗→体成分公式
    用真值修正——通用估算变个体校准）

血液检测：
    激素（皮质醇/甲状腺/性激素——内分泌基线）——
    代谢（血糖/血脂——能量基线）——
    炎症（CRP——慢性炎症状态）——
    校准 PBM 的健康参数

病史单（必填——正式化）：
    重大基础疾病（心血管/神经/代谢）——
    神经类病史（癫痫/精神类用药）——
    家族遗传病（UserProfile 健康字段）——
    过敏史（影响可能的刺激类型）——
    目的：安全阈值个体化 + 责任边界清晰——
    （隐瞒病史导致的意外——Feelings 不担责——
     诚实申报——安全参数才准）

基础检查：血压/心率/身高体重——常规项——
    充实 UserProfile 的作息+身体字段
```

## 四、医院合作——三方共赢

```
医院（获客）：体检套餐导流——健康筛查业务——
Feelings（获黄金数据）：金标准数据接入——
    校准模型的真值——漏桶参数/安全阈值/PBM 初始化的
    个体化输入——
用户（获筛查）：一次体检——查病 + 拿数据基础——
    体检不白做——数据两用——

"从上往下"的咬合：
    医院合作 = 专业层合作（不是大众市场）——
    医院背书 = 权威背书的起点（识货者验证——
    医疗数据生态的位置——专业机构——
    从上往下的第一站）
```

## 五、边界——静态金标准与动态 PBM

```
体检数据（静态金标准——一次测量）：
    初始化——安全阈值/漏桶参数/模型起点——
    不是日常数据——是"出生档案"——
    "你出厂是什么样"

PBM 数据（动态信号——日常采集）：
    趋势——感受地图——基线的日常漂移——
    "你现在怎么样"

互补不替代：
    体检初始化起点——PBM 追踪变化——
    体检数据不能替代 PBM（静态不是动态）——
    PBM 也不能替代体检（趋势不是真值）——
    日常估算（随时——趋势）+
    定期金标准（每几个月——校准锚）——
    估算不越跑越偏（定期被金标准拉回）——
    像 GPS 差分校正——像传感器定期标定
```
