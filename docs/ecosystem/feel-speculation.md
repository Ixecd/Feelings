# FEEL 与炒作：不迎合、不拯救、不背锅

> 作者：qc（小姐钦定）
> 日期：2026-05-16
> 性质：对 FEEL 代币上线后炒作预期的正式立场
> 核心：让炒币的归炒币，让产品的归产品。他们要赌，我们不拦；我们要做的，是守住 FEEL 的功能灵魂，不被炒作带歪。

---

## 一、炒作不可避免，但这不是我们需要解决的问题

FEEL 一旦上线，必然有人跟风炒作。

这件事没有悬念——加密世界的重力就是：只要有一个地址、一个合约、一个可交易的东西，赌徒就会来。他们不看白皮书，不读文档，不在乎产品有没有用户。"区块链""代币""Web3"——看见这几个词就冲。

```
跟风炒家的人
    只想一夜翻倍、拉人头、割下家
    就算不炒 FEEL，也会去炒各种空气币、资金盘
    他们来不是因为我们，他们来是因为他们有这个需求
```

我们不需要阻止这件事——阻止不了，也不需要阻止。我们需要的是：**让他们炒他们的，我们做我们的。不迎合、不引导、不背锅。**

---

## 二、合规红线：FEEL 不是投资品

### 2.1 国内合规底线

```
明确禁止
    虚拟货币相关业务活动属于非法金融活动
    代币发行融资（ICO）是非法公开融资
    境内严禁发行、交易、炒作
    境外发币也不能向境内提供服务

FEEL 的合规定位
    不是投资品，不是炒作品
    只是 Feelings 生态内的功能凭证
    不承诺收益、不保本、不搞法币直接兑换
    只在合规框架下做海外合规主体 + 功能型通证
    严格限制境内参与
```

### 2.2 对外沟通的铁律

```
全渠道沟通规范

只讲    功能（感受包支付/存储计费/API 调用/设备激活）
       场景（创作者分成/社区贡献奖励/硬件激活燃烧）
       治理（无投票权/无分红权/无保本承诺）

不提    「投资价值」
       「升值」「赚币」「翻倍」「暴富」
       任何价格预期、投资回报相关的话术

所有对外界面强制风险提示：
    「FEEL 是 Feelings 生态功能积分，非投资品、非货币、
     无保本、无收益承诺，价格波动极大，炒作风险自担。」
```

## 三、结构防御：让炒作的火烧不起来

态度上划清界限只是第一步。结构上让炒作本身变得无聊，才是根本。

### 3.1 没有炒作燃料

```
燃料一：治理权     FEEL 不承载 → 持有再多也投不了票
燃料二：分红预期   FEEL 不承诺 → 没有"持币生息"的叙事
燃料三：机构控盘   FEEL 不预售 → 没有"庄家拉盘"的预期
燃料四：团队砸盘   5年线性解锁 + 首年悬崖 → 没法上线就卖
```

**炒作者来了，发现没有治理权可以争，没有分红可以吃，没有庄家可以跟——他们能做的只有纯博弈。纯博弈的周期很短，因为他们需要持续的燃料来维持叙事，而 FEEL 不提供这个燃料。**

### 3.2 价格和使用脱钩

这是最核心的防御设计——FEEL 的价格和用户的使用体验不直接相关。

```
用户买感受包   → 创作者用法币标价 → 系统锚定法币换算 FEEL
               → 即使 FEEL 价格暴跌，不影响用户的体验成本
               → 即使 FEEL 价格暴涨，创作者不会因此变贵

平台收运营费   → 按法币计价，FEEL 实时换算
               → 平台收入稳定，不暴露于币价波动

创作者分成     → 锚定法币结算
               → FEEL 是结算媒介，不是计价单位
```

极度悲观的情况——FEEL 在二级市场跌了 90%，Feelings 生态内的用户花销不受影响，因为计价锚定在法币上。FEEL 只是结算的管道，不是价值的锚。

极度狂热的情况——FEEL 被炒到天上，生态内的成本同样不受影响。炒作者的高价接盘和实际使用之间有一道防火墙。

### 3.3 结构式反投机机制

```
锁仓
    团队与顾问 5 年线性解锁 + 首年 12 个月悬崖
    生态激励逐批释放，不是一次性注入
    存储池动用需链上公告 + 用途说明

限购
    公售每人限额，实名认证
    防止巨鲸一次性吸纳大量流通

燃烧
    生态越活跃 → 燃烧越多 → 流通量减少
    但这不是人为的通缩叙事
    是使用量的副产品——有真实用户在花 FEEL，才有燃烧
    没有使用量的燃烧是在制造假通缩
    FEEL 不搞这个

透明
    所有代币分配链上可查
    所有燃烧链上可查
    所有团队解锁时间表公开
    流动性透明，定期公开链上数据
```

## 四、态度：不共情、不拯救、不背锅

结构做完了，剩下的就是态度。这条线必须划死，因为一旦松动，就会把自己拖进不属于我们的游戏。

### 4.1 不共情

```
有人追高买 FEEL，跌了，跑来骂项目方
    → 这是他自己的选择
    → 他买的时候，我们连产品都没让他看过一眼
    → 他不是冲着 Feelings 买的，他是冲着"会涨"买的
    → 我们不需要共情一个赌输了的赌徒

有人在群里说"你们项目方不管币价吗"
    → 不管
    → 币价不是我们的 KPI
    → 用户的感受体验质量才是
```

### 4.2 不拯救

```
币价暴跌时
    → 不护盘、不托价、不回购
    → 我们的钱是硬件收益和 ToB 收入
    → 不是拿来给炒家兜底的

有人做空 FEEL，发负面消息配合
    → 不搭理
    → 产品本身是对空头最狠的回击
    → 用户设备还在戴，感受包还在买，创作者还在赚
    → 那些数据链上透明，不需要我们"辟谣"

产品一天天在变好
用户一天天在感受
创作者一天天在发布感受包
燃烧一天天在进行

这就是我们该做的事。剩下的，让他们自己玩。
```

### 4.3 不背锅

```
被监管问询时
    → 白皮书、GOVERNANCE、本文档立即可查
    → 明确定位：FEEL 是功能凭证，不是投资品
    → 我们没有承诺过任何投资回报
    → 我们没有诱导过任何人以投资为目的购买
    → 那些炒作的叙事，不是我们制造的

被人索赔时
    → 使用协议 + 风险提示已经覆盖
    → 公售时用户勾选的不是「我同意投资」
    → 是「我理解 FEEL 是功能型通证，我不期望从中获利」

锅不在我们头上。我们从头到尾说的就是一样的话：
FEEL 是工具，不是炒具。
```

## 五、两类人：我们要的和不要的

### 5.1 真正该留的人

```
使用者
    用 FEEL 买感受包的人
    用 FEEL 做云端存储的人
    用 FEEL 激活设备的人
    他们不在乎币价，在乎这个感受够不够真

建设者
    上传感受包的创作者
    写文档、做翻译的贡献者
    开发周边工具的工程师
    他们 earning FEEL，而不是 buying FEEL
```

这些人不关心 FEEL 今天是涨是跌。他们关心的是 Feelings 今天又多了几个感受坐标，AI 教练今天又精准地推了一次，四诊合参的矛盾点检测又发现了一个被命名的情绪。

### 5.2 来了也会走的人

```
炒作客
    冲着「会涨」来的
    发现没有发财叙事，自己就走了

空气猎手
    闻着币味来，准备写小作文煽动市场
    被风险提示和合规框架直接晾在外面

围观看客
    等着看「又一个人死掉的代币项目」
    等到最后发现——产品活得好好的，用户一直在用
    他们对 FEEL 的需求不是投机需求
    是真实的使用需求
```

**炒家来去如风，产品和社区才是长久。**

## 六、最狠的回击：活下来

对炒家的命运，最狠的不是骂他们，不是救他们，不是评判他们——是**让他们自己走完自己的循环**。

```
他们冲进来 → 没找到发财叙事 → 有人赚了点走了
            → 有人亏了骂了走了
            → 有人自己割自己然后说是我们割的

我们呢
    → 设备还在卖
    → 感受包还在流转
    → 用户还在用
    → 创作者还在赚
    → FEEL 还在燃烧
    → AI 教练还在说「你今天在这里」
```

整个过程中，Feelings 没有配合过任何一个炒作叙事，没有哄抬过任何一个价格信号，没有挽留过任何一个明天就要走的人。

**等他们亏完骂完离场，我们的产品还在、社区还在、价值还在。这才是最彻底的回应——我们活下来，他们被淘汰。**

他们亏了，那是他的命、他的选择、他的因果。我们不救市、不托价、不护盘，只埋头做产品。

他们赚了走了，那也一样——跟我们没关系。赚了的人不是因为懂 Feelings，亏了的人也不是因为 Feelings 产品不好。因果全在他们自己。我们只做一件事：把产品做好。
