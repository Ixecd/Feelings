# 保险作为兜底：信息透明，不参与销售

> 作者：qc
> 日期：2026-04-20
> 状态：v0.1 初版（骨架已搭，细节待填充）
> 核心：神经接入有未知风险，保险是用户应有的兜底，但 Feelings 不卖保险

---

## 一、为什么要谈这件事

```
Feelings 的用户在做什么
    使用神经接入设备
    进入深度感受体验
    可能在某些极端体验里有未知风险

哪怕红线和安全机制做到极致
    意外仍然可能发生
        硬件故障
        个体生理差异
        罕见的神经反应
        长期使用的累积影响（5-10 年后才显现）
        其他不可预知的情况

负责任的产品应该
    不仅设计安全机制
    也提示用户考虑兜底
    把"如果真出事了"这件事说清楚
```

**保险不是免责声明，是真实的责任态度。**

## 二、Feelings 的立场

**这是这份文档最重要的一节。**

```
Feelings 不做的事

❌ 不与任何保险公司有商业合作
❌ 不接收任何保险推荐返佣
❌ 不基于用户的感受数据推送保险产品
❌ 不在产品内集成任何保险购买入口
❌ 不让保险成为新的盈利模式
❌ 不利用恐惧驱动用户购买
```

```
Feelings 做的事

✓ 提供独立的「保险讨论」信息页面
✓ 在使用契约里明确说明这件事
✓ 列出保险类型供用户参考
✓ 让用户自己去保险公司选择
✓ 公开声明 Feelings 不从用户的保险决策中获益
```

**核心原则：信息透明，不参与销售。**

## 三、建议考虑的保险类型

> [TODO] 这一节需要根据 Feelings 实际进入市场时的情况详细化
> 各国的保险产品类型和监管不同
> 当前给出的是原则性建议，不是具体推荐

### 3.1 医疗险

```
作用      覆盖医疗费用
适用      Feelings 使用过程中如果出现需要就医的情况
建议      用户有基础医疗险（社保 + 商业医疗补充）
```

### 3.2 意外险

```
作用      覆盖意外伤害和身故
适用      设备使用过程中的意外
建议      考虑包含"医疗器械相关意外"条款的版本
```

### 3.3 重疾险

```
作用      覆盖重大疾病
适用      作为长期保障
注意      和 Feelings 使用没有直接关联
         但作为人生整体保障是合理的
```

### 3.4 设备财产险（如果适用）

```
作用      覆盖设备损坏、丢失
适用      Feelings 设备本身的保护
注意      Feelings 设备的具体保险方案
         待硬件正式发售后会提供独立说明
```

## 四、不建议考虑的保险类型

```
❌ 专门"针对神经接入"的特殊险
    这种险目前不存在合规产品
    如果有人推销，很可能是骗局或营销陷阱

❌ 任何承诺"使用 Feelings 会获得理赔"的产品
    Feelings 不与任何保险绑定
    有这种宣传的，不是 Feelings 合作方

❌ 高佣金的"创新险种"
    简单医疗 + 意外 + 重疾基本足够
    复杂险种通常意味着高代理费，对用户不利
```

## 五、Feelings 信号的法律地位

**这是 insurance-baseline.md 里最重要的立场声明。**

```
Feelings 的感受信号

不构成医疗诊断
    Feelings 不是医疗设备
    四诊合参的信号是感受参考，不是临床诊断
    无法替代医院的检查结论

不构成保险法律意义上的「知情通知」
    Feelings 信号没有经过医疗机构确认
    在保险合同的「既往症」认定上没有法律效力

用户的义务
    在处理保险相关事宜时
    应遵循当地法律和保险合同的如实告知义务
    这是用户自己的法律责任

Feelings 的立场
    不提供任何关于保险申报的建议
    不介入用户与保险公司之间的任何事务
    这不是 Feelings 的职责范围
```

关于 Feelings 作为连续健康监测工具的完整立场，详见 `docs/health-awareness.md`。

## 八、为什么这件事容易做错

```
其他平台的常见做法

平台 + 保险公司合作
    "为你定制的专属保险"
    "Feelings 用户专享保障"
    返佣进入平台收入

为什么 Feelings 不能这么做
    一旦开始返佣，就有动机推销
    有动机推销，就会用恐惧驱动
    用恐惧驱动，就违反 Feelings 哲学
    把感受变成购买焦虑

这是一条滑坡
    从"提示考虑保险"
    到"推荐合适的保险"
    到"独家定制的保险"
    到"不买就不安全"
    
Feelings 在第一步就停下
```

## 十、给用户的话

如果用户读到这份文档，最想传达的是：

```
Feelings 在意你的兜底
但 Feelings 不卖保险
这两件事不矛盾

保险这件事
    你应该考虑
    但不应该从 Feelings 这里买
    去找独立的保险经纪
    或者你信任的保险公司
    自己做决定

Feelings 只负责
    把这件事告诉你
    不藏着不掖着
    不利用你的恐惧
    不从你的决策中获益
```
