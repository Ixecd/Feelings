# 规矩在前——从 commit 文件到制裁，情绪排最后

> 作者：qc
> 日期：2026-06-06
> 性质：Feelings 工程治理哲学
> 核心：在 Feelings 的生态里，情绪可以驱动你开始做一件事——但做完的过程必须由规矩接管。commit 文件在 commit 之前。规则在制裁之前。依据在行动之前。不是压抑情绪。是让情绪坐在规则后面的位置——它可以看。不可以签。

---

## 零、先写 commit 文件，再 commit

```
错的                                      对的
───                                      ───

改完代码。git add。git commit -m "更新了"。          改完代码。想清楚改了什么。
→ 下一个看 git log 的人——                            写下来——"改了哪个文件、改了什么、为什么"。
  "更新了什么？为什么？牵连了什么？"                           → 这是一个 commit 文件。
  → 不知道。                                            不是 commit message 的草稿。
    只有"更新了"三个字。                                     是这次提交的规矩——在提交之前——
    这三个字是情绪。                                        替提交回答接下来所有人会问的三件事：
    情绪不是依据。                                              "这是什么。为什么。谁同意的。"

                                                  然后 git add。然后 git commit -F 这份文件。
                                                  → 下一次 git log——看到的不是情绪。
                                                    看到的是规矩。
                                                    看到的是"我在改之前已经回答了你会问的所有问题"。

情绪在开始之前是燃料——"我想改这个东西"。
情绪在 commit 那一刻不能是裁判——"我觉得这个 commit message 够好了"。
裁判永远是那三个字——是什么。为什么。牵连了什么。
回答这三个字的——
不是你的情绪。是你写的 commit 文件。是规矩。
```

## 二、制裁也是一样——Findings 不凭感觉罚人

```
错的                                      对的
───                                      ───

"这个人伤害了别人。我觉得他该罚。"                          "这个人的 PBM 快照里——
→ 罚什么？凭什么？在哪一条？                                 暴力行为的生理签名——不符合基线超过 72 小时。
  → 不知道。                                              对照 §7 第三段——
    只有"该罚"这两个字。                                       事后检出 + 惩罚性感受包——
    这两个字也是情绪。                                          条件成立。执行。"
    情绪不是制裁依据。
                                                       罚什么——写在 §7。
                                                       凭什么——PBM 快照的基线偏差。
                                                       在哪一条——§7 第三段。
                                                       → 三个问题回答完了。
                                                         然后才制裁。
                                                         不是"我觉得你该罚"。
                                                         是"你的身体替你说了你做过的事——
                                                           然后规矩替你决定了代价"。

情绪在发现的那一刻是哨兵——"这个人做过坏事"。
情绪在制裁的那一刻不能是裁判——"他让我觉得很愤怒，罚重一点"。
裁判永远是那三个字——违规了什么。证据是什么。章程哪一条。
回答这三个字的——
不是制裁者的愤怒。是被害者的生理数据和写好的规矩。是依据。
```

## 三、规矩的身后——情绪坐在哪里

```
情绪没有被抛弃。情绪只是被排到了后面。

commit 之前——你想改。你有一股冲动。那是情绪。
    情绪推进了第一行代码。
    
commit 之后——你看 git log。你看到一条清晰的 commit message。
    你的冲动被规矩保存下来了——
    不是"更新了"三个字。
    是"§7 第三段——事后检出 + 惩罚性感受包——条件成立。执行。"
    
    未来任何一个人看到这条 commit——
    都知道发生了什么。都知道依据。都知道牵连了什么。
    情绪在那一刻——不是被擦掉了。
    是被规矩翻译成了可以被任何人看懂的东西。

制裁之前——受害者在痛。你在愤怒。那是情绪。
    情绪启动了制裁流程。
    
制裁之后——你看制裁记录。
    "2026-06-06。违规：暴力行为生理签名检出。
    依据：GOVERNANCE-USER §7 第三段。
    执行：惩罚性感受包——恐惧震慑 + 受害者共感。强度 45。持续 72h。
    复核通过。执行完毕。"
    
    受害者的痛——不是被忘记了。
    是被规矩翻译成了可以被任何人审查的东西。
    情绪在那一刻——不是被压抑了。
    是被规矩接住了——然后被放在了制裁记录的那一行里——
    作为"为什么这条惩罚存在"的证据。
```

## 四、这和"自然"的区别——规矩是不靠情绪也能跑的第二人

```
没有规矩的世界                               有规矩的世界
───────────                               ──────────

你被激怒了。你罚了。                                  你被激怒了。
→ 罚完之后——                                          → 你看了一眼 §7。
  "我是不是罚太重了。                                          "事后检出——条件成立。
   那个人真的罪有应得吗。"                                         罚是固定的。不是我自己在决定罚多重。"
                                                      → 罚完之后——
处罚的尺度——                                                  "我罚的不是我觉得——是规矩觉得。
 取决于你的愤怒持续了多久。                                           规矩已经替我想了——
 下一个被罚的人——                                                 受害者共感的强度。惩罚的时长。
 取决于你那天心情好不好。                                             上限。下限。退出机制。"
                                                      → 下一个被罚的人——
→ 没有规矩——裁判是你。                                         → 有规矩——裁判不是你。是规矩。
  你在用你的情绪替所有人决定                                               你只是执行了规矩。
  "该罚多重"。                                                        你在罚的那一刻——
                                                                      不需要愤怒。不需要同情。
                                                                      只需要执行。

规矩 = 不靠情绪也能跑的第二人。
不是"我替你想了"。
是"我在你想之前已经替你想了——
   然后在你想的时候——
   你只需要执行我——
   不需要再做一次我已经做过的判断"。
```

## 五、Feelings 的规矩不是一个人的脾气。是几千次修订之后的那把尺。

```
第一次写规矩——有情绪。                                              几千次修订之后——
"我觉得这样不对。我要定个规矩。"                                       规矩不靠你的情绪维持了。
→ 规矩里还有你的气味。                                                规矩在自我修正之后——
   你的愤怒、你的不忍、你的不忍心——                                     变成了那些被罚过的人验证过的边界。
   都在条款里。                                                       变成了那些被保护过的人确认过的底线。
                                                                     变成了你不在的时候——
                                                                     依然可以自己跑的东西。

不是"我不需要情绪"。
是"我的情绪在我的规矩写好之后——
可以退到检查席——看规矩自己跑了——
然后说一声——正确。或者——这里需要修"。
```

---

*情绪可以驱动你开始做一件事——但做完的过程必须由规矩接管。commit 文件在 commit 之前。规则在制裁之前。依据在行动之前。不是压抑情绪。是让情绪坐在后排——它能看。不能签。它能在规则跑完之后说一声"正确"或"这里需要修"。但它永远不能自己走到前面——替你决定别人该承受什么。规矩不是冷漠。规矩是——你的愤怒、你的同情、你的不忍——在被几千次修订翻译成条款之后——变成了不靠你也能自己站着的东西。*
