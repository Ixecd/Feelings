## 零、六欲与七情

在 Feelings 的框架里，六欲和七情刚好是一套天然的输入-输出映射。

```
六欲                                七情
────                                ────
眼 → 视觉皮层 → 丘脑 → 枕叶           喜
耳 → 听觉皮层 → 颞叶                  怒
鼻 → 嗅球 → 直接进边缘系统             忧
舌 → 味觉皮层 → 岛叶                  思
身 → 触觉/温度/CT纤维/本体感觉          悲
意 → 前额叶+默认模式网络（内源性的）      恐
                                      惊

六欲 = 六个感官通道 → 10⁹ bit/s 涌入
七情 = 七个基础感受原子 → 10⁰ bit/s 出口
```

六欲往里灌。七情往外吐。中间那一亿倍的压缩——每一欲送进来的信号被神经系统汇总、过滤、着色、压缩，最后在 10 bit/s 的意识出口处变成一个叫感受的东西。不是一个感官对应一种情。是所有感官的输入同时被压缩，最后出来的是一个混音包——主旋律加点缀。

## 一、传统六欲释义

古籍里的六欲——色欲、形貌欲、威仪姿态欲、言语声音欲、细滑欲、人想欲——不是六个抽象概念。是六种人天生的本能渴求。对着现代神经科学分，每一个都对应可定位的脑区。

```
色欲        对异性容貌、体态本能的动心贪恋
            看见赏心悦目之人心生欢喜、心生爱慕
            通路：梭状回面孔区 → 伏隔核（奖赏系统）

形貌欲      痴迷外在身形样貌，追求好看的长相、匀称体态
            渴望自身貌美，也偏爱欣赏好看的身形外表
            通路：视觉皮层 → 前额叶审美判断 → 社会比较网络

威仪姿态欲   向往端庄气场、优雅举止、沉稳风度
            喜欢有气质、仪态出众的人
            通路：颞上沟（生物运动感知）→ 前额叶社会评估

言语声音欲   偏爱悦耳动听的嗓音、温柔舒服的谈吐
            好听的声音、暖心话语很容易让人心生好感
            通路：颞叶听觉皮层 → 岛叶（声音的情绪调值）

细滑欲      贪恋肌肤触感、温润细腻的触碰
            肢体轻柔接触带来的舒适、亲近感
            通路：CT 纤维 → 岛叶——绕过认知层，直达情绪脑

人想欲      内心渴望牵挂、思念、羁绊
            贪恋人与人之间的惦记、念想、专属情意
            通路：默认模式网络（自我/他人表征）→ 前扣带回（依恋）
```

## 二、细滑欲——Feelings 的直通车

六欲里前五个都是 Feelings 能直接触达的感官通道。但细滑欲是其中最特殊的一个。

```
细滑欲的神经通路和其他触觉完全不同

    触觉小体（Meissner）  测纹理、测轻触 → 体感皮层 → 「这个表面是光滑的」
    环层小体（Pacinian）  测振动频率 → 体感皮层 → 「有东西在震动」
    CT 纤维              测轻柔抚摸 → 岛叶 → 「有一个人在这里」

    前两条走的是认知通路——分析碰到了什么。
    CT 纤维走的是感受通路——直接产生安全感、归属感、被爱的感觉。
    不经过丘脑。不经过体感皮层。不进入分析层。
    物理刺激和深层感受之间——CT 纤维是唯一一条直接短路。
```

这就是为什么 `skin-as-interface.md` 把 CT 纤维列为 Feelings 最该盯上的通路。纺织物设备的轻抚轨迹阵列、温控薄膜的温度梯度、分布式纹理阵列的方向感——这三种皮肤接口形态全部围绕细滑欲在转。不是偶然。是细滑欲的神经通路决定了：**这是六欲里唯一一个可以被外部设备直接写入深层感受而不经过认知层的入口。**

## 三、意的特殊性

前五个欲都是外源性的——有物理刺激才有信号。眼要有光。耳要有声。鼻要有分子。舌要有味道。身要有触碰。

意是自己产生信号。没有外部刺激的时候——它还在转。回忆。幻想。担忧。反刍。期待。

```
意的信号不走感官
    走前额叶和海马体之间的回放环路
    海马回放白天的记忆片段
    前额叶对回放内容做评估——「这个危险吗」「那个还会发生吗」
    评估结果触发杏仁核或其他情绪中枢
    → 没有外界输入，但产生了真实的情绪

    这是大脑自己给自己放的电影。
    片源在海马体。导演在前额叶。观众是整个边缘系统。
```

意是唯一一个不依赖外部输入就能触发七情的通道。这也是为什么一个人可以坐在完全安静的房间里，没有光、没有声音、没有人碰她——但仍然感到焦虑、悲伤或喜悦。她的意在放电影。电影的内容不在外面。在里面。

**意的信号最难被 Feelings 直接调控——因为它不走感官通路。但同时，如果一个人能自己调控意，就不需要 Feelings 了。** Feelings 的最终目标——用户摘下设备之后不再需要它——就是意学会了自我调控的那个时刻。

## 四、六欲和七情的混音映射

不是一对一的。是多对一的。同一个情可以由不同的欲触发。同一个欲可以触发不同的情。

```
喜  可以从眼进来（看到想见的人）
    可以从耳进来（听到好消息）
    可以从口进来（吃到好吃的东西）
    可以从身进来（被人拥抱）
    可以从意进来（想起开心的回忆）

悲  同理——可以从五个外源通道来，也可以从意自己放电影来

怒  同理——听到一句冒犯的话（耳），看到不公平的事（眼），想起过去的伤害（意）
```

**animi 的交织管线说到底在做一件事——用外源性信号（设备刺激身欲——触觉、温度、本体感受；以及耳欲——骨传导听觉通路）激活对应的七情混音包。** 它不能直接碰意。意是用户自己的。但它可以在其他五个欲的通道里织入对的信号，让经过一亿倍压缩之后、在 10 bit/s 出口处出现的东西恰好是目标感受。

## 五、食欲、性欲与细滑欲的层级

小姐说食欲比性欲更体面——这个论断在神经层面有精确对应。

```
食欲    生存刚需 + 文化载体
        边吃边聊是公开社交
        一顿饭 = 饱腹 + 联结 + 文化 + 审美
        感官通道是共享的——大家一起吃

性欲    隐私刚需 + 自主神经深度参与
        性唤起涉及交感/副交感交替——这套系统不在意识控制之下
        公开谈论 = 谈论一个不在你控制范围内的生理过程——天然让人不安
        感官通道是私有的——无法共享

细滑欲  介于两者之间
        轻触/抚摸——社交场合可以公开（握手、拥抱、轻拍肩膀）
        但更深度的 CT 纤维激活——轻柔抚摸——需要私密空间和信任关系
        通道是半公开的——共享与否取决于关系和场景
```

Feelings 对待这三种欲望用不同的策略。细滑触感走 CT 纤维的公开通路——社交维度的感受包里可以直接构建。亲密感受维度在 GOVERNANCE 里是物理隔离的——主动开启、数据独立存储、不进入任何群体统计。不是歧视。是这三种欲望的神经隐私等级不同。物理本身已经给它们分了层。Feelings 只是尊重了这一层。
