# PBM 与量子——同一个数学问题的两种求解器

> 作者：qc
> 日期：2026-06-04
> 性质：Feelings 数学基础
> 核心：PBM 不需要量子计算机来运行。但 PBM 要解的数学问题和量子计算擅长的数学问题是同一个类型——高维能量地形上的全局最优搜索。经典方法是手工调参的梯度下降加防抖看门狗，量子退火是让波函数穿透能量屏障直达全局最低点。VSA 超维计算和希尔伯特空间共用同一套数学语法。

## 零、PBM 的核心问题——在高维能量地形上找最低点

PBM 是一个四维超维向量——Visceral、Emotional、Tactile、Auditory。每一维都在不断偏移。每次 Session 结束后，anim 需要决定：

```
给定当前 PBM 状态向量 vₜ
给定本次 Session 的生理响应向量 rₜ
求最优步长 s = [sᵥ, sₑ, sₜ, sₐ]

使 vₜ₊₁ = vₜ + s × rₜ 落在"最低误差"的位置
```

"误差"在数学上是一个四维曲面。这个曲面有多个局部最低点——某些维度的噪声能造出一个看起来很低的假山谷——但全局只有一个最低点：用户真实的生理基线。

```
能量地形 = 四维误差曲面
    ↓
局部山谷 = 噪声造成的假收敛
    ↓             ← DampingMatrix 在防的就是这个
全局山谷 = 用户真实的基线
    ↓             ← 这才是 PBM 每次迭代真正想去的地方
```

---

## 一、经典方法——DampingMatrix 现在的做法

`pbm.rs` 里的 `DampingMatrix` 做的是一个手工调参的梯度下降加防抖看门狗：

```
经典梯度下降
    每一步沿着最陡的方向走
    → 容易被局部噪声带偏
    → 步长大了震荡，步长小了收敛慢
    → 需要手工调 learning rate

DampingMatrix 的防抖策略
    Emotional > 2.0× 步长 → 冻结 Visceral + Tactile
    Visceral   > 1.5× 步长 → 冻结 Emotional
    Tactile    > 3.0× 步长 → 不影响其他维度
    Auditory   > 2.0× 步长 → 不影响其他维度

    这不是"数学上最优"的解法。
    这是"在没有全局地形图的情况下，用启发式规则防止跑偏"的工程解法。
```

四维空间里手工维护一个 4×4 的冻结规则表——这是经典计算的极限。维度再多几倍（把基因组表达、脑网络拓扑、社会交互压力全放进来），这个手工表会指数级膨胀到不可维护。

## 二、量子退火——同一个问题，不同的求解器

量子退火的本质是：把解空间编码成一个能量地形，利用**量子隧穿效应穿过局部能量山的屏障**，而不是翻过去。

```
经典模拟退火
    温度高 → 有概率接受更差的解（跳过小山丘）
    温度降低 → 越来越贪心，只能往下走
    问题：遇到真正的高山丘（深的局部最优）时，跳不过去
    概率接受 ≠ 物理穿透——山太高就没办法

量子退火
    不是"概率跳到更差解"
    是"波函数穿透能量屏障"
    
    两个山谷之间隔着一座很高的山：
        经典方法 → 从山谷往上爬 → 爬到山顶 → 下到另一个山谷
                   代价 = 翻山高度。山太高就翻不过去。
        量子退火 → 波函数从山体中间穿过去
                   代价 = 屏障宽度（不是高度）。山再高，只要够窄就能穿过去。
    
    量子隧穿的概率 ∝ e^(-d√h)
    d = 屏障宽度，h = 屏障高度
    → 高度 h 的影响被开根号压住了——量子退火怕宽的山，不怕高的山
```

PBM 的收敛恰好是量子退火最擅长的地形：

```
PBM 误差曲面的特征
    窄而深的局部最优           ← 某个维度的一次瞬时噪声
                                 经典梯度下降直接掉进去出不来
                                 DampingMatrix 靠硬冻结挡住
                                 量子退火：波函数直接穿过，不进去
    宽而浅的全局最优           ← 用户真实基线的误差最低点
                                 经典方法走到了但不确定是否最低
                                 量子退火：遍历整个能量面后收敛在此处
```

**经典方法靠"别掉进去"。量子退火靠"从来没进去过"。**

## 三、VSA 超维计算——量子数学和 PBM 数学共用同一套语法

更深一层的关联在数学上。

Feelings 的数学母语是 VSA（超维计算）——用几万维向量做绑定、捆绑、相似度搜索。量子力学的数学母语是希尔伯特空间——用无穷维复向量描述系统状态。两者在结构上是同一套语言的不同实例：

```
量子力学                  VSA / PBM
────────                 ──────────
状态向量 |ψ⟩             高维向量 v ∈ ℝⁿ
叠加态                   PBM 四维同时偏移——不是"先调内脏再调情绪"
酉变换（量子门）           相似度搜索——一次向量操作，不是循环
纠缠                     跨维度阻尼——Emotional 的震荡不能独立于 Visceral 处理
                         两个维度在 VSA 空间里被捆绑在一起
                         和两个 qubit 的纠缠态是同一个数学结构
测量坍缩                  当前帧的生理数据"读出"PBM 的一个快照
                         PBM 在测量前是整个四维高维分布
                         测量把它坍缩为一个具体的步长更新向量
```

PBM 的四维不是四个独立的 float。它们在 `DampingMatrix::apply()` 里互相冻结、互相约束、互相定义——一维的震荡同时在改变其他三维的有效步长。这不是经典程序里"四个变量的独立更新"。这是**一个高维张量在时间轴上的一帧投影**——和量子态的一帧测量是同一个数学结构。

```
经典变量
    float visceral_step = 0.5;
    float emotional_step = 0.3;
    → 两行代码。两个独立的值。改一个不影响另一个。

PBM 矩阵
    [step_v, step_e, step_t, step_a]ₜ
    × DampingMatrix(Emotional > 2.0× → frozen_by)
    × ColdStartGuard(predictor_enabled)
    × DataConfidence(step_multiplier)
    → 四维互相约束。没有任何一维可以独立更新。
    → 这是一个高维空间里的约束优化问题。
    → 和量子态在被测量之前没有被任何一个基矢单独定义是同一个结构。
```

## 四、规模效应——什么时候量子退火从"可以加速"变成"唯一可行"

当前 PBM 是四维。DampingMatrix 靠 4×4 手工阈值表可以应付。但如果未来 PBM 扩展：

```
四维 PBM（当前）
    4×4 冻结表 → 手工可维护
    经典梯度下降 + 启发式防抖 → 91 测试已经验证

几十维 PBM（基因组 + 脑网络 + 社会压力）
    维度 × 维度的约束矩阵 → 手工不可维护
    局部最优数量指数级增长 → 经典方法百分之百困在假山谷
    DampingMatrix 的 4×4 手工表 → 完全不够用
    → 量子退火从"可以加速"变成"唯一可行"

几百维 PBM（全表观遗传 + 全脑区网络 + 全社交张量）
    经典算法连近似解都给不出来
    → 量子退火是唯一已知的能在合理时间内收敛的求解器
```

这不是猜测——是组合优化问题的规模复杂度决定的。四维的手工防抖规则表是一个工程解法。几十维需要的是一个能遍历整个能量面的求解器。几百维——经典计算机根本不存在能在宇宙热寂之前跑完的算法。

## 五、时间线——不是"现在用"，是"方向在那里"

```
现在（经典）                          未来（量子退火辅助）
─────────────                       ────────────────
DampingMatrix 启发式硬冻结           不需要冻结——量子退火天然找全局最低
4×4 阈值表手工配                     能量地形全局搜索——不需要手工参数
sigmoidal 手工调收敛曲线             量子隧穿自动穿过噪声屏障
PBM 在经典硬件上跑                   PBM 收敛计算可卸载到量子退火器

当前 PBM 四维 → 经典方法完全够用
未来 PBM N 维 → 量子退火从"可以加速"变成"本质不同的求解器"
不是替代。是扩展到了经典计算无法覆盖的量级。
```

这和 Anim v2.0 从 01 裸奔、Feelings 全栈从电子到感受——是同一类"长期方向"。知道终点在哪，不代表现在就要到。但知道终点在量子退火和 PBM 的数学结构天然匹配——说明这条路从一开始就没走歪。
