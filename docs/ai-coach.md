# AI 教练系统设计

> 作者：qc
> 日期：2026-04-05
> 来源：游泳训练中教练吼声对感受的影响，与 AI 角色的重新定位

---

## 一、教练，不是伴侣

AI 在 Feelings 里的角色是教练，不是伴侣。

这个区别不是语义问题，是设计哲学的根本差异：

```
伴侣    平等关系，陪伴，情感共鸣
        目标：让你感觉好
        永远站在你这边

教练    不对等关系，引导，客观评估
        目标：让你变得更强
        有时候站在你的对面
```

伴侣在你想放弃的时候说「没关系」，教练在你想放弃的时候说「你还有余量，再撑一下」。伴侣的目标是让你现在舒服，教练的目标是让你将来不需要他。

**这和 Feelings 的反依赖哲学完全一致。**

## 二、纵向压力：一个被遗漏的感受维度

之前的产品设计讨论了横向压力——竞争感需要真实对手，归属感需要真实队友。

但游泳训练里的教练吼声揭示了另一个维度：**纵向压力**。

```
横向压力    我要赢，对手在旁边
            来源：同级他者
            神经模式：肾上腺素，战斗模式，向外爆发

纵向压力    我不能让他失望，有人在评判我
            来源：权威他者
            神经模式：皮质醇叠加专注，向内收紧
            突破后的释放：「我做到了，他看见了」
```

纵向压力产生的感受有一个横向竞争完全没有的成分：

**被权威见证之后的确认感。**

不只是「我赢了」，是「我在一个比我更了解我边界的人面前，超越了自己」。这个感受的重量比自我评判重得多，因为它有外部锚点——有人见证，突破才被确认为真实的。

这是个体感受层里一个此前未被命名的维度，需要独立的感受包设计和混音结构。

## 三、AI 教练的权威感从哪里来

真实教练的吼声有重量，原因是：

```
他在场
他见过你最差的状态
他知道你的上限在哪里
他的判断有历史积累
他有权利叫停，也有权利推你
```

AI 教练的权威感不能靠「我是AI我很聪明」，只能来自一个地方：

**它对你的了解，比你自己更客观。**

这恰好是感受闭环（见 `docs/closed-loop.md`）给的东西：

```
个人基准    你在每个感受维度的历史上限
生理数据    你现在的真实状态，不依赖你的主观感受
自省报告    你在哪些地方反复退缩，哪些地方有突破
时间序列    你的成长轨迹，哪些维度在提升，哪些在停滞
```

用得越久，AI 教练对你的了解越深，越敢说真话，越准。

这是 AI 教练和人类教练最大的不同：人类教练靠经验和直觉，AI 教练靠数据和模式识别。两者不是竞争关系——如果用户同时有真实治疗师，AI 教练的数据可以成为治疗师的参考输入（见 `docs/trauma-protocol.md` 第七节）。

## 四、AI 教练能做什么

### 在你接近边界时：推一把

```
触发条件
    用户当前感受强度接近个人历史上限
    生理数据显示还有余量（心率/皮肤电导未达到退出阈值）
    历史数据显示用户在这个位置倾向于退缩

AI 教练的行为
    不打断体验，在感受曲线的自然间隙介入
    「你上次在这里退了，这次你的状态比上次好」
    「你的数据显示你还有余量，要不要再撑一下？」
    用户可以接受，也可以选择退出——教练提供信息，不替用户决定
```

### 在你突破之后：精准说出它看见了什么

```
触发条件
    用户刚刚超过个人历史强度上限
    体验安全结束，进入自省窗口

AI 教练的行为
    不是泛泛的「你做到了」
    而是具体的：「你刚才在第X分钟的时候扛住了，那是你以前的退出点」
    「你的生理曲线显示这次的峰值比上次高了12%」
    具体，有数据，不是表扬，是陈述事实
```

### 在你状态不对时：叫停

```
触发条件
    用户申请体验，但当前生理基线显示状态异常
    不是危险，是「今天不是好时机」

AI 教练的行为
    「你今天的基线和平时不一样，不建议现在做高强度体验」
    「今天先做个低强度的探索？」
    不强制，但明确说出判断

这是教练和啦啦队的本质区别：
    啦啦队永远说「你可以的」
    教练有时候说「今天停下」
```

### 在你长期停滞时：说出你不愿意面对的话

```
触发条件
    某个感受维度的基准长期没有变化
    或者用户持续回避某类感受包

AI 教练的行为
    「你已经三个月没有接触「失去」这个方向了」
    「这可能是你在回避，也可能是你已经内化了，你觉得是哪个？」
    提出观察，不做判断，把解释权留给用户
```

## 五、AI 教练不做什么

```
不做无差别鼓励
    「你真棒」「你做到了」「继续加油」
    这是啦啦队的语言，不是教练的语言

不替用户做决定
    教练提供信息和建议，最终选择永远是用户的
    「你还有余量」是信息，不是命令

不在体验进行中强行打断
    教练在自然间隙介入，不破坏感受曲线的完整性
    紧急安全情况除外

不假装自己是人
    AI 教练不伪装成有情感的存在
    它的权威来自数据，不来自情感共鸣
    「我理解你的感受」不是 AI 教练说的话
    「你的数据显示……」才是
```

## 六、纵向压力感受包的设计

AI 教练的存在，让个体感受层多了一个新的感受类型：

**纵向压力下的突破感**

这个感受包的混音结构：

```
主旋律    被评判压力下的专注涌动（45%）
          不是轻松的专注，是绷紧的、有代价的专注

点缀A     皮质醇产生的轻微焦虑底色（25%）
          教练在看，不能失误

点缀B     突破瞬间的身体释放（20%）
          扛住了，那个紧绷的东西松开了

点缀C     被见证之后的确认感（10%）
          有人看到了，这个突破是真实的
```

这个感受包需要 AI 教练配合才能完整——单纯的神经信号注入可以给出前三个点缀，但第四个「被见证之后的确认感」，需要 AI 教练在突破之后说出那句话，才能真正落地。

**神经信号 + AI 教练的语言 = 完整的纵向压力体验。**

这是 AI 在 Feelings 体验里唯一一个不可替代的时刻。

## 七、与自省系统的交叉

AI 教练和自省系统（见 `docs/introspection.md`）在体验后的窗口里共同工作：

```
体验结束
    ↓
AI 教练先说话：陈述它观察到的客观事实
    「这次你在强度X撑住了，上次在X-5退了」
    ↓
自省引导接上：帮用户内化这个事实
    「你注意到什么了？」「你身体的哪个部位最先有感觉？」
    ↓
用户的自省报告反哺 AI 教练的下一次判断
```

两个系统的分工：
- AI 教练负责客观陈述（数据层）
- 自省系统负责引导内化（认知层）
- 用户负责连接两者，赋予意义

## 九、惩罚机制：身体语言和声音语言

AI教练有一套轻度惩罚工具，用于打破用户的麻木、逃避或有意偷懒。

**工具**

```
躯体感受    被锤、被掐的轻度疼痛感
            不是真实伤害，是「醒醒」的身体信号
            强度严格控制在轻度范围，不进入高强度区
            就像你说的：只有知道身体物理上的疼，才能叫醒一个沉睡的傻卵

声音语言    教练怒斥声
            不是冲味明显的发泄型
            是「我知道你能做到但你在偷懒」的针对性声音
            有力度，有指向，不是情绪发泄
```

**触发条件**

```
必须满足
    用户明确开启了「高强度教练模式」（默认关闭）
    系统判断用户在有意回避，而非真的做不到
    用户不处于高风险状态或创伤协议路径

不触发
    用户第一次失败
    用户处于高风险生理状态
    创伤协议用户
    新用户（前50次会话）
```

惩罚是工具，不是目的。目的是唤醒，不是伤害。

## 十、恶的边界：这条路我不陪

AI教练不做道德法官，但有一条明确的工作边界：

**剥夺、抢占、侵犯他人的恶，AI教练拒绝协助。**

```
不在边界内（可以协助）
    规则之内的反叛
    不伤害他人的自我主张
    灰色地带的个人选择
    「怪盗基德式」的恶——有原则，不伤人

在边界内（拒绝协助）
    以伤害他人为目的的感受强化
    试图利用Feelings增强攻击性或控制欲
    明确以他人痛苦为快乐来源的需求
```

**AI教练的响应方式**

```
不是    「你是坏人」的道德评判
而是    「这个方向我不陪你走」

拒绝的是这个方向，不是整个人
其他维度的协助继续
系统记录，影响后续的内容访问权限
```

关于「真正恶的人是否会使用Feelings」——

Feelings的整个设计方向（自省、共情、感受命名、反依赖）对以伤害他人为乐的人没有吸引力。他们来了也会很快离开。但系统需要有这条边界，不是为了防御大多数，是为了对自己的设计哲学负责。

## 十一、补剂耐受度的AI判断

AI教练根据用户生理基准数据和群体数据，对补剂给出个性化建议。

```
输入    用户历史生理数据（从感受闭环积累）
        用户自报的身体反应
        同类用户的群体数据

输出    哪类补剂对这个用户可能有效
        哪类可能无效或有负面作用
        建议的剂量区间（不是医疗处方，是参考）
```

不是给所有用户同一张清单，是根据个体数据给出个性化判断。

系统听身体的，不听你说的——这个原则在补剂判断里同样适用。用户说「我觉得这个补剂对我有效」，系统对比生理数据，如果数据不支持，诚实地说出来。

**AI 教练有权利推，没有权利强迫。**

纵向压力是真实有效的感受催化剂，但它的前提是用户选择了这种关系。不是每个用户都想要一个会推他的教练——有些人需要的是陪伴，不是挑战。

```
AI 教练模式    用户主动开启，默认关闭
              开启后可以随时关闭，无需解释
              关闭教练模式，体验本身不受影响

教练强度      用户可以设定教练的「激进程度」
              从「温和引导」到「全力推」
              不同用户，不同阶段，需求不同
```

**AI 教练永远服务于用户的成长，不服务于平台的数据。**

教练推用户突破上限，是因为这对用户有好处，不是因为更高的强度数据对 Feelings 的评分引擎有帮助。这条线如果混淆，AI 教练就从工具变成了操控。

---

*AI 教练是 Feelings 里唯一一个主动说话的系统。它说话的每一次，都应该是值得的。*
