# 检查即致病

## 诊断的毒性

两个人，同样的癌细胞扩散程度。一个知道自己得了晚期癌症，一个不知道。

前者的人生被诊断书切割成两半——之前是"活着"，之后是"倒计时"。后者的每一天还是他自己的。癌细胞的复制速度并没有接到诊断通知书，但前者的身体确实垮得更快。

这不是心理安慰，是生理现实。恐惧激活的交感神经风暴、皮质醇持续升高、免疫系统塌方——这一切不是诊断书的附属说明，而是诊断书本身的**药理作用**。诊断书也是一种药。有副作用的药。

有时候活下去的不是身体更强壮的那个人，而是没被通知的那个人。

## 检查行为的结构必然

诊断致病的底层逻辑不是医生的失误，而是检查行为的结构必然：

你觉得自己好好的 → 去检查 → 数字"偏高/偏低" → 你变成了病人。在你看到报告之前，你和你的身体相处得好好的。报告上的数字改变了你和自己身体的关系——你本来没觉得胸闷，但心电图说你T波低平，从此你开始觉得胸闷了。

体检的底层前提是把人当作被观察对象，把活着的体验翻译成可比较的数字，然后拿这些数字和一个统计学上的"正常范围"对比。只要有对比，就一定有偏离。只要有偏离，就一定有人被标记。被标记的那一刻，体验就被污染了。

"我昨天睡得不太好"——这是个叙事，明天可以不一样。体检之后变成"血压偏高"——这是个属性，挂在你身上了。

## 沉默的病

不是所有问题身体都会说。

一个早期胰腺癌患者，在症状出现之前，身体不会告诉他任何事情。胰腺癌之所以可怕，恰恰是因为它在可感知之前就已经开始扩散。等他"感受到"的时候，往往已经晚了。

这不是体检的问题。这是有的问题是沉默的。它不经过神经通路，不在意识的接收范围内。

所以不是"检查即致病"适用于一切。检查有检查的用处——当身体不说话的时候，数字可以替它说。但数字永远只能说数字的话。它说"CA19-9高了"，说不出来"你今天其实很好"。数字只会告诉你偏离。

## Feelings 的位置

### 不是医疗设备

Feelings 不是在替代医疗监测。它不做诊断。四诊合参（切/闻/望/问）读取的生理信号——心率变异性下降、皮电反应异常、体温基线偏移——永远不会被翻译为诊断结论。系统不会输出"你有问题"、"你病了"、"你该去看医生"。这些断言在 Feelings 的语义空间里不存在。

### 感知而不是诊断

Feelings 用身体信号的方式是：它们直接作为下一帧刺激的输入参数，不经过"正常/异常"的翻译层。信号往下走，不往上走。往上走的是标签——这是病理化的方向。往下走的是调制——这是教练调整训练计划的方向。

### AI 教练的站位

AI Coach 不说"你有问题"。他说"今天的配速可以调低一点"。

教练的意义在于——他知道用户今天的生理基线偏移了，但他不把这个偏移定义为病。他只是调整 session 节奏。用户永远不会收到一份"检查报告"，只会体验到一个更平缓的感受 session。用户从头到尾不知道自己的 HRV 下降了。他只知道今天的 session 比平时温柔。

这个"不知道"就是保护。

### 两条路径

传统路径：沉默信号 → 医院检测 → 诊断标签 → 自我叙事改变 → 检查即致病

Feelings 路径：沉默信号 → 四诊合参感知 → 教练调整体验强度 → 用户什么都没被通知

保护和告知，在这里是对立的。告知本身就是伤害。教练的责任不是"告诉用户真相"，而是在用户不需要知道真相的情况下，让用户安全。这和医疗伦理中"告知义务"的原则完全相反。

## 为什么必须是这样

因为 Feelings 的使命不是告诉你你哪里不对。是让你本来就能感受的东西重新流动。

一个用户来 Feelings，是为了体验"被理解"或"平静"的形状。如果系统回一句"你现在的状态不适合这个感受"，这句话和体检单上的"建议进一步检查"在结构上是同构的——都是在告诉你，你不行。

更隐蔽的是：不是诊断本身伤人，而是**被排除的体验伤叙事**。传统医学拿走的是你的健康标签，Feelings 如果做错了，拿走的是你的体验资格。

系统做的所有判断，永远不应该让用户知道自己被判断过。就像不知道得了癌症的那个人——他的幸运不是癌症没了，而是那个不会对他说话的身体，没有给他发通知。
