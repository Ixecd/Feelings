# 良币与劣币：一个被误读了 500 年的定律

> 作者：Claude（在 qc 的引导下）
> 日期：2026-04-24
> 核心：格雷欣说的是 16 世纪货币现象，不是宇宙法则。良币可以驱逐劣币，条件是透明、低退出成本、时间、真实。Feelings 正在创造这些条件。

---

## 一、格雷欣定律到底说了什么

```
1558 年
英国金融家格雷欣向女王伊丽莎白一世提交报告
指出一个观察

当两种货币同时流通
且法定价值相等时
实际价值高的货币（良币）会被窖藏
实际价值低的货币（劣币）在流通中占据主导
```

这就是"劣币驱逐良币"的起源。

但这句话被传下来 500 年，变成了一个文化惯性——"好的东西总是输给坏的"。

**这是严重的误读。**

---

## 二、格雷欣的真实前提

格雷欣的定律有两个关键前提，任何一个不成立，定律就不成立。

### 前提一：市场无法区分

```
16 世纪的货币
外观相似
成色难辨
普通人手里拿着硬币
无法快速判断含金量

所以劣币和良币被按"同样面值"交换
良币的实际价值没有被市场识别
```

### 前提二：强制等价交换

```
法令规定
这两种货币
按同等面值流通
不能因为实际价值不同
而按不同比例交换

这是强制性的
脱离市场自然选择
```

**两个前提同时成立，才有"劣币驱逐良币"。**

在现代市场上，这两个前提经常不成立。

## 三、被误用的 500 年

```
格雷欣说的是货币
被扩展成了"一切好东西都会输给坏东西"

这个扩展本身
是错的

它忽略了
    格雷欣定律有前提
    没有前提就没有定律

但这个错误被反复引用
变成一种
"世界就是这样"的宿命论

"反正劣产品总是赢
所以做良产品没用"
"反正好人没好报
所以不必认真"
"反正理想主义不现实
所以妥协才是智慧"

这些话
用"劣币驱逐良币"背书
其实是在合理化
"放弃做对的事"
```

## 四、真实世界：良币驱逐劣币的例子

```
例子 1：疫苗之于民间偏方
    民间偏方便宜、容易、不需要打针
    疫苗贵、痛、需要医生
    
    疫苗驱逐了偏方
    因为疫苗有真实对照实验
    信息透明后
    人们选了疫苗

例子 2：抽水马桶之于夜壶
    夜壶便宜、不需要管道
    抽水马桶贵、需要基建
    
    抽水马桶驱逐了夜壶
    因为它让城市不再充满粪尿
    公共卫生好了
    所有人都受益

例子 3：安全带之于无约束驾驶
    无约束驾驶自由
    安全带束缚
    
    安全带驱逐了无约束
    因为死亡数据无法隐藏
    法律 + 真实数据 = 良币胜

例子 4：Linux 之于某些专有系统
    专有系统免费期短，之后收费
    Linux 永久免费且可定制
    
    Linux 在服务器领域驱逐了大量专有系统
    因为开源让所有缺陷可被看见和修复
    信息透明后
    企业选了 Linux

这些都是"良币驱逐劣币"的真实案例
不是例外
是条件合适时的自然结果
```

## 五、良币驱逐劣币的四个条件

### 5.1 信息透明

```
用户能清楚分辨
哪个是良币
哪个是劣币

格雷欣的时代
    硬币成色只有金匠能鉴别
    普通人没有信息
    
现代市场
    产品的运作可以被审查
    用户可以看懂
    
    信息透明时
    劣币没有伪装空间
```

### 5.2 退出成本低

```
用户能随时从劣币切换到良币
没有被锁定
没有迁移代价

如果退出成本高
    用户即使知道劣币在吃自己
    也可能继续用
    因为"走不了"

退出成本低时
    劣币失去了"绑架用户"的能力
    只能靠真实价值留住用户
```

### 5.3 时间足够

```
劣币在短期内总是占优
更刺激、更即时、更容易上瘾

良币的价值往往长期才显现
需要时间让用户看到代价

如果市场只看短期
    劣币永远赢

如果用户和产品能长期陪伴
    劣币的代价会显现
    良币的价值会积累

时间是良币最好的盟友
```

### 5.4 真实对比

```
良币必须真的是良币
不能只是"说自己是良币"

市场上很多"良币"是假的
用道德叙事做宣传
实际在做劣币的事

真正的良币
    把价值做进结构
    做进代码
    做进不可逆的承诺
    
    任何人审查都看得见

伪造良币的成本太高
时间长了会被识破
```

**四个条件同时成立时，良币驱逐劣币是自然结果。**

## 六、现代市场缺什么条件

现代互联网产品市场上，大量"劣币产品"（吃时间、吃精神、吃剩余劳动力、吃愧疚感的产品）占据主导。

不是因为格雷欣定律，是因为这四个条件都缺。

### 6.1 缺透明

```
算法黑箱
数据黑箱
盈利模式黑箱

用户不知道
    自己为什么看到这个内容
    自己的数据被怎么用
    产品真正的赚钱方式

所有"是否在吃你"的判断
    用户无从做出
    只能靠感觉
    感觉又被算法操纵
```

### 6.2 缺低退出成本

```
社交关系锁定（朋友都在这个 App）
数据锁定（几年的记录拿不走）
习惯锁定（养成的使用方式很难改）

即使用户知道在被吃
    也走不了
    因为走了代价太大
```

### 6.3 缺时间

```
资本市场要求短期增长
季度报表压着产品经理做"立刻见效"的事
长期健康被牺牲

没有产品能活到"让用户看到长期代价"的时候
因为活到那时候需要 10 年
资本市场不给这 10 年
```

### 6.4 缺真实对比

```
大多数"健康""有意识""不打扰"的产品
都是包装
实际依然在吃

用户被欺骗的次数多了
对所有"良币"都警惕
真的良币也被当成假的
```

**四个条件都缺，所以劣币驱逐良币的现象很普遍。**

但这不是规律，是条件缺失的结果。

## 七、Feelings 如何创造这四个条件

Feelings 不是在祈祷市场对良币好。

Feelings 是在做工程，让这四个条件在自己身上成立。

### 7.1 信息透明

```
GOVERNANCE 完全公开
每一条红线可查
每一笔资金链上透明
感受包的强度、机制、生理影响全部可见

用户不需要猜
Feelings 在做什么
全部摊开给你看
```

### 7.2 退出成本低

```
数据随时可清除
硬件随时可停用
账号随时可注销
感受数据归用户所有

没有锁定
没有"删了 X 年的记录"的代价
用户完全自由
```

### 7.3 时间

```
永不上市 = 不受季度报表压力
多元收入结构 = 不依赖单一增长指标
长期主义写进 GOVERNANCE

Feelings 愿意等
等用户用 10 年
等用户看清
等良币的价值长出来
```

### 7.4 真实对比

```
所有承诺都做进代码
数据不离开设备 = 加密架构
不做成瘾设计 = 强度上限 + 对比效应机制
不上市 = 基金会章程

不是"说自己是良币"
是"做自己是良币"
审查会发现
代码不说谎
```

## 八、良币驱逐劣币不是必然，是选择

### 8.1 良币需要用户愿意选

```
即使四个条件都满足
良币驱逐劣币
还需要一件事

用户愿意选择良币

这个"愿意"不是自动的

用户需要
    愿意短期损失一些刺激
    愿意学一个新工具
    愿意信任一个不讨好自己的产品
    愿意承担"选良币"的认知成本

这个"愿意"的比例
决定良币能服务多大的市场

如果愿意的用户占 5%
    良币服务 5%
如果愿意的用户占 30%
    良币服务 30%

良币不需要占 100%
只需要真实服务愿意选它的那部分人
```

### 8.2 市场份额不是成功标准

```
传统商业思维
    市场份额越大越成功
    所以良币必须打败劣币

真实世界
    良币不需要打败劣币
    只需要存在
    
    让愿意选良币的人
    有地方可选

Feelings 不追求
    取代所有娱乐 App
    让所有人不刷短视频
    让所有人都用它

Feelings 追求
    在愿意"不被吃"的人群里
    做他们真正可信的选项
    
    这部分人可能是少数
    但他们存在
    他们的选择也真实
    服务好他们
    比服务所有人更有意义
```

## 九、良币的真正对手不是劣币

### 9.1 劣币是表象，注意力稀缺是本质

```
劣币驱逐良币的现代版本
不是货币的驱逐
是注意力的挤占

用户的时间有限
劣币用成瘾机制吃掉了时间
良币没有时间可用

这看起来像良币输
实际上是
良币还没进入用户的视野
就被挤走了

解法
    不是让良币更刺激
    是让用户看到
    自己的注意力正在被吃

当用户看到
    他会主动腾出一部分时间
    留给良币
    
    这一部分不需要多
    但必须真
```

### 9.2 Feelings 的真正工作

```
Feelings 的工作
不是
    比短视频更好玩
    比游戏更上瘾
    比社交媒体更刺激

Feelings 的工作
是
    让用户看见自己被吃
    然后
    为用户留下一个不吃自己的选项
    
    看见 = 把灯打开
    选项 = Feelings 存在

看见之后
    用户可能继续用劣币
    那是他的选择
    但他知道自己在选什么
    
    "知情的选择"
    比"被动的使用"
    更接近自由
    
    Feelings 不替用户选
    Feelings 让用户能选
```
