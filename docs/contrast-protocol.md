# 对比协议：盲选强度与反差感受设计

> 作者：qc
> 日期：2026-04-05
> 来源：对期待污染问题的直接回应

---

## 一、问题起点：期待污染

Feelings 面临一个核心悖论：

用户打开应用，比如选择"韧性，强度 6"，点击确认。
在信号到达之前，"我即将感受到韧性"这个认知已经激活了一套神经预期框架。
用户接收到的，不是纯粹的信号，而是信号叠加期待之后的混合物。

这不是用户体验问题，是信号污染问题。

一个对照：同样是经历极端压力，知道自己接下来面对什么的人，和毫无预备直接进入的人，神经底层的接收状态是完全不同的。前者的防御、预判、应激在刺激到来之前就已经激活；后者的神经系统处于中立底层，感受直接落在未设防的地方。

**期待本身会改变神经底层。这是 Feelings 必须处理的第一个信号干扰源。**

---

## 二、设计方案：盲选强度

解法是把控制权一分为二，拆开给不同的主体：

```
用户控制：强度上限（我愿意被带到多深的地方）
系统控制：感受内容（那个地方是什么）
```

用户唯一的输入是强度封顶，比如 6。
至于这次体验装载的是平静、恐惧、失去还是成就感——不知道，系统决定。

这个设计同时解决了几件事：

- **期待污染消失**：用户没有"我将感受到 X"的预激活框架，神经底层保持中立
- **体验变成探索**：不是消费一个已知名字的产品，而是被带往未知的地方
- **强度本身的语义改变**：不再是"我要感受多强的韧性"，而是"我愿意去多深，但不知道那里是什么"

这个设定本身就在塑造一种特定的初始神经状态：开放、轻微不确定、无防御激活。这是接收感受信号的更干净的底层。

---

## 三、核心机制：反差

盲选的副产品是反差。

当系统不需要迎合用户期待，它可以选择给出与用户当前状态**彻底相反**的感受。这不是噱头，是感受密度最大化的有效路径。

神经科学的对比效应：感受的强度不只取决于信号本身，取决于它与当前基线的落差。

```
冷水在热水之后，更冷。
沉默在噪音之后，更深。
失去在满足之后，更有重量。
```

反差是感受的放大器。

这也悄悄改写了 Feelings 的核心命题。不只是"让你访问没有经历过的感受"，而是：

**让你感受到自己当下状态的边界在哪里。**

你在哪，系统把你推到对面去。那个对面不是目的地，穿越的过程才是产品。

---

## 四、版本迭代逻辑

### v1：纯随机

感受内容在强度上限内随机分配。

**优点**：实现简单，无需生理数据，零配置上手
**目标**：验证盲选模式的用户接受度，收集感受反馈数据
**局限**：反差不受控，可能在错误时机给出错误方向的感受

---

### v2：基于当前生理状态，给出彻底相反的感受

设备实时采集用户当前生理基线（心率、皮肤电导、呼吸频率等），
系统判断当前状态坐标，然后在强度上限内选择方向最远的感受注入。

```
用户当前：高度紧张、警觉亢奋
→ 系统选择：深度平静、放空

用户当前：低能量、情绪平淡
→ 系统选择：专注涌动、成就感激活

用户当前：孤立内缩
→ 系统选择：归属感、开阔的本体感受
```

**优点**：反差被精确化，感受密度最大化
**技术依赖**：生理传感器实时数据 + 状态分类模型

---

## 五、安全边界：扩展 vs 击穿

反差设计有一个必须正视的极端情况：

"彻底相反"在大多数状态下是扩展，但在某些临界状态下可能是击穿。

```
用户当前：解离性麻木（情绪系统关闭的自我保护态）
对面方向：强烈的悲伤
结果：不是唤醒，可能是触发创伤闪回
```

所以 v2 的生理状态检测承担两个完全不同的判断任务：

```
判断 A：现在的基线在哪里？（决定给什么）
判断 B：现在的状态是否适合接收任何反差刺激？（决定能不能给）
```

同一套传感器数据，两套判断逻辑，两个都不能省。

**判断 B 的输出不是内容选择，是通行证**。没有通行证，系统降级到"平静保底包"，不注入任何反差，只提供一个稳定的中性锚点。

这个边界检测是 v2 的技术难点，不是伦理附加题。

---

## 六、悬而未决的问题

**不确定性本身是否也是可调的？**

盲选模式创造了不确定性，但用户对"不知道接下来是什么"的耐受度也是个体差异极大的变量。有人在不确定里开放，有人在不确定里焦虑——后者的期待污染可能从"期待特定感受"变成了"期待恐惧"。

这是一个还没有答案的设计问题，记录在此。
