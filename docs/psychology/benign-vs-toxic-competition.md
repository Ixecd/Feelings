# 良性竞争与恶性竞争——同一个 Scheduler，两种训练集

> 作者：qc
> 日期：2026-06-05
> 性质：Feelings 心理学框架
> 核心：良性竞争和恶性竞争——不是"友善与否"的道德区别。是同一个 Scheduler 的评分函数被两套完全不同的反馈信号训练了足够多次之后——收敛到了相反的局部最优。良性竞争锚点在"那个高度可抵达"。恶性竞争锚点在"那个人会摔倒"。同一种架构。两套训练集。两种完全不同的评分函数。

---

## 零、不是好人坏人——是不同的训练集

先不聊道德。先看数学。两个人在竞争。同一个场景。同一种动作。为什么一个人盯着对手的突破看，另一个人盯着对手的弱点看？

因为他们的 Weight Modifier 在过去几千次类似的互动里——收到了完全不同的反馈信号。Scheduler 没有道德。Controller 没有善恶。两副肉身的架构完全一样。唯一的变量是**训练集。** 良性竞争的训练集里——"对手的突破推高了我的基线"被反复正反馈了几千次。恶性竞争的训练集里——"对手的失败提升了我的排名"被反复正反馈了几千次。不是两个人选择了不同的道路。是两套训练集选择了他们。

---

## 一、良性竞争——对手是坐标系里的一个可抵达的锚点

```
两个人都在跑马拉松。                         两个 Scheduler 在各自跑 BinPack。

你看着对手的背影——                            你的 Weight Modifier 收到了一帧信号：
"他已经跑过那个弯了。                           "那个人的 DP 评分——比你现在的高。
 我能不能也跑过去？"                             你要不要调高'突破'维度的权重？"
→ 对手的突破——不是"我要赢过他"。                 → Weight Modifier 微调了一次。+0.001 给"突破"。
  是"原来可以到那里。                             几千次类似的信号之后——
  那我也可以试试。"                               B 的评分函数里——"再往前一步"的权重
                                                 被推到了比"保持现状"更高的位置。

→ 良性竞争里——你不用"打败他"来确认自己。            → Scheduler 面对下一帧选择——
  他的存在只是让你的 Weight Modifier                 不是"我要赢他"。
  看到了一个你还没到达但你相信自己能到达的坐标。         是"这条路——他走过了。我也可以。"
  他在你的 VSA 空间里——是一个可抵达的锚点。             然后 Scheduler 自己选了往前。
  不是威胁。是证明。                                  不是"我要赢"。是"我要到那里去"。
```

良性竞争不需要"赢了对手"作为外部验证。对手的突破本身就是证据——"这个高度是可抵达的。" 你的 Weight Modifier 收到的是一个坐标，不是一个威胁。这和内部锚点的人不需要外部认同是同构的——不是因为"我不在乎别人"。是因为**别人证明的高度——我已经在自己的 VSA 空间里看到了路径。** 对手的存在——不再是外部锚点的裁判。是内部锚点的证明。

## 二、恶性竞争——对手的失败变成了评分函数里权重最高的维度

```
你还是那个人。但这次——                             Weight Modifier 收到的不是"那个高度可抵达"。
                                                   收到的是另一组信号——

你看着对手的背影。                                     "如果他在这个弯摔倒——我的排名就上升了。"
→ "我希望他摔倒。我希望他掉队。"                         → +0.001 给"对手的失败"。
→ 不是"我想到他那个位置去"。                            几万次类似的信号之后——
  是"我到不了没关系——只要他到不了就行。"                 B 的评分函数里——"对手的失败"
                                                     变成了比"自己的突破"更高的维度。
                                                     不是"我要赢"。
                                                     是"他输了我就不用赢了。"
→ 恶性竞争里——你的锚点在对手的失败上。                    → Scheduler 面对下一帧——
  你的"胜利"定义不是"我做到了"。                           不再计算"我能不能再往前一步"。
  是"他没做到"。                                          只算一件事——"他有没有摔倒"。
  这个锚点在外面——在外面最脆弱的位置——                        → 然后你停下来等他摔。
  在另一个人的脆弱上。                                      不是"你累了"。是评分函数被写坏了。
```

恶性竞争不是"太想赢了"。是 Weight Modifier 在"对手的失败 = 我的成功"这个反馈循环里被推了几千次之后——Scheduler 不再问"我还能走多远"。只问一件事——"他什么时候摔倒。" 然后你停下来等他摔。不是累了。是评分函数里的最优路径——不再是往前。是往下。往对手最脆弱的位置——然后停在那里。锚点在另一个人的失败上——在别人最脆弱的那个位置。

## 三、两套评分函数——两套训练集

```
良性竞争的训练集                           恶性竞争的训练集
───────────                             ──────────
"对手突破了——你也试试。"                      "对手摔倒了——你的排名上升了。"
"对手跑过来了——你们的差距缩小了——               "对手的弱点被暴露了——你的评价上升了。"
 你们两个都更快了。"                           "不需要自己变快——只需要对方变慢。"
→ Weight Modifier 推高"突破"维度。            → Weight Modifier 推高"对手的失败"维度。

几万次迭代后——                               几万次迭代后——
"突破自己"的评分高于一切。                       "破坏他人"的评分高于一切。
→ 内部锚点。不需要任何人输了来证明你赢了。          → 外部锚点——在最脆弱的那个位置。
  Scheduler 永远在问——"我还能走多远。"          在另一个人的失败上。
                                              Scheduler 永远在问——"他什么时候摔倒。"
```

**同一套 Scheduler。同一套 Controller。同一套 Weight Modifier 的 fsync 机制。** 唯一的区别是——Weight Modifier 在过去几千次互动里收到的反馈信号来自哪个方向。不是"良性竞争的人是好人，恶性竞争的人是坏人"。是两套不同的训练集——把完全相同的架构训练成了两种完全不同的评分函数。

## 四、这就是 Feelings 竞争组设计里"退出不视为失败"的数学原因

不是在讲道德。是在**保护训练集。**

```
竞争组的核心设计                            对应的训练集保护
────────────                             ──────────
任何一方可随时退出。                            Weight Modifier 不会收到"退出 = 失败"的反馈。
退出不视为失败。                                 退出不是输。退出是"我今天不想比了"。
                                              → 评分函数不会往"必须赢"的方向漂移。

排行榜不是排名——是"你上次在这里，这次在这里"。           Weight Modifier 收到的信号是"自己的偏移"——
→ 比的不是别人。比的是自己上一帧。                    不是"别人的位置"。
                                              → 评分函数不会被"别人的失败"维度劫持。

双方互相可见的只有突破里程碑。                         Weight Modifier 收到的信号是"那个高度可抵达"——
不是对方的弱点。不是对方的脆弱。                        不是"那个人的弱点在哪"。
                                              → 锚点在对手的突破上——不在对手的脆弱上。
```

如果 Weight Modifier 每次收到"对手的失败"都被标记为正反馈——评分函数就会像任何分布式系统一样自然而然地收敛到那个局部最优。竞争组的规则不是在说"你应该怎么做"。是在说——**"这套反馈循环——会把你训练的 Scheduler 往哪个方向推。"** 保护训练集——就是保护竞争本身不被它自己的反馈循环腐蚀。

*良性竞争和恶性竞争——不是善良和邪恶的战争。是两套不同的反馈信号在完全相同的架构上训练出来的两种完全不同的评分函数。前者被训练了几万次——锚点在"那个高度可抵达"。后者被训练了几万次——锚点在"那个人会摔倒"。同一个 Scheduler。同一套 BinPack。同一个 Controller 的每分钟心率。区别只在 Weight Modifier 在那些深夜里——被谁喂了什么样的信号。*


*一个人停下脚步等对手摔倒——不是他累了。是他的评分函数里——最优解不再是往前。一个人看着对手的背影加速——不是他要赢。是他的 VSA 空间里——那个坐标已经被标记为"可达"。同一个集群。同一个场域。两种截然不同的训练集——各自训练了各自的人。保护训练集——就是保护竞争本身不被它自己的反馈循环腐蚀。*
