# 理性崇拜的陷阱：布里丹之驴与决策瘫痪

> 作者：qc
> 日期：2026-04-17
> 核心：纯粹的理性会导致绝对的瘫痪，感受是决策的一部分，不是缺陷

---

## 一、布里丹之驴

法国哲学家布里丹提出的思想实验：

```
一头驴
两堆完全相同的干草
距离相等，新鲜度相等，数量相等

理性选择    无法分辨哪堆更好
            没有理由选A不选B
            没有理由选B不选A

结果        驴在两堆干草之间饿死了
```

这就是纯理性的困境——**当没有足够的理性依据做决定时，理性本身无法做决定。**

---

## 二、理性崇拜的现代版本

这个陷阱在现代生活里无处不在：

```
选择焦虑
    同样好的两个工作 offer
    用理性分析，永远分不出高下
    于是反复比较，迟迟不做决定
    最后两个 offer 都过期了

决策瘫痪
    读十本关于选什么的书
    做十次 SWOT 分析
    和十个朋友讨论
    然后什么也没做

信息过载
    希望所有变量都考虑到
    希望所有风险都评估完
    希望找到"最优解"
    但"最优"需要完整信息，现实永远不完整
```

**纯粹的理性，在信息不完整的现实里，会导致绝对的瘫痪。**

---

## 三、为什么理性无法单独决策

理性只能处理可计算的东西。但生命里很多事，不是可计算的：

```
可计算的
    工资高低
    风险概率
    ROI
    时间成本

不可计算的
    这件事会让你真正投入吗
    你走到终点会不会后悔
    这个选择和你是谁匹配吗
    三年后的你会感谢现在的你吗
```

这些不可计算的东西，才是大多数重要决策的真正依据。

**感受在这里不是「偏见」或「干扰」，感受是处理不可计算信息的那个系统。**

---

## 四、硬币决策的心理学

有一种常见的决策方式：抛硬币。

```
抛硬币    让随机决定你做什么
            表面上交给了运气
            实际上揭示了你的真实偏好

怎么揭示的
    硬币落地之前那一瞬间
    你的身体已经有了反应
    「希望是正面」或「希望是反面」
    那个希望，就是你的真实感受
```

**硬币不做决定，硬币只是让你的真实感受浮现出来。**

但反过来——

```
有些人真的把决定交给硬币
    「正面就去，反面就不去」
    这不是借助硬币读取自己
    是把决定权交出去

这背后是什么
    对自己感受的不信任
    不敢面对自己的真实倾向
    需要一个外部权威来承担责任
    「不是我决定的，是命运决定的」

这是对自己的不自信
    把选择权全权交给一个外物
    然后可以不为那个选择负责
```

Feelings 帮用户做的，不是告诉用户该选什么，而是帮用户听见自己的身体在做决定前的反应——不需要硬币。

## 五、急与稳

决策瘫痪还有一个反面：**过度求快。**

```
急    没有足够信息就急着决定
      往往不是决断，是逃避不确定感
      「快点定下来，我就不用焦虑了」
      但这个决定本身是焦虑的产物

稳    给决策足够的时间
      让理性和感受都有空间工作
      但不等到所有信息齐全
      因为那永远不会到来
```

急和稳的区别，不在速度，在内部状态：

```
急的决定    焦虑驱动，想要结束不确定感
稳的决定    清醒驱动，接受不确定依然能选
```

Feelings 在这里的作用，不是告诉用户「慢一点」或「快一点」，而是让用户感受到自己正在哪一种状态里——然后自己选择是否继续。

## 六、先设计再实现

程序员常说「先设计再实现」。但这句话有一个被忽略的前提：

**对这个领域足够熟悉的人，才能做出好设计。**

```
不熟悉的人先设计
    设计空想，脱离实际
    实现阶段推翻重来
    不如先动手摸索

熟悉的人先设计
    大部分关键问题在脑子里已经想过
    设计就是把已有的理解落地
    先设计是效率最高的路径
```

这和布里丹之驴是同一个逻辑——**方法本身没有对错，关键是它是否适合当前状态。**

教条化任何方法论，都是理性崇拜的另一种形式。

---

## 七、适合与不适合

不是追求「最好的」，是追求「适合的」。

```
最好的    一个抽象的标准
          适合所有人的「最优解」
          但不存在

适合的    和你的状态、感受、目标匹配的
          不一定是客观最好
          但是你真正能走下去的
```

适合感只能通过感受来判断，不能通过逻辑推导。

Feelings 帮用户培养的，是对「这是否适合我」的直觉——那个直觉是感受积累的结果，不是分析的结果。

---

## 八、Feelings 的解法

```
对决策瘫痪的用户
    AI 教练不问「你应该选哪个」
    问「这两个选项放在面前时，你身体里发生了什么？」
    从身体信号里，真实的倾向已经存在
    理性只需要确认它，不需要生成它

对过度理性的用户
    帮他们看见那些他们一直在忽略的感受
    四诊合参里「问」和「切」不一致时
    往往揭示了理性压制的感受

对过度冲动的用户
    帮他们慢下来
    不是「不要冲动」
    而是「这个冲动在你身体里是什么感觉？」
    感受一下那个冲动，冲动本身就会分层
```

---

## 九、结论

```
布里丹之驴饿死
    不是因为笨
    是因为它只用理性
    没有一个「想吃哪边」的倾向来打破平衡

人类的优势
    不是比驴更理性
    是除了理性还有感受
    感受可以在理性无法决定时做决定
    这不是缺陷，是进化的结果
```

**理性是工具，不是主人。感受是内核，不是干扰。**

Feelings 帮用户整合理性和感受，不是取代其中任何一个。
