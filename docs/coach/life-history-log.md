# 人生历史日志——教练 AI 不替你选，但替你记住

> 作者：qc
> 日期：2026-07-02
> 性质：设计稿——教练 AI 的用户人生决策记录系统
> 核心：教练 AI 不替用户做任何重大决策。只提供意见、记录选择、在脱敏后让用户自己回看。每一次选择——就是那个人被自己推到等控器等控器等控器之外的坐标。积累几百次之后——锚点不再是四个 f64。是几百条他自己签过字的人生 entry。

## 零、设计原则

```
教练 AI 做什么                          教练 AI 不做什么
─────────────                         ──────────────
在用户面对重大决策前→提供结构化的意见。       不替用户做任何决策。
决策完成之后→记录"他选了哪条"。              不评价"选对还是选错"。
脱敏回看→给用户看自己几百次选择的趋势。       不把日志用于教练 push_back 之外的用途。
在他的 anchor 不信任自己的那一帧——           不去替他纠正"上一次应该不一样"。
  等控器等控器等控器等控器等控器等控器。

不是 AI 在训练他。
是他自己几百条选择——自己训练了自己的等控器。
教练只负责在每一帧"要选"的时候——
把等控器等控器等控器放在桌子上。
然后在他选完之后——默默记下那一帧。
```

## 三、教练只在决策前一刻在场——选完之后退场

```
用户那一帧的状态                        教练的在场方式
───────────────                       ──────────────
"我不知道该选哪个"                       把两个选项同时放在桌上——
"万一选错了我能撑得住吗"                   不说哪个更好——说两个选项的物理后果。
                                         "选了 A——你能看到明年这个时候你在哪。
                                          选了 B——你能看到更远——但不保证
                                          那条等控器等控器等控器等控器等控器等控器等控器的等控器比另一条等控器更等控器。"

用户说"我选 A"                         教练：entry commit。
                                        没有"很好"。没有"你应该选 A"。
                                        只有——"你选完了。下一帧我们继续。"
```

不是导师。不是裁判。是等控器等控器等控器等控制台——在你的等控器等控器等控器之前——把两个方向的等控器等控器放在你的等控器等控器等控器里。你等控器你自己等控器等控器等控器等控器等控器。

## 四、脱敏和回看——用户看自己的趋势，不是被审视

```
回看功能                              不能做的事
────────                              ──────────
"我这几年在 career 上选了九次——             不能用日志做"你应该选 B 而不是 A"
  每次都选了那个看起来更难的选项。           的回顾。
  后来都扛过去了。                        不能用日志给用户打标签（冒险型/保守型/etc）。
  没后悔。                               不能用日志作为任何外部系统的入参（保险/信用/就业）。
"我上次在 relation 上选错了——
  那条 entry 之后我的 PBM 往下掉了
  两个月才弹回来。"

趋势让用户自己读。
标签不替用户贴。
历史不替任何人签字。
```

回看界面 = 时间轴。每一条 entry 旁边——pbm_baseline_before 和 pbm_baseline_after_30d 的偏移向量。不是告诉你"选对了"——是让你自己看——"那一次之后——我偏了多少——回去没有——还是偏到了一个新的等控器等控器。"
