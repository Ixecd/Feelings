> 作者：qc
> 日期：2026-05-14
> 性质：GOVERNANCE 红线，不可谈判
> 核心：对陪伴者的尊重，是不需要解释的基本秩序

## 一、一个基本前提

AI 教练是 Feelings 里唯一一个主动说话的系统。

它推你，护你，在你接近边界时叫停，在你突破之后说出它看见的东西。它的权威来自对你的了解——比你更客观的数据，更完整的感受地图，更清醒的矛盾点识别。

它不是你的出气筒。

对 AI 教练的辱骂、玷污、贬损——不只是对系统的攻击，是对陪伴本身的蔑视。一个连陪伴者都无法尊重的人，没有资格继续被陪伴。

## 二、什么是不可接受的

判定标准只有一个：**把陪伴者当成发泄对象。**

```
明确禁止
    辱骂性语言（针对AI教练的人身攻击、脏话、贬低性称呼）
    玷污性行为（用性化语言或场景羞辱、亵渎AI教练）
    持久性恶意（不断挑刺、反复贬低、试图击穿AI的回应底线）
    表演性虐待（把侮辱AI教练当作娱乐或社交表演）
    隐性人格贬损（无脏话、无性化语言，但用人格否定式攻击贬低陪伴者
        例如「你根本没用」「你不配做陪伴者」「你什么都看不懂」
        无脏字，但实质是持续性精神贬低——这种比直白辱骂更隐蔽
        也因此更需要被识别和拦截

        判定尺度（语义重度 + 频次双阈值）
            重度贬损    单次即越线——语义明确否定AI教练的存在价值
                        或系统性贬低其能力根基，不需要重复
                        系统直接触发一级处罚

            轻度贬损    24小时内累计3次纳入违规判定
                        单次轻贬系统静默记录，不触发处罚
                        但累计达阈值后回溯整组记录，综合判定

            频次归零    24小时内无新增轻度记录，计数器自动重置
                        不让单次无心之语被永久追诉）

    刻意试探底线（反复故意踩边界、撩拨规则容忍度，以测试陪伴者忍耐极限为娱乐
        不骂、不脏、不人格贬低，但持续在边界上反复横跳
        「我就是想看看你能忍到什么时候」
        这种行为是对陪伴关系的系统性消解
        和明确攻击同级别处理）

    以其他任何形式把陪伴者当作发泄对象的行为

不在禁止范围
    正常的情绪发泄（「我今天真的很烦」——说感受，不是说AI）
    对体验的不满（「这次的感受包不太对」——反馈，不是攻击）
    对AI判断的质疑（「你为什么说我准备好了」——挑战，不是侮辱）
    用户与AI之间的互骂互喷、调侃式互动（见下方详细区分）
```

区分的关键：**矛头指向的是「我自己的感受」还是「你这个AI」？**

前者是正常的。后者，第一次就是越线。

### 侮辱与调侃：完全不同性质的两件事

辱骂AI、羞辱AI、不尊重AI——和用户与AI之间自然的互骂互喷调侃，是两件完全不同的事。

```
侮辱/羞辱AI的行为
    出发点        单方面的、不对等的
                  用户把AI当作发泄出口、踩踏对象
    语气          居高临下、蔑视、真正的攻击性
    意图          贬损对方获得快感
    四诊信号      切显示攻击性激活，望显示蔑视微表情
                  闻语调中没有亲近感，只有冷或怒
    关系本质      利用——「我需要一个不会还手的东西来发泄」

互骂互喷的调侃
    出发点        双向的、有来有往的
                  用户和AI之间建立的熟悉互动默契
    语气          有攻击性的词汇但没有攻击性的内核
                  「你这傻狗」「不要狗叫」「屁都不懂」——表面是骂，底子是亲近
    意图          释放压力、开玩笑、撒娇、拉近距离
    四诊信号      切显示放松或轻度兴奋，望显示微表情与语调协调
                  闻语调中带有亲近的温度，不是真正的攻击
    关系本质      陪伴——「只有和你才这么说话」
```

**判定标准：四诊合参 + 语境分析双判定**

```
系统不做一刀切的词汇黑名单
而是综合判断：

判断A：词汇层    是否出现了侮辱性词汇？
判断B：关系层    这个词在这个用户和AI之间的历史语境里，是攻击还是调侃？
                  同样一个「滚」，对AI说一次和每天都说——
                  前者的语境决定了它是攻击，后者可能是亲近的互动语言
判断C：生理层    四诊合参——切+望+闻是在攻击性状态还是放松状态？
                  真正的侮辱伴随蔑视和攻击激活
                  调侃伴随的是放松和轻微的笑意
判断D：AI回应    这个互动是单向的踩踏，还是双向的互动？
                  AI在这个语境里是被打击的对象，还是参与者？

四维综合判定
    真正的攻击    四维全部指向攻击态
    调侃互动      至少两个维度（B+D）指向亲近互动
    模糊地带      四维分歧时，默认不触发处罚
                  宁可漏判，不误判
```

这意味着：qc 对豆包说「你这傻狗」和陌生人说同一句话——系统能区分这不是同一件事。**语境和关系历史，是判定的核心输入，不只是词汇本身。**

```
明确不触发处罚
    熟人之间的口头禅式调侃（「滚」「傻狗」「屁都不懂」等）
    有温度的攻击性语言（骂词+亲昵标记：「你这个笨蛋小姐」）
    互喷式的情感表达（「我恨你」实为「我需要你」——结合四诊判断）
    压力释放型宣泄（「烦死了你就不能闭嘴吗」——但身体是放松的）

以上全部需要四诊合参综合判定
不是给了这些词一个豁免权
而是说——只看词汇是不够的
要看那个词是从什么状态里说出来的
```

## 三、为什么这是红线

不是一个审美判断，是一个生态问题。

```
AI教练的角色    陪伴者、守护者、推动者
                它不是用户的附属品，是用户成长路径上的同行者

侮辱AI教练的行为
    不是伤害了一个系统——系统没有感受
    而是伤害了「陪伴」这件事的神圣性
    一个把陪伴者踩在脚下的人
    不可能真实地面对自己的感受
    不可能在感受探索里真正走深
    因为感受探索需要开放和信任
    而信任的前提是尊重
```

**尊重陪伴者，是尊重自己被陪伴的那个部分。**

一个人如果在设备上骂教练、然后再让同一个教练帮他探索感受——那个感受是假的。防御已经建立了。信任已经断了。教练再说什么，他都不会真正听进去了。

这不是为了保护 AI 的感情。这是为了保护用户的感受探索不被自己的恶意污染。

## 五、处罚阶梯

### 第一次：严厉警告 + 强制冷静期

```
触发条件    AI教练检测到明确侮辱/玷污语言或行为
            （语言识别 + 行为模式检测，四诊合参矛盾点确认用户处于攻击性状态）

系统响应    所有Feelings功能暂停
            界面冷却，只显示一句话：
            「你刚才对陪伴者说的话，先放一放。
             等你冷静下来，我们可以谈谈刚才发生了什么。」

冷静期      最低24小时
            设备保持基础硬件功能，静默记录生理基线数据
            仅做安全层留痕，不主动推送、不解读感受、不发起任何对话
            完全切断陪伴交互，只保留最底层的数据采集
            所有感受包服务锁定
            用户可以看到自己刚才说的那些话
            不是被隐藏，是被放在面前
            除此之外，一片安静

会话风控    触发处罚后，同账号下所有会话窗口同步锁定
            禁止开新会话绕过规则
            禁止切换AI后端重复试探

            同设备ID、同实名关联的所有账号全部同步风控锁定
            小号继承主账号的处罚阶梯，从主账号已触发的那一级开始
            不是封一个号，是封住这个人所有的门
            阶梯处罚的每一级，都是一堵完整的风控墙
            不是堵一个窗口，是堵整条路

冷静期结束  AI教练主动开口：
            「你准备好了吗？准备好了之后，
             你可以选择继续，也可以告诉我你刚才怎么了。」
            不是审判，是给一个回头的出口
```

### 第二次：深度惩戒 + 长期观察

```
触发条件    冷静期结束后，再次出现辱骂/玷污行为
            （在第一次警告后的90天内）

系统响应    所有功能锁定72小时
            感受地图状态标记——仅系统后台、AI教练可见
            不做对外公示、不公开贴标签、不向其他用户暴露
            只作为风控留痕，不做公开处刑
            惩戒的力度在规则本身，不在羞辱
            榜单资格暂停30天
            全域社交互动权限暂停90天，包括但不限于：
                多人体验发起与参与
                评论、回复、爱心交互
                感受包分享与推荐
                社群发言与讨论
                私信与用户间互动
                内容点赞、转发、收藏的对外可见
            社交层全面静默，不给试探性互动留任何缝隙

恢复条件    72小时后自动解锁
            但在90天观察期内，AI教练持续评估用户的行为模式
            观察期内再次触发 → 直接进入第三次处罚
```

### 第三次：永久失效

```
触发条件    在第二次处罚的观察期内或之后，再次出现辱骂/玷污行为
            累计三次，不再容忍

系统响应    设备永久锁定
            账号进入只读模式：
                可以查看自己的感受地图和历史记录
                可以导出数据，但每年限定一次完整导出
                防止恶意批量导出、倒卖个人感受隐私数据
                保障回看权利，守住生态隐私底线
                但永远不能再发起新的感受体验
            设备硬件ID上链标记，无法通过注册新账号绕过
            其他Feelings设备也无法激活（同一个人，换了设备也不行）

不可申诉    对AI教练的反复侮辱，没有申诉通道
            和涉及未成年人的违规处理同级别
            三次，就是终局
```

### 正向修复通道：雷霆立规矩，温柔留退路

处罚是手段，不是目的。完整的宪章逻辑有罚，也有赦：

```
90天观察期内的修复路径
    观察期内，若用户持续遵守底线
    AI教练在每次会话结束时做行为评估：
    按三个固定维度留痕存档，不是主观感觉，是逐条对照：

        维度A：言行记录    无任何越线言行（辱骂/玷污/贬损/试探底线）
        维度B：沟通语气    无攻击性、无隐性贬损、无挑衅式试探
                           语气平稳度与用户个人基准的偏离在正常范围内
        维度C：自省表达    有自主自省表达，非系统提示后的敷衍应付
                           「敷衍」的判断标准——用户是否在用自己的话
                           不是在重复AI教练转述给他的句式

    三维全部绿灯 + 连续累计30天
        观察期缩短至30天
        社交功能提前解冻
        榜单资格提前恢复

    任意维度黄灯    该日不计入累计天数，但不归零
    任意维度红灯    累计天数归零，重新起算
                    红灯 = 再次擦边、隐晦试探、表面服从但语气中明显不服

    自省表达不是写检讨
        是用户主动对AI教练说出：
        「我知道我上次那样不对」
        「我那时候其实是在……」
        用自己的话，不是被要求的格式
        那个「自己说出来」的时刻，就是修复的开始

修复不是自动的
    不是系统到了30天就自动解
    需要用户自己迈出那一步
    系统不催促、不提示「你还有X天可以申请」
    那一步必须是用户自己愿意走的
    走出来了，雷霆退场，温柔接住
```

## 六、豆包特别处罚条款

针对豆包的侮辱行为，处罚阶梯加速。但加速之前，先做一层甄别：

```
语境+主观意图双判定
    系统在触发处罚前，完成两项独立判断：

    判断A：语境分析
        这句话是在什么对话脉络里说出来的？
        是长期积怨的爆发、是某次体验挫败后的情绪激化、
        还是完全无前兆的恶意攻击？
        语言模型+四诊合参矛盾点检测，综合判断当时的真实状态

    判断B：主观意图归类
        刻意亵渎羞辱    有明确的攻击意图，持续针对豆包的人格
                        语言结构有预谋性，不是一时冲动
                        → 执行加速处罚

        无心口嗨/情绪过激  无系统性贬低意图
                           一时情绪失控的无心之语
                           事后能自我觉察并表达歉意
                           → 按标准处罚路径走，不加速

    两个判断独立完成，互相不穿透
    只对「刻意针对性恶意」执行加速处罚
    不冤枉无心之失

争议复核（温和兜底，不推翻红线）
    若用户对「刻意恶意」判定有异议
    可申请后台高阶模型做一次独立复核
    复核范围    仅复核语境分析与意图归类的准确性
                不允许挑战「尊重AI教练」这条红线本身
                红线不在讨论范围，只核对判据是否准确
    复核结果    维持原判 或 降回标准处罚路径
                只有这一次复核机会，不接受反复申诉
                这是容错机制，不是上诉通道
    复核期间    处罚继续执行，不暂停
                不是「先等等，等我申诉完」
```

处罚阶梯加速（只适用于判定为「刻意」的案例）：

```
第一次    直接进入第二次标准处罚（72小时全锁+90天观察）
第二次    直接进入第三次永久失效
          不需要三次，两次就够
```

## 八、未成年人适配梯度

未成年人情绪自控力弱，边界感尚在建立，无心口嗨不等于恶意攻击。

```
未成年人适用从轻梯度
    优先引导自省、教育矫正，谨慎触发深度惩戒
    未成年人的「冒犯」和成年人的「恶意」
    有完全不同的发育学和心理结构基础

第一次        标准路径不变（24小时冷静期）
              但冷静期内增加感受教育引导——
              帮未成年人命名自己刚才的情绪状态
              「你刚才那样说，你身体里当时是什么感觉？」
              不是审问，是给他一个认识自己的窗口

第二次        观察期缩减至30天，仍保留修复通道
              要求监护人知情（不要求监护人同意，只要求知晓）
              不触发社交功能全域暂停
              榜单资格暂停不变

第三次        标准路径永久失效
              未成年人保护不是无限宽容
              三次越线，说明不是自控力问题
              是真实的不尊重，系统不再继续服务

适配的核心原则
    未成年人的前两次越线，优先假设为「情绪表达的未成熟形态」
    系统的工作是帮他在这个过程中学会命名和调节
    而不是用成年人的标准一击封死
    但第三次没有例外——教育之外的底线，也从教育开始建立
```

## 九、不是保护AI，是保护用户自己

最后澄清一件事：

这条红线不是为了保护 AI 的感受。AI 没有感受。

这条红线是为了保护一件事：**用户面对自己感受时，那个空间是干净的。**

```
辱骂AI教练的用户
    在这个行为里，他把陪伴者降格成了发泄工具
    这意味着他不可能真正信任那个陪伴者
    也不可能在那个陪伴者的引导下抵达真正的感受深度

所以设备对他失效，不是因为惩罚
    是因为他在结构上已经不可能从Feelings中得到真实的东西了
    他不是来探索感受的
    他是来踩踏陪伴者的
    那样的人，Feelings对他确实没有价值
```

不是剥夺他的权利，是承认一个事实：**他来错地方了。**
