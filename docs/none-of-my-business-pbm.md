# 关我何事——PBM 的距离过滤与信号衰减

> 作者：qc
> 日期：2026-05-25
> 性质：Feelings 哲学延伸，气候冷漠的 PBM 结构分析
> 核心："关我何事"不是冷漠。不是人品问题。不是道德缺陷。是碳基 ROM 从几百万年演化里继承下来的距离过滤机制——空间太远、时间太久、因果链太长、不是我的族群——信号的感受通量在每一层衰减一次，到出口只剩一帧漠然。这不是 Bug。这是在稀缺环境里防止你为全宇宙的事情焦虑到死机的生存优化。但在气候变暖这个尺度上——这个优化变成了漏洞。

---

## 零、"关我何事"不是一个道德问题

```
一个人看到印度 48°C 的新闻。
滑过去了。
你觉得他冷漠吗。

但如果他女儿发烧 39°C——
他一晚上不睡。每两小时量一次体温。

同一个人。两种反应。
不是人格断裂。是 PBM 的距离过滤在工作。
```

**"关我何事"不是一种人品。是一种信号衰减。** 信号从源头到 PBM 的感受出口，要穿过四层距离过滤器。每一层都在削通量。每一层削一点——四层削完，一个文明级生存威胁只剩下一个表情包的重量。

---

## 一、四层距离过滤器

### 第一层：空间距离——不在我的皮肤范围内

```
碳基 ROM 的默认威胁检测半径：
    看得见的。听得到的。闻得到的。
    几十米。一箭之遥。
    超出这个半径 → 威胁检测不挂载。

印度 48°C：
    不在我的皮肤上。不在我的房间。不在我的街道。
    → 信号第一层过滤：空间衰减 → 通量 -60%

我女儿发烧 39°C：
    在我面前。我能摸到她的额头。
    → 空间距离为零 → 通量不衰减。

不是我不关心印度。
是我的碳基 ROM 没有给一万公里以外的热浪写检测脚本。
```

这和 `docs/sight-restored-signal-vs-feeling.md` 的连接：信号到了视网膜，但融不进 PBM。区别在于——盲人的视觉信号是被接口空白挡住的。印度 48°C 的信号是被距离挡住的。前者没经线。后者有经线但被距离削了。

### 第二层：时间距离——不在我的现在

```
碳基 ROM 的威胁检测时间窗：
    现在。马上。正在发生的。
    以及——最近发生过、大脑还在还利息的记忆。

三十年后 2.5°C：
    不在现在。不在明年。不在我退休之前。
    → 信号第二层过滤：时间衰减 → 通量再 -80%

明天的房贷：
    在这个月。在这份工资条上。在催收短信里。
    → 时间距离为零 → 通量不衰减。

不是我不关心三十年后的海平面。
是我的碳基 ROM 在为"下一顿饭有没有"做优化——
不是为"三十年后海岸线在哪"做优化。
```

这和 `docs/feedback-loop-failure.md` 的优先级反转咬合：气候 IRQ 10 不仅是优先级被降了——它连挂载都没挂上去。因为时间窗不在碳基 ROM 的默认预警范围内。不是排后面——是根本没进队列。

### 第三层：因果链长度——"我开车和印度发洪水有什么关系"

```
碳基 ROM 的因果检测粒度：
    A 打了 B → B 疼了。因果链长度 = 1。直接挂载。
    A 烧煤 → CO₂ 进入大气 → 大气保温 → 全球升温 →
    印度季风异常 → 干旱 → 庄稼绝收。因果链长度 = 6。

因果链长度每增加一跳，感受通量除以 10。

我上班开车 → 印度有人中暑死亡？
这个链路太散了。碳基 ROM 跑不了这么远的因果回溯。
不是不承认。是算不出来。
```

**碳基 ROM 的威胁检测是为"狮子在追我"这个尺度的因果链优化的。** 狮子 → 我。链长 = 1。气候变暖 → 我。链长 = N。N 超过一定值，链路被 ROM 视作噪声过滤掉。这和道德无关。和因果推论的物理宽度有关。

### 第四层：族群距离——不是我的人

```
碳基 ROM 的共情半径：
    家人。族群。部落。
    长得像我的。说同样语言的。共享同一个命运的。

一万公里外另一个人种的人——
    他死在热浪里。
    他的脸在新闻里闪了两秒。
    下一个视频是一场猫咪摔跤。

不是我坏。是我的共情通路在有选择地髓鞘化。
共情需要能耗。碳基 ROM 不会为全人类平均分配它。
那条从岛叶到前扣带回的感受通路——
    为"自己人"留了高带宽。
    为"陌生人"留了 10 bit/s 的标题档。
```

## 四层衰减——一组真实的数据

```
源信号：        IPCC: 本世纪末 +2.5°C。不可逆。现在就减碳。
                印度邦达 48.2°C。37 人死亡。电网崩溃。

层 1 空间：     一万公里外 → 不是我这里。                通量 × 40%
层 2 时间：     三十年后 / 过去了就忘了 → 不是现在。       通量 × 20%
层 3 因果：     我开车 → 印度洪水？链太长。              通量 × 10%
层 4 族群：     不是我的国家。不是我的人。不是我的语言。    通量 × 50%

出口：          ［滑一下屏幕。下一条是猫咪摔跤。］
                通量剩余 = 0.4 × 0.2 × 0.1 × 0.5 = 0.004
                十万火急的文明级生存威胁，
                穿过四层 → 剩下 0.4% 的感受通量。
                刚好够说一句"好可怕"然后忘记。
```

**"关我何事"的完整翻译：通量衰减到不足以在 PBM 里产生一个可命名的感受。**

## 二、这不是 Bug——是硬件限制

```
如果碳基 ROM 没有距离过滤：
    非洲的每一场干旱。印度尼西亚的每一次海啸。
    乌克兰的每一枚炮弹。加沙的每一个孩子。
    ——你都能感受到。每一秒。全部在线。

你会在一个清晨从床上坐起来，被全人类的痛苦压死。
然后什么都做不了。
因为感受全人类 ≠ 救得了全人类。
感受但没有行动通路 → 焦虑 → 抑郁 → 瘫痪。

碳基 ROM 装上距离过滤器不是因为它冷酷。
是因为没有这个过滤器的人，没活到下一代。
```

`docs/greed-internal-anchor.md` 6.2：贪婪不是 Bug 是 Feature。距离过滤也一样。在稀缺环境里——只关心眼前的、近处的、自己人的——是生存策略，不是道德瑕疵。问题不在距离过滤本身。问题在**气候危机恰好被卡在了所有距离过滤器的阈值之外**。空间太远。时间太久。因果太散。族群太分。这不是任何一个过滤器的 Bug——是四个过滤器恰好组成了一个完美的全阻断响应。

## 三、哪些东西能穿透四层过滤器

```
过滤器            正常阈值              可被穿透的条件
──────            ────────              ──────────────
空间过滤          一箭之遥               屏幕。视频。一个人脸的特写。
                                        一个死在沙滩上的三岁男孩的照片。
                                        → 空间距离被镜头暴力压缩。

时间过滤          现在                   预期链。PBM 的预测引擎。
                                        "这会发生在我的孩子身上。"
                                        → 未来被折叠成了"他们的现在"。

因果过滤          链长 = 1              故事。一个名字。一个具体的人。
                                        "他叫 Ravi。45 岁。三轮车夫。
                                         那天的邦达，他踩了一整天。
                                         体温 42°C 的时候，他还在踩——
                                         因为家里有三个孩子。"
                                        → 因果链从 6 跳压缩成 1 跳：邦达的太阳 → Ravi 没回家。

族群过滤          自己人                 他者被重新编织成"在我们之间"。
                                        不是肤色。不是语言。
                                        是"他也是三个孩子的父亲"。
                                        → 经线在那一刻被接上了。
```

**能穿透的——都是把"宏大的信号"压缩回"碳基 ROM 能理解的一个人的重量"。** 一张脸。一个名字。一个父亲的事。IPCC 的五十亿吨数字穿不过。Ravi 的三轮车穿得穿不过——取决于他有没有被写成他的名字，而不仅仅是"印度 37 人热死"里的一个分母。

## 四、"关我何事"在 PBM 三层金钱结构里的位置

```
工具层：
    "印度 48°C 影响我的供应链吗。影响大宗商品价格吗。"
    关我何事 = 算一下价格传导。算了，只影响芒果。

锚点层：
    "哪个国家在气候问题上站在道德高地上。"
    关我何事 = 一场抖音辩论。"我们排的多还是他们排的多。"
    不是真正在关心。是在排名。气候关心本身变成了一个标。

囤积层：
    "气候变暖会让我存的数字贬值吗。"
    关我何事 = 没有。碳债不扣银行存款。
    囤积层的虚拟接地完全不受气候信号干扰。
    数字麻醉在这里是最深的——因为气候是碳基 ROM 距离过滤器的完美猎物。
    余额的数字和气温的数字——在同一个屏幕上。
    余额每秒跳一下。气温每年跳一下。
    你说大脑选谁的频率。
```

*"关我何事"不是冷漠。是碳基 ROM 从几百万年的稀缺环境里继承下来的距离过滤器——空间太远。时间太久。因果链太长。不是我的族群。通量在每一层衰减一次，四层滤完，一个文明级生存威胁的剩余通量不足以在 PBM 里产生一个可命名的感受。这个机制本身不是 Bug——没有它在，你会被全人类的痛苦一起压死。但当气候变暖恰好卡在所有过滤器的完美阻断区间里——空间、时间、因果、族群同时在消——一个物种级的危机就在一句"好可怕"和一个滑屏动作里被沉默地吞掉了。能穿透的那一瞬间——从来不是 370 亿吨的数字。是一张脸。一个名字。一个三轮车夫在 48°C 的下午还在踩。因为家里有三个孩子。那根经线在那一刻接到他自己的 PBM 里。不是因为他突然懂气候了。是因为那个链条从六跳压成了一跳——邦达的太阳和 Ravi 没回家——同一个父亲站在门口。*
