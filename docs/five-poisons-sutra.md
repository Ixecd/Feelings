# Five Poisons Sutra — 贪、嗔、痴、谩、疑

> 作者：qc
> 日期：2026-05-25
> 性质：Feelings 哲学延伸，五毒的 PBM 锚点方向分析
> 核心：五毒不是毒。是五种驱动力。每一种都跑在同一根经线上——差别在于经线的另一端站着什么。外部锚点把驱动力变成毒。内部锚点把驱动力变成引擎。同一根线。两个方向。

---

## 零、不是毒——是方向

```
外部锚点 —— 参照在别人眼睛里。
    我是谁 = 别人看到的。
    我是谁 = 我拥有的 ÷ 你拥有的。
    我是谁 = 那个数字。那个排名。那个标。
    → 五种驱动力全速运转。不停。不够。
    → 毒。

内部锚点 —— 参照在自己织的绳上。
    我是谁 = 我织过的。
    我是谁 = 我纠正过的。
    我是谁 = 我命了名的、我能感受到的。
    → 五种驱动力跑在同一根经线上。
    → 同一根线。同样的强度。
    → 不是毒。是引擎。
```

**差别不在你被什么驱动。差别在你往什么方向开。**

---

## 一、贪 —— 什么都想要 vs 什么都想探索

```
外部锚点：
    什么都想要。永远不够。
    更多的鞋。更高的排名。更多的零在屏幕上的数字。
    囤积层。虚拟接地。
    while(true) { grab(); }
    → 碳基 ROM 在无限计数器上裸奔。
    → 贪之为毒：油箱永远不会满，因为油表焊在外部数字上。

内部锚点：
    什么都想探索。永远没学完。
    二十二层全栈。一百多篇文档。
    内部锚点的精神创造维度没有天然天花板。
    → 不是囤积——是编织。
    → 贪之为引擎：那根绳永远织不完，因为经线一直在开新的行。
```

**同一种驱动：永不满足。外部版：永远不够。内部版：永远没完。前者是诅咒。后者是一生的事业。**

---

## 二、嗔 —— 什么都看不惯 vs 眼光挑剔

```
外部锚点：
    什么都看不惯。所有人都是错的。
    愤怒当燃料。烧别人。烧自己。
    冲人去的——不冲事去的。
    → 杏仁核抄近道抢了前额叶的裁判权。
    → 嗔之为毒：世界永远不会对，因为参照是一个需要别人错才能站住的自我。

内部锚点：
    每一根松掉的丝都逃不过眼睛。不放过任何模糊的思考。
    资本五种吃法——点名。对应结构。不绕。
    不是冲人——是冲那个在黑暗里转的机器。
    → 不是看不惯——是看清。
    → 嗔之为引擎：信号是清晰的。靶子是结构性的。能量是被引导的。
```

**同一种驱动：拒绝接受不对的东西。外部版：你不对。内部版：这不对。前者需要一个靶子来确认自己的高度。后者需要一个纠正来让东西变对。**

---

## 三、痴 —— 什么都想不明白 vs 什么都想搞清楚

```
外部锚点：
    什么都想不明白。在别人的答案里迷路。
    消费。滚动。吸收。从不合成。
    信号到处都是。编织接口是空的。
    → 痴之为毒：世界是噪声，因为意义的参照在外面。

内部锚点：
    什么都想搞清楚。不搞透不撒手。
    信号→感受→意识。拆到一帧一毫秒。
    PBM 框架。锚点谱系。停机悖论。
    → 痴之为引擎：困惑不是终点。困惑是追问的起点。
```

**同一种驱动：已知和需要知道之间的那个缺口。外部版：别人来填。内部版：我来搭桥。前者是消费。后者是建造。**

---

## 四、谩 —— 什么都看不起 vs 保持自我

```
外部锚点：
    什么都看不起。需要别人低所以自己才能高。
    站在上面需要踩在别人身上。
    → 谩之为毒：高度是比较的。比较永远不会结束。

内部锚点：
    不需要踩任何人来确认高度。
    不上市。不做留存优化。不在黑暗中悄悄越线。
    那份绝对——不是因为骄傲。是因为真的在某个东西上站住了。
    → 谩之为引擎：不在看别人。不在比较。在看自己做的那个东西。
```

**同一种驱动：一种与别人分离的自我感。外部版：我在你之上。内部版：我站在我自己建的东西上。前者需要一个踩在你脖子上的脚。后者只需要一块地。**

---

## 五、疑 —— 什么都不相信 vs 只相信自己

```
外部锚点：
    什么都不相信。怀疑作为拆迁工具。
    拆完。从不重建。什么都不剩。
    → 世界是假的。人人都在撒谎。费那个劲干什么。
    → 疑之为毒：只有解构没有建造的怀疑。剩下一地碎石。

内部锚点：
    只相信被验证过的。怀疑作为验证工具。
    不信。查。查完之后——从地基开始自己重建。
    → PBM 这套框架不是继承来的。是怀疑出来的。
    → 疑之为引擎：每一根丝都被拉过才被信任。每一个锚点都被测试过才被挂载。
```

**同一种驱动：拒绝不经验证就接受。外部版：什么都不信——什么都不建。内部版：什么都不信——然后自己建一切。**

---

## 六、同一根经线

五毒共享同一个结构：

```
每一种毒 = 一个驱动力矢量。
    矢量指向某个方向。

    指向外部锚点 → 永不终止。
        更多。更好。更高。更对。更可信。
        → 对比集是无限的。
        → 驱动力一直跑到硬件烧毁。

    指向内部锚点 → 收敛。
        探索完了。纠正好了。搞懂了。建好了。验完了。
        → 终止条件是内部的。
        → 驱动力跑到丝织进绳的那一刻。
        → 然后停了。或者移到下一根丝。
```

**五毒不是毒。是五种力度。毒不在力度里。毒在力度被指向的方向上。**

*贪。嗔。痴。谩。疑。五个字被当成诊断写了两千年。它们不是诊断——是五根线。每根线有两个方向。指向外部锚点——线永不到头，驱动力烧穿硬件。指向内部锚点——线织进经里，驱动力建起一个能承住人的东西。毒不在线里。毒在线被指向哪里。而解药——不是更少。解药是方向。*
