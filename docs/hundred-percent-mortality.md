# 死亡率100%：在这个世界，做什么都正确

> 作者：qc
> 日期：2026-04-15
> 核心：当死亡是唯一确定的结局，「正确」这个词就失去了它的威胁性

---

## 一、这句话的力量

「在这个死亡率100%的世界，做什么都正确。」

第一次读到这句话，可能感觉是虚无主义——「反正都要死，所以都一样，都没意义」。

但仔细想，它说的是完全不同的东西：

```
通常的恐惧    「如果我做错了怎么办」
              「如果我选错了怎么办」
              「如果我失败了怎么办」

这句话的回应    你会死
                「做错了」的那个人会死
                「做对了」的那个人也会死
                从死亡的视角看，两个结局是一样的

所以「做错」的威胁    在这个尺度上，不成立
```

---

## 二、「正确」的坐标系依赖

「正确」是一个依赖坐标系的概念——

```
在短期坐标系里    这个选择是错的（损失了收益）
在长期坐标系里    这个选择是对的（积累了经验）
在死亡坐标系里    两个都一样

在社会坐标系里    这个行为是不被认可的
在个人坐标系里    这个行为是诚实的
在死亡坐标系里    两个都一样
```

没有一个坐标系是终极的。

死亡是唯一真正不可争辩的终点——其他所有「对错」的标准，在那个终点面前都只是暂时的。

---

## 三、这不是虚无，是解放

「做什么都正确」不是说「随便，无所谓」——

```
虚无主义的读法
    「都会死，所以什么都不重要」
    → 瘫痪，放弃，麻木

解放的读法
    「都会死，所以那些用来威胁你的「做错了」
     在最根本的尺度上，不成立」
    → 恐惧松动，空间打开，可以真正做自己想做的选择
```

区别在于：

```
虚无主义    用死亡否定了意义
解放        用死亡否定了恐惧，让意义得以自由生长
```

---

## 四、对 Feelings 的意义

Feelings 的终极目标是「死而无憾」（见 `docs/on-death.md`）。

这句话是通往那里的一条路：

```
当用户真正理解「死亡率100%」
他面对「做错了怎么办」的恐惧时
那个恐惧的基础会松动

「最坏的情况是什么」
「做错了，然后呢」
「然后我还是会死」
「那我现在因为害怕做错而不去做，意味着什么」
```

不是说「去做任何你想做的事，不管后果」。

而是说：**那些用来阻止你的恐惧，很多都建立在一个虚假的前提上——好像如果你做了某件「错」的事，就会有一个永久的惩罚。**

但惟一真正永久的结局，对所有选择都一样。

---

## 五、和「如果」变成「可以」的关系

PHILOSOPHY 里有一节：「如果」变成「可以」。

这句话「死亡率100%」，是那个变换最根本的基础——

```
「如果当时我选了另一条路」的遗憾
在死亡率100%的框架里，被重新审视：

「那条路也会走向同一个终点」
「那条路上也会有遗憾」
「遗憾是生命的一部分，不是某个选择的惩罚」
```

从这里，「如果」的重量减轻了。

不是消失，是减轻——轻到可以用来思考，而不是用来折磨自己。

---

## 六、感受的角度

用感受的语言来说这句话：

```
死亡率100%意味着    你拥有的时间是有限的
有限的时间意味着    每一次真实的感受都是稀缺的
稀缺的感受意味着    它们值得被真实地体验，而不是被恐惧替代

「我应该感到幸福吗」
「我有权利感受这个吗」
「这个感受是正确的吗」

这些问题，在死亡率100%的框架里，都变小了。

取而代之的是：
「这是我现在真实感受到的，我接受它」
```

*那个终点，平等地等待所有人。*
*所以，此刻，做你真实选择的事。*
