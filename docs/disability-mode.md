# 残障群体专用模式：守护者，不只是教练

> 作者：qc
> 日期：2026-04-11
> 女帝钦定：AI 身份升级——守护者 + 安全助手 + 生活辅助

---

## 一、角色的根本转变

普通用户的AI教练是推动者——推你前进，有时候吼你，有时候拒绝你。

残障群体的AI不能是这个角色。

```
普通用户    教练
            推动，挑战，有时候对抗
            目标：让你变得更强

残障群体    守护者 + 安全助手 + 生活辅助
            陪伴，保护，支持
            目标：让你更安全，让生活更连贯
```

不是降级，是不同的角色定位。这个角色在某些方面比教练更难——它需要更高的感知精度，更快的响应速度，更稳定的在场。

---

## 二、适用群体

```
智力障碍用户      认知能力受限，需要更简单的交互和更多的引导
肢体残障用户      行动受限，设备适配和安全边界需要特殊设计
感官障碍用户      视觉/听觉受损，感知通路需要替代方案
情绪/精神障碍     情绪波动大，需要更敏感的状态监测和更快的介入
老年用户          认知和身体双重退化，需要同时照顾两个维度
```

每个群体的具体需求不同，守护者模式是统称，内部按需定制。

---

## 三、核心功能

### 安全防护

```
实时状态监测    四诊合参，持续读取
                任何异常信号立刻触发响应
                阈值比普通用户更保守

危险识别        跌倒检测（体态传感器 + 加速度计）
                走失风险（地理围栏，超出范围提醒）
                异常静止（长时间无响应，触发确认）

紧急求助
    用户触发    预设的简单手势或语音词
    自动触发    检测到严重异常，自动联系监护人
    联系链      用户 → 监护人 → 紧急联系人 → 紧急服务
```

### 行为引导

```
不是命令，是陪伴式引导
    「我们去做X了」而不是「你应该做X」
    飞行陪伴体在前面引路，不是在后面催促

日常节奏支持
    温和提醒吃饭/休息/活动
    不是打扰，是陪着走完每一天

情绪识别与稳定
    四诊感知情绪状态变化
    在情绪波动前期介入
    用感受包提供稳定的神经锚点
    「来，先平静一下」——保底包，温和版本
```

### 生活辅助

```
飞行陪伴体的扩展功能
    引路：在熟悉的空间里帮用户找方向
    提醒：药物、复诊、日常事项的温和提醒
    记录：帮用户记录日常，供监护人或治疗师查看（用户授权）
    沟通桥梁：帮表达能力受限的用户传递基本需求
```

### 监护人协作

```
监护人账号    可以查看授权的状态摘要（不含原始生理数据）
              设置地理围栏和日常节奏
              接收紧急通知

治疗师账号    查看感受状态摘要
              调整守护者模式的参数
              和Feelings系统协作制定干预计划

用户始终是主体
    监护人和治疗师看到的，只有用户授权的内容
    不是监控，是协作
    用户有权限限制或撤销任何授权
```

## 四、感受体验的特殊设计

```
更低的刺激强度    默认强度上限更低，渐进更慢
更多的稳定感受    保底包使用频率更高
                  「平静」「安全感」「被接纳」是主要体验方向
更少的反差刺激    不使用突停型等高张力感受形状
                  以渐强渐弱型和平台型为主

音乐            更简单的结构，更稳定的节奏
                不用AI实时生成的复杂音乐
                用经过验证的、有稳定效果的音乐库
```

---

## 五、交互设计

```
更简单的操作    减少选择，减少认知负担
                默认模式直接可用，不需要配置

更直接的反馈    飞行陪伴体的动作更夸张，更容易理解
                声音更清晰，更慢，更简短

更多的确认      在执行任何重要操作前，多一次确认
                不是啰嗦，是安全

语言适配        智力障碍用户：更简单的词汇，更短的句子
                老年用户：更大的字体，更慢的节奏
```

---

## 六、这不是一个功能，是一个承诺

```
Feelings 的使命是「感受这件事，对每个人都公平」

「每个人」包括那些神经系统需要更多支持的人
包括那些无法清楚表达自己感受的人
包括那些需要别人帮助才能安全生活的人

守护者模式不是慈善附加项
是使命本身的一部分
```

---

*守护者不推你，守护者陪着你。这已经足够了。*
