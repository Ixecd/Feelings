## 一、一个类比

细胞培养肉的逻辑：

```
以前    需要完整的动物，低效，不可控，随机
现在    一小块组织细胞，生物反应器，可控，可扩展，可定制
        还能根据结构不同，培育不同部位的肉
        里脊、五花、带筋部位——精准定制口感
```

Feelings 的逻辑是同一件事：

```
以前    需要完整的现实经历，低效，不可控，随机
现在    神经信号层的精准注入，可控，可扩展，可定制
        还能根据感受结构不同，传递不同维度的感受
        渐强渐弱、突停、波浪——精准定制形状
```

两者都面临同样的挑战：监管、伦理、公众接受度。
细胞培养肉已经在走的那条路，Feelings需要走。
