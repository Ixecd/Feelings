## 一、睡眠是感受闭环的修复窗口

Feelings 的感受闭环在白天工作，神经系统在夜间修复。

睡眠质量是 Feelings 是否真正起效的客观验证指标——不依赖用户主观报告，数据直接说话。深睡时长提升，清醒次数减少，说明神经系统在白天被正确地训练和使用，夜间修复得更充分。

睡眠环境系统的目标：让用户的身体在正确的物理条件下进入最深的修复状态。

## 二、光：最被忽视的信号

**太阳光 vs 人工光**

褪黑素的分泌由光线控制，具体是光的波段——蓝光（460-480nm）抑制褪黑素，红光/暖光促进褪黑素。

```
白天    需要蓝光    提高警觉，抑制褪黑素，同步昼夜节律
傍晚    减少蓝光    开始切换，准备进入休息状态
睡前    接近零蓝光  让褪黑素自然分泌
```

Feelings 的立场：**褪黑素应该完全由用户自己产生，不靠外部补充。**

外部补充褪黑素打断了身体自主调节的回路。系统可以做的是：根据设备传感器和用户作息数据，在合适的时间提醒用户调整光线环境，或者联动智能灯具调整色温。

这不是给用户一个开关，是帮用户找回身体本来就有的节律。

**AI可以做的**

```
根据用户历史入睡时间    推算最佳开始降低蓝光的时间点
根据地理位置和季节      判断当地日落时间，给出光线调整建议
根据睡眠数据反馈        如果深睡不足，检查是否有光线干扰
```

## 三、温度：理想睡眠的物理条件

核心体温下降是进入深度睡眠的必要条件。身体需要把热量散出去，环境温度是这个过程的关键变量。

**理想睡眠温度：18-19°C**

这不是舒适温度，是最有利于深睡的温度。很多人觉得「冷了睡不着」，是因为手脚冰凉——身体想散热但末梢循环不够好，热量散不出去。

**手脚冰凉的用户需要特别处理**

手脚冰凉的本质是末梢血液循环不足，核心体温散不出去，反而导致深睡困难。

```
不是加热整个房间    → 反而更难散热
而是局部加热手脚    → 促进末梢血管扩张，帮助核心体温散出
                       比如睡前热水泡脚10分钟
```

AI根据用户体质数据（从Feelings生理传感器积累）判断是否属于末梢循环不足类型，给出对应建议。

**温度与感受包的交叉**

高强度体验后核心体温会升高，这时候不适合直接入睡。Feelings可以在高强度会话结束后，提示用户等待体温恢复，或者给一个「降温引导」的轻感受包，帮助身体更快进入休息状态。

## 四、补剂：辅助而非替代，耐受度因人而异

Feelings 不推荐任何直接作用于褪黑素通路的补充剂。身体自主产生褪黑素的能力需要被保护，不是被绕过。

可以考虑的是**缓冲类补剂**——帮助身体更好地完成自然过程，而不是替代自然过程：

```
南非醉茄（Ashwagandha）    适应原，降低皮质醇，减少睡前焦虑
甘氨酸镁                   促进肌肉放松，轻微降低核心体温
鱼油（Omega-3）            抗炎，改善神经传导效率
护肝片                     如果用户有饮酒习惯，肝脏负担影响睡眠质量
```

**AI判断补剂的个体耐受度**

每个人对补剂的反应不同。AI根据用户基数的积累数据，结合个人生理基准，判断哪类补剂对这个用户可能有效，哪类可能无效甚至有负面作用。

不是给所有用户同一张补剂清单，是根据个体数据给出个性化建议。

这是「系统听身体的，不听你说的」原则在睡眠领域的应用。

**明确拒绝的**

```
直接补充褪黑素    绕过身体自主调节，长期依赖后自主分泌能力下降
安眠药类          不在Feelings的范畴，属于医疗干预
裸盖菇素等        受控物质，不碰
```

## 五、饮食与睡眠

睡前吃不吃东西，没有统一答案，因人而异。核心原则只有一条：

**不要吃撑。**

消化系统高负荷运转时，核心体温不容易下降，深睡受影响。轻食或不吃，是更有利于深睡的选择。但空腹入睡如果导致血糖过低，也会影响睡眠质量。

AI根据用户历史数据判断个体的最佳睡前饮食模式，不做统一规定。

## 六、睡眠数据作为Feelings的核心验证指标

```
追踪指标
    深睡时长        目标 > 2小时（参考基准：2小时53分钟，清醒0次）
    清醒次数        目标 0次
    入睡时长        从关灯到入睡的时间
    睡眠结构        深睡/浅睡/REM比例

验证逻辑
    使用Feelings前    建立睡眠基线
    使用期间          持续追踪
    对比前后          深睡时长是否提升，清醒次数是否减少
```

Feelings不说「你感受到了什么」，说「你的深睡从1小时涨到了2小时53分钟」。这是最有说服力的证明。
