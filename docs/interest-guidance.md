# 兴趣引导：感受空白的入口

> 作者：qc
> 日期：2026-04-10
> 核心：兴趣不是目的，是感受体验的入口

---

## 一、开放状态是最好的起点

用户戴上设备，没有特定目标，什么都不想做。

这不是空白，是开放状态——神经系统处于中性，没有预期框架，没有防御激活。这是接收新体验的最佳状态。

大多数产品在这个时刻会推内容、推任务、推打卡。

Feelings 在这个时刻做一件不同的事：**读取用户当前的感受空白，然后推荐一个真实的兴趣方向作为入口。**

---

## 二、兴趣推荐的逻辑

不是基于「你可能喜欢什么」，是基于「你从来没有真实体验过什么」。

```
标准推荐逻辑    根据偏好推你喜欢的
                结果：用户在舒适区里反复转
                感受地图不会扩展

Feelings逻辑    根据感受档案里的空白推
                「你从来没有体验过X类感受」
                「Y这个兴趣正好能触发这类感受」
                结果：兴趣成为感受地图扩展的入口
```

兴趣是手段，感受扩展是目的。

---

## 三、具体推荐方式

不是泛泛的「你可以试试游泳」，是精确的感受-兴趣映射：

```
用户感受档案显示    从未体验过「专注在手的感受」
                    本体感受维度的手部感知是空白
系统推荐            「要不要试试陶艺？」
                    「陶土在手里的质感，和你身体完全专注于指尖的感受，
                     是你从来没有真实接触过的维度」

用户感受档案显示    归属感维度长期缺失
                    没有真实的集体体验记录
系统推荐            「这周有一个户外徒步活动，三到五人的小队」
                    「那种肩并肩走过一段路之后的归属感，
                     是你的感受地图里还没有的坐标」
```

推荐足够具体，用户知道为什么这个兴趣和他有关。

---

## 四、兴趣推荐的边界

```
推荐的是方向，不是强迫
    用户可以接受，可以忽略，可以说「我不想做这个」
    系统记录拒绝，不反复推同一个方向

推荐的是真实活动，不是Feelings内部体验
    不是「要不要体验一个归属感感受包」
    是「要不要去参加一个真实的活动」
    Feelings把用户往外推，不往内拉

推荐的频率
    不是每次开机都推
    是用户处于开放状态、没有明确目标时才推
    一次只推一个方向
```

---

## 五、兴趣与感受闭环

用户接受推荐，去参加了活动，戴着Feelings回来。

```
活动中        增强模式工作，那个感受被放大和固定
活动后        自省系统引导复盘
              「你今天体验到的，是什么感觉的？」
              「这和你之前想象的有什么不同？」

结果          感受地图上出现了一个新的坐标
              下一次的推荐会基于这个新的坐标做更新
```

兴趣推荐→真实体验→感受固定→地图扩展→新的空白被发现→新的推荐。

这是一个持续生长的循环。

---

*兴趣是最好的老师，因为兴趣让人真实地在场。Feelings 帮用户找到那个让他真实在场的入口。*
