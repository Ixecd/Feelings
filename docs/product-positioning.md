# 产品定位：你知道身体里发生了什么，但你感受过吗？

> 作者：qc
> 日期：2026-04-12

---

## 一、一个对话

DK人体大百科是有史以来最成功的人体科普读物之一。

它做的事情是：把复杂的人体系统，用精确的视觉呈现出来，让普通人第一次「看见」自己身体里发生的事情。

神经元是什么样的，突触如何传递信号，情绪在大脑里走什么路径——这些原本只存在于教科书里的东西，被DK用图像带到了每个人面前。

**Feelings 和DK的对话是这样的：**

```
DK        让你看见身体里的结构
Feelings  让你感受到神经系统里的运作

DK        「这是情绪在大脑里的路径」（图像）
Feelings  「这是情绪在你的神经系统里真实发生的感觉」（体验）
```

你知道愤怒激活了杏仁核。但你感受过「杏仁核被激活」是什么体验吗？

你知道迷走神经影响情绪基调。但你感受过「迷走神经被刺激」之后身体里发生了什么吗？

---

## 二、知道和感受之间的鸿沟

DK解决了「知道」的问题——用视觉让知识变得可及。

但「知道」和「感受」之间，有一道鸿沟：

```
知道    「压力会让皮质醇升高，影响免疫系统」
        这是认知层的信息，可以被理解，被记住

感受    「这就是皮质醇升高时，我的身体里发生的事情」
        这是感受层的体验，会被神经系统记住，会改变行为
```

大多数人读完DK，对身体的了解增加了，但和自己身体的关系没有改变。

因为信息不能替代体验。

Feelings 填补这个鸿沟——不是用更多的信息，而是用真实的神经层面的体验。

---

## 三、DK作为卖点的具体切入

**「你知道平静是什么，但你感受过真正的平静吗？」**

DK告诉你平静时副交感神经系统激活，心率下降，皮质醇减少。

Feelings让你第一次真实地接触那个状态，知道它在你的神经系统里是什么感觉。

**「你知道成就感的神经底层，但你感受过它的完整混音吗？」**

DK告诉你成就感和多巴胺、血清素有关。

Feelings让你接触「完成一件极难的事之后的感受」——不只是多巴胺，是成就（50%）+疲惫的释然（25%）+轻微的空洞感（15%）+对自己的微小确信（10%）。

那个完整的混音，才是真实的成就感。

## 四、两者的关系

DK和Feelings不是竞争关系，是互补关系：

```
DK        建立认知地图：「原来身体是这样运作的」
Feelings  建立感受地图：「原来这个感受是这样的」

DK让人对自己的身体产生好奇
Feelings让这个好奇有了落地的方式
```

理想的用户旅程：

```
读DK        「原来平静时神经系统是这样的，有点神奇」
用Feelings  「原来这就是那个状态在我身体里的感觉」
回看DK      「现在这张图对我有了完全不同的意义」
```

知识和体验互相强化，理解变得立体。

非医院 = 不做诊断、不做处方、不替代心理治疗。这不是技术做不到，是定位选择——跨进疾病侧 = FDA/CE/NMPA 医疗监管全面触发，监管债吃掉创新空间。更根本的：Feelings 不治"病"，它建"健壮底盘"。病是医院的事。
