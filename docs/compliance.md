# 合规路径：进入市场，不是进入资本

> 作者：qc
> 日期：2026-04-12
> 核心：合规是进入市场的门票，不是进入资本市场的手续

---

## 零、关于「上市」的澄清

合规文档里讨论的是**产品进入市场**（product market entry），不是**资本市场上市**（IPO）。

```
Feelings 永远不上市（GOVERNANCE红线）
    上市引入股东利益，和感受民主化哲学不相容
    季度报表压力会摧毁所有长期主义决策

这里讨论的合规
    是让产品合法销售和使用的资质
    医疗器械注册证、数据合规认证
    是产品进入用户手里的门票
    不是进入资本市场的手续
```

## 一、为什么合规是重中之重

```
技术做完了    但监管不批 → 产品上不了市
数据泄露      一次事故   → 信任崩塌，永远无法恢复
合规没做好    进不了市场 → 欧盟/中国/美国每个地区一套规则
```

Feelings的特殊性让合规比普通产品难得多：

```
普通App       处理行为数据（位置/购买/浏览）
              现行法规有明确规定

Feelings      处理神经数据——人类最私密的数据
              现行法规几乎是空白
              但风险是真实的，而且是不可逆的
```

空白不代表安全，代表Feelings需要主动定义标准，而不是等监管来定义。

## 二、医疗器械合规路径

神经刺激设备，在大多数国家会被归类为医疗器械。这是最大的合规挑战，也是必须提前布局的。

### 进入策略：先医疗，后消费

```
错误路径    直接做消费级产品，绕过医疗监管
            风险：一旦出现安全事故，整个产品被叫停

正确路径    先做医疗适应症，拿到器械证，再扩消费
            已被Neuralink/Synchron/清华NEO验证的路线
```

**第一批医疗适应症（监管路径最清晰）**

```
睡眠障碍    失眠是明确的医疗适应症
            tDCS用于睡眠改善已有临床数据
            监管路径相对清晰

焦虑/抑郁  迷走神经刺激用于抑郁已获FDA批准
            可以在已批准的技术路线上做创新

疼痛管理   神经刺激用于慢性疼痛有完整的临床路径
```

### 各地区监管机构

```
中国        NMPA（国家药监局）
            第三类医疗器械（最高级别，最严格）
            需要临床试验数据
            建议路径：先在国内做临床，积累数据

欧盟        CE MDR（Medical Device Regulation）
            2021年新规，要求更严
            需要公告机构（Notified Body）审核
            建议路径：和欧洲医院合作做临床

美国        FDA 510(k) 或 PMA
            510(k)：证明和已批准设备实质等同
            PMA：全新技术，需要完整临床试验
            建议路径：先找已批准的类似设备做510(k)
```

### 时间预估

```
中国NMPA第三类    3-5年（含临床试验）
欧盟CE MDR        2-4年
美国FDA PMA       5-7年

策略：三地同步启动，中国先行
      中国临床数据可以支持其他地区的申请
```

## 三、数据合规

### 神经数据的特殊地位

```
现行分类    个人信息 → 敏感个人信息 → 生物识别信息
神经数据    目前大多数法规没有专门分类
            但它比生物识别更敏感——
            它揭示的不只是你是谁，还有你怎么想、怎么感受

Feelings的立场    按最高标准处理
                  不等监管来要求，主动做到最严
```

### 各地区数据法规

```
中国
    《个人信息保护法》（PIPL）
    《数据安全法》
    敏感个人信息需要单独同意
    数据本地化要求（境内数据不得出境，除非通过评估）
    Feelings的应对：原始神经数据永远在设备上，不上传服务器
                    符合最严格的本地化要求

欧盟
    GDPR
    数据最小化原则
    被遗忘权（用户可以要求删除所有数据）
    数据保护影响评估（DPIA）对高风险处理是强制的
    Feelings的应对：数据在设备上，DPO（数据保护官）提前任命

美国
    目前没有联邦统一法规
    各州法律：CCPA（加州）、CPRA等
    神经数据专项法规正在各州推进（科罗拉多已立法）
    Feelings的应对：主动符合最严格的州法，不等联邦法出台
```

### 数据合规的技术实现

```
数据最小化    只采集感受体验需要的信号
              不采集位置（除非用户明确授权兴趣引导功能）
              不采集通讯内容

用途限制      采集的数据只用于感受体验和个人基准
              不用于广告，不用于第三方，不用于训练模型（除非用户授权）

用户控制      随时可以下载自己的所有数据
              随时可以删除，删除即彻底删除
              随时可以撤销任何授权

审计日志      所有数据访问行为记录在案
              用户可以查看谁访问了自己的数据
              不可篡改，链上存证
```

## 四、权限管控体系

### 角色与权限矩阵

```
角色          可以看到什么              可以做什么
─────────────────────────────────────────────────────
用户本人      所有自己的数据            完全控制
监护人        授权范围内的状态摘要      设置安全参数
治疗师        授权范围内的感受摘要      调整治疗方案
创作者        自己上传的感受包数据      管理自己的作品
平台审核      感受包内容（脱敏）        审核/下架
平台运营      脱敏统计数据              系统维护
```

**核心原则：用户始终是主体，没有用户的明确授权，任何角色都无法访问用户数据。**

### 设备管控

```
唯一标识      每套设备出厂时烧入不可复制的硬件标识
账号绑定      标识和账号绑定上链，不可伪造
防克隆        固件签名验证，伪造设备无法激活
远程销毁      设备丢失时，远程清除所有本地数据
              下次联网时自动执行，保护用户隐私
```

### 感受包内容管控

```
上传审核流程
    创作者上传感受包叙述
    AI初步审核（内核置信度 + 内容安全）
    人工复核（高风险类别）
    通过后上线，不通过给出理由

高风险类别（强制人工复核）
    亲密感受维度
    高强度感受包（>80档）
    涉及创伤/痛苦的感受包

违规处理
    轻微违规    下架 + 警告
    严重违规    永久封禁，无申诉通道
    涉及未成年人的任何内容    立即删除 + 报告执法机构
```

## 五、人身安全合规

神经刺激设备的人身安全，是监管机构最关注的。

```
临床前安全测试
    动物实验    验证刺激参数的安全范围
    体外测试    验证设备的电气安全
    生物相容性  验证材料不产生不良反应

临床安全监测
    不良事件报告（Adverse Event Reporting）强制要求
    所有安全事件必须上报监管机构
    Feelings的安全事件记录体系，需要和监管报告对接

上市后监控
    持续收集用户安全数据
    定期向监管机构提交安全报告
    发现系统性问题，主动召回
```

## 六、开源与合规的关系

Feelings 是开源的，但开源不意味着合规风险降低。

```
开源的好处    代码可被审计，透明度高
              社区可以发现安全漏洞
              符合部分监管机构对可验证性的要求

开源的挑战    任何人可以 fork，做出不合规的版本
              Feelings 品牌需要和不合规的 fork 区分
              需要明确的商标政策和合规认证体系
```

**策略**：代码 MIT 开源，合规认证（医疗器械证）和品牌（Feelings）归 Feelings 所有。

使用开源代码做产品，需要自己去拿合规认证，不能借用 Feelings 的认证。

## 七、合规时间线

```
现在          建立合规框架（本文档）
              聘请医疗器械合规顾问
              开始和 NMPA 的预沟通

原型阶段      启动 IRB（机构审查委员会）审批
              设计临床试验方案
              建立不良事件报告机制

产品阶段      提交医疗器械注册
              完成 GDPR/PIPL 合规审计
              建立数据保护官（DPO）机制

商业化阶段    各地区医疗器械证拿到
              扩展消费级市场
              持续上市后监控
```
