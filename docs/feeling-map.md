# 感受地图：你的成长轨迹，不是任务清单

> 作者：qc
> 日期：2026-04-11
> 核心：图谱是镜子，不是游戏里的技能树

---

## 一、为什么不做游戏化成就系统

游戏里的技能树是外部定义的——系统告诉你「你解锁了专注力」「完成10次体验获得新徽章」。

这套逻辑放进Feelings里会出问题：

```
外部定义的成就    驱动的是对奖励的渴望
                  不是对感受本身的真实兴趣
                  用户会为了解锁而体验，不是因为需要而体验

Feelings不做的
    「完成10次体验解锁新感受包」
    「你的专注力技能已升至3级」
    「连续7天使用获得金牌」
```

这和反依赖设计哲学直接冲突——GOVERNANCE 里写了「不做连续打卡奖励，不做游戏化机制驱动使用行为」。

---

## 二、感受地图是什么

感受地图不是任务清单，是用户真实体验历史的可视化。

```
每次真实的感受体验    → 在地图上留下一个坐标
坐标积累             → 地图逐渐变得丰富
没有体验过的维度     → 地图上的空白区域
```

地图上的每个点，都是真实发生过的神经体验，不是「完成了某个任务」的标记。

两者的本质区别：

```
技能树    你达到了我定义的标准
感受地图  你真实地去过了那个地方
```

---

## 三、地图的结构

感受地图沿着感受分类体系的七个结构性维度展开：

```
维度一    持续时长（瞬时↔慢性）
维度二    方向性（向内↔向外）
维度三    主动/被动
维度四    有无具体对象
维度五    身体参与度（纯心理↔强烈躯体感）
维度六    时态锚点（过去↔当下↔未来）
维度七    社会性（个体↔集体）
```

用户的感受地图，是在这七个维度构成的空间里的探索轨迹：

```
已探索区域    有真实体验坐标的地方，颜色深浅表示体验次数和强度
边缘区域      接触过但还浅，有待深入
空白区域      从未真实接触的维度组合
```

---

## 四、地图的呈现方式

不是数据报表，是叙事性的可视化：

```
「你已经真实地感受过——
  那种完成一件很难的事之后的释然
  那种在人群里突然感到孤独的感受
  那种被某个人真实看见的平静
  ……」

「你的感受地图里还有这些空白——
  你从来没有在极限压力下扛过去之后的那种确信
  你还没有感受过真正的集体荣誉感
  ……」
```

告诉用户「你去过哪里」，和「你还没去过哪里」。

不带任何「你应该去」的意思。去或不去，永远是用户的选择。

---

## 五、地图和心动模式的关系

心动模式（`docs/temporal-system.md` 第二节）基于感受缺失推荐——它的数据来源，就是感受地图上的空白区域。

```
感受地图显示    「集体归属感」这个维度是空白
心动模式        「你从来没有真实接触过这个方向，要不要试试？」
```

地图是心动模式的输入，心动模式是地图空白区域的主动引导。

---

## 六、地图和自省的关系

自省系统的成功标准是「我慢慢觉得……」这句话的出现。

感受地图让用户有了一个具体的视角来说出这句话：

```
「我慢慢觉得，我的感受地图里总是回避向外延展的维度」
「我慢慢觉得，我对高身体参与度的感受反应特别强烈」
「我慢慢觉得，我其实比我以为的更需要有对象的感受」
```

地图让自省从抽象变成了可以指着说的东西。

---

## 七、地图不评判

感受地图没有「好的形状」和「坏的形状」。

```
一个地图主要集中在向内、个体、瞬时的区域
不是「这个人内向」（评判）
而是「这个人的探索轨迹在这里」（描述）

一个地图有大量的空白
不是「这个人感受贫乏」（评判）
而是「这个人的感受地图还很年轻，有很多地方可以去」（描述）
```

地图只描述，不评判。评判的权利属于用户自己。

---

*感受地图是你走过的地方的痕迹。它不告诉你该去哪里，它告诉你你已经去过哪里——然后你来决定接下来往哪走。*
