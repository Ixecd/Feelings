# 定价模型：从免费出发，按需扩展

> 作者：qc
> 日期：2026-04-11
> 核心：感受民主化从硬件入门门槛开始

---

## 一、核心原则

```
感受的访问权不以价格区隔（GOVERNANCE红线）
但设备本身是有成本的，需要可持续的商业模式

解法：
    核心设备免费    降低入门门槛，让所有人都能进来
    扩展设备收费    按需付费，感受地图想走多远走多远
```

---

## 二、免费层：耳后设备

耳后设备是唯一必选设备，永久免费。

```
包含功能
    迷走神经刺激（情绪基调调节）
    心率采集
    基础皮肤电导
    音乐信号通路（AI生成音乐完整支持）
    基础安全监测

能体验的感受
    情绪基调类感受（平静/愉悦/低落方向性调节）
    音乐驱动的感受体验（完整）
    基础感受闭环（有限精度）
```

免费不是「残缺版」，是真实可用的起点。耳后设备单独使用，已经是一个完整的Feelings体验，只是感受地图的覆盖范围有限。

---

## 三、收费层：扩展设备

每个扩展设备独立定价，固定价格，不是指数递增。

**为什么固定价格，不是指数**

```
指数定价    每增加一个设备价格翻倍
            在某个节点让用户觉得「不值」而停止
            违背「渐进式接入」的产品哲学

固定定价    每个设备有自己的价格，代表它的真实价值
            用户按需添加，不被指数吓退
            更公平，更透明，和链上治理一致
```

**扩展设备价格（待定，需硬件成本确认）**

```
后颈设备    本体感受 / 姿态感知 / 体温运动采集
腕部设备    精确皮肤电导 / 细粒度情绪信号
颞部设备    认知状态 / EEG初步采集
飞行陪伴体  望+闻感知 / 陪伴存在感
触觉设备    长期扩展，价格待定
```

## 四、低收入用户保护

感受民主化需要财务支撑：

```
存储池用途之一    给低收入用户补贴扩展设备成本
AI教练判断        当用户的经济状况（用户主动授权提供）
                  和某个扩展体验的实际价值不匹配时
                  教练会评估：「这个对你的感受地图扩展
                               是否真的值得你现在的花销？」
                  不是劝阻，是帮用户做更清醒的决定
```

**关于小时候因为穷主动拒绝的问题**

那种提前的自我保护——「不想要，就不会失望」——是一种真实的感受模式，在神经系统里留下了印记。

AI教练启动童年补偿机制时，核心不是消费建议，是填补心理缺口：

```
「当年的你值得，现在的你也值得。」

不鼓励消费
    不是「你现在有钱了，买吧」
    是帮用户看清楚那个拒绝背后的感受
    「你当时不是不想要，是觉得自己不配拥有」

补偿机制
    强度基准：童年最高强度20，AI按此尺度温和补偿
    不冲击，不越界，从那个尺度开始，慢慢扩展
    让用户在安全的范围内，重新接触那个当年被拒绝的感受

AI教练的判断
    这件事的真实价值 vs 当时的「巨额感」
    现在的经济状况 vs 扩展体验的实际意义
    帮用户做基于真实情况的清醒选择
    而不是被「买不起」的恐惧或「别人都有」的压力驱动
```

## 五、首年探索：可能的变体

一个值得讨论的定价变体：

```
首年    耳后设备免费
        所有扩展设备首年免费试用（有时长限制）
        让用户先建立习惯，感受到价值

次年    按固定价格购买想保留的扩展设备
        不强制，用哪个买哪个
```

这个模式的逻辑：Feelings 的价值需要时间来感受。首年让用户真正知道扩展设备的价值，然后让他们做真实的购买决定，而不是在不了解的情况下掏钱。

---

## 六、与链上治理的关系

```
硬件收益    上链存证，进入分成体系
            扩展设备的部分收益流向感受包创作者
            部分进入存储池，用于低收入用户补贴

透明定价    定价规则上链，平台不能私自涨价
            价格变更需要治理宪章更新流程
```

---

*免费入门，是因为感受这件事对所有人都公平。收费扩展，是因为更广的感受地图需要更多的技术支撑。每一分钱，都花得理直气壮。*
