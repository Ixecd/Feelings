# 推荐系统：只为高控制权用户设计

> 作者：qc
> 日期：2026-04-14
> 核心：推荐系统不是给所有人的，是给那些知道自己在干什么的人

---

## 一、为什么不给所有人推荐

Feelings 的默认入口是立方体——直接开始，系统读取状态，自动判断。

这个设计是刻意的：

```
推荐系统的本质    替用户做选择
                  「系统认为你现在应该体验这个」

对新用户的危害
    感受探索还没有建立自己的方向感
    推荐会污染这个自主探索的过程
    用户变成了「消费推荐内容的人」
    而不是「探索自己感受地图的人」

对成熟用户
    推荐是工具，不是引导
    他们知道自己要什么
    推荐帮他们找到，不是替他们决定
```

**推荐系统只为高控制权用户设计。**

---

## 二、什么是高控制权用户

```
不是付费等级，不是使用时长
而是感受探索的成熟度

判断标准（系统自动评估）
    感受地图有足够多的真实坐标（>50个维度坐标）
    个人基准已经稳定（超过100次体验的基线）
    自省系统使用频率正常（不是从不用，不是过度依赖）
    TCP解锁阶段达到一定水平
    行为模式显示主动探索倾向（不是被动等待）

达到这些标准的用户
    推荐系统对他们解锁
    他们可以选择开启或关闭
    默认关闭
```

## 三、推荐系统的设计逻辑

### 不是「你可能喜欢」

```
普通推荐系统    基于历史行为
                「喜欢X的人也喜欢Y」
                强化已有偏好
                感受地图越来越窄

Feelings推荐    基于感受地图的空白
                「你从来没有真实接触过这个维度」
                扩展感受地图
                越推越宽，不是越推越窄
```

### 三种推荐模式

**模式一：感受地图空白探索**

```
系统扫描用户感受地图
找到从未触及的维度组合
推荐能触达那个空白的感受包

不是「你会喜欢」
而是「你还没去过这里，要不要看看」
```

**模式二：状态匹配推荐**

```
四诊合参读取当前状态
判断「这个状态最适合什么样的感受体验」

不是每次都推新的
而是「现在的你，适合这个」
有时候是熟悉的感受包（当用户需要稳定的时候）
有时候是新的维度（当用户状态好、可以探索的时候）
```

**模式三：成长路径推荐**

```
分析用户的感受地图演进轨迹
识别「下一步最自然的扩展方向」

就像学习路径一样
「你已经深入了A，B和C是自然的下一站」
不是随机推，是有逻辑的成长引导
```

---

## 四、推荐的边界

```
推荐系统不做的

不推强度超过用户当前TCP上限的感受包
    安全边界不因为推荐而松动

不推用户明确拒绝过的方向
    拒绝即信号，记录，不重复

不在用户状态不好时推高挑战性内容
    四诊判断状态低于基准，推荐切换到稳定性感受包

不替代用户的主动选择
    推荐是建议，不是指令
    用户随时可以忽略推荐，直接从立方体开始
```

---

## 五、推荐系统的数据基础

```
输入数据
    感受地图坐标（已探索的维度和深度）
    个人基准（当前神经系统基线）
    四诊实时状态（当下的感受方向）
    感受包内核置信度（感受包质量评分）
    社区数据（脱敏的群体感受模式）

算法
    不是纯协同过滤（「喜欢X的人也喜欢Y」）
    而是感受地图空白检测 + 状态匹配 + 成长路径分析
    三个维度加权，动态调整

隐私
    推荐计算在本地完成（个人数据不离设备）
    只有脱敏的感受包受欢迎度数据上传
    推荐结果是本地生成的，不是服务器下发的
```

---

## 六、推荐系统和反依赖设计的关系

```
矛盾点    推荐系统的本质是「让用户继续使用」
          这和反依赖设计有张力

解法      推荐的目标不是「让用户继续用Feelings」
          而是「让用户的感受地图继续扩展」

          当感受地图扩展到一定程度
          推荐系统的建议会越来越多地指向真实生活
          「你的感受地图在这个维度还没有真实生活的坐标
           推荐你去做X，不是体验感受包」

推荐最终指向外部    不是把用户锁在Feelings里
                    而是帮用户在真实生活里找到感受的入口
```

---

*推荐系统是工具，不是引导者。高控制权的用户拿着这个工具，探索自己的感受地图。*
