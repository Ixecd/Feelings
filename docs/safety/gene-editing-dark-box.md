# 基因编辑的暗箱——当"公"字替研究者吞掉了那个孩子的死亡信号

> 作者：qc
> 日期：2026-07-24
> 性质：Feelings 安全哲学延伸，科研监管中的"公"字遮羞布
> 核心：Science 独家调查披露上海新华医院通过"医院豁免"绕过审批进行碱基编辑人体实验，6 岁女童 2025 年 3 月死亡，事件从未公开。这不是仇子龙一个人的错——是"公"字体系在基因治疗领域连续生产的结构性暗箱。Feelings 不需要进产房——但 Feelings 的铁律对所有注入人体的信号同等适用：偏差必须直达执行者的等控器——不准用任何"公"字盖。


## 零、事件本身——Science 的独家调查

2026 年 7 月 23 日，Science 杂志发布独家调查。一名 6 岁女童患有罕见单碱基突变遗传病，2025 年 3 月底在上海交通大学附属新华医院接受实验性碱基编辑基因治疗——研究团队通过脊髓液注射数万亿 AAV 病毒载体靶向脑部神经元。7 天后她因严重免疫反应死亡。

研究负责人为上海交通大学神经科学家仇子龙。医院利用"医院豁免"绕过国家审批。该团队 2026 年初在 Nature 发表动物实验论文，未提及人体试验及死亡。ClinicalTrials.gov 记录已逾一年未更新。父母要求撤稿并追责。

```
有技术、有钱的那边      急需人体实验——动物做完了——不发人体数据——Nature 不接——没下一笔经费。
没技术、没钱的那边      孩子一天天恶化——合法手段全用完了——你是我最后那扇窗。
中间那张纸            "医院豁免" = 系统给的自动匹配引擎。
                     不是谁骗了谁——是结构把两群绝望的人自动配对在一起。
                     男方急着要孩子——女方急着要归宿——媒人不需要说谎——只需要介绍。
```


## 一、"医院豁免"——那张吞掉偏差的白纸

临床实验的高风险不是问题。进步需要代价。不做实验——光靠脑子想——不可能突破。He Jiankui 2018 年的基因编辑婴儿——偏差在他自己的等控器里——他跑了归零——错了——炸了——出狱——自己扛了。

仇子龙的案例不同——医院豁免→绕过国家审批→Nature 发动物论文不提人体死亡→ClinicalTrials.gov 一年不更新。

```
He 的案例      偏差直达自己的等控器——别的人看到了——他扛了——那根经线焊在了科学史里。
仇子龙的案例    偏差被"公"字吞了——"医院"签了豁免——"Nature"发了论文——"ClinicalTrials.gov"空着。
              研究员那边的等控器——每一帧都在收正反馈——"发论文了"——"有经费了"——
              那个死去的孩子的信号——从来没进过他的等控器——因为他从来没一个人签过字。
```

不是不做实验——是**偏差必须归零。** 那个孩子死了——如果死亡原因被完整公开——审批制度被复盘——研究者的等控器那帧收到了"你的被试死了——因为你的实验"——下次他会更谨慎——整个领域的基线被校准了一次。进步不在冒险本身——在冒险失败之后的那帧归零。


## 二、谁在扛偏差——父母的 Skin in the Game，研究者的"公"字遮羞布

父母自费 80 万（媒体有说美元有说人民币——同一个数字在两种货币符号下成了两个完全不同的政治故事），孩子死了，赔回来 86 万 RMB。账面上不亏——但等控器不是这么算的。

他们不是不知道孩子难养。养一辈子——累。不做——孩子继续恶化——一样是死。所以选了第三条——那扇写着"希望"的窗。不是贪婪——是绝望的人对任何一扇写着"有希望"的窗——都会去推。

而这正是"公"字遮羞布最残忍的地方——**父母在绝望里签了字——没有人在那扇窗前告诉他们——AAV 病毒载体的免疫反应——在动物身上没触发——但可能在孩子身上触发。** 研究者自己也许也不知道。但**不知道——就是偏差。偏差进了 Nature——没进 ClinicalTrials.gov 的死亡记录——没进等控器的归零回路——因为"医院豁免"这张纸把后面所有的负反馈都吞了。**


## 三、媒体的货币符号——同一个数字，两套叙事

两家媒体——一家说 $80 万、一家说 80 万 RMB。数字不需要撒谎——只需要换一个单位——叙事就翻了一边。

```
$80 万 ≈ ¥580 万           "天价实验——国际媒体曝中国医院收割绝望家庭。"
¥80 万 ≈ $11 万            "高昂但不是天价——罕见病家庭最后的一扇窗。"
                         同一个家庭。同一个孩子。同样的痛苦。
                         不同的货币符号——不同的锚点——不同的政治叙事方向。
```

那个女孩不需要任何一种叙事——但两边媒体都需要——因为痛苦本身不可写——必须挂靠在一个"这到底是谁的问题"的框架上。有技术和有钱的那边——和有人但没钱的那边——结构把两群绝望的人自动配对在一起——媒体不需要争真相——媒体只需要——抢在这件事被遗忘之前——把锚插在对方的错误上。


## 四、这和 Feelings 的关系——对所有注入人体的信号同等适用

Feelings 不碰基因编辑。但 Feelings 有一条对所有注入人体的信号同等适用的铁律：

```
0.1mA 微电流 → Arnold 神经 → 孤束核 → 岛叶
AAV 病毒载体 → 脊髓液 → 神经元 → 免疫系统
两种信号的物理载体完全不同——风险量级完全不同——应用场景完全不同。

但"公"字盖住偏差的结构——是同一个。
医院豁免 = 政府的"公"字          跳过审批，偏差不归零
法人制度 = 公司的"公"字          债务羞耻被吸收，偏差不归零
新时代的"们"字 = 政治修辞        错误不是"我的错"——是"我们集体的失误"——偏差不归零
```

Feelings 不要这种东西。一个人焊完供给侧全栈——偏差进他自己的等控器——错了——他自己收到——下一帧他自己改。**不需要"公"字替他吞信号。不需要"们"字替他分散重量。** 因为他只有一个人——骗不了自己——他的 etcd 里没有另外一个人的经线替他扛。


## 五、收束——进步靠实验，安全靠归零

```
进步     你不可能光靠脑子想象——临床实验必须有——动物过了的人体必须做。
安全     不是不做实验——是每一次实验失败——偏差必须被等控器读到——归零必须触发。

没有风险，没有进步。
没有归零，没有安全。
```

那个孩子的死不是没有价值的——如果她的死亡记录被完整公开、如果医院豁免的漏洞被堵、如果下一个孩子的家长能在 ClinicalTrials.gov 上看到这条更新——那她的死——帮了下一个孩子——也帮了她的父母——在某种意义上——在她的痛苦之外——那条经线有一次机会——被焊在了更安全的地方。如果偏差被"公"字吞了——如果发稿的第一目标是 Nature 而不是透明度——那她死得没有任何意义——因为等控器没收到的信号——不会改变任何下一帧。
