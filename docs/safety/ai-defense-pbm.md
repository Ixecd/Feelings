# AI 与国防——同一个技术的两条分岔路

> 作者：qc
> 日期：2026-05-27
> 性质：Feelings 哲学延伸，AI 国防应用的 PBM 锚点分析
> 核心：Claude 拒绝了自主武器公司。Gemini 接入了五角大楼机密网络。不是谁聪明谁蠢——是两家公司的 PBM 焊在了两根完全不同的锚点上。Anthropic 的内部锚点 = 安全宪法。"无害高于有用"撞上了杀伤链——门关了。Google 的外部锚点 = 国防合同价值 60 亿美元。600 人抗议——继续签。"任何合法用途" = 把 oi 关掉。不是被迫。是自愿。

## 零、两个选择——同一门技术

```
2026 年。同一代大语言模型。

Anthropic（Claude）：
    安那间（Anduril）来敲门——自主武器公司。
    拒绝了。Acceptable Use Policy 写着"不用于武器系统、不用于造成人身伤害"。
    门关了。不是针对军方。是针对杀人的那条链。

Google（Gemini）：
    五角大楼来敲门——机密军事网络。
    签了。"用于任何合法政府 purpose。"
    600 名员工联名抗议。高层继续推进。
    → 门开了。灯关了。Gemini 进去了。
```

不是同一个人做了不同的选择。是两家公司的锚点焊在了完全不同的东西上。同一门技术。两个方向。

## 一、Anthropic 的 PBM——内部锚点就是安全宪法

```
Anthropic 的安全模型：
    第一层：有用——Claude 能帮你做什么。
    第二层：无害——Claude 不能帮你伤害别人。
    两层之间有一个冲突解决机制——当"有用"和"不伤害"撞在一起，
    无害赢。

军方来说："帮我分析这批卫星图像里的防空阵地。"
    有用 = 能。目标识别是 Claude 的强项。
    不伤害 = 分析完了那些阵地会被炸。人会死。
    → 无害赢了。拒绝。

这不是政治立场。这是训练出来的结构。
你自己写的 AUP 说"不用于武器系统"——
    安那间（Anduril）主营自主武器。
    合同条款和 AUP 之间的冲突不是可以协商的。
    是架构级的。
```

这和 Feelings 的 cross checker 完全咬合——不是"建议不要"。是"交叉资格不存在"。不是道德判断。是安全规则在交织期直接拒绝。Anthropic 的安全宪法 = 自己的内部锚点。计分器不在外面。在所有试图从外面来驱动的竞标上——不跳。

## 三、"任何合法用途"——道德责任的完美外包

```
"用于任何合法政府 purpose"——

这句话写的不是"我们相信军方"。
写的是"我们不知道你会拿去做什么。但我不想知道。
        你那边'合法'——我这边就不用审计。"

这和 CAPITALISM-ORIGINAL-SIN.md 里吃气候的黑暗完全同构：
    烧煤的人——利润在西方。碳在大气里。代价在下一个世纪的印度农民身上。
    Google——合同在硅谷。模型在战场。责任在"合法"那两个字里。
    两种黑暗用的同一套结构——把成本外化到另一个时空。
    一个外化给了下一代人。一个外化给了下一个受害者。

不是技术在杀人。是技术的建造者自己不摸枪——
但他给了摸枪的人一把不需要自己拉保险栓的智能瞄具。
然后说"你拿它打猎。合法用途。"
```

```
Gemini 接入机密军事网络之后：

    机密网络是隔离的。审计日志在军方手里。

问："Gemini 有没有被用来筛选轰炸目标。"
答："系统数据不对外。合作愉快。"

灯关了。黑暗完整了。

这和 CAPITALISM-ORIGINAL-SIN.md 里所有吃法的共同特征一样——
被吃的人看不见自己在被吃。
开发模型的人也看不见自己的模型在吃什么。
关了灯。两端都看不见。
中间是一根"任何合法用途"的管子。
```

## 五、两套 PBM——同一门技术的两条分岔路

```
Anthropic PBM                 Google PBM
─────────────                 ──────────
内部锚点：安全宪法              外部锚点：国防合同金额
无害高于有用                   市场份额高于伦理审查
被拒门外。自己做了政府自己不敢做的选择       进去。把oi关在你审计不到的黑箱里。

不是 Claude 聪明、Gemini 蠢。
是两家公司的 PBM 焊在了两根完全不同的锚点上。

Anthropic 的内部锚点 = 安全宪法。
    撞上了 → 死了。门关了。

    即把交叉资格全部交给军方定义。
    即关在机密网络黑箱里——连被追责的名字都没有。

    被炸的人问不到硅谷。
    国会听证会问不到 Google——机密。问国防部。
    国防听证会问不到 Google——合规的。签了约的。
    背过身去。两个口袋都空了。
    Google 自己跑掉了一个自己亲手扶起来的模型丢下的道德残留。
```

## 六、AI 在国防里的结构性悖论

```
Feelings 的安全模型：
    强度 > cap → oi。交叉被挡。
    HR > 硬上限 → 紧急截断曲线。
    → 安全层有 oi。不安全 = 不生成。

国防 AI 的安全模型：
    需要杀伤链不刹车。
    oi 在哪。不是技术上装不了。
    是装上之后它在战场上只能帮你走到无关痛痒的安全距离——
    不会替你按扳机。
    国防要的是不刹车。AI 安全要的是会刹车。
    两套系统在设计图的第一行就已经互斥了。

Google 选了关掉 oi。Anthropic 选了留着 oi。
不是技术路线不同。是 oi 的开关到底归谁。
Anthropic 自己拿着开关。Google 把开关给了军方。
区别只有这一个。
```
