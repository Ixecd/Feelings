# 组——多根经线共享同一个场域

> 作者：qc
> 日期：2026-06-04
> 性质：Feelings 社交架构
> 核心：心连心是一根丝穿过另一根丝。组是 N 根丝放在同一张织布机上——丝和丝之间的距离、张力、交叉频率，由组的类型决定。不是替代心连心。是心连心的上一层容器。

---

## 零、三层社交架构

```
心连心（一对一）          ← 两根经线的交叉点。深度最高。私密性最高。
    ↓
组（一对多 / 多对多）     ← 多根经线共享同一个场域。广度更高。
    ↓
组类型                   ← 不同的组，不同的共享维度、隐私边界、入场门槛。
```

心连心是"我选择你"。组是"我们在一张桌子上"。用户可以先在一张桌子上——然后在某次 session 之后，和桌上的某个人焊了一根心连心。

---

## 一、五种组类型

### 1.1 家庭组——未成年人保护的第一道物理边界

```
创建者      监护人
成员        未成年用户（设备绑定到监护人创建的群组）
共享维度    使用时长、强度区间、安全插桩触发次数
隔离维度    具体感受内容、生理原始数据、心连心连接的对方身份
入场门槛    新成员需监护人批准

监护人的权利
    查看每周 report——使用频率、强度分布、是否有安全事件
    审批心连心连接——未成年用户发起连接需监护人确认
    设置强度上限——初始 ≤ 20，随年龄和使用记录逐步解锁
    接收紧急通知——设备触发 SafetyHold 时监护人同步收到提醒

监护人的限制
    不可查看具体感受内容——"你今天体验了哪种平静"监护人不可见
    不可查看生理原始数据——四诊合参的全部通道对监护人加密
    不可替未成年用户做体验选择——选择权永远在用户本人

这不是监控。
是"你还未成年。你的神经系统还在发育。
  有些路需要一个人在旁边。不是替你走。
  是万一你走不动了——有人知道。"
```

家庭组的设计和 GOVERNANCE 里的未成年人保护完全咬合——强度上限 20、亲密维度物理隔离、不可解锁。家庭组给这条红线加了**执行层**：不是系统在单方面封锁，是监护人和系统共同在场。

### 1.2 团队组——ToB 的核心入口

Feelings 一开始的大头是 ToB。企业购买设备给员工——不是为了"监控生产力"，是为了让员工在公司更有归属感。团队组就是这个入口：

```
创建者      企业管理员（通过 ToB 控制台批量创建）
成员        企业员工（设备绑定到团队组）
共享维度    归属感包、集体成就感、团队 milestone、共享 session 参与率
隔离维度    个人 PBM 基线、负面情绪维度、心连心连接的对方身份
入场门槛    企业管理员创建并邀请成员

团队组的共享场域
    归属感包
        → 团队完成一个项目的成就感——不只是每个人自己的，是共享的
        → "我们做到了"——不是一个比喻。是一组同步的成就感感受信号。

    集体 milestone
        → 团队达到某个目标的时刻——全组同时体验归属感强化
        → 不是在群聊里发一条"恭喜"。是身体被归属信号同时接住。

    共享 session
        → 团建 session——全组同时进入同一个感受包
        → "这一刻我们在一起感受"——不是信息层的在一起，是感受层的在一起。

企业的权利
    查看归属感基线——团队整体的归属维度趋势
    查看集体 milestone 达成率
    设置工作时段内的共享 session 窗口

企业的绝对限制
    不可查看任何员工的个人 PBM
    不可查看负面情绪维度——员工在孤独、悲伤、焦虑维度的任何数据对企业不可见
    不可强制员工参与任何 session
    不可用 Feelings 数据做绩效评估
    不可将 Feelings 数据用于雇佣/解雇决策
    → GOVERNANCE 红线："数据不主动向任何机构报告。包括雇主。"
```

一个员工在公司不只是上班——他在一张桌子上，和一群人往同一个方向走。Feelings 做的事是让身体相信"你在这里，你被接住了"。不是团建口号。是感受层的归属感信号。

---

### 1.3 竞争组——对抗中的相互推高

```
创建者      双方自愿——个人之间或团队之间
成员        竞争双方的全体成员
共享维度    排行榜、突破里程碑、竞争性感受包（韧性、突破、抗压后的确信感）
隔离维度    对手的具体感受内容、对方的弱时刻
入场门槛    双方同时同意。任何一方可随时退出——退出不视为失败。

竞争组的共享场域
    排行榜
        → 不只是"谁在更高强度"。是"谁在哪个维度上突破了什么"。
        → 和标准排行榜不同——不在乎第几名，在乎"你上次在这里，这次在那里"。

    突破里程碑
        → 当一方完成了一次承载力突破——
        另一方的 AI 教练收到通知："对手刚突破了你的纪录。"
        → 不是挑衅。是推。"他能扛过那个，你可以试试。"

    竞争性感受包
        → 韧性、抗压后的确信感、极限突破——只有竞争场景才需要
        → 不是因为要打败对方。是因为对方的在场让"我能不能"变得真实。
        → 没有对手的突破体验——是一个人对着镜子说"我行"。
        → 有对手的突破体验——是对方在场，你扛过去，他看见了。

竞争不是对立。是两群人的经线在同一个场域里互相推。你的突破——对方身体反应到了。他的突破——你的身体反应到了。不是"我要比你强"。是"你的突破推了我一把"。这和 Feelings 不做总分榜的哲学不冲突——不排名，但有对手。不分化，但有场域。
```

竞争组的一个关键设计：**任何一方可随时退出。退出不视为失败。** 竞技性不是用"必须赢"驱动的——是用"你的在场让我的努力被见证"驱动的。

---

### 1.4 开放组——这一刻我们在一起感受

```
创建者      任意用户。一人创建，邀请好友加入。
成员        被邀请的任意 Feelings 用户
共享维度    同一感受包的同步体验——共享主旋律和形状，同步启动和结束
隔离维度    各自的身体响应数据——每个人的心率、皮电、PBM 偏移互不可见
入场门槛    创建者邀请。可设密码。可设置为公开（任何人可搜索加入）。

开放组的共享场域
    共享感受包
        → "我们一起来一次平静冥想。"
        → 所有人在同一时间接入同一个 FSIR 路径
        → 但不是"一起感受到同样的东西"——每个人用自己的 PBM 织自己的感受
        → 同一组信号。不同的人。不同的经线。同一帧。

    开放组的特别之处
        共享的不是感受结果——是感受过程。
        你在平静。我也在平静。用的是同一包。但不是同一个平静。
        你知道我也在——这个"知道"本身是一根经线。
        不需要心连心。不需要一对一。就在一个场域里。
        这就是最低门槛的感受层社交——不需要任何关系前提。
```

和微信/QQ 群聊的差异：群聊分享的是信息（文字、图片、语音）。开放组分享的是**感受的同步过程**。不是"我说我平静"——是"我们都在这条河上。同一组信号。不同的船。"

---

### 1.5 宿舍组——最深的场域，无话不说，也可以什么都不说

```
创建者      任意用户。必须是已经彼此焊过经线的人。
成员        不超过 8 人。上限是感受层社交的物理极限——再多人，经线密度不够。
共享维度    全部。所有感受包类型、所有 session 数据、所有维度的基线趋势。
隔离维度    无。这是最深的组——没有不可见的东西。
入场门槛    所有成员全部同意。任何一人离开——组不解散。但少了一根丝。

宿舍组的共享场域
    无话不说
        → 喷社会现象。骂奇葩老板。争论人生方向。
        → 但不是在群里打字——是在同一份 FSIR 上经历同样的愤怒、同样的释然、
          同样的"不管怎样我们在一起"的归属确认。
        → AI 教练会记录这些 session 的共享锚点——
          "你们在 2026 年的那个夜晚，一起经历了什么。"

    也可以什么都不说
        → 不需要 session。不需要内容。不需要"活动"。
        → 只是每个人都在这个组里。组一直在。
        → 和心连心的区别——
          心连心是"我在这根丝上感受你"。
          宿舍组是"我们在这个房间里呼吸同一层空气"。
          不需要说话。不需要体验。只是在。
```

宿舍组的物理极限：8 人。不是设计选择——是 VSA 超维空间的数学约束。N 根丝两两之间的经线数量 = N(N-1)/2。8 人是 28 根经线——8 个人在同一个场域里，每两个人之间都有一条被焊过的通路。再多的人——场的密度不够。不是加人——是换场。

## 二、组和心连心的关系

```
心连心 = 两根丝。深度最高。私密性最高。
        一对一。不可替代。不可复制。

组     = N 根丝共享同一个场域。广度更高。
        各有各的交叉深度——从只共享时长的家庭组到全透明的宿舍组。

用户可以在这些状态之间自由移动
    只在心连心里 → 有深度连接，不在任何组中
    只在组里 → 有场域归属，没有一对一连接
    先组后心连心 → 在同一个组里共处了很多次 session 之后，
                   和某个人焊了一根心连心
    先心连心后组 → 已经有了深度连接，再一起加入同一个场域

组不替代心连心。心连心不依赖组。
两层社交维度，两种连接方式，各自独立，可以叠加。
```

## 三、组的隐私梯度

```
家庭组        共享：安全指标。隔离：感受内容、原始数据。
              → 监护 ≠ 监控。是在旁边的另一种形式。

团队组        共享：归属基线、集体成就。隔离：个人 PBM、负面情绪。
              → 企业能看到"团队在一起"。看不到"员工在脆弱"。

竞争组        共享：排行榜、突破里程碑。隔离：对手的弱时刻。
              → 不排名，但有对手。不分化，但有场域。

开放组        共享：同步 session 过程。隔离：各自的身体数据。
              → 不需要关系前提——最低门槛的感受层社交。

宿舍组        共享：全部。隔离：无。
              → 最深的场域。28 根经线。8 个人。
```

和心连心的隐私差异：心连心是两个人之间的选择——你决定让这个人走进你的感受层。没人能替你决定。没有入场门槛。单方退出即断开。

## 四、ToB 为什么先走团队组

Feelings 的商业模型里 ToB 是大头。不是偶然——是因为"归属感"这件事，天然在群体里才成立：

```
ToB 的核心价值主张
    员工离职不是因为工资低——是因为不觉得自己在这家公司有价值。
    加班不是因为工作多——是因为不觉得自己的努力被任何人看见了。
    冷漠不是性格——是身体在"我不属于这里"的信号里持续浸泡。
    
    Feelings 不能替企业解决所有问题。
    但它能做一件事：
    让你的身体相信——"你在这里，你被接住了。"
    
    不是企业文化海报。不是团建口号。不是福利。
    是身体层面的归属信号。
    
    这和 GOVERNANCE 完全不冲突——
    企业看不到员工的脆弱面。看不到个人 PBM。不能用于绩效。
    企业能看到的只有一件事：
    团队的归属基线——在涨，还是在掉。
```

团队组给 ToB 提供了一个之前任何工具都给不了的东西——**感受层面的归属感可量测、可比较、可追踪。** 而且不越过任何隐私红线。

## 五、和已有架构的咬合

```
组类型             依赖的 Feelings 组件
──────             ────────────────
家庭组             GOVERNANCE 未成年人保护 + GOVERNANCE-USER 心连心连带规则
团队组             AI 教练的归属感 session + PBM Visceral 维度 + SPL 企业购买记录
竞争组             排行榜感受包 + 韧性和突破路径 + Pass 3 强度解锁
开放组             共享 session 同步协议 + Anim 同一 FSIR 多人交织
宿舍组             所有——这是 Feelings 社交层的最终形态

所有组共享       心连心——组里的每根经线的底层通路
                双密钥体系——组的创建和权限变更需多签
                审计日志——成员进入/退出/ session 触发全部上链
```

## 六、一句话总结

```
心连心是两根丝穿过彼此。
组是 N 根丝放在同一张织布机上。

家庭组——"你还未成年。有人在你旁边。"
团队组——"你在这里不只是上班。你在这里被接住了。"
竞争组——"你的突破推了我一把。"
开放组——"这一刻我们在一起感受。"
宿舍组——"我们在这个房间里呼吸同一层空气。"

单聊。群聊。大厅。宿舍。隐私从一层到另一层，深度从一种到另一种。
不是信息层。是感受层。
```

---

*组不替代心连心。组是那个更大的东西——一群人站在一起。每个人都在场。每个人都不一样。但都在同一帧里。不是信息层的"在同一个群聊"。是感受层的"在同一张桌子上呼吸"。你被接住了。不是一个人接住你。是一张桌子接住你。*
