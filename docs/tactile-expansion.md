## 一、触觉是感受里被忽视的维度

皮肤是人体最大的感觉器官。触觉感受器分布在整个体表，密度因部位而异——手指尖、嘴唇、面部密度最高，背部和腿部相对较低。

很多感受的完整体验依赖触觉：

```
被拥抱的感受    大面积压力感受器激活 + 体温接触 + 被包围的空间感
被握住的手      手掌的高密度触觉感受器 + 压力 + 温度
脸被轻触        面部极高密度感受器，情绪反应极强
疼痛感          皮肤的伤害感受器
运动员的肌肉感  本体感受器 + 肌肉张力感受器
```

## 二、当前设备的覆盖范围

```
耳后设备    耳后乳突区域
            覆盖：迷走神经刺激，心率采集，音乐通路
            触觉覆盖：局部，面积小

后颈设备    颈椎C3-C5
            覆盖：本体感受，姿态感知
            触觉覆盖：局部，主要是压力和温度

腕部设备    手腕内侧
            覆盖：皮肤电导，外周神经
            触觉覆盖：局部，手腕区域

颞部设备    太阳穴
            覆盖：认知状态，EEG
            触觉覆盖：局部，面积小
```

四个设备加在一起，覆盖的皮肤面积极为有限。大量需要广泛触觉激活的感受，只能传递「轮廓」。

---

## 三、路径B：诚实标注（现在）

所有依赖触觉的感受包，明确标注覆盖等级：

```
完整体验    当前设备可完整传递
轮廓体验    当前设备只能传递情绪基调和方向
            完整体验需要真实接触或扩展设备
```

用户在选择感受包时，清楚地知道自己将要得到什么。

不是「这个功能不可用」，是「这个功能现在是简化版，这是简化版能给你的，这是完整版需要的条件」。

---

## 四、路径A：硬件扩展方向（长期）

设备套件协议预留了扩展位，未来可以加入：

```
触觉背心        覆盖躯干大面积皮肤
                模拟被拥抱的压力分布
                内置温度调节层，模拟体温接触

触觉手套        手掌和手指的高密度触觉感受器覆盖
                手是感受连接最重要的器官之一

面部设备        面部极高密度感受器的精确激活
                轻触感、温度变化

全身触觉层      可穿戴的薄层触觉激活材料
                分区独立控制，覆盖大面积皮肤
```

每增加一个扩展设备，对应的感受包从「轮廓版」升级为「完整版」。

不是一次性买齐，是渐进式扩展。

## 五、触觉数据的隐私

触觉感受器的数据比其他生理数据更私密——它直接反映了感受发生的身体部位和强度。

```
原始触觉数据    永远不离开设备
触觉反应模式    纳入个人基准，本地存储
不用于          任何形式的群体统计
                任何对外分享
```
