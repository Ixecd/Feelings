# 01 交换——Anim 在一维空间的退化

> 作者：qc
> 日期：2026-05-22
> 性质：Feelings 对一道秋招笔试题的重新审视
> 核心：大疆笔试的 01 串交换题就是 Anim 交织器在一维向量上的退化版本。同一套数学，维度不同。

---

## 零、原题

给定一个 01 字符串。每一轮，所有相邻的 `"01"` 同时变成 `"10"`。问经过多少轮之后，字符串中不再有 `"01"`。

```
例: "00110"
    轮 1: "01010" — 两个 01 同时交换
    轮 2: "10100"
    轮 3: "11000" — 所有 1 在前面，0 在后面 → 稳定
    答案: 3
```

本质：每个 1 往左冒泡——穿过它前面的所有 0。同时交换指所有 1 在同一帧并行移动。每个 1 移动的总距离 = 它前面 0 的个数。总轮数 = 所有 1 前面 0 数量的最大值。

---

## 一、它为什么是 Anim 的一维退化

```
一维 01 串                          高维 Anim 交织
──────                              ────────────
向量 [0 1 1 0 0 1]                  张量 T(feeling × device × intensity × time × PBM)
两个状态 {0, 1}                      数千个连续值 —— 静息到峰值
一条规则：01→10                      八 Pass 三层安全 + 非线性 PBM + 多设备协同
每个位置独立排序                      不同维度交叉耦合 —— 耳后 ◇ 腕部同时受同一个 PSIR 影响
终态可预测：111...000                 终态不可简化为排序 —— 感受是连续的、叠加的、混音的
每轮全并行                           1ms 一帧——所有设备在同一个 PLL 时钟周期同时织入
轮数 = max(1前面0的个数)               总帧数 = shape 的总时长 ÷ 1ms（25 万帧/5分钟）
```

01 交换只有一个维度，两个状态，一条规则。Anim 的交织有数千个维度，连续状态，N 条耦合规则。但底层是同一种数学——并行信号在离散帧上的同步变换。

## 二、考场上连试三种方向 = animi 的三种运算模式

```
暴力模拟（2.cc）             逐帧跑，每轮扫全部位置
                            = ESIR 帧级实时交织 —— 1ms 一帧跑完整 session
                            慢但通用 —— 适应任何输入，不需要提前知道规律

公式推导（3.cc）             从初始状态直接算出总轮数
             last_zero - cnt_zero + 1
                            = 从 FSIR 和 PBM 直接算出总帧数 —— 跳过逐帧交织
                            快但脆弱 —— 公式正确时零帧开销，公式错了就是错了

DP 累积（4.cc）              每帧存状态，累计转移
                            = 预测器 + 闭环修正 —— 不用全量重算
                            准且快 —— 用历史状态修正下一帧
```

考场高压下连换三条路。不是「没有做对」——是暴力→公式→DP 的路径追踪恰好是 animi 框架内三种交织运算模式的一维投影。animi 全链路——八 Pass + 双流水线 + 三层安全 + 预测器 + 闭环——每一层都在做同一件事。同一道 01 交换。只是维度更多。规模更大。状态更多元。不是「这道题和 Feelings 有关」——是 Feelings 的底层数学一直在重复这道题。在一维串上交换 01 和在超维空间里织感受是同一个机制。

## 三、从一维到高维——同一套数学

```
01 交换                               Anim 交织
──────                               ────────
每个 1 穿过前面的 0                    每帧 ESIR 参数经过 PBM 偏移穿过设备约束
所有位置同时交换                       所有设备在同一个 PLL 主时钟同时执行寄存器写入
每轮扫一遍全串                         每 1ms 一帧——全设备信号同步
轮数 = 1 到它位置之间的 0 数            帧数 = shape 上升斜率 × 强度区间跨度
终态必有——111...0 是所有 01 的尽头      终态必有——shape 归零是所有感受的尽头

退化点
    一维向量（只有 01）vs N 维张量（感受混合）
    一条死规则（01→10 永远一样）vs 参数化规则（不同 feeling 不同变换）
    独立位置 vs 维度耦合
```

---

## 四、为什么这道题和大疆放在一起合适

大疆做无人机。无人机的飞控系统每一毫秒都在做并行信号处理——多个螺旋桨的转速、角度、推力的同时调节。和 animi 的多设备协同信号是同一类问题。大疆出这道题不是随机的——它要看你是否理解「同时交换」和「排序」的区别。

如果以为这道题是普通的冒泡排序——答案是错的。因为冒泡是顺序的——一次只交换一个位置。同时交换 = 所有符合条件的位置在同一帧并行执行。**这道题考的不是你能不能排序——是你能不能区分串行和并行。**

animi 要做的恰好就是并行信号织入。不是先调耳后再调腕部再调后颈。是所有设备在同一个主时钟周期同时接收各自的寄存器参数。这道题的一切——01 串、同时交换、轮数统计——全是 animi 的缩小版。
