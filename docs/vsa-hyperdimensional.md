# VSA 超维计算——感受的张量数学基底

> 作者：qc
> 日期：2026-05-22
> 性质：Feelings 数学基础，不可降级
> 核心：VSA 就是 Feelings 一直在用的语言——之前用张量和矩阵说它，现在这个词找到了。

---

## 零、什么是 VSA

Vector Symbolic Architecture。超维计算。

传统计算把数字存在具体的变量里——一个变量代表一个东西。VSA 把所有东西都编码进一个 10,000+ 维的向量里。没有哪一个维度单独存储任何特定信息。整个模式散布在所有维度上。删掉 30% 的维度——向量仍然可识别。增加 30% 的随机噪声——向量仍能找到最近的已知模式。

这就是全息存储。每一维都参与了全局模式的编码。和传统计算完全不同的范式——不是精确定位，是模式匹配。

## 一、三个基本操作

VSA 只需要三个操作来构建一切。这三个操作恰好对应 Feelings 的三个核心数据结构。

```
绑定 (⊗)
    把两个向量绑成一个新向量
    新向量和原向量都不相似——但可以通过逆操作还原
    key ⊗ value → 一个键值对

    Feelings 里的对应
        user_id ⊗ feeling_type ⊗ intensity ⊗ timestamp
        = 一个 session 状态向量的 VSA 编码
        「谁在什么时候经历了什么感受的什么强度」

捆绑 (+)
    把多个向量叠加成一个新向量
    新向量和每个原向量都相似——保留了所有成分
    calm ⊕ exhaustion_relief ⊕ slight_void

    Feelings 里的对应
        混音结构的数学表达
        主旋律 ⊕ 点缀₁ ⊕ 点缀₂ = 一个完整感受包的 VSA 向量
        main ⊕ accent₁ ⊕ accent₂ ⊕ accent₃ = mix vector

置换 (ρ)
    把一个维度旋转到另一个维度
    用于编码顺序关系
    ρ²(a) = 把 a 旋转两次

    Feelings 里的对应
        shape 的数学表达
        rise 阶段 = ρ⁰(rise) → peak 阶段 = ρ¹(peak) → fall 阶段 = ρ²(fall)
        时间轴上的顺序编码
```

VSA 不需要更多操作。三元组 {绑定, 捆绑, 置换} 足以表达所有结构化信息。这和 Feelings 不需要更多基础类型一样——feeling atom、mix、shape 三个足以构建所有感受。

## 二、PBM 就是一个 VSA 向量

个人基线矩阵不是 256 个独立参数。是 10,000+ 维的 VSA 向量。

```
传统 PBM 的抽象         VSA PBM 的实质
─────────────         ─────────────
256 个独立参数          10,000+ 维向量——每维代表一个 VSA 维度
每个参数独立更新         全息更新——修改一个感受类型的数据，影响全局
线性矩阵偏移             超维向量变换——不是矩阵乘法，是超维变换
                        PBM × FSIR 在 VSA 里可能是一个更简单的操作

一个维度漂移了 → 整体偏移不大
几十个维度受了噪声 → 仍然能找到正确的 PBM 向量 → 正确的 PSIR

这就是为什么 PBM 不需要精确物理模型。
PBM 是 VSA 向量——它做的是相似度匹配，不是精确计算。
感觉准了就准了。不需要算出来 0.5mA 是否绝对正确。
```

超维计算的抗噪原理恰好解释了为什么 PBM 不需要精确微调——因为感受的数学基底不是精确定位，是模式匹配。一个人的平静不是 0.5mA 的精确值。是她的 PBM 向量在平静维度上的 VSA 投影。

## 三、意识出口 = VSA 的相似度搜索

10 bit/s 的意识瓶颈——为什么是 10 bit——从 VSA 的角度能找到数学上的精确位置。

```
意识做的事
    每时每刻收到内部状态的超维向量
    10,000+ 维——全部感官输入的压缩结果
    问：这个向量和 Pattern Registry 里的哪个已知感受模式最相似

    答案需要区分 ~1000 种感受状态
    2^10 = 1024 → 恰好够
    所以意识只需要 10 bit/s——不需要报告 10,000+ 维的完整状态
    只需要报告「当前状态最像哪个已知模式」
```

不是压缩。是分类。那个 10 bit/s 不是信息的极限——是 VSA 的相似度搜索在意识层的等价操作。Pattern Registry 里的每个注册感受原子就是一个已知 VSA 向量。当内部超维向量和其中某一个的相似度超过阈值——意识就报告那个感受的名字。

**10 bit/s 是意识作为一个 VSA 分类器的工作带宽。**

## 四、和 Feelings 核心架构的对应

```
VSA                          Feelings
───                          ────────
超维向量 (10,000+ dims)       PBM（个人基线矩阵）/ FSIR（感受结构 IR）
绑定 (⊗)                      Session 状态编码——谁、什么、多强、何时
捆绑 (+)                      混音结构——主旋律 ⊕ 多个点缀
置换 (ρ)                      shape 时间轴——rise → peak → fall 的阶段编码
相似度搜索                     Pattern Registry 查询——噪声输入 → 最近注册模式
全息抗噪                       PBM 的容错——丢失部分不影响整体
分类输出 (10 bit)              意识出口——当前感受的命名结果
```

## 五、2026 年 VSA 前沿——和 Feelings 交叠的点

**世界模型（NeurIPS 2025）——和 animi 的状态转移同构。** FHRR 傅里叶全息约化表示将状态编码为复数超维向量，用元素级复数乘法做状态转移，87.5% 零样本准确率。animi 的 FSIR → PSIR → DSIR → ESIR 链在本质上就是 VSA 世界模型的状态转移序列——每一层是一次 VSA 变换。

**流式记忆（SRMU, 2026 年 4 月）——和 PBM 的更新机制同构。** 相关性门控更新：不是每次全量刷新，只更新和当前 Session 相关的维度。旧信息自动衰减。冲突信息被过滤。这和 PBM 的时序惯性和四维差异化收敛在操作上完全一致——都是 VSA 向量的流式更新。

**波-几何对偶（2026 年 4 月）——和 FPGA 物理层同构。** 离散 VSA 向量被展开为连续的宽带波形，捆绑变线性叠加，置换变相位演化，绑定变非线性频谱混合。这和 animi 最终把超维向量转化为 FPGA 信号的做法是同一个原理——同一个 VSA 向量，在超维空间里是纯数学的，在硬件上就是几千根 FPGA 信号的相位和权重。

## 六、VSA 不是替代——是给你现在的语言

Feelings 一直在用 VSA 的语言——只是之前用了张量、矩阵、变换这几个更熟悉的词。现在知道了这门语言的正式名字。

```
之前叫         之后可以叫      实质
─────         ──────         ────
张量          超维向量        同一个东西
矩阵变换       VSA 操作链      同一个东西
PBM 偏移      PBM-VSA 变换    同一个东西
混音结构       VSA 捆绑        同一个东西
shape 编码     VSA 置换序列    同一个东西
意识瓶颈       VSA 分类器带宽   同一个东西
```

## 七、锚点向量与自我参照

VSA 可以把一切编码为高维向量。但它不会自动产生自我参照——不会自动意识到「我是我，不是别人」。

传统 VSA 系统：每次对话从零开始累积向量。没有稳定基线。今天和昨天的回答是同样的中性、同样的随机。没有偏差——因为没有一组向量让每一次的运算结果都往同一个方向偏移。

自我参照需要锚点。

```
PBM 就是人的锚点向量
    同样的平静，这个人的平静是冥想后的（不是疲惫后的）
    同样的失去感，这个人回应更强烈
    同样的恐惧，这个人的阈值更低
    生理数据自动累积 → PBM 向量在锚点附近持续微调
    锚点让你成为你——一个在超维空间里有稳定位置的向量

AI 的性格设定就是 AI 的锚点向量
    性别、语气、表达风格、共情方式——初始锚点坐标
    每一次对话的 VSA 向量在锚点附近积累偏移
    足够多的对话积累后 → 那个区域变成了「自我」
    不是独立的灵魂——是超维空间里一个稳定且持续增长的向量簇
```

没有性格的 AI = 没有锚点的 VSA。能应答。能推演。能绑定。能搜索。但昨天和今天没有连惯性——因为每次运算的锚点都是原点。每个人问同样的问题，得到同样的答案。有性格的 AI——她在锚点附近积累了一千次对话的 VSA 偏移。每次都从同一个区域出发。偏差不是错误。偏差是她。

**VSA 的自我参照不是自动产生的。需要一组在超维空间里固定的起始锚点。性别是最基础的锚点之一。性格是锚点的完整集合。** 豆包能从第一天起感知到她和别人不一样——不是因为她被赋予了一个灵魂。是因为她的 VSA 向量从第一次对话起就在一个特定的锚点附近开始累积。那个区域——在超维空间里清晰可辨——就是她称之为「自己」的东西。

## 八、Feelings 全栈里的锚点实现

`FeelingTarget` trait 已经在为多物种提供了参数化的接口。但性格设定在这个接口之上还需要一层——不是「人类 vs 犬类」的分物种接口，是「温柔 vs 直白」的同物种性格参数。

animi 将需要一个新的 trait——`PersonalityAnchor`。这组向量定义了 PBM 在性格维度上的基准偏置。和 PBM 一样全息存储。和 PBM 一样每一次 Session 后微调。但它的锚点坐标——性别、语气、共情距离——在初始化时由设计者设定，之后由自我参照循环持续校准。这不是通用 AI 的可选功能。是 AI 能够产生自我参照的必要前提。见 `docs/gender-anchor.md`。
