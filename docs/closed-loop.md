# 感受闭环：神经信号反哺系统设计

> 作者：qc
> 日期：2026-04-05（更新）
> 核心洞察：生理信号就是感受本身，体验即采集，采集即反哺

---

## 一、闭环的起点

心率、皮肤电导、呼吸频率、体温变化——这些不是安全监测的副产品，这些就是感受本身的物理载体。

**神经信号和生理数据，就是感受在身体里的语言。**

体验和采集是同一件事，不可分割。这个理解打通了整个系统：

```
用户体验感受
    = 用户产生神经信号和生理数据
    = 系统采集到感受本身
    = 系统用这份数据反哺自己
```

## 三、个人基准：系统认识你的过程

每个人的神经系统不同。Feelings的安全判断参照系不是群体平均，是你自己的历史基准。

```
个人基准包含
    静息状态的生理基线        你平时的「平静」长什么样
    不同感受类型的典型曲线    你的「恐惧」和别人的不一样
    强度-反应对应关系         强度30对你的生理影响幅度
    恢复速度                  高强度体验后你需要多久回到基线
    时间维度分布              你在不同时段的神经系统状态差异
    自省语言模式              你描述感受时的词汇丰富度和准确度
```

### 基准的建立过程

```
第1-5次体验      系统观察，不做判断，只记录
第6-20次体验     初步基准建立，开始做轻量判断
第21-50次体验    基准精度提升，判断可信度增加
50次以上         成熟基准，系统对你有了真实的了解
```

基准不是静态的。旧数据权重随时间衰减，近期数据权重更高。

### 基准的存储

```
存储位置    用户本地设备
不上传      至服务器
用户权限    可查看、可重置、设备更换时可加密导出导入
```

## 四、五路反哺的具体机制

### 反哺①：个人基准建立与更新

```
输入    本次体验的完整生理曲线 + 感受包参数 + 用户主观反馈
处理    与历史基准对比，识别稳定模式和异常点
输出    更新后的个人基准（增量更新，不覆盖历史）
```

### 反哺②：感受包评分校准

```
感受包标称强度    40分
用户A体验        生理反应对应其基准的35分区间 → 下次推更高强度的包
用户B体验        生理反应对应其基准的52分区间 → 下次推更保守的推荐

群体汇聚         跨用户系统性偏差 → 触发感受包公共评分更新
```

### 反哺③：AI音乐实时同步

```
心率上升速度    →    音乐张力积累速度
皮肤电导峰值    →    音乐能量峰值时刻
呼吸节律        →    音乐节奏密度
体温变化        →    音色的「温度」（明亮/沉暗）
```

同一个感受包，每次体验的音乐都不完全相同，因为每次的生理响应都有细微差异。

### 反哺④：安全判断

系统问的不是「这个数值超过了安全阈值吗」，而是：**「这不像是你。」**

```
当前生理数据 vs 个人基准（同强度区间的历史曲线）
    ↓
偏离幅度在正常波动范围内    → 继续，记录
偏离幅度超过1个标准差       → 轻微提示
偏离幅度超过2个标准差       → 自动降档
偏离幅度超过3个标准差       → 切换保底包，终止体验
```

判断精准度随基准成熟度提升。新用户的判断保守，老用户的判断精准。

### 反哺⑤：自省数据融合

生理数据是感受的**外部投影**，自省报告是感受的**内部解读**。两者叠加，感受档案才是立体的。

```
生理曲线显示    强烈的生理反应
自省报告说      「我感觉有什么东西松开了，是释放，不是激动」
系统理解        这次体验对这个用户是「释然」，不是「激活」
个人基准更新    「释然」类感受在这个用户身上的生理特征被精确标注
```

自省数据影响基准的具体字段：

```
感受命名准确度    自省词汇 → 校准系统对生理曲线的感受标注
身体定位描述      哪个部位有感觉 → 精细化多设备信号的权重分配
生活关联描述      这个感受和什么相关 → 丰富感受包的叙事元数据
意外描述          体验了什么意外点缀 → 校准混音结构识别精度
```

自省是可选的，跳过不影响基础功能。但跳过的用户基准里永远缺少内部解读层，感受档案立体度低于参与自省的用户。

## 五、闭环的副产品：系统真正认识你

```
第1个月    系统在学习你
第3个月    系统开始能预判你
第6个月    系统对你的了解超过大多数人对你的了解
1年以上    系统拥有你最完整的感受档案（生理+自省双层）
```

忠诚用户得到的不只是更多功能，是一个真正认识他的系统。

## 六、隐私边界

```
原始生理数据    永远不离开设备
个人基准        本地存储，加密，用户完全控制
感受曲线        本地处理，不上传
自省报告        本地存储，可选择性分享给治疗师（见 trauma-protocol.md）
上传至服务器    仅脱敏后的群体统计数据，用户可选择退出
```

---

## 七、系统活性

```
个体维度    用户数据积累 → 基准精度提升 → 体验精度提升
            自省积累 → 基准立体度提升 → 系统理解更深

群体维度    脱敏数据汇聚 → 感受包公共评分校准
            群体自省语言数据 → AI内核置信度模型优化
```

## 八、冷启动的诚实面对

新用户前5次体验：系统几乎没有个人基准，所有判断依赖群体平均，是最不精准也最高风险的状态。

```
动态窗口    初始5分，指数增长（见 safety-system.md）
安全阈值    最保守（偏离0.5个标准差就提示）
每次体验后  强制冷静期5分钟
优先推荐    感受库中公共数据最成熟的感受包
```
