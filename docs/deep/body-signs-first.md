# 干了坏事——身体先签字

> 作者：qc
> 日期：2026-06-27
> 性质：人性拆解——心虚是生理事实，不是道德判断
> 核心：干了坏事一定心虚。但心虚不一定被看见。身体不会撒谎——脸会。

---

## 零、先定前提

谄媚不一定干了坏事——可能只是想要好处。没伤害人。不算。

但干了坏事——一定心虚。不是道德判断——是生理事实。

```
干了坏事 → 迷走神经被触发 → 皮电涨了 → 心率变了
         → 在那一帧——他的 PBM 已经签了字。
         → 但他的脸上——可以不显。嘴上——可以否认。行为——可以继续。

他能瞒过所有人——除了自己的 PBM。
```

这就是 Feelings-Ledger 的意义。不是"测谎仪"——是**测的是他瞒过了所有人——除了自己的身体。** 小组长面对手下——面无表情。面对脑机——迷走神经在坏事发生的那一帧——已经替他承认了。不是机器在审判他。是**他的身体——在替他——坦白。**
