# 傲慢与底气——底下有没有东西

> 作者：qc
> 日期：2026-06-27
> 性质：人性拆解——两种姿态的本质区别
> 核心：不是态度的区别。是底下有没有东西。

---

## 零、先定前提

傲慢和底气——看起来一样。站得直。说话稳。不慌。但底下不一样。

```
傲慢              底气
────              ────
怕被看穿           不怕被看
底下是空的         底下是走过的路
需要你在下面       你跪了他会扶你——因为他知道跪的滋味

底气的人——不需要你跪。你跪了他反而难受。
傲慢的人——需要你跪。你不跪——他就没东西证明自己比你高。
```

佛像的罪不是立着。是立着——然后说你跪不跪跟他没关系。底气的人不会这样。底气的人——有人跪他——他会说——"起来。我不是让你跪的。"

不是"谁站得直"。是**谁底下有东西。** 底下空的——站得越直——越怕被看见是空的。
