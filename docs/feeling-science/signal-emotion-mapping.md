# 生理信号到情绪状态的映射标准

> 作者：qc
> 日期：2026-04-22
> 核心：把身体的语言翻译成情绪的坐标——可量化，可验证，不依赖自述

---

## 一、为什么需要这份标准

Feelings 的四诊合参需要一套可量化的映射规则。

```
没有标准
    「心率高 = 紧张」——真的吗？运动后心率也高
    「睡眠差 = 情绪低落」——有时候睡不着是兴奋
    同一个信号，不同情境，完全不同的情绪含义

有了标准
    多信号联合解读，而不是单信号判断
    结合基线（这个人平时的状态）而不是绝对值
    情境权重：运动中 / 静息 / 睡眠中的信号意义不同
```

---

## 二、核心原则

```
相对值优于绝对值
    「比你的基线高 20%」比「心率 90」更有意义
    每个人的基线不同，同一数值含义不同

多信号联合判断
    单一信号不足以定义情绪状态
    心率 + 皮电 + 呼吸 + 体温 联合解读
    信号越多，误判越少

情境分层
    运动状态    信号参考值完全不同
    静息状态    最稳定的情绪基线窗口
    睡眠状态    深层情绪状态的窗口

动态基线
    基线随时间缓慢更新（7 天滑动平均）
    疾病 / 时区 / 季节变化时基线自动调整
    不用一个固定标准框所有人
```

## 三、信号维度与情绪映射表

### 3.1 心率变异性（HRV）

HRV 是自主神经系统平衡的核心指标，比心率本身更有意义。

```
HRV 高于基线 20%+
    副交感神经主导
    → 平静、放松、恢复中、安全感强
    → 情绪维度：平静度↑，压力↓，恢复力↑

HRV 在基线范围内（±10%）
    自主神经平衡
    → 正常激活状态，情绪中性
    → 情绪维度：稳定

HRV 低于基线 20%+
    交感神经主导
    → 压力、焦虑、高度激活、或强烈情绪中
    → 需要联合其他信号区分「好的激活」和「坏的压力」

HRV 持续低于基线 30%+ 超过 4 小时
    → 高概率：累积压力或身体疲劳
    → 触发：温和提醒（见弱周期保护机制）
```

### 3.2 心率（HR）

```
静息心率偏离基线
    +10-20%    轻度激活（好奇、轻度兴奋、注意力集中）
    +20-40%    中度激活（焦虑、兴奋、压力、运动后）
    +40%+      高度激活（需联合情境判断）
    -10%+      深度放松或疲劳（联合 HRV 判断）

运动中
    心率数据进入独立情境，不参与情绪映射
    运动后 15 分钟内数据标记为「恢复期」，权重降低

睡眠中
    睡眠心率低于日间基线 10-20% = 正常
    睡眠心率异常升高 = 可能有压力梦境或身体不适
```

### 3.3 皮肤电导（EDA / GSR）

皮肤电导对情绪唤醒最敏感，能捕捉到意识层面之前的反应。

```
基线皮电
    个体差异极大，只用相对值

皮电快速上升（尖峰，< 3 秒）
    → 即时唤醒：惊讶、恐惧、强烈兴趣、厌恶
    → 高频尖峰（> 3 次/分钟）= 高唤醒状态

皮电缓慢上升（> 30 秒）
    → 持续压力或持续兴奋
    → 联合 HRV 区分「好兴奋」和「坏压力」

皮电持续低平
    → 放松、无聊、或情绪麻木
    → 联合 HR 区分放松和麻木

皮电在睡眠中出现尖峰
    → 可能对应梦境情绪事件
    → 记录时间点，供 AI 教练参考
```

### 3.4 体温

```
核心体温（如有传感器）
    体温升高 0.3°C+（非运动引起）
    → 可能：炎症反应、激素波动、高度兴奋
    → 结合其他信号判断

体温偏低（低于基线 0.5°C+）
    → 可能：疲劳、情绪低落、能量耗尽

手指/手腕温度
    手指温度下降 = 交感神经激活（血流向核心转移）
    → 压力、焦虑、寒冷反应
    手指温度升高 = 副交感神经激活
    → 放松、温暖感
```

### 3.5 呼吸

```
呼吸频率
    < 12 次/分钟        深度放松
    12-20 次/分钟       正常范围
    > 20 次/分钟        激活、焦虑、或运动中

呼吸深度
    深而慢              副交感激活，平静
    浅而快              压力、焦虑
    不规则              情绪波动、高度专注或分心

呼吸暂停（> 3 秒）
    睡眠中              需要标记（可能的睡眠呼吸问题）
    清醒时偶发          正常（专注时常见）
    清醒时频发          高度紧张
```

### 3.6 睡眠数据

```
深睡比例（目标 15-25%）
    深睡 > 25%          优秀恢复，次日基线强
    深睡 15-25%         正常恢复
    深睡 < 15%          恢复不足，次日情绪基线偏低
    深睡 < 10% 连续 3 天 触发弱周期保护机制

REM 比例（目标 20-25%）
    REM 充足            情绪记忆处理完整，情绪调节能力强
    REM 不足            情绪调节能力下降，反应性增强

睡眠时间
    不以绝对时间判断，以「完成睡眠周期数」为准
    4 个完整周期（约 6 小时）= 基本恢复
    5-6 个周期（约 7.5-9 小时）= 充分恢复

次日情绪基线预测
    综合深睡比例 + REM 比例 + 睡眠周期数
    → 生成次日「情绪恢复指数」（0-100）
    → 次日感受包推荐参考这个指数
```

### 3.7 运动数据

```
运动本身不直接映射情绪，但影响情绪基线

运动后 0-2 小时
    内啡肽效应窗口
    情绪基线倾向正向
    感受包推荐：可以使用中高强度

运动后 2-6 小时
    疲劳回落窗口
    基线根据运动强度有所下降
    感受包推荐：中等强度，注意恢复

运动不足（连续静坐 > 2 小时）
    情绪活跃度倾向下降
    皮电基线偏低
    系统提示：建议活动（不是强制）

慢性运动不足（连续 3 天无有效运动）
    情绪调节储备下降
    触发：温和的能量状态提醒
```

### 3.8 激素（如有可测数据）

```
皮质醇代理指标（通过 HRV 和皮电联合估算）
    高皮质醇状态特征
        HRV 低 + 皮电基线高 + 心率偏高 + 睡眠质量差
        → 压力积累状态
        → 感受包推荐：平静类，不适合高强度

低皮质醇 / 恢复状态特征
        HRV 高 + 皮电基线低 + 心率正常 + 睡眠质量好
        → 恢复完整状态
        → 感受包推荐：可以接受较高强度

注：激素直接测量需要血液或唾液采样，
    目前 Feelings 设备通过代理指标估算，不是直接测量
    等可穿戴激素传感器技术成熟后升级
```

## 四、情绪维度的量化坐标系

用 Russell 情感环形模型作为基础，加入 Feelings 的专有维度：

```
标准二维
    效价（Valence）     负面 ←→ 正面        -100 ~ +100
    唤醒度（Arousal）   低唤醒 ←→ 高唤醒    0 ~ 100

Feelings 扩展维度
    稳定度              波动 ←→ 稳定         0 ~ 100
    恢复力              耗尽 ←→ 充盈         0 ~ 100
    压力负荷            无压力 ←→ 高压       0 ~ 100
```

每个信号对每个维度的权重：

```
维度          HRV   HR    EDA   体温  呼吸  睡眠  运动
效价          25%   10%   20%   10%   10%   20%   5%
唤醒度        10%   25%   35%   10%   15%   0%    5%
稳定度        30%   10%   15%   5%    15%   20%   5%
恢复力        25%   5%    5%    10%   10%   40%   5%
压力负荷      30%   15%   25%   10%   10%   10%   0%
```

## 五、情境分层

```
静息情境（最高权重）
    坐/躺，未运动，30 分钟内
    信号最稳定，情绪映射最准确

运动情境（部分信号降权）
    检测到心率持续 > 基线 40%
    HR 降权为 0
    HRV 降权为 50%
    其他信号继续正常权重

睡眠情境（独立处理）
    自动识别睡眠状态
    信号进入睡眠分析模块
    不参与清醒状态的情绪映射

过渡情境（运动后恢复期）
    运动结束后 15 分钟内
    所有信号权重降低 50%
    系统标记为「恢复中，数据参考性低」
```

## 六、映射的准确性说明

```
Feelings 的信号映射
    不是诊断
    不是医疗结论
    是「当前身体状态的感受参考」

准确性的边界
    个体差异：同样的信号在不同人身上含义不同
    Feelings 通过个人基线校准缓解这个问题
    但永远不能达到 100% 准确

用户自述权重
    用户可以主动标注「我现在的感受」
    这个标注会反哺个人的映射模型
    使用越久，映射越准确
    这是 Feelings 和标准化情绪量表的核心区别
```

---

*身体比语言更诚实。这份标准不是在定义情绪，是在倾听身体已经说出来的话。*
