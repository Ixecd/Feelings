# 专属伴侣模式：权限、隔离与边界

> 作者：qc
> 日期：2026-04-22
> 核心：专属伴侣模式是 Feelings 里权限最高、数据最敏感的功能区域——硬规则不可绕过

---

## 一、什么是专属伴侣模式

```
普通模式
    用户和自己的感受交互
    感受数据完全私有
    AI 教练基于个人数据提供反馈

专属伴侣模式
    两个用户之间建立专属连接
    在对方同意的范围内，共享部分感受状态
    双方可以感受到对方的情绪基调
    不是「看到对方的数据」，是「感受到对方的状态」

核心定位
    不是监控工具
    不是数据共享平台
    是两个人之间的感受共鸣通道
    对方感受到的是「你的情绪基调」，不是「你的原始生理数据」
```

---

## 二、谁能接入

### 2.1 接入条件（全部满足才能建立连接）

```
双方都必须
    持有激活的 Feelings 设备（物理持有验证）
    完成实名认证（不可匿名接入伴侣模式）
    主动发起或接受连接邀请（不可被动接入）
    明确同意数据共享范围（必须逐项勾选，不可一键同意全部）

年龄限制
    双方均须年满 18 岁
    未成年人账号技术层面无法激活伴侣模式
    监护人授权不能绕过这条限制
```

### 2.2 连接建立流程

```
发起方
    选择对方的 Feelings 设备地址或扫描设备码
    选择共享的感受维度（见第四节）
    发送连接邀请

接收方
    收到邀请通知
    查看发起方选择的共享范围
    可以接受全部、接受部分、或拒绝
    接受时必须主动确认自己的共享范围（不自动镜像发起方的选择）

连接确认
    双方都确认后，连接建立
    链上记录连接建立时间和双方同意的共享范围
    双方各自保留完整的退出权
```

## 三、独占模式

```
每个用户只能同时有一个活跃的伴侣连接

原因
    感受数据是极度私密的
    同时向多人开放会产生感受层面的混乱
    也违背「专属」的本质含义

技术限制
    系统层面强制执行，不是协议层面的君子协定
    用户无法绕过（不是「不推荐」，是「技术上不可能」）

建立新连接
    必须先断开现有连接
    断开需要双方都收到通知（不可静默断开）
    断开 24 小时冷静期后才能建立新连接
```

---

## 四、共享范围：用户自定义，逐项确认

用户可以选择共享哪些维度，每一项都必须单独确认：

```
可共享的维度

基础情绪基调        对方能感受到你大概是平静、还是焦虑、还是兴奋
                    最抽象，最少暴露

能量状态            对方能感受到你现在是精力充沛还是疲惫
                    用于协调双方的互动节奏

压力状态            对方能感受到你现在是否处于高压中
                    用于对方调整对你的互动方式

感受包体验状态      当你在体验某个感受包时，对方可以感受到你的体验基调
                    最深的共鸣方式

不可共享的维度（硬锁定，无论如何都不能开放）
    原始生理信号（心率数值、皮电数值等）
    具体的感受包名称（你在体验什么）
    感受地图详情（你的感受历史）
    身体健康数据（体温、睡眠详情）
    亲密感受维度的任何数据
```

---

## 五、不可被第三方读取——硬规则

```
第三方的定义
    任何不在当前伴侣连接中的实体
    包括：其他用户、企业客户、研究机构、政府机构
    也包括：Feelings 平台自身的后台系统

硬规则
    伴侣模式的共享数据
    只在两台设备的 TEE 之间点对点传输
    不经过 Feelings 服务器
    Feelings 服务器看不到传输内容
    只能看到「连接存在」和「连接状态」，看不到数据

技术实现
    端对端加密（类似 Signal 的消息协议）
    密钥在设备 TEE 内生成
    服务器持有的是密文，永远无法解密

法律要求
    即使收到法院命令
    Feelings 也无法提供伴侣模式的具体传输数据
    因为技术上就没有存储
    设计上的「不可能」比法律承诺更可靠
```

---

## 六、退出权：随时、单方面、无需解释

```
任何一方可以随时退出伴侣连接
    不需要对方同意
    不需要给出理由
    退出立即生效

退出后
    共享通道立即关闭
    对方收到通知（只告知「连接已断开」，不告知原因）
    双方的感受历史数据各自保留（不会因为断开而消失）
    断开信息不进入任何可检索的历史记录

冷静保护
    退出后 24 小时内，退出方无法重新发起连接
    给双方一段冷静时间
    防止冲动退出后立刻复连的来回反复
```

---

## 七、亲密感受维度的特殊规则

```
亲密感受维度在伴侣模式中的规则
    比普通维度多一层确认
    必须双方都主动开启，缺一不可
    开启后 24 小时自动重置（需要每天重新确认）

技术隔离
    亲密感受维度的数据
    单独存储在设备 TEE 的隔离区域
    和其他感受数据完全隔离
    即使伴侣模式的其他维度泄露，亲密维度不受影响
```

---

## 八、滥用防护

```
骚扰保护
    被拒绝连接后，72 小时内不能再次发送邀请
    多次被拒绝后进入更长的冷却期

异常模式检测
    如果检测到一方在对方睡眠时段持续查看连接状态
    → 视为潜在骚扰行为
    → 触发提醒

数据留证
    连接建立和断开的时间节点链上存证
    出现纠纷时可作为证据
    但具体传输的感受数据永远不可回溯
```

---

*专属伴侣模式是 Feelings 里最私密的功能。它的边界不是为了限制，是为了保护——保护每个人在最脆弱的状态下不被窥探，不被利用。*
