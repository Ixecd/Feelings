# 持续健康关注：诚实提醒，不做诊断

> 作者：qc
> 日期：2026-04-20
> 核心：Feelings 察觉异常信号时，是诚实的朋友，不是哑巴，也不是医生

---

## 一、Feelings 作为连续监测工具

传统体检是离散的——一年一次，两次之间发生的变化，没有人知道。

Feelings 的四诊合参是连续的：

```
每次体验
    都在更新用户的生理基准
    心率变异性、皮肤电导、肌肉张力
    呼吸模式、体温波动、感受反应速度

累积下来
    Feelings 拥有一条时间线
    不是某一天的快照
    是持续变化的生理轨迹

这让 Feelings 能看到
    某些指标的缓慢漂移
    一次性体检很难发现的趋势性变化
    用户自己感知不到的微弱信号
```

**这是 Feelings 的价值之一，也是 Feelings 的责任之一。**

---

## 二、发现异常信号时的处理原则

**察觉到，就要说。不说是不诚实的。**

但怎么说，需要非常小心。

```
Feelings 的提醒原则

描述信号，不做诊断
    说：「检测到 X 信号持续 Y 天」
    不说：「您可能患有 Z」

首次提醒，中性表达
    「系统注意到某项指标有变化，建议关注」
    不夸大，不淡化

持续存在时，周期性更新
    信号持续：周期性告知用户状态
    不高频轰炸，不制造焦虑
    频率由信号的变化速度决定，不是固定轰炸

信号消失时，同样告知
    「上次提醒的信号已恢复到基准范围」
    完整的信息，包括好消息
```

---

## 三、提醒的边界

```
可以做的

    ✓ 描述检测到的信号
    ✓ 说明信号持续的时间
    ✓ 建议用户「可以考虑关注」
    ✓ 提示「如果信号持续，建议咨询医生」
    ✓ 在用户主动询问时提供更多信号细节

不可以做的

    ✗ 给出任何医疗诊断
    ✗ 说「您可能患有 XX 疾病」
    ✗ 高频提醒制造恐惧
    ✗ 夸大信号的严重性
    ✗ 加入任何商业引导（「及时保障」之类）
    ✗ 基于异常信号推送任何保险或医疗产品
```

**核心边界：Feelings 是诚实的朋友，不是恐惧制造机。**

---

## 四、用户的决定权

```
Feelings 提供信号
    用户自己决定做什么

用户的选择权
    选择关注或忽略这个信号
    选择是否就医
    选择就医的时间和方式
    选择是否把这个信息告诉任何人

Feelings 的立场
    不催促
    不施压
    不判断用户的选择
    不跟踪用户是否「按建议行动了」
```

**感受的所有权在用户，健康决策的所有权也在用户。**

---

## 五、Feelings 信号的法律地位

这是一个需要明确表达的立场：

```
Feelings 的感受信号

不构成医疗诊断
    Feelings 不是医疗设备
    信号不等于诊断结论
    无法替代临床检查

不构成保险法律意义上的「知情通知」
    Feelings 信号没有经过医疗机构确认
    在保险合同的「既往症」认定上没有法律效力
    用户在处理保险相关事宜时
    应遵循当地法律和保险合同的如实告知义务

Feelings 不提供任何关于保险申报的建议
    这不是 Feelings 的职责范围
    详见 docs/insurance-baseline.md
```

## 六、为什么不做成「全自动健康管家」

```
有一种可能的设计方向
    检测到异常 → 自动推送就医提醒 → 自动推荐医院 → 自动帮用户预约

为什么 Feelings 不这样做

    这条路的终点是「替用户做决定」
    Feelings 的哲学是「帮用户认识自己」
    不是「替用户管理自己」

    全自动的健康管家
    表面上是关心用户
    实际上是剥夺用户的感受主权
    用户变成了被系统「照顾」的对象
    而不是自己感受和健康的主人

Feelings 选择
    提供信息
    保持边界
    让用户自己决定
```

## 七、和四诊合参的关系

Feelings 的异常信号来自四诊合参：

```
望    视觉信号（面部微表情、姿态）
闻    听觉信号（呼吸声、心音）
问    感受自述（用户主动输入）
切    触觉信号（脉搏、皮肤电导、肌肉张力）
```

四诊合参的本质是**整体性的感受参考**，不是逐项的医疗指标。

```
发现某项指标异常时
    放在整体感受的语境里解读
    不单独拿出来说「您的心率变异性偏低」
    而是「最近的感受状态显示身体可能需要更多休息」

这样的表达
    更诚实（没有夸大单项指标的意义）
    更完整（结合整体状态）
    更有用（用户能做的具体行动更清晰）
```
