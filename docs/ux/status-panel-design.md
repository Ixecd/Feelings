# 视觉化状态面板设计

> 作者：qc
> 日期：2026-04-22
> 核心：一眼看懂当前状态——强势度、能量、情绪稳定度、生理负荷

---

## 一、设计原则

```
一眼读懂，不需要解读
    看一秒钟就知道现在是什么状态
    不需要看数字，不需要看说明
    颜色和形态直接传递含义

极简，不焦虑
    不展示「你比昨天差了 X%」
    不展示「你比同龄人低 Y 分」
    只展示「现在是什么状态」
    不制造比较焦虑

感受优先，数字其次
    主要用视觉语言（形态、颜色、动态）
    数字在第二层，需要点进去才看到
    符合 Feelings 的哲学：身体比数字更诚实
```

---

## 二、主状态面板布局

```
设备屏幕（或 App 主界面）
    中央：Feelings 菱形（会呼吸、会变形）
    外圈：四象限指示器
    底部：当前状态文字描述（一句话）
```

---

## 三、核心视觉元素：Feelings 菱形

菱形是 Feelings 的入口形状，也是状态面板的核心显示元素。

### 3.1 形态含义

```
菱形大小
    大：能量状态高，生理储备充足
    小：能量状态低，需要保护

菱形「呼吸」节律
    快：神经激活度高，兴奋/紧张/专注
    慢：神经激活度低，放松/疲惫
    均匀：情绪稳定
    不规则：情绪波动中

菱形轮廓清晰度
    清晰锐利：状态稳定，信号质量好
    模糊/渐变：状态波动，或传感器数据不稳定

菱形扭曲程度
    完美菱形：各维度均衡
    某个方向突出：对应维度特别高
    某个方向凹陷：对应维度偏低
```

### 3.2 颜色体系

```
强势区（CEI 75-100）
    深邃蓝紫    冷静的力量感，不是刺眼的亢奋
    「黑曜石」  #1a1a2e → #16213e

高效区（CEI 55-74）
    中性蓝绿    清醒、平衡、可信赖
    「深海」    #0f3460 → #1a6b7d

维持区（CEI 35-54）
    暖灰色      轻微疲惫，但还在运转
    「黎明前」  #8e8d8a → #b8b0a2

保护区（CEI 15-34）
    深琥珀      柔和的警示，不是刺眼的红色
    「落日」    #c47c2b → #8b5a2b

临界区（CEI 0-14）
    深沉的紫红  不是警报，是沉默的保护
    「深渊」    #5c1a3a → #3d0d26
```

## 四、四象限指示器

菱形外圈的四个方向，分别对应四个维度：

```
上方（↑）    强势度（神经激活度 + 情绪稳定度综合）
下方（↓）    生理储备（恢复程度）
左方（←）    压力负荷（越低越好）
右方（→）    能量状态（CEI）

指示方式
    每个方向有一个弧形进度条
    满弧 = 100%，空弧 = 0%
    颜色跟随当前状态的主色调
    不显示具体数字（数字在第二层）
```

---

## 五、底部状态描述

```
一句话描述当前状态，不超过 10 个字
    强势区     「状态峰值，适合高强度」
    高效区     「状态良好，正常推进」
    维持区     「适合轻量工作，注意恢复」
    保护区     「休整期，系统已切换轻量模式」
    临界区     「深度休整中」

弱周期特殊描述
    「你在休整期，慢慢来」
    不说「你的状态很差」
    不说「需要改善」
```

## 六、动态效果

```
菱形呼吸动画
    基于实时呼吸频率数据
    如果没有呼吸数据，使用心率代替
    呼吸动画的节律和用户当前呼吸同步
    看着它，可以自然引导用户的呼吸节奏

状态变化过渡
    CEI 变化时，颜色平滑过渡
    不是突然跳变
    变化速度：实际 CEI 变化速度的 1/10
    （实际状态 1 小时内变化，显示 10 分钟内完成过渡）
    避免焦虑感

「进入体验」的入口
    独立模式（没连手机）
        戴上设备 → 教练 AI 根据 PBM 状态自动推送感受。
        用户没有控制权——纯身体的等控器自己决定。
        感觉就像一首你不知道名字但刚好适合此刻的歌。

    联动模式（连接手机 App）
        打开 App → 主面板显示三维菱形——实时 PBM 投影。
        点击菱形中心 → 教练 AI 推送建议感受方向。
        "你现在可以试试平静。你的迷走神经昨晚恢复得很好。"
        用户可以选择接受建议——或自己调整主旋律+点缀。
        确认 → 教练 AI 验证。
        通过 → 信号签发。
        不通过 → 强度降级或替换替代感受包。

    确认需要经过教练 AI 验证
        不是"你想选什么就选什么"。
        是"你想选这个——你的 PBM 现在能不能接住"。
        AI 验证你的 cap、是否在不应期、是否有漏桶累积超限。
        三道全过 → 信号签发。
        任何一道不过 → 自动降级或拒绝，同时用三维图案告诉你原因。
        "你的等控器现在需要休息。下午再试。"

    这个入口永远在那里。
    面板是状态显示，不是操作中心。
```

## 七、第二层：详细数据

用户主动点击某个象限，才进入详细数据视图：

```
强势度详情
    神经激活度：XX
    情绪稳定度：XX
    「强势窗口预计还有约 X 小时」

生理储备详情
    最近一次睡眠恢复指数：XX
    运动疲劳余量：XX
    「上次充分恢复：X 小时/天前」

压力负荷详情
    当前压力负荷：XX
    「过去 24 小时的最高点：XX（出现在 X 时间）」
    注意：弱周期中不显示这些比较数据

能量状态详情
    综合 CEI：XX
    趋势：上升/下降/稳定
    「预计达到强势区还需要：约 X 小时恢复」
    注意：弱周期中不显示「还需要 X 才能好」
```

## 八、特殊状态的视觉处理

```
弱周期状态
    菱形变小（能量低）
    呼吸节律变慢变均匀（引导平静）
    颜色进入深沉的保护区色调
    四象限指示器变暗（不想让用户盯着低数字看）
    底部只显示「你在休整期，慢慢来」
    不显示「比基线低多少」

强势峰值状态
    菱形轻微扩大并有微妙的发光边缘
    呼吸节律有力均匀
    颜色是最深的蓝紫强势色
    底部显示「状态峰值」
    这个状态不常见，有微妙的「珍惜它」的设计感

专属伴侣模式激活时
    菱形外出现第二个更小的菱形（代表对方）
    两个菱形之间有细线连接
    对方菱形的颜色基调传递对方的情绪基调
    点击对方菱形，只看到「对方当前的状态基调」
    不显示对方的具体数值
```

## 九、无数据 / 设备未佩戴状态

```
设备不在手上（超过 10 分钟无信号）
    菱形轮廓变为虚线
    无呼吸动画
    颜色变为中性灰
    底部显示「设备未连接」
    不显示上次数据（防止误读）

数据质量低（传感器读取不稳定）
    菱形轮廓保持实线但略微模糊
    底部显示「信号读取中」
    显示的状态是上一次稳定读取的值
    有轻微的「数据不稳定」视觉提示
```

---

*状态面板的目标只有一个：让你一眼知道自己在哪里，然后你来决定要去哪里。*
