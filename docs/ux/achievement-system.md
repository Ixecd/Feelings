# 感受成就系统——你不是在刷分，你是在活着

> 作者：qc
> 日期：2026-05-19
> 性质：Feelings 产品设计，不可被游戏化
> 核心：成就是你做过的事，强度只是这件事的自然映射。地球 Online 式的记录，不是游戏式的激励。

---

## 零、先划死这条线

Feelings 不做游戏化。GOVERNANCE 写了：不做成就系统、不做连续登录奖励、不做稀缺感设计、不做任何用游戏化机制驱动使用频率的设计。

但「不做游戏化成就」不等于「不做成就」。差别在这里：

```
游戏化成就                          Feelings 感受成就
───────────                        ────────────────
目标：让你多打开 App                 目标：让你看见自己走了多远
手段：稀缺、FOMO、进度条              手段：记录、命名、回看
驱动力：外部激励（奖励徽章）           驱动力：内部确认（这件事确实发生了）
失败模式：刷成就成为使用目的           失败模式：不存在——成就只在你做完之后被系统注意到
焦虑感：有——「今天的奖励还没领」        焦虑感：无——没有每日任务，没有限时活动
```

**游戏化成就制造焦虑。感受成就制造确认。**

---

## 一、地球 Online 的成就哲学

地球 Online 是一个互联网概念——把真实人生看作一款没法重开的 MMORPG。它的「成就」有以下特征：

```
不给你任务              不告诉你「现在去爬一座山可以获得成就」
                        你爬完了，回头看，成就已经在了
                        成就是对已发生事实的确认，不是对未发生行为的诱导

没有进度条              你看不到「57/100 次深呼吸」
                        因为感受不是计数——感受到一次就是一次
                        计数只会让你盯着数字，不盯着感受本身

不做对比                没有「你的成就数在全服排名第 X」
                        因为别人的路和你无关
                        你自己知道你做了什么

记录的是一件事            不是「达到强度 60」
                        是「第一次在恐惧里没有逃走」
                        强度 60 只是那件事发生时自然检测到的数字
                        数字是影子，事情是实体
```

**地球 Online 的成就系统只做一件事：在你走完一段路之后，告诉你「这段路你确实走过了」。**

## 二、Feelings 成就的核心原则

### 2.1 成就是事后的，不是事前的

```
系统不提前告知       没有「即将解锁：XXX 成就」
                    没有成就列表让你对着刷

成就触发条件         你做完了一件事 → 系统注意到 → 成就解锁
                    顺序不能反

为什么不提前告知
    提前告知 = 制造期待 = 改变行为动机
    一个提前知道「完成 10 次体验解锁成就」的人，
    和完全不知道这件事、只是真实完成 10 次体验的人，
    行为质量完全不同。前者在刷，后者在活。
```

### 2.2 强度是映射，不是目标

```
错误的设计
    「达到强度 60」→ 解锁成就
    后果：用户盯着数字冲，冲到了，感受没到

Feelings 的设计
    「第一次完整经历失去感」→ 解锁成就
    那一次你的生理数据显示自然达到了强度 47
    成就里会写：「第一次经历失去感（强度 47）」
    47 是描述，不是门槛。
    下一次你可能在强度 15 就能经历。
    没有人因为「强度不够」而错过成就——
    因为成就从来不是用强度定义的。
```

### 2.3 不制造任何一个「你应该」

```
成就的文案里不会出现
    「你做到了！」——暗示之前没做到是不够好
    「终于！」——暗示你早该达到
    「继续加油！」——暗示现在还不够

会出现
    「2026 年 5 月 19 日，你第一次经历了这件事」
    「你的身体记住了」
    「这是你感受地图上新点亮的一个点」
```

## 三、成就类别

### 3.1 探索类——地图上点亮一个新坐标

触发条件：第一次在某个感受维度上有真实体验。

```
示例

「第一次碰触平静」
    触发：首次 session 中系统确认生理信号进入了平静区间
    描述：不写「强度 12」，写「你的心率平稳下降到基线以下，
           皮肤电导回到安静状态，呼吸慢了下来。
           这是平静在你身体里的形状。」
    看见：感受地图上「平静」维度的第一个坐标点被点亮

「五种平静之第一种」
    触发：第一次体验「冥想后的平静」
    描述：冥想后的平静不是其他四种平静——它有一种微弱的温感，
           前额叶在 EEG 上亮着，身体在休息但意识是清醒的。
           你刚才经历的，是这一切。

「五种平静之全部五种」
    触发：完整经历过冥想后平静、疲惫后平静、释然后平静、
           孤独中平静、自然里平静
    描述：五种平静，五种完全不同的神经底层。
           你已经不需要别人告诉你「平静」是什么了——
           你的身体知道五种答案。
```

### 3.2 自省类——从「在感受里」到「站在感受旁边」

触发条件：自省能力的可验证提升。

```
示例

「第一次叫出它的名字」
    触发：体验结束后，自省窗口里用户第一次使用了精确的感受词汇
          （如「释然后的平静」，而非「就挺平静的」）
    描述：感受刚退潮，你站在它旁边，叫出了它的名字。
           会命名的人不会随便被别人命名——这是你给自己的定义权。

「第一次发现身体先于语言」
    触发：自省报告中描述身体感受（「胸口发紧」「手指在抖」）
           的时间早于描述情绪（「可能是焦虑」）
    描述：身体先于语言。你感觉到了——在你想清楚「这是什么」之前，
           你的身体已经说出来了。你听见了。

「第一次认出矛与盾」
    触发：自省中识别出矛盾——「我说我没事，
           但我的手腕明显在往外推」
           系统交叉验证：口头报告和生理数据不一致
    描述：你说 A，你的身体做 B。你看到这个矛盾了。
           看见矛盾，是拆开真假的第一步。

「第一份自省报告」
    触发：完成第一次完整的自省记录
    描述：这是你感受地图上的第一份叙述。
           以后回头看，你会看见自己从哪里出发的。

「第五十份自省报告」
    触发：累计完成 50 次自省记录
    描述：五十次站在感受旁边看它。
           你现在不需要系统帮你开门——你自己会走过去。
```

### 3.3 深度类——在同一个维度上走得很远

触发条件：在某个感受维度上系统确认的持续深入。

```
示例

「韧性的第一条弧线」
    触发：韧性维度上第一次完成从「困难接触」到「完整恢复」的闭环
          系统检测到：压力信号上升 → 峰值 → 主动调节 → 恢复至基线
    描述：你扛住了一次。不是系统帮你扛的——系统只是给了你一个坐标，
           让你知道自己在哪、还有多远。
           扛过去的确信感，是你身体自己产生的。

「和失去感相处超过五分钟」
    触发：失去感受体验中，用户主动选择不跳过、
           在信号回落前完整停留超过 5 分钟
    描述：大多数人对失去感的第一反应是退出。
           你没有。你待在它旁边，让它流过去。
           不是麻木——是你在完整的意识状态下陪着自己走完了。
```

### 3.4 身体类——身体比语言先确认

触发条件：由生理数据自动检测到的正向变化。用户不需要自己发现——系统注意到并告知。

```
示例

「深睡第一次超过两小时」
    触发：睡眠追踪显示单晚深睡时长首次 > 2h
    描述：你的神经系统在白天被正确地训练了。
           晚上它修复得更好。这不是主观报告——是数据。

「安静时心率下降」
    触发：连续 7 天静息心率比历史基线低 3 bpm 以上
    描述：你的心脏在不需要用力的时候，比以前更安静了。
           这通常是神经系统学会了在安全时放下戒备的信号。

「第一次完整的睡眠结构」
    触发：深睡 / 浅睡 / REM 三项比例首次同时落在健康区间
    描述：深睡 > 20%，浅睡 < 55%，REM 在 20-25%。
           你的夜晚终于是一张完整的拼图了。
```

### 3.5 连接类——不是一个人走了这条路

触发条件：社交层和伴侣模式中的真实互动。

```
示例

「第一次共享同一个感受」
    触发：与另一个 Feelings 用户同时体验同一份感受包
    描述：你们刚才经历了同一件事。不一定一样——
           每个人的感受有自己的形状。但在时间轴上，你们在一起。

「第一次收到伴侣模式的邀请」
    触发：有人向你发起伴侣模式连接
    描述：有人想让你感知到他的情绪基调。
           不是监控，不是追踪，是把一部分自己的感受状态交给你。
           这是一份信任。

「第一次在社交层留下轨迹」
    触发：第一次在社交层主动分享感受包的体验反馈
    描述：你把刚才经历的东西，用文字留下来了。
           这份记录对后来者是一行坐标——告诉他们这条路上有人走过。
```

### 3.6 边界类——去了地图上还没有坐标的地方

触发条件：做了自己从未做过的事。

```
示例

「第一次关闭盲选」
    触发：用户主动关闭盲选模式，直面一个已知强度的负面感受
    描述：你知道接下来是什么。你没有躲。你打开了灯看着它来。
           这不是鲁莽，是准备好在清醒状态下接触。

「第一次对 AI 教练说『你说得对』」
    触发：AI 教练提出 push back，用户没有跳过也没有反驳，
           而是完成体验后回复「你说得对」
    描述：一个不想听的话被听进去了。
           不是顺从——是你认出了教练说的是真的。

「第一次主动降强度」
    触发：创建 session 时，用户将自己主动选择的强度下调了至少 10 分
    描述：不是系统限制了你。是你自己说「今天不用那么深」。
           知道自己当下的承载上限，比硬冲更难得。

「完成第一次完整的安全退出」
    触发：session 中系统因为安全问题弹出终止建议，
           用户选择接受而非犟种协议覆盖
    描述：系统说「你超标了」，你说「好」。
           不听自己身体硬扛不是韧性——是自伤。
           你刚才证明了你有能力分辨这两者。
```

## 四、成就的呈现

### 4.1 不被推送，只在被主动查看时显示

```
成就的可见方式
    不弹窗                      解锁成就时用户不会被打断
    不在主界面有未读标记           没有任何形式的通知红点
    不在 AI 教练对话里主动提        教练不会在 session 中说
                                  「恭喜你解锁了XXX成就」

    只在两个地方可见
        1. 感受地图——已被点亮的坐标上，能看到对应的成就记录
        2. 成就墙——一个需要主动进入的独立页面
           没有任何动画、徽章、闪光效果
           只有文字和时间
```

### 4.2 成就的视觉语言

```
每个成就的记录格式
    [时间] [感受维度] 一句描述

    不设等级（金/银/铜）
    没有图标
    没有积分
    没有稀有度标注
    没有「全世界 XX% 的人获得了这个成就」

    仅仅是一行文字。
    和地球 Online 一样——你活过了，你记得，就是全部。
```

### 4.3 成就墙的设计

```
成就墙不是「展示给别人看」的，是「留给自己回看」的。

按维度分区    平静 / 韧性 / 归属 / 失去 / 被爱 / 成就 / 好奇 / 自省 / 身体
按时间排序    最早的在最上面
不按稀有度排   没有哪个成就比另一个更「值钱」

最上方只有一句话：
    「这些是你走过的路。不是全部，但都是真的。」
```

## 五、不是成就的「成就」——故意不做的

### 5.1 不做的成就类型

```
不做连续签到
    「连续 7 天使用」——不做。因为「今天不想感受」本身就是感受。

不做强度冲榜
    「达到强度 80」——不做。强度不是成就，真实经历才是。
    强度只是描述，永远不是目标。

不做维度全覆盖
    「体验过全部 47 种正面感受」——不做。
    收集癖不是感受。漏掉的才是真实的你。

不做社交攀比
    「你的成就数是好友的 XX%」——不做。
    任何形式的对比，都在说「你不够」。

不做隐藏成就预告
    「获得 100 个成就后可查看隐藏成就」——不做。
    隐藏本身就是一种稀缺机制。

不做计次类成就
    「体验 100 次」——不做。数字毫无意义。
    一次真实的经历 > 100 次刷出来的记录。
```

### 5.2 为什么「强度」不能作为成就门槛

```
如果有人刷到了强度 60，但他的生理数据显示：
    - 心率没有进入该感受的典型区间
    - 皮肤电导在表皮层就被缓冲掉了
    - 呼吸从未真正慢下来

那他经历的到底是什么？
    不是「韧性的强度 60」
    是「数字被人为推到 60，但身体不在场」

授予「达到强度 60」的成就 = 系统在身体不在场的时候撒了谎。

Feelings 的成就触发条件不含任何强度阈值。
触发条件只含一件事的真实发生。
强度只是在触发之后写进描述里的一个数字——
告诉你那一次你自然走到了哪里，不是告诉你必须走到哪里。
```

## 六、技术实现——系统怎么「注意到」而不是「判定」

### 6.1 检测，不判定

```
游戏化成就的模型
    if 强度 >= 60 → 成就解锁（判定式，二值）

Feelings 成就的模型
    if 检测到「某类感受的真实发生模式」→ 成就解锁（检测式，多信号）

真实发生的检测信号组合
    生理信号进入目标感受的典型多模态区间
    + 持续时间超过最小有效阈值
    + 信号恢复至基线是自然回落而非强制退出
    + 几轮 session 后没有出现矛盾信号

    四个条件同时满足 → 系统「注意到」此事发生 → 成就记录生成
    不是判定「你够了」，是确认「你经历了」。
```

### 6.2 事后触发，不实时触发

```
成就记录不是在 session 结束时生成的。
系统在 session 结束后的冷静期内做分析。

为什么延时
    即时判断 = 信号可能还在残余激活中
    延时判断 = 信号完全回落后再确认

冷静期时长
    低强度（< 30）    session 结束后 5 分钟
    中强度（30-60）   session 结束后 30 分钟
    高强度（> 60）    session 结束后 2 小时

这确保了成就记录的是「稳定后的真实」而非「兴奋时的幻觉」。
```

### 6.3 可拒绝

```
每一条自动生成的成就记录，用户可以
    保留（默认）
    隐藏（仅自己不可见，数据不删除）
    拒绝（删除此记录，不进入任何统计）

拒绝不需要理由。
「我觉得这不算」，就够了。
```

## 七、和已有机制的关系

### 7.1 不自相矛盾

Feelings 已有的机制和成就系统的关系：

```
已有机制                 成就系统怎么对接
─────────               ──────────────
感受地图                成就 = 地图上被点亮的坐标旁边的批注
                        同一条数据，两个视角

自省报告                自省是主动的，成就是被动的
                        你写下来的自省 ≠ 系统注意到的成就
                        但可以重合——你发现了一个变化，系统也发现了

榜单                    榜单是公开的，成就是私有的
                        榜单上显示「你在归属感维度进入了前 6666 名」
                        成就墙说「2026 年 5 月 19 日，你第一次完整感受归属感」
                        一个是位置，一个是记忆。两种东西。

身体数据                身体成就是由数据触发的
                        但描述用的语言不是数据语言
                        「深睡 2h」→ 成就写「你的神经系统修复得很好」
                        数据只在触发时被读取，不写在成就里
```

### 7.2 「不游戏化」不是「不记录」

```
游戏化    用虚假的稀缺和进度驱动行为
记录      用真实的回顾确认已发生的事情

成就系统做的是记录。不做任何驱动行为的事。
如果记录本身影响了用户的行为——
让用户想「我该去多经历一些」——
这只能是用户自己生出的想法，不是系统诱导的结果。
```

## 八、总结

```
感受成就系统

做一件事之后被确认    不是做完一件事得到奖励
强度是影子            不是目标
没有预告              没有进度条
没有比较              没有排行榜
没有稀缺              没有限时
没有闪光              没有徽章
只有文字和时间        只有你走过的路

地球 Online 的成就系统不需要服务器验证你有没有作弊——
因为你在活着，这件事不需要证明。
Feelings 的成就系统也一样——
你感受到了，这件事不需要徽章来证明。
徽章不会让你的感受更真实。
```
