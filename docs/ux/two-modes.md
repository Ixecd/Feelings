# 两种模式：增强现实与感受生成

> 作者：qc
> 日期：2026-04-06
> 核心：出门在外戴着，也可以一个人在家里享受整个Feelings带来的感受张力

---

## 一、同一套设备，两种工作方式

Feelings 根据用户当前状态，自动判断或由用户选择进入哪种模式：

```
增强模式    用户在真实场景中
            场景提供内容，Feelings设计感受的形状和深度

生成模式    用户独处，没有外部场景
            Feelings直接注入完整的感受体验
```

不是二选一的功能开关，是系统根据当前状态的智能判断。

---

## 二、增强模式

**触发条件**

```
设备检测到    用户在运动（游泳、跑步、健身）
              用户在社交场景（多人在场的生理信号）
              用户在移动（位置传感器变化）
              用户主动选择「增强模式」
```

**工作方式**

场景在外部真实发生，Feelings在内部工作：

```
游泳时        Feelings感知到高强度运动
              增强「突破边界」的感受形状
              可以是突停型——游到极限然后戛然停下的那个空洞
              可以是波浪型——每一圈都在加深的节奏感

吃饭时        Feelings感知到社交场景
              增强归属感和联结感的基调
              不创造关系，让真实的关系感受更清晰

博物馆时      感知到用户在接触历史内容
              增强感受的落地深度，让它停得更久
              让那个震撼真正刻进神经系统
```

**用户体验**

出门在外，正常生活。Feelings在耳后、后颈、腕部默默工作，不打扰，不提示，只是让那些感受比平时更真实。

偶尔一个信号——「你现在的状态适合深化这个感受，要开启增强吗？」

## 三、生成模式

**触发条件**

```
设备检测到    用户静止，独处
              没有社交场景信号
              用户主动选择「感受体验」
```

**工作方式**

没有外部场景，感受完全由内部生成：

```
用户在家，躺着或坐着
闭眼，身体自然放松
Feelings读取当前生理基线
判断现在适合什么感受方向
    ↓
注入感受包
混音结构 + 感受形状 + 音乐 全部启动
    ↓
用户在安静的空间里
体验那些日常生活里触及不到的感受
```

**肢体的状态**

生成模式下，最佳状态：

```
推荐    闭眼，躺着或坐着
        让身体自然响应感受信号
        不刻意控制，不刻意压制身体的自然反应
        自然产生的肢体冲动是感受的一部分，不要阻止它

不推荐  同时刷手机或看视频
        注意力分割会干扰感受落地
        两个输入流互相竞争，感受密度大幅下降
```

**感受形状在生成模式里的价值**

生成模式是感受形状发挥最大效果的场景：

```
突停型的断裂    在外部无干扰的环境里，那个断裂最清晰
余震型的余波    没有外部刺激竞争，余波会被完整感受到
延迟爆发型      铺垫阶段不会被外部事件打断，等待更有质感
双峰型的意外    第二峰在完全投入的状态下，意外感最强
```

## 四、模式切换

两种模式不是硬切换，是连续的：

```
用户出门游泳（增强模式）
    ↓
游完回家，躺下（生成模式）
    ↓
Feelings检测到状态变化，轻提示
「你现在的状态适合一次完整的感受体验，要继续吗？」
    ↓
用户确认，无缝切换
```

增强模式里积累的感受状态，可以成为生成模式的起点——系统知道用户今天经历了什么，可以在生成模式里做有意义的延伸或对比。

---

## 五、与感受闭环的关系

两种模式产生的数据都进入感受闭环：

```
增强模式    真实场景里的感受数据
            反映用户在真实生活里的神经系统状态
            是个人基准最真实的部分

生成模式    纯粹的感受体验数据
            更精确，干扰更少
            是评分校准和感受包优化的主要数据来源
```

两种数据互相补充——增强模式给生活的真实截面，生成模式给精确的感受测量。
