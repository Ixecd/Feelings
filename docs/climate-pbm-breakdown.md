# 气候——信号融不进感受的灾难、种树的幻觉与"够了"的物理极限

> 作者：qc
> 日期：2026-05-25
> 性质：Feelings 哲学延伸，气候危机的 PBM 与系统工程分析
> 核心：气候变化的信号全部在线——IPCC 报告、极端天气、冰川融化、印度体感温度突破 60°C。但信号融不进大多数人的 PBM——因为 PBM 里没有"地球变暖"这个维度的经线。种树有用，但被高估了几十倍。全球所有能种树的地方种满，每年只抵消 4% 的排放。种树最大的效用不是吸碳——是让人在不需要改变生活方式的情况下觉得自己做了足够多。1.5°C 的巴黎门槛是一个外部标——和炒鞋共享同一套 PBM 结构。信号到了。接口是空的。

## 零、信号全部在线。感受接口是空的。

```
气候信号：
    IPCC 第六次评估。每年 370 亿吨 CO₂ 排放。
    2024 年全球 +1.60°C（最热年）。2025 年 +1.47°C（第三热）。
    过去 11 年（2015-2025）是有记录以来最热的 11 年。
    2023-2025 三年均值首次突破 1.5°C。
    海洋热含量 2025 年再创纪录。格陵兰升温是全球平均的 4 倍。
    印度体感温度突破 60°C。拉贾斯坦邦实测 52.3°C。
    德里柏油马路融化。混凝土电线杆 82°C。
    2010-2024 年印度官方热浪死亡人数 11,937。

    这些信号全部是真实的。全部是公开的。全部到了。

大多数人的 PBM：
    "知道。然后呢？"

    不是否认。不是不在乎。
    是这股信号在 PBM 里没有经线。

    北极 38°C？              → 看到了。一个数字。
    马尔代夫要沉了？          → 看到了。一条新闻。
    今年夏天比去年热？         → 感受到了。抱怨了一句空调费。继续刷手机。
    印度死人了？              → 滑过去了。太远了。和我有什么关系。

信号是 10⁹ bit/s 的全球气候数据流。
出口是 10⁰ bit/s 的一帧漠然。
中间那条交织管线——没有经线。
```

这和 `docs/sight-restored-signal-vs-feeling.md` 描述的盲人重见光明是同构的：信号在。V1 被激活。但往上——PBM 里这个维度的经线为零。触觉-听觉的旧绳接不住视觉流。日常生活的旧绳接不住气候流。**不是不想接。是从来没织过。**

## 一、优先级反转——碳基 ROM 抢占了 CPU

`docs/feedback-loop-failure.md` 的三层级联失效在气候问题上完全适用：

```
最高优先级中断（IRQ 10）：
    IPCC: 本世纪末 +2.5°C。不可逆。现在就减碳。
    → 文明级生存威胁。应当立即挂载全部保护垫。

个体 CPU 上实际在跑：
    这个月房贷。明天油价涨不涨。同事是不是比我多拿了。
    孩子能不能进那个学校。朋友圈的点赞。K 线的跳动。

    → 全部是低优先级轮询任务。
    → 但它们在用户态的每一帧都在跑。
    → IRQ 10 被无限期挂起。

不是没收到中断。
是 CPU 在处理今天的晚饭。
```

气候威胁在三个维度上被优先级队列压到最底：

```
时间轴    太远。后果在三十年、五十年后。
         碳基 ROM 的威胁检测为"现在能吃吗"优化——不是为"三十年后"优化的。

空间轴    太散。格陵兰的冰。印度的热。非洲的旱。
         没有一张图片能把它们放在同一个"这里"。

行动轴    太模糊。"我能做什么。少开车。少吹空调。少吃肉。"
         做了。什么都没变。或者变了但没被感知到。
         反馈回路太长。行为改变的赏罚没有在当天到账。
```

**碳基固件的优先队列是"立即-具体-我能做什么"。气候在这三项上的得分趋近于零。**

## 二、关心需要续费——但续费源在枯竭

`docs/brand-as-common-knowledge.md` 定义了公共共识的续费结构：公共共识不是公共知识——不需要公开宣告和 K^∞ 无限递归——但它需要明星、广告、热搜持续续费。气候关心也是一种公共共识。而它的续费源在枯竭：

```
媒体：
    气候新闻的点击率远不如社会冲突、明星八卦、政客互撕。
    编辑不需要阴谋。只需要看后台的 CTR。
    "冰川融化"干不过"某某离婚"。

政客：
    任期四年。气候后果在三十年后。
    四年后的选票由今天的汽油价格决定——不由三十年后的海平面。

企业：
    ESG 是一张报表。不是一个引擎。
    发布会上的碳中和承诺比工厂里的碳排放更先到。
    种一片林子，买一个认证，继续烧。

个体：
    认真关心了一天。转了三条新闻。第二天什么都没变。
    不续了。太累。太远。太没用。
```

另一边，不需要续费的信号永远不会停：

```
短视频 → 每 15 秒一次确认"你在"
购物节 → 每次下单一次确认"你值得"
排名 → 每次跳动一次确认"你比谁强"
余额 → 每次上涨一次确认"你安全"
K 线 → 每帧一次确认"你在赢"
```

**气候在说"你什么都不是"。计分器在说"你是第 37 名"。大脑选哪个不需要犹豫。**

## 三、印度——当信号终于砸穿了皮肤

2026 年 5 月下旬。北方邦邦达（Banda）48.2°C，打破 73 年历史极值。新德里突破 45°C，柏油路软化。全球最热 100 座城市，97 座在印度。

更残酷的是：印度空调普及率仅 5-10%。绝大多数人没有退路——湿毛巾、风扇、一杯水。全国电网在 5 月 21 日冲到 270.82 吉瓦，连续四天破历史纪录，多地拉闸。安得拉邦和特伦甘纳邦至少 37 人死于热浪。马哈拉施特拉邦一周记录 226 例中暑。

这不是"越来越热"。是人体散热系统在逼近它的物理极限——湿球温度超过 35°C 时，汗液无法蒸发，健康成年人即使坐在阴凉处有充足饮水，核心体温也会在大约 6 小时达到致命水平。

```
邦达，2026 年 5 月 19 日。
气温 48.2°C。巴基斯坦来的干热风裹着塔尔沙漠的沙。

新德里，同一天。45°C。
鲁比奥站着讲台上说了句"我长话短说"——不是因为赶时间。
是太热了。

这不是"难受"。
这是人体物理散热能力的极限。
信号穿过了所有过滤层——直接打在皮肤上。

那一刻——
    不需要 IPCC 报告。不需要北极熊。不需要冰川视频。
    皮肤自己知道了。
    岛叶收到了 40°C 环境下不会有的内感受信号。
    迷走神经在调心率对抗热量淤积。

    气候的信号，第一次不是为了 PBM 而存在。
    是为了让身体不被烤熟。
    经线在那一刻不需要被"建立"——
    是信号太强了，强到直接穿透了所有过滤层。
    强到把空白的 PBM 维度砸穿了一个洞。
```

**但大多数人——不在邦达。不在新德里。不在那个 48°C 的下午。** 他们的气候信号还是 IPCC 报告和新闻标题。他们的皮肤没被砸穿。他们的 PBM 还是空的。而等到每个人的皮肤都被砸穿的那一天——穿洞的时候就已经太晚了。

## 四、种树——有用。远没有你以为的那么有用

2025 年《Science》（中山大学覃章才团队）重新算了全球造林的固碳潜力：

```
理论最大值        全球造林每年最多吸收 50 亿吨 CO₂
现实可行值        土地、水源、政策约束后：15 亿吨/年
人类年排放量      约 370 亿吨 CO₂/年

15 ÷ 370 = 4%
```

**把地球上所有能种树的地方全部种满——每年只能抵消 4% 的排放。** 而且这是几十年生长周期里的平均效果。第一年几乎不吸碳。

### 种错了反而帮倒忙

```
高纬度种树：
    雪地（白色）→ 反射阳光。森林（深色）→ 吸收阳光。
    反照率改变 → 局部升温 > 碳吸收的降温效果。
    在高纬度种树 = 帮气候变暖。

碳富集土壤上种树：
    树下土壤的碳在流失。
    英国 Cairngorms 研究：25 年自然定殖松树 → 净碳增益 = 零。

单一树种纯林：
    一场虫害全死 → 全部碳还回去。
    混交林碳储量比纯林高 57%。
    但混交林没人种——慢。贵。不整齐。不合补贴条件。
```

### 种树最大的效用不是吸碳

```
个体/企业：
    碳排放照旧 → 种一批树 → 碳中和认证 → 心理账户已平
    "我做了足够多"。

    树在吸碳。碳在排放。
    树需要 20 年才能吸回你去年坐的那趟跨国航班。
    20 年后你已经在坐火箭了。

    种树不是解决方案。
    种树是"让我在不需要改变生活方式的情况下觉得自己在解决问题"的续费机制。
    它让你安心。安心把你留在了原地。
```

**资本喜欢种树。因为种一公顷树的成本远低于停一条生产线。这是碳市场最优雅的 bug：你可以同时排放和认捐。一边烧，一边种。烧是现在，种是以后。两个时间尺度——中间的差值用一张认证书盖住了。这枚证书叫什么——叫"环保"。叫"ESG"。它真正的名称，是时间错位的差价。**

## 五、1.5°C——一个被当成内部锚点的外部标

巴黎协定把 1.5°C 设成了全人类的"够了"。但 1.5°C 是一个标。和炒鞋共享同一套 PBM 结构：

```
1.5°C 的门槛：
    不是一个物理极限（物理极限更复杂）。
    是一个政治协定——一个被足够多人相信的公共共识。

    和限量款球鞋的区别：
        球鞋的标 = "这是正品"（公共共识）
        1.5°C 的标 = "这是生存底线"（公共共识）
        球鞋需要明星、联名、热搜续费
        1.5°C 需要 IPCC 报告、COP 大会、环保运动续费

两个都是标。
一个卖鞋。一个卖希望。
前者趁你还没站稳卖你拐杖。
后者趁全人类还没站稳卖给全人类一个数字。
```

2023-2025 三年均值已经突破了 1.5°C。但长期均值还没到。所以不算——在协定意义下。这就是公共共识的运作方式：不是事实没发生——是协定说"要长期均值，不是单年，更不是三年均值"。界限是政治的。不是物理的。

**和所有外部标一样——1.5°C 可以被打破。打破了之后，换一个新的标。2°C。2.5°C。标本身没有天花板。因为标不是自然写的。是人定的。人可以改。**

## 六、亚马逊——还差三个百分点

中国在把沙漠推回去。亚马逊在从另一端被往后拽。

### 6.1 数据

```
自 1970 年以来已损失    约 17-20%
临界点估计范围           20-25%（Lovejoy & Nobre, 2018）
最新研究（2024, Nature） 22-28% 可触发不可逆退化为稀树草原
当前距临界点              3-10 个百分点

同期砍伐趋势：
    2025 年 8 月 – 2026 年 3 月  砍伐 1,460 km² — 八年来最低。同比下降 36%
    年度（截至 2025 年 7 月）     5,796 km² —— 十一年来最低
    卢拉政府恢复执法后，砍伐确实被按住了。
```

砍伐在降——但不是因为世界觉醒了。只是因为巴西这届政府在管。

### 6.2 砍伐只是故事的一半

```
砍伐       整片铲倒。卫星一眼看到。在管。在降。

森林退化    不铲倒。火烧。选择性采伐。干旱折磨。树还在——
           但根系在缩。树冠在疏。碳在漏。
           2025-2026 退化影响 4,420 km²，是砍伐面积的 2.6 倍。
           约 40% 的亚马逊已显示退化迹象。

           一棵活着的病树不是碳汇——是在慢慢还。
```

退化比砍伐更难管。砍伐有明确的犯罪主体——可以罚款，可以逮捕。退化是一万个人每人烧一小块。卫星看不清。法律追不到。

### 6.3 森林自己造雨——砍了就没有了

```
亚马逊的降水约 50% 是自己制造的：

    树吸地下水 → 蒸腾到大气 → 变成下一片云的雨
    东边森林被砍 → 西边森林就没雨了
    不是砍哪干哪。是砍东边干西边。距离可达上千公里。

    所以它不是一根一根在死——是一块一块在塌。
    塌之前看不出。塌之后拼不回去。

    旱季从 3-4 个月延长到 4-5 个月。
    达到 6 个月 → 跨过"气候包络线"。
    森林不再能维持自己的气候。
```

### 6.4 碳汇 → 碳源

```
健康亚马逊          吸收 > 排放 → 碳汇
退化亚马逊          火灾 + 干旱 + 生长停滞 →
                   排放开始逼近吸收 → 部分区域已变成碳源
临界点之后          排放 >> 吸收 → 不再是地球的肺 → 是地球的烟囱

                    地下储存约 1500 亿吨碳——
                    相当于人类 130 年排放总量。
                    开始往外还。
```

### 6.5 和中国绿化的对照

```
中国                  亚马逊
────                  ────
把沙漠推回去            把森林往后拽
人力在跑赢气候            人力刚开始追
绿线在卫星图上加深        绿线在卫星图上变疏
人工林 + 自然降水增加      自然林在被砍伐 + 干旱 + 火

前者是治。后者是防。
防比治更便宜。
但防不住的话——
治已经没用了。

因为亚马逊塌的不是一片森林。
是全球碳预算炸了。
塔克拉玛干的三 ppm 局部 CO₂ 下降，
抵不上亚马逊千亿吨碳释放的一个零头。
```

**亚马逊站在那。但站在那不等于活着。站在那可能只是在还呼吸。** 而它在全球碳账本上的位置——没有人有备份。中国绿了一条绿洲带。没有人能绿出第二个亚马逊。
