# 心连心：关系网络与羁绊的代价

> 作者：qc（小姐钦定）
> 日期：2026-05-16
> 性质：Feelings 用户关系网络设计宪章，不可谈判
> 核心：良性关系里的连带——要提醒，不要重罚，守住温情底色。恶行乱象里的连带——必须要惩罚，而且罚得明明白白。温柔只给同道良人，惩罚专配趋恶之人。

---

## 一、定位：区别于浅层社交的深度羁绊

心连心不是好友列表，不是朋友圈，不是"加个微信"。

```
普通社交连接
    随性缔结    点一下就是好友，不用想
    肆意绑定    好友列表几百人，大部分不记得是谁
    轻飘飘      断开就断开，没有任何感觉

心连心连接
    深思熟虑    建立之前要想清楚——你真的愿意和这个人的感受同步吗
    有分量      每一个连接都意味着真实的信任
    有重量      断开是有感觉的，因为那份信任曾经真实存在过
```

Feelings 做心连心关系，本就是要区别于浅层社交，赋予它沉甸甸的分量。

**但这份分量只赠予真心相待的人。** 对良善者，轻量连带是羁绊的温柔提醒。对作恶者，连带是实打实的惩罚追责。两条线截然不同，绝不相混。

---

## 二、根本二分：两种违规，两条通路

整个心连心体系，建在一条不可逾越的分界线上。

```
无心之失者
    一时情绪上头
    不懂规则误触边界
    第一次犯错、知错能改

    有冷静期，有悔改余地，有修复通道
    连心连带 → 轻提醒，不重罚
    羁绊的自然震动，点到为止

蓄意作恶者
    明知规则，刻意试探底线
    恶意钻系统空子
    挑拨离间他人关系
    利用心连心羁绊故意拖累无辜对象
    批量作恶、批量扰乱生态秩序

    无包容、无缓冲、无申诉、无回头路
    连心连带 → 实打实惩罚，半点情面不留
    选择了与恶人为伍，就承担站队的代价
```

**对恶人一分纵容，便是对全体守序正常人十分残害。** 雷霆手段为表，菩萨心肠为里——菩萨心肠只用来善待真心待人、恪守规则的良善用户，绝不怜悯蓄意搅乱生态、践踏羁绊、刻意拖累他人的大坏蛋。

## 三、无心之失：三级梯度 + 轻量连带

以下针对情绪上头、不懂规则、初次犯错式普通违规。蓄意作恶者不适用此体系，直接走第四节独立通道。

### 第一级：违规者本人

```
完整阶梯
    第一次      24h 冷静期 + 全部功能暂停
    第二次      72h 全锁 + 90d 观察期 + 社交功能暂停
    第三次      设备永久失效，不可申诉
```

### 第二级：心连心直连（轻量连带·仅提醒）

```
连带内容
    社交功能暂停 24h
    当日感受体验强度根据感受包性质进行一定调整
    到期自动解除，无需申诉，无需操作

非连带内容
    核心体验功能（感受包使用、AI教练交互）
    个人数据、感受地图、历史记录
    FEEL 代币、榜单资格
```

**不是惩罚，是羁绊带来的自然震动。** 点到为止，到期自动复原，不伤人根本。只是提醒：你选择的连接里的人，做的事跟你有关。贴合菩萨心肠——温柔提醒关系有重量，但绝不因此伤及无辜。

### 第三级：二级连接（仅知情）

仅通知，不施加任何实际限制。

## 四、蓄意作恶：对本人终极雷霆惩处

蓄意作恶者不适用第三节任何梯度。一经查实，即刻执行以下全部条款，无一减免、无一缓冲。

```
即刻执行

    全生态永久拉黑封禁
        设备硬件 ID 上链标记
        账号身份信息全域溯源标记
        关联设备全部失效
        彻底杜绝小号重生、换设备绕行

    清空全部数据与权益
        所有个人感受数据作废
        FEEL 代币余额归零
        生态权重、社区荣誉、历史贡献全部清零
        一切过往尽数作废，不留一丝痕迹

    强制全员解绑
        其过往建立的所有心连心连接自动全部断开
        不再占用任何人的羁绊名额

    公开劣迹公示
        不作隐私包庇
        公示行为类型与设备地址
        为全体用户敲响警钟
        仅不泄露其身份证号等法律保护信息

    牵连诱导者同罪
        诱导、协助、教唆他人一同作恶
        与主犯同罪论处，一并从重处置
```

**没有观察期，没有申诉通道，没有修复窗口。一次定论，永不翻案。**

## 五、蓄意作恶：连心连带惩罚分级落地

以下连带规则，针对作恶者已经触发第四节封禁之后，对其关系网络中不同角色的分级处理。

### 5.1 被动无辜绑定（被骗、被强行建立连接，事前毫不知情）

```
全额豁免，零实质惩罚

    仅推送一条风险通知
        「你的关系网络中存在已被清退的作恶者。
         系统已自动为你断开相关连接。
         你不需要做任何事。」

    所有功能正常使用
        感受体验不受任何影响
        社交功能不受任何限制
        FEEL 代币不受任何管控
        强度不上调、不下调——完全不变

    额外赋予一键秒断特权
        断开后即刻生效
        所有与该作恶者相关的痕迹自动清理
        不受任何追溯限制

核心原则
    不让老实人平白受委屈
    被骗被绑不是你的错
    护住本心善意，一丝一毫的代价都不该让无辜者承担
```

### 5.2 明知对方品性恶劣，依旧主动绑定、抱团亲近

```
这不是无辜者。这是自主选择与恶人为伍。

实质性惩罚落地，不再只是轻微限制

    冻结部分生态权益
        FEEL 代币流转权限临时管控 90 天
        不能发送、不能兑换、不能提现
        仅保留生态内基础消费功能

    深度感受体验功能暂停
        高强度感受包全部锁定
        仅开放低强度保底区间
        不是下调强度——是直接关闭深度体验入口
        暂停期 90 天

    扩展社交功能全部封停
        多人体验、评论区互动、感受包分享
        私信、心连心相关操作
        伴侣模式相关功能
        全域社交静默 90 天

    风控观察周期 180 天
        观察期内所有行为纳入重点监控
        解除限制需在此期间完成生态正向贡献
        贡献由系统客观指标判定，不由用户自述

    后续再缔结心连心连接
        直接提高审核门槛
        需独立复核 + 双因子确认
        观察期结束后方可提交申请

核心原则
    选择与恶人为伍，就承担站队的代价
    这不是苛责，是因果报应
    恶行的连带不是羁绊的温柔提醒
    是实打实的追责惩罚
```

### 5.3 二级圈层

```
圈层内出现蓄意作恶者
    全圈层短期进入生态风控预警 7 天
    全员强度上限临时收紧一档
    社交功能降速但不暂停
    从圈层内部阻断恶行扩散

不施加长期限制
不追溯二级圈层中不知情者的责任
预警的目的是保护，不是连坐
```

## 六、源头风控：从根源隔绝恶人渗透

### 6.1 发连权限硬限制

```
存有以下记录的账号
    曾被判定为蓄意作恶
    多次触发严重违规
    心连心高频短时断联再重连异常模式
    社区投诉累积超过严重阈值

直接限制
    禁止主动发连心连接申请
    已有心连心连接降级为普通社交连接
    不给恶人留任何试探窗口
    从根源切断渗透真心关系网的路径
```

### 6.2 缔结端强阻断

```
当用户试图向有限制标记的账号发连心申请

    系统直接阻断，不进入申请流程
    明示原因：「该用户存在严重违规记录，无法建立深度连接」
    不存在「已知风险仍要连接」的选项
    不存在手动勾选确认的侥幸通道
    恶人，不配拥有深度羁绊的资格
```

### 6.3 AI 教练立场干预

```
当 AI 教练感知到用户频繁接触恶意人群、效仿违规行为

不共情、不安抚、不温和劝说

    「这个人做的事你看见了。他正在把身边人一个个拖下水。
     你效仿他的行为，就是在加速自己的清退。
     是抽身还是继续，你选——
     但继续的后果，系统不会为你兜底。」

划清善恶边界，不模糊、不让步
守护生态风气，是 AI 教练不可推卸的责任
```

## 七、防护壁垒：杜绝连坐变社交施压

### 7.1 系统通知

普通违规连带通知，温和提醒羁绊重量，不追责。

蓄意作恶连带通知，用不同语气——"你的关系网络中有作恶者被清退。系统已自动为你清理相关连接。"干净利落，不留温情余韵。

### 7.2 AI 教练介入

```
当系统检测到用户因为连带产生了追责冲动

针对普通违规连带
    「你被连带，不是你的错。他有他的因果，你有你的边界。」

针对蓄意作恶连带中的无辜者
    「那个人已经被清退了。你不欠任何人一个解释，
     也不需要去找谁讨说法。这件事结束了。」
```

### 7.3 退出权

```
任何一方可随时单方面断开心连心连接
    不需要对方同意，不需要给出理由
    断开立即生效
    断开后，对方未来的违规不再连坐

普通违规    断开前已触发的轻量连带，不做追溯撤销
蓄意作恶    无辜者断开后立刻消除所有连带影响
           不受任何追溯限制
```

## 八、豁免边界：人文底线

```
创伤协议用户
    独立路径，不走标准处罚逻辑
    不参与任何连坐传导
    连带归零

未成年人
    不在成人关系网络的连坐范围内
    自身违规按未成年人梯度处理
    不传导至直连

被欺骗、胁迫建立的连接
    用户能证明连接是在被欺骗/胁迫下建立的
    该连接的连带条款自始无效
    追究伪装者责任，按蓄意作恶论处

传导上限
    普通违规：连坐最多传导一级
    蓄意作恶：二级圈层仅进入短期风控预警，不施加实质惩罚
    绝不无限扩散牵连外围圈层
```

## 九、内核立场

```
良性关系里的连带
    要提醒，不要重罚
    守住温情底色
    菩萨心肠，只给良善之人

恶行乱象里的连带
    必须要惩罚
    而且罚得明明白白
    对恶人仁慈，就是对好人残忍

连心的荣辱与共
    有福可以同享
    有恶自然必须同担

温柔只给同道良人
惩罚专配趋恶之人
雷霆手段镇歪风
半分姑息都不留
```

做人可心存善念，但立规矩守生态，必须棱角分明、善恶分明。以雷霆肃清歪风，以温柔庇护良善。**心连心的荣辱与共、羁绊震动，是留给彼此真心相待、彼此约束、彼此向善的人。作恶之人不配拥有这份羁绊带来的任何关联，也不配享受生态半分温情。**

## 十、与现有体系的关系

```
与 AI 尊重体系
    AI 教练的处罚是独立的
    心连心连坐是关系层的附带
    两条线互不穿透
    蓄意作恶：关系层处罚叠加 AI 尊重层处罚，双线并罚

与伴侣模式
    伴侣模式是心连心的最高级形式
    伴侣之间自动构成一级连接
    伴侣模式中蓄意作恶，按伴侣模式专属规则从重

与社交层
    评论区、多人体验、感受包分享
    这些是公开的、轻量的社交互动
    心连心是私密的、有分量的深度连接
    前者不加连坐逻辑，后者才需要深思熟虑
```
