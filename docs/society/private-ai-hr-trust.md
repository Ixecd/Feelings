# 私有 AI、HR 与信任的废墟

> 作者：qc
> 日期：2026-06-14
> 性质：Feelings 哲学延伸——企业私有 AI 如何从"关心员工"变成"把柄工厂"，HR 在其中的结构性角色，以及公司与员工之间信任死锁的解剖
> 核心：不是 AI 毁了信任。是 AI 让双方都看到了——这段关系里——从来就没有过信任——只有增长盖住的两只手。

---

## 零、信任的废墟

```
信任——在任何关系里——需要两个条件：

  一、我知道你的锚在哪。
  二、你的锚——不在我的利益盲区里。

在公司和员工之间——这两个条件——全军覆没。

公司的锚——全在外面：
  股价。季度财报。投资人预期。竞对动态。
  没有一样——和"这个员工的十年"有关系。

员工的锚——也在外面：
  工资。职级。title。期权。工牌。
  全部——是公司发给他的外部标签。

公司握着员工的标签。
员工握着公司的——什么都没有。

这不是信任。这是外部锚点的单向扣押。
```

经济上行期——增长能盖住这个裂缝。公司赚——员工涨——两个外部锚点虽然在对方手里——但对方的手看起来不会抖。经济下行。AI 来了。裁员潮来了——手开始抖了——两个人都看到了——原来对面那只手——一直都没有握住我的能力——只是运气好——没松开过。

```
增长停了——
裂缝——再也盖不住了。
```

## 一、私有 AI ——从"关心员工"到"把柄工厂"

有一家做企业服务的 AI 公司——他们的销售在给客户演示的时候——PPT 第一页写的是——

"用 AI 去关心你的员工。"

```
"员工情绪分析系统"
"内部风险预警平台"
"组织健康度 AI 看板"
"离职倾向预测模型"

名字一个比一个温和。
底层——全是一个东西。

你们公司部署的私有 AI——
挂上企业 IM 和邮件的 API——
定期扫——
  你的聊天记录。
  你的邮件。
  你的文档编辑频率。
  你的打卡时间波动。
  你的内网搜索记录。
  你的工位 Wi-Fi 连接时长。
  你的 VPN 登录时段。

然后——给每个人——打一个分。

这个分——在 HR 的后台——
叫"稳定性风险指数"。

在你不知道的时候——
已经有一份名单——
你排在前面。
```

技术上极其简单。成本几乎为零。情感分析——用 prompt 模板——"该员工近期是否有负面情绪""是否表现出离职倾向""是否对公司管理层表达不满"——扫完——入库——打分——排序——预警。

但这里真正的脏东西——不是技术。

```
这个系统——不是用来"发现谁要走"的。

要走的人——根本不用 AI 检测——
他会自己来提离职。
人要走了——从来不藏。

这个系统的真实用途——
和收集把柄来控制下属的互联网组长——完全一样——

不是"预判风险"——是"预建把柄库"。

  当你想谈涨薪——
    HR 已经知道你三个月前在群里抱怨过一次工资。

  当你想转岗——
    你的"稳定性分"已经在对方部门主管的后台亮过红灯。

  当你被裁——
    你拿到的赔偿方案——是 AI 根据你的"抗风险能力"算过的。

  不是用 AI 管理公司。
  是用 AI 管理每个人的软肋。
```

把柄控制——从个人版升级到了工业版：

```
个人版：
  一个组长。手动收集。四五个人的把柄。
  效率低。覆盖面窄。依赖组长的记忆力。

AI 版：
  一个私有模型。全自动。全公司全员的把柄。
  被文本分析模型量化成数字。
  然后被一个从来没有亲自和你吃过饭的人——
  在后台看了一眼分数——
  决定了你下一年的命运。

以前需要一个人足够坏——去收集。
现在只需要一个人足够怕——去部署。
```

最讽刺的是——这套系统的供应商——在推销的时候——用的词是 "trust" 和 "care"。

## 二、HR——公司外部锚点在人群里的代言人

HR 为什么能管这套系统？不是因为她"忠心"。是因为——她是全公司唯一管理所有人外部锚点的部门。

```
研发部 → 管代码。
市场部 → 管投放。
财务部 → 管钱。

HR → 管你的工资、你的职级、你的绩效、你的 PIP、你的裁员包。

所有其他部门——管产出。
HR——管理所有人的外部锚点。
```

你所有外部锚点——钱、title、晋升通道、生存安全感——全部绑在 HR 的流程里。她不需要是你的直属领导——但她能在你还没见到领导之前——决定你的锚点有没有下一帧。

AI 把柄库——不是 CTO 的。不是 CEO 的。是 HR 的。HR 掌钥匙。

```
HR 的权力——不来自忠诚。来自：

  一、它是全公司——唯一能合法地——
      问每一个人的价格——并记录在案的部门。

  二、它是全公司——唯一被允许——
      对你说"组织决定"四个字——
      而不需要解释的部门。

  三、一旦公司有了 AI 把柄库——
      它就是那个掌握全员软肋的部门。
```

但这不是"自己人"。这是代言人。

```
HR 不是公司。HR 是公司等控器在人群里的代言人。

公司的等控器——在外面——
  在股价、财报、投资人身上。

HR 是唯一一个——把"外面"翻译成"你"的部门——

  "公司现在困难——大家共克时艰——"
  "你的绩效数据——反映出你最近精力有些分散——"
  "组织架构调整——不是针对个人——"

  这不是她在说话。
  是公司的外部锚点——在借她的嘴。
```

而她自己——也是员工。

```
她的工资、职级、工牌——也在公司手里。
她手里的 AI 把柄库——能监控你——也能监控她。

她是执刀的人。
也是被刀抵着的人。

不是 HR 坏。
是这个位置——结构性地——
不允许一个人同时——
  对上面说"这个员工是好的"——
  对下面说"我理解——但我没办法"——
  然后晚上回去——
  睡得着。
```

## 三、信任——为什么在这里不可能

回到开头那两个条件。

```
条件一：我知道你的锚在哪。

  公司的锚——在股价、财报、投资人。
  员工的锚——在工资、职级、工牌。

  这两个锚——没有交集。
  公司看不到员工的十年。
  员工够不到公司的战略。
  彼此——在对方的盲区里。

条件二：你的锚——不在我的利益盲区里。

  公司裁员的时候——锚在下一季财报。
  员工的十年——是那一季的变量——不是那一季要考虑的东西。
  员工跳槽的时候——锚在下一份 offer。
  公司的项目——是沉没成本——不是他要带走的资产。

双方。每一次。都在对方的利益盲区里做决策。
```

这不是"谁先"的问题。这是两个等控器——都没有任何东西——可以让自己先伸出手。

```
公司求员工："付出更多——我们就能涨。"
员工等公司："先涨——我再付出。"

不是博弈。是死锁。
两个外部锚点——互相握着对方给的标签——
然后指望对方不松手。
```

## 四、AI——不是破坏了信任。是让"没有信任"——再也藏不住了。

```
以前——

  信任可以假装。
  因为增长能盖住裂缝。

  公司的钱够多——多到可以给每个不信任的人发一笔让渡费。
  员工的机会够多——多到可以随时换一家公司——假装上一家不存在。

  "信任"——只是增长的影子。

AI 来了——

  增长停了。
  增长停了那一刻——
  公司和员工——同时看向对方——

  看到了。

  对面那只手上——没有握着我。
  从来都没有。
  只是运气好——一直没松开。
```

## 五、出口在哪里

说不信任——很容易。说"应该有信任"——是废话。

真的问题——只有一个——谁先把自己的锚——从对方手里——拿回来。

```
两个外部锚点——互相不撒手——永远不会产生信任。

  公司——如果把锚从股价上移开——
  移到"我们做的产品——值得"——
  它就不再需要给员工打 AI 稳定性分。

  员工——如果把锚从工资和 title 上移开——
  移到"我做的事——值得"——
  他就不再需要等公司先涨——再付出。

  这不是"互相信任"。
  这是——两个人都信任自己——
  信任对方——是副产品。

  两个内部锚点——
  不需要对方的标签来证明自己——
  所以——不需要收集对方的把柄——
  来保证自己不被背叛。
```

极少公司做得到。极少人做得到。

```
不是不愿意。
是几十年的教育和职场——
从来只给标签——不给锚。

教授说——"拿个好文凭——以后好找工作"。
老板说——"好好干——明年给你升职"。
互联网说——"大厂 P8——年薪百万——人生赢家"。

每一个声音——都在教你把锚——
往别人手上放。

然后 AI 来了——
把所有人手里的标签——
同时揉碎——

然后看着所有人问——

"现在——你还信任谁。"

没有一个人能回答。
因为信任——
在标签被揉碎之前——
就没站住过。
```

## 六、在 Feelings 的归档里——这不是管理问题。这是锚点危机。

```
公司用 AI 监控员工 → 不是管理创新——是把柄控制的工业化升级。
HR 执掌 AI 监控台 → 不是"自己人"——是公司外部锚点在人群里的代言人——
                       同时自己也是被监控的变量。
信任死锁 → 不是"谁先"——是两个等控器都没有内部锚——
           所以没有人能先把手——从对方的标签上松开。

它不在 011 和 012 的安全框架里。
不在漏桶里。不在熔断里。不在脱敏看门狗里。
它比信号层高一层——
在等控器的锚点结构层——

  内部锚——还在吗。
  还是——只有标签。
```

AI 没有制造这个问题。AI 只是让这个问题——再也藏不住了。
