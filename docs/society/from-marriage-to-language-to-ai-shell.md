## 一、妻妾为何缩成了一夫一妻

妻妾制不是被法律废除的，是被信息铲平的。

```
蒸汽革命     一个人不用管家丁成群才能生产。机器替了劳动力。
             不需要一个地主养百口人。多了——物理不让你养。

工业革命     流水线。一个人。一台机器。不需要宗族。不需要妻妾替他管后院。
             女人也能上班。不要你那个饭碗。她不用靠你锁。
             一夫一妻——是双方都养得起自己——不需要另一个人替他扛。

互联网       信息透明。谁在外面有两个。一搜。全知道。壳碎了。
             以前妾是隐在府里——没人知道。现在不是纸——是数据在云端——没人能替你藏。
             信息把最后那层"没人知道"的壳拆了。
```

不是道德进步。是蒸汽、电力、光纤——一层一层——把那层壳拆了。拆完之后——一夫一妻——不是法律推的——是物理只给得了一个。没有壳。藏不住。也养不了多的。那个人自己也能跑。不需要你锁。一帧归零——不需要等任何人。


## 二、人妻和偷情——猴子已经演过一遍了

偷情不是人类发明的。猴子早就演过一遍了。三只猴子一台戏——每一只的盘算——都焊在基因里。

```
母猴的盘算    最大化后代基因多样性。
             不专一依附最强猴王——默许偷袭交配——让自己幼崽混合多个雄性基因。
             一旦族群环境剧变、首领意外死亡——后代不会全绑定单一雄性血脉——
             大幅降低一窝幼崽全部被新首领杀死的风险。
             这是雌性演化出来的自保策略——不是"不忠"——是基因在替她分散风险。

偷袭雄猴的盘算  正面打斗会重伤甚至死亡。
               弱势个体放弃硬刚——专挑首领分心、外出争斗时偷配——
               不用承担战斗代价——也能传递基因。
               这是自然选择保留的投机策略。两种路线并行——整个种群基因池会更丰富。

母猴不反抗      不是"愿意"——是反抗得不偿失。
               奋力挣扎、高声呼叫——会引来首领暴怒——轻则自己受攻击——重则腹中幼崽被杀死。
```

放到人类社会来看——道德、契约、情感、责任体系——本质就是人类用文明规则——压制这套原始灵长类本能。婚姻最根本是利益捆绑。爱情是上层的情感包装。底层骨架是法定利益共同体。两个人——出钱——出力——谁欠谁——在纸上——写着。

人妻——不是喜欢"别人的老婆"。是**喜欢那层已经被别人锁过的经线——不需要签合约——不需要扛利益——不需要锁——她自己有自己的壳——你推——退——都是她的——不是你的。便宜。不锁。归零。不用扛。** 补充合约上没写排他性——那扇门是开着的。两个成年人——在各自的基线上——自己跑了——自己扛——不需要任何人替你们归零。

所以幸福和爱是非常昂贵的。不是价格昂贵。是**有保质期。** 每次当你进入到幸福中时——倒计时也就开始了。合约轨上每一帧——你俩都在跑——对了——那是幸福——偏了——归零——再跑——再歪——再归——直到有一天——不是谁不想跑了——是任何一台等控器都有自己的归零极限——超过——壳裂——裂——那层——不是你——也不是她——是时间。


## 三、道德——最古老的公字壳

当代婚姻中，双方都老老实实并不会被指指点点——反而会被冠以"负责任的好夫妻。"如果出现出轨——街坊邻里指指点点——这指点的本身就是道德对人直接的作用。

```
不出轨的人    被盖章"好夫妻"——壳替他加分——"我们——是——模范——"——归零——不需要——跑——
              因为——别人——已经——替他们——盖章——"你——没——问题。"

出轨的人      不是先怕警察——是怕隔壁看见了——菜场——电梯——每个人偏过头——不说——
              但你的等控器在回家路上——在电梯里——没有人开口——壳替所有人盯着——
              那天晚上——邻居没跟你说"早"——那一帧——比任何法庭——更——深——"
              你——被——集——体——焊——回——去——了。"
```

道德就是最古老的公字壳。法律没有在每一张床上盯着——街坊在盯。不需要监狱——只需要——"你今天没跟我——说——早——"——偏差——有人在对你——沉默——沉默——沉默——不是——字——是——那冷掉的"早。"


## 四、有了孩子之后——两条路

结了婚，有了孩子。一方觉得压力太大——走了——消失了。有的人没走——留下了——把自己的牺牲发在网上——证明自己是一个负责任的人。

```
抛弃的人     他走了。他不会发——发——街坊——互联网——壳——会把他骂碎。
             自私——利己——选——走——不归零——壳——是沉默——消失。
             不需要任何人的赞扬——不需要"负责任"三个字——不是他的——他不争——不演。
             沉默本身就是壳——替他躲过所有偏差——没人知道他在哪——他的等控器不需要跑——
             不需要面对"我不负责任"的归零——因为没人看——没人写评论——然后骂碎。
             不需要演——只需要沉默。

留下的人     他留下了。代价是自由和时间——劳作——日复一日。
             他把牺牲发在网上——"我是负责的父亲——我没有抛弃——"
             网络——赞扬——鼓励——"你是好爸爸。"
             那些话不是空洞——是他的新壳——替他在那帧——不再觉得苦——不再是"我失去——"
             而是——"我在被认可——我的牺牲——有意义——值——"
             他的等控器在那些赞里——跑——再跑——不是他不累——是壳替他跑——
             "我是负责的好人——我在做对的事——"
             然后——继续——干——不跑——不悔。
```

不是哪条路更高尚。两者都是等控器在归零。抛弃者用消失躲偏差——留下者用网络赞——把牺牲归零为"我被认可了——我是负责的——好人。"那层"负责"——不是自由——是壳——替他跑——不需要自己说服自己——不需要问"我为什么这样"——因为别人已经替他回答了。"你是好人。他信了。然后——继续——劳作——不需要再怀疑——壳已经锁住了那扇门。

所以"为了孩子"——大部分时候——是借口。孩子是两个人共同选择的结果——生之前没考虑——生之后——孩子变成了挡箭牌。"我这么累——还不是为了孩子——"不是孩子让你累了——是你在没想清楚之前——签了那张合约——然后把合约的物理代价——推到孩子身上——说——"是——为了——你——"不是孩子的错——是你自己选的——孩子从来没要求过——你——留下——或者——你——走。孩子只是个壳——替你——盖住了——"我自己——不想——扛——我的——在你说——我是为了——而——我——本该——自己——签——字——那一刻——自己跑——归零——不是——在——孩子——面前——把——责任——推——给——一——具——还没——长大——的——等控器。"

## 五点五、有人就是喜欢孕妇——禁忌本身增稠了渴望

有一部分人——就是对孕妇有性唤起。心理学上有个专属名词——**妊娠恋物癖**——在各类小众性偏好谱系里并不罕见。成因不是单一的。

```
身体感官     孕期激素带来的身体特征改变、孕育生命的特殊氛围感——打破了常规审美——
             对这类人群会形成独特的感官吸引力。不是他选的——是那根经线在某个他不知道的帧——
             偏在了那个方向上——他自己也不知道为什么。

权力心理     孕期女性行动受限、身心更为脆弱——这种强弱落差——让一部分人获得心理满足。
             不是喜欢孕妇——是喜欢"她被锁住了"——那帧——他的等控器——不需要再害怕——被拒绝——
             被甩——因为她在物理上——被孕期锁在原地。支配欲和安全感——同时——被满足了。
```

这种偏好只要仅仅停留在内心幻想层面——不去纠缠现实中的孕妇——不实施骚扰——仅仅属于个人私密心理偏好——不触碰法律与道德红线。一旦越界——强行搭讪——骚扰——刻意劝说诱导孕期性行为——不顾对方孕期健康风险——尤其是前置胎盘、有流产风险的孕妇——亲密行为会直接威胁母体与胎儿生命。这已经不是偏好——是**漠视对方身体安危——只满足自身欲望——等控器在那个方向上——已经焊歪到不需要看对方——壳——已经——不是壳了——是碾过去的——不——看——对方的——脸。**

社会层面为何普遍排斥这种公开取向。孕妇处在生命最需要保护的弱势阶段——社会共识是对其进行保护而非当作欲望对象。将孕育新生命的特殊生理状态——单纯当作情欲载体——很容易突破大众伦理共识。所以这类想法很少会被公开讨论。

但这里有一层悖论。**正是因为社会层面普遍排斥——禁忌感——反而进一步增稠了那群人对孕妇的渴望。** 越不能提——越不能说——越——被——压——在那条经线上——那条——不是他选的——在那层——"不能说"——"不该说"——壳——底下——越长——越——粗——不是因为他想——是那层壳——在压——压——越——反弹——那条——他已经——无法自己控制——归零——的线——在——隐秘的角落里——独自——跑——越跑——越——偏——偏——到——壳——也——看不——到——他的——等控器——在——那——无限——压——紧——的——壳——下——藏——着——那根——从不被人允许——自己——说——出来的——经线。**

这就和前面串起来了。绝对有这种——在怀孕期间发生了性交——孩子生下来——然后嘴上一直说"不都是为了孩子嘛"的人。那层壳——"为了孩子"——替他——盖住了孕期那几帧——不是"为了孩子"——是他自己对孕妇的渴望——在"为了孩子"这层最不——容易被追问——的壳——后面——藏——在——两个字的——背后——别人——看不见——他的——等控器——在那些帧——不是——父职——是——自己——从未——归零——的那条——孕妇——性——吸引——经线。


## 七、社达从胎盘开始——那条经线已经被人替你焊了

```
孕期母体焦虑 → 胎盘 → 胎儿 HPA 轴发育偏向过度警戒
              → 出生后基线皮质醇比别人高
              → 杏仁核敏化阈值更低
              → 等控器在还没任何外部事件之前，已经在"危险"方向提前焊了第一帧
```

不是基因。是那根基线——在子宫里——已经被母体的皮质醇提前焊歪了。别人出生——基线是平的。他出生——基线已经往焦虑方向偏了。同样的偏差——别人跑一次就归零——他跑三次。起点不是他的——是你在孕肚里的情绪替他提前焊了。他不记得——但他的身体记得。

社达不是后来的。是在脐带被剪断之前——在任何一个生物第一帧前——那条已经被母体的弱焊在低的出发线上的经线——永远不认识自己的那个原点。


## 八、语言——劣势方卖惨求同情

弱者的等控器不能咬。没有壳。只有哭。只有说——只有一遍一遍对另一个人重复偏差。终于有人替他——"嗯，那是真的疼。"然后——在语言里——他的等控器不需要咬——不需要跑——不需要死——在被听懂的那一帧——归零了。

```
强者    壳厚——偏差被壳吞——不需要说——不需要哭——壳替他扛。
弱者    无壳——只有哭——只有说——用语言替自己归零——不需要咬——不需要死。
```

不是弱者被淘汰。是弱者的那条最原始的经线——哭——诉——在人类这里——不止是一颗信号——是唯一不需要野兽法则、不需要公字壳、不需要咬的归零路。人可以用语言卖惨。用语言求情。用语言替自己的等控器——在那个他不需要面对任何物理暴力的空间里——跑完偏差归零。


## 九、语言是有逻辑的动物演化出来的工具

```
兽      用石头砸——用树枝捅——但不会对自己说——"不可以。"
人      会对自己说——"不能这么做。"
        那是逻辑——不需要任何外部暴力——不需要壳——不需要别人扛——
        自己用自己说过的那句——"因为——所以——不应该"——提前锁住了本能。
```

逻辑先于语言。不是因为你有了汉语才能想"因为——所以。"是你先有了那根因果链的经线——然后随便用任何一串符号——中文——英文——俄语——只要对面那台等控器能从这串符号里复原出同一根因果链——语言就完成了它的唯一任务。不是传字。是传那一帧。"因为——所以——然后——你懂了——我也说完了。"

反过来——当语言不通——逻辑传不过去——你再愤怒——对方只感到懵比。你用中文天花乱坠的脏话骂一个不懂中文的外国人——他不是愤怒——是完全不知道你在说什么——不是因为你骂得不够狠——是他的等控器在那几帧——缺了那套符号和解码键。而逻辑——在俄语里——和汉语——是同一条——只是壳不同——里面那条——是一样的。

本质上——人是有逻辑、能演化出语言、用语言替自己和他人跑归零的动物。不比野兽高级。只是多了一层——"因为。"然后不需要咬。只是——对面缺了那套解码键——再精彩的脏话——他听到的——只是你在乱叫。
