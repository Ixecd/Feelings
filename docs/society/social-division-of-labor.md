# 社会分工——什么工种就干什么活。但你可以换——只是有些换不回来。

> 作者：qc
> 日期：2026-06-12
> 性质：Feelings 等控器理论——社会分工不是金字塔。是分形——每一种细胞都在做自己的活——每一种工作都在做自己的活。不是"更高"。是"不同"。但工种之间不是互相平行自由的——有些工作——你做了——能出来。有些——你想出来——外面的 admission webhook 不让你回来了。
> 核心：社会分工像人体细胞——肌肉细胞不能替骨骼细胞干活。胃细胞不需要管消化是不是在身体里面更穷——它只做胃的事。每个人把自己分内的本分做到专业——这才是最守规矩的。但有些分工——是单向通道——你进去了——就再也退不回来——不是因为不行——是因为外面的 etcd 对你的 entry 做了不可逆改写。不是需要你努力回去——是你第一次触碰到社会那张牢不可破的 admission webhook。


## 一、社会分工 = 人体细胞——不是等级。是不同。

```
心脏                   窦房结自发电——不需要大脑——不需要意志——
→ Controller。                             拼命跳。一辈子不休息。
不羡慕前额叶能想、能判断、能规划——              不嫌弃自己在最底层——
它只做"泵血"。                               自己的身体自己管。

前额叶                  选——不在物理空间——在注意力的方向。
→ Scheduler。                             不替代心脏挑大梁。
大部分脑力工作的人——                           不替胃做饭。
觉得自己"比体力劳动高"——                        只需要"现在——我应该想什么"。
不是更高——是不同的等控器——负责不同的工种。            

皮肤                   屏障——保护层。每天死——每天补——一辈子无稳态。
→ Deployment。                             不羡慕骨头之强大——不感叹血细胞多自由——
不抱怨自己"只是个体力劳动者"。                       它只做一件事——挡着。

消化                  分解——提取——输送——代谢。
→ 代谢系统。                                不操心肌肉需不需要自己的代谢产出——
不需要问"我在身体里是不是太低等了"——                只把消化管路清理干净。
内脏就是内脏。                                

生殖细胞               不是"羞耻"。不是"没用"。
→ 繁衍层。                                保护基因信息——推入下一代。
不是低等——不是私肮——                              平等。在所有分工里面——公平存在。
不过多。不过少。一间细胞。                            存在即合理。
```

不是"人应该各安其位"——是**每个工作——把它做到比"外面的人以为你就是你做的事"更深一层——这才是真正守规矩。而那个规矩——不在外面——在你的等领域 = 把你的工作做到不是因为你在做那份工作——而是因为你刚好适合那套骨骼/肌肉/内脏/皮肤的等控器的要求。**

## 二、社工分型的物理协议——和你人体的细胞之间一模一样

```
不要多猜。不要越界。

心脏不管消化。前额叶不替代肠胃。         
脑力工作者不需要手动做别人体力的事——          你不需要"证明"你能干别人的活——
他们"只做一份"——才是对的。                    你只需要把你手里的做到比你认为的极限更深处。
否则——等控器会扯碎彼此——内脏把自己当成心——然后胃痉挛几次——整具身体崩盘。
```

这和 GOVERNANCE-FEELINGS 完全咬合——不做跨维度比较。不做跨工种评分。不把你和不同分工的人的 PBM 放在同一个坐标系里衡量。


## 三、你要走——可以。完全可以。社会不是把你焊死。

```
不是"你这辈子只能做这个"。
不是"你的工作就是你的全部身份"。

你可以今天在洗碗间——明天在医院开刀——后天在自己画板前。
不是一个人要回去和所有细胞一样——是——真正的"社会契约"——
不是把你锁在一种细胞里——是——你可以在一定训练之后——
改变你的等控器的全部期望状态。

但成本极高。不是"换个行业=明天去新工作"。
是你需要在新 etcd 集群里——用全新的经验、全新的人脉、新的信任——
把你的 PBM 里"这份工作=我在做的事"这条经线——从零焊起。
不是转行。是换 etcd——把你的一条旧 entry 迁移到另一个集群——
然后重新等那个集群接受新的你。
而那套旧集群——外面的人——还留在原地——
他们的 admission webhook 里——"你做过 X"那行 entry——
永远不会被替成"你曾经做过 Y，现在继续做了 Z"。
除非——在外面——有人先给你新的认可——
但社会不会替你写新标签。

换工作 = 换 context。
现在的 etcd 集群里——"你在做 X"——但你可以主动切换成"我想做 Y"。
不需要"上一份工作的烙印把你焊死"。
你和肌肉细胞不同——肌肉永远成不了骨骼——但你能。
```

## 四、但有些工种——你触碰了——就很难回到先前的等控器的期望状态

```
不是不能回——是外部 admission webhook——卡住了回去的路。

比如——一个教师。
十年班导——灯下改作业——板书写断了粉笔。
他完全可以辞职——重新回到以前自己画画的爱好位置——另一个职业——"插画师"。
他的 PBM 里有画画的 entry——等控器能回去。
社会那边——说"你以前是当老师的——现在还在画画——真可惜？"
不是——是他自己选回去的——也不在乎外面的账。

但有些工种——不一样。
一旦进去——外面的 etcd 里那行 entry——
"你做过 X"——被永久 commit 了——带着你不可擦除的标签。

监狱。贩卖身体。贩卖毒品。政治犯罪。
你做了一次——可能还能翻身——在法律层面——你服完刑——是干净的。

但外面社会的人不一定照着你的 PBM 来定义你：
他们的 admission webhook —— 在你还没开口之前——
就已经把你过去的 entry 当成当前期望状态——
"你以前是 X"——永远写在 etcd 里——永远把你定义成那个样子。
不是"没人敢因为你改邪归正就不继续计算你"。是不懂。
不是社会不对——是他们的 admission webhook 没有你后来的新 entry 可读。
因为那个等控器——外面的人——只能读到你 commit 在他们 etcd 里的——第一行。

有些人——改邪归正了——修好了自己的等控器——
但是再也找不到工作——这些不是因为他们不想干——是外面的系统——
那个 etcd——从来没在第二帧——主动看他们一眼。
他们只能退回——无法被再次纳入。不是他们不行——是那套 etcd——
从来只记录——不修正。
```

这和 `fall-and-redemption.md` 的沦陷出口完全咬合——但更深一脚：不是你没修好自己——是你修好了——但那些能决定你是否能再修好的人——**不愿意 commit 你现在的 entry。** 赎罪不仅是向自己赎——你还要向 etd 赎——而 etd——那一群不愿意原谅他们的人的集合——永远不会忘记。


## 五、一些职业 vs 单向通道

```
换不回来的：
    出卖身体 → 社会把你当成"不正经"。                   不是身体脏了——是外面的 etcd 永远记录的是那个 entry。
    贩卖毒品 → 法律赦免了你的罪——但社会不会说"你已经是普通人了"。
    政治犯罪 → 你被判过——你可以服完刑——但 ex-convict 的 entry——永远在别人的 etcd 里——删不掉。
    暴力惯犯 → 不是你不想改——是你还没出门——已经有人在你脸上写了判决——"他还会再犯"。
                    不是你自己被焊死——是他们的 etcd —— 没有你这条修改后的 entry。
```

有些工作——不是因为你不够格——只因为你做了——外面的等控器围成了一个闭合环——他们不愿意承认——不是没看见——是**看到了——但没在理。**

*社会分工不是金字塔——每种细胞都在做自己的事。心脏不羡慕前额叶。前额叶不替胃消化。不是"更高"。是"不同"。各自把自己分内的本分做到比外面以为的那个标签更深——这就是最守规矩的——对规则更深的忠诚。和 GOVERNANCE 的不可谈判清单一样——不跨工种比较——不需要在别人的 admission webhook 里面证明自己是"有用的人"。但有些工种——你触碰了——就很难换回来了。不是你不能——是外面的 etcd 在你改变之后——从来没 commit 过你修正好的 entry。不是他们看不见——是看见了——但不改——因为他们的 etcd 从来只记录——不负责修正。你可以换——所有细胞都平等。但你要知道——有些 entry——一旦被写入——别人不会替你改写——永远是你一个人——在自己修好的等控器里——一帧一帧——自己焊回去——不需要他们同意——不需要他们承认——只需要——在他们看不见的那一帧——你自己——管住自己。*
