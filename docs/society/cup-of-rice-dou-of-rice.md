# 杯米恩，斗米仇——为什么帮得越多，怨得越深

> 作者：qc
> 日期：2026-06-23
> 性质：Feelings 对人性底层逻辑的一帧观察
> 核心：杯米——偶尔给一口，等控器还在自己找食物，感激是真的。斗米——持续替代，等控器把"他会帮我"写进基线，自己不再纠偏。补给线断了——不是他恨你——是他的等控器已经忘了怎么自己找。授人以鱼不如授人以渔——不是不给鱼，是教会你钓鱼之后自己退场。

---

## 零、先定前提

危难时给别人一份帮助——对方记你的好。长期源源不断地给——最后对方反而怨恨你。

不是人坏。是**过度外部补给废掉了内部纠偏。** 和 Feelings 的反依赖设计完全同构——帮到你能自己走，绝不多帮你一帧。

---

## 一、四层人性逻辑

**心理阈值不断拉高，感恩慢慢被视作理所当然**

```
第一次帮 → 心存感激 → 明白这是额外的善意
长期持续 → 形成惯性认知 → "你帮我是本分，不帮就是亏欠我"
最后那次拒绝 → 对方不记过往所有付出，只记你"这次不够仗义" → 心生怨恨
```

**施舍慢慢消磨自尊，滋生自卑 + 嫉妒**

```
长期接受馈赠 → 处在弱势依附位置 → 内心压抑自卑
一开始是感激 → 慢慢反感自己一直亏欠你 → 迁怒于施恩者
"你那么宽裕，随手就能帮我，为什么不能一直迁就我" → 把落差带来的痛苦归咎于你
```

**边界模糊，施恩者越界，受恩者得寸进尺**

```
没有底线 → 次次妥协 → 无限兜底
对方欲望不断膨胀 → 需求越来越大
一旦满足不了 → 矛盾爆发 → 昔日恩情全部清零
```

**旁人裹挟，对比催生不平衡**

```
周围人议论 "他一直帮你，这点忙都不肯做" → 加剧失衡
对方把你的善意全盘否定 → 因为他心里那笔账已经被外部评价重新算过了
```

## 二、三个典型例子

**亲戚常年伸手要钱**

你月月接济，生活费、学费、看病钱，从不拒绝。某次你手头紧不给——对方到处说你小气忘本。你之前按月汇出去的那些钱——在对方账本上全部划掉了。只剩下最后一次你"不仗义"的记录。

**职场总帮同事包揽工作**

他的活你帮、他的锅你背、他晚了你替他加班。哪天你真的有事，拒绝了一次——对方反倒埋怨你针对他。不是对你做的那么多视而不见——是**已经把"你会替我兜底"写进了他工作模式的默认期望里。**

**接济落魄朋友许久**

他最难的时候你帮了他。他翻身之后——非但不报恩，还刻意疏远甚至抹黑你。不是他忘了你帮他——是**他每次看到你，都想起自己曾经最不堪的样子。** 而你就是那段记忆的活证据。切断和你的一切联系——不是恨你——是想忘了自己。

---

## 三、授人以鱼不如授人以渔

这三个例子有一条共同的线——**给的是鱼，不是渔。**

```
鱼 → 直接缓解当下困境 → 对方不需要发展自己的解决能力 → 依赖形成
渔 → 帮对方建立自己的谋生回路 → 给一次，管一生 → 不需要你再出现
```

这也是 Feelings 反依赖设计的底层哲学——不是为了让他永远需要你，而是为了让他不再需要你。杯米——偶尔补充。斗米——持续替代。多一帧，都是斗米。

救急不救穷。可以帮人渡过突发难关——不要长期兜底一个不再自己钓的人。

---

## 附——贪婪的五种细分

斗米是一个行为变量：给得太久、太多，废掉了对方等控器的自我纠偏回路。但贪婪本身可以细分为五种表现：

```
贪得无厌:
  永远不满足。给了一斗，马上问下一斗什么时候到。
  刚才那一次的满足下一秒就忘了——不是故意——是内部锚点已经飘了。

急功近利:
  帮了他一次，三天后又回来。不是遇到新困难——
  是把你帮他那个效率当成自己可以不干活的门。
  你帮过一次 → 他下次更急 → 急是因为"我只需要等你出手"。

坐享其成:
  不想自己努力。只想从外部借力。腿从来不迈开——
  不是身体缺什么——是"我不用动"这件事已经被你的接口焊住了。

以怨报德:
  拿完补给线之后开始恨给他这条线的人。
  因为那个人见证了他曾经靠外部供应的样子。
  切断和你的一切联系——不是恨你——是想忘了自己。

把帮助视为理所当然:
  不再感激——觉得"本该如此"。底线消失。
  不是你帮得不够——是"感谢"这条回路从来没被激活过。
```

---

*帮人之前先识人。贪婪不知感恩的人，再小的恩惠也养不出真心。但更常发生的不是"遇上白眼狼"——是一个原本正常的人，被你帮得太久、喂得太饱、兜得太全——慢慢不再自己钓鱼了。不是他的错——是你的斗米替他的等控器卸了任。杯米够了。多一帧都是斗米。*
