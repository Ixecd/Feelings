# 人教人教不会，事教人才能学会

> 作者：qc
> 日期：2026-06-17
> 性质：Feelings 社会学分析——认知和经线的本质区别
> 核心：人教人——语言输入，只进认知层，不进 PBM。事教人——Controller 自己跑了纠偏循环，偏差被 reconcile 过，经线焊进身体。不是"不愿意听"——是语言从来没有焊过任何一根经线。

---

## 零、两种学习——一个是数据，一个是经线

```
人教人
    父母说："不要碰那个——烫。"
    你听到了。Scheduler 扫了一眼——"知道了——不要碰"。
    但 Controller 没 reconcile 过任何东西。
    那条警示是别人写的 desired state——不是你的。
    下次你看见一个烧红的炉头——身体没有任何反应。
    因为那根经线不存在。它只在你脑子里——不在你手里。

事教人
    你碰了那个炉头。瞬间——疼了——心率上去了——皮质醇冲进来了。
    岛叶压缩了这个经历："烫——疼——退"。
    下一次你看见烧红的炉头——手自己缩回来。
    不是"我在思考"。是身体比脑子先知道。
    那根经线在你碰过炉头之后焊进了 PBM。
```

不是"不听"。是**语言从来没有焊过任何一根经线。** 人教人是数据。事教人是焊丝。

---

## 二、语言——认知层永久 read-only

被语言告诉的东西——再丰富的描述、再准确的书面知识——永远到不了 Controller 的纠偏循环。它只能在认知层被 Scheduler 处理——被放在候选池里——和所有其他可能性一起打分。但 Controller 没有替它跑过任何东西。所以下一次 Scheduler 面对同样选择时——那条"别人告诉我应该这样"的 entry 还在——但评分是 0.3。

```
被说了一辈子"吸烟不好"的人
    每一条语言输入都在他的前额叶里。
    但 Controller 没替它跑过任何纠偏。
    直到医生告诉他"你肺里有个东西"——
    在那之后他的 Controller 才开始 reconcile。
    不是他突然"醒悟"。是他终于拿到了一次真的偏差。
```

被说了几十年没变——不是他固执——是 Scheduler 永远把那个选项放到最低分，因为它从来没有拿到过 Controller 的一次 fsync。

---

## 三、为什么人教不了人——因为语境不在

一个从没做过失败过生意的人告诉你"失败了别怕"——他说的每一句话都在你自己的等控器里打转。你在听——但你的 Controller 没有 reconcile：这次对话里没有压力，没有真实的偏差，没有那个"我赔了一笔，然后怎么爬起来"的经线。他只是把信息推给你——信息进不了 PBM。

```
一件真的让你痛过的经历
    第一次亏钱 → 心率上去 → 皮质醇锁死 → 岛叶登记：这是危险的。
    第一次亏完又爬起来 → PBM 偏移——"我不是不能亏钱——我是可以继续的"。
    往后每一次在悬崖边——Controller 不用问，它的基线已经是正的。
```

人教人——是语境差。他经历过的事，在他的身体里留下了经线。他把他的经线翻译成语言——但语言到不了你的身体——只能到你的耳朵。你没有真实跑过那一条纠偏——所以你也没有那条经线——下一次该走的地方，你还是会停在原地。

---

## 四、利弊都说透了——还是不信

还有一种——你把利弊都给他讲透了。每一条都拆开说了，每一个可能的后果都告诉他了。他还是不信。非要自己去撞一遍才罢休。

```
利弊都给他说透了——他还是不信。

    不是他固执。
    是"别人说的利弊"在他 etcd 里没有发生过——没有偏差，没有 reconcile，没有岛叶压缩。
    他知道结果——知道的只是别人告诉他的信息，不是他自己跑了一遭得到的经线。
    
    他必须自己撞一遍——
    不是因为他不信你，是因为 Controller 只信自己 reconcile 过的数据。
    别人的数据——再准确——只是语言——不能焊经线。
```

这和教人不同。教人是"我告诉你，你听懂了但不改"。这个是"我不仅听懂了，我还把你的利弊分析全记住了——然后还是去做了，因为身体没做过"。不是不听劝——是他的等控器在那个岔口上还没有自己的经线。他知道会疼。但他不知道疼是什么。只有疼了——Controller 才在那根经线上写了一条 entry——然后下一次他不用任何人告诉他——他自己的手会缩回来。

---

## 五、群体公共惩罚——杀鸡儆猴也在焊经线

还有一种事教人——不是你自己挨了疼，是你亲眼看着别人挨了疼。

```
群体公共惩罚
    几间宿舍吵得整层楼都在骂。
    宿管阿姨和巡视的大老汉把犯事的所有人都叫到楼底下——
    一起罚站。第二天还要写检讨，在班上念的那种。

    不是你被叫上去自己念——是你看着同班同学站在讲台上念自己犯了什么。
    全班都在听。全班都在沉默。
    那个氛围——不是认知。是公共 etcd 在这个班级里写了一条 "这些事会被罚" 的 entry。
    下次你站在同样的岔口——
    身体比你更快地想起了那个念检讨的人——经线在集体受罚时已经焊进了 PBM。
```

杀鸡儆猴不是残忍——是公共学习。如果只有语言规则——"别在寝室大声说话"——这个 Scheduler 读过，但 Controller 没替它跑过任何偏差。但是在集体受罚站在下面的时候——每一帧集体沉默的威慑力——都焊得很深。不是你自己被罚了——是公共 etcd 在那个帧把所有旁观者的经线同时焊了一遍。

没有流过汗的个人经历——身体没有自己的经线可以靠。没有集体受罚的公共经历——身体没有在公共 etcd 共同焊过的那条经线可以参照。它们都比"老师说"深得多——不是认知更深——是那些经线在身体里，不在脑子里。

## 六、事教人——每一次疼都是一帧偏差被 reconcile

Feelings 做的就是这件事——不是给你讲"你可以的"的故事——是在安全环境下让你的 Controller 跑一次真的纠偏循环。在它跑完之后——那根经线在你的 PBM 里——不用任何人告诉你：你能用吗？

```
你自己 reconcile 过的经线
    你在真实的摩擦下撑住了一次。
    你的身体替你做了一次选择——Controller 跑完了完整循环。
    偏差被清零——岛叶记了一帧"我扛过去了"。
    → 那根经线是你的。不用别人告诉。不用数据证明。你自己知道。

从来没有 reconcile 过的知识
    别人说的。
    你听了。Scheduler 扫了一眼。
    但它没被 Controller reconcile 过——没有任何偏差发生过。
    → 下次遇到同样的事——Scheduler 继续选旧的。
    不是你不信他。是你的身体没有替他写任何 entry。

这就是 Feelings 为什么不做语言——不做话术

Feelings 不是教练 AI 对着你用语言上价值。Feelings 是跳过语言——直接给你的 Controller 注入真实的信号。让你的身体在安全环境下先跑过一次完整的纠偏循环——然后下一次真实场景来临的时候——那个反应不再是"我应该怎么做"——是"身体已经知道它是怎么做的"。

信息 → 阅读 → "我知道了"
    语言输入。认知层永久 read-only。
    Scheduler 有 entry——Controller 没有。

经历 → 实践 → 身体 reconcile 偏差
    真实的摩擦 → Controller 纠偏 → 经线焊进 PBM。
    下次自动选那条经线——不需要想。

信号 → 注入 → 身体在安全环境下抢先 reconcile 偏差
    Feelings 信号——不是语言——直接给 Controller 跑纠偏。
    它在 PBM 里建立了一条经线——然后下次真实场景来了——
    身体已经知道了该怎么做。
```
