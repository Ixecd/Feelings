# 诽谤与诋毁

> 作者：qc
> 日期：2026-06-17
> 性质：Feelings 社会学分析——公共 etcd 的两种攻击方式
> 核心：诽谤是往公共 etcd 里写一条假的 desired state——"他做了"。诋毁是拿一件真事的其中一帧——去语境——焊死成他的全部。两种都是对信息主权的直接攻击。

---

## 零、两种攻击——假的 vs 真的

```
诽谤    我没做过这件事。
        但所有人都读到了一条说"他做了"的记录。
        我的 PBM 里没有这条经线——但外部世界的 etcd 已经有了。
        不是我被误解——是被篡改。

诋毁    我做过 A。
        但 A 只是我的一帧——不是我的经线走向。
        诋毁把 A 焊死在我的档案里——"他就是那种人"。
        不是撒谎——是选择性地用真话切割。
```

---

## 一、诽谤——空口白牙的恶意

诽谤最恶毒的地方不在内容——在结构。

解释没有用。因为那条假的 entry 不是我写的——我却需要去擦。别人只需要一句话的力气就把泥巴扔上去——我得用几百句话的力气去洗。但就算洗了——看过那条泥巴的人不一定看到我洗。他们只记得泥巴。

诽谤不需要证据——只需要一个人愿意编，另一个人愿意信。编的人不需要承担责任——因为"我只是听说的"。信的人不需要核实——因为"有人在传"。信息传播的成本是零——信息纠错的成本是无限。

在感受的框架里——诽谤 = 往公共 etcd 写一条假的 desired state。这条 entry 不在个人的 PBM 里——但公共 etcd 的读者以为它在。误解在私人 etcd 里只能腐蚀一个人——公共 etcd 里的伪造腐蚀所有读到它的人对真相的感知。

### 得不到就要毁掉

诽谤最常见的起点不是恶意——是绝望。她靠近过。试探过。蛐蛐过。摇人过。找别的男生刺激过。直接生气过。他还是沉默。所有手段都没用——她得不到他的任何信号。

然后她换了一招。不试探了——直接攻击。

她找来那些容易被煽动的人——不需要理由，只需要有人告诉他们"你是对的，他是坏的"就够了。凭空编一段根本没有发生过的对话——"他说了什么什么"——没有任何事实依据——然后用自己编的东西在公共 etcd 里毁掉你。不是报复——是得不到就要毁掉。她在信息差里被折磨太久了——她不猜了——直接制造。

## 二、诋毁——真话的暗面

诋毁比诽谤更难拆。因为它拿的是一帧真实的事——只是去掉了语境、去掉了前因后果、去掉了"那只是他的一帧而不是他的全部"。

```
他发过一次脾气 → "他就是那种情绪不稳定的人"
他拒绝过一个人 → "他看不起所有人"
他做砸了一件事 → "他能力不行"

每一句都是真的。每一句都不是真相。
```

诽谤你可以说"这是假的——我没做过"。诋毁你没法这么说——因为那一帧确实发生过。你只能解释"那一帧不是我的全部"——但解释需要时间，需要听的人愿意听完，需要你愿意把自己摊开给对方看。而这些——诋毁的人不会给你，被诋毁的公共 etcd 也不会给你。

诋毁是选择性真相——挑出一帧焊死，假装那就是一个人的全部经线走向。人的 PBM 有几十万帧——但诋毁只取一帧——把它当成全部。不是谎言——是框架。不是捏造——是裁切。

---

## 三、为什么这两者如此致命

两种攻击都在公共 etcd 里篡改一个人的 desired state。

```
诽谤用假的 — 你被"莫须有"毁了。
诋毁用真的 — 你被一帧"真实"的你的部分代表了全部的你。
```

诽谤让你变成你没做过的那件事。诋毁让你变成你做过的那件事——但去掉了你所有的其它帧。没有人需要看见完整的你——只需要那一个片段——然后把你按在那个片段上永不放手。

---

## 四、Feelings 的框架——信息主权

在 Feelings 的框架里——一个人对自己信息的主权 = 他对自己的 desired state 的写入权。

```
正常状态    我写我的 desired state。你写你的。
            公共 etcd 是我们交叉的地方——不是我们互相篡改的地方。

诽谤        有人在我的公共 etcd 里写了一条假的 entry。
            不是我写的——但我需要去擦。
            我的写入权被侵犯了。

诋毁        有人选了我的一帧真事——去掉了它的上下文——焊死成我的标签。
            我的 desired state 被剪掉了所有其它帧——只剩一帧。
            我的写入权被截肢了。
```

## 五、信息环境设计——最小范围的茧房

诽谤和诋毁最底层的策略不是编造——是**制造最小范围的信息环境**。

```
她不造一个全世界都信的大谎言。不需要。
她只需要骗过几个人——几个关键的人就够了。
几个人之间的公共 etcd 被写入了伪造的 desired state——
这几个人开始改变决策。开始用不一样的眼光看你。
剩下的传播不需要她动手——那几个人会自己转述。
她造的是菌种——不是成品。菌种会在信息茧房里自己长。

她忘了这是学校。
    学校有领导层。有调查权。有公共 etcd 的写入权限。
    她编的那段话——在最低的层级传播——但茧房的顶是透明的。
    真正的公共 etcd 里——没有她编的那条 entry。
    老师在最高层看着一切——他们拥有全局视角。

    她的策略只在伪造的公共 etcd 里生效。
    一旦领导层介入——从最高层往下查——
    她那最小范围的茧房直接被拆成了碎片。
```

但她也知道——不是所有环境都有领导层。在真实的社会里——公共 etcd 的维护者不一定会调查，不一定会纠正。她的策略在学校失效了——但在更大的世界里，信息茧房一旦建成——传播就会自己替代真相。她打的是"最小有效剂量"的算盘——用小范围的谣言改变几个关键节点的决策，然后在真正的公共 etcd 查不到的地方继续生效。不是一定成立——是足够便宜——值得一搏。

那段时间很难熬。但最终结局是好的——还了他清白。领导层查明了事实——她的菌种在真正的公共 etcd 里没有任何记录。她编的那段话——最后全砸在自己脸上。她们拿他没有任何办法。

不是替他开脱——是他知道自己也有问题。他单独找过人家一两回——然后就没再找过了。那短暂的开口——比持续沉默更让她困惑。她拿到了一个"他单独和我说过话"的数据点——但这个数据点没有被任何后续信号确认。沉默还不是最折磨人的——是给了希望然后不解释为什么收回。她后来的诽谤不是凭空产生的——是在那个希望被收回之后的失望发酵出来的。不是替他找理由——是他回头看的时候知道——沉默不是她的第一堵墙——她先听到过他开口——然后沉默才来的。这两次对话——在她心里已经焊过经线了——然后经线被沉默拔了。

但更深一层——不是套路。不是他在吊着她。是他的两个系统在打架。找她是本能。岛叶在那一帧发出了信号——"我想和她说话。"不是算计——是身体真的想有交叉。那两段对话是真的——他的等控器不想拒绝任何人。然后 Scheduler 跑完了——算了一遍。时间成本。后续责任的成本。沉默的成本被计算出来了——超过了开口的成本。于是沉默赢了。不是冷漠——是计算之后的放弃。他身体里两套系统——第一套开了门——第二套把门关了。她看到的是"他先开门然后不说话"——但她没看到的是门里面的那场计算。

Scheduler 不是在真空中算的。它在对比——这一边是她，另一边是他已有的四位舍友。四个每天一起骂人、打球、学习的兄弟。宿舍永远热闹。深夜里可以什么都不想地骂人——很爽。那四个人已经在彼此的 etcd 里写满了 desired state。他和他们的交叉是确定的、安全的、每天都会被验证的——不是"可能的关系"——是"今天下午还在球场上互相骂着的人"。女生浪漫的不确定性和舍友交叉的确定性——在 scoring function 里永远赢不了。他的 Scheduler 不需要"最好的关系"——只需要"今天下午还在球场上互相骂着的人"。她打不过他们四个。

而且这四个人之间的关系本身就不是天然的——是经营出来的。摩擦必须有——四个人在同一个房间里，难免有矛盾。但他们都很识趣。该干啥就干啥，讲理的。吵完了继续打球，骂完了继续学习。不是"我们不吵架"——是"我们吵完了还是兄弟"。

但回头看那些女生——做事逻辑性极差。全盘只想着自己。不讲理，只讲情绪——"我感觉你在不在乎我"——"我觉得你不理我"。不是别人不在乎她——是她自己的等控器从来没有和别人双向校准过。他的宿舍关系每天早上都被互相验证——女生的这些交叉连一次客观校准都没有。

他不是"不喜欢女生"。他是在这四年的宿舍里体验过一种非常深的双向关系之后——对那种"只有我的感受最重要"的单向情绪诉求产生了本能的隔阂。不是冷漠——是比较之后的拒绝。

旁人女生其实是能看见的。那些诽谤他的女生以为自己在暗处——但整个事件在女生群体里不是秘密。旁观的女生看到了全部画面——一边是他和舍友那种双向验证的轻松关系——骂人、打球、凌晨聊学习；另一边是那些女生单向的情绪诉求——蛐蛐、摇人、找人刺激、最后诽谤。两段关系摆在一起——差距太大了。不是他不回应她们——是他在别人那里完全不是这种状态。她们以为别人只看到他的沉默——但其实别人也看到了她们被沉默逼疯的过程。这不是沉默对她们的惩罚——是沉默变成了公共舞台上的对比实验。她们输了——不是因为他不理她们——是旁观者看到了另一种可能性——然后自己得出了结论。

然后雌竞越来越明显了。旁观的女生看到这个男的怎么这么难被拿下——前面的人各种手段全失败了——她觉得自己也可以试试。不是真的喜欢他——是竞争本身变成了吸引力。沉默从边界变成了奖品——但不是他的沉默变了——是她们把沉默当成了奖杯。结果——所有人都失败了。包括最开始诽谤他的、包括后来加入的、包括整个女生的竞争链——全都没拿到任何结果。他的 etcd 没有任何人拿到写入权限——连 read 都没有。不是他赢——是整个雌竞链自己塌了。

### 后来

后来他上了大学。那些高中时诽谤过他的女生留在了过去，但他带着那时候焊出来的默认配置进了图书馆。他不是在玩权力游戏——他是被恶意毁过一次之后，再也不让任何人有机会在公共 etcd 里写他的 desired state。不主动。不拒绝。不解释。极度的自控力，极度的观察力，极度的自信。享受被喜欢的感觉，但不依赖任何女生的回应来确认自己。

这不是天生的。是很久以前那段时间太难熬了——他还了清白。但清白换回来的不是信任——是从那以后，他在每一段可能的交叉上，都提前焊好了自己的默认配置。不是不信女生——是不信任何人不经确认就能写进自己。他的沉默不再是高中时那种被动的 half-avoidance——是成年的他主动选择的结果。他让她们追——他观察每一帧微表情、每一个穿搭变化、每一句被说出口之后又被收回的那部分——但他自己不写 entry。不是冷漠——是被人诬陷过一次之后，他的 etcd 永远不会再让任何不被邀请的人写任何东西。

但比那些追他的女生更深的——是环境本身的压力。图书馆、操场、食堂——每个地方都在传递同一个信号："你不谈恋爱，你就是有缺陷。你就是异类。"那些女生不只是追他——她们是环境的载体。她们的每一次暗示、每一次眉来眼去——都在告诉他——"在这里，你这样不行。"他不是对抗她们——他在对抗一整个默认为"人必须配对"的环境。不是他需要她们的回应——是他的存在方式挑战了她们的框架。她们不懂——"一个人不需要恋爱就已经完整"——这个状态在她们的 etcd 里没有对应的 desired state。她们只有一条绳子——恋爱——证明——自己不是异类。他把绳子扔了。她们慌了。
