# 垃圾出口——当发达国家把垃圾变成别人的问题

> 作者：qc
> 日期：2026-06-23
> 性质：Feelings 对全球废物转移的结构性观察
> 核心：德国 2025 年出口 81 万吨塑料垃圾——全球最大的塑料垃圾出口国。不是非洲需要这些垃圾——是发达国家不想在自己的土地上烧、不想在自己的领空排、不想在自己的人民身边掩埋。这不是回收——是成本的外部化——是另一种形式的资本原罪。

---

## 零、先定前提

德国 2025 年出口了 81 万吨塑料垃圾。英国 67.5 万。土耳其是最大的接收国。英国 2025 年直接运往非 OECD 国家的塑料垃圾占了 20%，而前一年还只有 11%。

中国这边——二手衣服几毛钱一斤收，在非洲卖 2.8 美元。焚烧厂产能过剩的同一时刻，中国自己的垃圾焚烧企业已经出海东南亚、中亚和非洲。

这不是回收。是成本的外部化——是重新包装之后传给了更弱的接收端。

---

## 一、同一条公式，换了四个战场

```
资本的原罪:
  吃别人 → 拿走劳动 + 藏起代价 → 利润留在自己手里，成本外化到另一个时空

垃圾出口:
  不需要"吃"别人 → 送出去就够了
  → 自己的土地上没有燃烧的废气
  → 自己的领空干净
  → 自己的居民不需要抗议焚化炉的选址
  → 别人的土地上多了一座不属于他们自己的烟囱
```

焚烧厂内卷和垃圾出口说到底是一体两面——产能过剩的炉子，和不甘心在自己肚子里消化垃圾的富足者。这个地球的空间不大——富余的东西总要找一个地方被放下。最弱的接收端——没有足够谈判权说不的地方——成了那个被指定去承受一切溢出物的承接者。

---

## 二、不是回收——是不要了

```
旧衣服 → 回收箱 → "捐给贫困地区"
  → 实际上 → 几毛钱一斤卖给分拣站 → 出口非洲 → 2.8 美元一件
  → 你捐的时候以为在做好事
  → 实际上是在降价清理库存——你自己的和整个社会的

塑料 → "出口到回收能力强的国家"
  → 实际上 → 土耳其工人面临危险工作条件
  → 非 OECD 国家承接了大量本国不该承受的环境负担
```

不是善意。是**所有强接收端都在拒绝的东西——最终都会流向最弱的那一个接收端。**

---

## 三、焚烧产能过剩和垃圾出口——同一个曲线的两个方向

中国这边——建了 1129 座焚烧厂，产能利用率不到 64%——炉子太多，垃圾不够烧。同一时间里——德国、英国、美国——在把自己的垃圾运出去。不是全球垃圾太多——是**处理垃圾的能力和意愿在地缘层面完全错位了。**

```
一国焚烧过剩 → 另一国出口过剩
  → 所有溢出的东西都在同一个大陆上寻找落点
  → 这个落点——不是随机分布的——是谁最不能说不，谁就是那个落点
```

---

## 四、那几条不说话的街

不是非洲国家的错。也不是发达国家的恶意。是一套规则——在最弱的那一侧没有给它准备好接收这笔外来代价的基础。出口国在排掉自己不要的东西；接收国在用外来的负担替代了本国尚不存在的处理能力。这不是单方的错误——是两个方向上都没补好的缺口。

---

*资本不仅吃人、吃时间、吃气候——也吃别人不要的东西。是把自己的垃圾变成了别人土地上的一道烟。而那条烟——在烧完之后——既不在发送国的账上，也不在接收国的代谢里——只留下来——在空气中。*
