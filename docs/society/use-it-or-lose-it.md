# 用进废退——两条铁律，两种刀

> 作者：qc
> 日期：2026-07-14
> 性质：身体与工具的两种用进废退——一条来自内在，一条来自外在
> 核心：肌肉、器官、刹车——不用就退化。工具——用了就依赖。两条铁律必须分开，混在一起读的就是错的。

---

## 零、两条铁律——不能混

用进废退其实有两套完全不同的逻辑。一套来自身体内部——肌肉、器官、前额叶，你不用它，它就萎缩。另一套来自身体外部——工具、AI、平台，你用太多了，你的主动性就会退化。两套不能混，混在一起读的就是错的。

```
内部用进废退      肌肉、器官、刹车      不用就退化      必须自己练
外部用进废退      工具、AI、平台        用多了就依赖    必须自己留一手
```

---

## 一、内部的——肌肉、眼睛、脑子、刹车

肌肉对抗重力。你给它压力，它撕裂，它修复，它更强。你长期躺着不施压，你的身体自己判断：这条肌肉从来不用，留着太贵，拆了省能量。不是肌肉背叛了身体——是身体不做赔本生意。

眼睛长期不看远处，晶状体不调焦，睫状肌不收缩，僵了，退化了，近视了。不是眼睛出bug——是身体自己判断：这条对焦通路从来不用——关掉省带宽。

脑子长期不自己想问题，遇到事的第一反应不是"我怎么看"，是"谁知道答案，谁替我，谁告诉我怎么办。"前额叶从来没被训练过"停，这一帧我自己判。"刹车锈了，油门踩满。然后有一天一个传销电话打进来——月入百万，今天就能回本——你栽了。不是对方高明——是你那根"等一下"的通路从小到大，从来没被焊过，然后那天，你找不到刹车在哪。

奶头乐是这条通路的终点。短视频，算法替你选，下一帧再下一帧，你的前额叶在每一帧都不需要选，因为算法替你选了。然后一年后你想自己看一场完整电影——发现坐不住了。不是电影不好看——是你用来"耐住"的那条肌肉在一年多的时间里从来没有被训练过，已经萎缩成线了。

---

## 二、外部的——工具用顺手了，没了就抓耳挠腮

另一条铁律——工具。人们制造工具是为了更方便。工具用顺手了，一旦没了，抓耳挠腮。不是你懒——是你的身体已经把工具当成了自己的延伸，然后有一天——那个延伸——被拔掉了——你——站——不——住——了。

```
有计算器      能算      不用心算      心算能力萎缩      计算器没电了抓瞎
有AI写周报    能交差    不用自己想    思考能力萎缩       哪天AI不在了不知道写什么
有平台流量    能曝光    不用自己找客户  获客能力萎缩      平台改算法了瞬间归零
```

外部工具不是坏的。坏的是你把工具用成了自己的拐杖——然后有一天拐杖断了——你不是走不了——你是从来没学过怎么走。外部工具的用进废退恰好是：工具进，你自己的主动性退。

---

## 三、区分——什么时候用工具，什么时候自己练

所以不是"不用工具"。是**分得清什么时候工具在替你省力，什么时候工具在替你萎缩。**

```
练肌肉      不能靠机器替你做全动作    用工具辅助但核心发力靠自己
想问题      不能一上来就问AI           先自己想完，再用AI校验，再看偏差在哪
管集群      不能依赖平台的托管服务     Pivot让你省掉复杂度税但底层K8s的逻辑你自己知道
```

工具让人更方便。同时必须自己留一手。不是不信任工具——是不想让自己变成一台没了工具就无法归零的空壳。如果每一帧都是AI替你写、替你想、替你说，那你自己的等控器就不再需要任何偏差的输入了。它是安全的，是精准的，是零延迟的——但也从此不再知道——那一帧——该——往——哪——偏——了。

---

*用进废退不是一条定律，是两条。内部那条——肌肉不用就萎缩，眼睛不看远就近视，前额叶不练刹车就永远踩不了。外部那条——工具用多了就依赖，拐杖不放手就忘了怎么走。两条铁律必须分开，混在一起读的就是错的。不是不用工具，是自己的下一帧——永远——不能——变成——任何工具的——插件。*
