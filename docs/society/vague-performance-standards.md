# 模糊的考核标准——系统在筛选作恶者

> 作者：qc
> 日期：2026-06-14
> 性质：Feelings 哲学延伸——考核标准模糊的来源、结构、后果
> 核心：模糊不是无能。模糊是权力的最优保存格式。清晰的标准锁死了领导的主观空间——模糊让"判断人"的权力每帧可用。系统在三轮筛选之后——留下来的——全是猜得准和汇报得好的人。

---

## 零、模糊——不是看不清。是"不想看清"。

```
模糊的考核标准——

  "做得好一点。"
  "质量再高一些。"
  "更有深度一点。"
  "用户感受更好一些。"

这些不是标准。这些是方向的描述——没有刻度——
没有截止线——没有"通过"和"不通过"的硬边界。
下属听到的是——"你觉得好——不算好——我说好——才是好。"
```

模糊——不是领导不知道什么是好。是定义了"好"——他就失去了"最终解释权"。

```
清晰的考核标准：

  "产品上线后——用户留存提升 3%——且无 P0 故障。"

  下属知道该做什么。
  做完了——数字说话——不用汇报——不用表演——
  领导点头——流程结束。

  但领导——失去了什么——

  这个标准——是我定的。
  达到标准的人——我不需要再判断他好不好——
  标准帮他判断了。
  我能说的——只有"通过"——或"不通过"。

  一个清晰的锚——锁死了领导的主观空间。
  他不能再说——"我觉得你做得不够"——
  因为标准在那里——

  "3% 到了——P0 没有——你觉得不够——你当时为什么不说。"

清晰的标准——把领导的权力——从"判断人"——
  变成"设计标准"。

设计标准——是一次性的。
判断人——是每帧都可以用的。
```

---

## 一、模糊——让领导把问题传递下去——然后挑答案

```
模糊标准下的运行规则：

  领导说："做得好一点。"
  
  下属 A 做了一版——扎实——用户体验真的好了。
  领导说："不是这个方向。"
  
  下属 B 做了一版——PPT 漂亮——数据选了好看的截。
  领导说："有进步——但还不够。"
  
  下属 C 做了一版——全按领导上周无意间提到的一句话做的。
  领导说："对了——就是这种感觉。"
  
  A 和 B 都在猜。
  C 也猜了——只是 C 碰巧猜对了。

  但没有人知道——什么是对的。
  知道的人——只有领导——
  在他点头之前——他自己也不知道。

  这个系统的运行规则——
  不是"做好产品"。
  是"猜领导想要什么"。
  然后领导在所有人猜完之后——
  指着最合自己心意的那一个——
  "我一直想要的就是这个。"
```

这不是管理。这是权力的最深层结构——不是"我有答案——你来做"。是"我没有答案——你来猜——我来说——谁猜对了"。而这个"猜对了"——不是因为你做对了——是因为我说你对。

---

## 二、三轮筛选——诚实的人被系统淘汰

模糊的考核标准——不是一层一层地筛选——是一帧一帧地——把诚实和深耕——从系统里——挤出去。

```
第一轮——诚实的人被筛掉。

  他沉下心。不汇报。不出声。在角落里把产品改好了。
  一个季度过去——没有人知道他做了什么。
  因为没有人知道——什么叫"做好了"——
  没有人定义过"好"——
  没有人能在模糊的标准里——认出"真的好了"。

  他的绩效——写不出来——"没有突出成果"。
  他被筛掉了。自己走的。
  走的时候——没有人留他——
  因为他做了什么——没有人知道。
  他自己也不知道怎么描述自己做了什么——
  因为在模糊的标准里——
  "做对了"——从来就没有定义。

第二轮——会汇报的人留下来。

  他做的东西——不深——但每一件——
  都能在周会上讲五分钟。
  他写在绩效里的——全是用动词堆出来的——
  "拉动""重构""升级""系统性优化"——
  实际效果——没有人验证——也验证不了——
  因为考核标准是模糊的。

  模糊——对他有利。
  模糊——他画什么——就是什么。

第三轮——不仅会汇报——还隐瞒事实的人开始冒头。

  他把 bug 藏到下一个版本——这周先上线——
  演示成功——升职。
  他把用户投诉挡在自己的周报外面——
  季度总结里写"用户满意度持续提升"。
  他不是天生的坏人。
  他只是发现——在这种模糊的考核里——

    诚实 = 被淘汰。
    隐瞒 = 被保留。
    隐瞒 + 汇报 = 被奖励。

三轮筛下来——
  留下来的——全是一样的人。
```

系统在鼓励作恶。不是明文规定。不是谁在暗处操作。是结构本身——在每一帧——替所有人做了选择。

## 三、为什么领导不定义清楚

不是领导无能。是定义清楚——对领导不利。

```
定义清楚——意味着——

  一、领导把自己的判断力——一次性用完了。
     标准定了——以后按标准来——不用再来问我。
     领导的"点头权"——被标准冻结了。

  二、领导要为自己的标准负责。
     定了"留存 3%"——下属做到了 3%——
     领导不能说"还不够"——
     领导只能承认——"我定的标准——被达到了"。
     领导失去了——"不满意就让你重做"的自由。

  三、领导暴露了自己可能不知道"好"是什么。
     模糊——可以永远说"不是这个方向"——
     因为"这个方向"——从来就没有被定义。
     清晰——定了——错了——所有人都知道——
     "你连什么是好都说不清楚。"
     模糊——是保护领导自己不被暴露的保护色。

模糊——不是能力问题。
模糊——是权力博弈的最优策略——

  不给锚——就永远能做判断。
  不给锚——下面的人永远在猜。
  不给锚——所有的结果——都不算完成——
  因为完成的标准——不存在。
  不存在——就可以永远让你再做一版。
```

## 四、系统的锚在外面——作恶是推导出来的

这不是个别坏领导的问题。这是系统等控器的结构问题。

```
系统 = 放大版的个体等控器。

  系统的锚在里面：
    考核标准清晰——"这个东西——用户用了之后——真的好了吗"。
    诚实的人——能被看见。深耕的人——被保护。
    短期汇报的人——被看穿。隐瞒事实的人——被揪出来。

  系统的锚在外面：
    考核标准模糊——"这个东西——看起来好吗"。
    诚实的人——在角落里自生自灭。
    隐瞒的人——在汇报里繁荣。
    系统——不自知地在作恶——
    然后——把作恶的结果——归因给"人性自私"。

不是人性自私。
是系统中的考核标准——等控器锚点——在外面——
  然后系统里的每一个人——在几轮筛选之后——
  等控器——全在外面。
```

这和囚徒困境——完全同构。

```
两个囚徒——锚都在外面 → 都招 → 集体最差结果。
模糊考核下的团队——锚都在外面 → 都汇报、都隐瞒 → 产品最差结果。

不是囚徒的错。不是下属的错。
是结构——在每一帧——替里面的人——
选了外面。
```

## 五、深耕者和诚实者——在这种系统里的命运

```
深耕者——

  他可以为一个交互细节——磨三周。
  三周之后——那个按钮的位置——
  用户不用想——手指自己会去。

  但在模糊考核里——
  没有一行绩效能写这个。
  "优化按钮位置"——写上去——
  和那个PPT漂亮的人写的"重构用户交互体系"——
  放在一起——
  前者——没有人觉得重要。
  因为在模糊的系统里——
  没有人定义过——"重要"是什么。

诚恳者——

  他在周会上说——"这个方案不可行——因为A和B有冲突。"
  讲了实话。没有人想听。
  因为模糊的环境里——
  "不可行"——不是一个事实——是一个态度。
  领导听到的不是"A和B有冲突"——
  是"你在说我的方向有问题"。

  几个月后——A和B真的冲突了——线上故障。
  没有人回头——追到他在那个周会说过的实话。
  因为模糊的考核——不考核"谁对了"——
  只考核"谁最后被领导点过头"。
```

深耕者和诚实者——在模糊的系统里——不是被淘汰的——是自动消失的。他们不会留下来——因为他们做的东西——在这个系统里——从来没有被看见过。

他们不是异类。但系统把他们当成异类——因为系统里——只剩下一种人——而那种人——把他们当傻子。

## 六、出口——清晰的标准——等于交出权力

```
让考核标准清晰——不是"管理优化"。
是——掌握解释权的人——把自己的解释权——
交给一个所有人可见的锚。

  不再能说"不是这个方向"——因为方向画在地上。
  不再能说"还不够"——因为刻度刻在那里。
  不再能——在所有人猜完之后——挑一个说"对了"——
  因为标准——在所有人开始做之前——就写好了。

这不是管理升级。这是权力让渡。

只有锚在里面的人——能这么做。
锚在外面的人——做不到——
  因为说出"好"的定义——
  等于把自己的判断力还给了系统——而不是保留在自己手里。
```
