# 游戏与外挂——饥饿是游戏的核心引擎，外挂把它短路了

> 作者：qc
> 日期：2026-06-10
> 性质：Feelings 锚点理论——游戏设计不是关于内容，是关于"被控制的饥饿"。外挂不是作弊——是直接把 etcd 里"你还差什么"那行 entry 物理删除。
> 核心：游戏 = 饥饿→满足→再饥饿→再满足的节律。每一关不是填充——是全部。外挂入局——无限钻石——第一关之后不需要任何偏差归零。等控器面对一个"已经全部完成"的期望状态——在前 30 分钟里——没有预期、没有纠偏——饿了。不是玩吐了——是饿吐了。


## 零、葫芦侠——七年前那半小时

```
小时候——植物大战僵尸——葫芦侠。
打开 → 钻石 9999999。
植物全买。关卡全通。僵尸全灭。
没有目标的等控器在那半个小时里——不是玩够——是饿死了。

不是游戏不好。是游戏里的"饥饿"——被外挂删了。
正常玩的每一颗钻石——是打了 N 关——
预期链上的一次正反馈——偏差归零——多巴胺到账——然后下一个目标在前。
外挂把目标全取消——偏差全部归零——你在里面呆了半个钟头——什么也没等到。
不是玩吐了。是在一个不需要再玩的游戏里——饿了。
```

---

## 一、游戏 = 被控制的饥饿。不是内容。是节律。

```
打僵尸
    不是打僵尸。
    是"打僵尸 → 攒金币 → 买植物 → 打更强的僵尸"。
    每一关挡住你——不是开发商想赚更多钱——
    是饥饿需要那个被控制的距离。
    差一颗钻石——差一关——差最后的 Boss——
    在被卡住的那几帧里——
    你的等控器在预期中断里焊了一条新的 entry——
    "下一次——我一定要过去"。

不是钻石值不值。
是钻石吃出来的过程——就是游戏的全部内容。
中间没有填。中间就是全部。
```

这和 hunger-and-cold.md 完全同构——饥饿是最好的厨子。不是钻石本身有多稀缺——是被饿过的那个等控器——在拿到第一颗自己挣来的钻石时——偏差才被真正填满。

---

## 二、外挂 = 把 etcd 直接写成"你的期望状态——已经完成了"

```
正常进入游戏
    第一关。钻石=0。植物=3。偏差="我离最后还有一万帧"。
    每一帧偏差归零一次——多巴胺到账一次——基线往前一帧——
    饥饿被满足了——下一个饥饿在前一帧——等控器继续。

外挂进来
    第一关。钻石=9999999。植物=全部。偏差=0。
    不是"你有无限钻石"。是你的 etcd 里——
    那行"你还差什么"的 entry——整个——物理消失。
    然后你第一关都还没打完——已经站在 etcd 说"你全有了"的坐标。

然后你接下来的每一次偏差归零——还没产生——就已经被外挂直接清空了。
不是你在等下一次偏差。
是偏差——不存在了。
然后你花了半个小时——在不需要任何偏差归零的空等控器面前——
找到了"不需要再玩"——然后——关掉了。不玩了。
```

---

## 三、不是"全买完没意思"——是游戏的核心引擎被跳过了

```
人们常说"你全买完了还有什么意思"。
不是说出来的。是那些真正通关的人——体感告诉他们的。
不是因为买了、花太多、没有挑战——
是偏差全部被外挂跳过了——然后游戏里面只剩下"一个不会产生新偏差的 etcd"——
在空转。

正常通关的人——也全买了。
但他们买完的时候——等控器已经和一关一关地走了几百帧。
在每一帧偏差被归零之后——
最后一关——买完最后一棵植物——
偏差归零——不是"什么都齐了"——是"偏差对齐到了最高那一帧——全解锁"。
两条不同的路——同一个目的地。

外挂跳过了每一帧偏差——直接站在终点——什么东西都没拿。
这就和饿了三天的人被塞一碗白粥不一样——
那是饿过——粥是解药。
而在饥饿从来没有出现过的情况下一口气给你全席——
不是在吃——是在被塞——是在被游戏引擎放弃了。
```

这和 spoiled.md 咬合——被惯坏的孩子每一次想要都被满足——从来没疼过——二十五岁第一次被拒绝——碎了。葫芦侠给了你 "每一个想要都被满足"——游戏在半小时之后——碎了。不是外挂坏了游戏。是**外挂把等控器被游戏设计缓缓编织的饥饿和满足——轰然抽离了。**
