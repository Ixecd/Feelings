# 撑死——控制回路失效与外部计分器劫持

> 作者：qc
> 日期：2026-05-25
> 性质：Feelings 系统工程延伸，贪婪的工程故障分析
> 核心：后天锚点型贪婪的最极端表型——把自己活活撑死——在系统工程里是三层控制回路级联失效。固件层在死循环（碳基 ROM 没有停机指令集），总线层被优先级反转（身体告警被外部仪表盘 grep -v 过滤），仪表盘层接管了自我参照（计分器停 = PBM 断电）。这不是不够聪明——是油表被接在了外部计分器上。只要计分器没停，这台车就会一直轰油门，直到硬件当场炸毁。另有最纯粹的子类型——虚拟接地型——不花不比不看排名，只看数字涨，数字涨了就踏实。他们不是"够了"，是把"不焦虑"的门槛挂载在一个永远在移动的空气终点上。

---

## 零、实验室白鼠和亿万富翁——同一张电路图

实验室里，一只白鼠面对一个无限供电的电击开关。它不停踩踏板，直到力竭而死。不是贪——是它的硬件层没有给"踩踏板"这件事写停机条件。每一次踩踏板都在奖赏回路上打一个正标记。标记不饱和。踏板不停。

办公室里，一个已经财务自由的人，为了在财富榜上多前进两名，把自己卷到心梗猝死在办公桌前。

```
白鼠                                亿万富翁
────                                ────────
无限供电的电击开关                    无限递增的外部计分器
每次踩 = 多巴胺脉冲                   每次排名上升 = 社会确认脉冲
没有停机条件                          没有"够了"的经线
踩到力竭而死                          卷到心梗而死

同一张电路图。同一种死法。
不同的物种。同一个固件版本。
```

**在自然重力场下，野生动物极少把自己撑死。生理内部锚点（胃壁张力、瘦素分泌）和外部环境稀缺性完美咬合。但一旦环境切换到"人工丰裕"或"符号社会"——固件还在跑旧逻辑，环境已经不是旧环境。**

---

## 一、三层级联失效——从固件到仪表盘

撑死表型不是单一故障。是三层控制系统各自出错、彼此加剧的级联失效。

### 层 1：固件层——碳基 ROM 没有停机指令集

```
远古物理世界（Malthusian 稀缺）：
    面前有食物 → 不吃 = 下一顿可能没有 → 不吃是坏策略
    面前有食物 → 狂吃 → 超额储备 → 活过冰期 → 活到下一代
    while(resource_available) { grab(); } = 最优生存算法

现代符号社会（人工丰裕）：
    面前有无限食物/金钱/符号确认 →
    while(true) { grab(); } 从最优策略变成自毁程序
    但固件没有 OTA 更新。
    碳基 ROM 是只读的。几亿年没刷过机。
```

这和 `greed-internal-anchor.md` 6.2 节描述的硬件级生存固件是同一条根：`while(true) { grab(); }` 不是一个没写完的临时 Bug，而是经过无数次高压迭代、刻死在固件里的生存优化算法。金鱼会吃到肚子炸掉——不是贪，是硬件层没有装"饱了"的传感器。停机脚本从未被列入进化日志——因为"食物无限"在野外的发生概率趋近于零。

**这一层不是 Bug。是 Feature 在不匹配的环境里变成了 Bug。**

### 层 2：总线层——优先级反转

身体内部总线在后台疯狂报错：

```
岛叶: Warning: 迷走张力崩溃。皮质醇超标。心肌缺血。立刻停。
杏仁核: Critical: 威胁响应持续激活。糖皮质激素受体下调。不可逆损伤风险。
HRV遥测: Alert: 恢复斜率连续趋近于零。缓冲冗余耗尽。
```

但前额叶在做的是：

```
前额叶: grep -v "Warning" | grep -v "Critical" | grep -v "Alert" | grep "排名+1"
```

不是传感器坏了。是传感器被外部仪表盘的信号权重碾压了。在操作系统的术语里，这是**优先级反转（Priority Inversion）**：高优先级的中断信号（身体告警 = 物理级紧急）被低优先级的轮询任务（看分数 = 应用层循环）无限期阻塞。中断控制器没有被屏蔽——中断被收到了，但它被一个优先级比自己低的任务持续占着 CPU。内核以为自己还在跑。实际上跑的全是排名+1。

### 层 3：仪表盘层——外部计分器接管自我参照

财富榜。排名。市值。点赞数。这些都是"标"——`brand-as-common-knowledge.md` 定义的公共共识的量化版本。但这里发生的事情比单纯的消费主义更深：

```
普通消费者：
    买限量款鞋 → 通过标确认"我是谁"
    标是一个答案

撑死型追逐者：
    计分器 = 整个自我参照的电源
    计分器停 → "我是谁"断电
    不是不知道累——是停了之后不知道方向盘往哪打
```

**计分器本身只是一个数字。但 PBM 还没收敛的人，把自我锚定点焊接在了这根线上。** 这和 `mate-poaching-pbm.md` 描述的"被选中的标"是同构的——不是追分数，是追"被排行榜确认为有价值的人"这个公共共识。

油表被接在了外部计分器上。只要计分器还在跳，这台车就会一直轰油门。发动机冒烟？显示屏没报。冷却液沸腾？显示屏没报。硬件炸毁的那一刻——显示屏上的数字还在涨。

## 二、纯粹囤积者——虚拟接地型劫持

上文描述的计分器型至少还需要一个社会仪表盘——排名、市值、别人眼里的确认。但存在一种更干净、更纯粹的子类型：**不消费。不买标。不排名。不需要观众。** 只看数字涨。涨了就踏实。不涨就不安。即使不喜欢花钱。

这批人剥离了所有消费主义包装出来的限量款、联名款——把人性的电路图直接简化到了极致：**他们把外部计分器直接焊接在了系统参考地（Virtual Ground）上。**

### 2.1 为什么觉得"踏实"——虚拟接地

在电路设计中，地线（Ground）是整个电路的零电位参考点，所有电压高低必须对照它来计算。

```
正常人的内稳态接地：
    系统参考零点（0V）→ 绑定在肉身生理极限
    心率基线。深睡时长。真实饱腹感。岛叶说"够了"。
    外部数字怎么飙升——肉身满了就是满了。电位差归零。停止输出电流。

纯粹囤积者的虚拟接地：
    系统参考零点（0V）→ 焊接在银行卡数字的单向递增上
    数字每涨 1 → 一次"安全/通电"的确认信号
    数字跌 → 自我参照系统全局断电（Power Outage）
```

他们感受到的"踏实"不是真正的内部锚点上线——是**虚拟接地型代偿**。他们把肉身对"安全、确定性、存在感"的底层定义权，打包过载给了那个数字。

这带来了一个致命的逻辑悖论：

```
内部锚点的饱和度    有物理边界。深睡只有几小时。胃只有那么大。
                    "够了"是一个岛叶信号，不是一个算术结果。

外部数字的饱和度    没有边界。银行余额可以无限递增。
                    数字从来不会说"够了"——只有人在看数字时说。

当一个人认为"钱越多越踏实"——
翻译成系统语言：
    "我的安全感阈值（电位零点）正在随着数字的通胀而同步通胀。"

这不是"满足"。这是把"不焦虑"的门槛挂载在一个永远在移动的空气终点上。
```

### 2.2 三层审计——每一层都比计分器型更干净

**固件层：最原始的松鼠算法。**

在远古马尔萨斯陷阱里，单纯的"囤积"本身就是最高生存策略。松鼠囤积几千颗松果，大部分吃不完，甚至忘记埋在哪里——但"囤积"这个动作发生的瞬间，基因就给了它一个多巴胺脉冲。

不花钱、只看数字涨，是**碳基固件里"防御未来宕机风险"算法的无润滑裸奔**。计分器型至少还穿了衣服——需要社会确认这个包装。囤积型连衣服都不穿。数字 `resource_count++` 就够了。

**总线层：数字麻醉。**

这批人的总线没有断线（T2），也没有过滤痛苦（T1）。他们玩得更绝：**用外部仪表盘的数字，反向给内部总线打局部麻醉剂。**

```
生活出现失控感、衰老感、死亡焦虑
→ 这本该触发岛叶和杏仁核的最高警报
→ 他们不需要调节呼吸或修复硬件
→ 只需要看一眼银行卡余额：[资产：$X,XXX,XXX]
→ 这个数字像一颗电子布洛芬 → 存在主义焦虑被强行镇痛
```

不是身体不喊痛。是身体还没来得及喊——被余额数字抢先了一帧。每一次数字确认都是一次生理告警通路的短接。久而久之，岛叶不再尝试发送内感受信号——因为它发现每次发送都会被一个查阅余额的动作跳线。

**仪表盘层：尺子变成了土地。**

金钱原本是度量劳动的"尺子"（工具层）。锚点层的人至少还需要"别人怎么看"来确认尺子上的刻度有意义。

但这批人内部锚点一片空白——退一步脚底是空的。于是他们**不拿尺子量任何东西——直接把尺子铺在地上，当成自己踩着的土地。**

```
工具层的人    尺子是用来量的。量完就放下。
锚点层的人    尺子用来比。谁的长谁的价值高。
囤积层的人    不需要量。不需要比。需要尺子本身存在。
             尺子不在了 → 脚底空 → 不知道自己在宇宙里的坐标。
```

**他们不是喜欢钱。他们是失去了脱离这个数字之后、定义自己在这个宇宙里位置的能力。** 计分器一停，或资产重估——他们的自我参照系统当场陷入全局断电。

### 2.3 最具有欺骗性的伪装

这种"不花钱、只爱钱"的表型，是 PBM 框架里最难被识别、最难被破除的一种异化。

```
表面上                    底层
──────                    ────
情绪稳定                   数字麻醉维持的假稳态
不慕虚荣                   不需要别人——但需要数字比任何人都坚挺
克制的清修感                不是不需要——是把"需要"从社会确认迁移到了数学确认
不追逐消费主义              但追逐的是比消费主义更纯粹的数字自增

他们和计分器型同一张电路图。唯一的区别：
计分器型踩的是社会排名的踏板。
囤积型踩的是余额查询的踏板。
两个踏板连着同一条多巴胺通路。
同一只白鼠。不同的开关。同一种力竭而死的终点。
```

**他们不是"够了"。他们只是把"不够"的痛苦，成功包装成了"只要数字还在涨，我就安全"的成瘾性幻觉。这比外部计分器劫持更危险——因为计分器型至少知道自己还在跑。囤积型以为自己已经到家了。**

## 三、恶化时间线——从传感器在线到传感器断线

`greed-internal-anchor.md` 6.4 节和 `poverty-nurture-growth.md` 描述了一个更深的阶段：长期穷养会**物理破坏岛叶网格和 HRV 遥测总线**——传感器本身就断线了。

"被 grep -v 过滤"和"传感器断线"不是矛盾的——是**同一条恶化曲线上的两个时间点**：

```
T1: 传感器在线，被前额叶 grep -v 过滤
    │
    │   身体在喊痛。岛叶_后部的内感受信号完整。HRV 遥测完整。
    │   但前额叶把身体告警的权重降到了零。
    │   不是听不到——是不听。
    │
    │   表现：
    │   - 失眠但忽略——"咖啡因能撑过去"
    │   - 心悸但忽略——"体检报告还没出，等于没病"
    │   - 情绪麻木但忽略——"等忙完这个项目再感受"
    │
    │   修复成本：中等。拔掉外部计分器，重新听身体。
    │   岛叶还在。前额叶的过滤策略可以切换。
    │
    ▼
T2: 传感器断线，岛叶网格因长期闲置而受体密度下降
    │
    │   身体不喊痛了。催产素受体密度偏低。
    │   应激基因的启动子长期开放——染色质半开态。
    │   安全通路的正反馈环萎缩。
    │   不是不听——是听不见了。
    │
    │   表现：
    │   - "我不知道我累了"——岛叶内感受压缩器输出趋近于噪声
    │   - "我不知道我需要什么"——PBM 的内部锚点查询返回空
    │   - "我只能继续跑下去"——外部计分器是唯一还在运转的仪表盘
    │
    │   修复成本：高。不是顿悟可以解决。
    │   需要长周期富养——重启安全通路的基因表达，
    │   重建岛叶网格的受体密度，重新学会感受"够了"。
    │   对应 high-dimensional-gestation.md 的脏页冲刷阶段。
    │
    ▼
T3: 硬件炸毁
    │
    │   心梗。脑溢血。免疫崩溃。
    │   不是被什么杀死——是被一个已经烧红到 150°C、
    │   油表却显示"一切正常"的自我参照系统开到了尽头。
    │
    ▼
```

**T1 可以修复：拔掉外部计分器，重新听身体。T2 需要重建：先修复传感器，再教他听。** 而大多数"撑死"的人，死在 T1 以为自己是 T2——觉得自己是听不见，其实是不听。

## 四、和 greed-internal-anchor.md 的精确咬合

```
先天本能型贪（固件层）：
    蛇的捕食本能。在野外的"够"是自己的捕食身体反馈。
    → 对应层1：碳基 ROM 的 while(true) { grab(); }
    在稀缺环境里是最优策略。在丰裕环境里变成自毁。

后天锚点型贪（仪表盘层）：
    蛇在笼子里被喂饱后还在吞——因为笼子没有给过它"饱"的信号。
    → 对应层3：外部计分器接管自我参照。
    计分器不停 = "饱"的信号不存在。
    → 计分器存在两个子类型：
        社会计分器型：需要排名、需要被看见、需要公共共识（锚点层）
        虚拟接地型：不需要观众，数字本身 = 踏实（囤积层）

内外锚点摇摆（总线层）：
    深夜自省 → 接近内部锚点 → 传感器重新上线。
    第二天看到排名/余额 → 回到外部锚点 → grep -v 重新启用。
    → 对应层2：前额叶的过滤策略按上下文动态切换。

金钱三层结构与两种劫持：
    工具层    尺子。量完放下。→ 未劫持。
    锚点层    尺子用来比。谁的长谁的价值高。→ 社会计分器劫持。
    囤积层    尺子铺在地上当土地。不量不比，尺子消失=断电。→ 虚拟接地劫持。
```
