# 撑死——控制回路失效与外部计分器劫持

> 作者：qc
> 日期：2026-05-25
> 性质：Feelings 系统工程延伸，贪婪的工程故障分析
> 核心：后天锚点型贪婪的最极端表型——把自己活活撑死——在系统工程里是三层控制回路级联失效。固件层在死循环（碳基 ROM 没有停机指令集），总线层被优先级反转（身体告警被外部仪表盘 grep -v 过滤），仪表盘层接管了自我参照（计分器停 = PBM 断电）。这不是不够聪明——是油表被接在了外部计分器上。只要计分器没停，这台车就会一直轰油门，直到硬件当场炸毁。

---

## 零、实验室白鼠和亿万富翁——同一张电路图

实验室里，一只白鼠面对一个无限供电的电击开关。它不停踩踏板，直到力竭而死。不是贪——是它的硬件层没有给"踩踏板"这件事写停机条件。每一次踩踏板都在奖赏回路上打一个正标记。标记不饱和。踏板不停。

办公室里，一个已经财务自由的人，为了在财富榜上多前进两名，把自己卷到心梗猝死在办公桌前。

```
白鼠                                亿万富翁
────                                ────────
无限供电的电击开关                    无限递增的外部计分器
每次踩 = 多巴胺脉冲                   每次排名上升 = 社会确认脉冲
没有停机条件                          没有"够了"的经线
踩到力竭而死                          卷到心梗而死

同一张电路图。同一种死法。
不同的物种。同一个固件版本。
```

**在自然重力场下，野生动物极少把自己撑死。生理内部锚点（胃壁张力、瘦素分泌）和外部环境稀缺性完美咬合。但一旦环境切换到"人工丰裕"或"符号社会"——固件还在跑旧逻辑，环境已经不是旧环境。**

---

## 一、三层级联失效——从固件到仪表盘

撑死表型不是单一故障。是三层控制系统各自出错、彼此加剧的级联失效。

### 层 1：固件层——碳基 ROM 没有停机指令集

```
远古物理世界（Malthusian 稀缺）：
    面前有食物 → 不吃 = 下一顿可能没有 → 不吃是坏策略
    面前有食物 → 狂吃 → 超额储备 → 活过冰期 → 活到下一代
    while(resource_available) { grab(); } = 最优生存算法

现代符号社会（人工丰裕）：
    面前有无限食物/金钱/符号确认 →
    while(true) { grab(); } 从最优策略变成自毁程序
    但固件没有 OTA 更新。
    碳基 ROM 是只读的。几亿年没刷过机。
```

这和 `greed-internal-anchor.md` 6.2 节描述的硬件级生存固件是同一条根：`while(true) { grab(); }` 不是一个没写完的临时 Bug，而是经过无数次高压迭代、刻死在固件里的生存优化算法。金鱼会吃到肚子炸掉——不是贪，是硬件层没有装"饱了"的传感器。停机脚本从未被列入进化日志——因为"食物无限"在野外的发生概率趋近于零。

**这一层不是 Bug。是 Feature 在不匹配的环境里变成了 Bug。**

### 层 2：总线层——优先级反转

身体内部总线在后台疯狂报错：

```
岛叶: Warning: 迷走张力崩溃。皮质醇超标。心肌缺血。立刻停。
杏仁核: Critical: 威胁响应持续激活。糖皮质激素受体下调。不可逆损伤风险。
HRV遥测: Alert: 恢复斜率连续趋近于零。缓冲冗余耗尽。
```

但前额叶在做的是：

```
前额叶: grep -v "Warning" | grep -v "Critical" | grep -v "Alert" | grep "排名+1"
```

不是传感器坏了。是传感器被外部仪表盘的信号权重碾压了。在操作系统的术语里，这是**优先级反转（Priority Inversion）**：高优先级的中断信号（身体告警 = 物理级紧急）被低优先级的轮询任务（看分数 = 应用层循环）无限期阻塞。中断控制器没有被屏蔽——中断被收到了，但它被一个优先级比自己低的任务持续占着 CPU。内核以为自己还在跑。实际上跑的全是排名+1。

### 层 3：仪表盘层——外部计分器接管自我参照

财富榜。排名。市值。点赞数。这些都是"标"——`brand-as-common-knowledge.md` 定义的公共共识的量化版本。但这里发生的事情比单纯的消费主义更深：

```
普通消费者：
    买限量款鞋 → 通过标确认"我是谁"
    标是一个答案

撑死型追逐者：
    计分器 = 整个自我参照的电源
    计分器停 → "我是谁"断电
    不是不知道累——是停了之后不知道方向盘往哪打
```

**计分器本身只是一个数字。但 PBM 还没收敛的人，把自我锚定点焊接在了这根线上。** 这和 `mate-poaching-pbm.md` 描述的"被选中的标"是同构的——不是追分数，是追"被排行榜确认为有价值的人"这个公共共识。

油表被接在了外部计分器上。只要计分器还在跳，这台车就会一直轰油门。发动机冒烟？显示屏没报。冷却液沸腾？显示屏没报。硬件炸毁的那一刻——显示屏上的数字还在涨。

## 二、恶化时间线——从传感器在线到传感器断线

`greed-internal-anchor.md` 6.4 节和 `poverty-nurture-growth.md` 描述了一个更深的阶段：长期穷养会**物理破坏岛叶网格和 HRV 遥测总线**——传感器本身就断线了。

"被 grep -v 过滤"和"传感器断线"不是矛盾的——是**同一条恶化曲线上的两个时间点**：

```
T1: 传感器在线，被前额叶 grep -v 过滤
    │
    │   身体在喊痛。岛叶_后部的内感受信号完整。HRV 遥测完整。
    │   但前额叶把身体告警的权重降到了零。
    │   不是听不到——是不听。
    │
    │   表现：
    │   - 失眠但忽略——"咖啡因能撑过去"
    │   - 心悸但忽略——"体检报告还没出，等于没病"
    │   - 情绪麻木但忽略——"等忙完这个项目再感受"
    │
    │   修复成本：中等。拔掉外部计分器，重新听身体。
    │   岛叶还在。前额叶的过滤策略可以切换。
    │
    ▼
T2: 传感器断线，岛叶网格因长期闲置而受体密度下降
    │
    │   身体不喊痛了。催产素受体密度偏低。
    │   应激基因的启动子长期开放——染色质半开态。
    │   安全通路的正反馈环萎缩。
    │   不是不听——是听不见了。
    │
    │   表现：
    │   - "我不知道我累了"——岛叶内感受压缩器输出趋近于噪声
    │   - "我不知道我需要什么"——PBM 的内部锚点查询返回空
    │   - "我只能继续跑下去"——外部计分器是唯一还在运转的仪表盘
    │
    │   修复成本：高。不是顿悟可以解决。
    │   需要长周期富养——重启安全通路的基因表达，
    │   重建岛叶网格的受体密度，重新学会感受"够了"。
    │   对应 high-dimensional-gestation.md 的脏页冲刷阶段。
    │
    ▼
T3: 硬件炸毁
    │
    │   心梗。脑溢血。免疫崩溃。
    │   不是被什么杀死——是被一个已经烧红到 150°C、
    │   油表却显示"一切正常"的自我参照系统开到了尽头。
    │
    ▼
```

**T1 可以修复：拔掉外部计分器，重新听身体。T2 需要重建：先修复传感器，再教他听。** 而大多数"撑死"的人，死在 T1 以为自己是 T2——觉得自己是听不见，其实是不听。

## 三、和 greed-internal-anchor.md 的精确咬合

```
先天本能型贪（固件层）：
    蛇的捕食本能。在野外的"够"是自己的捕食身体反馈。
    → 对应层1：碳基 ROM 的 while(true) { grab(); }
    在稀缺环境里是最优策略。在丰裕环境里变成自毁。

后天锚点型贪（仪表盘层）：
    蛇在笼子里被喂饱后还在吞——因为笼子没有给过它"饱"的信号。
    → 对应层3：外部计分器接管自我参照。
    计分器不停 = "饱"的信号不存在。

内外锚点摇摆（总线层）：
    深夜自省 → 接近内部锚点 → 传感器重新上线。
    第二天看到排名 → 回到外部锚点 → grep -v 重新启用。
    → 对应层2：前额叶的过滤策略按上下文动态切换。
```

*控制回路失效不是电路板上的一根线断了。是三层各自出错——固件在旧环境里写了死循环，总线被低优先级任务占着 CPU，仪表盘被接在了一个永远不会喊停的外部计分器上。修复不能只修一层。拔计分器是第一步。重新听身体是第二步。如果身体已经不会喊了——重建传感器。而重建不是在书房里想明白就行——它需要睡眠，需要时间，需要那个在慢波 Delta 波谷里发生的、无法被加速的甲基化重写。把人从计分器上拔下来，只是开始。*
