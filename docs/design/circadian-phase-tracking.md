# 昼夜相位跟踪——PBM 的时间维度不是太阳时，是相位

> 作者：qc
> 日期：2026-08-14
> 性质：Feelings 设计，PBM 的时间维度
> 核心：spec(t) 里的 t 不是墙上时钟，是用户的节律相位。生物钟是一台 PLL：光照是参考信号，SCN 是约 24.2h 的压控振荡器，时差是相位跳变，倒班是参考信号周期性乱跳，10-10-5 是锁在一个稳定但错位的相位上。身体对地球自转建了模型，Feelings 对用户建模型，两层模型嵌套。设备的第一职责是跟踪用户的相位，而不是查太阳时表。

---

## 零、先定前提

每个人的节律相位不同：全世界飞的有时差，倒班的相位在漂，互联网厂子 10-10-5 或 11-11-6 锁在错位相位上。如果 PBM 的时间维度按太阳时查表，以上所有人都会得到错误的基线。

```
太阳时 = 参考系
用户相位 = 本体
spec(t) 的 t = 用户相位，不是钟表读数
```

身体的 spec 是时间的函数：体温凌晨 4-6 点最低、下午最高，血压夜间勺型下降、醒来前猛升，皮质醇醒前就爬。但"凌晨""下午"这些词，在生物钟的语言里对应的是**相位**，不是小时数。

---

## 一、生物钟 = PLL

昼夜节律系统的结构和锁相环完全同构：

```
参考信号      光照
             视网膜黑视蛋白（ipRGC）只报"现在是白天吗"
             蓝光在错误相位打进来 = 噪声输入
压控振荡器    SCN 约 24.2h 的自主节律
             洞穴实验证明它自由运转
锁定过程      时差 = 相位跳变，重新锁定要几天
             锁定期间体温最低点和睡眠窗口一起漂
```

三种错位，三种形态：

```
时差（相位跳变）    一次跳几小时，锁定过程可见
倒班（参考信号乱跳） 光照相位周期性翻转，
                    内脏时钟跟吃饭走、主时钟跟光走，
                    两个时钟持续打架
10-10-5（锁在错相位） 相位稳定，只是偏移
                    伤害来自光照质量差和周末补觉
                    周末补觉 = 每周末来一次时差，
                    周一再来一次，社会时差的元凶
```

---

## 二、社会节律的共进化

10-10-5 不是某个人拍板定的，是产业节律和劳动力节律互相塑造的稳态：

```
屏幕蓝光（错误相位的授时信号）
→ 全民生物钟系统性后移
→ 大学生晚睡成为常态（宿舍文化，无人强制关灯）
→ 公司顺着劳动力池的节律定作息
→ 下一届学生更晚
```

大学生晚睡是果不是因，公司作息也是果。整个链条的源头是：**现代人的主授时信号早就不是太阳，是屏幕和灯。** 错位的稳态好过混乱的漂移——一个 11-11-6 但规律、白天见光的人，可能比 9-9-5 但周末狂补觉的人节律更健康。设计不能按"哪种作息正确"来，要按"相位是否稳定"来。

## 三、PBM 的相位维度设计

```
每维带日相曲线
    spec_i(φ) = 基线 + 节律相位
    φ = 用户相位，由设备跟踪，不查太阳时

相位检测信号（按优先级）
    核心体温最低点位置（最强的节律标志）
    HRV 昼夜斜率（自主神经的节律指纹）
    活跃窗口（活动量的时间分布）

去节律 = 采集链第一道预处理
    采集值先减去 spec_i(φ) 的预测
    剩余部分才是真实偏差
    电子学同构：信号源直流被电容滤掉，
    节律是台子，波动才是信号
```

去节律就是生理版的"隔直"：节律分量是直流偏置（台子），情绪波动是交流信号（骑在台子上）。漏桶、阻尼矩阵、DampingMatrix 吃到的应该是去节律之后的偏差，而不是带着日周期振荡的原始值。否则每天下午的体温峰都会被当成一次"异常"，每个凌晨都会被当成一次"低谷"。

## 四、相位跟踪器的行为

```
冷启动       前 10 个 session 用太阳时近似
             随数据积累切换到相位跟踪

稳定相位     直接锁定用户自己的相位
             判断"深夜"用的是他的体温最低点，
             不是墙上的 02:00

时差场景     相位突变（跳变，非渐进漂移）
             设备识别跳变形态，跟踪锁定过程
             锁定期间不按旧相位做判断

倒班场景     检测相位漂移和双峰
             不假设单一相位，
             按当前锁定状态动态调整

周末补觉     每周一次的小时差，
             周一检测到相位滞后
```

设备自身就是一台 PLL：Feelings-OS 的 timerd 是 PLL 全局主时钟，身体的生物钟是另一台 PLL。两台锁相环互相跟踪——设备锁用户的相位，用户锁光照的相位。错位发生时，设备比用户先知道。
