# 耳部设备形态：一副能感知、能刺激的 IEM

> 作者：qc
> 日期：2026-09-11
> 核心：**形态跟着靶点走**；耳塞/IEM 天然解决"耳甲贴合 + 密封 + 音频"三个问题
> 关联：`architecture/ear-as-anchor.md`、`architecture/nerve-endings-and-device-placement.md`

---

## 一、形态由靶点决定

tVNS 刺激的是**迷走神经耳支（ABVN）**，但它在耳朵上分布不止一处，于是设备形态分叉：

```
耳屏(tragus)            耳甲艇(cymba conchae)       耳甲腔(cavum)
  前突的小瓣              耳甲里的凹腔             更深的腔
    │                        │
 夹子就够               要"塞进去"才够得着
 Nurosym / 多数消费级     NEMOS(临床钛电极) / 耳塞类
```

- **耳屏靶点 → 夹子**：好夹、方便、消费级主流（Nurosym 就是耳屏夹）
- **耳甲艇靶点 → 塞进耳甲的东西**：耳甲艇常被认为是**ABVN 分布最密**处，但要"进耳"才够得着

**Feelings 选耳甲艇**——因为最终形态要做成**耳塞（音频 + 感知 + 刺激一体）**，耳塞天然贴耳甲，而够不到耳屏。

---

## 二、电极贴合的真实问题（实测）

手上那片**导电橡胶耳电极**（磨砂、一整片）戴上后：

```
对耳轮（凸的脊）  → 紧紧贴着   ✅
耳甲（凹的腔）    → 贴不紧     ❌
```

看似小事，其实致命：

```
对耳轮紧贴、耳甲虚接
  → 电流从「低阻的对耳轮」抄近路走
  → 靶点（耳甲艇）几乎没刺激到
  → 要加大电流也未必打到靶点，还先在对耳轮上刺得痛
```

**根因**：靶点在**凹腔**里，**平/硬的片状电极够不着**。

---

## 三、刺激的电极法则

```
作用电极(active)：小、集中在靶点   → 高电流密度 → 精准
回流电极(return)：大、分散         → 低电流密度 → 不痛
```

两个要点：

1. **决定刺激的是电流密度（mA/cm²），不是总电流**。大电极把电流摊开 → 靶点只分到一小部分。
2. **面积越小，电流上限越低**（否则局部密度过大 → 灼伤）。所以"小作用电极"的电流要按面积缩小——这和电流三层上限（编码 2.55 / 硬熔断 1.8 / 治疗 1.5mA）里的**个体化**是一回事。

---

## 四、IEM：天然答案

**IEM（In-Ear Monitor，入耳式监听耳机）**——乐手用的深插入耳耳机——恰好满足耳部设备的所有硬需求：

```
✅ 塞进耳甲/耳道  → 天然接触耳甲（靶点）     ← 解决"贴不紧"
✅ 硅胶/定制壳    → 密封（挡环境光 + 隔音）
✅ 自带扬声器     → 音频执行器（声音）
✅ 成熟形态       → 舒服、稳固、能久戴
```

**公模 vs 定制**：

| 用途 | 公模（通用版型） | 定制（CIEM，耳印翻模） |
|---|---|---|
| 音频 | ✅ 够用（关键在耳道密封） | ✅ 更贴 |
| PPG 光学 | 🟡 通常够（看 `r`） | ✅ 精准对位 |
| tVNS 电极 | 🟡 要试（未必压到耳甲艇） | ✅ 靶点可靠接触 |

公模**够用**（尤其音频）——起步就该用它；够不够打靶点，靠**刺激后 HRV 反应**说话。

---

## 五、一体化的耳塞

最终形态 ≈ **一副定制 IEM + 加装**：

```
定制 IEM 壳
  ├── 接触耳甲的那一面  → 导电面（tVNS，靶点 = 耳甲艇）
  ├── 声道里            → 动铁/动圈单元（音频）
  ├── 接触耳甲/耳道的面  → 红光/绿光 LED + PD（PPG）
  └── （未来）耳道电极   → 耳-EEG
```

一体解决：**刺激 + 音频 + 感知**，还天然贴合。耳印本身就能拿来**精确设计电极位置和光学窗口位置**。

---

## 六、光路必须密封（今天的关键发现）

**实测教训**：iCESugar 板载 LED 的光漏进 MAX30102 窗口 → 自相关 r 掉到 0.03、HR 乱跳；
**把板子翻面遮光 → r 回到 0.9，HR 对上手表**。

```
直射光（板载 LED / 环境灯）→ 强、可能闪 → 大干扰   ← 必须遮死
透射光（太阳穿过耳朵）      → 弱、稳定     → 主要是 DC/慢变 → 能滤
```

- **耳朵薄、半透光**：太阳从另一侧也能穿到 PD，但穿进来的主要是**直流 + 慢变** → 环境光消除 + 去 DC/高通就能处理
- 真正要防的是**直射光**和**光的快速变化**（树影闪动 → 当运动伪迹）

**设计硬要求**：光学窗口周围必须有不透光、贴皮肤的**遮光罩**——耳道是天然暗腔，耳塞形态天然满足。

---

## 七、原型路径

```
1. 公模 IEM 起步（便宜、快、能换套调尺寸）
2. 壳上贴导电面（耳甲那侧）+ 光学窗
3. 实测三个指标：
     电极阻抗 / PPG 的 r / 刺激后 HRV 反应
4. 够用 → 定型公模；不够 → 上定制（耳印翻模）
```

**Feelings 是个人设备**，公模迭代完全合理——**先跑通、再精修**，别一上来就定制（贵、慢，靶点和参数还没定）。

---

## 八、结论

1. **形态跟着靶点走**：耳屏→夹子；耳甲艇→耳塞/IEM
2. **Feelings 选耳甲艇**，因为要做**耳塞 + 音频 + 感知一体**
3. **IEM 天然解决**"耳甲贴合 + 密封 + 音频"——耳部设备本质就是**一副能感知、能刺激的定制 IEM**
4. **电极法则**：小作用电极（耳甲艇）+ 大回流电极（耳垂/耳后）
5. **光路必须密封**：直射光遮死；透射/慢变交给算法
6. **先公模、数据定型、再定制**

---

*一副好的耳塞，本来就该贴合耳甲、密封、出声。Feelings 要做的，只是让它在贴合的那一面上——既能感觉，也能说话。*
