# 耳部设备形态：一副能感知、能刺激的 IEM

> 作者：qc
> 日期：2026-09-11
> 核心：**形态跟着靶点走**；耳塞/IEM 天然解决"耳甲贴合 + 密封 + 音频"三个问题
> 关联：`architecture/ear-as-anchor.md`、`architecture/nerve-endings-and-device-placement.md`

---

## 一、形态由靶点决定

tVNS 刺激的是**迷走神经耳支（ABVN）**。耳朵上可及的位置有三处，形态跟着它们分叉：

```
耳屏(tragus)        耳甲腔(cavum conchae)         耳甲艇(cymba conchae)
  前突的小瓣          耳甲下半、通耳道口            耳甲上半、在"耳轮脚"之上
    │                    │                            │
 夹子就够            耳塞天然坐在这里              耳塞常擦到，但压不实/无绝缘
 Nurosym             公模 / 定制 IEM                NEMOS（专门压上去的钛电极）
```

> 耳甲（concha）被「**耳轮脚（crus of helix）**」这条脊分成上下两块：
> **耳甲艇（cymba）在上**，**耳甲腔（cavum）在下**。耳塞坐进耳里，落的是**耳甲腔**。

- **耳屏 → 夹子**：好夹、方便、消费级主流（Nurosym）
- **耳甲腔 → 耳塞/IEM**：耳塞天然坐在里面
- **耳甲艇 → 专门电极**：耳塞上缘**常能擦到**，但**轻擦 + 无绝缘 → 电流从旁边压实处流走**，电学上打不中；要用**小电极 + 压实 + 绝缘**（NEMOS 做法）

**Feelings 的形态是耳塞**——因为要**音频 + 感知 + 刺激一体**，而耳塞天然落在**耳甲腔**（但耳甲腔中心可能非迷走，见第九节）。
**耳甲艇**虽常被认为 ABVN 最密、耳塞上缘也**常能擦到**，但"擦到"≠"刺激到"——**压不实 + 没绝缘，电流会从旁边的耳大神经地盘抄近路**。所以耳甲艇要么交给**定制壳压实的专用电极**，要么把靶点放**耳道后下壁 / 耳甲边缘**（见第九节）。

## 二、电极贴合的真实问题（实测）

手上那片**导电橡胶耳电极**（磨砂、一整片）戴上后：

```
对耳轮（凸的脊）  → 紧紧贴着   ✅
耳甲腔（凹的腔）  → 贴不紧     ❌
```

看似小事，其实致命：

```
对耳轮紧贴、耳甲虚接
  → 电流从「低阻的对耳轮」抄近路走
  → 靶点（耳甲腔）几乎没刺激到
  → 要加大电流也未必打到靶点，还先在对耳轮上刺得痛
```

**根因**：靶点在**凹腔**里，**平/硬的片状电极够不着**。

---

## 三、刺激的电极法则

```
作用电极(active)：小、集中在靶点   → 高电流密度 → 精准
回流电极(return)：大、分散         → 低电流密度 → 不痛
```

两个要点：

1. **决定刺激的是电流密度（mA/cm²），不是总电流**。大电极把电流摊开 → 靶点只分到一小部分。
2. **面积越小，电流上限越低**（否则局部密度过大 → 灼伤）。所以"小作用电极"的电流要按面积缩小——这和电流三层上限（编码 2.55 / 硬熔断 1.8 / 治疗 1.5mA）里的**个体化**是一回事。

## 四、IEM：天然答案

**IEM（In-Ear Monitor，入耳式监听耳机）**——乐手用的深插入耳耳机——恰好满足耳部设备的所有硬需求：

```
✅ 塞进耳甲/耳道  → 天然接触耳甲腔（靶点）     ← 解决"贴不紧"
✅ 硅胶/定制壳    → 密封（挡环境光 + 隔音）
✅ 自带扬声器     → 音频执行器（声音）
✅ 成熟形态       → 舒服、稳固、能久戴
```

**公模 vs 定制**：

| 用途 | 公模（通用版型） | 定制（CIEM，耳印翻模） |
|---|---|---|
| 音频 | ✅ 够用（关键在耳道密封） | ✅ 更贴 |
| PPG 光学 | 🟡 通常够（看 `r`） | ✅ 精准对位 |
| tVNS 电极 | 🟡 要试（未必压到耳甲腔） | ✅ 靶点可靠接触 |

公模**够用**（尤其音频）——起步就该用它；够不够打靶点，靠**刺激后 HRV 反应**说话。

## 五、一体化的耳塞

最终形态 ≈ **一副定制 IEM + 加装**：

```
定制 IEM 壳
  ├── 接触耳甲的那一面  → 导电面（tVNS，靶点 = 耳甲腔）
  ├── 声道里            → 动铁/动圈单元（音频）
  ├── 接触耳甲/耳道的面  → 红光/绿光 LED + PD（PPG）
  └── （未来）耳道电极   → 耳-EEG
```

一体解决：**刺激 + 音频 + 感知**，还天然贴合。耳印本身就能拿来**精确设计电极位置和光学窗口位置**。

---

## 六、光路必须密封（今天的关键发现）

**实测教训**：iCESugar 板载 LED 的光漏进 MAX30102 窗口 → 自相关 r 掉到 0.03、HR 乱跳；
**把板子翻面遮光 → r 回到 0.9，HR 对上手表**。

```
直射光（板载 LED / 环境灯）→ 强、可能闪 → 大干扰   ← 必须遮死
透射光（太阳穿过耳朵）      → 弱、稳定     → 主要是 DC/慢变 → 能滤
```

- **耳朵薄、半透光**：太阳从另一侧也能穿到 PD，但穿进来的主要是**直流 + 慢变** → 环境光消除 + 去 DC/高通就能处理
- 真正要防的是**直射光**和**光的快速变化**（树影闪动 → 当运动伪迹）

**设计硬要求**：光学窗口周围必须有不透光、贴皮肤的**遮光罩**——耳道是天然暗腔，耳塞形态天然满足。

## 七、原型路径

```
1. 公模 IEM 起步（便宜、快、能换套调尺寸）
2. 壳上贴导电面（耳甲那侧）+ 光学窗
3. 实测三个指标：
     电极阻抗 / PPG 的 r / 刺激后 HRV 反应
4. 够用 → 定型公模；不够 → 上定制（耳印翻模）
```

**Feelings 是个人设备**，公模迭代完全合理——**先跑通、再精修**，别一上来就定制（贵、慢，靶点和参数还没定）。

---

## 八、普适解剖 + 通用形态 + 个体剂量

**耳甲腔是"人类标配"**：

```
你是个耳朵   → 就有耳甲腔（人人都有，只是形状/大小不同）
你能戴上耳机 → 耳机就落在耳甲腔里 → 就接触到「迷走耳支的分布区」
               （但"分布区" ≠ "有效靶点" —— 见第九节）
```

所以**接触是普适的**——不需要为每个人定制才能"碰到"迷走。这是耳塞形态比定制电极更重要的优势：**任何人都能用**。

但"接触"要变成"有效刺激"，有两个个体差异：

1. **可靠电接触因人而异**：形状/大小不同 → 接触阻抗不同 → 需要的电流不同（是**剂量**问题，不是"能不能"问题）
2. **靶点位置/密度因人而异**：纤维束在哪、多密，每个人不一样 → 同一耳塞的效应强弱不同

**所以解法不是"为每人定制硬件"，而是**：

```
通用硬件（耳塞 + 导电面）  +  个体化剂量（按你的基线校准）
```

这与 Feelings 的核心是同一件事——**个体基线、电流三层上限里的个体化、闭环按基线触发**：

> **硬件通用、软件个体化。** 这才是能规模化的路。

---

## 九、"地盘"可能不是迷走的：靶点必须用数据找

第八节说"接触普适"——但**接触 ≠ 有效刺激**；而且更麻烦的是：**连这块地都可能不属于迷走。**

**① 接触 ≠ 有效（三个变量）**

```
1. 皮下深度   脂肪/结缔组织厚的人，神经埋得深 → 同样电流，有人有感有人无感
2. 热点位置   神经是几条密度高的「热点」，不是均匀铺满地；公模随便贴 → 大概率贴到"荒地"
3. 界面阻抗   蹭着 / 有油 / 压力不足 → 角质层阻抗爆炸 → 电流全耗在表皮，穿不到皮下
```

**② 那"热点"在哪？——不在耳甲腔**

经典解剖（Peuker & Filler 2002 等）：

```
迷走耳支(ABVN / Arnold 神经) 主要分布：
   耳甲艇(cymba)   ✅ 最密
   耳屏(tragus)    ✅
   耳轮根          ✅
   耳道后下壁      ✅（Arnold 反射：掏耳朵引发咳嗽）
   耳甲腔(cavum)   ❌ 主要归「耳大神经」(颈丛 C2-C3)，不是迷走
```

旁证最硬：**NEMOS 打耳甲艇、Nurosym 打耳屏——没有一家打耳甲腔**（那儿不是迷走）。

所以**耳塞天然落在耳甲腔，可能正好踩在迷走的边缘/隔壁**。

**③ 好在耳塞还有一条路——耳道**

入耳段能碰到**耳道后下壁的 ABVN**（Arnold 反射的解剖基础）。

**→ 耳塞形态的靶点候选（待数据确认）**：

```
✅ 耳道后下壁（ABVN）              ← 耳塞入耳段天然接触
🟡 耳甲腔靠上、靠近耳轮脚 / 耳甲艇下缘的边缘
❌ 耳甲腔中心（可能是耳大神经，非迷走）
```

> **形态通用（谁都能戴）；但靶点必须用数据找，不能靠"踩在地盘上"想当然——甚至那块地可能都不是迷走的。**

**④ 耳甲艇"小、高、变异大"——但真正的问题不是"够不到"，是"擦到 ≠ 刺激到"**

看 BERHORAL 那类挂耳/开放式耳机、再对照自己的耳朵，会发现两件事：

**(a) 耳甲艇是个很小的口袋，位置还偏高**（耳轮脚之上、对耳轮下脚之下），而且**个体差异极大**（有人几乎只是一个小凹）。

```
耳甲艇：面积小（耳甲腔的零头） + 位置高（贴着耳轮脚上缘） + 因人而异
                │
      ┌─────────┼─────────┐
      ▼         ▼         ▼
  耳机单元为放音设计      靶点这么小          ABVN 却几乎人人都有
  → 落面积最大的          → 通用接触 ±几mm      （小而稳）
    耳甲腔（耳大神经）       就滑出迷走区
  → 形态与靶点天生错位     → non-responder 的解剖学解释
```

**(b) 但 IEM / 挂耳 / 开放式的壳上缘，其实常能"擦到"耳甲艇**——只是**轻擦，不压实**。这里必须把三个层次分开：

```
① 几何接触：壳够大够高 → 上缘常擦到耳甲艇     ✅ 常见
② 力学压力：轻擦 ≠ 压住 → 压力低、贴合面积小
③ 电学效果：电流只走「阻抗最低」路径 → 不走轻擦那点
```

**为什么"轻擦"在电学上 ≈ 没打中**：

- 电极-皮肤界面阻抗**随接触压力/贴合面积下降**：压得越实 → 阻抗越低。
- 耳机壳上**硬脊处（对耳轮/耳轮/耳甲腔凸面）压得实 → 低阻**；耳甲艇只轻擦 → **高阻**。
- 电流按阻抗分流：**绝大部分从压实的低阻点抄近路走**，轻擦处只分到极小一部分。
- 更隐蔽：只要**壳上其他地方没绝缘、还压得实**，它们就是**并联分流路径** → 电流被摊走。
- 结果：**你以为打在耳甲艇，电流其实从旁边的耳大神经地盘流光了。**

**关键反转**：不是"迷走铺满耳朵、耳机刚好打中"，而是——

```
耳甲腔：大  → 耳大神经（非迷走）        ← 耳机单元落这里
耳甲艇：小  → ABVN 最稳定落点（人人有）  ← 刺激要这里
```

**"小"≠"不重要"**：耳甲艇小、却是 ABVN **最可靠**的落点；耳甲腔大、却基本不归迷走。**迷走躲在小口袋里，通用耳机"碰到"也不算打中它。**

**判据不是"够不够得到"，而是**：

```
① 作用电极要「小」且「压实在靶点」    → 电流密度集中
② 靶点以外全部「绝缘」               → 堵死分流路径
③ 回流电极大、在远处（耳垂/耳后）     → 不痛
```

这正是 NEMOS / Nurosym：**只在靶点露铜，其余全绝缘 + 稳定压力**。普通耳机**无绝缘、压力随机** → 即使碰到耳甲艇，电学上也不成立。

**→ 由此打开一条路：定制 IEM 壳压耳甲艇**

既然 IEM 壳上缘本来就能升到耳甲艇，"**定制 IEM 壳 + 上表面按耳印塑形成正好压实耳甲艇的作用电极、其余绝缘**"就**可行**——等于把 NEMOS 的精准电极**做进一副耳塞**，一并解决**音频 + PPG + 耳甲艇 tVNS**。难点从"够不到"变成"**怎么稳定压实 + 绝缘**"（可解的工程问题）；代价是大概要**定制壳**。

**→ 更省事的路：现成的骨传导模当电极载体（2026-09-12 补）**

不必从头做定制壳——**骨传导耳机（bone-conduction earpiece）本来就压在耳甲/耳甲艇区域**，把它当"电极壳"就现成解决"稳定压实耳甲艇"：

```
骨传导耳机（Shokz 类）压耳甲/耳甲艇
  → 贴合耳甲艇那一面做成导电面（作用电极）
  → 其余表面绝缘（防分流，见第三节）
  → 耳垂/耳后放回流电极
= 一个现成、舒适、压得实的「耳甲艇电极载体」
```

**旁证**：一份 taVNS 临床试验方案正是这么做的——**标准耳甲艇位置 + 骨传导模塞入**，电极压耳甲艇，刺激 60min，EEG 地形图有明显变化。说明这条路**别人验证过、可行**。

意义：形态从"**定制 IEM 壳塑形**"降级为"**现成骨传导模 + 导电面**"——**能直接试**，不用先翻耳印、开模；等验证有效、要量产时再谈定制。

**另一种实现：耳塞 + 小把柄 + 环电极**

耳甲艇小 → 电极也小。"耳塞上带个小把柄（伸进耳甲艇）、把柄/周围一圈做电极"是同一条路的另一种形态。

**小电极 → 电流上限低**（密度约束，见第三节电极法则）：耳甲艇电极天然用低电流，**1.5mA 上限是合理的**（详见 `mvp-vagus-loop` 的 S3 刺激参数基线）。别照搬大电极研究的 50mA。

**三个 ABVN 靶点的取舍**：

| 靶点 | ABVN | 可及性 | 代表 |
|---|---|---|---|
| 耳甲艇 cymba | ✅ 最稳/最密 | 🟡 要压实 + 绝缘；**骨传导模 / 定制壳可行** | NEMOS / 骨传导模 |
| 耳屏 tragus | ✅ | ✅ 凸出、好夹、压力稳定 | Nurosym |
| 耳道后下壁 | ✅ | 🟡 需密封、入耳 | （耳塞入耳段） |

**结论**：Feelings 的设备**不是"带刺激功能的耳机"，而是"贴在耳朵上的精准刺激器（可能顺带放音频）"**。靶点小、高、因人而异 → "**找到你的点**"是物理必需，不是营销话术——这正是"通用形态 + 个体剂量"的解剖学依据。

> 实证：拿 BERHORAL 那类挂耳/开放式对照——发声单元落在**耳甲腔（大、非迷走）**，细弧搭在**对耳轮**上；耳甲艇大概率只是被上缘**轻擦**，没压实、也没绝缘 → **电学上打不中**。这不是设计失误，是"耳机为音频而生、不负责刺激"的必然。

## 十、结论

1. **形态跟着靶点走**：耳屏→夹子（Nurosym）；耳甲艇→要压实+绝缘的专用电极（NEMOS/定制 IEM）；耳道/耳甲边缘→耳塞
2. **Feelings 用耳塞形态**（音频 + 感知 + 刺激一体），但**靶点待数据确认**——候选是**耳道后下壁 / 耳甲边缘**，**未必是耳甲腔中心**
3. **IEM 天然解决**"贴合 + 密封 + 音频"——耳部设备本质就是**一副能感知、能刺激的耳塞**
4. **电极法则**：小作用电极（打在靶点）+ 大回流电极（耳垂/耳后）
5. **接触 ≠ 有效**：靶点小/高/变异大（第九节④）、皮下深度、界面阻抗——全要用数据说话；"找到你的点"是物理必需
6. **擦到 ≠ 刺激到**：几何接触 / 压力 / 电流是三层；靶点要"**小电极 + 压实 + 绝缘**"（第九节④）
7. **先公模/骨传导模、数据定型、再定制**（想一体打耳甲艇 → 骨传导模或定制壳压耳甲艇）

---

*一副好的耳塞，本来就该贴合、密封、出声。Feelings 要做的，是让它在贴合的那一面上——**先找对地方**，再既能感觉，也能说话。*
