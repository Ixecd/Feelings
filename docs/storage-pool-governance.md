# 存储池治理：资金安全与银行托管

> 作者：qc
> 日期：2026-04-20
> 核心：存储池的钱是用户和员工信任的物质基础，分散托管，链上透明，多签授权

---

## 一、存储池是什么

```
Feelings 的收入来源
    硬件销售
    平台运营费
    感受包创作者分成（平台运营费部分）
    存储服务利息收益

所有收入进入存储池
    存储池是 Feelings 运营的资金中枢
    进出全部链上记录，透明可查

存储池的支出
    工资（日结/月结，链上到账）
    硬件采购和供应链付款
    平台运营成本
    创作者分成结算
    基础设施维护
```

**存储池不是老板的钱，是 Feelings 这个体系的公共资金。**

---

## 二、为什么分散到多家银行

```
单一银行的风险
    账户被冻结（法律纠纷/监管问题）
    银行系统故障（概率低但存在）
    单点操作失误
    任何一个风险都可能中断工资发放和运营

分散托管的目标
    没有任何一家银行的问题能让 Feelings 停摆
    工资发放不因单一银行故障而中断
    保持运营的连续性
```

## 三、五家银行的定位与分笔

### 整体分配

```
工商银行    25%    战略储备
建设银行    25%    运营资金
中国银行    20%    外汇储备
农业银行    15%    区域运营
招商银行    15%    流动资金

合计        100%
```

### 各行职能说明

**工商银行（25%）— 战略储备**

```
定位    国有四大行之首，资产规模最大，国家信用最强
用途    长期持有，不轻易动
        极端情况下的备用资金
        重大资本支出（建设工厂/大额设备采购）

触发动用的条件
    重大资本支出超过一定金额
    需要三人及以上授权
    链上记录动用理由

特点    最静，动得最少，是 Feelings 的压仓石
```

**建设银行（25%）— 运营资金**

```
定位    国有四大行，对公业务成熟，基础设施经验丰富
用途    硬件采购付款
        供应链结算
        中期运营周转（季度级别）
        工厂相关支出

特点    稳定的日常运营出口，和供应链深度绑定
```

**中国银行（20%）— 外汇储备**

```
定位    国有四大行，外汇业务最强
用途    国际化后的跨境结算
        外币收入的管理
        海外供应商付款（进口传感器/芯片等）
        未来海外市场的资金储备

现阶段    暂时以人民币存放
          待 Feelings 国际化后逐步转换用途

特点    面向未来的储备，现在不动，以后很重要
```

**农业银行（15%）— 区域运营**

```
定位    国有四大行，覆盖最广，下沉市场经验最丰富
用途    工厂所在地的本地结算
        区域供应商付款
        未来在非一线城市建工厂时的本地账户
        员工在当地的工资发放

特点    覆盖广度，未来工厂下沉到二三线城市时发挥作用
```

**招商银行（15%）— 流动资金**

```
定位    股份制商业银行，API 最成熟，对公服务最灵活
用途    工资日结和月结的主出口
        链上结算的法币出入口
        高频小额流水
        开发者/贡献者的链上分成结算

特点    最活，流转最快，是 Feelings 链上结算的接口层
        招行的 API 成熟度和灵活性是选它的核心理由
        牺牲一部分"国有信用"换来操作灵活性
        但金额只占 15%，风险可控
```

## 四、资金流动逻辑

```
收入进入
    硬件销售收入 → 建设银行（运营账户）
    平台运营费  → 建设银行（运营账户）
    创作者分成  → 招商银行（流动账户，快速结算）
    利息收益    → 工商银行（沉淀增值）

定期调拨
    每季度根据各账户余额和支出预测
    在五家银行之间进行再平衡
    保持目标比例（允许 ±5% 的偏差）
    调拨需要多签授权（见第五节）

支出出口
    工资日结/月结 → 招商银行
    硬件采购      → 建设银行
    外汇支出      → 中国银行
    本地工厂支出  → 农业银行
    重大资本支出  → 工商银行
```

## 五、多签授权规则

**银行放在哪里是"托管"，钱怎么动才是"管理"。**

这一节比分笔比例更重要。

```
小额支出（< 5万元）
    1 人授权即可
    日常运营流水，不需要繁琐流程
    链上自动记录

中额支出（5万 - 50万元）
    2 人授权
    财务负责人 + 项目负责人
    24小时内完成授权

大额支出（50万 - 500万元）
    3 人授权
    财务负责人 + 项目负责人 + qc
    72小时内完成授权

重大支出（> 500万元）
    qc 必须在场签署
    + 另外 2 人授权
    需要书面说明用途
    链上永久记录

跨银行调拨（再平衡操作）
    2 人授权
    必须注明调拨理由
    链上记录
```

## 六、透明度规则

```
对内透明
    所有员工可以查看存储池的总余额和月度收支摘要
    不包含具体的采购合同金额（商业敏感）
    不包含个人薪酬（岗位范围公开，个人不公开）

对外透明
    定期发布存储池透明度报告（季度）
    包含：总收入、总支出分类、各银行余额占比
    不包含：具体合同、个人薪酬、商业敏感信息

链上记录
    每一笔超过一定金额的资金流动
    都在链上有对应记录
    不可篡改，可审计
```

## 七、风险应对

```
某家银行账户被冻结
    其余四家账户正常运转
    工资发放切换到其他账户
    业务不中断

某家银行系统故障
    同上，备用账户接管
    通常 24 小时内恢复

存储池余额下降到警戒线
    触发警报通知核心团队
    暂停非必要支出
    优先保障工资发放
    优先保障安全机制运营

极端情况（Feelings 进入终止流程）
    存储池按 state-machine.md 的终止流程处理
    优先结清所有工资
    优先向用户履行退款承诺
    剩余资金按 GOVERNANCE 规定处置
```
