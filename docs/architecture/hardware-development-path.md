# 硬件开发路径——从 FPGA 开发板到定制 PCB

> 作者：qc
> 日期：2026-06-20
> 核心：Feelings 的硬件不是买现成的传感器组装——是从 FPGA 跑通信号通路，到自画 PCB，到最终定制 ASIC 的完整路径。

---

## 一、总览

```
v0.1–v0.3: FPGA 开发板 + 现成传感器 → 信号通路验证
v0.5–v0.7: 第一版柔性 PCB → 耳后吸附式原型
v1.0–v1.5: 第二版 PCB + 多设设备协同 → 量产前验证
v2.0+:     ASIC 流片 → 消费级产品
```

每一阶段不依赖上一阶段完成全部才启动——信号通路跑通就可以开始画板子，画板子的时候 ASIC 设计同步推进。

---

## 二、FPGA 设备采购

### 2.1 选型

当前首选 Lattice iCE40UP5K / Gowin GW1N 系列：

```
要求:
  功耗       < 100mW (耳后吸附式，紧贴皮肤)
  封装       3×4mm BGA (耳背空间刚好够)
  片上 BRAM   ≥ 64KB (分支预测器 + 帧缓冲区)
  硬 IP       PLL (时钟锁定——timerd 需要)
              DSP (信号滤波——PPG 预处理)
              I2C/SPI (传感器总线)

候选:
  iCE40UP5K     $6   48-pin QFN   5280 LUT   120KB BRAM
  GW1N-4        $5   64-pin QFN   4608 LUT   180KB BRAM
  ECP5-12       $12  256-pin BGA  12K LUT    136KB BRAM (v1.0 升级选项)
```

### 2.2 配套开发板

不买官方的 $200 开发板——买最小系统板 + 自己焊外围：

```
最小系统板:
  iCE40 最小系统板 (淘宝/Seeed)    ~¥40
  GW1N 最小系统板                   ~¥35
  USB Blaster JTAG 下载器          ~¥30

外围传感器 (开发板阶段飞线连接):
  AD5933 阻抗测量模块               ~¥50  (EDA 皮肤电导)
  MAX30102 PPG 心率血氧模块         ~¥15  (耳后 PPG)
  MAX30003 ECG 模拟前端             ~¥80  (心率，v0.5+ 精度)
  DS18B20 体温传感器                ~¥5   (后颈温度)
  ICS-43434 I2S 数字麦克风          ~¥25  (骨传导音频通路)

总预算: ¥300-500 → 第一阶段信号通路验证全部覆盖
```

### 2.3 仪器

这些不是可选的——没有就调不了硬件：

```
必选:
  数字万用表 (Fluke 15B+ 或优利德)       ~¥300
  逻辑分析仪 (Saleae 克隆 / DSLogic)       ~¥100
  示波器 (Siglent SDS1104X-E 或 Rigol)     ~¥2000
    → 必须 100MHz 带宽以上——PPG 信号调理需要看开关噪声

可选 (v0.5+):
  阻抗分析仪 (AD5933 评估板自带)
  频谱分析仪 (RF 干扰排查——蓝牙/WiFi 共存)
```

## 三、PCB 设计

### 3.1 不是"电路和外观"——是四层物理

```
原理图 (Schematic)
  FPGA 引脚分配 → UART/I2C/SPI/PDM 哪个引脚连哪个传感器
  供电设计 → 电池 → LDO → 1.2V (FPGA 核) + 3.3V (IO)
  模拟前端 → AD5933 激励/接收路径 + 抗混叠滤波

布局 (Layout)
  ┌─────────────────────────────────────────────┐
  │ 问题                    │ 做错的结果            │
  ├─────────────────────────────────────────────┤
  │ PPG 模拟走线跨数字区域   │ 心电信号被 FPGA 时钟污染 │
  │ 退耦电容离 LDO > 2mm    │ 电源纹波 = PPG 读数抖动  │
  │ 层叠错误 (信号/地/电源)  │ 整板 EMI 过不了认证     │
  │ 阻抗不匹配 (USB/I2S)    │ 数据丢帧                │
  │ 板子谐振频率 = 1kHz     │ 每帧输出自带振动伪影    │
  └─────────────────────────────────────────────┘

制造 (Fabrication)
  4 层板                   嘉立创 ¥50/5片
  6 层板 (v1.0+)           嘉立创 ¥200/5片
  阻抗控制 (±10%)          需指定层叠结构
  微孔 (0.2/0.4mm)         v1.5+ BGA 必须

外壳 (Enclosure)
  与 PCB 弯折匹配 → 柔性材料 + 波纹密封
  医用硅胶生物相容性 → ISO 10993
  IP68 防水 → 双层密封 + 气压平衡膜
```

### 3.2 工具链

```
EDA:
  KiCad 8.x (开源) → 原理图 + 布局
  嘉立创 EDA     → 在线版，直接对接嘉立创制造

仿真:
  SPICE (LTSpice)     → 电源退耦仿真
  KiCad 自带 SI 工具  → 关键走线阻抗
  FEM (OpenEMS)       → 天线/磁耦合仿真 (v1.0+)

制造接口:
  导出 Gerber + NC Drill → 发给嘉立创
  BOM + CPL → 贴片清单
```

## 四、焊接

### 4.1 开发板阶段 (手焊)

```
工具:
  恒温焊台 (T12 或 936 克隆)     ~¥200
  焊锡 0.3mm 含铅 (SnPb)         ~¥30   (含铅好焊——手工原型)
  助焊剂 (松香/免洗)              ~¥10
  镊子 (Vetus ST-14)              ~¥25
  热风枪 (QFP/BGA 拆焊用)         ~¥150

技能要求:
  0603 电阻电容 → 可以手焊
  QFN 48/64 FPGA → 热风 + 助焊剂
  BGA → 手焊不碰——BGA 上嘉立创 SMT
```

### 4.2 PCB 阶段 (嘉立创 SMT)

```
流程:
  1. KiCad 导出 BOM + CPL (贴片坐标)
  2. 上传嘉立创 → 自动匹配其元件库
  3. 库里没有的 → 下单寄过去 (或用它的替代料)
  4. 回来自己焊接插件 (电池座、传感器排线、JTAG 接口)

嘉立创 SMT 费用:
  工程费 ¥50
  贴片 ¥0.01/点
  5片板子 → 总共 ¥100-200
```

### 4.3 电源的特别注意

```
LDO 焊接后 → 万用表测对地阻抗 → 确保没有短路
→ 通电 → 测 1.2V/3.3V 输出电压
→ 示波器看纹波 → < 10mVpp

这一步不过 → 所有后续调试都是白费
```

## 五、下载电路 (FPGA 位流烧录)

### 5.1 开发阶段 (JTAG / SPI)

```
iCE40:
  IceStorm 开源工具链    完整的 Verilog→位流→下载
  USB Blaster (FT2232)   通过 SPI Flash 间接烧录
  或直接用 FTDI MPSSE 模式直写

Gowin GW1N:
  Gowin IDE (官方)       Windows/Linux
  或 openFPGALoader      开源工具链支持 GW1N
  JTAG 下载              USB Blaster 兼容

烧录流程:
  1. Verilog/VHDL 综合 → LUT/FF/BRAM
  2. 布局布线 → 位流 (.bit)
  3. JTAG → FPGA SRAM (掉电丢失，调试用)
  4. SPI → 外部 Flash (耐久，生产用)
```

### 5.2 生产阶段 (出厂烧录)

```
量产时不做 JTAG:
  1. 嘉立创 SMT 时指定 Flash 预烧录 (额外 ¥30/批)
  2. 或 PCB 板回来后通过测试座 + SPI 批量烧录
  3. 固件签名 → ECDSA → FPGA 启动时验证 → 防篡改
```

## 六、调试与验证

```
上电后的调试顺序:
  1. 电源 → 万用表测电压
  2. 时钟 → 示波器看晶振起振
  3. JTAG 连通 → openFPGALoader 检测到芯片
  4. 点亮 LED → 第一个 Verilog 模块跑通
  5. I2C 扫描 → 确认传感器在总线上
  6. PPG 读数 → 示波器看 ADC 输出波形
  7. AD5933 校准 → 已知电阻测阻抗精度
  8. VNS 刺激 → 示波器看电流波形 + 安全限流测试
```

## 七、与 Feelings 全栈的咬合

```
Stage            Feelings 软件侧         硬件侧
───────────────────────────────────────────────────
v0.1–v0.3       .anim → .esir 编译       开发板飞线——信号通路跑通
v0.5–v0.7       Core 运行时 + PBM        第一版 PCB——耳后吸附式原型
v1.0–v1.5       Anim + Core + 多设备     第二版 PCB——多设备协同
v2.0+           Feelings-OS 硬实时        ASIC 流片——消费级
```

硬件和软件同步迭代。开发板验证一个 Pass，PCB 对应一个阶段。不是先做完软件再做硬件——是每一层都从开发板验证到 PCB 再到定制 ASIC，逐层推进。
