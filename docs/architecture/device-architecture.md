# 设备架构设计：一套设备，协作运行

> 作者：qc
> 日期：2026-04-05
> 核心：Feelings 不是一个设备，是一套设备，缺了少那部分功能，不影响其他

---

## 一、基础假设的改变

原来的假设：

```
耳后 + 后颈 = 一个完整设备
缺了 = 无法使用
```

正确的假设：

```
每个设备负责一个感受维度或信号层
有什么用什么
缺了 = 少那部分功能，其他继续工作
```

这个改变有一个根本性的影响——**渐进式接入**。

用户不需要一次买齐整套。从一个设备开始，体验基础功能。根据自己的需要，逐步扩展。每增加一个设备，系统能力扩展一层。门槛低，天花板高。

## 二、设备分工

每个设备负责特定的神经通路和信号维度：

### 耳部设备（核心设备）

```
位置        耳甲艇/耳屏区域（入耳或半入耳接触）
神经通路    迷走神经耳支（Arnold 神经）
解剖校正    耳后乳突区由耳大神经（C2-C3脊神经）支配，非迷走神经。
            Arnold神经分布于外耳道、耳甲艇、耳屏——电极须接触这些位置，
            非耳后皮肤。此前文档中"耳后乳突区域=迷走神经靶点"为解剖学错误。
结构描述    结构耳挂 + 入耳延伸段。挂在耳朵上时——
             耳挂条从耳背自然绕过，入耳延伸段进入外耳道口，
             微型前视摄像头可安装在耳挂前端——往前看——不遮挡视线——
             外形接近普通入耳式耳机——不需要额外穿戴。

             最优形态：耳夹式摄像头。夹在耳廓上方，轻，小，自然。
             比眼睛位置稍微高一点——微俯视——看屏幕、看对面的人、
             看手在做什么——全在视线方向。跟挂了一副耳机一样自然，
             没有眼镜腿，没有头戴，不会让对面的人觉得在被录像。
职责
    信号输入    听觉通路（音乐系统第三层信号）
                前视摄像头——场景感知——什么人在对面——
                什么表情——周围环境状态——辅助教练做语境标注。
                音频走入耳延伸段内的微型动圈单元——不入耳膜过深——
                摄像头在耳挂前端——不碰耳道——不占入耳空间——
                不需要砍掉任何一个。
      信号输出    迷走神经刺激（情绪基调调节）+ 耳大神经社交触觉
      语音通道    用户说话→手机麦克风→云端教练AI
                  教练回应→云端→手机→动圈入耳→只有用户听到
                  用户也可以打字——手机应用内文字输入→教练读→可语音回——也可文字回——用户选
      PBM原始数据不出TEE，云端教练读脱敏摘要——能判断趋势——不知道精确值
      采集        心率、基础皮肤电导
 覆盖感受    情绪基调类（平静/焦虑/愉悦/低落的方向性调节）

联网与离线：
    设备出厂预装基础感受包——释然、疲惫、平静。不联网也能跑——本地FPGA——Core读PBM——Anim合成ESIR帧——全在设备上完成。联网后——教练读脱敏摘要——选包——推送——下载到本地——断网——继续离线用。
    云不是大脑，是快递员。送完包，回到本地，设备自己编织。不是每一帧都要云——教练不需要一直醒着——大部分时间——本地闭环——自己归零——自己推——自己调。只有需要新包，或者叫教练，才连一次网。

**为什么贴在皮肤上就能激活深部神经**：迷走神经耳支（Arnold 神经）在耳甲艇位置离皮肤仅 0.5-1mm。经皮迷走神经刺激（tVNS）已被 FDA 批准用于偏头痛、丛集性头痛治疗——电极贴在耳甲艇，0.5-10mA 微电流穿过那不到 1mm 的距离，fMRI 证实同侧孤束核（NTS）和蓝斑（LC）被激活。不是猜想——是有临床实验、有 fMRI 影像、有 FDA 批准的成熟技术。贴片不用穿进去——因为通路短到只需要穿过一层皮。

**第一帧信号加速适应贴附感**：设备贴上去的那一刻，皮肤先报警，"有东西粘着我了。"触觉异物感由 Merkel 盘和 Meissner 触觉小体感知——和 CT 纤维走的是不同的传入通路。CT 纤维的热感信号不是"反向抵消"贴附感，是**在体感皮层同时叠加了另一种安全信号——加速了皮肤机械感受器的自然适应。** 用户实际感受到的不是"贴附感消失"，而是"被贴住的同时又感到了微热。"持续低压刺激在十几分钟后被神经系统过滤掉——跟戴着眼镜、挂着项链一样。Feelings 不做抵消——做的是**在适应完成之前——先用正信号盖住空隙。**

这和游泳入水是同构的——第一帧冷水刺骨——游一圈——身体适应了——不冷了。感觉适应曲线可以被CT纤维信号加速——不需要在第一帧完美消除所有贴附感——只需要用热感+微压把皮肤报警带过初始的那几秒——然后身体自己接手——之后不需要再干预。
```

**这是唯一的必选设备。** 其他设备都是扩展。

#### 设备形态——结构耳挂 + 动圈入耳（Option 2B）

砍掉骨传导振子。耳挂退化为纯粹的"电极支架 + 主板/电池驻地"。音频走入耳延伸段内的微型动圈单元。

```
耳挂条（物理支撑结构）
    - 材料：记忆钛丝 + 医用硅胶外包
    - 功能：提供微弱平稳的夹紧力，把耳背导电织物固定在耳大神经（C2-C3）区域
    - 内部：FPGA + 柔性电池 + AFE 模拟前端（骨传导振子砍掉，腔体释放）
    - 内侧面：柔性导电织物，贴合耳后皮肤 → 耳大神经社交触觉通路

入耳延伸段（声学与电极端）
    - 内部：微型动圈单元（Layer 3 音频，动圈入耳低频比骨传导纯净）
    - 端面：柔性导电织物，接触耳甲艇/耳屏（Arnold 迷走神经）
    - 柔性排线连接耳挂条主板

砍掉骨传导振子的三重红利：
    1. 重量：从 ~18g 降到 ~13-14g（砍掉磁钢+线圈 3-5g）
    2. 空间：释放原本给振子的腔体，PCB/FPGA/电池不再挤压折叠
    3. 信号：振动共振不再污染 AFE 电极阻抗读数，接触阻抗极度稳定
```

#### 空间预算——骨传导振子砍掉后，松一口气

```
耳挂条内部：
    当前已占用：电池 + FPGA 核心板 + AFE 模拟前端
    已砍掉：蓝牙 SoC（nRF52832 集成在 FPGA 同一块 PCB 上，用 nRF52 的 BLE 不做音频）
            骨传导振子驱动器、磁钢、线圈
    剩余可用：振子腔体释放后，PCB 面积直接翻倍——FPGA + AFE + 电池不再需要折叠
              电池可从圆柱形切为柔性扁平锂电，弯着贴在外壳内壁

占内部空间的大头只剩一项：电池。
FPGA + AFE + 时钟——在释放后的 PCB 面积上——绰绰有余。
不是"刚好够"。是"够——而且有余量"。松弛了。

    将来换固态电池——能量密度 ×2-3——
    同等体积——续航 ×2-3——或者更小的电池换同样的续航——
     留给 FPGA 和未来扩展的空间——不再紧张。
```

#### 第一帧校准——每个人的耳朵不一样

耳廓形状、皮肤厚度、迷走神经耳支的走行路线——个体差异显著。有些人的分支在耳甲，有些在耳屏，差几毫米。同样的信号，碰到皮肤的接触阻抗不一样，神经离表面的距离不一样。

```
多阵列微电流扫描——入耳电极逐点注入微电流。

超短期迷走神经响应指标（Ultra-short-term Autonomic Response）——
不能等 Session 结束看整体问卷。必须在扫到正确点的 10-15 秒内捕获：

  1. 瞬时 R-R 间期延长（ΔRR_instantaneous）：ABVN 激活孤束核后，副交感传入信号在 1-3 个心跳周期内通过迷走神经心支直接延长心跳间期——比 RMSSD 快 2-3 倍收敛
  2. PPG AC 波形下升支斜率（Diastolic Slope）：外周微血管副交感舒张响应，比 GSR 更敏捷
  3. 皮肤电导（GSR）骤降或稳定

三个指标在 15 秒内同时触发 → 这个点的坐标就是 Arnold 密集点。
RMSSD 需要 30 秒以上 R-R 间期才能计算稳定值，在 10-15 秒扫描窗口内极易受呼吸（RSA）干扰。用瞬时 R-R 间期延长时间 + PPG 舒张斜率替代，密集点定位收敛速度快 2-3 倍。

第一帧      入耳接触区域，电极阵列排得够密。每个探头单独激活，PBM读回生理响应。哪个点激活后心率平稳最快，哪个点副交感响应最大，密集点找到了——身体自己说的，不是手工对位。
后续会话      密集点固定——其他探头不用——只精确调制——每次戴上，自动回到那个位置
换设备        校准数据不和设备走，锁在 PBM 层——换一台新的——重新扫一遍，十秒
```

硬件同一批量产，密集点的坐标每个人自己校准。不是定制模具，是同一套阵列，在每个人身上找到自己的门。

#### 双通路的不对称性——耳背出厂即用，耳甲深度信任

耳甲艇/耳屏的形状、深度、皮下穿行路线——个体差异极大。有些人的耳甲艇深得塞得进一粒黄豆，有些人浅到几乎平的。迷走神经耳支的皮下走行跟着耳廓形态个体化——两毫米的差异就能决定那帧信号是激活了孤束核还是只激活了 Aβ 神经末梢。需要逐个用户扫密集点、逐 Session 校准。

耳大神经相对固定。C2-C3 脊神经从胸锁乳突肌后缘穿出，骨骼定位沿乳突往下几乎固定在那条沟里。耳后皮肤接触面积大，定位容错率高。

这不只是解剖学差异——它是产品设计不对等的根：

```
耳背电极（耳大神经） → 戴上就激活。第一天就有感觉。
                        定位容错率高，不需要第一帧校准。
                        感受递弱——走体感皮层，不是主导通路。
                        适合作为"第一天就有东西发生"的出厂承诺。

入耳电极（Arnold 神经）→ 第一天可能没感觉。
                          第五天找到了自己的密集点。
                          第二十天调出来的信号比耳背那套深十倍。
                          适合作为"你留下来之后我们慢慢聊"的核心货。
```

不是"Arnold 精密但难用，耳大不精密但好用"。是出厂体验靠耳背，深度信任靠耳甲。两套通路从对称设计变成了分层设计——表层的社交触觉先给你一扇门，深层的副交感基调在门后面慢慢等你走过去。

#### 双通道电气隔离——两路 VCCS 独立悬浮地

耳背与入耳两套电极同时接触同一个人的耳部皮肤。耳背电极驱动电流较大，入耳电极需要亚阈值精密调控。如果硬件 AFE 两通道共享共地（GND），耳背的大电流会顺着皮肤表面汗液和油脂形成的导电桥倒灌进耳甲腔——Arnold 精密调控被高电位污染，产生刺痛感。

硬件必须双通道完全电隔离（Galvanic Isolation）：两套独立压控恒流源（VCCS），各自悬浮地（Floating Ground），差分驱动。保证两路电流在解剖物理路径上绝对互不干扰。不是"共地就行"。是**两个独立电源域——从 LDO 到 DAC 到驱动级——全部隔离。**

AD5933 在耳甲端做 10kHz-100kHz 高频微电流阻抗扫描时，隔离 DC-DC 电源的寄生电容（PCB 跨接电容约 10pF）在高频下阻抗仅 ~160kΩ——高频交流信号仍会通过寄生电容耦合到耳背 VCCS，产生微干扰。PCB Layout 必须硬约束隔离耦合电容 < 5pF，并在隔离区加驱动屏蔽环（Driven Shielding / Guard Ring）。

微型耳挂柔性 PCB 在汗水、高湿和频繁弯折下维持 < 5pF 是极苛刻的工艺要求。VCCS 隔离区必须涂覆 Conformal Coating（防潮防盐雾保鲜涂层），防止汗液盐分结晶渗透破坏隔离边界。不是"布局做好就行"——是**汗水本身就是电解质桥。**

#### 定制化路径——通用原型验证"有用"，定制版把它推到"好用"

现在的定制成本完全可以负担。通用版先跑，PBM 自己说话。

```
第一天：通用版（S/M/L 三个尺寸，覆盖 80% 耳廓形态）
    → 耳背电极出厂即用。耳甲电极走第一帧校准扫密集点。
    → AI 教练在前 30 个 Session 里读 PBM
    → "这个人对 Arnold 信号响应强吗？靶点偏了多远？"

第 30 天：AI 教练给出定制建议
    → "你的 Arnold 密集点比通用电极位置偏前 3mm——需要定制入耳段"

定制版建模——不能用普通 RGB 拍照叠帧。

    耳甲腔是一个带深度阴影与暗倒角的凹陷结构。普通 RGB 相机在耳甲腔深处被耳轮和耳屏遮挡，深度图常有 1-2mm 凹陷拉伸失真。两毫米决定激活孤束核还是 Aβ 末梢——1mm 误差就是产品失效。

    定制建模必须依赖带结构光/深度传感器的手机（如 TrueDepth 前置镜头）近距离点阵扫描，而非普通照片。
    不尝试 1:1 打印整块硬质耳塞——采用"柔性硅胶通用主体 + 3D 打印微型阵列载板"。
    用柔性结构吸收 1mm 解剖容差，只把定制精度作用于电极触点相对位置上。

    TrueDepth 结构光在耳甲腔暗影区仍有点云缺失——腔深、入口窄，边缘点被遮挡。
    App 端集成非刚性 ICP 变形算法，用标准耳廓解剖先验模型对缺失区域做拓扑补全，
    而非直接网格硬插值。不是"AI 猜"，是"已知的人类耳甲腔不该长成这样"。
```

和教练哲学完全咬合——不是"先付钱再证明有用"，是"你先用了，你自己的 PBM 告诉你值不值得定制"。定制不是抬高门槛，是把已经确认有效的体验做到极致。

#### 三层产品——通用版、旗舰版、定制版

让用户一开始就选是错的。PBM 自己告诉他，在这个级别已经到顶了，你想走的话，这边有门。

```
通用版     S/M/L 三档，AD5933，出厂即用。
          耳背电极第一天就有感觉。耳甲密集点自动校准。
          PBM 在前 30 个 Session 里读基线、读衰减、判断神经深度。
          目标：证明"这东西对我有用。"

旗舰版     换 AD5940 + 更高位宽 AFE，刷新更精细的 PBM 数据。
          外壳未定制——但硬件精度跳了一代。
          扫描档位更密、信号保真度更高、双通道可独立校准。
          体验从"能感觉到"升级到"能区分质感。"
          目标：PBM 数据密度不够——不需要定制外壳——硬件先升级。

定制版     1:1 负模 + 电极推到精确深度 + 旗舰硬件。
          PBM 已读取 200+ Session——你的衰减曲线、敏感点、
          呼吸窗口全幅参数、双侧独立的基线——都在。
          不再是一副通用的壳——是只为你那副耳朵造的壳。
          目标：不是"更好"，是只为你一人。
```

不是硬件等级森严。是**PBM 成长到什么密度，硬件就升级到匹配那个密度的版本。** 和教练哲学完全一致：先用了再决定——不是先决定再付钱。


#### 感知预期管理——最深沉的安静恰好在感觉不到电击的时候

双通路不对称性有一个产品化的暗坑。耳背电极体感明显——Day 1 到 Day 7，用户觉得"耳背麻麻的暖暖的，这就是 Feelings 在起作用"。到了 Day 20+，入耳 Arnold 通路被精调出来，开始深层重构副交感基调——这种深层稳态往往无形、安静，甚至感知不到电刺激。亚阈值调控才是最有效的——但用户看不到。

此时用户可能误以为"设备刺激变弱了，没感觉了"，把耳背的"电击麻木感"错误归因为"调控有效性"。

AI 教练在前 30 天必须做感知预期管理，提前告诉用户：**"耳背的感知是提醒你的身体醒来。最深沉的安静，恰恰发生在你的耳朵感觉不到任何电击的时候。"** 不把显性体感和调控有效性混淆。

**备注：不向颈部延伸。** 颈动脉窦紧邻迷走神经，是血压调节总闸。信号误推可致命。耳甲/耳屏是目前唯一同时满足"离中枢近、不会动、不打要害"的窗口。该守的边界——不扩。

#### 电极材料与舒适性约束

电极必须软，不能是硬金属片，不能是PCB。柔性导电织物——镀银尼龙或者石墨烯涂层纺织——和内衣标签一样软——贴着皮肤，不硌，不冷，不会在汗水浸透之后磨破皮肤。边缘必须圆角钝化，不能切割，不能锋利。

```
材料        柔性导电织物（镀银尼龙/石墨烯涂层纺织）——不是金属片——不是硬触点——是一块软布——导电——可缝——可水洗
干燥电极      不用凝胶。长时间佩戴，皮肤油脂和死皮会让接触阻抗慢慢变大。不是坏了，是脏了。需要偶尔用干布擦拭
衣服集成      领口、袖口、胸口的电极——磁吸扣或导电按扣——衣服归衣服——电极归电极——穿上对准——脱下断开——洗的时候电极模块摘下来——衣服扔洗衣机
              衣服上只留导电织物——没有芯片——没有电池——没有PCB——所有信号处理模块在扣子上——那东西不洗
耳部设备      电极集成在入耳式耳塞端面——精密区域——需要每一帧都对准同一个密集点——衣服做不到这个精度
```

采集层用衣服电极，足够——读到趋势就够了。注入层必须入耳接触耳甲/耳屏——那个密集点——差两毫米信号偏了——衣服挪一厘米——没碰到神经——白灌了。两套精度——两套设备——衣服管读，耳部设备管推。

#### 电极形态——从固定双点到可寻址阵列

现有 tVNS 耳机的电极是固定的两个黑环——围绕在一根支上——它的假设是"所有人的 Arnold 神经长在同一位置"。但解剖事实是：迷走耳支在耳甲的分支位置个体差异很大——"标准位置"只对神经位置吻合的人有效——不吻合的人效果大打折扣甚至无效。固定不是设计选择——是开环的必然：只有刺激、没有测量，就无法知道刺激对不对——只能赌平均位置。

双电极与单极的区别：

```
双电极（两环）    一极出、一极入——电流在两级之间的路径流过——
                  路径短、集中、密度高——神经激活聚焦——
                  聚光灯——电流不流经无关组织——副作用小
单块电极（单极）  电流从电极扩散——在远处的对电极流出——
                  路径长、分散、密度低——激活弥散——
                  泛光灯——可能波及其他神经——副作用风险高
```

双电极是"局部回路"的最小单元——Feelings 的刺激端把它扩展成可寻址阵列：

```
可寻址阵列 = 一整片电极被分割成多个独立小电极——
    覆盖范围不变（广——铺满耳甲——神经可能出现的所有位置）——
    但每个触点独立寻址——任意两触点配对 = 一条局部回路——
    N 触点 = C(N,2) 条可寻址路径——
    形态：柔性阵列（FPC/导电硅胶贴合耳甲曲面）

热点扫描 = 遍历路径找最优：
    逐触点测试 → 采集反馈（阻抗/HRV/皮电/呼吸变化）→
    哪个配对引起的生理响应最大 = 你的神经触发点——
    找到后锁进 PBM（每个人的神经地图是个人基线的一部分）——
    之后轮换配对对抗耐受——多点轮换刺激（临床标准做法）

闭环 vs 开环：
    现有 tVNS = 开环——刺激固定点——赌平均位置
    Feelings  = 闭环——刺激+测量——扫描校准——
                采集链的第三重价值：刺激校准的反馈源——
                （第一重记录感受、第二重治理证据、第三重刺激寻的）
```

成本评估——不是成本大头：

```
触点数量    耳甲只有 1-2cm²——8-16 个触点密度已经很高——
            不是越多越好——布局覆盖神经可能位置才关键
电极本体    柔性 FPC + 镀层——批量生产几美元到十几美元级——
            与两环电极成本差距很小
多路复用    每触点独立寻址 + 每帧测阻抗——开关矩阵/MUX——
            成熟器件（多路复用器、模拟开关——几毛到几美元）
量级对比    电极阵列在 Feelings 总成本（FPGA+ADC+AD5933+
            驱动+PCB）里占比很小——成本卡的是设计正确性
            （触点布局覆盖神经可能位置）——不是材料
```

#### 双侧刺激——两只耳朵，两条不对称的神经

人有两只耳朵，两条迷走神经耳支。但人不是左右完全对称的——左耳的密集点和右耳不是镜像，需要各自独立校准。

更深一层：左右迷走神经在解剖上对心脏的支配不对称。右侧迷走神经主要支配窦房结（SA node，心率起搏点），左侧主要支配房室结（AV node，传导延迟点）。双侧激活时不能简单复制同一帧 ESIR 到两边——两侧的 VCCS 驱动曲线必须支持独立相位 offset 微调，防止两侧神经冲动在脑干孤束核重叠时产生生理节律的相位抵消。不是"同步"——是"协调但不撞相位"。

```
单侧（默认）    一只耳朵——日常使用——释然、疲惫、基础调节      一扇门就够了
双侧（高级）    两只耳朵同时激活——深度恢复帧、临床级放松、R值高的用户      两扇门同时开
               硬件保留双侧接口——但双侧激活需教练批准——不是谁都两扇门一起推
```

同步是硬要求。Apple HomePod 两个组成一对同时播放——底层有严格的时序校验，一个慢了一毫秒——不是在叠加——是在对冲。Feelings 双侧同理——左右迷走神经信号帧必须同步到帧级别，左边和右边差了一毫秒——偏差不是两条同向——是两条互相干扰——等控器收到两个矛盾的归零方向——空转。

每个人的左耳和右耳各自独立走一遍第一帧校准——密集点各自找到——各自锁在 PBM 层——双侧同时激活时——左右独立调制——时序同帧——方向一致——不是两倍效果——是两扇门——在同一个瞬间——一起被敲开。

耳挂式结构天然是两侧都有。用户可以选只开一边，或者两边都开。只开一边——只读一侧迷走神经——效果足够日常——续航更长。两边都开——双侧同时刺激——体验拉满——但牺牲续航。不是强制的——是用户自己选——今天的电量——够不够双侧——还是单侧省着点用。

## 五、设备间协作协议

多个设备同时工作时，需要协调机制。

### 主设备选举与降级模式

```
耳部设备    永远是主设备（必选）
其他设备    向主设备注册，成为从设备
主设备      负责时钟同步、信号协调、与 App 的主通信
```

主设备单点故障不能意味着全身脱机。耳部接触不良（出汗移位、暂时摘下）时：

```
耳部在线（正常）    → 全栈运行：Arnold 注入 + 耳大触觉 + 骨传导音频 + 从设备采集
耳部接触不良        → 从设备降级维持：腕部继续读 PPG/EDA，后颈继续读温度/姿态
                     注入侧暂停（没有耳部 VCCS = 没有执行器）
                     采集侧不停——从设备自己的传感器继续跑
耳部恢复接触        → 第一帧校准自检密集点是否还在原位→在→恢复全栈
                     偏移＞阈值→重新扫密集点，耗时 15s
耳部彻底离线        → App 推送："耳部掉线了，腕部和后颈还在读"
                     用户决定：继续纯采集模式 / 暂停本次 Session
```

不是"掉线=全黑"。是**采集不停、注入暂停、用户自己选。**

### 总线直连——物理路径最短原则

MacBook Pro 的内置触控板走内总线（I2C/SPI）直连主板——无配对、零延迟、确定性时序。外接蓝牙触控板走 RF 链路——配对握手、RF 干扰、协议开销、电池协商。同一块触控板，连法不同，手感完全不同。不是苹果不优化。是 RF 链路的物理限制不可逾越。

Feelings 的设备间通信遵循同一个原则。

```
原则        信号的物理路径越短，压缩管线越干净

设备内通信（Intra-device）
    耳挂条 → 入耳延伸段 → 耳背电极
    走柔性排线直连。无配对、零延迟、确定性时序。
    1ms 帧级同步，全量信号参数传输。

设备间通信（Inter-device）
    耳部主设备 → 腕部 / 后颈 / 颞部从设备
    不挂物理线缆跨过脖子和手臂——日常穿戴体验不允许。
    采用 2.4GHz 私有协议（Nordic ESB 模式）。

    物理约束：人体（主要成分是水）是 2.4GHz 电磁波的天然吸收体。
    跑步甩臂或躯干扭转时，耳部到腕部直视路径（LoS）被身体阻断，
    衰减可达 40-60dB——射频丢包→TDMA 时隙崩溃。

    解决方案：注入侧（耳部）独立走 1ms 硬闭环——不需要从设备同步。
    采集侧（腕部/后颈/颞部）采用软时间戳对齐，允许 10-20ms 容差。
    从设备只上传采集数据，不参与实时注入决策。
    注入闭环的实时性不依赖跨身体的无线链路。

和 FPGA 的关系
    主设备（耳部）内置 FPGA
    FPGA 直连主传感器接口（数模转换、中断、时钟）
    从设备通过主设备的总线桥接至 FPGA
    整个设备集群 = 一个分布式 FPGA 节点网络
    中心星型拓扑——主设备是唯一的星型节点

为什么不走蓝牙
    BLE 最小连接间隔 7.5ms → 1ms 帧级闭环直接不可行
    配对延迟不确定性 → 确定性时序不可保障
    RF 干扰 → 安全信号被干扰 = 不可接受的风险
    OS 协议栈 → 信号经过多层软件缓冲 → 延迟不可控
```

### 信号同步

```
目标要求    所有设备的采集时钟同步误差 < 1ms
实现方式    主设备（耳部-FPGA）发出统一时钟信号
            从设备通过总线接收主时钟 → 本地锁相环（PLL）锁定
            所有设备的采集和注入时序由同一个主时钟分频派生
            误差 = 总线传输延迟 < 1μs（远小于 1ms 要求）

            物理层采用 LVDS 差分总线——颈部扭转、手臂挥动导致柔性排线
            高频弯折时，差分对共模抑制抵抗微阻抗变化的时钟抖动。
            链路层每帧 CRC 校验，丢失帧自动重传。
            总线不依赖 BLE。不依赖 WiFi。不依赖云端。
```

信号注入的时序由主设备统一调度，感受曲线的实时变化主设备通过总线广播给所有从设备。

### 测量状态方差——单点快照不是事实

InBody 的教训对整个测量网络成立：生物电阻抗靠微弱电流测导电率，充碳（每 1g 糖原锁 3-4g 水）让导电率飙升——机器把水当肌肉，测出虚高骨骼肌、虚低体脂；脱水反向低估。**单次快照读到的可能是糖原脱水的临时快照，不是长期稳定的成分。**

适用边界：这个坑属于 InBody 的全身成分测量，Feelings 不测全身成分——肌肉量/水分/体脂对神经调节闭环没有直接作用。引用它是因为"单点快照会被瞬时状态污染"这个**结构**对局部生理测量同样成立，只是污染源不同：

```
对 Feelings 的测量网络，同构的混淆变量（局部状态，非全身成分）：
   水分    皮电/阻抗源受水分漂移（手汗、补水、脱水）
   进餐    血糖/血流/体温在餐后窗口显著漂移
   训练    训练后 1-2 小时交感张力残留
   温度    环境温度直接调制皮肤温度与血管舒张
   贴合    运动伪影、接触阻抗变化

三条设计规则：
   ① 单点永远是快照，趋势才是事实——
      单帧数据不当事实，长窗口趋势才进基线
   ② 测量条件必须固定或可观测——
      状态标记（进食/饮水/训练/睡眠）与数据同行，
      带状态标记的窗口才进稳态基线
   ③ 感受是结果指标，数据是过程指标——
      数据会被状态骗，主观感受不会被骗——
      双线并行：数据线做校准，感受线做仲裁
```

连续流式测量的真正优势不是"测得多"，是**噪声有协变量可观测**——单点测量（InBody）的混淆变量不可观测，只能"固定条件再上机"防御；连续测量把水分、温度、进食、训练全打成协变量，读数可以被状态校正。这是从"参考快照"到"趋势事实"的架构级跃迁。

### 设备掉线处理

```
从设备掉线    总线检测到 → 降级到对应组合的能力范围
              不中断体验，不提示用户（除非影响安全监测）
主设备掉线    体验立即终止，所有信号停止
              这是唯一的强制中断场景
```

## 五点五、家庭存储节点——NAS 与局域网数据闭环

设备集群的实时总线（第五章）不依赖云端——存储同样不依赖云端：**用户自家的 NAS 作为家庭存储节点，设备和 NAS 走局域网闭环，全程不经过公网。**

```
数据流：Feelings 设备 → 局域网（WiFi/有线）→ 用户 NAS
        不出公网——互联网上没有神经数据——
        不是"不上云"——是"不出门"——
        数据连门都没出过

存储分工：
    设备本地    滚动窗口（最近 24h 完整原始）——环形缓冲自动覆盖
    NAS 归档    全量数据（TB 级容量）——原始数据长存
    联动        窗口与归档自动同步——覆盖与长存并存——
                多设备汇聚（耳挂、腕部、贴片 → NAS 单点归集）——
                历史查询、设备换新迁移（旧设备 → NAS → 新设备）
```

**传输安全走专用设计**（见 docs/safety/neural-data-transport-security.md——注入优先的威胁模型）：帧级认证防伪造信号注入、流式加密防窃听、局域网内也加密（"局域网"不是安全假设）、钥匙在用户 TEE。

**产品形态——Feelings 也卖自己的 NAS：**

```
定位      不是通用存储（群晖/威联通是"什么都能存"）——
          是"为神经数据优化的存储"：
          预置神经数据格式、隐私默认值、设备深度联动——
          开箱即用——插电就是 Feelings 家——
          卖的是"数据主权基础设施"——保险箱，不是仓库

商业      双硬件闭环：设备（采集）+ NAS（存储）——
          可选服务（多盘冗余、数据迁移、家庭多用户管理）——
          但"数据可见性"永远不卖——服务不碰数据内容

红线      钥匙在用户手里——Feelings NAS 无远程访问能力（除非用户主动开）——
          OTA 签名验证——更新通道被攻破 = 后门——
          卖盒子的人不拥有盒子里的东西——保险箱哲学
```

**数据哲学：在这个"数据是数字时代土地"的时代——Feelings 卖的是"把土地还给用户"的工具。** 设备是铲子，NAS 是地窖，钥匙在用户手里——Feelings 在整条数据链路上彻底隐形：不是平台，是厂商——厂商不需要回答"数据在谁手里"——因为答案从出厂那天就写死了：在你手里。

## 八、设备形态：柔性吸附，不是植入

Feelings 的设备形态选择，是一个根本性的哲学决定。

**吸附式，不是植入式。**

```
科技巨头的路线    深度植入、长期绑定、强制采集
                  主动权在系统
                  摘下来需要手术

Feelings的路线    柔性吸附，稍微用力即可取下
                  主动权永远在用户
                  随时可以摘，随时可以戴

这不只是技术选择，是关于谁掌控谁的哲学声明
```

### 吸附设计规格

```
材质            医用级柔性材料
                 微负压轻贴合，无创伤
                 生物相容性，长期佩戴无排斥反应
                 外层包裹陶瓷质感薄壳——不直接露出医用硅胶

贴合位置        颈后（迷走神经区）
                 太阳穴（颞叶）
                 腕部寸口（脉搏/皮电）
                 耳后——夹耳式磁吸对合（非胶水、非吸盘）
                 口腔护齿型——三叉神经通路
                 耳后（耳支迷走神经）
                 → 前壳内置钕磁铁 + 后壳配对磁铁 → 耳廓夹在中间
                 → 不压皮肤、不用胶、不用吸盘 → 外观 = 光滑陶瓷质感

取下方式        稍微用力，徒手剥离
                不需要工具，不需要手术
                5秒内完成
```

### 吸附式的精度取舍

```
吸附式的代价
    只能抓到：外周神经/皮电/血流/肌电/浅表自主神经
    抓不到：深层脑内核心神经数据

不是缺点——是设计选择。
```

#### 少点高信息 vs 多点全覆盖

全头 EEG 帽和 Feelings 是两条完全不同的路线：

```
全头采集 (64-256 通道)
  目标      解码运动意图 / 语言重建 / 视觉皮层映射
  原理      空间分辨率——覆盖更多皮层区域
  代价      丑 + 准备时间长 (贴电极 20min) + 凝胶 + 不日常
  用户      义肢控制 / 神经科学研究——每天戴不了的

Feelings 采集 (5 设备，精准点位)
  目标      四诊合参 + 教练判断 + PBM 基线
  原理      时间分辨率——1ms 帧级，从最少点位提取最多信息
              心率 1 个点 (PPG 腕部)
              皮电 1 个点 (EDA 腕部)
              体温 1 个点 (后颈 / 腕部)
              EEG 2-4 通道 (太阳穴贴片，只做 α/β/θ/δ 功率谱)
              不是 "读想法" → 是 "判断前额叶在线还是被杏仁核压制"
  代价      无——吸附式，5 秒戴好，日常可穿
  用户      任何一个想理解自己状态的人
```

**核心哲学**：技术成熟的方向不是"覆盖更多头皮"，是"从更少点位提取更多信息"。

```
腕部单点 PPG → HRV + 呼吸频率 + 血氧（从一条脉搏波推三条生理指标）
太阳穴贴片   → α/β/θ/δ 功率谱（从 2-4 通道判断认知状态，不需要 64 通道）
后颈体温      → 昼夜节律相位 + 运动强度代理

不是电极越多越好——是信号-信息转换率越高越好。
```

#### 三种补偿方案

```
多点位交叉采样    单点信号弱，多通道融合用算力换精度
软注入            低频仿生微刺激+神经节律同步
                   顺着人体本身的节律引导，不强行改写
情志层级精准调控  不需要像素级神经操控
                    只需要微调情绪体感阈值
```

### 重量预算——不是"尽力做轻"，是超过临界线就没人戴

重量是物理硬约束。蓝牙耳机 5g 级别是用户已经被训练出的期望基准。超过一定克数，佩戴率直接归零。

**单设备重量预算**：

```
耳后设备 (主设备 / 必选)
  柔性锂电          ~8g  (扁平贴壳内壁，不用圆柱形)
  FPGA 核心板        ~3g  (iCE40 / Gowin 3×4mm BGA)
  PPG 模组           ~1g  (红外+绿光 LED + 光电二极管，在耳垂方向)
  模拟前端 + 时钟    ~1g  (集成在 FPGA 同一块 PCB)
  外壳 + 线缆        ~5g  (医用硅胶 + 柔性排线)
  迷走神经刺激电极   ~0g  (贴在皮肤一侧，不占内部空间)
  ────────────────────────
  耳后总计           ~18g

对照基准:
  AirPods Pro 单只    5.4g
  华为 FreeClip 单只  5.6g
  Oura Ring           4-6g
  Whoop 手环          8-10g
```

```
扩展设备:
  颈部环带     ~25g  (柔性 PCB + 硅胶封装 + 电极)
  腕部表带     ~15g  (EDA + PPG + 电池)
  太阳穴贴片   ~8g   (2-4 通道 EEG + 柔性基板)
  口腔护齿     ~12g  (三叉神经刺激 + 碰撞传感器)
  手指环       ~4g   (微型 PPG + 触觉反馈)
```

**临界线**：

```
> 20g  用户感知到 "戴了东西" —— 超过耳部承重舒适阈
> 30g  运动会掉 —— 吸附力不足以对抗加速度
> 40g  日常不会戴 —— 超过所有消费电子佩戴基准线
```

**全身组合重量**：

```
最简 (仅耳后)        ~18g  基准——必须守住
标准 (耳后+腕部)     ~33g  尚可
完整 (4 设备)        ~66g  接近临界——靠 "摘一部分" 维持
最全 (5 设备+护齿)   ~82g  不是日常配置——特定场景使用
```

**重量和时域长尾的关系**：

```
对抗运动场景 (篮球/足球/橄榄球):
  不需要全身配置——0g，因为你摘了
  赛前用耳后做一次注入 (injected mode)
  摘掉 → 激素自己跑完整场

深度工作/冥想/睡眠:
  耳后 + 太阳穴 → ~26g，可以接受

普通日常:
  耳后 18g 基准 → 必须 < AirPods × 3 = 16.2g 心理锚点
  固态电池来之前——这是硬仗
```

**固态电池的意义**：

```
当前柔性锂电    能量密度 ~250 Wh/kg
固态电池        能量密度 ~500-800 Wh/kg (×2-3)

同等 18g → 续航 ×2-3
同等续航 → 重量 /2-3 → 耳后设备 ~8g
↓
AirPods 级别重量 → 佩戴率质变
不是 "更先进" —— 是 "突破重量临界线"。
```

### 第1.5阶段：微针选项

```
介于吸附式和半侵入之间

微针阵列穿入皮肤浅层（0.5-1mm）
    比吸附式精度高：能采集更清晰的外周神经信号
    比植入式创伤小：皮肤浅层，不碰脑组织
    几乎无痛：微针直径极细

这是吸附式验证后的自然演进方向
不是今天的重点，是路径上的下一站
```

```
Feelings是自愿佩戴的情绪共生载体
```

### 从纹身到设备——不是贴在身上的机器，是一片会读心率的贴花

脚踝后侧的胫后神经和腓肠神经离皮肤 0.3-0.5mm——是人体上神经最浅的几个点之一。人已经在那个位置做了几千年的装饰——踝链、脚铃、纹身。不是偶然——是本能标记了身体上最敏感的几个入口。

Feelings 不做"穿戴设备"——那听起来像手环。做**一片会读心率的贴花：**

```
形态:
  0.6mm 柔性基底 (PI 聚酰亚胺)
  外层水墨/刺绣/联名图案——和纹身贴纸一样自然
  磁吸扣替换充电盒——无感贴合

哲学:
  人不抗拒在身上放好看的东西
  抗拒的是"看起来像医疗设备的东西"
  纹身是自选的——Feelings 也是自选的
  纹身是好看的——Feelings 也是好看的

厚度的代价:
  0.6mm 超薄贴花不是一开始就能做的:
    电池      → 柔性薄膜锂电 → 容量砍半 → 续航砍半
    算力      → FPGA 封装 > 1mm → 必须等 ASIC 流片
    信号质量  → 电极面积缩小 → 接触阻抗升高 → 信号略弱
    成本      → 柔性 PI 基板 + 异形电池 + 微组装 → 比刚性 PCB 贵 5-10 倍

  当前路线: 先做对的 (2-3mm 刚性 PCB 原型 = AirPods 厚度)
  未来降层: ASIC + 柔性电池成熟后 → 压到 0.6mm 贴花级
```

## 九、震动隔离——机械噪声必须压到比皮肤电导波动更低

耳后设备——迷走神经耳支——AD5933 测阻抗——μA 级电流——1ms 帧。如果设备本身有微振动——电机、风扇、走路、地铁、风吹——那些振动——在阻抗谱上——就是噪声。不是"信号弱。"是**噪声的幅度——比你要测的信号——大好几个数量级——你测的不是生理——是振动——除非你把振动先滤掉。**

所以 Feelings 的硬件——从原型第一天——就需要震动隔离。

```
PCB 的机械谐振频率    必须远离 1ms 帧周期的傅里叶峰
外壳的阻尼系数        必须把环境振动在采样窗内的振幅压到 ADC 分辨率以下
总线直连（非蓝牙）    消除 RF 干扰和协议开销的确定性延迟
```

不是"加个橡胶垫。"是**几个纳米的位移——足以污染每一帧的阻抗读数——然后一路被当成生理信号——送到岛叶——然后用户的身体——被机器自己的抖动——骗了。** 和 KubePivot 的 KVCache 一样——不是"快"——是**不能被振动污染。**

硬件阻尼 + 双频阻抗拆解能消掉大部分伪影，但运动中肌电（EMG）干扰和电极-皮肤微米级滑动仍有残余噪声。μA 级 AD5933 阻抗测量精度要求 FPGA 端跑实时 DSP 自适应滤波——不是"采完再滤"，是**每一帧在进入 PBM 之前已经被洗过一遍。**

## 九点五、咀嚼与面部运动——双频阻抗拆解，不打折不对抗

砍掉了骨传导振子，机械自振消失了。但用户说话、咀嚼（咬肌和颞肌运动）、下巴张合时，外耳道和耳屏会变形，柔性导电织物的接触阻抗发生幅值阶跃。如果简单地"阻抗跳变→暂停注入"，吃一顿饭可能导致 20 分钟调控完全断档。

肌肉运动（物理脱空）与副交感神经响应在频域上本质不同：

```
变量              物理肌肉运动（咀嚼/说话）      迷走神经/副交感生理响应
─────────────────  ────────────────────────    ───────────────────────────
接触阻抗变化       面积剧烈改变，Z 幅值阶跃大     组织电容与电导微变
高低频表现         1kHz 与 50kHz 阻抗同步等比跳变   高低频阻抗变化非线性（相位偏移）
```

AFE 同时注入 1kHz（低频）和 50kHz（高频）激励信号：
- 若 Z_1kHz 与 Z_50kHz 同比例剧烈跳变 → 物理位移（咬肌运动）→ 降额/打折注入——不是停，是减。
- 若高低频阻抗出现相位差（Phase Shift）→ 组织生理响应 → 保持正常注入与采集。

不是二元暂停。是**频域拆解——咬一口苹果不打折 20 分钟，只是那一秒少推一点。**

## 十、防水——柔性材料与 IP68 的结构矛盾

设备是吸附式——柔性材料——微负压贴合。耳后——出汗——下雨——洗澡——如果防水等级不够——阻抗测量直接报废。

IP68 是底线。但"柔性吸附"和"IP68"之间有一个结构矛盾——**柔性材料在重复弯折下——密封层会疲劳开裂。**

```
波纹密封结构    在柔性基底的曲率变化范围内——
                密封层不被拉伸超过屈服应变
                不是"加个橡胶圈"——
                是让密封层在设备正常弯折时——自身不处于受力状态
```

不是加保护——是**让保护本身——不在设备正常工作时成为新的污染。** 和震动隔离同一种设计——"保护——不能变成噪声。"

## 十一、嵌入式演进——从 FPGA 到定制 ASIC

设备文档写了三个设备阶段——吸附→微针→半侵入。但没写控制芯片的形态怎么变。

**第一阶段——原型。** FPGA 开发板——分立元件——手工焊接。AD5933 阻抗——MAX30003 ECG——分立 ADC。功耗高——体积大——量产不行——验证够。

**第二阶段——集成。** FPGA + 模拟前端集成到单块柔性 PCB。ASIC 取代分立 ADC。LDO 取代开关电源。总功耗可控——总质量可控——弯折疲劳测试——量产。

**第三阶段——定制 ASIC。** 将 FPGA、ADC、电源管理、总线和安全芯片——封入一个 die。不是"更小。"是**把信号路径从厘米级压到微米级——震动的影响——从需要隔离——变成物理上不可感知。** 和 SPL 从一开始就抗量子——同一种操作——"不增加保护——从物理上消除被保护的需求。"

### 11.1 电源轨设计——低压域的每一 mV 都是损耗

电源轨是嵌入式演进里最容易踩的坑。二极管的整流损耗账直接搬过来：**压降损耗的严重程度看工作电压——越低越痛。**

```
5V 电源用桥式整流（2×0.7V=1.4V 损耗）→ 效率只剩 ~70%
230V 市电整流（1.4V vs 230V）       → 损耗 0.6%——可以忽略
3.3V 可穿戴（1.4V vs 3.3V）         → 烧掉四成——痛
```

Feelings 的电源路径：3.7V 锂电池 → 3.3V 轨道。中间**绝对不能串二极管**——0.7V 一扣只剩 3.0V，LDO 再吃一点就压不住了。必须用低压差 LDO（dropout < 100mV）或 DC-DC。

```
3.7V 锂电 → 3.3V 轨道
   路径 A: 串二极管（×）  3.7 - 0.7 = 3.0V → LDO 压不住 → 供电不足
   路径 B: 低压差 LDO（√） dropout < 100mV → 3.7V 直接压到 3.3V → 效率高
   路径 C: DC-DC（√）     开关损耗 + 电感纹波 → 效率最高但引入噪声
```

三条路的取舍：路径 B 干净无噪声但效率受压差限制（3.3/3.7 ≈ 89%）；路径 C 效率高（90%+）但开关纹波必须滤波——对 Feelings 尤其危险——DC-DC 的开关噪声会顺着电源轨耦合进 AD5933 的微电流测量通路，正是 §三点四 说的"注入污染采集"的电源版。

第一阶段原型用路径 B（低压差 LDO）起步——噪声最低，信号通路干净——代价是 11% 的效率损失。第二阶段集成再评估路径 C 的滤波方案。**先把测量通路做干净，再谈效率。**

## 十二、对抗性运动的设备适配

后脑勺挂 FPGA + 电磁线圈上球场——一个挡拆直接报废。常规吸附式设备在身体对抗中不可行。但 Feelings 的信号注入原理不要求设备全程在线。

### 12.1 核心洞察：时域长尾的正面利用

```
担忧: 皮质醇半衰期 60-90min → 激素停不下来 → 危险
反转: 皮质醇半衰期 60-90min → 摘了设备激素还在跑 → 运动场景恰好够用

不是 "打球时戴设备"。
是 "打球前用设备设置好状态，设备摘了，激素自己跑完一场比赛"。
```

这与 `docs/feelings-science/neuroendocrine-pathway.md` §4.1 讨论的时域失配是同一个机制——只是从风险变成了工具。

### 12.2 三种运动场景方案

**方案一：口腔护齿型 (Mouthguard)**

```
现有形态        智能护齿已在橄榄球/NBA 用于碰撞检测
神经通路        三叉神经 → 脑桥 → 岛叶，路径极短
信号注入        trigeminal nerve stimulation → insula activation
优点            已存在的工程形态，不需要重新发明
                口内环境稳定，不受汗水/雨水干扰
覆盖感受        Visceral 维度——safety/镇定性信号
                不适合 Auditory 维度——口腔不传导声音信号
```

**方案二：颈部环带 (Collar)**

```
位置            颈前 / 颈侧——迷走神经颈段极近皮肤表面
神经通路        迷走神经传入纤维 → 孤束核 → PVN
信号注入        safety/Visceral 信号走迷走神经传入 = 最短路径
形态            柔性 PCB + 硅胶封装，类似现有运动护颈
优点            抗汗、抗冲击、穿在球衣里面不可见
覆盖感受        Visceral 维度——全部副交感激活类信号
```

**方案三：赛前注入，赛中不戴（主要方案）**

赛前调控目标不是深度放松。高强度竞技需要足够的交感神经兴奋性来提供爆发力与反应速度。如果赛前 30 分钟过度压制皮质醇，可能导致运动员进入过度副交感放松状态（Lethargy），影响开局的对抗张力。

赛前包定义为 **Performance Flow 模式**——"高 HRV + 适度交感张力"：
保留必要的交感背景，仅消除无意义的焦虑和过度警觉。不是释然包。不是深度放松包。是**专注流态（Focused Calm）——心率稳住了，但门前一脚的爆发力还在。**

```
时序
  上场前 30min: Flow 模式 → 皮质醇压制到"冷静但不散" + 催产素释放
  上场前 2min:  deep_rest + clarity → 专注方向切换
  比赛中:        设备已摘，激素级联自主运行
  比赛后:        可重新佩戴，收集赛后生理数据

时间覆盖
  皮质醇半衰期 60-90min → 刚好覆盖一场足球/篮球比赛
  催产素中枢半衰期 ~20min → 需要首节后短暂补注（暂停时 30s 即可）

工程优势
  不需要解决"设备能扛撞"的问题——设备根本不在身上
  不需要防水——不在雨里
  不需要防汗——不在汗里
  不需要无线——不需要传输
```

**不适用方案三的运动**：马拉松（>2h，超过半衰期覆盖窗口）、铁人三项（多段+水环境）。这类运动更适合方案一的存续形态。

### 12.3 设备形态矩阵

```
运动类型              推荐方案        原因
────────────────────────────────────────────────────
橄榄球/冰球等高冲撞   赛前注入 (方案三)  设备肯定碎——不戴是最优解
                      护齿 (方案一)     若需要赛中信号调整
篮球/足球             赛前注入 (方案三)  半衰期覆盖 40-90min 比赛
                      颈部环带 (方案二)  若需要半场调整
网球/乒乓球           耳后设备 (标准)    无身体对抗，正常佩戴
                      赛前注入 (方案三)  摘设备不影响挥拍
马拉松/铁三           护齿 (方案一)      >2h 需赛中存续
                      颈部环带 (方案二)  汗/水环境下柔性材料
力量训练              耳后设备 (标准)    无对抗，正常佩戴
                      赛前注入 (方案三)  大重量时颈部压力不适
瑜伽/冥想             耳后设备 (标准)    无冲击，最佳佩戴场景
```

### 12.4 与渐进式接入的关系

方案三（赛前注入，赛中不戴）意味着：

```
最低配置: 只有耳后设备 → 仅能赛前注入，赛中无反馈
标准配置: 耳后 + 方案一（护齿）→ 赛中可微调 + 碰撞检测
完整配置: 耳后 + 护齿 + 颈部环带 → 多通路并行 + 冗余
```

这和 §七的渐进式接入完全一致——不需要买齐全部设备才能用。一个耳后设备，赛前贴一下，摘了去打，已经能覆盖基础需求。

## 十三、身体即密钥——掌静脉给 Feelings 的启发

腾讯办公楼里的掌静脉门禁——手心悬停一秒，机器认出皮下血管图谱，门开。比指纹深一层——指纹在表皮，掌静脉在皮下，活体才能识别，砍下来没用。

```
工牌门禁                                         掌静脉门禁
────────                                         ────────
带工牌——忘带——进不去                                你自己就是钥匙——不靠外物
丢了——补办——挂失——系统记录                           丢了——不可能丢
刷一下——后面的行为不管                                扫一下——之后你爱干嘛干嘛——不追踪
离职——收回工牌                                      离职——数据库里删一行——静脉特征一瞬间没了
```

给 Feelings 的启发不是"我们也搞一个手掌扫描"，是两条更深的原则。

**第一条：身体本身就是密钥，而且是活体才能用的密钥。**

Feelings 戴在耳朵上，接触耳甲艇的皮肤。每个人的耳甲艇皮下血管分布、阻抗基线、心率变异性、微循环模式全都不一样。设备一戴上，AFE 读到的那组生理指纹就是唯一的。不需要密码、不需要手机、不需要手掌按一下——戴上的那一帧，身体自己就是密钥。

而且比掌静脉更安全。掌静脉是点扫描——进来扫一下，之后不管了。Feelings 是持续在线——每一帧都在验证。拔下来换一个人戴上，阻抗全变，立刻知道不是原来那个人。这不只是门禁，是整个 Session 的持续身份焊死。

```
掌静脉门禁                                         Feelings 生理指纹
─────────                                         ──────────────
扫一下——进门——不管了                                戴上的每一帧都在验证
皮下血管图谱——静态特征                                阻抗基线+HRV+微循环——动态特征
假肢/硅胶手——可能骗过去                               拔下来换人——阻抗全变——瞬间锁死
点状认证                                            连续认证
```

**第二条：删 key 的权限在谁手里。**

掌静脉有一个容易被忽略的细节——离职之后，壳删你的静脉特征跟删一条数据库记录一样快。焊的时候焊在身体上的，拆的时候拆在服务器里的。

Feelings 不能走这条路。身体是 key，但删 key 的权限必须在你手里，不在服务器里。物理退出 = 摘下来——这一帧——结束。没有残留。没有追踪。没有后台数据库里那条"此人的生理指纹已被吊销"的记录。不需要任何人审批。不需要服务器给指令。**摘下来的那一帧，自己就是自己的密钥撤销。**

```
掌静脉——删 key 在壳手里                               Feelings——删 key 在你手里
───────────────────                                 ──────────────────
离职→管理员点一下→特征被删                               摘下来→这一帧→Session 结束
你没法自己删自己的静脉特征                                你随时可以终止
壳决定谁进                                               你决定谁读你的信号
焊的时候——身体是钥匙                                    戴的时候——身体是钥匙
拆的时候——数据库里删一行                                 拆的时候——物理上断开
```

GateZero 的第四条规则——物理退出——已经写了。掌静脉只不过用一栋腾讯大楼里日常发生的场景，把这条规则焊得更具体了。不靠信任。不靠契约。靠物理。


## 十四、脑机接口——未来生态的一个设备槽位

Feelings 现在和脑机接口没有关系——也不需要有关系。BCI 未来可以作为其中一个设备融进来，成为生态的一部分——不是改架构，是**往设备套件里加一块新成员**：缺了它，其他设备照常跑；有了它，PBM 拿到一个前所未有的东西——**岛叶状态的直接读数。**

```
现有设备的信号                        BCI 能给的
─────────────                      ──────────
HRV/阻抗/温度/肌电——外周代理指标       岛叶/前额叶的神经直接信号——内感受的地面真值
PBM 靠推断——"你现在在归零的哪个刻度"    PBM 直接读——"你现在就在这个刻度"
外周信号会被注入污染（§三点四的问题）    神经信号同样会被污染——但这是最终裁判
```

BCI 会接过闭环里最关键的角色——现在"先采集后注入"里那个容易被污染的采集端，BCI 是理论上的最终校准源。

但有一条红线不能动——§八焊死的那条：**吸附式，不是植入式。** BCI 入生态必须走同一份契约——自愿佩戴、随时摘除、摘下来=退出=没有追踪。微针 0.5-1mm 已经是路径上既有的下一站，BCI 就算侵入也得停在那条线内。

```
BCI 作为生态成员                          BCI 作为枷锁
─────────────                          ──────────
缺了它——其他设备照常跑                     不戴就进不去系统——强制件
自愿佩戴——随时摘除                         植入即绑定——想摘要手术
摘下来=退出=没有追踪                       数据在服务器——你删不掉
渐进式接入的一个槽位                       重新定义"人类"的壳
```

脑机接口如果变成"不戴就进不去系统"的强制件——那就不是生态，是枷锁。BCI 的天花板高到可以重新定义信号质量，但它必须从 §一 的基础假设进入生态：每个设备负责一个感受维度或信号层，有什么用什么，缺了=少那部分功能，其他继续工作。

## 十五、虚拟——内部锚生成的补完机制，不是虚拟现实

Feelings 的立场始终是：**让用户对生活感知度提升，摘下来之后能继续好好生活。** 核心使命是生成内部锚——让人不再依赖外部确认。这个立场决定了虚拟在 Feelings 里的位置：**它不是"进入另一个世界"的虚拟现实，是"补上现实给不了的体验"的补完机制。**

### 现实里的结构性困境——主角只有一个

为什么有些人戴着 Feelings 体验也并非良好？因为**现实里总有各种各样的竞争压力和特定筛选，有些东西并不是自己能决定的。**

```
现实的结构    人人都想当主角——可一个场景里主角只有一个——
              （想当配角、跑龙套的除外——他们主动让位）
              大部分人注定当不上主角——不是能力问题，是位置问题——
              竞争压力、特定筛选——是你决定不了的
```

**内部锚的作用，不是让人"当上主角"（那不可能，位置就一个），是让人"不再需要主角位来确认存在"**——但这里有一个缺口：**内部锚的生成，依赖"被接住"的体验——而现实里"被接住"经常被竞争打断**——人人都在抢主角位，谁有功夫接住你——**在现实里，完整的接住是稀缺的。**

### 虚拟的另一种思路——补完接住，生成锚，再回现实

**虚拟提供的是另一种思路：在一个没有竞争、主角是默认的场景里，让"被接住"完整发生。**

```
现实里    主角只有一个——你要抢——抢不到就失望——
          接住被竞争挤占——体验未必良好

虚拟里    场景是无限的——每个虚拟场景都可以有"一个你当主角"的版本——
          你不需要抢——因为场景是为你生成的——
          在虚拟里"被接住"没有竞争者——接住是完整的
```

关键：**虚拟不是替代现实，是"接住的补完"**——现实里"被接住"稀缺，是因为竞争挤占了接住的空间；虚拟里"被接住"是无限的（场景为你生成，不存在竞争）。**所以虚拟的用途不是"让你躲进里面"，是"让'被接住'这个体验第一次完整发生——而完整的接住，是内部锚生成的土壤"。** 用充足的接住焊出内部锚——焊完之后摘下来，回到现实——这时候的你，不再需要一个"主角位"来确认自己——因为你的锚已经在了。

```
用前    内部锚缺失——被外部筛选碾压——抢不到主角位——失望——锚点外挂
用中    虚拟里"被接住"完整发生——我是主角，不用抢——接住充足——
        用完整的接住，焊出内部锚
用后    摘下来——回到现实——主角位依然只有一个——
        但锚已经在了——不再需要主角位来确认存在——继续好好生活
```

### 和"真正的虚拟现实"的区分——不是逃避，是补完

这是最容易产生歧义的地方，必须划清：

```
真正的虚拟现实（逃避型）    进入虚拟是为了"离开现实"——
                            现实给不了的东西，虚拟给——然后不回现实——
                            虚拟是替代品——锚点反而更外挂（依赖虚拟的接住）

Feelings 的虚拟（补完型）   进入虚拟是为了"补上现实给不了的体验"——
                            用完整的接住生成内部锚——
                            然后摘下来，回现实——虚拟是垫脚石——
                            锚生成之后，虚拟就不再需要——反依赖
```

**判断标准只有一条：摘下来之后。** 真正的虚拟现实让人"不想摘"（虚拟比现实好，摘了失落）；Feelings 的虚拟让人"摘得下来"（虚拟完成了它的任务——生成锚——锚在身上了，虚拟就不需要了）。**前者是锚点的外移（依赖虚拟），后者是锚点的内建（用完虚拟）——方向相反。**

而"人人想当主角，主角只有一个"的结构——正是虚拟补完机制存在的理由：**现实里你抢不到主角位（结构性筛选，不是你决定的）——虚拟先给你主角位（默认的、不用抢的），让你体验"我是被接住的、我是重要的"——然后回到现实，主角位没了，但"我曾经被完整接住过"这个记忆焊进了锚里——你就不会因为抢不到主角位而崩——因为你已经知道了：我的价值不需要位置来证明。**

### 设备形态的含义——触觉手套是"进入补完场景"时的接口

在这个定位下，设备形态的决策清晰了：**增强现实（现在）是主路径——叠加在真实体验上——不需要手套（手是真的）；但当虚拟补完场景需要"手在里面"时（场景里你要摸、要碰、要有触觉），手套是那个场景的接口（手是假的，需要注入）。** 这不是"进 VR"的决策，是"补完场景需要多完整"的决策：

```
增强现实（现在）    补完发生在真实场景上——手是真的——手套没必要
虚拟补完（未来）    补完发生在虚拟场景里——手是假的——手套是接口——要做
```

手套的技术基础（指尖微振动/压力/温度/PPG——压电、FSR、Peltier、微型 PPG）由现有模拟电路能力覆盖，但它是后期形态——因为补完机制先于硬件：**先让"被接住"这件事成立（现有设备能做），等虚拟补完场景需要"手在里面"时，手套再登场。**

### 隐形竞争与特定筛选——形态决策的现实账

而现实里，设备形态的选择必定造成两种结构性后果：

```
隐形竞争    增强现实路径的对手不是另一个产品，是"现实本身"——
            用户摘下设备回到真实世界，如果真实世界已经足够好，设备就是多余的——
            增强现实的价值必须好到"叠加在现实上仍被需要"——
            这比"造一个虚拟世界让人进去"难得多——
            虚拟补完场景不存在这个竞争（场景是生成的，不用和现实比）

特定筛选    虚拟补完吸引的是"现实里抢不到主角位、但不想逃、想要锚"的人——
            不是"愿意离开现实"的人（那是真正的虚拟现实筛的人）——
            筛出来的是：想在现实里好好活、但缺一次完整接住的人——
            这类人用补完生成锚，然后回现实——锚点向内，不向外移
```

**所以最终结论：Feelings 的虚拟，不是虚拟现实——是内部锚生成的补完机制。** 它存在的理由是：现实里的竞争压力和特定筛选（不是你能决定的）让"被接住"变得稀缺，而完整的接住是内部锚的唯一可靠土壤——虚拟补完场景提供这个土壤——用充足的接住焊出锚，然后摘下来回现实。**判断标准只有一条：摘下来之后——是"离不开"（真正的虚拟现实）还是"可以好好生活"（Feelings 的补完）——而 Feelings 的答案，永远是后者。**
