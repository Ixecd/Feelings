# 修车与信号——Feelings 硬件之道和柴油机修理术的同构

> 作者：qc
> 日期：2026-06-21
> 核心：修了几十年大车的父亲不知道 FPGA 是什么。但他的每一根手指都知道物理世界怎么运转——而 Feelings 的硬件，不过是一辆微型化的柴油车。

---

## 一、同一个世界，不同的尺寸

```
大车修理                             Feelings 硬件
───────────────────────────────────────────────────
24V 电瓶                            3.7V 锂电
几百安培启动电流                    几十毫安静态电流
12 毫米粗铜线                       0.1mm 细铜箔
万用表搭铁测通断                    万用表测对地阻抗
耳朵听发动机声音诊断                示波器看纹波诊断
```

本质是同一套物理：**电流从电源出发，经过负载，回到地。路上任何一个地方虚接、短路、电阻偏高——就是故障。**

尺寸变了，原理不变。

---

## 二、电源——他卖了几十年，我用了几个月才懂

```
父亲的日常:
  "这电瓶启动电流不够，你听着启动机转不起来了对吧？"
  "正负极接反，全车电气烧光——我见过不止一次。"
  "冬天电瓶放电快，夏天充电效率高——温度和电有关。"

Feelings 的镜像:
  电压监控   → LDO 输出 1.2V/3.3V，万用表一搭就知道
  极性       → 电池座焊反 = 上电冒烟。他讲的那个"全车烧光"故事
               永远不会发生在 Feelings 上——但原理一样：你接反了，就没了
  温度       → 柔性锂电贴在皮肤上，体温 36°C 是常态
               他说的"冬天夏天不一样"——电池放电曲线随温度漂移的那条线
```

他不认识 LDO。但他认识"电压不够→东西不转"这件事——在 24V 大车上和 3.3V PCB 上，是一个道理。

---

## 三、接地——全车烧光和 PCB 地弹

```
大车:
  接地螺栓松了 → 电流走到不该走的路径 → 线束过热 → 绝缘层熔化 → 起火
  他修过多少次"全车线束重接"——手上有疤。

PCB:
  地平面不完整 → 数字电流走过模拟前端 → PPG 读数 = 电源噪声
  EMI 超标 → 外界的干扰注入到了 PPG 模拟前端 → PPG 读数 = 外界噪声
  板子不会起火——但用户的身体会被错误读取的数据误导
  大车跑在路上，Feelings 贴在皮肤上
  错误的接地在大车上烧了线束——在 Feelings 上烧不了东西——但烧掉了信号的可靠性
```

他修车时的接地思维——每一个螺栓拧紧，每一个搭铁点打磨——就是 PCB 上的"单点接地"和"星型走线"。尺寸缩了三个数量级，逻辑一条没变。

---

## 四、振动——柴油机和 1ms 帧周期

```
大车:
  柴油机怠速 → 低频高振幅振动 → 一切螺丝周期性松脱
  他的解决: 弹簧垫 + 螺纹胶 + 定期检查扭矩

PCB:
  1ms 采样帧周期，对应基频 1kHz
  PCB 机械固有谐振频率若落在该频段 → 振动周期性调制采集信号 → 规律性噪声
  不是信号弱——是噪声比信号大几个数量级

他的"弹簧垫"：
  等于 = PCB 的橡胶减震垫
他的"定期检查扭矩"：
  等于 = 持续监控 AD5933 阻抗基线——偏离即报警
```

---

## 五、接触不良——老本行的巅峰

```
修大车的人对"接触"的敏感度——写在脊椎里:

  电瓶端子没拧紧 → 启动电流不够 → 司机打电话骂人
  线束插头进水 → 接触电阻变大 → 传感器读数乱跳
  保险丝座氧化 → 时通时断 → 最难查的故障


Feelings 的"接触":

  耳后电极没贴好 → 阻抗偏高 → 信号弱
  出汗 → 皮肤电导骤变 → 伪像
  运动 → 电极微移 → 基线漂移

他的世界观:
  "接触不良——四个字我修了三十年。"
  "不要信你的眼睛——万用表打一下。"
  FPGA 开发板上的 SPI 接口——通信时好时坏——他能猜：接触。
  而你才会怀疑是逻辑错。
```

## 六、热管理——发动机散热和皮肤上的 FPGA

```
大车:
  柴油机运行温度 85-95°C
  散热器堵了 → 水温过线 → 发动机拉缸 → 报废

Feelings:
  整机核心功耗器件（FPGA、电源芯片、运放）散热受限
  柔性锂电 + 体温 36°C——热路径几乎不存在
  热管理失败 → FPGA 降频 → 1ms 帧周期保不住

相同的逻辑:
  散热器堵了 = 热路径断了
  大车加散热片、换大风扇 = PCB 加铜皮散热 + 导热硅胶
  他在马路边拧散热器螺丝——和在实验室里调 PCB 热仿真——同一件事
```

## 七、仪表盘和示波器——懂物理的人不需要解释

```
修车:
  听发动机声音 → 诊断
  看排气管颜色 → 诊断
  摸水管温度 → 诊断

硬件调试:
  示波器看纹波 → 诊断
  万用表测对地阻抗 → 诊断 (他的老本行)
  逻辑分析仪抓 SPI → 诊断
```

你跟他说"示波器看电压波形"——他看一下屏幕，说"这不就是发动机转速表？"对。横轴不一样，纵轴不一样——但一个懂物理的人看到的是一个东西：**变化、周期、异常峰值。** 不是仪器多了——是呈现得更细了。不是难度高了——是换了个显示方式。他修了几十年才积累的直觉，在硬件调试中是极有用的——他能帮你盯住那些你盯着协议却忽略了的物理信号。

---

## 八、结论

父亲不知道 FPGA 四个字母，不知道 KiCad 怎么画板子，不知道 0603 电阻长什么样。

但他知道电流不过了就是断了。知道发热了就是阻值高了。知道接触不好的时候信仪表不如打万用表。知道每一次发动机启动都是对整台车所有螺丝的全面检查——所以定期拧紧扭矩不是"多一事"，是"少一毛病"。

Feelings 的硬件——每一层都在复现他修车的逻辑。不是"跨行借鉴"。是**同样的物理规律、不同尺度的表现。** 小到微安的电流，大到几百安培的启动电流，遵从同一条定律。小到微米的贴片电容，大到几十厘米长的轮圈，需要同一双手来调——稳，准，不抖。
