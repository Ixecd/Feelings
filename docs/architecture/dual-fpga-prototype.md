# 双板联调——iCE40 采集 + GW1N 帧引擎的原型闭环

> 作者：qc
> 日期：2026-06-22
> 核心：两块几十块钱的 FPGA 开发板，三根飞线，一套完整的闭环生物安全系统。不是等两板合流——是各验各的，中间只接三根线。

---

## 一、为什么两块板

跨 FPGA 厂商移植是硬件原语全面重构。不想重写：

```
iCE40UP5K (ICESugar, ¥40)
  职责: 传感器驱动 + 数据采集 + 字节流喷出
  工具: IceStorm 开源工具链
  不跑 ESIR 管线 → BRAM 够用

GW1N-LV4LQ144 (¥35)
  职责: Anim ESIR 帧引擎 + NeuroEnergyTracker 漏桶 + 安全熔断
  工具: Gowin IDE 或 openFPGALoader
  180KB BRAM → 帧 buffer + 分支预测器全覆盖
```

两块板不移植代码。iCE40 所有代码写到死只负责采集。GW1N 所有代码负责帧信号。物理界面只在三根线上。

## 三、iCE40 侧——采集与字节流

不做复杂逻辑。只做三件事：

```
1. 初始化:
   I2C 总线 → AD5933 (阻抗) + MAX30102 (PPG)
   1-Wire → DS18B20 (温度)

2. 采集 (1ms 帧):
   读 AD5933 阻抗值 (16bit) + PPG 心率 (16bit)
   DS18B20 异步——每 1000ms 触发一次 Convert，其余 999 帧填上一帧缓存值
   → 打包成 9 字节帧:
     [0xAA, 0xBB, GSR_H, GSR_L, HRV_H, HRV_L, TEMP_H, TEMP_L, CHECKSUM]
     ^------^ 帧头                                XOR 校验和 ^------^

3. 喷出:
   UART TX → 460800 baud → GW1N RX
   9 字节 × 10 bit/byte ÷ 460800 ≈ 195μs → 给 I2C 留 805μs
```

不校验、不纠正、不缓存——RAW 数据直出。GW1N 侧验证 Checksum 失败→丢弃整帧→不污染漏桶。

---

### 3.1 防伪帧 (False Positive)

数据内部的 GSRL 和 HRVH 在动态范围内可能恰好 = [0xAA, 0xBB]。若真帧头因线路扰动丢失 → GW1N 把数据误判为新一帧 → 字节流位移 → 乱码喂入漏桶 → 误熔断。

**解决**：9 字节帧 → 第 9 字节 = 前 8 字节 XOR Checksum。GW1N 收到 9 字节后才算帧有效。校验失败 → 整帧丢弃。

### 3.2 亚稳态同步 (Metastability)

两块板子各有独立晶振。iCE40 TX 信号对 GW1N 时钟是完全异步的外部打入信号。若信号跳变发生在 GW1N 采样时钟的 Setup/Hold 窗口内 → 第一级触发器进入亚稳态 → 接收 FIFO 随机乱码。

**解决**：GW1N UART RX 引脚输入处强制打两拍同步：

```verilog
reg rx_sync_0, rx_sync_1;
always @(posedge clk) begin
    rx_sync_0 <= uart_rx_pin;
    rx_sync_1 <= rx_sync_0; // rx_sync_1 作为状态机真正输入
end
```

### 3.3 断线看门狗 (Watchdog)

UART 飞线松动掉落 → iCE40 继续喷数据 → GW1N 串口中断静默 → 漏桶停在最后一帧 → 无限输出同一强度 → 生物安全红线。

**解决**：GW1N 侧 5ms 超时定时器。每次成功解包合法帧后重置。连续 5 帧无合法数据 → 硬件触发最高优先级熔断，清空帧 Buffer，切回安全锚点帧。

### 3.4 共地噪声 (Ground Loop)

两块板子插电脑 USB → PC 开关电源漏电 → 50Hz 工频噪声沿地线灌入 AD5933 模拟前端 → GSR 读数 = 噪声毛刺 → PBM 校准失效。

**解决**：调试时两块板子统一插同一个移动电源供电。与市电网物理隔离——纯直流浮地。示波器看到的是干净的皮电波形。

### 3.5 I2C 强制升档 Fast Mode (400kHz)

MAX30102 FIFO 连续读 6 字节 + AD5933 阻抗读多寄存器。100kHz 下加上起始/地址/应答开销 → 单次 6 字节读 ≈ 700μs。加上 AD5933 → 805μs 窗口瞬间告急。

**解决**：iCE40 I2C 主控状态机时钟分频系数直接设为 400kHz。所有传感器读取时间缩短到 150-200μs。1ms 循环稳如磐石。

### 3.6 GW1N 侧 UART 波特率分频误差

460800 bps → 16 倍过采样 = 7.3728MHz。GW1N 板载 24MHz → $24 \div 7.3728 \approx 3.25$。强行取分频 3 → 过采样时钟 = 8MHz → 波特率误差 8.5%。串口通信累积误差超 4.5% → 高位字节 + Checksum 随机乱码 → 误触看门狗熔断。

**解决**：利用 GW1N 内部 rPLL 硬核 IP → 把 24MHz 升/降频到能整除 7.3728MHz 的主频。或采用累加器型分数分频，或改用 8 倍过采样替代 16 倍，把波特率误差压到 1% 以内。

### 3.7 看门狗异步清除

5ms 溢出 → 不能只清 Buffer + 状态机排队。输出引脚的物理电平必须在下一个时钟上升沿无条件拉回安全电平（高阻态或绝对安全电压）。熔断信号不等状态机——异步清除，最高优先级直连硬件 pin。

## 四、GW1N 侧——帧引擎与安全熔断

```
1. 中断接收:
   UART RX 打两拍同步后进入状态机
   → 检测帧头 0xAA 0xBB → 收集 9 字节 → XOR Checksum 验证
   → 失败→丢弃；通过→解包

2. 漏桶算账:
   GSR/HRV → NeuroEnergyTracker.intake_and_verify()
   → 四维漏桶累积 → 动态修正 CriticalThreshold + LeakRate
   → 跨维度耦合 σ → 全局桶 → 熔断判定

3. 帧输出:
   安全通过 → ESIR 帧序列从帧 buffer 推出去
   熔断     → 帧 buffer 清零 → 发送安全锚点帧

4. 看门狗:
   5ms 超时定时器。每次收到合法帧后重置。
   超时 → 传感器断开/链路崩溃 → 硬件最高优先级熔断
```

## 六、上电验证顺序

```
0. 两块板子统一插移动电源 → 纯直流浮地 → 与市电物理隔离
1. 万用表测两面 VCC → 3.3V ± 0.1V
2. GND 连通 → 万用表蜂鸣档 → 两面共地 OK
3. iCE40 端 → 写死 UART 每秒发 0x55 → GW1N 接收 → 串口终端看到 0x55
   → 物理层通
4. 接 AD5933 → 测已知电阻 → 读数在规格内
5. 接 PPG → 手指放上 → LED 闪烁 = 心跳 → 波形在示波器上能看到
6. 联合 → iCE40 喷 9 字节帧 + Checksum → GW1N 验证通过 → 漏桶在算
7. 拔掉飞线 → 5ms 内 GW1N 看门狗溢出 → 熔断信号异步直连输出引脚拉安全电平 → Buffer 清零
```
