# 双板联调——iCE40 采集 + GW1N 帧引擎的原型闭环

> 作者：qc
> 日期：2026-06-22
> 核心：两块几十块钱的 FPGA 开发板，三根飞线，一套完整的闭环生物安全系统。不是等两板合流——是各验各的，中间只接三根线。

---

## 一、为什么两块板

跨 FPGA 厂商移植是硬件原语全面重构。不想重写：

```
iCE40UP5K (ICESugar, ¥40)
  职责: 传感器驱动 + 数据采集 + 字节流喷出
  工具: IceStorm 开源工具链
  不跑 ESIR 管线 → BRAM 够用

GW1N-LV4LQ144 (¥35)
  职责: Anim ESIR 帧引擎 + NeuroEnergyTracker 漏桶 + 安全熔断
  工具: Gowin IDE 或 openFPGALoader
  180KB BRAM → 帧 buffer + 分支预测器全覆盖
```

两块板不移植代码。iCE40 所有代码写到死只负责采集。GW1N 所有代码负责帧信号。物理界面只在三根线上。

## 三、iCE40 侧——采集与字节流

不做复杂逻辑。只做三件事：

```
1. 初始化:
   I2C 总线 → AD5933 (阻抗) + MAX30102 (PPG)
   1-Wire → DS18B20 (温度)

2. 采集 (1ms 帧):
   读 AD5933 阻抗值 (16bit) + PPG 心率 (16bit)
   DS18B20 异步——每 1000ms 触发一次 Convert，其余 999 帧填上一帧缓存值
   →   打包成 9 字节帧:
     [0xAA, 0xBB, GSR_H, GSR_L, HRV_H, HRV_L, TEMP_H, TEMP_L, CHECKSUM]
     ^------^ 帧头                                XOR 校验和 ^------^
   → 10 字节帧 (含帧序号):
     [0xAA, 0xBB, GSR_H, GSR_L, HRV_H, HRV_L, TEMP_H, TEMP_L, SEQ, CRC8]
     ^------^ 帧头                           帧序号^--^  ^----------^

3. 喷出:
   UART TX → 460800 baud → GW1N RX
   10 字节 × 10 bit/byte ÷ 460800 ≈ 217μs → 给 I2C 留 783μs
```

不校验、不纠正、不缓存——RAW 数据直出。GW1N 侧验证 Checksum 失败→丢弃整帧→不污染漏桶。

---

### 3.1 防伪帧 (False Positive)

数据内部的 GSRL 和 HRVH 在动态范围内可能恰好 = [0xAA, 0xBB]。若真帧头因线路扰动丢失 → GW1N 把数据误判为新一帧 → 字节流位移 → 乱码喂入漏桶 → 误熔断。

**解决**：9 字节帧 → 第 9 字节 = 前 8 字节 XOR Checksum。GW1N 收到 9 字节后才算帧有效。校验失败 → 整帧丢弃。

### 3.2 亚稳态同步 (Metastability)

两块板子各有独立晶振。iCE40 TX 信号对 GW1N 时钟是完全异步的外部打入信号。若信号跳变发生在 GW1N 采样时钟的 Setup/Hold 窗口内 → 第一级触发器进入亚稳态 → 接收 FIFO 随机乱码。

**解决**：GW1N UART RX 引脚输入处强制打两拍同步：

```verilog
reg rx_sync_0, rx_sync_1;
always @(posedge clk) begin
    rx_sync_0 <= uart_rx_pin;
    rx_sync_1 <= rx_sync_0; // rx_sync_1 作为状态机真正输入
end
```

### 3.3 断线看门狗 (Watchdog)

UART 飞线松动掉落 → iCE40 继续喷数据 → GW1N 串口中断静默 → 漏桶停在最后一帧 → 无限输出同一强度 → 生物安全红线。

**解决**：GW1N 侧 5ms 超时定时器。每次成功解包合法帧后重置。连续 5 帧无合法数据 → 硬件触发最高优先级熔断，清空帧 Buffer，切回安全锚点帧。

### 3.4 共地噪声 (Ground Loop)

两块板子插电脑 USB → PC 开关电源漏电 → 50Hz 工频噪声沿地线灌入 AD5933 模拟前端 → GSR 读数 = 噪声毛刺 → PBM 校准失效。

**解决**：调试时两块板子统一插同一个移动电源供电。与市电网物理隔离——纯直流浮地。示波器看到的是干净的皮电波形。

### 3.5 I2C 强制升档 Fast Mode (400kHz)

MAX30102 FIFO 连续读 6 字节 + AD5933 阻抗读多寄存器。100kHz 下加上起始/地址/应答开销 → 单次 6 字节读 ≈ 700μs。加上 AD5933 → 805μs 窗口瞬间告急。

**解决**：iCE40 I2C 主控状态机时钟分频系数直接设为 400kHz。所有传感器读取时间缩短到 150-200μs。1ms 循环稳如磐石。

### 3.6 GW1N 侧 UART 波特率分频误差

460800 bps → 16 倍过采样 = 7.3728MHz。GW1N 板载 24MHz → $24 \div 7.3728 \approx 3.25$。强行取分频 3 → 过采样时钟 = 8MHz → 波特率误差 8.5%。串口通信累积误差超 4.5% → 高位字节 + Checksum 随机乱码 → 误触看门狗熔断。

分数分频引入周期抖动 → 采样窗口偏移 → 高速 460800 下极易丢字节。降低至 8 倍过采样 → 抗噪能力弱化 → 飞线干扰造成采样误判。

**解决**：GW1N 内部 rPLL 硬核 IP——从 24MHz 生成精准 7.3728MHz 过采样时钟。零误差、零抖动。rPLL 是高云 FPGA 标配硬核，不消耗逻辑单元。不妥协分频，不降低过采样倍数。

### 3.7 看门狗异步清除

5ms 溢出 → 不能只清 Buffer + 状态机排队。输出引脚的物理电平必须在下一个时钟上升沿无条件拉回安全电平（高阻态或绝对安全电压）。熔断信号不等状态机——异步清除，最高优先级直连硬件 pin。

### 3.8 采集时序 FIFO 解耦

I2C 400kHz 压缩传感器读取到 200μs 以内——但 DS18B20 转换超时重读、AD5933 增益校准额外耗时等负载波动会击穿 1ms 窗口。时序溢出 → 帧打包延迟 → UART 流速率错乱 → GW1N 校验大面积失败。

**解决**：iCE40 侧引入小型输出 FIFO（~16 字节，占极小 BRAM）。采集逻辑写完帧即返回——不等串口发送完。UART 状态机独立从 FIFO 读帧发送。采集周期不再被传输阻塞——时序余量大幅拉宽。

### 3.9 量产级共地降噪

移动电源浮地仅覆盖调试场景。量产整机 DC-DC 电源 + 压电升压高压电路持续引入共模噪声污染 AD5933 模拟前端——浮地治标不治本。

**解决**：
```
iCE40 模拟区单点接地——数字地/模拟地 0Ω 电阻单点汇流——分割铺铜
AD5933 电源: LC 滤波 + 0.1μF + 10μF 去耦电容
传感器 I2C 总线: 串联 220Ω 限流电阻——抑制数字开关噪声耦合
```

### 3.10 压电功率侧防护

当前仅在 PWM 信号端加数字隔离器——升压芯片功率地、高压输出端无隔离。50V 高压瞬态浪涌仍有耦合到系统地的风险。

**解决**：升压芯片供电增加 TVS 管吸收高压反激浪涌。隔离器两侧独立供电——彻底切断功率域与采集数字域地环路。

### 3.11 熔断自动恢复

飞线短暂接触不良 → 看门狗熔断 → 链路恢复后系统永久停在安全锚点帧 → 需人工重新上电复位。

**解决**：熔断锁存 + 解锁条件。连续收到 3 帧合法校验通过的数据 → 自动清除熔断锁存 → 恢复 ESIR 正常帧输出。不需要重启设备。

### 3.12 CRC-8-CCITT 换 XOR

单字节 XOR 只能检出单比特翻转——连续多位错误、字节错位极易漏检。原型阶段够用，迭代替换为 CRC-8-CCITT（多项式 $X^8 + X^2 + X + 1$）。Verilog 实现只需 ~8 个 LUT 组合逻辑，一条流水线打过去。漏检率下降几个数量级。

### 3.13 BRAM 余量预留

GW1N BRAM 全部分配给帧 buffer + 漏桶预测器。后期新增世界模型、Agent 逻辑会资源溢出。原型阶段预留 ~10% BRAM 空闲，方便迭代扩展。

### 3.14 在线动态配置寄存器

漏桶参数（LeakRate、CriticalThreshold、跨维度耦合 σ）写死在 Verilog 里 → 每次调参重编译 GW1N → 几百次迭代 = 几百次编译。原型阶段开一条极简配置总线（外部调参板临时接入或串口转发）把这些参数变成可在线修改的寄存器——不用重烧 FPGA。

### 3.15 AD5933 上电 1s 自标定

AD5933 内部振荡器和外部放大器在不同体温、环境温度下——初始相位和阻抗增益（Gain Factor）会漂移。上电前 1s 用模拟开关先切到板载 1% 精度标准电阻——跑一轮自校准拿到当前真实基线——再切回人体电极。不是医疗设备，但精度可以和医疗设备看齐。

### 3.16 帧序号 + GW1N 接收 FIFO

10 字节帧——第 9 字节帧序号（0-255 循环），第 10 字节 CRC-8-CCITT。GW1N 直接统计丢帧率、判断字节错位——不用示波器。GW1N 侧 16-32 字节接收 FIFO——防状态机处理慢时溢出丢包。iCE40 发送 FIFO 满 → 丢旧帧保留最新帧 + 记录丢帧计数——绝不阻塞 1ms 采集主循环。

### 3.17 硬件电流比较器——最后一道纯硬件防线

算法漏桶→FPGA 逻辑熔断→外部下拉电阻。再补一道不需 FPGA 的纯硬件兜底：电域恒流源输出回路串 100Ω 精密采样电阻 + 硬件比较器设定 1.2 倍最大安全电流阈值。一旦超限——比较器直接拉低恒流源使能端——不经过 FPGA。逻辑跑飞、引脚异常——绕不过这道物理栅。

### 3.18 模拟前端滤波

AD5933 高阻抗模拟前端——体表 50Hz 工频干扰直接耦合，只靠前端滤波不够。每路电极输入端串 10kΩ + 并 100nF 电容到模拟地——截止频率约 160Hz——滤除工频高频谐波，不影响 GSR 低频信号。I2C SDA/SCL 各串 220Ω + 靠近 FPGA 端放 100pF 去耦电容——抑制数字开关尖峰。

### 3.19 调试 LED——没有示波器的唯一排错手段

软件转硬件最头疼的是"不知道哪里出问题"。4 个 LED 定位 90% 基础问题：

```
iCE40:
  LED1  采集状态灯   1s 闪一次 = 正常  常亮/常灭 = 主循环卡死
  LED2  I2C 错误灯   传感器通信失败常亮

GW1N:
  LED3  帧接收灯    每秒闪一次 = 持续收到合法帧
  LED4  熔断状态灯   常亮 = 触发熔断  闪烁 = 看门狗超时
```

不用串口、不用示波器——上电看灯就知物理层/链路层/业务层是否正常。

### 3.20 测试模式——伪数据源脱离传感器调试

iCE40 GPIO 引脚拉高→测试模式。不接传感器——自动生成递增 GSR/HRV/温度伪数据、打包合法 10 字节帧发出。GW1N 帧引擎 + 漏桶算法 + 熔断逻辑完全脱离传感器硬件独立调试。前后端并行开发——不用纠结"读数不对是传感器还是算法"。

## 四、GW1N 侧——帧引擎与安全熔断

```
1. 中断接收:
   UART RX 打两拍同步后进入状态机
   → 检测帧头 0xAA 0xBB → 收集 9 字节 → XOR Checksum 验证
   → 失败→丢弃；通过→解包

2. 漏桶算账:
   GSR/HRV → NeuroEnergyTracker.intake_and_verify()
   → 四维漏桶累积 → 动态修正 CriticalThreshold + LeakRate
   → 跨维度耦合 σ → 全局桶 → 熔断判定

3. 帧输出:
   安全通过 → ESIR 帧序列从帧 buffer 推出去
   熔断     → 帧 buffer 清零 → 发送安全锚点帧

4. 看门狗:
   5ms 超时定时器。每次收到合法帧后重置。
   超时 → 传感器断开/链路崩溃 → 硬件最高优先级熔断
```

## 五、多模态物理域路由——不是全走电极

GW1N 的 ESIR 输出根据物理介质分三路。不是全用电极——不同的感官走不同的物理载体：

```
电域 (Electrical):
  通路: VNS(耳后) / Trigeminal(护齿) / Cortical(太阳穴)
  硬件: 恒流源 DAC → 电极 → 神经直接激活
  安全: 最高优先级硬件熔断——切断恒流源使能端——清空帧 buffer

机械域 (Mechanical):
  通路: CtFiber(腕部触觉) / SpinalCervical(后颈本体感)
  硬件: PWM → LRA 线性马达 / 压电陶瓷 → 机械振动
  安全: 软件级衰减——降占空比，不走全局硬件熔断

声学域 (Acoustic):
  通路: Cochlear(骨传导振子)
  硬件: I2S 总线 → Audio DAC → 骨传导功放
  安全: 限幅 + 动态范围压缩——不过载声损伤
```

### 4.1 非对称熔断

不同的物理介质——熔断策略是不同的。电域上的积累能量必须切断电源；机械域上的触觉只有降占空比；骨传导上的信号只需要限幅度——其他通道的安全监测可以继续正常运转。

```
NeuroEnergyTracker 四维漏桶
  ↓
  ├─ 电域 → 临界值超限 → 硬件使能切断 + 全局锚点帧切换 (最高优先级)
  ├─ 机械域 → 临界值超限 → PWM 降占空比 + 进入静默节律 (软件级衰减，不影响电域)
  └─ 声学域 → 临界值超限 → DRC 介入 + 动态范围压缩 (体验保护，不触发全局熔断)
```

### 4.2 物理隔离——不需要通道间隔离电路

电、机械、声三个域的物理介质是完全独立的——VNS 电流不会串到骨传导振子上，机械振动没有电荷交换。不需要多通道电气隔离——只需要集中精力做好电极那一路的恒流隔离。整个系统的抗干扰能力在物理层面就已经拉高了一个数量级。

### 4.3 电域硬件死锁防护

FPGA 复位或熔断时 GPIO 进入高阻态 → 恒流源 EN 引脚悬空 → 电平不确定 → 随机放电。

**防线一**：DAC 使能端 PCB 走线上焊 4.7kΩ 强下拉电阻到 GND。FPGA 三态化时外部电路无条件将使能端拉低，关闭电流。

**防线二**：GW1N 内部漏桶电域超限信号 + 看门狗超时信号 → 纯组合逻辑或门直连输出引脚。不经过时钟同步排队——异步硬路径。

### 4.4 机械域——压电高压回灌

LRA 马达 2-5V 安全，但压电陶瓷需 50V+ 高压驱动。升压电感 EMI + 高压地 → 与 AD5933 模拟地共地 → 开关噪声污染阻抗前级。

**防线**：GW1N PWM 输出与压电驱动芯片之间加 ¥1.5 数字隔离器。高压地与传感器模拟地物理切断。

### 4.5 声学域——I2S 跨时钟域

ESIR 管线 1ms 帧写入 vs Audio DAC 16kHz LRCK 读出——两套完全不同的时钟。

**防线**：GW1N BRAM 配置为双口 RAM。写侧由帧状态机控制，读侧由 I2S BCLK/LRCK 时钟域控制。天然跨时钟域对齐，不加额外同步逻辑。

### 4.6 非对称熔断的跨维度耦合

机械域或声学域超限 → 不触发全局电域熔断。但它们的累积能量应在数字层面动态抬高电域的敏感度——当机械或声学漏桶充盈度超 80% 时，电域的临界阈值自动下调一个 σ。物理隔离不等于系统论忽视——身体是一个整体。

## 七、上电验证顺序

```
0. 两块板子统一插移动电源 → 纯直流浮地 → 与市电物理隔离
1. 万用表测两面 VCC → 3.3V ± 0.1V
2. GND 连通 → 万用表蜂鸣档 → 两面共地 OK

```
