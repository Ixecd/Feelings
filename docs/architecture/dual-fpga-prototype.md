# 双板联调——iCE40 采集 + GW1N 帧引擎的原型闭环

> 作者：qc
> 日期：2026-06-22
> 核心：两块几十块钱的 FPGA 开发板，三根飞线，一套完整的闭环生物安全系统。不是等两板合流——是各验各的，中间只接三根线。

---

## 一、为什么两块板

跨 FPGA 厂商移植是硬件原语全面重构。不想重写：

```
iCE40UP5K (ICESugar, ¥40)
  职责: 传感器驱动 + 数据采集 + 字节流喷出
  工具: IceStorm 开源工具链
  不跑 ESIR 管线 → BRAM 够用

GW1N-LV4LQ144 (¥35)
  职责: Anim ESIR 帧引擎 + NeuroEnergyTracker 漏桶 + 安全熔断
  工具: Gowin IDE 或 openFPGALoader
  180KB BRAM → 帧 buffer + 分支预测器全覆盖
```

两块板不移植代码。iCE40 所有代码写到死只负责采集。GW1N 所有代码负责帧信号。物理界面只在三根线上。

## 二、物理连接——三根线

```
┌──────────────────────┐                     ┌──────────────────────┐
│    iCE40 (v0.5)      │                     │    GW1N-4 (v0.6)     │
│                      │                     │                      │
│ ┌──────────────────┐ │    GSR / HRV 字节流  │ ┌──────────────────┐ │
│ │ AD5933 + PPG 驱动 │─┼─── UART TX/RX ───────>│ │ Anim ESIR 管线   │ │
│ └──────────────────┘ │                     │ │ (漏桶/安全机制)    │ │
└──────────────────────┘                     └───────────────────┬──┘
                                                                  │ (输出)
                                                                  ▼
                                                             安全执行帧
```

```
接线:
  iCE40 GND  ←→  GW1N GND      共地
  iCE40 TX   →   GW1N RX       数据单向流
  iCE40 RX   ←   GW1N TX       可选——GW1N 回传确认帧 (ACK)

总共: 3 根杜邦线。不需要电平转换——两块板都是 3.3V。
```

## 三、iCE40 侧——采集与字节流

不做复杂逻辑。只做三件事：

```
1. 初始化:
   I2C 总线 → AD5933 (阻抗) + MAX30102 (PPG)
   1-Wire → DS18B20 (温度)

2. 采集 (1ms 帧):
   读 AD5933 阻抗值 (16bit) + PPG 心率 (16bit) + 温度 (16bit)
   → 打包成 8 字节帧:
     [0xAA, 0xBB, GSR_H, GSR_L, HRV_H, HRV_L, TEMP_H, TEMP_L]
     ^------^ 帧头

3. 喷出:
   UART TX → 115200 baud → GW1N RX
   每毫秒喷 8 字节 → 64kbps → 串口轻松跑
```

不校验、不纠正、不缓存——RAW 数据直出。如果 GW1N 没收到——下一帧 1ms 后到。

---

## 四、GW1N 侧——帧引擎与安全熔断

```
1. 中断接收:
   UART RX 中断 → 检测帧头 0xAA 0xBB → 收集 8 字节 → 解包

2. 漏桶算账:
   GSR/HRV → NeuroEnergyTracker.intake_and_verify()
   → 四维漏桶累积 → 动态修正 CriticalThreshold + LeakRate
   → 跨维度耦合 σ → 全局桶 → 熔断判定

3. 帧输出:
   安全通过 → ESIR 帧序列从帧 buffer 推出去
   熔断     → 帧 buffer 清零 → 发送安全锚点帧
```

## 五、ADR 对齐

```
ADR 008   FSIR ABI              Postcard 二进制 = ESIR 帧格式
ADR 011   Neuro-Leaky Bucket   漏桶状态机在 GW1N BRAM 里跑
ADR 012   Rhythm + Cap         GW1N 接收 GSR/HRV 后动态调 cap
ADR 016   DeviceCapability     iCE40 = 采集设备，GW1N = 注入设备
```

## 六、上电验证顺序

```
1. 万用表测两面 VCC → 3.3V ± 0.1V
2. GND 连通 → 万用表蜂鸣档 → 两面共地 OK
3. iCE40 端 → 写死 UART 每秒发 0x55 → GW1N 接收 → 串口终端看到 0x55
   → 物理层通
4. 接 AD5933 → 测已知电阻 → 读数在规格内
5. 接 PPG → 手指放上 → LED 闪烁 = 心跳 → 波形在示波器上能看到
6. 联合 → iCE40 真的在喷 8 字节帧 → GW1N 真的在解 → 漏桶真的在算
```
