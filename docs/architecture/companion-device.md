# 飞行陪伴体：伙伴的眼睛，不是监控设备

> 作者：qc
> 日期：2026-04-11
> 来源：大唐不夜城的飞行小玩具，把「摄像头是伙伴的眼睛」从隐喻变成产品

---

## 一、设计起点

Feelings 的四诊合参需要「望」——摄像头读取面部微表情和体态。

但摄像头有一个天然的心理负担：「它在看我」→ 用户开始表演 → 数据失真。

解法是把摄像头从「监控设备」变成「伙伴的眼睛」。

飞行陪伴体把这个设计从隐喻变成了真实的产品形态——不是固定在某个角落盯着你的镜头，是一个会飞的小东西，绕着你转，陪着你，用它的眼睛看你。

---

## 二、形态设计

**默认形态：熊猫**

```
软萌，低威胁感
第一眼让人想摸，不是让人警惕
熊猫的圆形轮廓和黑白配色，视觉上最不具攻击性
而且熊猫本身就具备好奇性——「这是什么？」
```

**可定制**

```
用户可以选择自己的伙伴形象
不限于动物，可以是任何用户喜欢的形态
形象是皮，功能不变
```

**好奇性入场**

用户第一次看到飞行陪伴体，第一个反应是「这是什么？」——好奇心天然被激活，防御还没有建立。这是最好的第一印象时机。

## 三、静音飞行：猫头鹰仿生设计

飞行陪伴体和你在一起的时间很长。它不是偶尔飞一下，是持续在场。

如果它吵，用户会下意识把它关掉——不是不喜欢它，是噪音让人无法安静。陪伴体一关，望诊就没了，四诊合参就缺了一角。

所以飞行噪音不是体验问题，是功能可用性问题。安静不是加分项，是底线。

### 3.1 猫头鹰是怎么做到的

猫头鹰是自然界最安静的飞行者。它的猎物——田鼠、蝙蝠——听力极度敏锐，但猫头鹰掠过时，它们听不到任何东西。

安静不是靠慢，是靠结构。三个特征：

```
前缘锯齿
    翅膀最前缘的羽毛呈梳齿状，凹凸不齐
    平滑表面会把气流推成一个大涡流 → 产生明显的嘶嘶声
    锯齿结构把气流打碎成无数微型涡流 → 每个涡流太小，无法形成可听噪声
    本质：把大噪声分解成听不见的小噪声

绒面结构
    翅膀上表面和腿部覆盖极细密的绒羽
    像天鹅绒一样的质地
    吸收飞行中摩擦产生的高频声音
    本质：把翅膀本身变成一个天然的吸音材料

后缘流苏
    翅膀后缘的羽毛末梢松散，像软毛刷
    后缘是上下表面气流汇合处——平滑边缘会产生明显的湍流劈裂声
    流苏结构允许气流逐渐混合，而非突然碰撞
    本质：降低气流混合速度，消除劈裂声峰值
```

三个特征配合在一起：**前缘打碎噪声 → 绒面吸收残余 → 后缘平滑释放**。一整套物理降噪链路。

### 3.2 在飞行陪伴体上的工程翻译

飞行陪伴体不是猫头鹰——它用的是旋翼/涵道风扇，不是扑翼。但三条降噪原理可以直接翻译：

```
前缘锯齿 → 旋翼叶片前缘造型
    叶片前缘不光滑，做微锯齿纹理（0.3-0.5mm 齿深）
    单片叶产生的大涡流 → 打散为大量微涡流
    工艺：精密注塑成型，模具表面微米级激光蚀刻

绒面结构 → 涵道内壁吸音层
    涵道内壁覆盖仿绒面微结构——微孔阵列 + 绒状涂层
    吸收叶片经过涵道壁时的高频摩擦声
    工艺：微发泡聚氨酯内衬，表面开放微孔密度 > 80%

后缘流苏 → 叶片尾缘柔性后掠
    叶片尾缘做柔软的后掠渐变，末端不是锋利的直角
    类似猫头鹰飞羽的末端分叉——让对侧气流逐渐混合而非突然劈裂
    工艺：TPU 柔性材料包覆叶片尾缘，硬度从叶根到叶尖递减
```

### 3.3 旋翼降噪：转速和叶片联动

摩擦声只是噪声来源之一。另一大来源是**叶片尖端涡流**——旋翼高速旋转时，叶尖不断切过上一圈留下的涡流，产生周期性的「啪啪」声（Blade-Vortex Interaction，BVI）。

BVI 是小型飞行器最明显的噪声特征。直升机越用力，啪啪声越大。陪伴体不能有这个声音——在安静房间里，它必须几乎无声。

```
抑制 BVI 的三条路径

路径一：增大桨盘面积
    相同升力下，桨盘面积越大，叶片单位面积载荷越小
    载荷小 → 叶尖涡流弱 → BVI 声压降低
    具体：采用多叶片设计 + 等效桨盘面积最大化（在尺寸约束下）

路径二：降低叶尖马赫数
    转速越低，叶尖线速度越低，BVI 越弱
    但低转速 = 低升力 → 必须用更大桨盘面积补偿
    两个参数互为代价：陪伴体的尺寸上限（约 15-20cm 翼展）给定了
    在此约束下找转速和桨面积的帕累托最优

路径三：叶片涡流分布控制
    均布载荷叶片 → 叶尖集中涡流
    椭圆分布载荷叶片 → 涡流沿叶展分散
    分散的涡流比集中的更难形成可听 BVI
    具体：叶片翼型从叶根到叶尖渐变
```

**在 15-20cm 尺度上的预期效果**

```
安静室内（背景噪声 ~25dBA）
    陪伴体悬停时 50cm 处的目标噪声 < 30dBA
    实测目标     几乎无法被用户察觉
                「比翻书的声音还小」

低速跟随（1-2m/s）
    目标噪声     < 35dBA
                用户听到的不是噪声，是轻微的空气流动感

公共场合（环境噪声 ~50-60dBA）
    陪伴体完全融入环境底噪，不可分辨
```

### 3.4 电机和传动噪声

旋翼不是唯一噪声源。电机、轴承、传动机构都有自己的声音。

```
无刷电机
    外转子无刷电机——低 KV 值，大扭矩，低转速，较安静
    PWM 驱动频率 > 20kHz——超出人耳可听范围
    正弦波驱动（非方波）——消除换向时的电流冲击噪声

陶瓷轴承
    微型陶瓷球轴承代替钢轴承
    硬度更高，圆度更精确——振动更少
    不需要油脂润滑——干式运转，无油脂搅动声
    寿命更长——陪伴体是日常用品，不是赛季器材

传动消除
    直驱设计，无减速齿轮组
    常见做法：电机 → 小齿轮 → 大齿轮（减速增扭）→ 旋翼
    噪音代价：齿轮啮合的持续高频啸叫
    陪伴体：电机转子直接连接旋翼轴
    代价：需要专门的极低 KV 电机——转速刚好匹配旋翼最优转速
    对控制算法的要求更高，但换来了零齿轮噪声
```

### 3.5 涵道设计：推力 + 静音 + 安全

陪伴体采用涵道风扇而非开放旋翼。涵道本身既是安全保护（叶片不外露），也是声学屏障。

```
涵道气动声学设计
    入口收缩段
        气流加速入口，减少入口湍流
        入口边缘倒圆处理，避免气流分离啸叫

    中段叶片区
        叶片尖端与涵道内壁间隙 ≤ 0.5mm
        间隙越小，叶尖泄漏涡越弱
        这是 BVI 抑制最有效的手段之一

    出口扩散段
        气流逐步减速排出，减少出口湍流
        出口边缘同样做流苏状锯齿
        消除出口处的涡脱落噪声

涵道声学隔离
    涵道外壳夹层结构
        外层：轻薄刚性壳体（保持结构强度）
        中间：微发泡吸音层（2-3mm厚度）
        内层：仿绒面微结构表面（见 3.1 节）
    三层结构让涵道本身成为一个物理低通滤波器
    高频噪声在穿出涵道之前就被吸收
```

### 3.6 低噪声飞行姿态

降噪不只是硬件的事。怎么飞也决定了安静不安静。

```
悬停
    噪声最低的姿态
    叶片恒速，气流稳定，涡流模式不变
    陪伴体大多数时间处于悬停或极慢跟随状态

加速 / 爬升
    需要瞬时加力，噪声短暂上升
    姿态切换的过渡噪声不可避免，但可以最小化
    加速曲线平滑——不突然跳转速，用缓启动算法

下降
    关键：避免涡环状态（Vortex Ring State）
    下降太快 → 叶片卷入自己制造的下洗气流 → 涡流急剧增大
    → 噪声骤升 + 升力骤降（最危险的小型飞行器状态之一）
    陪伴体下降速率被硬编码上限：< 0.3m/s（猫头鹰捕猎时的典型下降速率）
    宁愿慢，不宁愿吵，更不宁愿摔

跟随时
    用户走路速度通常 1-1.5m/s
    此速度下陪伴体轻松跟随，噪声低于 35dBA
    重点：跟随时的平滑轨迹规划
        不突然加速追位置，用预判补偿延迟
        四诊数据提前预判用户移动方向
```

### 3.7 这和多旋翼常见做法的区别

消费级无人机行业的设计优先级：

```
常见多旋翼         飞行陪伴体
───────────       ─────────────
推力最大化          安静最优先
续航最大化          安静最优先
散热靠风冷          放弃风冷依赖（安静优先意味着低速，意味着散热靠自己）
外观靠贴纸          biomimetic 结构即外观
螺旋桨是消耗品      叶片是不可更换的一体结构（安静结构=复杂结构）
```

陪伴体不做可折叠、不做快拆、不做模块化旋翼。安静是一体化的——锯齿、绒面、流苏、涵道、直驱，每一项都融进机身本体，拆开就没有意义。

## 四、功能设计

**感知功能**

```
摄像头（望）    面部微表情 / 瞳孔 / 眨眼 / 体态
麦克风（闻）    语调 / 语速 / 呼吸节律
数据处理        本地，不上传，和其他设备数据汇入同一个AI教练
```

**陪伴功能**

```
绕着用户飞行    不是悬停盯着，是自然地在场
靠近时          轻微的存在感，「我在这里」
距离感          自动维持合适的距离，不侵入用户空间
```

**记录美好瞬间**

```
拍照 / 录像
    用户指令或系统判断「这是值得记录的时刻」
    从伙伴的视角留下记录
    数据本地存储，不上传
    用户完全控制：可以随时删除，可以关闭记录功能

什么时候自动记录
    感受峰值时刻（用户明确授权的情况下）
    用户主动呼唤「记录一下」
    默认不自动记录，需要用户主动开启
```

**AI教练的物理出口**

```
怒斥时          俯冲靠近，语气有力但不冲
                「你在偷懒，我看见了」
                比冷冰冰的文字提示更有存在感

鼓励时          轻盈地绕一圈
                「你刚才扛住了」

警告时          悬停在面前，轻微震动

礼貌呵斥（公共场合）
                不乱跑：「这里人多，跟紧我」
                不碰人：自动感知周围人员，保持安全距离
                不扰民：安静场所噪音本身已极低（见第三节），无需额外降噪
                        公共场合自动切换「低调模式」——降低飞行高度，减少动线
```

## 五、一个教练，多只眼睛

飞行陪伴体是AI教练的一只眼，不是独立的AI：

```
不是    多个设备 → 各自判断 → 汇总结论
而是    多个设备 = 同一个AI教练的多只感知器官

耳后设备    切（心率/皮肤电导）
腕部设备    切（精确皮肤电导/呼吸）
飞行陪伴体  望（摄像头）+ 闻（麦克风）
颞部设备    切（前额叶状态）

所有感知    汇入同一个AI教练
AI教练      用所有感知做一个综合判断，不是多个判断相加
```

这和四诊合参的哲学完全一致——不是多个医生各自看，是一个医生用多种感知做一个综合判断。

## 六、特殊用户群体的陪伴体设计

对于智障、残疾等特殊用户群体，飞行陪伴体的角色需要根本性调整：

```
普通用户    教练——推你，有时候吼你，有时候拒绝你
特殊用户    陪伴守护者——不推，不吼，但一直在

具体调整
    飞行更平稳，更轻柔，不做突然的俯冲动作
    语音更温和，语调更低，节奏更慢
    感知异常立刻响应，但不用「怒斥」，用「靠近陪伴」
    和监护人/治疗师的设备联动，异常时同步通知
    AI教练降级为陪伴者模式，不做推动性干预
```

这是一个完全独立的使用协议，需要专门设计和测试。
